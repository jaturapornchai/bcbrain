# โปรโมชั่นในแอป POS

โปรโมชั่นตั้งในระบบหลัก BC Ai Account แล้วซิงก์มาที่เครื่อง แอปคำนวณใหม่ทุกครั้งที่เพิ่ม/ลบ/แก้รายการ ผลแสดงในแถบ "โปรโมชั่นและสิทธิพิเศษ" ใต้รายการสินค้า (กดย่อ/ขยายได้)

## ชนิดโปรโมชั่นและสิ่งที่แอปทำ
| ชนิด | ตัวอย่าง | แอปทำอะไร |
|---|---|---|
| ซื้อครบจำนวน ลดราคา (บาทหรือ %) | คละครบ 3 ชิ้น ลด 5% | **ลดให้อัตโนมัติ** ที่ท้ายบิล |
| ซื้อครบจำนวน ลดตามสเต็ป | ซื้อมากลดมาก | **ลดให้อัตโนมัติ** |
| ราคาเหมา/ราคาพิเศษต่อหน่วย | ซื้อครบ 3 ขวด ขวดละ 50 บาท | **ลดให้อัตโนมัติ** (จำกัดจำนวนต่อบิลได้) |
| ซื้อครบยอด ลดเงินสดท้ายบิล | ครบ 500 ลด 20 | **ลดให้อัตโนมัติ** |
| ซื้อครบยอด ลด % ท้ายบิล | สมาชิก VIP ลด 5% | **ลดให้อัตโนมัติ** |
| ซื้อครบจำนวน/ครบยอด แถมสินค้าฟรี | ครบ 1,000 แถมทิชชู่ | **แสดงข้อความแจ้งเท่านั้น** แคชเชียร์ต้องหยิบของแถมเอง |
| คละกลุ่มสินค้า แถมฟรี | | แสดงข้อความแจ้งเท่านั้น |
| สะสมยอดสินค้าแบรนด์ของร้าน แจกคูปองท้ายบิล / แลกของพรีเมียม | | แสดงข้อความแจ้งเท่านั้น |

ส่วนลดจากโปรโมชั่นจะถูกใส่เป็น "ส่วนลดท้ายบิล" ตอนไหนที่ยังไม่มีส่วนลดท้ายบิลที่แคชเชียร์กรอกเอง ถ้ามีส่วนลดที่กรอกเองอยู่ก่อน โปรโมชั่นจะไม่ทับ

## เงื่อนไขที่แอปตรวจ
- ช่วงวันที่เริ่ม-สิ้นสุดของโปรโมชั่น
- ตัวกรองวัน: เสาร์-อาทิตย์, วันที่ 1 และ 16, ช่วงวันที่ 25 ถึง 5
- ใช้เฉพาะสมาชิก หรือเฉพาะสมาชิกระดับ VIP/GOLD/PLATINUM หรือกลุ่มร้านค้าส่ง
- จำนวนขั้นต่ำ ยอดขั้นต่ำ และจำนวนสูงสุดต่อบิล

## ข้อจำกัด (ตรงๆ)
- **ไม่ตรวจช่วงเวลาของวัน** เช่นโปร 17:00-20:00 แอปจะไม่แยกตามเวลา ตรวจแค่วันที่และตัวกรองวัน
- ของแถมไม่เข้าตะกร้าเอง แม้ระบบหลังตั้งว่าให้เพิ่มอัตโนมัติ
- ถ้าเปลี่ยนราคาเอง/ใส่ส่วนลดเอง แอปคำนวณโปรโมชั่นใหม่ให้
- ปุ่มคำนวณใหม่ (ไอคอนบนแถบบน) ใช้สั่งคำนวณซ้ำได้
