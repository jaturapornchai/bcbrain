# ระบบจัดซื้อและเทียบราคา PO และ RFQ

ระบบ **จัดซื้อ PO และ RFQ** ช่วยฝ่ายจัดซื้อวางแผนสั่งสินค้าเติมคลังอย่างเป็นระบบ ตั้งแต่เรดาร์แจ้งเตือนของใกล้หมด ไปจนถึงการขอใบเสนอราคาเทียบหลายเจ้า การวนต่อรองราคา การอนุมัติสั่งซื้อ และการตรวจรับเทียบ 3 ทางร่วมกับคลังสินค้าและบัญชี

## ขั้นตอนการทำงานครบวงจร

1. **เรดาร์สินค้าใกล้หมด (Replenishment Radar)**: ดึงรายการสินค้าที่สต็อกต่ำกว่าเกณฑ์เพื่อแนะนำจำนวนสั่งซื้อ สามารถกดสร้างใบสั่งซื้อหรือหยิบใส่ตะกร้าขอซื้อได้ทันที
2. **ตะกร้าขอซื้อ (PR Cart) และขอใบเสนอราคา (RFQ)**: ส่งรายการเข้ากระบวนการสืบราคาโดยดึงใบเสนอราคาจากผู้ขายเทียบกัน (เช่น เทียบ 3 ราย) พร้อมแนบไฟล์/ภาพใบเสนอราคาเก็บในที่เก็บไฟล์กลาง
3. **การวนต่อรองราคาหลายรอบ**: บันทึกรอบการต่อรองราคาเมื่อผู้ขายลดราคาลงมาในรอบถัดไป เพื่อให้ผู้มีอำนาจเห็นประวัติราคาก่อนอนุมัติ
4. **อนุมัติสั่งซื้อและส่งเข้าคลังรับของ (PO & 3-Way Match)**: เมื่อสั่งซื้อแล้ว เอกสารจะเชื่อมต่อไปยัง [[sys-wms-warehouse]] เพื่อตรวจรับหน้าท่า ถ่ายรูปพาเลทและใบส่งของ จากนั้นจับคู่ 3 ทาง (ใบสั่งซื้อ — ใบรับของคลัง — ใบกำกับภาษีซื้อ) ก่อนส่งข้อมูลภาษีเข้า [[sys-etax-invoice]] และ [[sys-account-overview]]

## เหมาะกับธุรกิจแบบไหนและข้อควรทราบในการใช้งานจริง

- **เหมาะกับและช่วยลดงานอะไร**: เหมาะกับกิจการค้าส่ง ศูนย์กระจายสินค้า ผู้รับเหมา โรงงาน และองค์กรที่ต้องสั่งซื้อของจำนวนมากจากผู้ขายหลายราย ช่วยแจ้งเตือนของใกล้จุดสั่งซื้ออัตโนมัติ เก็บหลักฐานสืบราคา–ต่อรองหลายรอบอย่างโปร่งใส และตรวจรับเทียบ 3 ทางก่อนจ่ายเงินลดปัญหาสั่งของซ้ำหรือจ่ายบิลไม่ตรงของจริง (เปิดใช้งานในรุ่น **Professional** และ **Enterprise**)
- เมื่อเปิดโมดูลนี้ครั้งแรกในฐานบริษัทใหม่ ระบบจะสร้างใบขอซื้อ ใบสืบราคา และใบสั่งซื้อตัวอย่างชุดแรกไว้ให้ทดลองกดเลื่อนสถานะและอัปโหลดรูปหลักฐานได้ทันที
- หากต้องการอนุมัติวงเงินและคุมงบประมาณตามผังสายงานของบริษัท สามารถใช้ร่วมกับเมนูคุมงบประมาณและสายอนุมัติเอกสารใน [[sys-account-overview]] (รหัสเมนู **1096**)

## คำถามที่ลูกค้ามักถาม

**ถาม: บริษัทมีนโยบายต้องเทียบราคาซัพพลายเออร์อย่างน้อย 3 เจ้าก่อนอนุมัติซื้อ ระบบรองรับไหม?**
ตอบ: รองรับครบครับ สามารถสร้างใบขอราคา (RFQ) เทียบราคาผู้ขายหลายเจ้า พร้อมแนบไฟล์ใบเสนอราคาและบันทึกประวัติการวนต่อรองราคาหลายรอบ เพื่อให้ผู้มีอำนาจเห็นราคาเปรียบเทียบก่อนกดอนุมัติสั่งซื้อ PO ครับ

**ถาม: การจับคู่ 3 ทาง (3-Way Match) ช่วยป้องกันข้อผิดพลาดอะไรให้ฝ่ายบัญชี?**
ตอบ: ช่วยเทียบยอดและจำนวนสินค้าระหว่าง 3 เอกสาร ได้แก่ **ใบสั่งซื้อ (PO) — ใบรับของหน้าท่าคลังพร้อมรูปพาเลท — และใบกำกับภาษีซื้อ** ก่อนตั้งหนี้เจ้าหนี้ ลดความเสี่ยงจ่ายเงินเกินของที่รับจริงหรือลงภาษีซื้อผิดพลาดครับ

**ถาม: ฝ่ายจัดซื้อจะรู้ได้ยังไงว่าสินค้าตัวไหนในคลังใกล้หมดและควรสั่งซื้อกี่ชิ้น?**
ตอบ: มี **เรดาร์สินค้าใกล้หมด (Replenishment Radar)** ดึงรายการที่สต็อกลดต่ำกว่าเกณฑ์สั่งซื้อขั้นต่ำมาแนะนำจำนวนที่ควรสั่ง แล้วกดหยิบใส่ตะกร้าขอซื้อ (PR Cart) ต่อได้ทันทีครับ

**ถาม: กิจการขนาดเล็กที่ต้องการออกแค่ใบขอซื้อ PR และใบสั่งซื้อ PO ธรรมดา ต้องซื้อรุ่น Professional เลยไหม?**
ตอบ: ไม่จำเป็นครับ งานเอกสารใบขอซื้อและใบสั่งซื้อมาตรฐานมีอยู่ในระบบหลัก [[sys-account-overview]] ตั้งแต่รุ่น **Starter / Standard** แล้วครับ ส่วนโมดูลจัดซื้อเชิงรุกพร้อมเทียบราคา RFQ หลายรอบและสายอนุมัติหลายชั้นจะอยู่ในรุ่น **Professional** ขึ้นไป
