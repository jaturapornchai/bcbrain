# หลังบ้านระบบ POS บนเว็บ BC Ai Account

**ภาพรวมในหน้าเดียว:** ระบบขายหน้าร้าน (POS) มี 2 ฝั่ง ฝั่งแคชเชียร์คือแอปจุดขายที่ใช้ขายของ ส่วนฝั่งหลังบ้านคือหน้าจอบนเว็บ BC Ai Account ที่เจ้าของร้านหรือพนักงานบัญชีใช้ตั้งค่า ดูสถานะเครื่อง ดูบิล และบันทึกเงินทอน/ส่งเงิน บทนี้อธิบายเฉพาะฝั่งหลังบ้าน (ฝั่งแอปแคชเชียร์ดู [[sys-pos-overview]])

## หลังบ้านทำอะไรได้
- ตั้งค่าร้านที่จะพิมพ์บนใบเสร็จ ภาษี ส่วนลดสมาชิก: [[howto-pos-web-startup-config]]
- ลงทะเบียนเครื่อง POS แต่ละเครื่อง กำหนดคลังที่ตัดสต็อกและรูปแบบเลขที่บิล: [[howto-pos-web-machine-register]]
- สร้าง "รหัสเชื่อมเครื่อง" เพื่อให้เครื่อง POS เครื่องจริงเชื่อมกับบริษัท: [[howto-pos-web-pair-device]]
- ดูว่าเครื่องไหนซิงก์ล่าสุดเมื่อไร มีบิลค้างส่งกี่บิล มีบิลผิดพลาดกี่บิล: [[howto-pos-web-monitor-sync]]
- บันทึกรับเงินทอนเปิดกะ / ส่งเงินปิดกะ: [[howto-pos-web-shift-cash]]
- ดูรายการบิลขายล่าสุดและยกเลิกบิล: [[howto-pos-web-bill-list-cancel]]
- สร้างคูปองส่วนลด: [[howto-pos-web-coupons]]
- กำหนดสูตรโปรโมชั่น (10 รูปแบบ): [[howto-pos-web-promotions]]
- กำหนดเงื่อนไขสะสมแต้มสมาชิก: [[howto-pos-web-loyalty-points]]
- ตั้งค่า QR พร้อมเพย์: [[howto-pos-web-qr-payment]]

## เมนูที่เกี่ยวข้อง (ชื่อตามหน้าจอ)
| เมนู | ใช้ทำอะไร |
|---|---|
| เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดค่าเริ่มต้น POS | ค่าร้านและสิทธิ์ทั่วไป |
| เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรหัสเครื่อง POS | ทะเบียนเครื่อง สถานะซิงก์ รหัสเชื่อมเครื่อง |
| เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดคุณสมบัติของเครื่อง POS | หน้าเดียวกับรหัสเครื่อง POS |
| เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดเงื่อนไขสะสมแต้ม | แต้มสมาชิก |
| เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดค่า QR Code Payment (และ กำหนดค่าเครื่องรูดบัตรเครดิต, กำหนดค่าจอแสดงผล QR Code) | ตั้งค่า QR พร้อมเพย์ (สามเมนูนี้เปิดหน้าตั้งค่า QR หน้าเดียวกัน) |
| สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › กำหนดสูตรโปรโมชั่น | สร้างโปรโมชั่น |
| เริ่มต้น › ตั้งค่าระบบการเงินและธนาคาร › รายละเอียดคูปอง | ดู/สร้างคูปอง |
| ขาย › ระบบขายหน้าร้าน POS › สร้างคูปองแบบเร็ว | สร้างคูปองเป็นชุด |
| ขาย › ระบบขายหน้าร้าน POS › บันทึกรับเงิน (เงินทอน) | รับเงินทอนเข้าลิ้นชัก |
| ขาย › ระบบขายหน้าร้าน POS › บันทึกส่งเงิน POS | นำส่งเงินปิดกะ |
| ขาย › ระบบขายหน้าร้าน POS › รายการใบกำกับภาษีอย่างย่อ | ดูบิลขาย POS |
| ขาย › ระบบขายหน้าร้าน POS › รายการใบกำกับภาษีอย่างเต็มออกแทน | หน้ารายการบิลเดียวกัน พร้อมแบบฟอร์มออกใบกำกับเต็มรูป (ยังกรอกแล้วบันทึกไม่ได้ ดู [[faq-pos-web-full-tax-invoice]]) |
| ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › รายการใบกำกับภาษีอย่างย่อยกเลิก | หน้ารายการบิลเดียวกัน ใช้กดยกเลิกบิล |
| เริ่มต้น › ตั้งค่าระบบขายและ POS › ออกแบบหน้าจอขาย POS / Download ระบบเสียงพูด | ออกแบบหน้าจอขายและเสียง |

## เชื่อมกับระบบบัญชีอย่างไร
บิลที่แคชเชียร์ขายจะถูกส่งขึ้นระบบ แล้วกลายเป็นเอกสารขายสินค้าและบริการแบบขายสด ตัดสต็อก และลงบัญชีให้อัตโนมัติ อ่านรายละเอียดที่ [[sys-pos-web-bill-to-accounting]] ส่วนการตั้งค่าที่แก้บนหลังบ้านจะถูกส่งลงเครื่อง POS ตอนเครื่องซิงก์ครั้งถัดไป (ต้องมีเน็ต)

## หน้าจอ POS ฝังในเว็บ
เมื่อเข้าโมดูล POS บนเว็บ จะเห็นแถบด้านบนสลับระหว่าง "จุดขายแคชเชียร์" กับหน้าตั้งค่า เช่น "สูตรโปรโมชั่น POS (Dede 10 รูปแบบ)", "กำหนดค่าเริ่มต้น POS", "รหัสเครื่อง POS" และมีปุ่มทดสอบเสียงเอฟเฟกต์/เสียงพูด รวมถึงปุ่มดูหน้าจอแบบ Desktop / Tablet / Mobile ต้องล็อกอินและเลือกฐานข้อมูลบริษัทก่อน เว็บเปิดจอขายด้วยบัญชีที่ล็อกอินอยู่ (ไม่ต้องใช้รหัสเชื่อมเครื่อง)

## ข้อจำกัดที่ต้องรู้ (พูดตรงๆ)
- ช่องตั้งค่าบางส่วนบนหน้า "กำหนดค่าเริ่มต้น POS" แสดงบนจอแต่ **ยังไม่ถูกบันทึก** ดู [[ts-pos-web-setting-not-applied]]
- ไม่มีหน้ารายงานสรุปยอดขาย POS แยกกะ/แยกเครื่องในหลังบ้านหน้านี้ ที่ดูได้คือรายการบิลล่าสุด 50 บิล และประวัติรับเงินทอน/ส่งเงิน 50 รายการ
- รับเงินทอน/ส่งเงิน เป็นการบันทึกเพื่อควบคุมลิ้นชัก ไม่สร้างรายการบัญชี ดู [[howto-pos-web-shift-cash]]
- ข้อกฎหมายเรื่องใบกำกับภาษีอย่างย่อให้ปรึกษาผู้สอบบัญชีหรือสรรพากร
