# AutoCare ส่วนไหนใช้งานจริง ส่วนไหนยังเป็นตัวสาธิต

หน้านี้ให้ผู้ช่วยตอบลูกค้าก่อนซื้อและตอนใช้งานอย่างตรงไปตรงมา ระบบ AutoCare มีโครงงานซ่อมที่ครบเส้นทาง (รับรถ → ซ่อม → ปิดบิล → ลงบัญชี) แต่ **หลายจุดยังมีค่าตัวอย่างฝังอยู่** พนักงานต้องรู้ก่อนใช้งานจริง

## ข้อมูลตัวอย่างที่ระบบใส่ให้เอง
- เมื่อเปิดใช้ AutoCare ครั้งแรกในฐานข้อมูลบริษัท ระบบ **เพิ่มข้อมูลตัวอย่าง** เข้าไปเอง ได้แก่ รถ ลูกค้า ผู้จำหน่ายยาง สินค้ายาง/อะไหล่/ค่าแรง คลังและชั้นวาง ช่องซ่อม ช่าง ใบงานซ่อม ใบรับของ ใบเคลม และคูปองตัวอย่าง
- ระบบยังออก **ใบกำกับภาษีขายตัวอย่างและใบรับสินค้าตัวอย่าง** เข้าไปในบัญชีด้วย
- จึงควรทดลองกับฐานข้อมูลทดสอบก่อน ถ้าจะใช้กับบริษัทจริงให้ปรึกษาทีมงานเรื่องการล้างข้อมูลตัวอย่างก่อนใช้งาน

## ค่าที่เติมให้เองเมื่อปล่อยช่องว่าง
เมื่อบันทึกโดยไม่กรอกช่องใดช่องหนึ่ง ระบบอาจเติมค่าตัวอย่างลงไป เช่น
- เปิดใบรับรถใหม่: ใบงานจะมี **รายการยางตัวอย่าง 4 เส้น เส้นละ 3,990 บาท** ติดมาเสมอ และเลขตัวถัง (VIN) ตัวอย่าง ต้องลบ/แก้เอง ดู [[ts-autocare-default-tire-line]]
- บันทึกรถโดยไม่ใส่เลขตัวถัง: ระบบใส่เลขตัวถังตัวอย่างให้ ดู [[ts-autocare-vehicle-save-warnings]]
- รหัสลูกค้าที่เว้นว่าง จะเป็นรหัสลูกค้าตัวอย่าง ทำให้บิลขายออกไปที่ลูกค้าตัวอย่าง ต้องเลือกลูกค้าจริงจากปุ่มค้นหาทุกครั้ง
- บันทึกใบเคลม: ผูกกับใบงานและลูกค้าตัวอย่างโดยอัตโนมัติ (ใบเคลมจึงไม่เชื่อมใบงานจริง)
- ทุกครั้งที่กดบันทึกแก้ไขใบงานจากเว็บ รหัสช่างของใบงานจะถูกตั้งเป็นช่างคนแรกของระบบ (ชื่อช่างยังตามที่กรอก) ทำให้ส่วนแบ่งช่างอาจไปลงผิดคน ถ้าพบให้ส่งต่อเจ้าหน้าที่
- เปิดใบรับรถจากแอปมือถือ: ชื่อและเบอร์ลูกค้า เลขไมล์ ช่องซ่อม และช่างที่กรอกในแอปไม่ถูกบันทึก ระบบใส่ค่าตัวอย่างแทน ต้องตรวจและแก้ที่เว็บ ดู [[sys-autocare-mobile-overview]]

## ฟังก์ชันที่ยังเป็นตัวสาธิต
| ฟังก์ชัน | ความจริง |
|---|---|
| ตรวจสภาพรถ 35 จุด | หน้าจอมีการ์ดตรวจเพียง 3 หัวข้อ (ดอกยาง, ผ้าเบรก, แบตเตอรี่) ข้อความผลตรวจเป็นข้อความตัวอย่าง |
| ปุ่ม 🟢 ปกติ / 🟡 เฝ้าระวัง / 🔴 ต้องซ่อม | ทุกปุ่ม (รวมปกติ) เพิ่มรายการผ้าเบรกเสนอซ่อมราคาตัวอย่าง 3,190 บาท |
| ส่งลิงก์อนุมัติเข้า LINE ลูกค้า | ระบบ **ไม่ส่งข้อความ LINE จริง** แค่บันทึกว่าเสนอซ่อมแล้ว ลูกค้าไม่ได้รับอะไร |
| ปุ่มตรวจสภาพล้อแม็ก 4 ล้อ | ข้อความผลตรวจเป็นตัวอย่างตายตัว ปุ่มแค่บันทึกใบงานซ้ำ ไม่มีที่ถ่ายรูปหรือลายเซ็นบนเว็บ |
| ปุ่ม "อนุมัติส่วนลด VIP ฿500" (ในแผงใบงาน แสดงเมื่อใบงานยังไม่เคยอนุมัติส่วนลด) | ส่วนลดตายตัว 500 บาท (ถ้าใบงานนั้นมีส่วนลดพิเศษที่ขอไว้แล้ว จะใช้ยอดที่ขอไว้) เรื่องจำกัดคนกดอนุมัติ ส่งต่อเจ้าหน้าที่ |
| ใบรับของ (ซ่อนราคาทุน) เข้าบิลซื้อ | สินค้า ราคาทุน และ DOT ในบิลซื้อเป็นค่าตัวอย่างตามผู้จำหน่าย ไม่ใช่ที่กรอก |
| คูปองสมาชิก | ตัดสิทธิ์นับครั้งได้ แต่ **ไม่ลดยอดในบิลอัตโนมัติ** |
| หน้า "ประมวลผล" | ช่องสถานะ "ถูกต้อง 100%" เป็นข้อความคงที่ ไม่ใช่ผลตรวจจริง |
| ปุ่ม "รับรถใหม่ด่วน (1 คลิก)" | สร้างใบงานด้วยทะเบียนสุ่มและลูกค้าตัวอย่าง ใช้ทดลองเท่านั้น |

## ที่ใช้งานจริงได้
- ทะเบียนรถ ลูกค้า ทะเบียนยางและล็อต DOT ช่องซ่อม แพ็กเกจคูปอง
- ใบงานซ่อม เพิ่ม/ลบรายการ ส่วนลดหักเทิร์น เลื่อนสถานะ กระดานคิว
- ปิดบิลออกใบกำกับภาษีขาย ตัดสต็อก ลงบัญชี รับเงินตามวิธีที่เลือก
