# จ่ายเงินล่วงหน้า กับ จ่ายเงินมัดจำ ต่างกันอย่างไร?

**ตอบสั้น:** ทั้งสองอย่างคือจ่ายเงินให้ผู้ขายก่อนได้ของ ต่างกันที่ เงินมัดจำมีภาษีซื้อและนำไปตัดในใบซื้อได้ ส่วนเงินจ่ายล่วงหน้าไม่มีช่องภาษี และในระบบตอนนี้ยังนำไปตัดในใบซื้อไม่ได้ ทำได้แค่รับคืน

## รายละเอียด
| เรื่อง | จ่ายเงินล่วงหน้า | จ่ายเงินมัดจำ |
|---|---|---|
| เมนู | ซื้อ › จ่ายเงินล่วงหน้า | ซื้อ › จ่ายเงินมัดจำ |
| ภาษีซื้อ | ไม่มีช่องภาษี | มีประเภทภาษี บันทึกภาษีซื้อได้ |
| ลงบัญชี | เงินจ่ายล่วงหน้า เต็มจำนวน | เงินมัดจำจ่าย (ก่อนภาษี) และ ภาษีซื้อ |
| นำไปตัดในใบซื้อ | ยังไม่มีหน้าจอให้ตัด | ตัดได้ที่แท็บ "ใช้เงินมัดจำ" ของใบซื้อ |
| ได้เงินคืน | รับคืนจ่ายเงินล่วงหน้า | รับคืนจ่ายเงินมัดจำ |
| ยอดยกมา | จ่ายเงินล่วงหน้ายกมา | จ่ายเงินมัดจำยกมา |

- แท็บ "ใช้เงินมัดจำ" มีใน ซื้อสินค้า/ตั้งหนี้ซื้อ, ตั้งหนี้ซื้อจากการรับสินค้า และ ตั้งหนี้อื่นๆ (เจ้าหนี้)
- การเลือกว่ากิจการควรบันทึกเป็นเงินล่วงหน้าหรือเงินมัดจำ และเรื่องภาษีของเงินที่จ่ายก่อน เป็นเรื่องนโยบายบัญชีและภาษี ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร
- ถ้าลูกค้าบันทึกเป็นเงินจ่ายล่วงหน้าไว้แล้ว และต้องการหักในใบซื้อ ให้ส่งต่อเจ้าหน้าที่ช่วยแนะนำวิธีปรับปรุงรายการ
