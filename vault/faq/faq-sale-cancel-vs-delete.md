# เอกสารขายออกผิด ควร ลบ หรือ ยกเลิก?

**ตอบสั้น:** **ลบ** = เอกสารหายจากระบบ ไม่เหลือประวัติ เหมาะกับใบที่เพิ่งบันทึกผิดและยังไม่ได้ส่งให้ใคร **ยกเลิก** = เอกสารเดิมยังอยู่ ขึ้นสถานะยกเลิกแล้ว และมีใบยกเลิกเก็บไว้ เหมาะกับใบที่ส่งให้ลูกค้าแล้ว เช่น ใบกำกับภาษี ใบเสร็จ

## รายละเอียด
| เรื่อง | ลบ | ยกเลิก |
|---|---|---|
| ทำที่ไหน | หน้าเอกสารนั้น ปุ่ม "ลบ" | เมนูยกเลิกของเอกสารนั้น เช่น ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ |
| เอกสารเดิม | หายจากระบบ | ยังอยู่ สถานะ "ยกเลิกแล้ว" |
| ประวัติ | ไม่มี | มีใบยกเลิก + เหตุผลในหมายเหตุ |
| เลขที่เอกสาร | เลขนั้นว่าง ใช้ซ้ำได้ | เลขเดิมยังถูกใช้อยู่ |
| สต็อก ยอดลูกหนี้ | ถอนออก | ไม่นับเอกสารที่ยกเลิก |
| รายการบัญชี | ถอนออก | ระบบกลับรายการให้ในวันที่ของใบยกเลิก |
| ทำผิดแล้วคืนได้ไหม | ไม่ได้ | คืนได้ด้วย "คืนสถานะเอกสารปกติ" |

**ทั้งสองแบบทำไม่ได้เมื่อ** มีเอกสารอื่นใช้ใบนี้อยู่ เช่น บิลขายที่ถูกวางบิล รับชำระ หรือมีใบลดหนี้อ้างอิง ต้องยกเลิกใบปลายทางก่อน
- ลบ/แก้ไม่ได้ ขึ้น "ห้ามแก้ไข หรือลบข้อมูล" → [[ts-sale-cannot-edit]]
- ยกเลิกไม่ได้ ขึ้น "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้" → [[ts-sale-cannot-cancel]]

**แนะนำ**
- บิลที่ยังไม่ได้พิมพ์หรือส่งลูกค้า → แก้ไขได้เลย ไม่ต้องลบ ([[howto-sale-edit-delete]])
- บิลที่ส่งลูกค้าแล้ว ยอดผิดเล็กน้อย → ออกใบลดหนี้หรือใบเพิ่มหนี้ปรับยอดแทน ([[howto-sale-credit-note]], [[howto-sale-debit-note]])
- บิลที่ส่งลูกค้าแล้วและไม่ใช้ทั้งใบ → ยกเลิก ([[howto-sale-cancel-docs]])
- เอกสารในงวดบัญชีที่ปิดแล้ว ระบบไม่ให้ลบ แก้ หรือยกเลิก ขึ้น "วันที่เอกสาร ... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ" ([[ts-common-period-closed]])
- การยกเลิกใบกำกับภาษีที่ออกให้ลูกค้าไปแล้วต้องทำเอกสารอะไรเพิ่ม เป็นเรื่องข้อกฎหมาย ให้ปรึกษาผู้สอบบัญชี/สรรพากร
