# ทำไมสต็อกติดลบได้ ทั้งที่ตั้งห้ามติดลบไว้แล้ว?

**ตอบสั้น:** ระบบตรวจห้ามติดลบเฉพาะตอนสร้างเอกสารใหม่บางชนิด และต้องเปิดตัวเลือกให้ครบชุด ถ้าเข้ากรณีด้านล่าง ยอดก็ยังติดลบได้

## รายละเอียด
**กรณีที่ระบบไม่ตรวจ**
| กรณี | ผล |
|---|---|
| ตัวเลือกหลัก ห้ามเบิกสินค้าติดลบ ปิดอยู่ | ไม่ตรวจติดลบกับเอกสารใดเลย |
| แก้ไขเอกสารเดิม | ไม่ตรวจ เช่น แก้จำนวนในใบเบิกเก่าให้มากขึ้น |
| ใบปรับปรุงสต็อก (ลด) | ไม่ตรวจ |
| ยกเลิกหรือลบใบรับเข้า | ใบออกที่บันทึกไปแล้วอาจกลายเป็นติดลบ |
| สินค้าที่ติ๊ก ควบคุมยอดคงเหลือ | ระบบข้ามการตรวจสินค้าตัวนั้น |
| ตั้ง ประเภทห้ามสินค้าติดลบ = ทั้งระบบ | ตรวจยอดรวมทุกคลัง คลังใดคลังหนึ่งจึงติดลบได้ |

**เอกสารที่ตรวจ (เมื่อเปิดตัวเลือกครบ)**
- ใบเบิก ใบโอน บิลขาย ใบสั่งขาย เพิ่มหนี้ขาย ตามตัวเลือกคู่ที่เปิด ([[howto-stock-options]])

**ถ้าอยากให้ห้ามติดลบจริงจัง**
1. เปิด ห้ามเบิกสินค้าติดลบ และตัวเลือกคู่ของเอกสารที่ต้องการ
2. ตั้ง ประเภทห้ามสินค้าติดลบ เป็น เฉพาะคลังสินค้า หรือ เฉพาะที่เก็บสินค้า ถ้าต้องการคุมรายคลัง
3. ตรวจสินค้าที่ติ๊ก ควบคุมยอดคงเหลือ ไว้
4. ระวังการแก้เอกสารเก่าและบันทึกย้อนหลัง

**ยอดติดลบไปแล้วทำอย่างไร**
- ไล่หาเอกสารที่ทำให้ติดลบ ([[howto-stock-inquiry-movement]]) แล้วแก้เอกสาร หรือปรับปรุงสต็อก ([[howto-stock-adjust]])
- ข้อความตอนห้ามติดลบ ดู [[ts-stock-negative-not-allowed]]
