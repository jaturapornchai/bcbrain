# ประมวลผลสิ้นงวดแล้ว ทำไมยังแก้เอกสารในเดือนนั้นได้?

**ตอบสั้น:** เพราะเป็นคนละเรื่องกัน ประมวลผลสิ้นงวด แค่สร้างใบสำคัญปิดบัญชี (โอนรายได้และค่าใช้จ่ายเข้าบัญชีกำไรขาดทุน) ไม่ได้ล็อกงวด ถ้าต้องการล็อกไม่ให้แก้ ต้องเปลี่ยนสถานะงวดเป็น ปิดงวดบัญชี (Closed) ที่ กำหนดงวดบัญชี

## รายละเอียด
| | ประมวลผลสิ้นงวด / สิ้นปี | สถานะงวด ปิดงวดบัญชี (Closed) |
|---|---|---|
| ทำอะไร | สร้างใบสำคัญปิดบัญชี ลงวันที่สิ้นสุดของงวด | กันไม่ให้บันทึก แก้ ลบ หรือยกเลิก เอกสารซื้อ ขาย สต็อก รับ/จ่ายชำระหนี้ และข้อมูลรายวัน ที่วันที่อยู่ในงวดนั้น |
| ล็อกเอกสารไหม | ไม่ล็อก | ล็อก ขึ้น "วันที่เอกสาร ... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ" |
| ทำที่ไหน | บัญชี › ประมวลผลสิ้นงวด / ประมวลผลสิ้นปี (เฉพาะ Admin) | เริ่มต้น › ตั้งค่าระบบบัญชีและภาษี › กำหนดงวดบัญชี |

- ถ้าแก้เอกสารหลังปิดบัญชีไปแล้ว ให้ประมวลผลสิ้นงวดใหม่ด้วยเลขที่เอกสารปิดงวดเดิม ระบบลบใบเดิมแล้วสร้างใหม่ทับ
- งวดที่ปิดแล้ว ไม่ได้กันการประมวลผลสิ้นงวด/สิ้นปี และการบันทึกค่าเสื่อมราคา ระบบยังสร้างใบสำคัญลงวันที่ในงวดที่ปิดได้
- ถ้าปิดบัญชีทุกเดือนไปแล้ว ตอนประมวลผลสิ้นปีจะขึ้น "ไม่มียอดรายได้/ค่าใช้จ่ายในช่วงวันที่ ... ถึง ..." เพราะไม่มียอดเหลือให้ปิด เป็นเรื่องปกติ
- การปิดบัญชีทุกเดือนหรือปิดเฉพาะสิ้นปี ให้ปรึกษาผู้สอบบัญชี
