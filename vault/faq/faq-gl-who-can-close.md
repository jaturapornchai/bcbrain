# ใครทำปิดงวด ปิดปี ประมวลผลบัญชีได้บ้าง?

**ตอบสั้น:** เฉพาะผู้ใช้ระดับผู้ดูแลระบบ (Admin) ผู้ใช้ทั่วไปเปิดเมนูแล้วจะขึ้น "จำกัดสิทธิ์เฉพาะผู้ดูแลระบบ (Admin) เท่านั้น"

## รายละเอียด
- เมนูที่เป็นของ Admin เท่านั้น: ประมวลผลจากข้อมูลรายวัน, สรุปบัญชีสินค้าและต้นทุนขาย, ประมวลผลสิ้นงวด, ประมวลผลสิ้นปี, ประมวลผลกำไร/ขาดทุน และต้นทุนขาย, ยกเลิกผ่านรายการ, กำหนดงวดบัญชี และการเปลี่ยนรหัสบัญชี
- เมนู ผ่านรายการ และ ตรวจสอบความถูกต้อง ไม่ได้จำกัดเฉพาะ Admin ใช้สิทธิ์ตามที่ตั้งให้กลุ่มผู้ใช้
- ผู้ใช้ทั่วไปต้องการทำ ให้ Admin ทำแทน ([[ts-common-no-permission]])
