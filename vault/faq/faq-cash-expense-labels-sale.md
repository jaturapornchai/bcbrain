# ทำไมจอค่าใช้จ่ายอื่นๆ ขึ้นตัวเลือก ขายเชื่อ / ขายสด?

**ตอบสั้น:** เป็นข้อความบนจอที่ยังใช้ชื่อเดียวกับฝั่งขาย ความหมายจริงคือ "1: ขายสด" = จ่ายเงินทันที และ "0: ขายเชื่อ (เครดิต)" = ยังไม่จ่าย ตั้งเป็นหนี้ค้างจ่ายเจ้าหนี้ เอกสาร ค่าใช้จ่ายอื่นๆ และ เพิ่มหนี้ค่าใช้จ่ายอื่นๆ ลงบัญชีตามความหมายนี้

## รายละเอียด
- ช่องนี้ชื่อ "ประเภทรายการ" อยู่ที่หัวเอกสาร ค่าเริ่มต้นของค่าใช้จ่ายอื่นๆ คือแบบจ่ายทันที
- แบบจ่ายทันที ต้องกรอกช่องทางจ่ายในแท็บ "การรับ/จ่ายชำระเงิน" ให้ครบยอด
- แบบเชื่อ ไม่ต้องกรอกแท็บจ่ายชำระ ระบบตั้งยอดค้างจ่ายให้เจ้าหนี้ แล้วไปจ่ายภายหลังที่ระบบเจ้าหนี้ ([[howto-ap-overview]])
- เพิ่มหนี้ค่าใช้จ่ายอื่นๆ ใช้ตัวเลือกนี้แบบเดียวกัน
- ลดหนี้ค่าใช้จ่ายอื่นๆ ที่เลือก "0: ขายเชื่อ (เครดิต)" ระบบลดยอดค้างจ่ายเจ้าหนี้ให้ แต่การลงบัญชีอัตโนมัติยังลงฝั่งเงินสดเหมือนรับเงินคืนทันที ไม่ได้ลงลดเจ้าหนี้ ให้ตรวจแท็บ "การลงบัญชี (GL)" ก่อนบันทึก และส่งต่อเจ้าหน้าที่
- ถ้าลูกค้าสับสนกับชื่อตัวเลือกนี้ ให้ส่งต่อทีมงานเป็นข้อเสนอแนะปรับข้อความบนจอ
