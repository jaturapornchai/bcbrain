# ขายสด กับ ขายเชื่อ ต่างกันอย่างไร?

**ตอบสั้น:** ในหน้า ขายสินค้า/บริการ ช่อง "ประเภทรายการ" มี "0: ขายเชื่อ (เครดิต)" = ลูกค้ายังไม่จ่าย เกิดเป็นหนี้ค้าง และ "1: ขายสด" = รับเงินครบในบิลนั้นเลย ตั้งค่าเริ่มต้นได้ทั้งระดับร้านและระดับลูกค้า

## รายละเอียด
| เรื่อง | ขายเชื่อ (เครดิต) | ขายสด |
|---|---|---|
| รับเงิน | รับภายหลังด้วยใบเสร็จรับเงิน ([[howto-ar-receipt]]) | ใส่ช่องทางรับเงินในแท็บรับชำระให้ครบยอด ([[howto-sale-cash-payment]]) |
| หนี้ค้าง | ขึ้นใน "ดึงเอกสารค้างชำระ" ของใบวางบิล/ใบเสร็จ | ไม่เป็นหนี้ ไม่ขึ้น |
| ตรวจวงเงินเครดิต | ตรวจ ([[howto-sale-credit-limit]]) | ไม่ตรวจ |
| เครดิต (วัน) / ครบกำหนด | ระบบคิดจากลูกค้า | เครดิตเป็น 0 วัน ครบกำหนดเป็นวันที่เอกสาร |
| ลงบัญชี | เดบิต ลูกหนี้ | เดบิต เงินสด/ธนาคาร ตามช่องทาง ([[faq-sale-gl-posting]]) |

**ค่าเริ่มต้นของบิลใหม่ (เรียงจากที่ระบบใช้ก่อน)**
1. ลูกค้าที่ตั้ง "ประเภทการขาย" ใน รายละเอียดลูกหนี้ เป็น "ขายสด" หรือ "ขายเชื่อ" → เลือกลูกค้าแล้วบิลเปลี่ยนตามให้
2. ถ้าลูกค้าตั้ง "ไม่เลือก" → ใช้ข้อเลือกร้าน "ประเภทการขาย (เริ่มต้น)" (ไม่เลือก / ขายเงินเชื่อ / ขายเงินสด) ในแท็บ "4.ระบบขาย" ([[howto-sale-settings]])
3. แก้ในบิลเองได้ก่อนบันทึก

**ข้อควรรู้**
- ขายสดแต่ใส่เงินไม่ครบยอด ระบบไม่ยอมบันทึก ขึ้น "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" ([[ts-sale-payment-incomplete]])
- ลูกค้าจ่ายบางส่วนตอนซื้อ ให้ทำเป็นขายเชื่อ แล้วออกใบเสร็จรับชำระส่วนที่จ่าย ([[faq-ar-partial-payment]])
- ลูกค้าที่ถูกปิดสถานะเครดิต ยังขายสดได้ ([[faq-sale-overdue-check]])
- บันทึกเป็นขายสดผิด อยากเปลี่ยนเป็นขายเชื่อ → แก้บิลได้ถ้ายังไม่ถูกนำไปใช้ต่อ ([[howto-sale-edit-delete]])
