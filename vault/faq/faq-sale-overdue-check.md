# ระบบห้ามขายหรือเตือน ลูกค้าที่ค้างชำระเกินกำหนด ได้ไหม?

**ตอบสั้น:** ตอนนี้ยังไม่ได้อัตโนมัติ ข้อเลือก "เตือนเมื่อเกินกำหนดชำระ" และ "ห้ามขายเมื่อเกินกำหนดชำระ" มีบนจอแต่ระบบยังไม่ทำงาน ถ้าต้องการหยุดขายเงินเชื่อให้ลูกค้าที่ค้างนาน ให้เปลี่ยน "สถานะสินเชื่อ" ของลูกค้ารายนั้นเอง

## รายละเอียด
**ข้อเลือกที่ยังไม่ทำงาน** (แท็บ "4.ระบบขาย" ใน กำหนดข้อเลือกพิเศษต่างๆ)
- "เตือนเมื่อเกินกำหนดชำระ"
- "ห้ามขายเมื่อเกินกำหนดชำระ"
- "ตรวจสอบเกินกำหนดชำระ (สั่งจอง)" และ "ตรวจสอบเกินกำหนดชำระ (สั่งขาย)"
- "ไม่ตรวจสอบวันครบกำหนด ใบลดหนี้ (ขาย)"
- "ปิดสถานะเครดิตลูกหนี้อัตโนมัติ"

**วิธีที่ใช้ได้ตอนนี้**
1. ดูลูกค้าที่ค้างเกินกำหนดจากรายงานลูกหนี้ เช่น "รายงานอายุลูกหนี้" (ลูกหนี้ › รายงานวิเคราะห์อายุหนี้และเคลื่อนไหวลูกหนี้) หรือ "รายงานใบส่งของค้างชำระ-ตามวันที่" (ลูกหนี้ › รายงานสรุปยอดค้างชำระและวงเงินลูกหนี้) ([[rpt-overview]])
2. เปิด ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › รายละเอียดลูกหนี้ เลือกลูกค้า
3. ส่วน "2. รายละเอียดและสินเชื่อ" เปลี่ยน "สถานะสินเชื่อ" เป็น "ปิดวงเงิน" หรือ "หยุดขายชั่วคราว" แล้วใส่ "เหตุผลในการระงับ"
4. บันทึก

**ผลหลังเปลี่ยนสถานะสินเชื่อ**
- ใบขายเงินเชื่อ และตั้งหนี้อื่นๆ ของลูกค้านี้ บันทึกไม่ได้ ขึ้น "ลูกค้า ... : ... ถูกปิดสถานะเครดิต"
- ถ้าเป็น "หยุดขายชั่วคราว" และร้านเปิดการตรวจวงเงินที่ใบสั่งขาย ระบบยอมเฉพาะบิลที่อ้างใบสั่งที่อนุมัติแล้ว นอกนั้นขึ้น "ลูกค้า ... : ... ยังไม่อนุมัติเปิดสถานะเครดิต"
- ขายเงินสดได้ตามปกติ
- ลูกค้าจ่ายหนี้แล้ว เปลี่ยนกลับเป็น "เปิดวงเงิน"
