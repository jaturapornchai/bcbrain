# นอกจากระบบบัญชี มีระบบอะไรอีกบ้าง?

**ตอบสั้น:** หลังเลือกฐานข้อมูล ระบบเปิดหน้า "เมนูรวมทุกระบบ" มีการ์ดระบบงาน 15 ระบบ รวมระบบบัญชีด้วย กด "เข้าใช้งานระบบนี้" ที่การ์ดเพื่อเปิดระบบนั้น ความพร้อมและข้อจำกัดของแต่ละระบบ ดูหน้าของระบบนั้น ส่วนระบบไหนรวมในแพ็กเกจ สอบถามฝ่ายขาย

## รายละเอียด
| ระบบ | ใช้ทำอะไร | ดูต่อ |
|---|---|---|
| BC Account | บัญชีและ ERP ซื้อ ขาย สต็อก การเงิน ภาษี | [[sys-account-overview]] |
| ขาย POS | จุดขายหน้าร้านและแคชเชียร์ | [[sys-pos-overview]] |
| BC AutoCare | ศูนย์บริการรถยนต์ ร้านยาง อู่ซ่อม | [[sys-autocare-overview]] |
| ภาษี e-Tax | ใบกำกับภาษีอิเล็กทรอนิกส์ | [[sys-etax-overview]] |
| จัดซื้อ PO | บริหารงานจัดซื้อ | [[sys-procure-overview]] |
| คลัง WMS | บริหารคลังสินค้า | [[sys-wms-overview]] |
| ขนส่ง TMS | บริหารสายรถและการจัดส่ง | [[sys-tms-overview]] |
| ร้านค้าส่ง Market | ขายส่งระหว่างธุรกิจ | [[sys-market-overview]] |
| แดชบอร์ด BI | ข้อมูลสรุปสำหรับผู้บริหาร | [[sys-dashboard-overview]] |
| CRM | ดูแลความสัมพันธ์ลูกค้า | [[sys-crm-overview]] |
| แชท LINE OA | รวมแชทลูกค้าจาก LINE | [[sys-lineoa-overview]] |
| ถามตอบ AI | ผู้ช่วยวิเคราะห์บัญชี | [[sys-ai-overview]] |
| 3D Monitor TV | แผนที่ธุรกรรม 3 มิติ | [[sys-monitormap-overview]] |
| 3D จอพนักงาน | ดูหน้าจอการทำงานสด | [[sys-workmonitor-overview]] |
| 3D Warning | ตรวจจับความผิดปกติ | [[sys-fraudwarning-overview]] |

- ค้นหาระบบได้ที่ช่องค้นหาบนหน้ารวมระบบ ดู [[start-main-menu]]
- ทุกระบบใช้ฐานข้อมูลของบริษัทเดียวกัน วิธีเชื่อมกับระบบบัญชีของแต่ละระบบ ดูหน้าของระบบนั้น
