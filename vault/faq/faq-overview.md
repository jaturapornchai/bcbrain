# ถาม-ตอบที่พบบ่อย (FAQ)

หนึ่งโน้ตต่อหนึ่งคำถาม (70 ข้อ) ทุกข้อตอบจากโน้ตในคลังและยืนยันกับโค้ดจริง มีส่วน "ที่มาในโค้ด" อ้าง `path:line` ถ้าโน้ตขัดกับโค้ดปัจจุบันให้เชื่อโค้ด กลับหน้าแรก [[index]]

## ลงบัญชี GL (Dr/Cr)
- [[faq-sale-invoice-gl-posting]] — ขายสินค้า (ใบกำกับ 44) แล้วลงบัญชี GL อะไรบ้าง
- [[faq-purchase-invoice-gl-posting]] — ซื้อสินค้า (ใบซื้อ 12) ลงบัญชี GL ยังไง ภาษีซื้อเข้าบัญชีไหน
- [[faq-sale-return-credit-note-gl]] — รับคืน/ลดหนี้ (48) และส่งคืน/ลดหนี้ (16) ลงบัญชี GL กลับด้านยังไง
- [[faq-ar-receipt-ap-payment-gl]] — รับชำระหนี้ (239) / จ่ายชำระหนี้ (19) ลงบัญชี GL ยังไง เช็ค โอน ภาษีหัก ไปไหน
- [[faq-other-income-expense-gl]] — รายได้อื่นๆ (250) / ค่าใช้จ่ายอื่นๆ (260) ลงบัญชีเข้าบัญชีไหน ตั้งรหัสบัญชีที่ไหน
- [[faq-journal-voucher-jv]] — บันทึกรายวันทั่วไป (JV) เองยังไง แก้ GL ที่ระบบลงอัตโนมัติผ่าน JV ได้ไหม
- [[faq-gl-template-doc-format]] — ตั้งรูปแบบการลงบัญชี (GL) ในรูปแบบเอกสารยังไง และระบบใช้เมื่อไร
- [[faq-gl-not-balanced]] — บันทึกเอกสารแล้วขึ้น GL ไม่สมดุล (debit credit do not balance) แก้ยังไง
- [[faq-gl-rebuild-when]] — ต้องกดประมวลผลลงบัญชี (Rebuild GL) ใหม่เมื่อไร มันลบอะไรทิ้งบ้าง

## ภาษีมูลค่าเพิ่มและภาษีหัก ณ ที่จ่าย
- [[faq-vat-exclude-include-calc]] — VAT แยกนอก กับ รวมใน คำนวณต่างกันยังไง ส่วนลดท้ายบิลหักก่อนหรือหลังภาษี
- [[faq-vat-purchase-sale-report]] — รายงานภาษีซื้อ/ภาษีขาย ดึงข้อมูลจากไหน ทำไมเอกสารบางใบไม่ขึ้นรายงาน
- [[faq-wht-certificate-pnd]] — ภาษีหัก ณ ที่จ่าย บันทึกตรงไหน ออก ภ.ง.ด.3 / ภ.ง.ด.53 / 50 ทวิ ได้จากเมนูไหน

## เงินสด ธนาคาร เช็ค มัดจำ
- [[faq-payment-tab-tenders]] — แท็บรับ/จ่ายชำระ (เงินสด โอน เช็ค บัตร PromptPay ภาษีหัก) เก็บและลงบัญชีอย่างไร ทำไมขึ้น "ยอดการจ่ายเงินไม่สมบูรณ์"
- [[faq-cheque-received-lifecycle]] — เช็ครับ ตั้งแต่รับ-นำฝาก-ผ่าน-คืน-ขาดสิทธิ์ ลงบัญชีและเปลี่ยนสถานะอย่างไร
- [[faq-cheque-paid-lifecycle]] — เช็คจ่าย ตั้งแต่จ่ายเช็ค-เช็คผ่าน-คืน-ขาดสิทธิ์-เปลี่ยนเช็ค ลงบัญชีอย่างไร
- [[faq-bank-transfer-petty-cash]] — ฝากเงิน/ถอนเงิน/โอนเงินระหว่างธนาคาร และเงินสดย่อย ลงบัญชีอย่างไร
- [[faq-deposit-vs-advance]] — เงินมัดจำกับเงินล่วงหน้าต่างกันอย่างไร ลงบัญชีและตัดใช้ในใบกำกับอย่างไร
- [[faq-rounding-decimal]] — ระบบปัดเศษทศนิยมเงินอย่างไร ทำไมยอดต่างกัน 0.01
- [[faq-fx-multi-currency]] — เอกสารสกุลเงินต่างประเทศคำนวณและลงบัญชีกำไร/ขาดทุนอัตราแลกเปลี่ยนอย่างไร

## งวดบัญชีและสินทรัพย์ถาวร
- [[faq-period-closed-cannot-save]] — บันทึก/แก้/ลบเอกสารไม่ได้ ขึ้นว่า "ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี" แก้อย่างไร
- [[faq-year-end-close]] — ปิดบัญชีสิ้นงวด/สิ้นปี (โอนรายได้-ค่าใช้จ่ายเข้ากำไรสะสม) ทำอย่างไร ระบบลงบัญชีอะไร
- [[faq-fixed-asset-depreciation]] — คิดค่าเสื่อมราคาสินทรัพย์ (โอนค่าเสื่อม 1801) คำนวณและลงบัญชีอย่างไร
- [[faq-fixed-asset-sale]] — ขายสินทรัพย์ (1802) ระบบคำนวณกำไร/ขาดทุนและลงบัญชีอย่างไร

## สต็อกและต้นทุนสินค้า
- [[faq-moving-average-cost]] — ต้นทุนสินค้าคิดแบบไหน ถัวเฉลี่ยเคลื่อนที่คำนวณยังไง
- [[faq-why-stock-cost-changed]] — ทำไมต้นทุนของเอกสารเก่าเปลี่ยนเอง ทั้งที่ไม่ได้แก้เอกสารนั้น
- [[faq-negative-stock]] — ทำไมสต็อกติดลบได้ และตั้งห้ามติดลบที่ไหน
- [[faq-stock-rebuild]] — คำนวณยอดสต๊อกใหม่ (Rebuild Stock) ทำอะไรบ้าง ต้องกดเมื่อไหร่
- [[faq-stock-opening-balance]] — บันทึกสินค้ายกมา (ยอดยกมาสต็อก) ยังไง และลงบัญชีอะไร
- [[faq-stock-transfer-warehouse]] — โอนสินค้าระหว่างคลัง/ที่เก็บ (72/70) ทำงานยังไง ต้นทุนเปลี่ยนไหม
- [[faq-stock-count-adjust]] — ตรวจนับสต็อกแล้วปรับยอดยังไง (ตรวจนับ 76 → ปรับปรุงเพิ่ม 66 / ลด 68)
- [[faq-hidden-cost-landed]] — ค่าขนส่ง ค่าอากรขาเข้า (ต้นทุนแฝง / Landed Cost) เข้าต้นทุนสินค้ายังไง
- [[faq-cost-type-fifo-lot]] — ตั้งประเภทต้นทุนเป็น FIFO / LOT / มาตรฐาน ได้ไหม ระบบคิดตามที่ตั้งหรือเปล่า
- [[faq-unit-conversion]] — ขายเป็นกล่อง/โหล แต่สต็อกนับเป็นชิ้น ระบบแปลงหน่วยยังไง
- [[faq-serial-lot-expire]] — สินค้ามี Serial / LOT / วันหมดอายุ ระบบตรวจอะไรให้บ้างตอนบันทึก

## ลูกหนี้ เจ้าหนี้ เครดิต และราคา
- [[faq-ap-ar-balance-where]] — ยอดลูกหนี้/เจ้าหนี้คงค้างดูได้ที่ไหน ระบบคิดจากอะไร
- [[faq-ap-ar-opening-balance]] — บันทึกยอดยกมาลูกหนี้/เจ้าหนี้ยังไง ทำไมไม่มี GL
- [[faq-credit-limit-approval]] — ขายเกินวงเงินเครดิตลูกค้าได้ไหม ต้องให้ใครอนุมัติ
- [[faq-billing-ar-ap]] — ใบวางบิลลงบัญชีไหม วางบิลแล้วยอดหนี้ลดหรือเปล่า
- [[faq-price-discount-source]] — ราคาขาย/ส่วนลดที่ขึ้นอัตโนมัติในเอกสาร ดึงมาจากไหน

## เอกสารและขั้นตอนงาน
- [[faq-procure-to-pay-steps]] — งานซื้อทำตามลำดับอย่างไร ตั้งแต่ขอซื้อ สั่งซื้อ รับของ จนถึงจ่ายเงินเจ้าหนี้
- [[faq-order-to-cash-steps]] — งานขายทำตามลำดับอย่างไร ตั้งแต่เสนอราคา สั่งขาย ขายสินค้า จนถึงรับเงินจากลูกหนี้
- [[faq-cancel-vs-edit-vs-delete]] — ยกเลิก แก้ไข ลบเอกสาร ต่างกันอย่างไร ผลต่อสต็อกและ GL
- [[faq-cannot-delete-document]] — ทำไมลบหรือแก้เอกสารไม่ได้ ขึ้น ห้ามแก้ไข หรือลบข้อมูล
- [[faq-doc-number-format]] — เลขที่เอกสารรันอย่างไร ตั้งรูปแบบเลขที่ที่ไหน
- [[faq-doc-ref-import]] — ดึงเอกสารอ้างอิง (ปุ่มดึงเอกสาร) ทำไมเอกสารต้นทางไม่ขึ้น
- [[faq-pos-bill-to-account]] — บิลขาย POS เข้าบัญชีและตัดสต็อกอย่างไร

## หน้าจอ รายงาน และการตั้งค่า
- [[faq-new-company-setup]] — เริ่มใช้บริษัท/ฐานข้อมูลใหม่ ต้องตั้งข้อมูลหลักอะไรบ้างก่อนบันทึกเอกสารได้
- [[faq-change-master-code]] — เปลี่ยนรหัสสินค้า/ลูกค้า/เจ้าหนี้/ผังบัญชีที่ใช้ไปแล้วได้ไหม ต้องทำยังไง
- [[faq-buddhist-year-date]] — วันที่ในระบบเป็น พ.ศ. หรือ ค.ศ. ตั้งที่ไหน แล้วทำไมวันที่ในรายงานกับในบัญชีไม่ตรงกัน
- [[faq-print-document-form]] — พิมพ์เอกสารออกมาเป็นฟอร์มยังไง แล้วปรับแบบฟอร์มพิมพ์ได้ที่ไหน
- [[faq-run-report-conditions]] — เรียกรายงานยังไง ตั้งเงื่อนไขตรงไหน และทำไมรายงานว่างหรือไม่มีเอกสารที่ยกเลิก
- [[faq-menu-code-to-screen]] — รหัสเมนู (เช่น 2.1.7 หรือ 4013) คือหน้าจอไหน และระบบเปิดหน้าจอจากรหัสยังไง
- [[faq-thai-term-to-code]] — คำศัพท์บัญชีภาษาไทย (เช่น เครดิต ครบกำหนด ยกเลิก ส่วนลด) คือตารางและคอลัมน์ไหนในฐานข้อมูล

## สิทธิ์ การเข้าระบบ และบริษัท
- [[faq-menu-permission-denied]] — ทำไมเข้าเมนู/กดบันทึกแล้วขึ้น 403 ไม่มีสิทธิ์ และตั้งสิทธิ์เมนูให้ผู้ใช้อย่างไร
- [[faq-wh-shelf-permission]] — จำกัดคลัง/ที่เก็บที่ผู้ใช้เลือกได้ (perm_wh_shelf) ตั้งอย่างไร และทำไมผู้ใช้เห็นคลังไม่ครบ
- [[faq-tenant-database-select]] — ระบบแยกบริษัท/ฐานข้อมูล (tenant, provider, company) อย่างไร และเลือกบริษัทตอน login อย่างไร
- [[faq-session-logout-expired]] — ทำไมถูกเด้งออกจากระบบ / ขึ้น "หมดเวลาใช้งาน" (token หมดอายุ, idle 30 นาที, logout) ทำงานอย่างไร

## สำหรับนักพัฒนา
- [[faq-where-trans-flag-handled]] — trans_flag ตัวหนึ่งถูกจัดการที่ไหนในโค้ดบ้าง (ถ้าจะเพิ่มหรือแก้ชนิดเอกสารต้องดูไฟล์ไหน)
- [[faq-query-gateway]] — Query Gateway (/query/list, /query/limit, /query/batch, /query/exec) ทำงานอย่างไร
- [[faq-query-exec-write-blocked]] — ทำไมเขียนข้อมูลผ่าน /query/exec ไม่ได้ (error 403 ตารางเงิน/สต็อก/GL)
- [[faq-process-engine-dispatcher]] — Process engine (/process) เรียก action อย่างไร และเพิ่ม action ใหม่ต้องแก้ที่ไหนบ้าง
- [[faq-mcp-server]] — MCP ของ BC Ai Account ใช้ทำอะไร และใช้ token อย่างไร
- [[faq-add-new-report]] — เพิ่มรายงานใหม่ (เมนูรายงาน) ต้องแก้ที่ไหนบ้าง และทำไมขึ้น "ไม่พบรายงาน"
- [[faq-add-master-screen]] — เพิ่มจอข้อมูลหลัก (master) ใหม่ต้องแก้ที่ไหนบ้าง และทำไมผู้ใช้ทั่วไปบันทึกไม่ได้
- [[faq-save-atomic-partial]] — บันทึก/ลบเอกสารแล้วข้อมูลไม่ครบหรือเหลือครึ่ง ๆ กลาง ๆ ได้ไหม (atomic transaction ทำงานอย่างไร)
- [[faq-concurrent-save-deadlock]] — หลายคนบันทึกเอกสารพร้อมกันแล้วช้า/ค้าง/ขึ้น deadlock หรือเลขที่ซ้ำ ระบบกันอย่างไร

## แก้ปัญหา ประวัติ และงานค้าง
- [[faq-balance-mismatch-troubleshoot]] — ยอดในรายงานไม่ตรงกับงบทดลอง (สต็อก ลูกหนี้ เจ้าหนี้) ต้องเช็กอะไรบ้าง
- [[faq-past-bugs-lessons]] — บั๊กที่เคยเกิดซ้ำในโปรเจกต์นี้มีอะไรบ้าง และบทเรียน/กฎที่ต้องระวังก่อนแก้โค้ดคืออะไร
- [[faq-open-items-unfinished]] — งานที่ยังไม่เสร็จหรือยังไม่ได้พอร์ตในระบบมีอะไรบ้าง (รายการค้างที่ตรวจกับโค้ดจริง)
- [[faq-parity-csharp-bccm]] — ระบบนี้เหมือนโปรแกรม C# เดิม (BCCM) แค่ไหน ตรวจ parity อย่างไร และเมื่อต่างกันให้ยึดอะไร
