# ขายสินค้า รับชำระหนี้ รับมัดจำ แล้วระบบลงบัญชีอะไรให้?

**ตอบสั้น:** เอกสารขายที่เกี่ยวกับเงินลงบัญชี (บัญชีแยกประเภท = สมุดบัญชีที่แยกยอดตามชื่อบัญชี) ให้อัตโนมัติตอนบันทึก โดยใช้ผังบัญชีมาตรฐานของระบบ ส่วนใบเสนอราคา ใบสั่งจอง ใบสั่งขาย ใบวางบิล และเอกสารยกมา ไม่ลงบัญชี

## รายละเอียด
| เอกสาร | เดบิต (ด้านซ้าย) | เครดิต (ด้านขวา) |
|---|---|---|
| ขายเงินเชื่อ | ลูกหนี้ และเงินมัดจำที่หัก | ขาย และภาษีขาย |
| ขายเงินสด | เงินสด / ธนาคาร (เงินโอน) ตามที่รับ และเงินมัดจำที่หัก | ขาย และภาษีขาย |
| รับคืนสินค้า/ลดหนี้ | ขาย และภาษีขาย | ลูกหนี้ (ถ้าคืนเป็นเงินสด = ช่องทางที่คืนเงิน) |
| เพิ่มหนี้ | ลูกหนี้ | ขาย และภาษีขาย |
| รับชำระหนี้ | เงินสด / ธนาคาร / เช็ค / ภาษีถูกหัก ณ ที่จ่าย | ลูกหนี้ |
| รับเงินมัดจำ | เงินที่รับ | เงินมัดจำรับ และภาษีขาย |
| รับเงินล่วงหน้า | เงินที่รับ | เงินรับล่วงหน้า |
| ตั้งหนี้อื่นๆ | ลูกหนี้ | รายได้อื่น และภาษีขาย |

**ข้อควรรู้**
- **ไม่มีรายการต้นทุนขาย** (ต้นทุนของสินค้าที่ขายออกไป) ในรายการบัญชีมาตรฐานของบิลขาย สต็อกและต้นทุนถูกคิดในระบบสินค้าคงคลังแยกต่างหาก ([[howto-stock-overview]]) ถ้าร้านต้องการลงต้นทุนขายในบัญชี ส่งต่อทีมงาน
- บัญชีที่ใช้เป็นบัญชีมาตรฐานของระบบ ไม่ได้แยกตามลูกค้า ช่อง "ผูกรหัสบัญชี" ในรายละเอียดลูกหนี้ ไม่ได้ถูกใช้ในการลงบัญชีมาตรฐาน
- รับเงินด้วยบัตรเครดิต ระบบลงเดบิตที่บัญชีลูกหนี้ (รอเงินจากธนาคารผู้ออกบัตร)
- บิลที่รับโอนเข้าหลายสมุดบัญชีธนาคาร ระบบใช้บัญชีของสมุดบัญชีบรรทัดแรกของบิล
- ใบเพิ่มหนี้แบบ "เพิ่มหนี้จากการขายเงินเชื่อ (ไม่กระทบสต๊อก)" ระบบลงเดบิตด้านเงินสด/ช่องทางรับเงิน ไม่ใช่ลูกหนี้ ถ้าลูกค้าเห็นรายการบัญชีไม่ตรง ส่งต่อทีมงาน
- ขายเป็นเงินตราต่างประเทศ ส่วนต่างอัตราแลกเปลี่ยนตอนรับชำระ ลงเป็นกำไรหรือขาดทุนจากอัตราแลกเปลี่ยน
- ยกเลิกเอกสาร ระบบกลับรายการบัญชีให้ในวันที่ของใบยกเลิก ([[howto-sale-cancel-docs]])

**ต้องการลงบัญชีแบบอื่น**
- ผู้ดูแลตั้งรูปแบบบัญชีให้แต่ละรูปแบบเอกสารได้ที่ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรูปแบบเลขที่เอกสาร (กด "แก้ไข" แล้วใช้ปุ่ม "Get Format" ที่ขึ้นคำอธิบายว่า "ดึงรูปแบบ GL อัตโนมัติจาก Master") เอกสารที่ใช้รูปแบบนั้นจะลงบัญชีตามที่ตั้งแทนแบบมาตรฐาน ควรให้ทีมงานช่วยตั้ง
- ดูรายการบัญชีของเอกสารได้ที่แท็บบัญชีในหน้าเอกสาร และในรายงานบัญชีแยกประเภท ([[howto-gl-overview]])
- การเลือกบัญชีให้ถูกตามมาตรฐานบัญชีของกิจการ ให้ปรึกษาผู้สอบบัญชี
