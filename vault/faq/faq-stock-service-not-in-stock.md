# ทำไมสินค้าบริการ สินค้าชุด ไม่มียอดคงเหลือ?

**ตอบสั้น:** ระบบนับยอดคงเหลือเฉพาะ 1.สินค้าทั่วไป 5.สินค้าฝากขาย และ 7.ผสมสี ประเภทอื่น เช่น บริการ สินค้าชุด ไม่เก็บสต็อก จึงไม่มียอดคงเหลือ เป็นเรื่องปกติ

## รายละเอียด
**ประเภทสินค้า กับ สต็อก**
| ประเภทสินค้า (ช่อง ประเภทสินค้า ในข้อมูลสินค้า) | มียอดคงเหลือ |
|---|---|
| 1.สินค้าทั่วไป | มี |
| 2.บริการ | ไม่มี |
| 3.สินค้าให้เช่า | ไม่มี |
| 4.สินค้าชุด | ไม่มี ตัดสต็อกที่ชิ้นส่วนในชุด ([[howto-stock-set-items]]) |
| 5.สินค้าฝากขาย | มี |
| 6.สูตรสี | ไม่มี |
| 7.ผสมสี | มี |

**ผลที่ลูกค้าเห็น**
- ขายหรือเบิกสินค้าประเภทที่ไม่มีสต็อก ยอดคงเหลือไม่ลด
- ยอดคงเหลือของสินค้าประเภทนี้เป็นศูนย์เสมอ ไม่ใช่ข้อมูลผิด
- ต้นทุนเฉลี่ยไม่ถูกคำนวณให้

**ตั้งประเภทผิด ทำอย่างไร**
1. ถ้ายังไม่เคยใช้สินค้า แก้ ประเภทสินค้า ในข้อมูลสินค้าได้เลย ([[howto-stock-item-master]])
2. ถ้าใช้แล้ว ปรึกษาทีมงานก่อน เพราะเอกสารเก่าเก็บประเภทเดิมไว้ ยอดย้อนหลังอาจไม่ตรง
3. ถ้าเป็นสินค้าที่ควรนับสต็อกแต่ตั้งเป็นบริการ ให้แจ้งทีมงานตรวจยอด ([[ts-stock-balance-wrong]])

**หมายเหตุหัวข้อ สินค้าถึงจุดสั่งซื้อ**
- หัวข้อนี้แสดงเฉพาะสินค้าที่ตั้ง จุดสั่งซื้อ ไว้มากกว่า 0 ([[howto-stock-inquiry-balance]])
