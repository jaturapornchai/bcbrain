# บันทึกใบตรวจนับแล้ว ทำไมยอดสต็อกยังไม่เปลี่ยน?

**ตอบสั้น:** ใบขอตรวจนับและใบตรวจนับเป็นแค่ใบบันทึกผลนับ ไม่เปลี่ยนยอดสต็อกและไม่ลงบัญชี ต้องไปเมนู ปรับปรุงสต็อกสินค้า/วัตถุดิบอัตโนมัติ เพื่อให้ระบบสร้างใบปรับปรุงเพิ่ม/ลดตามส่วนต่าง

## รายละเอียด
**ลำดับงานตรวจนับ**
1. ใบขอตรวจนับสินค้า (ถ้าต้องการ) = รายการที่จะให้พนักงานไปนับ
2. ใบตรวจนับสินค้า = จำนวนที่นับได้จริง ตามคลังและที่เก็บ ([[howto-stock-count]])
3. ปรับปรุงสต็อกสินค้า/วัตถุดิบอัตโนมัติ = ระบบเทียบยอดในระบบกับยอดนับ แล้วสร้างใบปรับปรุงให้ ([[howto-stock-count-auto-adjust]])

**ทำไมแยกขั้น**
- ให้ตรวจผลนับก่อน ถ้านับผิดก็แก้ใบตรวจนับได้ โดยสต็อกยังไม่เสีย
- นับหลายวันหลายจุดได้ แล้วประมวลผลทีเดียว

**ประมวลผลแล้วเกิดอะไร**
- ระบบใช้ยอดในระบบ ณ วันที่ของใบตรวจนับใบล่าสุดที่เลือก และใบปรับปรุงลงวันที่นั้น
- มูลค่าของใบปรับปรุงคิดที่ต้นทุนเฉลี่ย
- นับได้มากกว่า = ใบปรับปรุงเพิ่ม นับได้น้อยกว่า = ใบปรับปรุงลด (เลขที่เดียวกันแต่มี - นำหน้า)
- ใบปรับปรุงลงบัญชีตามปกติของใบปรับปรุง ([[faq-stock-gl-posting]])
- ประมวลผลซ้ำใบเดิมไม่ได้ ต้องยกเลิกใบปรับปรุงเดิมก่อน ([[ts-stock-count-already-adjusted]])

**ช่อง เปิดระบบเตือนตรวจนับซ้ำ**
- ในใบตรวจนับมีช่อง เปิดระบบเตือนตรวจนับซ้ำ และ เตือนย้อนหลัง (วัน) ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ระบบไม่เตือนเมื่อนับสินค้าซ้ำ
- อยากดูสินค้าที่นับซ้ำ ให้กดปุ่ม ตรวจสอบสินค้าซ้ำ ในหน้าจอปรับปรุงอัตโนมัติก่อนประมวลผล

**นับด้วย Serial**
- ใช้เมนู ตรวจสอบสินค้า Serial Number ระบบสร้างใบตรวจนับให้ แล้วต้องประมวลผลปรับปรุงเหมือนกัน ([[howto-stock-serial-count]])
