# เชื่อมกับ LINE ของลูกค้าจริงหรือยัง?

**ตอบสั้น:** ยังไม่พบการเชื่อม LINE จริงในโค้ด หน้า "แชท LINE OA" เป็นตัวจำลอง/สาธิต ลูกค้าทักมาทาง LINE จะไม่ปรากฏในหน้านี้ และข้อความที่พิมพ์ในหน้านี้ไม่ถูกส่งไปที่ LINE ของลูกค้า

## รายละเอียด
- ข้อความทุกอย่างเกิดและอยู่ในหน้าจอเท่านั้น ผู้ช่วย AI ตอบในหน้าจอ
- การ์ดสวยๆ ในแชทเป็นตัวอย่าง ยังไม่ถูกส่งออก
- ไม่มีการผูก "ลูกค้า" กับบัญชี LINE ของลูกค้า มีเพียงการผูก LINE ของ **พนักงาน** กับอีเมล ดู [[howto-lineoa-bind-staff-line]]
- คำโปรยของการ์ดระบบบนหน้าหลักพูดถึงการตอบแชทจาก LINE จริงและแจ้งเตือนอัตโนมัติ แต่โค้ดที่ตรวจพบยังไม่รองรับตามนั้น ถ้าลูกค้าถามก่อนซื้อ ให้บอกว่าเป็นส่วนสาธิต และสอบถามฝ่ายขายเรื่องแผนการเชื่อมต่อ
