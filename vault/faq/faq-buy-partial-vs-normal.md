# ซื้อสินค้าปกติ กับ ซื้อแบบทะยอยรับ ควรใช้แบบไหน?

**ตอบสั้น:** ถ้าของกับใบกำกับภาษีมาพร้อมกัน ใช้ ซื้อสินค้า/ตั้งหนี้ซื้อ ใบเดียวจบ ถ้าของมาก่อนแต่บิลมาทีหลัง หรือของทยอยมาหลายรอบ ใช้ ซื้อสินค้าแบบทะยอยรับ (รับของก่อนตั้งหนี้) คือรับของเข้าสต๊อกก่อน แล้วค่อยตั้งหนี้เมื่อบิลมา

## รายละเอียด
| เรื่อง | ซื้อสินค้า/ตั้งหนี้ซื้อ | แบบทะยอยรับ |
|---|---|---|
| จำนวนเอกสาร | 1 ใบ | 2 ขั้น: รับสินค้าตามใบสั่งซื้อ (ทะยอยรับ) แล้ว ตั้งหนี้ซื้อจากการรับสินค้า |
| สต๊อกเข้าเมื่อ | บันทึกใบซื้อ | บันทึกใบรับสินค้า |
| ภาษีซื้อเข้าเมื่อ | บันทึกใบซื้อ | บันทึกใบตั้งหนี้ |
| หนี้ค้างจ่ายเกิดเมื่อ | บันทึกใบซื้อ (เงินเชื่อ) | บันทึกใบตั้งหนี้ |
| ลงบัญชีตอนรับของ | - | ซื้อสินค้า คู่กับ เจ้าหนี้ไม่ถึงกำหนดตั้งหนี้ |
| คืนของ | ส่งคืนสินค้า/ลดหนี้ซื้อ | ส่งคืนสินค้าจากการรับ (ทะยอยรับ) |
| แก้ราคาหลังตั้งหนี้ | เพิ่มหนี้ซื้อ/ราคาผิด, ส่งคืน/ลดหนี้ซื้อ | เพิ่มหนี้ซื้อจากใบตั้งหนี้, ลดหนี้ซื้อจากใบตั้งหนี้ |

- สองแบบนี้แยกสายกัน ใบที่รับแบบทะยอยรับ ต้องตั้งหนี้ด้วยเมนูของแบบทะยอยรับเท่านั้น
- ใบตั้งหนี้จากการรับสินค้า ไม่เปลี่ยนสต๊อก เพราะของเข้าไปแล้วตอนรับ
- ใบเพิ่มหนี้และลดหนี้จากใบตั้งหนี้ ไม่เปลี่ยนจำนวนสต๊อก ถ้าคืนของจริงให้ใช้ ส่งคืนสินค้าจากการรับ
- ทั้งสองแบบดึงรายการจากใบสั่งซื้อได้ และตรวจจำนวนไม่ให้เกินใบสั่งซื้อเหมือนกัน ([[ts-buy-qty-over-po]])
