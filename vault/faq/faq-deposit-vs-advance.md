# คำถามพบบ่อย: เงินมัดจำ (Deposit) กับ เงินล่วงหน้า (Advance) ต่างกันอย่างไร?

ระบบแยกเอกสารสำหรับเงินรับ/จ่ายก่อนเปิดบิลออกเป็น 2 กลุ่ม ได้แก่ **เงินมัดจำ** และ **เงินล่วงหน้า** ซึ่งนำไปตัดลดยอดบนบิลขายหรือบิลซื้อได้ในลักษณะเดียวกัน แต่ต่างกันที่ลักษณะการใช้งานทางธุรกิจและผังบัญชีที่ลงรายการ

## 1. ความแตกต่างหลักระหว่าง "เงินมัดจำ" กับ "เงินล่วงหน้า"

| หัวข้อ | เงินมัดจำ (Deposit) | เงินล่วงหน้า (Advance) |
| --- | --- | --- |
| **ความหมายทางธุรกิจ** | เงินประกันสัญญา/ค่ามัดจำสินค้าหรือบริการที่วางไว้ก่อนส่งมอบจริง (เช่น มัดจำสั่งจองสินค้า มัดจำผู้รับเหมา/ซัพพลายเออร์) | เงินรับล่วงหน้าจากลูกค้าหรือจ่ายล่วงหน้าให้ผู้ขาย/พนักงาน เพื่อสำรองไว้หักล้างค่าสินค้า/ค่าใช้จ่ายในอนาคต |
| **ฝั่งขาย (ลูกหนี้)** | **รับเงินมัดจำ** จากลูกค้า (และมีเอกสารคืนเงินมัดจำ) | **รับเงินล่วงหน้า** จากลูกค้า (และมีเอกสารคืนเงินรับล่วงหน้า) |
| **ฝั่งซื้อ (เจ้าหนี้)** | **จ่ายเงินมัดจำ** ให้ผู้ขาย (และมีเอกสารรับคืนเงินมัดจำ) | **จ่ายเงินล่วงหน้า** ให้ผู้ขาย (และมีเอกสารรับคืนเงินจ่ายล่วงหน้า) |
| **การนำไปตัดบิล** | ดึงไปตัดในแท็บ **ใช้เงินมัดจำ** ของใบขาย / ใบตั้งหนี้ / ใบซื้อ / ค่าใช้จ่ายอื่นได้ | ดึงไปตัดยอดในหน้าบิลขาย / บิลซื้อ / ตั้งหนี้ ได้ตามประเภทเอกสารเดียวกัน |
| **ผังบัญชี (GL)** | ลงแยกผังบัญชีกลุ่มเงินมัดจำรับ/มัดจำจ่าย | ลงแยกผังบัญชีกลุ่มเงินรับล่วงหน้า/เงินจ่ายล่วงหน้า |

## 2. ขั้นตอนรับเงินมัดจำแล้วนำไปตัดยอดตอนออกบิลขายทำอย่างไร?
1. เมื่อรับเงินจากลูกค้าล่วงหน้า ให้เปิดเอกสาร **รับเงินมัดจำ** (หรือ **รับเงินล่วงหน้า**) ระบุรหัสลูกค้าและจำนวนเงินรับ
2. เมื่อถึงวันส่งของและเปิด **ใบขายสินค้า** (หรือตั้งหนี้รายได้อื่น) ให้เลือกแท็บ **ใช้เงินมัดจำ** ในหน้าเอกสารขาย
3. กดเลือกเลขที่เอกสารมัดจำของลูกค้าคนนั้น (ระบบจะแสดงเฉพาะเอกสารที่ยังมี **ยอดคงเหลือ** และยังไม่ถูกยกเลิก)
4. ระบุยอดมัดจำที่จะตัดในบิลนี้ — **ยอดตัดต้องมากกว่า 0** และ **ต้องไม่เกินยอดคงเหลือของเอกสารมัดจำ** รวมถึง **ไม่เกินมูลค่าสุทธิของบิลขาย**

## 3. ถ้าเปิดบิลขายแล้วยอดสุทธิน้อยกว่าเงินมัดจำที่ลูกค้าวางไว้ ต้องทำอย่างไร?
ระบบจะไม่อนุญาตให้ตัดมัดจำเกินมูลค่าสุทธิของบิล (ขึ้นเตือน `"ยอดมัดจำมากกว่ามูลค่าสุทธิ"`) ให้กรอกยอดตัดเท่ากับมูลค่าสุทธิของบิลนั้นก่อน ส่วนยอดมัดจำที่เหลืออยู่ในเอกสารมัดจำใบเดิมสามารถเก็บไว้ตัดในบิลครั้งถัดไป หรือทำเอกสาร **คืนเงินมัดจำ** ให้ลูกค้าได้

## 4. เงินมัดจำมีผลต่อวงเงินเครดิตลูกค้าและแจ้งเตือนตอนตั้งหนี้ซื้อไหม?
- **ฝั่งขาย:** หากบริษัทเปิดข้อเลือกพิเศษ **"วงเงินเครดิตรวมรายการมัดจำ"** ยอดเงินมัดจำจะถูกนำมาคำนวณร่วมในวงเงินเครดิตของลูกค้ารายนั้นด้วย
- **ฝั่งซื้อ:** หากเปิดข้อเลือก **"ใช้ระบบแจ้งเตือนการมัดจำหน้าตั้งหนี้จากการรับสินค้า"** ระบบจะช่วยเตือนให้ดึงยอดมัดจำคงค้างของเจ้าหนี้มาตัดเมื่อบันทึกตั้งหนี้รับของ จะได้ไม่เผลอจ่ายเงินเต็มจำนวนซ้ำ

## 5. แก้ไขหรือลบเอกสารรับเงินมัดจำที่เคยตัดบิลไปแล้วได้ไหม?
ไม่ได้โดยตรง เพราะหากเอกสารมัดจำถูกนำไปตัดในบิลขาย/บิลซื้อ หรือทำคืนเงินไปแล้ว ระบบจะล็อกไม่ให้ลบ (ขึ้นเตือน `"เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้"`) ต้องไปแก้ไขหรือลบเอกสารปลายทางที่ดึงไปตัดก่อน
