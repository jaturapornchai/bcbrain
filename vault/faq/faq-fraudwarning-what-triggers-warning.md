# พฤติกรรมแบบไหนที่ 3D Warning ถือว่าเสี่ยง?

**ตอบสั้น:** ระบบบวกคะแนนตามพฤติกรรม เช่น แก้แล้วปิดหนีไม่บันทึก ลบรายการ ดูหลายรายการแล้วปิด และแก้ช่องอ่อนไหว (ราคา ส่วนลด บัญชีธนาคาร สต็อก เครดิต เงินเดือน น้ำมัน) คะแนนรวมเป็นตัวกำหนดระดับ

## คะแนนต่อพฤติกรรม (โดยประมาณตามที่ระบบตั้งไว้)
| พฤติกรรม | คะแนนที่เพิ่ม |
|---|---|
| แก้ไขข้อมูลค้างไว้แล้วปิดหน้าจอโดยไม่กดบันทึก | 65 |
| สั่งลบรายการ/ยกเลิกเอกสาร | 72 |
| คลิกดูรายการต่อเนื่อง 4 รายการขึ้นไปแล้วปิดโดยไม่ทำอะไร | 52 |
| แก้หลายช่องแล้วกดยกเลิกไม่บันทึก | 48 |
| แก้ข้อมูลเงินเดือน โอที สิทธิ์ผู้ใช้ | 35 |
| แก้เลขบัญชีธนาคาร หรือยอดภาษี | 32 |
| แก้วงเงินเครดิตลูกค้า | 28 |
| แก้ราคา ส่วนลด ยอดเงิน | 26 |
| แก้เลขไมล์ น้ำมัน ค่าซ่อมบำรุง | 26 |
| แก้จำนวนคงเหลือ/ยอดตรวจนับสต็อก | 25 |
| สลับออกนอกระบบตอนเปิดหน้าจอสำคัญ | 22 |

คะแนนรวมถูกจำกัดระหว่าง 5 ถึง 99

## ระดับตามคะแนน
- 80 ขึ้นไป: วิกฤต (เสี่ยงทุจริตสูงมาก)
- 60-79: ความเสี่ยงสูง (ต้องตรวจสอบ)
- 40-59: ความเสี่ยงปานกลาง (เฝ้าระวัง)
- 20-39: ความเสี่ยงต่ำ (แจ้งเพื่อทราบ)
- ต่ำกว่า 20: ปกติ (ไม่พบความเสี่ยง)

เหตุการณ์ที่คะแนนตั้งแต่ 45 ขึ้นไป หรือเป็นการลบ/ปิดหนีไม่บันทึก/ยกเลิกหลังแก้ช่อง หรือกดบันทึกที่คะแนนตั้งแต่ 35 ขึ้นไป จะถูกตีว่าควรให้ผู้ช่วย AI ช่วยวิเคราะห์เพิ่ม

## ข้อควรรู้
- การจับช่องอ่อนไหวใช้การอ่านชื่อช่องบนจอ (เช่น มีคำว่าราคา ส่วนลด เครดิต) จึงอาจแจ้งเตือนเกินหรือตกหล่นได้
- การแก้ไขที่ถูกต้องตามหน้าที่ เช่น แคชเชียร์ใส่ส่วนลดตามนโยบาย ก็อาจติดคะแนนได้ ต้องดูบริบทก่อน
- ตัวเลขข้างต้นเป็นค่าที่ตั้งไว้ในระบบ ปรับเองไม่ได้จากหน้าจอ
