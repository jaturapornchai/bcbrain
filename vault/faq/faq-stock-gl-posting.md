# เอกสารสินค้าลงบัญชีอย่างไร (เบิก ปรับปรุง รับสำเร็จรูป ยกมา โอน)?

**ตอบสั้น:** เอกสารที่เปลี่ยนมูลค่าสต็อกจะลงบัญชีคู่ระหว่าง สินค้าคงเหลือ กับ ต้นทุนขาย ให้อัตโนมัติ ถ้ารูปแบบเอกสารตั้งรูปแบบการลงบัญชีไว้ ระบบใช้รูปแบบนั้นแทน

## รายละเอียด
**ค่าปกติของแต่ละเอกสาร**
| เอกสาร | เดบิต | เครดิต |
|---|---|---|
| ใบเบิกสินค้า/วัตถุดิบ | ต้นทุนขาย | สินค้าคงเหลือ |
| ปรับปรุงสต็อก (ลด) | ต้นทุนขาย | สินค้าคงเหลือ |
| รับคืนสินค้า/วัตถุดิบ จากการเบิก | สินค้าคงเหลือ | ต้นทุนขาย |
| รับสินค้าสำเร็จรูป | สินค้าคงเหลือ | ต้นทุนขาย |
| ปรับปรุงสต็อก (เพิ่ม) | สินค้าคงเหลือ | ต้นทุนขาย |
| สินค้ายกมา | สินค้าคงเหลือสำเร็จรูป | ทุนเรือนหุ้นสามัญ (ติ๊ก บันทึกรายการบัญชีตรง ในแท็บ GL แล้วแก้ได้) ([[howto-stock-opening-balance]]) |

- ใบขอเบิก ใบขอโอน ใบขอตรวจนับ ใบตรวจนับ ไม่ลงบัญชี
- ใบโอนปกติไม่ลงบัญชี เพราะมูลค่ารวมไม่เปลี่ยน ([[howto-stock-transfer]])
- ระบบเลือกรหัสบัญชีจากผังบัญชีของกิจการ ถ้าต้องการใช้บัญชีอื่น ให้ตั้งรูปแบบการลงบัญชีที่รูปแบบเอกสาร ([[howto-gl-overview]])

**จุดที่ควรรู้**
- ยอดที่ลงบัญชีใช้ยอดรวมของเอกสาร ราคาในแต่ละบรรทัดระบบใส่ต้นทุนเฉลี่ยปัจจุบันของสินค้าให้ก่อน และแก้ได้ ส่วนสต็อกของใบเบิก ใบปรับปรุงลด และใบปรับปรุงเพิ่มที่มีจำนวน คิดที่ต้นทุนเฉลี่ย ณ วันที่เอกสาร ยอดในบัญชีกับมูลค่าสต็อกจึงอาจต่างกัน ถ้าต่างกันให้ส่งต่อเจ้าหน้าที่ ([[howto-stock-adjust]])
- เอกสารที่ยอดรวมเป็นศูนย์ ระบบไม่ลงบัญชี
- เมนู คำนวณยอดสต๊อกใหม่ เปลี่ยนต้นทุนในเอกสาร แต่ไม่ลงบัญชีใหม่ และการเปิดเอกสารแล้วบันทึกใหม่ก็ยังลงบัญชีตามยอดรวมของเอกสาร ไม่ได้ตามต้นทุนใหม่ ถ้าต้องการให้บัญชีตรงกับต้นทุนใหม่ ให้ผู้ทำบัญชีปรับปรุงเอง ([[howto-stock-recalc]])
- ตัวเลือก การ Post บัญชีสินค้า (แบบ Periodic / แบบ Perpetual) ในการตั้งค่า ไม่เปลี่ยนการลงบัญชีอัตโนมัติตามตารางข้างบน มีผลแค่กับรายการตั้งต้นที่ระบบเสนอให้ ตอนตั้งรูปแบบการลงบัญชีที่รูปแบบเอกสาร และตอนนี้ระบบตีความค่าสองแบบนี้กลับกันกับป้ายบนจอ ถ้าลูกค้าจะใช้ตัวเลือกนี้ให้ส่งต่อเจ้าหน้าที่
- ยกเลิกเอกสาร รายการบัญชีของเอกสารเดิมยังอยู่ ระบบลงรายการกลับด้านให้ ในวันที่ของเอกสารยกเลิก ([[howto-stock-cancel-doc]])
- งวดบัญชีที่ปิดแล้ว บันทึกเอกสารในวันที่นั้นไม่ได้ ([[ts-common-period-closed]])

**เรื่องมาตรฐานบัญชี**
- จะใช้บัญชีไหน หรือบันทึกต้นทุนแบบ Periodic หรือ Perpetual ให้ปรึกษาผู้สอบบัญชี/สรรพากร
