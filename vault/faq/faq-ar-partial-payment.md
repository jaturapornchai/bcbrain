# ลูกค้าจ่ายไม่ครบ หรือจ่ายเกินยอดบิล รับชำระอย่างไร?

**ตอบสั้น:** จ่ายไม่ครบทำได้ ในใบเสร็จรับเงิน แก้ช่อง "ยอดชำระ" ของบิลนั้นให้เท่าที่ลูกค้าจ่ายจริง ส่วนที่เหลือยังเป็นหนี้ค้าง และขึ้นให้รับชำระครั้งต่อไป ส่วนการจ่ายเกินยอดบิล ระบบไม่ให้บันทึก ยกเว้นร้านเปิดข้อเลือกให้ชำระเกินได้

## รายละเอียด
**รับชำระบางส่วน**
1. ลูกหนี้ › รับชำระหนี้/ออกใบเสร็จรับเงิน กด "เพิ่มใหม่" เลือกลูกค้า
2. กด "ดึงเอกสารค้างชำระ" เลือกบิลที่ลูกค้าจ่าย ระบบใส่ยอดคงเหลือของแต่ละบิลให้ในช่อง "ยอดชำระ"
3. แก้ "ยอดชำระ" ของบิลที่ลูกค้าจ่ายไม่ครบ ให้เท่ากับเงินที่ได้รับจริง
4. ใส่เงินที่รับในแท็บ "การรับ/จ่ายชำระเงิน" ให้ตรงกับยอดสุทธิ แล้วกด "บันทึก" ([[howto-ar-receipt]])

**หลังบันทึก**
- ยอดคงเหลือของบิล = ยอดบิล หักยอดที่รับชำระไปแล้วทุกใบ (ไม่นับใบเสร็จที่ยกเลิก)
- รับครั้งต่อไป บิลเดิมขึ้นใน "ดึงเอกสารค้างชำระ" ด้วยยอดที่ยังเหลือ
- ถ้ารับครั้งต่อไปด้วย "อ้างอิงใบวางบิล" ระบบใส่ยอดตามใบวางบิลเดิม ไม่ใช่ยอดที่เหลือ ต้องแก้ "ยอดชำระ" ให้ไม่เกินยอดที่เหลือเอง ไม่งั้นบันทึกแล้วขึ้น "ป้อนยอดชำระเกิน : ... (ยอดคงเหลือ ...)"
- รับชำระครบแล้ว บิลไม่ขึ้นให้ดึงอีก

**ลูกค้าจ่ายเกินยอดบิล**
- ใส่ "ยอดชำระ" มากกว่ายอดคงเหลือ ระบบขึ้น "ป้อนยอดชำระเกิน : ... (ยอดคงเหลือ ...)" และไม่ให้บันทึก
- ถ้าร้านต้องการรับเกินได้ ผู้ดูแลเปิด "อนุญาติให้ชำระเกินยอดบิลได้" (แท็บ "1.ตั้งค่าระบบ") ใน เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ
- เปิดข้อเลือกนี้แล้ว ระบบไม่ตรวจยอดเลย รวมถึงบิลที่รับชำระครบไปแล้ว จึงต้องระวังรับเงินซ้ำบิลเดิม
- ทางเลือกที่ไม่ต้องเปิดข้อเลือก: รับเฉพาะยอดบิล ส่วนที่เกินบันทึกเป็นเงินรับล่วงหน้าแยกต่างหาก ([[howto-sale-advance-receipt]])

**รับชำระหลายบิลพร้อมกัน**
- เลือกได้หลายบิลในครั้งเดียว ใบลดหนี้ที่ค้างอยู่ขึ้นเป็นยอดติดลบ หักออกจากยอดรวมให้เอง
- ลูกค้าโอนมาไม่ครบหลายบิล ให้ตัดบิลเก่าให้ครบก่อน แล้วใส่ยอดที่เหลือในบิลถัดไป (ร้านตกลงกับลูกค้าเองว่าตัดบิลไหนก่อน)

**ข้อควรรู้**
- ส่วนที่ลูกค้าหักภาษี ณ ที่จ่ายไว้ ใส่ในแท็บ "ภาษีถูกหัก ณ. ที่จ่าย" ยอดนี้นับเป็นยอดชำระด้วย (ขึ้นในบรรทัด "8. ภาษีหัก ณ ที่จ่าย (นับเป็นยอดชำระ)") ([[howto-ar-receipt]])
- ยอดรับเงินไม่ตรงยอดสุทธิ ระบบขึ้น "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" ([[ts-sale-payment-incomplete]])
- ถ้าร้านเปิด "รับชำระหนี้อ้างอิงวางบิลทุกครั้ง" ต้องดึงผ่านใบวางบิลก่อน ([[faq-ar-billing-needed]])
