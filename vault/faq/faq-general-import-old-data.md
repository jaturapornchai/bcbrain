# ย้ายข้อมูลจากโปรแกรมเดิมหรือ Excel เข้าระบบได้ไหม?

**ตอบสั้น:** ได้บางส่วน ตอนนี้นำเข้าจากไฟล์ได้จริงคือ ผังบัญชี (รายชื่อบัญชีที่ใช้ลงบัญชี) และราคาสินค้า ส่วนข้อมูลสินค้า ลูกค้า ผู้จำหน่าย และยอดยกมา ยังไม่มีหน้าจอนำเข้าจากไฟล์ ต้องคีย์ทีละรายการ หรือติดต่อทีมงานเรื่องการย้ายข้อมูล

## รายละเอียด
| ข้อมูล | นำเข้าจากไฟล์ได้ไหม | ทำที่ไหน |
|---|---|---|
| ผังบัญชี | ได้ ไฟล์ CSV | บัญชี › ผังบัญชี (Chart of Accounts) › รายละเอียดผังบัญชี › ปุ่ม "นำเข้า CSV" |
| ราคาสินค้า | ได้ ไฟล์ข้อความหรือ CSV ไม่เกิน 5,000 รายการต่อครั้ง | หน้าจอปรับราคาสินค้า › ปุ่ม "นำเข้าไฟล์" |
| แบบฟอร์มพิมพ์และรูปแบบรายงาน | ได้ เฉพาะไฟล์ที่ส่งออกจากระบบนี้ | เริ่มต้น › นำเข้าข้อมูล แบบฟอร์ม และรูปภาพ |
| สินค้า ลูกค้า ผู้จำหน่าย | ยังไม่ได้ | เพิ่มทีละรายการในหน้าจอทะเบียน |
| ยอดยกมา (สต็อก หนี้ เช็ค มัดจำ) | ยังไม่ได้ | คีย์ในเมนูยอดยกมาของแต่ละระบบ |
| รูปสินค้า | ทีละสินค้า | หน้าจอสินค้า แนบรูปทีละรายการ |

- เมนู "นำเข้าข้อมูลหลัก" ตอนนี้แสดงหมวดข้อมูลให้ดูอย่างเดียว กด "เริ่มประมวลผล" แล้วขึ้นว่าเรียบร้อย แต่ไม่มีข้อมูลเข้า
- ถ้ายังไม่มีผังบัญชีเดิม เลือกแม่แบบผังบัญชีสำเร็จรูปได้ เช่น ธุรกิจซื้อมาขายไป ธุรกิจบริการ ธุรกิจผลิตและโรงงาน
- เมนูยอดยกมาของสต็อก หนี้ เช็ค และเงินมัดจำ ไม่สร้างรายการบัญชีแยกประเภทให้ ต้องบันทึกยอดยกมาฝั่งบัญชีแยกต่างหาก
- ข้อมูลเยอะมากและอยากให้ช่วยย้ายให้ สอบถามฝ่ายขายหรือทีมงาน
