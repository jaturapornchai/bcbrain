# เงินมัดจำ กับ เงินรับล่วงหน้า ต่างกันอย่างไร?

**ตอบสั้น:** ถ้าจะนำเงินที่ลูกค้าจ่ายมาก่อนไป **หักในบิลขายภายหลัง** ให้ใช้ ขาย › รับเงินมัดจำ ส่วน ขาย › รับเงินล่วงหน้า ในระบบนี้ไม่มีภาษีมูลค่าเพิ่มในใบ และเอาไปหักในบิลขายไม่ได้ ปิดยอดด้วยการคืนเงินรับล่วงหน้าเท่านั้น

## รายละเอียด
| เรื่อง | รับเงินมัดจำ | รับเงินล่วงหน้า |
|---|---|---|
| ภาษีมูลค่าเพิ่ม (ภาษีที่บวกในราคาขาย) | มีประเภทภาษีและเลขที่ใบกำกับภาษี สร้างรายการภาษีขาย | ไม่มีแท็บภาษีมูลค่าเพิ่ม |
| หักในบิลขาย | หักได้ในแท็บ "ใช้เงินมัดจำ" ของใบขาย | หักไม่ได้ |
| ปิดยอด | หักในบิลขาย หรือ คืนเงินมัดจำ | คืนเงินรับล่วงหน้า |
| ลงบัญชี | เดบิต เงินที่รับ / เครดิต เงินมัดจำรับ และภาษีขาย | เดบิต เงินที่รับ / เครดิต เงินรับล่วงหน้า |
| ยอดก่อนเริ่มใช้ระบบ | รับเงินมัดจำยกมา | รับเงินล่วงหน้ายกมา |

**แนะนำลูกค้าแบบนี้**
- ลูกค้าวางเงินไว้ก่อนส่งของ แล้วจะเปิดบิลหักทีหลัง → รับเงินมัดจำ ([[howto-sale-deposit-receipt]]) แล้วหักในใบขาย ([[howto-sale-deduct-deposit]])
- ลูกค้าจ่ายเงินมาก่อน ยังไม่รู้ว่าจะซื้ออะไร และร้านบันทึกแบบไม่มีภาษีมูลค่าเพิ่มในใบ → รับเงินล่วงหน้า ([[howto-sale-advance-receipt]])
- ลูกค้าโอนเงินมาเกินยอดบิล → ส่วนที่เกินบันทึกเป็นรับเงินล่วงหน้า หรือรับเงินมัดจำ แยกต่างหาก

**ข้อควรรู้**
- รับเงินล่วงหน้าไปแล้ว แต่อยากหักในบิล ทำในระบบตรงๆ ไม่ได้ ต้องคืนเงินรับล่วงหน้า แล้วบันทึกเป็นรับเงินมัดจำแทน ควรให้ผู้ดูแลบัญชีของร้านตัดสินใจก่อน
- ใบยกมาของทั้งสองแบบไม่ลงบัญชี ใช้เป็นยอดตั้งต้นเท่านั้น
- ภาษีของเงินมัดจำหรือเงินรับล่วงหน้าต้องออกใบกำกับเมื่อไร เป็นเรื่องข้อกฎหมาย ให้ปรึกษาผู้สอบบัญชี/สรรพากร
