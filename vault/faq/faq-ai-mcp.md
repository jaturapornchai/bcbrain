# คำถามพบบ่อย: สมองกิจการ (Company Brain) และผู้ช่วย AI / MCP

## 1. สมองกิจการ (Company Brain) กับการเชื่อมต่อ MCP ต่างกันอย่างไร?
- **สมองกิจการ (Company Brain):** เป็นหน้าต่างผู้ช่วย AI ในระบบ BC Ai Account โดยตรง เพื่อช่วยสรุปภาพรวม ถามตอบข้อมูลกิจการ และค้นหาข้อมูลธุรกิจอย่างรวดเร็ว
- **ระบบ MCP (Model Context Protocol):** เป็นช่องทางเชื่อมฐานข้อมูลกิจการเข้ากับโปรแกรมผู้ช่วย AI ภายนอกที่ผู้ใช้ใช้งานอยู่ โดยควบคุมสิทธิ์การเข้าถึงด้วย **MCP Token**

## 2. ให้ผู้ช่วย AI หรือ MCP ช่วยแก้ไข/ลบเอกสาร หรืออนุมัติรายการบัญชีได้ไหม?
**ไม่ได้** ระบบ MCP ของ BC Ai Account ออกแบบมาเป็น **โหมดอ่านอย่างเดียวเท่านั้น** เพื่อความปลอดภัยสูงสุดของข้อมูลการเงิน สต็อก และภาษี ผู้ช่วย AI สามารถเรียกดู สรุป วิเคราะห์ และตรวจสอบข้อมูลได้ แต่ไม่สามารถแก้ไข เพิ่ม หรือลบเอกสารในฐานข้อมูลจริงได้

## 3. ทำไมสร้าง MCP Token แล้วกลับมาดูรหัสเต็มซ้ำไม่ได้?
เพื่อความปลอดภัย ระบบจะแสดงรหัส **MCP Token เต็มเพียงครั้งเดียวทันทีที่กดสร้าง** หลังจากปิดหน้าต่างนั้นแล้วจะไม่แสดงรหัสเต็มอีก หากทำรหัส Token หาย หรือสงสัยว่ารหัสอาจรั่วไหล ให้เข้าไป **เพิกถอน Token เดิม** แล้วสร้างใหม่ทันที (หรือ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า**)

## 4. จำกัดสิทธิ์ให้ดูเฉพาะบางบริษัท หรือดูพร้อมกันหลายบริษัทได้ไหม?
**ได้** ตอนออก Token สามารถกำหนดขอบเขตฐานข้อมูลบริษัทที่อนุญาตให้ Token นั้นเข้าถึงได้ และในการสั่งอ่านข้อมูลพร้อมกันหลายบริษัทต่อหนึ่งคำขอ ระบบอนุญาตสูงสุด **20 ฐานข้อมูลต่อคำขอ**

## 5. กรณีใช้บัญชีโหมดทดลอง สามารถออกหรือยกเลิก Token ของบริษัทจริงได้ไหม?
**ไม่ได้** บัญชีผู้ใช้งานในโหมดทดลองจะถูกป้องกันไม่ให้ออกหรือเพิกถอน Token ของฐานข้อมูลบริษัทจริง ต้องเข้าสู่ระบบด้วยบัญชีผู้ดูแลที่มีสิทธิ์ของบริษัทจริงนั้นๆ

## คำถามที่ลูกค้ามักถาม

**ถาม: เปิดให้ผู้ช่วย AI เชื่อมต่อผ่าน MCP แล้ว กลัว AI จะไปเผลอแก้ไขหรือลบบิลในระบบ จะเกิดขึ้นได้ไหม?**
ตอบ: ไม่เกิดขึ้นแน่นอนครับ/ค่ะ ระบบ MCP ของ BC Ai Account ล็อกสิทธิ์เป็น **โหมดอ่านอย่างเดียว (Read-Only)** 100% สามารถถามสรุปยอดขาย สต็อก ลูกหนี้ และวิเคราะห์ธุรกิจได้ แต่ไม่สามารถเพิ่ม แก้ไข หรือลบข้อมูลจริงในฐานข้อมูลได้

**ถาม: เจ้าของกิจการมี 5 บริษัท อยากให้ผู้ช่วย AI ช่วยสรุปยอดรวมทุกบริษัทพร้อมกันทำได้ไหม?**
ตอบ: ทำได้ครับ/ค่ะ ตอนออก MCP Token สามารถกำหนดรายชื่อฐานข้อมูลบริษัทที่อนุญาตให้ Token นั้นเข้าถึงได้ และระบบรองรับการอ่านข้อมูลพร้อมกันสูงสุดถึง **20 ฐานข้อมูลต่อคำขอ**

**ถาม: สร้างรหัส MCP Token เสร็จแล้วเผลอปิดหน้าต่างไปโดยยังไม่ได้คัดลอกเก็บไว้ จะเปิดดูรหัสเดิมซ้ำได้ไหม?**
ตอบ: เพื่อความปลอดภัย ระบบจะแสดงรหัสเต็มเพียงครั้งเดียวตอนกดสร้างเท่านั้นครับ/ค่ะ หากลืมคัดลอกไว้ ให้กด **เพิกถอน Token เดิม** แล้วกดสร้างรหัสใหม่มาใช้งานแทนได้ทันที

**ถาม: สมองกิจการ (Company Brain) อยู่ในรุ่นไหนของ BC Ai Account?**
ตอบ: ผู้ช่วย AI พื้นฐานเปิดใช้งานในรุ่น **Professional** ขึ้นไป ส่วน **สมององค์กร 360 องศา** พร้อมการออก MCP Token เชื่อมข้อมูลบริษัทหลายนิติบุคคลอยู่ในรุ่น **Enterprise** ครับ/ค่ะ (ดูรายละเอียดรุ่นที่ [[sales-pricing-packages]])
