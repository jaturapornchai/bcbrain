# รายงานนับเอกสารที่ยกเลิกหรือไม่

## ตอบสั้น
รายงานปกติไม่นับเอกสารที่ยกเลิก และสำเนาเอกสารก็ไม่นับ ถ้าต้องการเห็นเอกสารยกเลิก ให้ติ๊ก "แสดงเอกสารที่ยกเลิก" (มีในหลายรายงาน ปกติไม่ติ๊ก) หรือเปิด "รายงานเอกสารยกเลิก" ของแต่ละหมวด (เช่น ระบบขาย ระบบซื้อ)

## รายละเอียด
- แต่ละหมวดมีกลุ่มรายงานเอกสารยกเลิกของตัวเอง ดู [[rpt-so-cancel-docs]] [[rpt-po-cancel-docs]] [[rpt-ar-cancel-docs]] [[rpt-ap-cancel-docs]] [[rpt-cb-cancel-docs]] [[rpt-ic-cancel-docs]]
- เมื่อติ๊ก "แสดงเอกสารที่ยกเลิก" รายงานกลุ่มขายและซื้อแสดงแถวของเอกสารยกเลิกแต่ยอดเป็น 0 เพื่อไม่ให้ยอดรวมเพี้ยน
- ไม่ใช่ทุกรายงานที่มีช่องนี้ (รายงานเอกสารยกเลิกเองก็ไม่มี) ถ้าไม่มีช่อง ให้ถือว่าไม่รวมเอกสารยกเลิก
