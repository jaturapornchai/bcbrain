# ประเภทภาษีในบิลขาย ต่างกันอย่างไร?

**ตอบสั้น:** เลือกที่ช่องประเภทภาษีบนหัวเอกสาร มี 4 แบบ "0: แยกนอก" (ราคาที่ใส่ยังไม่รวมภาษี) "1: รวมใน" (ราคาที่ใส่รวมภาษีแล้ว) "2: ยกเว้นภาษี" และ "3: ไม่กระทบภาษี" (ภาษีมูลค่าเพิ่ม = ภาษีที่บวกในราคาขาย)

## รายละเอียด
| ประเภท | ระบบคิดอย่างไร | รายงานภาษีขาย |
|---|---|---|
| 0: แยกนอก | ยอดสินค้าเป็นยอดก่อนภาษี ระบบบวกภาษีเพิ่มให้ | มีรายการ |
| 1: รวมใน | ยอดสินค้ารวมภาษีแล้ว ระบบแยกภาษีออกจากยอดให้ | มีรายการ |
| 2: ยกเว้นภาษี | ภาษีเป็น 0 ช่องอัตราภาษีกดไม่ได้ ช่อง "มูลค่ายกเว้นภาษี" แสดงเฉพาะยอดของสินค้าที่ตั้งประเภทภาษีเป็นยกเว้นภาษี | มีรายการ (ภาษี 0) |
| 3: ไม่กระทบภาษี | ภาษีเป็น 0 ช่องอัตราภาษีกดไม่ได้ ช่อง "มูลค่ายกเว้นภาษี" แสดงเฉพาะยอดของสินค้าที่ตั้งประเภทภาษีเป็นยกเว้นภาษี | ไม่มีรายการ |

**สินค้าที่ตั้งว่ายกเว้นภาษี**
- สินค้าแต่ละตัวมีช่อง "ประเภทภาษี" ให้เลือก "1.ภาษีมูลค่าเพิ่ม" หรือ "2.ยกเว้นภาษี" ตั้งที่ สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ข้อมูลสินค้า ([[howto-stock-overview]])
- สินค้าที่ตั้ง "ยกเว้นภาษี" ถูกคิดเป็นมูลค่ายกเว้นภาษี แม้บิลจะเลือกแยกนอกหรือรวมใน บิลเดียวจึงมีทั้งยอดที่มีภาษีและยอดยกเว้นได้

**ด้านล่างบิลแสดงยอด:** รวมมูลค่าสินค้า, ส่วนลดก่อนภาษี, มูลค่าส่วนลด, หักเงินมัดจำ, ยอดเงินก่อนภาษี, ยอดภาษีมูลค่าเพิ่ม, มูลค่าหลังคิดภาษี, มูลค่ายกเว้นภาษี

**ให้ระบบใส่ประเภทภาษีของลูกค้าเอง**
- ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › รายละเอียดลูกหนี้ ส่วน "2. รายละเอียดและสินเชื่อ" ติ๊ก "กำหนดประเภทภาษี" แล้วเลือก "ประเภทภาษี" (มีให้เลือก "0, ภาษีแยกนอก" "1, ภาษีรวมใน" "2, ภาษียกเว้น") และใส่ "อัตราภาษี (%)"
- ถ้าไม่ติ๊ก บิลใช้ค่าเริ่มต้นของเอกสาร แก้ในบิลได้ทุกครั้ง ([[howto-ar-customer-register]])

**ข้อควรรู้**
- เปลี่ยนประเภทภาษีหลังใส่รายการแล้ว ระบบคำนวณยอดใหม่ ตรวจยอดรวมก่อนบันทึก
- สินค้าหรือบริการไหนต้องเสียภาษี ยกเว้น หรืออัตราเท่าไร เป็นเรื่องข้อกฎหมาย ให้ปรึกษาผู้สอบบัญชี/สรรพากร
