# ยกเลิกใบกำกับภาษีแล้ว ทำไมยังอยู่ในรายงานภาษี?

**ตอบสั้น:** รายงานส่วนใหญ่ยังแสดงเอกสารนั้นไว้ แต่ยอดเป็น 0 และคอลัมน์ สถานะ ขึ้น "ยกเลิก" ยอดรวมของรายงานจึงไม่นับเอกสารที่ยกเลิก ยกเว้นรายงานแบบ (มาตรฐาน) ที่ยังแสดงเต็มยอด

## รายละเอียด
- แสดงยอด 0 + สถานะ ยกเลิก: รายงานภาษีขาย/ภาษีซื้อ, แบบ (แสดงมูลค่าอัตราภาษีศูนย์), แบบ (รูปแบบใหม่), รายงานสรุปภาษีขาย และรายงานภาษีหัก ณ ที่จ่าย (ภงด.3 / ภงด.53 / ภาษีถูกหัก)
- รายงานสรุปภาษี ไม่นับยอดของเอกสารที่ยกเลิก
- **รายงานภาษีขาย (มาตรฐาน) / รายงานภาษีซื้อ (มาตรฐาน)** ไม่มีคอลัมน์ สถานะ และยังแสดงเอกสารที่ยกเลิกเต็มยอด ต้องตัดออกเองตอนตรวจ หรือใช้รายงานแบบอื่นแทน
- ภาษีซื้อ/ภาษีขายในใบ จ่ายชำระหนี้ / รับชำระหนี้ ที่ยกเลิกแล้ว รุ่นปัจจุบันยังขึ้นเต็มยอดในรายงานภาษีมูลค่าเพิ่ม (ไม่ขึ้นยกเลิก) → ส่งต่อเจ้าหน้าที่
- ทางบัญชี ใบเดิมยังคงรายการบัญชีไว้ ระบบลงรายการกลับให้ด้วยเอกสารยกเลิก (สลับเดบิต/เครดิต ชื่อบัญชีมีเครื่องหมาย * นำหน้า)
- วิธีปฏิบัติกับใบกำกับภาษีที่ยกเลิก ให้ปรึกษาผู้สอบบัญชี/สรรพากร
