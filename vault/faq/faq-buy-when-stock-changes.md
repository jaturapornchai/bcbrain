# เอกสารซื้อใบไหนทำให้สต๊อกเพิ่มหรือลด?

**ตอบสั้น:** สต๊อกเพิ่มเมื่อบันทึก ซื้อสินค้า/ตั้งหนี้ซื้อ, รับสินค้าตามใบสั่งซื้อ (ทะยอยรับ) และเพิ่มหนี้แบบเพิ่มสินค้า สต๊อกลดเมื่อส่งคืนสินค้า ใบเสนอซื้อและใบสั่งซื้อไม่เปลี่ยนสต๊อก

## รายละเอียด
| เอกสาร | จำนวนสต๊อก |
|---|---|
| ใบเสนอซื้อ, ใบสั่งซื้อ, ใบอนุมัติ | ไม่เปลี่ยน |
| จ่ายเงินล่วงหน้า / จ่ายเงินมัดจำ | ไม่เปลี่ยน |
| ซื้อสินค้า/ตั้งหนี้ซื้อ | เพิ่ม |
| รับสินค้าตามใบสั่งซื้อ (ทะยอยรับ) | เพิ่ม |
| ตั้งหนี้ซื้อจากการรับสินค้า | ไม่เปลี่ยน (ของเข้าไปแล้วตอนรับ) |
| เพิ่มหนี้ซื้อ แบบ "เพิ่มหนี้เจ้าหนี้, เพิ่มสินค้า" | เพิ่ม |
| ส่งคืนสินค้า/ลดหนี้ซื้อ แบบ "ลดหนี้เจ้าหนี้, ลดสินค้า" หรือ "ส่งคืนเงินสด" | ลด |
| ส่งคืนสินค้าจากการรับ แบบ "ส่งคืนสินค้า" | ลด |
| แบบที่มีคำว่า "ราคาผิด" ในใบส่งคืน/ลดหนี้ซื้อ (รวม "ราคาผิดเงินสด (ไม่มีผลกับสต๊อกสินค้า)") เพิ่มหนี้ซื้อ และส่งคืนสินค้าจากการรับ | ไม่เปลี่ยนจำนวน แต่ปรับมูลค่าต้นทุน |
| เพิ่มหนี้ / ลดหนี้ซื้อจากใบตั้งหนี้ | ไม่เปลี่ยน แม้ชื่อตัวเลือกจะมีคำว่า เพิ่มสินค้า หรือ ลดสินค้า |

## ข้อควรรู้
- นับเฉพาะสินค้าที่ตั้งประเภทสินค้าเป็น สินค้าทั่วไป, สินค้าฝากขาย หรือ ผสมสี ส่วนประเภท บริการ, สินค้าให้เช่า, สินค้าชุด, สูตรสี ไม่เปลี่ยนสต๊อกจากเอกสารซื้อโดยตรง
- เอกสารที่ยกเลิกแล้ว ไม่นับในสต๊อก ([[howto-buy-cancel-docs]])
- ถ้าบันทึกแล้วสต๊อกไม่ขึ้น ให้ตรวจ ประเภทสินค้า ประเภทการส่งคืน และเมนูที่ใช้ ตามตารางนี้
- ถ้าตรวจแล้วถูกหมดแต่ยอดยังไม่ตรง ส่งต่อเจ้าหน้าที่พร้อมเลขที่เอกสาร ([[howto-stock-overview]])
