# ประมวลผลต้นทุนแฝงแล้ว มีผลกับต้นทุน สต็อก และบัญชีอย่างไร?

**ตอบสั้น:** ระบบสร้างใบปรับปรุงสต็อก (เพิ่ม) แบบเพิ่มเฉพาะมูลค่า จำนวนสินค้าไม่เปลี่ยน แต่ต้นทุนเฉลี่ยสูงขึ้น ทำให้ต้นทุนขายของบิลขายหลังวันที่นั้นสูงขึ้น และกำไรขั้นต้นลดลง

## รายละเอียด
**สต็อกและต้นทุน**
- ใบปรับปรุงที่สร้างใช้วันที่ของเอกสารต้นทุนแฝง และอ้างอิงเลขที่เอกสารต้นทุนแฝง
- มูลค่าที่ปันให้แต่ละสินค้าถูกบวกเข้ามูลค่าคงเหลือ ต้นทุนเฉลี่ยใหม่ = มูลค่ารวม ÷ จำนวนคงเหลือ
- ของที่ขายไปก่อนวันที่นั้นไม่เปลี่ยนต้นทุน
- ลบเอกสารต้นทุนแฝง ระบบลบใบปรับปรุงและคำนวณต้นทุนกลับให้

**บัญชี**
- ใบปรับปรุงที่สร้างลงบัญชีแบบใบปรับปรุงเพิ่ม ค่าปกติ เดบิต สินค้าคงเหลือ / เครดิต ต้นทุนขาย หรือตามรูปแบบการลงบัญชีของรูปแบบเอกสาร ([[faq-stock-gl-posting]])
- เอกสารค่าใช้จ่ายที่ใช้ (ตั้งหนี้อื่น ๆ หรือ ค่าใช้จ่ายอื่น ๆ) ลงบัญชีของมันเองอยู่แล้ว ให้ผู้ทำบัญชีตรวจว่าค่าใช้จ่ายส่วนนี้ไม่ถูกนับซ้ำ จะบันทึกแบบไหนปรึกษาผู้สอบบัญชี/สรรพากร

**หน้าจอสอบถามที่มีคำว่า (รวมต้นทุนแฝง)**
- ต้นทุนแฝงรวมอยู่ในต้นทุนเฉลี่ยปกติแล้ว ให้ดูหัวข้อปกติ เช่น บัญชีคุมพิเศษ กำไรขั้นต้นตามสินค้า
- หัวข้อ บัญชีคุมพิเศษ (รวมต้นทุนแฝง) และ กำไรขั้นต้นตามสินค้า (รวมต้นทุนแฝง) ตอนนี้อาจแสดงต้นทุนเป็น 0 หรือไม่ตรง เพราะระบบยังไม่ได้คำนวณต้นทุนส่วนนี้ ถ้าลูกค้าต้องใช้ ให้ส่งต่อเจ้าหน้าที่

**แก้ไขใบปรับปรุงที่สร้าง**
- แก้หรือลบที่เมนูปรับปรุงสต็อกไม่ได้ ต้องทำที่เมนู ประมวลผลเฉลี่ยต้นทุนแฝง ([[ts-stock-doc-locked]])
