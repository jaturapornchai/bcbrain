# ข้อมูลของเราปลอดภัยไหม ใครเห็นได้บ้าง?

**ตอบสั้น:** ระบบให้เข้าใช้ผ่านบัญชี Google แต่ละบริษัทมีฐานข้อมูลแยกกัน คนที่จะเห็นข้อมูลบริษัทได้ต้องถูก Admin ของบริษัทเชิญเป็นสมาชิกเท่านั้น และ Admin จำกัดได้ว่าพนักงานแต่ละคนเปิดหน้าจอไหนได้ รายละเอียดด้านเทคนิคหรือเอกสารรับรองความปลอดภัย สอบถามฝ่ายขาย

## รายละเอียด
- **เข้าสู่ระบบ:** ใช้บัญชี Google ของแต่ละคน ระบบไม่เก็บรหัสผ่าน Gmail ถ้าไม่ได้ใช้งานต่อเนื่องประมาณ 30 นาที ระบบให้เข้าสู่ระบบใหม่ ดู [[ts-common-session-expired]]
- **แยกบริษัท:** ข้อมูลแต่ละบริษัทอยู่คนละฐานข้อมูล ดู [[faq-general-multi-company]]
- **สิทธิ์ผู้ใช้:** Admin ทำได้ทุกอย่าง Member ใช้ได้เฉพาะหน้าจอที่ได้รับสิทธิ์ และเมนูตั้งค่าสำคัญใช้ได้เฉพาะ Admin ดู [[faq-general-users-and-roles]]
- **กันแก้ทับกัน:** ระหว่างที่มีคนแก้รายการอยู่ ระบบล็อกรายการนั้นไว้ คนอื่นแก้หรือลบไม่ได้จนกว่าจะเสร็จ แต่ผู้ที่มีสิทธิ์แก้ไขกด "ปลดล็อกและเข้าแก้ไขแทนทันที" ได้ ระบบไม่ได้จำกัดเฉพาะ Admin ดู [[ts-common-record-locked]]
- **ตรวจย้อนหลัง:** เมนู ประวัติการใช้งานและตรวจสอบระบบ (Audit Log) ดูได้ว่าใครเพิ่ม แก้ไข หรือลบรายการที่ระบบบันทึกไว้ ได้แก่ สินค้า ลูกค้า ผู้จำหน่าย ราคา รูปภาพ และการเปลี่ยนรหัส ข้อมูลหลักประเภทอื่นอาจยังไม่มีประวัติ สอบถามเจ้าหน้าที่ได้ ส่งต่อเจ้าหน้าที่ถ้าต้องการตรวจรายการอื่น ดู [[howto-setup-audit-log]] และประวัติของแต่ละรายการ ดู [[howto-common-record-history]]
- **เอกสารที่ใช้ไปแล้ว:** แก้หรือลบไม่ได้ถ้ามีเอกสารอื่นอ้างถึง หรืออยู่ในงวดที่ปิดแล้ว ดู [[ts-common-cannot-edit-used-doc]] และ [[ts-common-period-closed]]
- **ข้อจำกัด:** ประวัติการเข้าสู่ระบบและการเปิดเมนู ตอนนี้ยังไม่มีบันทึกให้ดู
- **ข้อแนะนำ:** ลบสมาชิกที่ลาออกทันที และอย่าใช้บัญชี Google เดียวร่วมกันหลายคน เพื่อให้ตรวจย้อนหลังได้ว่าใครทำอะไร
