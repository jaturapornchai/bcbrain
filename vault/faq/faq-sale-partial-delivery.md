# ส่งของบางส่วน เปิดบิลทีละรอบได้ไหม?

**ตอบสั้น:** ได้ ทำใบสั่งขาย (หรือใบสั่งจอง) ไว้ทั้งหมด แล้วตอนส่งของแต่ละรอบ เปิดใบขายโดยกด "ดึงเอกสาร" ใส่จำนวนเท่าที่ส่งจริง ระบบจำยอดที่ยังค้างไว้ให้ดึงรอบถัดไป

## รายละเอียด
**ขั้นตอนแต่ละรอบ**
1. ขาย › ขายสินค้า/บริการ กด "เพิ่มใหม่" เลือกลูกค้าและประเภทภาษีให้ตรงกับใบสั่งขาย
2. กด "ดึงเอกสาร" ข้างช่อง "เอกสารอ้างอิง" เลือกใบสั่งขาย ระบบดึงเฉพาะจำนวนที่ยังค้าง
3. แก้จำนวนให้เท่าที่ส่งรอบนี้ บรรทัดที่ยังไม่ส่งลบออกได้
4. บันทึก ([[howto-sale-pull-ref-doc]])

**ระบบจัดการยอดค้างอย่างไร**
- ยอดค้าง = จำนวนในใบสั่ง หักที่ดึงไปเปิดบิลแล้ว และหักที่ยกเลิกรายสินค้าไปแล้ว
- ดึงครบทุกบรรทัดแล้ว ใบสั่งขายถือว่าปิด ไม่ขึ้นให้ดึงอีก
- ใบสั่งที่ถูกดึงไปบางส่วน แก้หรือลบไม่ได้ ([[ts-sale-cannot-edit]])

**ใส่จำนวนเกินที่ค้าง**
- ใบขาย: ระบบไม่ให้บันทึก ขึ้น "จำนวนเกินเอกสารอ้างอิง : ..." ยกเว้นร้านเปิด "ปิดการตรวจสอบขายเกินกว่าจอง"
- ใบสั่งขายที่ดึงจากใบเสนอราคา/ใบสั่งจอง และใบสั่งจองที่ดึงจากใบเสนอราคา: ตรวจเมื่อร้านเปิด "ห้ามใส่จำนวนเกินเอกสารอ้างอิง"
- รายละเอียดที่ [[ts-sale-qty-over-ref]]

**ส่วนที่เหลือลูกค้าไม่เอาแล้ว**
- ใช้ ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกใบสั่งขายสินค้า เลือก "ยกเลิกรายสินค้า" แล้วกด "ดึงรายการ" ใส่ "จำนวนยกเลิก" เฉพาะส่วนที่ค้าง ([[howto-sale-cancel-docs]])
- ใบสั่งที่ถูกดึงครบแล้วยกเลิกไม่ได้ ขึ้น "เอกสาร ... ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้"

**ข้อควรรู้**
- ใบขายแต่ละรอบตัดสต็อกและเป็นหนี้ค้างแยกใบ วางบิลรวมได้ภายหลัง ([[howto-ar-billing]])
- ยอดที่ยังค้างในใบสั่ง ถูกนับเป็นยอดค้างจอง/ค้างส่ง ถ้าร้านเปิด "ห้ามขายสินค้าค้างจองทั้งระบบ" หรือ "ห้ามขายสินค้าค้างส่งทั้งระบบ" ยอดนี้จะกันไม่ให้ขายให้ลูกค้าอื่น จนกว่าจะเปิดบิลหรือยกเลิกส่วนที่ค้าง ([[ts-sale-stock-negative]])
