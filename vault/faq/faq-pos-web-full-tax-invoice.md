# เมนูรายการใบกำกับภาษีอย่างเต็มออกแทน ใช้ได้ไหม

**ตอบสั้น:** ตอนนี้ยังใช้บันทึกไม่ได้ เมนู "รายการใบกำกับภาษีอย่างเต็มออกแทน" ใต้เมนูระบบขายหน้าร้าน POS แสดงฟอร์มให้ดู แต่ไม่มีปุ่มบันทึกและไม่มีการเก็บข้อมูลลงระบบ กรอกแล้วไม่เกิดเอกสารใดๆ

หน้านี้มีกรอบ "ออกใบกำกับภาษีเต็มรูปแทนใบกำกับภาษีอย่างย่อ" ที่มีช่อง "อ้างอิงเลขที่ใบกำกับภาษีอย่างย่อ (ABB)", "รหัสลูกค้า / ชื่อผู้ซื้อในใบกำกับภาษีเต็มรูป", "เลขประจำตัวผู้เสียภาษี 13 หลัก / สาขา", "ที่อยู่ออกใบกำกับภาษีเต็มรูป" ด้านล่างเป็นตารางบิลเดียวกับหน้า "รายการใบกำกับภาษีอย่างย่อ" ซึ่งมีปุ่ม "ยกเลิกบิล" จริง ระวังอย่ากดโดยเข้าใจว่าเป็นการออกใบเต็มรูป เพราะจะยกเลิกบิลขายนั้นทันที ([[howto-pos-web-bill-list-cancel]])

ในแอปแคชเชียร์ ปุ่ม "ใบกำกับภาษี" ที่แผงปุ่มล่างเพียงเปิดหน้าต่างเลือกลูกค้า / สมาชิก ไม่ได้ออกใบกำกับภาษีเต็มรูป

**ถ้าลูกค้าขอใบกำกับภาษีเต็มรูปหลังซื้อที่ POS:**
1. อย่ากรอกฟอร์มนี้และอย่าบอกลูกค้าว่าออกให้แล้ว
2. ปรึกษาฝ่ายบัญชีหรือผู้ดูแลระบบว่าร้านจะออกเอกสารเต็มรูปแทนบิลเดิมด้วยขั้นตอนใด เช่น ผ่านเมนูขาย/ใบกำกับภาษีปกติ
3. ถ้าต้องยกเลิกบิลเดิมก่อน ดู [[howto-pos-web-bill-list-cancel]] (การยกเลิกบิลมีผลกับยอดขายและภาษี ควรให้ฝ่ายบัญชียืนยันก่อน)

ข้อกำหนดทางภาษีว่าต้องออกอย่างไรให้ปรึกษาผู้ทำบัญชีของร้าน หน้านี้ไม่ใช่คำแนะนำทางกฎหมาย
