# สถานะเช็คแต่ละแบบหมายความว่าอะไร?

**ตอบสั้น:** สถานะเช็คคำนวณจากเอกสารล่าสุดที่ยังไม่ถูกยกเลิกของเช็คใบนั้น ยกเลิกเอกสารขั้นหลังแล้ว สถานะจะกลับไปเป็นสถานะก่อนหน้าเอง

## รายละเอียด
| สถานะ | เช็ครับ (จากลูกค้า) | เช็คจ่าย (ให้ผู้ขาย) |
|---|---|---|
| เช็คในมือ | รับมาแล้ว ยังไม่นำฝาก (รวมเช็ครับยกมา) | สั่งจ่ายแล้ว ธนาคารยังไม่ตัดเงิน |
| เช็คนำฝาก | บันทึกนำฝากแล้ว รอธนาคารเรียกเก็บ | ไม่มี |
| เช็คผ่าน | ธนาคารเรียกเก็บได้แล้ว | ธนาคารตัดเงินแล้ว |
| เช็ครับคืน | ธนาคารคืนเช็ค (เช็คเด้ง) ทั้งเช็คที่นำฝากแล้วหรือผ่านแล้ว | เช็คที่ผ่านแล้วถูกคืน (เช็คจ่ายก็แสดงคำว่า เช็ครับคืน) |
| เช็คยกเลิก | บันทึกเช็คขาดสิทธิ์ | บันทึกเช็คขาดสิทธิ์ |
| เช็คเปลี่ยน | ลูกค้าเปลี่ยนเป็นเช็คใบใหม่หรือเงินอื่น | เปลี่ยนเป็นเช็คใบใหม่หรือเงินอื่น |
| เช็คตั้งหนี้ใหม่ | คืนเช็คให้ลูกค้า แล้วตั้งเป็นหนี้ค้างรับ | ไม่มี |

- ระบบยังมีสถานะ เช็คขายลด และ เช็คคืนนำเข้าใหม่ ในรายงาน แต่หน้าจอเวอร์ชันนี้ยังไม่มีเมนูให้บันทึกสองสถานะนี้
- เช็คที่ถูกคืน นำฝากใหม่ เปลี่ยน ตั้งหนี้ใหม่ หรือขาดสิทธิ์ ต่อได้
- ถ้ายกเลิกเอกสารรับเงินที่รับเช็คใบนั้นไว้ (ตอนเช็คยังอยู่ในมือ) เช็คยังค้างอยู่ในทะเบียนและยังแสดงเป็นเช็คในมือ เลือกนำฝากได้อยู่ ให้ส่งต่อเจ้าหน้าที่
- ดูสถานะได้ในรายงาน เช่น "รายงานรายละเอียดเช็ครับ - ตามวันที่รับ - ตามสถานะเช็ค" "รายงานรายละเอียดเช็ครับ - ตามวันที่ครบกำหนด" "รายงานรายละเอียดเช็คจ่าย - ตามวันที่รับ - ตามสถานะเช็ค" และ "รายงานรายละเอียดเช็คจ่าย - วันครบกำหนด" ([[rpt-overview]])
- หน้า ทะเบียนเช็ครับ / ทะเบียนเช็คจ่าย ไม่มีช่องแสดงสถานะ แต่เปิดเช็คแต่ละใบแล้วดูตาราง "ประวัติความเคลื่อนไหวเช็ค / บัตรเครดิต" ได้ว่าผ่านเอกสารอะไรมาแล้วบ้าง
