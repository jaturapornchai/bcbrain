# CRM อะไรจริง อะไรเป็นตัวสาธิต?

**ตอบสั้น:** ส่วนที่ดึงข้อมูลจากบัญชี (ลูกค้า ยอดซื้อ เอกสารขาย เกรด) และการจดประวัติการติดต่อ ใช้ได้จริง ส่วนที่เกี่ยวกับการส่งข้อความออก ตัวเลขการตลาด และผลงานทีมขาย ยังเป็นต้นแบบ

## ใช้ได้จริง
| เรื่อง | หมายเหตุ |
|---|---|
| รายชื่อลูกค้า ยอดซื้อสะสม เกรด แต้ม | คิดจากข้อมูลบัญชีของบริษัท ดู [[sys-crm-customer-grades]] |
| ใบเสนอราคา/ใบสั่งขาย/ใบขายบนกระดาน | ดึงจากเอกสารจริง (ล่าสุดไม่เกิน 40 ใบ) |
| จดประวัติการติดต่อลูกค้า | เก็บถาวรและเห็นทั้งทีม [[howto-crm-customer-visit-note]] |
| ตัวเลขสรุป ยอดขาย ใบลดหนี้ ยอดวางบิล/รับชำระ | รวมจากเอกสารบัญชี |
| รายชื่อลูกค้า | แสดงสูงสุด 100 รายที่ยอดซื้อสูงสุด |

## เป็นต้นแบบ / ตัวสาธิต
| เรื่อง | ความจริง |
|---|---|
| ส่งข้อความตอบแชท | บันทึกในหน้า CRM เท่านั้น ไม่ได้ส่งไป LINE ของลูกค้า |
| ทวงผ่าน LINE | เปลี่ยนสถานะ ไม่ได้ส่งข้อความ |
| ยิง Broadcast / ผลแคมเปญ | ไม่ได้ส่งจริง ตัวเลขผลลัพธ์ระบบตั้งให้ |
| สร้างดีล / เลื่อนขั้น / แปลงแชทเป็น QT | จดบนกระดานเท่านั้น ไม่ออกเอกสารบัญชี |
| คิวติดตามหนี้ ห้องแชท | ข้อมูลตัวอย่างในฐานข้อมูลสาธิต ไม่ได้ดึงจากหนี้จริง |
| ผลงานทีมขาย ยอด/เปอร์เซ็นต์เป้า | ตัวเลขสมมุติ |
| ปุ่มดึงพิกัด GPS | พิกัดตายตัว ไม่ใช่ตำแหน่งจริง ชื่อผู้ติดต่อและสถานที่ Check-in ที่บันทึกก็เป็นข้อความตัวอย่างตายตัว |
| การ์ดลูกค้าสนใจของลูกค้าที่ยังไม่เคยซื้อ | มูลค่าในการ์ดเป็นตัวเลขสมมุติของระบบ |
| แท็บ "สินค้าที่ลูกค้ารายนี้สั่งซื้อ" | ไม่ได้กรองตามลูกค้า แสดงสินค้าจากเอกสารขายล่าสุดของบริษัท |
| แท็บ Check-in หน้างาน | แสดงบันทึกของทุกลูกค้ารวมกัน |
| ตารางโทรติดตาม "ติดต่อแล้ว" | จำแค่ในหน้าจอ ไม่ถูกบันทึก |

ราคา แพ็กเกจ และแผนพัฒนาส่วนที่ยังไม่เสร็จ สอบถามฝ่ายขาย
