# แอปมือถือ AutoCare ทำอะไรได้ต่างจากเว็บ และทำไมข้อมูลที่พิมพ์ไม่ตรง?

**ตอบสั้น:** แอปมือถือทำได้เฉพาะงานหน้าอู่ 4 อย่าง (รับรถ แจ้งซ่อมเพิ่ม รับยางเข้าคลัง อนุมัติส่วนลด) ส่วนปิดบิล ออกใบกำกับภาษี ข้อมูลหลัก และรายงานต้องทำที่เว็บ และตอนนี้ข้อมูลบางช่องที่พิมพ์ในมือถือไม่ถูกบันทึกตรงตัว ต้องตรวจที่เว็บทุกครั้ง

## รายละเอียด
| งาน | มือถือ | เว็บ |
|---|---|---|
| เปิดใบรับรถ | ได้ (ข้อมูลบางช่องไม่ถูกบันทึกตรงตัว) | ได้ ครบทุกช่อง |
| แจ้งซ่อมเพิ่ม/อนุมัติ | ได้ (ราคาใช้ค่ามาตรฐาน) | ได้ |
| รับยางเข้าคลัง | ได้ แต่จำนวนใช้ค่ามาตรฐานและยอดสต็อกอาจไม่เพิ่ม | ได้ |
| อนุมัติส่วนลดพิเศษ | ได้ | ได้ |
| ปิดบิล ลงบัญชี ออกใบกำกับภาษี | ไม่ได้ | ได้ |
| ข้อมูลหลัก (รถ ช่อง ช่าง ยาง) | ไม่ได้ | ได้ |
| รายงานทั้งหมด | ไม่ได้ (มีเพียงตัวเลขสรุปและกระเป๋าเงินช่าง) | ได้ |

**ช่องที่พิมพ์แล้วอาจไม่ตรง** (ตรวจแล้วว่าแอปส่งชื่อช่องไม่ตรงกับที่ระบบรอรับ ระบบจึงใช้ค่ามาตรฐานแทน): เลขไมล์ ชื่อและเบอร์ลูกค้า ช่องซ่อมและช่าง สภาพขอบล้อ ราคาและชื่อรายการแจ้งซ่อมเพิ่มที่ลูกค้าเห็น จำนวนยางที่นับรับและเลขที่ใบสั่งซื้อ ที่ส่งตรงและบันทึกถูกมีเฉพาะ ทะเบียน จังหวัด ยี่ห้อ รุ่น และโหมดธุรกิจ

**คำแนะนำ:** ใช้แอปมือถือเพื่อเปิดใบงานให้เร็ว แล้วให้พนักงานออฟฟิศเปิดใบนั้นบนเว็บ AutoCare ตรวจและแก้ข้อมูลก่อนปิดบิล ถ้าลูกค้าอยากใช้แอปเป็นช่องทางหลักในหน้างานจริง ให้แจ้งฝ่ายพัฒนาเรื่องข้อมูลที่ไม่ตรงนี้
