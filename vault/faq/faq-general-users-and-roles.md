# ใช้หลายคนได้ไหม และแบ่งสิทธิ์พนักงานได้ไหม?

**ตอบสั้น:** ได้ Admin ของบริษัทเชิญพนักงานด้วยอีเมลบัญชี Google ของเขา แล้วเลือกให้เป็น Admin (ทำได้ทุกอย่าง) หรือ Member (ใช้ได้เฉพาะหน้าจอที่ได้รับสิทธิ์) จำนวนผู้ใช้ที่รวมในแต่ละแพ็กเกจและราคา สอบถามฝ่ายขาย

## รายละเอียด
- **เชิญพนักงาน:** หน้าเลือกฐานข้อมูล › การ์ดของบริษัท › ปุ่ม "สมาชิก & สิทธิ์จอ" กรอกช่อง "อีเมลผู้ใช้งาน (Google / Gmail)" เลือก "ระดับสิทธิ์ (Role)" และ "ผูกกับรหัสผู้ใช้ (BC User)" แล้วกด "เพิ่ม/บันทึก" ส่วนการเลือกหน้าจอที่ใช้ได้ กดปุ่ม "กำหนดสิทธิ์จอ"
- **Admin:** เปิดได้ทุกหน้าจอ เพิ่มลบสมาชิก และใช้เมนูตั้งค่าที่จำกัดเฉพาะผู้ดูแล
- **Member:** เห็นและใช้ได้เฉพาะหน้าจอที่ Admin ติ๊กให้ ปุ่มเพิ่ม แก้ไข ลบ ในหน้าจอนั้นใช้ได้ตามสิทธิ์ที่กำหนด
- **กลุ่มพนักงาน:** จัดพนักงานเป็นกลุ่มตามหน้าที่ เช่น ขาย จัดซื้อ คลัง แล้วกำหนดสิทธิ์ทั้งกลุ่ม ถ้าคนหนึ่งมีทั้งสิทธิ์ของตัวเองและสิทธิ์ของกลุ่ม ระบบรวมให้ คือได้สิทธิ์ถ้าฝั่งใดฝั่งหนึ่งให้
- **สิทธิ์คลัง:** จำกัดได้ว่าพนักงานแต่ละกลุ่มเลือกใช้คลังและที่เก็บไหนได้
- หลายคนเปิดรายการเดียวกันพร้อมกัน ระบบล็อกให้คนแรกแก้ก่อน ดู [[faq-general-many-users-at-once]]
- เมื่อพนักงานลาออก ให้ Admin ลบสมาชิกออกจากบริษัท เขาจะไม่เห็นฐานข้อมูลนั้นอีก ควรตรวจก่อนลบเพราะระบบไม่ถามยืนยัน
- ควรมี Admin อย่างน้อย 2 คน เผื่อคนใดคนหนึ่งเข้าระบบไม่ได้
