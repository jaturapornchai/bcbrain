# สินทรัพย์ชำรุด สูญหาย หรือจะตัดจำหน่ายทิ้ง บันทึกอย่างไร?

**ตอบสั้น:** ระบบยังไม่มีเอกสารตัดจำหน่ายแยก ทางที่ใช้ได้คือบันทึกผ่าน บันทึกการขายสินทรัพย์ โดยใส่ราคาขายเป็นศูนย์ ระบบจะตัดราคาทุนและค่าเสื่อมสะสมออก แล้วลงส่วนที่เหลือเป็นขาดทุนให้

## รายละเอียด
- เมนู กำหนดประเภทการตัดจำหน่าย (เริ่มต้น › ตั้งค่าระบบสินทรัพย์ถาวร) เก็บเป็นข้อมูลอ้างอิงเท่านั้น ยังไม่มีหน้าจอใดนำไปใช้
- ช่อง "สถานะ" ในข้อมูลสินทรัพย์ (ปรกติ / ชำรุด / สูญหาย) เป็นข้อมูลแสดงผล ไม่หยุดการคิดค่าเสื่อมและไม่ลงบัญชี
- ขั้นตอนแนะนำ:
  1. โอนค่าเสื่อมถึงวันก่อนวันตัดจำหน่าย ([[howto-asset-depreciation-post]])
  2. เปิด บันทึกการขายสินทรัพย์ เลือกขายเงินสด เลือกรหัสลูกหนี้ (ระบบบังคับกรอก) เลือกประเภทภาษีตามที่ผู้สอบบัญชีแนะนำ ใส่ราคาขาย 0 และใส่หมายเหตุว่าตัดจำหน่าย ([[howto-asset-sale]])
  3. ตรวจตาราง "รายการบัญชี" แล้วบันทึก
  4. เปลี่ยน "สถานะ" ในข้อมูลสินทรัพย์เป็น ชำรุด หรือ สูญหาย ไว้ดูภายหลัง
- เอกสารนี้จะชื่อว่าการขายในรายงาน ถ้าต้องการเอกสารแยกหรือหลักฐานประกอบการตัดจำหน่าย ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร และส่งต่อทีมงานเป็นข้อเสนอแนะ
