# ภาษีซื้อเข้ารายงานเดือนไหน เปลี่ยนเดือนภาษีได้ไหม?

**ตอบสั้น:** รายงานภาษีดึงตามช่อง เดือนภาษี / ปีภาษี ของแถวภาษี ถ้าไม่ได้ใส่ ระบบใช้เดือนและปีของวันที่ใบกำกับ เปลี่ยนได้ที่แถวภาษี

## รายละเอียด
- แก้วันที่ในแถวภาษี ระบบเปลี่ยน เดือนภาษี/ปีภาษี ตามให้ ถ้าต้องการเดือนอื่น ให้แก้ช่อง เดือนภาษี/ปีภาษี หลังใส่วันที่
- ในเอกสารซื้อขาย แถวภาษีถูกสร้างใหม่จากหัวเอกสารทุกครั้งที่บันทึก ถ้าจะเปลี่ยนเดือนภาษี ต้องติ๊ก "บันทึกภาษีซื้อเอง / หลายใบกำกับภาษี" (หรือฝั่งขาย "บันทึกภาษีขายเอง / หลายใบกำกับภาษี") ก่อนแก้ ไม่งั้นจะถูกเขียนทับ ([[howto-tax-vat-from-documents]])
- ในใบสำคัญที่บันทึกเอง แก้ที่แท็บภาษีได้เลย ([[howto-tax-journal-tax-tabs]])
- เปิดรายงานด้วยช่วงวันที่ของเดือนภาษีที่ต้องการ ระบบดูเดือนภาษี ไม่ใช่วันที่เอกสาร
- ภาษีซื้อใช้สิทธิ์ได้เดือนไหน ให้ปรึกษาผู้สอบบัญชี/สรรพากร
