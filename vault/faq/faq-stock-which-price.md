# ตอนเลือกสินค้าในบิล ระบบดึงราคาขายหรือราคาซื้อมาจากไหน?

**ตอบสั้น:** ราคาขายหาตามลำดับ ราคาตามลูกค้า → ราคาตามกลุ่มลูกค้า → ราคาขายทั่วไป → ราคาขายมาตรฐาน → สูตรราคาขาย → ราคาตามบาร์โค้ด ส่วนราคาซื้อหา ราคาตามเจ้าหนี้ → ราคาซื้อทั่วไป → ราคาซื้อครั้งล่าสุด ราคาที่ดึงมาแก้ในบิลได้เสมอ

## รายละเอียด
**ราคาขาย**
| ลำดับ | แหล่งราคา | ตั้งที่ |
|---|---|---|
| 1 | ราคาตามลูกค้า | [[howto-stock-sale-price]] |
| 2 | ราคาตามกลุ่มลูกค้า | [[howto-stock-sale-price]] |
| 3 | ราคาขายทั่วไป | [[howto-stock-sale-price]] |
| 4 | ราคาขายมาตรฐาน | [[howto-stock-sale-price]] |
| 5 | สูตรราคาขาย (ระดับราคา 1-9 ของลูกค้า หรือราคากลาง) | [[howto-stock-price-formula]] |
| 6 | ราคาตามบาร์โค้ด | [[howto-stock-barcode]] |

- แถวราคาต้องตรงทั้งหน่วยนับ ช่วงวันที่ ช่วงจำนวน และประเภทการขาย จึงจะถูกเลือก
- ไม่เจอราคาเลย และเปิด ระบบเรียกราคาขายล่าสุด ไว้ ระบบใช้ราคาขายล่าสุดหรือราคาขายเฉลี่ยของลูกค้ารายนั้น
- ช่อง ไม่ใช้งาน ในตารางราคา ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ถ้าเลิกใช้ราคาไหนให้ลบแถวหรือแก้ช่วงวันที่ให้หมดอายุ

**ราคาซื้อ**
1. ราคาตามเจ้าหนี้ของผู้ขายในบิล
2. ราคาซื้อทั่วไป
3. ราคาซื้อครั้งล่าสุดจากผู้ขายรายนั้น
- ระบบเทียบช่วงวันที่ของราคากับวันนี้ ไม่ใช่วันที่เอกสาร คีย์บิลย้อนหลังให้ตรวจราคาก่อนบันทึก ([[howto-stock-purchase-price]])

**ราคาไม่ขึ้น หรือขึ้นผิด ตรวจอะไร**
1. หน่วยนับในบิลตรงกับหน่วยในตารางราคาไหม
2. ช่วงวันที่ของแถวราคายังไม่หมดอายุ
3. จำนวนอยู่ในช่วงจำนวนของแถวราคา
4. ลูกค้าอยู่กลุ่มที่ตั้งราคาไว้ หรือตั้งระดับราคาไว้ไหม
