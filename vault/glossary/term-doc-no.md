# เลขที่เอกสาร / รูปแบบเลขที่เอกสาร

## ความหมายแบบบ้านๆ
เลขประจำตัวของเอกสารแต่ละใบ เช่น บิลขาย ใบสั่งซื้อ ห้ามซ้ำกัน
ระบบรันเลขให้อัตโนมัติตาม "รูปแบบ" ที่ตั้งไว้ต่อประเภทเอกสาร

## ตัวอย่าง
ร้านเอตั้งรูปแบบบิลขายเป็นตัวอักษรนำหน้า + ปีเดือน + เลขรัน
พอขึ้นเดือนใหม่ ส่วนปีเดือนในเลขเปลี่ยน เลขรันจึงเริ่มนับใหม่ของเดือนนั้น

## ในระบบ BC อยู่ตรงไหน
- เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรูปแบบเลขที่เอกสาร
- ช่องสำคัญ:
  - "รูปแบบเอกสาร (Format) :" ตัวอย่างบนจอ "เช่น @YYMM####"
  - "รูปแบบใบกำกับภาษี (Tax Format) :" สำหรับเลขที่ใบกำกับภาษี
  - "การรันเลขที่เอกสาร (Doc Running) :" ต่อเนื่อง / รายปี / รายเดือน / รายวัน
- วิธีตั้งทีละขั้น ดู [[howto-setup-doc-format]]

## ระบบทำอะไรให้อัตโนมัติ
- ตอนเปิดเอกสารใหม่ ระบบหาเลขถัดไปให้ (เลขล่าสุดของหัวเลขเดียวกัน + 1) ถ้ามีคนบันทึกเลขเดียวกันไปก่อน ตอนบันทึกจะขึ้น "เลขที่เอกสารซ้ำ" ให้เปลี่ยนเลขแล้วบันทึกใหม่
- ในรูปแบบใส่ปีเดือนวันได้ ทั้งแบบ ค.ศ. และ พ.ศ. (เช่น YY MM DD หรือ ปป)
- การเริ่มนับเลขใหม่ขึ้นกับปีเดือนวันที่ใส่ในรูปแบบเท่านั้น ช่อง "การรันเลขที่เอกสาร (Doc Running)" ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล
- เลขที่เอกสารยาวได้ไม่เกิน 25 ตัวอักษร ถ้ารูปแบบยาวเกินจะขึ้น "เลขที่เอกสาร ... ยาวเกิน 25 ตัวอักษร กรุณาแก้รูปแบบเลขที่เอกสาร"
- ข้อเลือกพิเศษ "ห้ามแก้ไขวันที่และเลขที่เอกสาร" (ที่ กำหนดข้อเลือกพิเศษต่างๆ แท็บ "1.ตั้งค่าระบบ" และในสิทธิ์ผู้ใช้) ถ้าลูกค้าต้องการล็อกการแก้วันที่และเลขที่เอกสารจริง ให้ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า
- รูปแบบที่มีเอกสารซื้อ-ขาย-คลัง หรือสมุดรายวันใช้อยู่แล้วลบไม่ได้ ขึ้นหัวข้อ "ห้ามลบ" ข้อความ "รหัสรูปแบบเอกสาร [...] ถูกใช้งานใน...แล้ว ไม่สามารถลบได้"
