# เลขประจำตัวผู้เสียภาษี / เลขที่สาขา

## ความหมายแบบบ้านๆ
- **เลขประจำตัวผู้เสียภาษี** = เลข 13 หลักของบริษัทหรือบุคคล ต้องพิมพ์บนใบกำกับภาษีเต็มรูปและใช้ในรายงานภาษี
- **เลขที่สาขา** = เลข 5 หลักบอกว่าเป็นสำนักงานใหญ่หรือสาขาไหน (สำนักงานใหญ่กรอก 00000)

## ตัวอย่าง
บริษัทบีขอใบกำกับภาษีเต็มรูปในนาม "สาขาที่ 1" ร้านเอต้องกรอกเลขผู้เสียภาษีของบริษัทบี และเลขที่สาขา 00001 ในทะเบียนลูกหนี้

## ในระบบ BC อยู่ตรงไหน
- ของลูกค้า/ผู้ขาย: ช่อง "เลขประจำตัวผู้เสียภาษี" "สถานประกอบการ" (สำนักงานใหญ่/สาขา) และ "เลขที่สาขา"
  ที่ ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › กำหนดลูกหนี้ / รายละเอียดลูกหนี้
  และ เจ้าหนี้ › ทะเบียนเจ้าหนี้ คู่ค้า และที่อยู่จัดส่ง › กำหนดเจ้าหนี้ / รายละเอียดเจ้าหนี้
- กรอกเลขเป็นตัวเลขติดกัน ไม่ต้องเว้นวรรค
- ของกิจการเราเอง: เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรายละเอียดบริษัท และ กำหนดรายละเอียดสาขา
- ในแท็บภาษีซื้อ/ภาษีขาย มีคอลัมน์ "เลขประจำตัวผู้เสียภาษี" "สถานประกอบการ" (เลือก "สำนักงานใหญ่" หรือ "สาขา") และ "เลขที่สาขา"

## ระบบทำอะไรให้อัตโนมัติ
- ตอนบันทึก ถ้าแถวภาษีในบิลยังว่างทั้งชื่อ เลขผู้เสียภาษี และสาขา ระบบเติมจากทะเบียนลูกหนี้/เจ้าหนี้ให้
  ถ้าพิมพ์ช่องใดช่องหนึ่งไว้แล้ว ระบบใช้ตามที่พิมพ์ ไม่ดึงจากทะเบียน
- รายงานภาษีซื้อ/ภาษีขาย/หัก ณ ที่จ่าย ใช้เลขที่บันทึกไว้ในรายการภาษีนั้น

## คำที่คล้าย/สับสนบ่อย
- สาขาของกิจการเรา (กำหนดรายละเอียดสาขา) กับ เลขที่สาขาของลูกค้า คนละที่กัน
- [[term-tax-invoice]] ใบกำกับภาษี
- [[term-wht]] ภาษีหัก ณ ที่จ่าย ใช้เลขผู้เสียภาษีหรือเลขบัตรประชาชน
