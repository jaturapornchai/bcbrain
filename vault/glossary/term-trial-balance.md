# งบทดลอง / บัญชีแยกประเภท

## ความหมายแบบบ้านๆ
- **บัญชีแยกประเภท** = รายการเคลื่อนไหวของบัญชีหนึ่งบัญชี เรียงตามวันที่ พร้อมยอดคงเหลือ
- **งบทดลอง** = ตารางยอดคงเหลือของทุกบัญชี ณ วันที่หนึ่ง ใช้เช็กว่ายอดเดบิตรวมเท่ากับเครดิตรวม
- **กระดาษทำการ** = ตารางที่ต่อจากงบทดลอง แยกยอดไปฝั่งงบกำไรขาดทุนและงบดุล

## ตัวอย่าง
ผู้ทำบัญชีของร้านเอดูงบทดลองสิ้นเดือน เห็นยอดธนาคารไม่ตรงกับ statement
จึงเปิดบัญชีแยกประเภทของบัญชีธนาคารนั้นเพื่อไล่ดูทีละรายการ

## ในระบบ BC อยู่ตรงไหน
- บนหน้าจอ: บัญชี › สอบถามบัญชีแยกประเภทและงบการเงิน (บนหน้าจอ) › แสดงงบทดลอง / แสดงงบทดลอง (มิติ) / แสดงกระดาษทำการ
- รายงาน: บัญชี › รายงานงบทดลอง กระดาษทำการ และงบการเงิน › รายงานงบทดลอง (มาตรฐาน)
- รายงาน: บัญชี › รายงานผังบัญชี สมุดรายวัน และบัญชีแยกประเภท › รายงานบัญชีแยกประเภท
- ส่งออก/พิมพ์รายงาน ดู [[rpt-print-export]]

## ระบบทำอะไรให้อัตโนมัติ
- รวมยอดจากข้อมูลรายวันทุกใบ ทั้งที่เอกสารสร้างให้และที่คีย์เอง
- นับรวมทั้งรายการที่ผ่านรายการแล้วและยังไม่ผ่าน
- รวมยอดบัญชีย่อยขึ้นไปที่บัญชีหลักตามโครงสร้างผังบัญชี
- รหัสบัญชีที่ไม่มีในผังจะขึ้นเป็น "(ไม่พบในผังบัญชี)" เพื่อให้ยอดเดบิตยังเท่าเครดิต ให้แก้รายการนั้น
- ตัวเลือกบนรายงาน เช่น "ต้องการแสดงยอดสุทธิ", "ต้องการแสดงยอดปรับปรุง", "รวมรายการปิดบัญชี", "รวมรายการยกไป"
