# ภาษีซื้อ / ภาษีขาย

## ความหมายแบบบ้านๆ
- **ภาษีขาย** = ภาษีมูลค่าเพิ่มที่เราเก็บจากลูกค้าตอนขาย
- **ภาษีซื้อ** = ภาษีมูลค่าเพิ่มที่เราจ่ายให้ผู้ขายตอนซื้อ
ทั้งสองอย่างไปรวมในรายงานภาษีมูลค่าเพิ่มประจำเดือน

## ตัวอย่าง
เดือนนี้ร้านเอขายของได้ภาษีขายจำนวนหนึ่ง และซื้อของมีภาษีซื้ออีกจำนวนหนึ่ง
ระบบรวบรวมใบกำกับภาษีทั้งสองฝั่งออกเป็นรายงานภาษีขายและรายงานภาษีซื้อ ให้ผู้ทำบัญชีใช้ยื่นแบบ

## ในระบบ BC อยู่ตรงไหน
- บิลซื้อ-ขายสร้างรายการภาษีให้เองจากหัวบิล
- แท็บ "ภาษีซื้อ" / "ภาษีขาย" ในข้อมูลรายวัน (บันทึกบัญชีเอง) และในรับชำระหนี้/จ่ายชำระหนี้ บันทึกได้หลายใบกำกับในเอกสารเดียว
- ช่องในแท็บ: เลขที่ใบกำกับ (ฝั่งขายชื่อ "เลขที่ใบกำกับภาษี"), เดือนภาษี, ปีภาษี, ฐานภาษี, อัตราภาษี, ยื่นเพิ่มเติม, เลขประจำตัวผู้เสียภาษี, สถานประกอบการ (สำนักงานใหญ่/สาขา)
- ช่อง "ประเภทภาษี": ฝั่งซื้อ "ปรกติ", "ขอคืนไม่ได้", "ไม่ถึงกำหนดชำระ" ฝั่งขาย "ปรกติ", "ไม่ถึงกำหนดชำระ"
- รายงาน: บัญชี › รายงานภาษีมูลค่าเพิ่ม (ภ.พ.30) › รายงานภาษีขาย / รายงานภาษีซื้อ

## ระบบทำอะไรให้อัตโนมัติ
- ลงบัญชี: ซื้อ → เดบิตบัญชีภาษีซื้อ (ในแม่แบบชื่อ "ภาษีซื้อ (มูลค่าเพิ่ม)") ขาย → เครดิตบัญชีภาษีขาย (ในแม่แบบชื่อ "ยอดภาษีมูลค่าเพิ่ม")
- ใช้เดือนภาษี/ปีภาษีของแต่ละใบในการจัดเข้ารายงาน
- ในข้อมูลรายวัน แท็บภาษีแก้ได้เฉพาะรายการที่บันทึกเอง รายการที่ระบบสร้างจากเอกสารอื่นแก้ที่เอกสารต้นทางแทน
