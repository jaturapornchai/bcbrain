# LOT / Serial Number / วันหมดอายุ

## ความหมายแบบบ้านๆ
- **LOT** = ชุดการผลิตหรือชุดที่รับเข้า แยกยอดคงเหลือเป็นรายล็อต
- **Serial Number** = เลขประจำเครื่องรายชิ้น เช่น มือถือ เครื่องใช้ไฟฟ้า
- **วันหมดอายุ** = คุมวันผลิต/วันหมดอายุรายล็อต เช่น อาหาร ยา เครื่องสำอาง

## ตัวอย่าง
ร้านเอขายยา รับเข้า 2 ล็อตคนละวันหมดอายุ เปิด "ใช้ระบบหมดอายุ" แล้วบันทึกวันหมดอายุตอนรับเข้า
ร้านบีขายพัดลม ติ๊ก "สินค้ามี Serial" แล้วคีย์เลขเครื่องทุกครั้งที่ซื้อเข้าและขายออก

## ในระบบ BC อยู่ตรงไหน
- ข้อมูลสินค้า: ช่องติ๊ก "สินค้ามี Serial", "ใช้ระบบหมดอายุ" และช่อง "ประเภทต้นทุน" เลือก "2.ต้นทุน LOT FIFO", "3.ต้นทุน LOT กำหนดเอง" หรือ "4.ต้นทุน FEFO (วันหมดอายุ)"
- ทะเบียน Serial: สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ทะเบียน Serial Number
- ดูยอดรายล็อต: สินค้า › สอบถามและวิเคราะห์ข้อมูลสินค้า (บนหน้าจอ) › ยอดคงเหลือสินค้าตาม LOT
- ล้างมูลค่าค้างในล็อตที่จำนวนเป็นศูนย์: สินค้า › ตรวจนับสต็อกและปรับปรุงจากการตรวจนับ › ปรับปรุงมูลค่าสินค้า Lot คงค้าง

## ระบบทำอะไรให้อัตโนมัติ
- สินค้า "3.ต้นทุน LOT กำหนดเอง" ต้องใส่เลขล็อตทุกบรรทัด ถ้าไม่ใส่ บันทึกไม่ได้ ขึ้นข้อความ "รหัสสินค้า ... ยังไม่บันทึกหมายเลข LOT แบบกำหนดเอง"
- ถ้าติ๊ก "ใช้ระบบค้นหา LOT อัตโนมัติ" (เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ แท็บ "4.ระบบขาย") ตอนเปิดบิลขายใหม่แล้วไม่ใส่ล็อต ระบบเลือกล็อตแรก (เรียงตามเลขล็อต) ที่ยอดในคลัง/ที่เก็บนั้นพอให้ ถ้าล็อตเดียวไม่พอจะแยกบรรทัดเพิ่มให้ ถ้าหาล็อตที่มีของไม่ได้ ยังขึ้นข้อความด้านบน
- ข้อความเรื่อง Serial ที่พบบ่อย:
  - ตอนบันทึกเอกสาร: "Serial Number ... ของสินค้า ... ซ้ำในเอกสาร" / "จำนวน Serial Number มากเกินไป"
  - ที่จอ ตรวจสอบสินค้า Serial Number: "มี Serial Number ว่างในรายการ" / "มีการป้อน Serial Number ... ซ้ำ" / "ไม่พบ Serial Number ... ในทะเบียน Serial"
