# เงินมัดจำ

## ความหมายแบบบ้านๆ
เงินที่ลูกค้าจ่ายไว้ก่อนเพื่อ "จอง" ว่าจะซื้อแน่ (หรือเราจ่ายให้ผู้ขาย) แล้วค่อยนำไปหักตอนออกบิลจริง
ในระบบ BC เอกสารเงินมัดจำมีภาษีมูลค่าเพิ่มได้

## ตัวอย่าง
ลูกค้าบีสั่งทำป้าย 20,000 บาท จ่ายมัดจำ 5,000 บาท ร้านเอบันทึก "รับเงินมัดจำ"
วันส่งงาน ร้านเอเปิดบิลขาย ไปที่แท็บ "ใช้เงินมัดจำ" เลือกใบมัดจำ 5,000 บาท บิลจะหักให้ ลูกค้าจ่ายเพิ่มเฉพาะส่วนที่เหลือ

## ในระบบ BC อยู่ตรงไหน
- ฝั่งขาย: ขาย › รับเงินมัดจำ / คืนเงินมัดจำ / รับเงินมัดจำยกมา
- ฝั่งซื้อ: ซื้อ › จ่ายเงินมัดจำ / รับคืนจ่ายเงินมัดจำ / จ่ายเงินมัดจำยกมา
- หักมัดจำ: แท็บ "ใช้เงินมัดจำ" ในบิลขาย บิลซื้อ ตั้งหนี้ซื้อจากการรับสินค้า ตั้งหนี้อื่นๆ รายได้อื่นๆ และค่าใช้จ่ายอื่นๆ (ยอดแสดงที่ช่อง "หักเงินมัดจำ:")

## ระบบทำอะไรให้อัตโนมัติ
- รับ/จ่ายมัดจำ ลงบัญชีอัตโนมัติ ส่วน "มัดจำยกมา" (ยอดค้างก่อนเริ่มระบบ) ไม่ลงบัญชี
- ระบบคุมยอดคงเหลือของใบมัดจำแต่ละใบ หักเกินไม่ได้
- ข้อความที่อาจเจอ
  - "ยอดตัดเงินมัดจำต้องมากกว่า 0"
  - "เลือกเอกสารเงินมัดจำ ... ซ้ำ"
  - "ไม่พบเอกสารเงินมัดจำ ... ของ ... (หรือถูกยกเลิกแล้ว)"
  - "ยอดตัดจ่ายมากกว่ายอดคงเหลือ: เอกสาร ... เกินอยู่ ..."
  - "เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้" (ใบมัดจำที่ถูกหักไปแล้วลบไม่ได้)
- ถ้าเปิดตัวเลือก "วงเงินเครดิตรวมรายการมัดจำ" ตอนตรวจวงเงินเครดิต ระบบนำเงินมัดจำและเงินรับล่วงหน้าที่ลูกค้ายังไม่ได้ใช้ ไปหักออกจากยอดค้างของลูกค้า ทำให้ขายเชื่อได้มากขึ้น

## คำที่คล้าย/สับสนบ่อย
- [[term-advance-payment]] เงินล่วงหน้า ไม่มีช่องภาษี และหักผ่านแท็บนี้ไม่ได้
- [[term-credit-limit]] วงเงินเครดิต
- เรื่องภาษีของเงินมัดจำตามกฎหมาย ให้ปรึกษาผู้สอบบัญชี/สรรพากร
