# ตั้งหนี้

## ความหมายแบบบ้านๆ
บันทึกว่า "มีหนี้เกิดขึ้นแล้ว" แต่ยังไม่ได้จ่ายหรือรับเงิน
- ตั้งหนี้ฝั่งลูกหนี้ = ลูกค้าค้างเงินเรา
- ตั้งหนี้ฝั่งเจ้าหนี้ = เราค้างเงินผู้ขาย

## ตัวอย่าง
- ร้านเอได้บิลค่าซ่อมแอร์ 3,000 บาท จ่ายสิ้นเดือน → ตั้งหนี้อื่นๆ (เจ้าหนี้) ไว้ก่อน
- ร้านเอให้ร้านบีเช่าพื้นที่ แต่ไม่ใช่การขายสินค้า → ตั้งหนี้อื่นๆ (ลูกหนี้)

## ในระบบ BC อยู่ตรงไหน
- ซื้อสินค้าเชื่อ: ซื้อ › ซื้อสินค้า/ตั้งหนี้ซื้อ (ตั้งหนี้พร้อมรับของ)
- หนี้ที่ไม่ใช่การซื้อขายสินค้า: เจ้าหนี้ › ตั้งหนี้อื่นๆ (เจ้าหนี้) และ ลูกหนี้ › ตั้งหนี้อื่นๆ (ลูกหนี้)
- ปรับยอดหนี้อื่นๆ: เพิ่มหนี้อื่นๆ / ลดหนี้อื่นๆ ทั้งฝั่งลูกหนี้และเจ้าหนี้
- หนี้ค้างจากก่อนเริ่มใช้ระบบ: ตั้งหนี้ยกมา (ดู [[term-opening-balance]])

## ระบบทำอะไรให้อัตโนมัติ
- เพิ่มยอดค้างของลูกหนี้/เจ้าหนี้รายนั้น รอรับ/จ่ายชำระ
- ตั้งหนี้อื่นๆ ลงบัญชีอัตโนมัติ (ตั้งหนี้ยกมาไม่ลงบัญชี)
- ตั้งหนี้อื่นๆ (ลูกหนี้) ถูกตรวจวงเงินเครดิตเหมือนบิลขายเชื่อ

## คำที่คล้าย/สับสนบ่อย
- [[term-credit-debit-note]] ลดหนี้/เพิ่มหนี้ คือแก้ยอดหนี้ที่ตั้งไว้แล้ว
- [[term-other-income-expense]] รายได้อื่นๆ/ค่าใช้จ่ายอื่นๆ ใช้เมื่อรับ-จ่ายเงินทันที
- [[term-goods-receipt]] ตั้งหนี้ซื้อจากการรับสินค้า (รับของก่อน ตั้งหนี้ทีหลัง)
