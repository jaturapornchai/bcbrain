# วงเงินเครดิต

## ความหมายแบบบ้านๆ
เพดานยอดค้างสูงสุดที่ยอมให้ลูกค้าคนหนึ่งติดเราได้ กันลูกค้าค้างเยอะจนเก็บเงินไม่ได้
บนจอทะเบียนลูกหนี้ใช้คำว่า "วงเงินสินเชื่อ"
ตั้งเป็น 0 = ไม่ตรวจวงเงินตอนเปิดบิล (ใบสั่งจอง/ใบสั่งขายคิดต่างไป ดูด้านล่าง)

## ตัวอย่าง
ร้านบีมีวงเงิน 50,000 บาท ตอนนี้ค้างอยู่ 45,000 บาท จะเปิดบิลขายเชื่ออีก 8,000 บาท
ยอดรวมเกินวงเงิน ระบบเตือนหรือห้ามบันทึก ตามที่ร้านตั้งค่าไว้

## ในระบบ BC อยู่ตรงไหน
- ตั้งวงเงินรายลูกค้า: ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › รายละเอียดลูกหนี้ หัวข้อ "2. รายละเอียดและสินเชื่อ"
  - ช่อง "วงเงินสินเชื่อ" และ "วงเงินสินเชื่อสูงสุด"
  - "สถานะสินเชื่อ" เลือกได้ เปิดวงเงิน / ปิดวงเงิน / หยุดขายชั่วคราว
  - ช่องติ๊ก "แจ้งเตือนเมื่อเกินวงเงินสินเชื่อ" มีผลกับใบสั่งจอง/ใบสั่งขาย (ดูด้านล่าง)
- ตั้งกติกา: เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ แท็บ "4.ระบบขาย"
  - "เตือนเกินวงเงินเครดิต" เตือนแล้วให้กดบันทึกต่อได้
  - "ห้ามขายเกินวงเงินเครดิต" บิลที่เกินวงเงินบันทึกไม่ได้
  - "ใช้ระบบรหัสผ่านอนุมัติวงเงินเครดิต" ใช้คู่กับ "ห้ามขายเกินวงเงินเครดิต" ระบบจะเปิดหน้าต่าง "ขออนุมัติวงเงินเครดิต" ให้ใส่ "รหัสผู้อนุมัติ" กับ "รหัสผ่าน" แล้วกด "อนุมัติ" ผู้อนุมัติต้องเป็นผู้ใช้ที่ได้สิทธิ์ "สามารถถอนอนุมัติวงเงินเครดิตลูกค้า"
  - "วงเงินเครดิตรวมเช็คคงค้าง" นับเช็ครับที่ยังไม่ผ่านของลูกค้าเป็นยอดค้างด้วย
  - "วงเงินเครดิตรวมรายการมัดจำ" ตอนเปิดบิล หักเงินมัดจำและเงินรับล่วงหน้าที่ลูกค้ายังใช้ไม่หมดออกจากยอดค้าง
  - "ตรวจสอบวงเงินรวมรายการสั่งขาย/สั่งจอง" เปิดการตรวจวงเงินตอนบันทึกใบสั่งจอง/ใบสั่งขาย
  - "สั่งจอง สั่งขาย เงินเชื่อตรวจสอบวงเงินลูกค้า" ใบสั่งจอง/ใบสั่งขายที่เกินวงเงินบันทึกไม่ได้
- เมนู เริ่มต้น › ตั้งค่าระบบลูกหนี้ › กำหนดเหตุผลอนุมัติวงเงิน และ เริ่มต้น › ตั้งค่าระบบขายและ POS › กำหนดกลุ่มอนุมัติวงเงิน บันทึกข้อมูลได้ แต่รุ่นปัจจุบันยังไม่ได้นำไปใช้ตอนตรวจวงเงิน

## ระบบทำอะไรให้อัตโนมัติ
- ตรวจตอนบันทึก ขาย › ขายสินค้า/บริการ แบบขายเชื่อ, ลูกหนี้ › ตั้งหนี้อื่นๆ (ลูกหนี้) และ เงินสด/ธนาคาร › รายได้อื่นๆ / เพิ่มหนี้รายได้อื่นๆ แบบเงินเชื่อ
  - ลูกค้าที่สถานะสินเชื่อไม่ใช่ "เปิดวงเงิน" บันทึกไม่ได้เสมอ แม้ไม่ได้เปิดตัวเลือกใดเลย ขึ้น "ลูกค้า ... : ... ถูกปิดสถานะเครดิต"
  - ยกเว้นลูกค้า "หยุดขายชั่วคราว" เมื่อเปิด "ตรวจสอบวงเงินรวมรายการสั่งขาย/สั่งจอง" ขายได้ถ้าดึงมาจากใบสั่งที่อนุมัติวงเงินแล้ว ไม่งั้นขึ้น "ลูกค้า ... : ... ยังไม่อนุมัติเปิดสถานะเครดิต"
  - วงเงินไม่ใช่ 0 และเปิด "เตือน..." หรือ "ห้ามขาย..." ไว้ ระบบเทียบยอดบิลนี้กับวงเงินที่เหลือ (วงเงิน ลบ ยอดค้าง)
  - เกินแบบเตือน: "ยอดวงเงินเครดิตของลูกค้า เกินที่กำหนดไว้ ต้องการดำเนินการต่อหรือไม่"
  - เกินแบบห้าม: "ยอดวงเงินเครดิตของลูกค้า เกินที่กำหนดไว้" บันทึกไม่ได้ (ถ้าเปิดระบบรหัสผ่านไว้จะให้ใส่รหัสผู้อนุมัติแทน ใส่ผิดขึ้น "รหัสผู้อนุมัติหรือรหัสผ่านไม่ถูกต้อง")
- ตรวจตอนบันทึก ขาย › ใบสั่งจองสินค้า และ ขาย › ใบสั่งขายสินค้า แบบเงินเชื่อ เมื่อเปิด "ตรวจสอบวงเงินรวมรายการสั่งขาย/สั่งจอง"
  - ยอดค้างนับรวมใบสั่งจองและใบสั่งขายเงินเชื่อที่ยังไม่ได้ดึงไปขายด้วย ถ้าเปิด "วงเงินเครดิตรวมรายการมัดจำ" จะบวกเงินรับล่วงหน้าที่ยังเหลือเข้าวงเงิน
  - ไม่เกินวงเงิน ระบบอนุมัติให้อัตโนมัติ
  - เกินวงเงิน ถาม "เกินวงเงินเครดิตลูกค้า ต้องการบันทึกเพื่อขออนุมัติหรือไม่" ตอบตกลงแล้วใบนั้นถูกพักไว้รออนุมัติวงเงิน
  - ลูกค้า "หยุดขายชั่วคราว" ถาม "ลูกค้าถูกปิดสถานะชั่วคราว ต้องการบันทึกเพื่อขออนุมัติหรือไม่" ทุกครั้ง
  - ลูกค้าวงเงิน 0 ใบสั่งเงินเชื่อถูกพักรออนุมัติทุกใบ (ถ้าสถานะเป็นปิดวงเงิน ขึ้น "ถูกปิดสถานะเครดิต")
  - เปิด "สั่งจอง สั่งขาย เงินเชื่อตรวจสอบวงเงินลูกค้า" ไว้ ใบที่ต้องรออนุมัติจะบันทึกไม่ได้ ขึ้น "เกินวงเงินเครดิตลูกค้า"
  - ลูกค้าที่ติ๊ก "แจ้งเตือนเมื่อเกินวงเงินสินเชื่อ" ไว้ ใบสั่งที่เกินวงเงินบันทึกไม่ได้ ขึ้น "เกินวงเงินเครดิต ไม่สามารถบันทึกเอกสารได้"
- ข้อจำกัด
  - ตัวเลือก "ใช้ระบบขออนุมัติวงเงินเครดิต" แบบส่งคำขอ ยังไม่รองรับในรุ่นนี้ เปิดไว้แล้วบิลที่เกินวงเงินจะบันทึกไม่ได้เลย (ไม่ถามรหัสผู้อนุมัติ) ส่งต่อเจ้าหน้าที่
  - ใบสั่งที่ถูกพักรออนุมัติวงเงิน รุ่นปัจจุบันยังไม่มีจอให้กดอนุมัติวงเงิน ส่งต่อเจ้าหน้าที่
