# ใบวางบิล / ใบรับวางบิล

## ความหมายแบบบ้านๆ
- **ใบวางบิล (ลูกหนี้)** = ร้านรวบรวมบิลที่ลูกค้าค้าง ส่งให้ลูกค้าดูว่า "ครบกำหนดจ่ายเท่านี้นะ" ยังไม่ได้รับเงิน
- **ใบรับวางบิล (เจ้าหนี้)** = ผู้ขายมาวางบิลกับเรา เราบันทึกไว้ว่ารับบิลอะไรมาแล้วบ้าง รอจ่าย

## ตัวอย่าง
ทุกวันที่ 25 ร้านเอรวม 5 บิลของบริษัทบี ทำใบวางบิลใบเดียวส่งไป
พอบริษัทบีโอนเงินมา ร้านเอเปิดรับชำระหนี้โดยอ้างอิงใบวางบิลใบนั้น

## ในระบบ BC อยู่ตรงไหน
- ลูกหนี้ › ใบวางบิล (ลูกหนี้)
- เจ้าหนี้ › ใบรับวางบิล (เจ้าหนี้)
- ตั้งเงื่อนไขการวางบิลของลูกค้าที่ เริ่มต้น › ตั้งค่าระบบลูกหนี้ › กำหนดเงื่อนไขการวางบิล

## ระบบทำอะไรให้อัตโนมัติ
- ใบวางบิลไม่ตัดหนี้ ไม่ลงบัญชี ยอดค้างยังอยู่จนกว่าจะรับ/จ่ายชำระ
- ตัวเลือก (ใน กำหนดข้อเลือกพิเศษต่างๆ) ที่เกี่ยวข้อง
  - "ห้ามวางบิลขายซ้ำ" / "ห้ามรับวางบิลซ้ำ" กันบิลเดิมถูกวางสองครั้ง ขึ้น "ห้ามวางบิลซ้ำ : ..." หรือ "ห้ามรับวางบิลซ้ำ : ..."
  - "ไม่แสดงเอกสารที่วางบิลไปแล้ว" ตอนเลือกบิลมาวาง จะซ่อนบิลที่วางแล้ว
  - "รับชำระหนี้อ้างอิงวางบิลทุกครั้ง" / "จ่ายชำระหนี้อ้างอิงวางบิลทุกครั้ง" ถ้ารับเงินโดยไม่อ้างใบวางบิล ขึ้น "... ต้องอ้างอิงใบวางบิล" หรือ "... ต้องอ้างอิงใบรับวางบิล"
