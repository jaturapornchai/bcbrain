## 3. Column Drill-Down Specification (`report_drilldown.go`)

`InferReportDrillEntity` จำแนกคอลัมน์ในผลลัพธ์รายงานอัตโนมัติ (doc, ref, customer, supplier, party, item, account, passbook, employee, warehouse, shelf, unit, asset, department, project, branch, side, allocate, item_group) เพื่อส่งให้ Frontend และ API เปิดหน้าจอต้นทางได้ตรงบริบท:
- ถ้าชื่อรายงานเกี่ยวกับซื้อ/เจ้าหนี้ (`_po_`, `_ap_`, `purchase`, `supplier`, `vat_buy`, `wht_report_in`) คอลัมน์คู่ค้ารวม (`party`) จะเปิดเจ้าหนี้ก่อน (`party_ap_first`)
- ถ้าชื่อรายงานเกี่ยวกับขาย/ลูกหนี้ (`_so_`, `_ar_`, `sale`, `customer`, `vat_sale`) คอลัมน์คู่ค้ารวมจะเปิดลูกหนี้ก่อน (`party_ar_first`)
- คอลัมน์คำว่า `ประเภท` ทุกชนิดจะถูกยกเว้นไม่ทำเป็น Drill-Down Master (`report_drilldown.go:118-120`)
