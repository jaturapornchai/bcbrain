# กำหนดรหัสจังหวัด / อำเภอ / ตำบล (เมนู 1015)

จอเดียวจัดการข้อมูลที่อยู่ไทย 3 ชั้น (จังหวัด > อำเภอ/เขต > ตำบล/แขวง + รหัสไปรษณีย์ + พิกัด) ที่ตาราง `erp_province`, `erp_amper`, `erp_tambon` ซึ่งช่องที่อยู่ของลูกค้า/เจ้าหนี้ใช้เป็นตัวเลือก (จอรายละเอียดลูกหนี้อ่านชื่อจาก `erp_province`/`erp_tambon` ที่ `CustomerDetailScreen.tsx:377,387` และเปิดตัวเลือกที่ `:1522,1611`; จอรายละเอียดเจ้าหนี้ที่ `SupplierDetailScreen.tsx:345,355,1555,1613`; ดู [[scr-customer-detail]] และ [[scr-supplier]]) มีปุ่ม **ดึงจังหวัดอัตโนมัติ** นำเข้าข้อมูลมาตรฐานทั้งประเทศ ตรรกะฝั่ง Go ดู [[proc-province-load]]

## วิธีเปิด
เริ่มต้น > ตั้งค่าองค์กร พนักงาน และเอกสาร > **กำหนดรหัสจังหวัด / อำเภอ / ตำบล** 1015 (`menu_setup_province`, `bcMenu.json:219`) ไม่จำกัดเฉพาะผู้ดูแลระบบ อีก 4 คีย์เมนูเปิดจอเดียวกัน (เป็น alias ที่ชี้มาที่ `menu_setup_province` ตาม `bcMenu.ts:243-246`): `menu_setup_province_auto`, `menu_province_auto`, `menu_setup_ampher`, `menu_setup_tambon` (`screenRegistry.tsx:1002-1010` วนลงทะเบียนด้วย `buildProvinceTreeEntry` `:987-1000`) กลไกเมนูดู [[fe-screen-registry-menu]] ค่ารหัสเมนูที่ส่งเข้าจอมาจาก `getMenuCodeByName("menu_setup_province", ...)` (`:994`)

## โครงจอ
- ซ้าย: **ผังโครงสร้าง** จังหวัด / อำเภอ / ตำบล แบบต้นไม้กางได้ โหลดทั้ง 3 ตารางครั้งเดียวด้วย `queryBatch` (เรียงตามรหัส, `:212-233`) กล่องค้นหา "ค้นหารหัส / ชื่อจังหวัด / อำเภอ / ตำบล / รหัสไปรษณีย์..." (`:1004`) กรองต้นไม้ในเครื่องและกางสายที่ตรงให้เอง (`:352-407` ตรงกับรหัส/ชื่อไทย/ชื่ออังกฤษ ของจังหวัด อำเภอ ตำบล และรหัสไปรษณีย์ของตำบล) ปุ่ม **กางจังหวัด** (กางดูอำเภอของทุกจังหวัด), **ขยายทั้งหมด** (กางทุกจังหวัดและทุกอำเภอ), **ยุบทั้งหมด** และปุ่มโหลดข้อมูลใหม่ (`:1036-1068`) และปุ่ม **ดึงจังหวัดอัตโนมัติ** (`:984-993`) ถ้าฐานว่างมีปุ่ม "ดึงรายชื่อ 77 จังหวัดมาตรฐานอัตโนมัติ" (`:1088-1102`)
- ขวา: ฟอร์ม 1 ใบสลับ 3 ระดับด้วยแท็บ "1. จังหวัด", "2. อำเภอ/เขต", "3. ตำบล/แขวง" (`:1486-1538`) บวกปุ่มลัด **เพิ่มจังหวัด**, **เพิ่มอำเภอในจังหวัดนี้**, **เพิ่มตำบลในอำเภอนี้** (`:1545-1582` ล็อกจังหวัด/อำเภอแม่ไว้ให้) ใต้ฟอร์มเป็นตารางลูก: เลือกจังหวัดจะเห็นตารางอำเภอ (รหัสอำเภอ, ชื่ออำเภอ/เขต (ไทย), ชื่อภาษาอังกฤษ, พิกัด GPS, จำนวนตำบล `:1830-1836`) เลือกอำเภอจะเห็นตารางตำบล (`:1899-1907`)
- ปุ่มแถบเครื่องมือ (`:1380-1432`): **เพิ่มใหม่**, **แก้ไข**, **ลบ**, **ปิดหน้าจอ** (โหมดดู); **บันทึก**, **ปิดหน้าจอ** (โหมดแก้ = ยกเลิกการแก้ `handleCancel`, tooltip "ยกเลิกการแก้ไข") ตามสิทธิ์ ดู [[proc-permission-rights]]
- คีย์ลัดมีแค่ **Ctrl+S** (หรือ Cmd+S) บันทึก (`:882-892`) ไม่มี Esc; ผู้ใช้กดคลิกโหนดอื่นหรือปุ่มเพิ่มขณะมีการแก้ค้าง ระบบถาม "มีข้อมูลค้างบันทึก ... ละทิ้งการแก้ไข / กลับไปบันทึก" (`guardedRun`, `:508-520`) ส่วนปิดหน้าจอขณะมีการแก้ค้างถามแยกอีกชุด "ปิดหน้าจอ / ทำงานต่อ" (`handleClose`, `:641-653`)

## ดึงจังหวัดอัตโนมัติ (นำเข้าข้อมูลมาตรฐาน)
กดปุ่มแล้วเปิดหน้าต่างรายการจังหวัดมาตรฐานจาก `POST /api/process/workflow/province-list` (ได้รหัส ชื่อ พิกัด `:895-910`; Go ใช้สิทธิ์อ่าน `permission.go:36`) ติ๊กเลือกไว้ครบทุกจังหวัดเป็นค่าเริ่มต้น (`:905`) มีช่องกรองชื่อ ปุ่มเลือกทั้งหมด / ยกเลิกทั้งหมด แล้วกด **นำเข้าข้อมูล (n จังหวัด)** (`:2086`) ส่งรหัสที่ติ๊กไป `POST /api/process/workflow/province-load` (`:912-943`) ข้อความบนหน้าต่างระบุว่าข้อมูลมาตรฐานมี 77 จังหวัด · 928 อำเภอ/เขต · 7,436 ตำบล/แขวง พร้อมรหัสไปรษณีย์ (`:1978`) สำเร็จแสดงจำนวนจังหวัด/อำเภอ/ตำบลที่นำเข้าแล้วโหลดต้นไม้ใหม่ เงื่อนไข: ต้องมีสิทธิ์เพิ่มหรือแก้ไข (`rights.readOnly` = ไม่มีสิทธิ์เพิ่มและแก้ไขทั้งคู่ ปุ่มถูกปิดและกดไม่ได้ `:914,987,1098`; ฝั่ง Go ใช้สิทธิ์เขียน `permission.go:51`) และต้องติ๊กอย่างน้อย 1 จังหวัด (`:919-922`)

ฝั่ง Go (`province_load.go:176-209`) รันใน transaction เดียวและล็อกกันสองคนโหลดพร้อมกัน ต่อจังหวัดที่ติ๊ก ลบแถวเดิมตามรหัสแล้วเขียนใหม่ ทีละระดับ (จังหวัด, อำเภอ, ตำบล) ชื่อไทย/อังกฤษมาจากข้อมูลมาตรฐานเสมอ ส่วนพิกัดเดิมที่ไม่เป็น 0 รหัสไปรษณีย์เดิมที่ไม่ว่าง และ `status`/`guid_code` เดิมของแถวจะถูกเก็บไว้ (`province_load.go:145-171`) รายละเอียดที่ [[proc-province-load]]

## บันทึกและลบ
- **บันทึก** (`:668-823`): ตรวจสิทธิ์ (`canSaveWithRights`) → รหัส → ชื่อไทย → (อำเภอ/ตำบล) จังหวัด/อำเภอแม่ → ตอนเพิ่มใหม่ตรวจรหัสซ้ำ: จังหวัดซ้ำที่รหัส, อำเภอซ้ำภายในจังหวัดเดียวกัน, ตำบลซ้ำภายในจังหวัด+อำเภอเดียวกัน (ข้อความ `รหัสอำเภอ "X" ในจังหวัด "Y" มีอยู่ในระบบแล้ว` `:740`) แล้ว INSERT หรือ UPDATE ทีละตาราง ผ่าน `queryExec` (UPDATE แก้ชื่อ ไทย/อังกฤษ พิกัด และรหัสไปรษณีย์ของตำบล) สำเร็จแล้วโหลดต้นไม้ใหม่และเลือกโหนดที่เพิ่งบันทึก
- **ลบ** (`:826-879`): ถามยืนยันโดยบอกขอบเขต: ลบจังหวัด "พร้อมอำเภอและตำบลภายใต้จังหวัดนี้", ลบอำเภอ "พร้อมตำบลภายใต้อำเภอนี้", ลบตำบลเดี่ยว ๆ; จังหวัด/อำเภอลบเป็นชุดคำสั่งเดียวด้วย `queryExecBatch` ซึ่งฝั่ง Go รันในธุรกรรมเดียว ล้มแล้วย้อนทั้งชุด (`service.go:130-171`)

## ข้อควรระวัง
- **ลบแล้วลบต่อเนื่องทั้งสาย โดยไม่ตรวจว่ามีลูกค้า/เจ้าหนี้ใช้รหัสนั้นอยู่หรือไม่** (ไม่มี query ตรวจอ้างอิงในฟังก์ชันลบ `:826-879`) ลูกค้า/เจ้าหนี้ที่เก็บรหัสจังหวัด/ตำบลเดิมไว้จะหาชื่อไม่เจอ ตรวจก่อนลบ
- รหัสอำเภอ/ตำบลซ้ำข้ามจังหวัดได้ ถือรหัสจังหวัดเป็นส่วนของคีย์ ไม่ใช่รหัสเดี่ยว
- ปุ่ม "ดึงจังหวัดอัตโนมัติ" **เปลี่ยนชื่อ** ของแถวที่รหัสตรงกับข้อมูลมาตรฐานกลับเป็นชื่อมาตรฐาน (ที่แก้ชื่อเองไว้จะหาย) แต่พิกัดที่ไม่เป็น 0 และรหัสไปรษณีย์ที่ไม่ว่างที่กรอกไว้จะอยู่ต่อ แถวที่รหัสไม่อยู่ในข้อมูลมาตรฐานไม่ถูกแตะ
- คอมเมนต์ในโค้ดตรงคีย์ลัด (`:881`) เขียนว่า F12 แต่ที่ผูกจริงคือ Ctrl+S (`:885`)
- ไม่มีตาราง tbl- แยกของ 3 ตารางนี้ในคลัง; โครงสร้างอ่านจากคำสั่ง SQL ในไฟล์ (`:212-233`): จังหวัด `code,name_1,name_2,lat,lng`; อำเภอ เพิ่ม `province`; ตำบล เพิ่ม `province,amper,zip_code` (ตาราง Go ยังมี `status`, `guid_code` `province_load.go:152,159,167`)
