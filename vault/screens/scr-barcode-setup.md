# กำหนดบาร์โค้ด / เพิ่มบาร์โค้ดแบบเร็ว / ตรวจ EAN13

สามจอในไฟล์ `BarcodeScreens.tsx` สำหรับบาร์โค้ดของสินค้าในหมวดสินค้า/คลัง กฎ การบันทึก และการสร้างเลขอยู่ที่ Go (`/api/process/barcode/*`, `barcode_handler.go:14-66`; ค้น/ตรวจ/สร้างเลขใช้สิทธิ์อ่าน ส่วน `save` กับ `ean13-apply` ใช้สิทธิ์เขียน = เพิ่มหรือแก้ไข `permission.go:26,40`) ดูตรรกะฝั่งเซิร์ฟเวอร์ที่ [[proc-barcode]] จอตั้งบาร์โค้ดหลักของสินค้าเต็มรูปแบบอยู่ใน [[scr-item-master]] (ส่วนหน่วยนับ & บาร์โค้ด)

## ตารางบาร์โค้ดที่ใช้ร่วม (`BarcodeGrid`, `:140-334`)
- คอลัมน์: บาร์โค้ด (ไม่เกิน 25 ตัวอักษร), หน่วยนับ (เลือกจากหน่วยนับของสินค้านั้น), ราคากลุ่มที่ 1-4 แต่ละกลุ่มแยก "ทั่วไป" กับ "สมาชิก" (ค่าเริ่มต้นแถวใหม่ "0")
- แถวใต้แต่ละบาร์โค้ด (ตัวเลือกของ #n): ปุ่ม **สร้างบาร์โค้ด**, checkbox **ไม่แสดง** (`hiddenText`), **ไม่สะสมแต้ม** (`noPoint`), **ลดล้างสต๊อก** (`isClearance`), ช่วง **จากวันที่ / ถึงวันที่** (ช่วงใช้ราคา) และปุ่ม **ลบ** บรรทัด
- แถวว่างต่อท้ายตาราง = แถวเพิ่มใหม่ (ปรากฏเฉพาะตอนแก้ไข); ตารางว่างขึ้น "ยังไม่มีบาร์โค้ด"
- แถบล่าง: ปุ่มสร้างบาร์โค้ดสำหรับแถวสุดท้าย และช่อง **เลขนำหน้า** (First Digit, เฉพาะตัวเลข ไม่เกิน 11 หลัก ค่าเริ่มต้น 2) พร้อมคำอธิบาย "(ว่าง = สุ่มทั้งหมด, 2 = บาร์โค้ดใช้ภายในร้าน)"
- สร้างบาร์โค้ด (`genBarcode`, `:160-170`): `POST /api/process/barcode/ean13-generate` ด้วย `{prefix, barcodes}` Go เติมเลขนำหน้าด้วยเลขสุ่มให้ครบ 12 หลักแล้วต่อหลักตรวจสอบ และเลือกเลขที่ไม่ซ้ำกับบาร์โค้ดใด ๆ ในฐานข้อมูล ลองสูงสุด 1,000 ครั้ง (`barcode.go:417-424`, `:472-507`) เลขนำหน้าต้องเป็นตัวเลข 0-11 หลัก (`barcode.go:468`) ถ้าเลขที่ได้ซ้ำกับแถวอื่นในตารางเดียวกันจะไม่ใส่ให้เงียบ ๆ (`:168`) ผิดพลาดแสดงข้อความใต้ปุ่ม ปุ่มล่างชื่อ "+ สร้างบาร์โค้ด 13 หลัก (แถวล่าสุด)" (`:323`) ในจอนี้มีแต่ปุ่ม ไม่มีคีย์ลัดสร้างบาร์โค้ด ช่องบาร์โค้ดในตารางพิมพ์ได้ไม่เกิน 25 ตัว (`maxLength`, `:227`) แต่ Go รับได้ถึง 50 (`barcode.go:225`)

## 2009 กำหนดบาร์โค้ดสินค้า (`BarcodeSetupScreen`, `:371-561`)
- ซ้าย: รายการสินค้า (รหัส, ชื่อ, หน่วย) ค้นได้ทั้งจากรหัส/ชื่อ และ **จากบาร์โค้ด** (ค้นด้วย `exists (select 1 from ic_inventory_barcode ...)` ต้องตรงทั้งค่าแต่ไม่สนตัวพิมพ์ เชื่อมกับเงื่อนไขรหัส/ชื่อด้วย `or` `:390-398`) ดับเบิลคลิกแถวเพื่อเลือกสินค้าและเข้าโหมดแก้ไขทันที (`:484`; ต้องมีสิทธิ์แก้ไข `BcDataList.tsx:146`) ดูกลไกที่ [[scr-data-list-and-lookup]]
- ขวา: "ข้อมูลสินค้า" อ่านอย่างเดียว (รหัส, ชื่อ, หน่วยนับมาตรฐาน, ประเภทหน่วยนับ "หน่วยนับเดียว"/"หลายหน่วยนับ") แล้วตารางบาร์โค้ด ไม่เลือกสินค้าแสดง "เลือกสินค้าจากรายการด้านซ้าย"
- ปุ่ม: โหมดดู = **แก้ไข**, **ลบ** (ลบบาร์โค้ด *ทั้งหมด* ของสินค้า ถามยืนยัน สำเร็จ `ลบบาร์โค้ดทั้งหมดของ <รหัส> แล้ว`, ปิดเมื่อไม่มีบาร์โค้ดหรือไม่มีสิทธิ์ลบ), **ปิดหน้าจอ**; โหมดแก้ = **บันทึก** (กดได้เมื่อมีการเปลี่ยนแปลง), **ปิดหน้าจอ** (ยกเลิกการแก้ คืนค่าเดิม) คีย์ลัด **Ctrl+S** / **Esc** ผ่าน `useShortcuts` (`:112-134`, ใช้งานที่ `:454`)
- บันทึก: ต้องมีสิทธิ์แก้ไข ส่ง `POST /api/process/barcode/save` ด้วย `{itemCode, barcodes}` แล้วโหลดสินค้านั้นใหม่; ลบส่ง `barcodes: []`
- กฎการบันทึกอยู่ที่ Go `SaveBarcodes` (`barcode.go:252-336`): ข้ามแถวที่บาร์โค้ดว่าง; บาร์โค้ดยาวเกิน 50 ตัวหรือซ้ำกันเองในตาราง (ไม่สนตัวพิมพ์) ขึ้น "บาร์โค้ดซ้ำ: X"; ถ้ามีสินค้าอื่นใช้บาร์โค้ดนั้นอยู่แล้วขึ้น "บาร์โค้ด X ถูกใช้แล้วกับสินค้า Y" (`:217-247`, `:289-303`); ราคาที่ว่างถือเป็น 0 และที่ไม่ใช่ตัวเลขขึ้น "ตัวเลขไม่ถูกต้อง (price): X" (`normDecimal`, `barcode.go:110-119`); คำอธิบายที่ว่างจะใช้ชื่อสินค้าแทน (`:309-312`)
- บันทึกคือ **แทนที่ทั้งชุด**: ลบทุกบรรทัดบาร์โค้ดของสินค้านั้นแล้วใส่ตามตาราง ในธุรกรรมเดียว (`barcode.go:305-325`) จึงล้างบาร์โค้ดทั้งหมดได้ด้วยการส่งชุดว่าง (ปุ่ม ลบ ใช้วิธีนี้) ข้อความผิดพลาดแสดงตามที่เซิร์ฟเวอร์ส่ง

## 2010 เพิ่มบาร์โค๊ดสินค้าแบบเร็ว (`BarcodeFastAddScreen`, `:563-784`)
ออกแบบให้ยิงบาร์โค้ดเครื่องสแกนซ้ำๆ เพื่อเพิ่มบาร์โค้ดให้สินค้าทีละตัว
1. ช่อง **บาร์โค้ด/รหัสสินค้า** ("ยิงบาร์โค้ดแล้วกด Enter") ค้นด้วย Enter หรือปุ่มค้นหา เรียก `POST /api/process/barcode/item` ได้ผล 3 แบบ: พบ (`found`) แสดงชื่อ/หน่วยมาตรฐาน/Shelf List และตารางบาร์โค้ดของสินค้า, ไม่พบ ขึ้น "ไม่พบสินค้า/บาร์โค้ดนี้" พร้อมปุ่ม **เพิ่มสินค้าใหม่** (`:754`) เปิดจอข้อมูลสินค้า 2001 (`openScreen("menu_ic_item_detail")` [[scr-item-master]]), บันทึกแล้ว ขึ้น "บันทึกเรียบร้อย ยิงบาร์โค้ดถัดไปได้เลย" (`:758`) และล้างข้อมูลสินค้า (พื้นเขียว) แต่ค้างคลัง/ที่เก็บ/Update Shelf ที่เลือกไว้ (`:647-650`)
   - Go หาด้วยรหัสสินค้าก่อน ถ้าไม่พบจึงหาจากบาร์โค้ด (`barcode.go:136-152`)
2. ตั้ง **คลัง/ที่เก็บ เริ่มต้น**: เลือกคลัง (กรองตามสิทธิ์คลัง/ที่เก็บของผู้ใช้ผ่าน `getWhPermFilter` ดู [[proc-wh-shelf-permission]]) แล้วเลือกที่เก็บ ค่าที่เลือกถูกส่งไปพร้อมการบันทึก (`whCode`, `locationCode`, `shelf`) ช่อง **Update Shelf** (ตัวพิมพ์ใหญ่ ไม่เกิน 50 ตัว `:724-725`) ถ้ากรอกแล้วไม่เลือกคลัง/ที่เก็บ Go ปฏิเสธ "ระบุ Update Shelf แล้ว ต้องเลือกคลัง/ที่เก็บเริ่มต้นก่อน" (`barcode.go:263-266`) ถ้าผ่านจะเพิ่มค่าชั้นนั้นต่อท้าย `shelf_list` ของแถวคลัง/ที่เก็บใน [[tbl-ic-wh-shelf]] ครั้งเดียว (`appendShelf`, `:340-370`)
3. ติ๊ก "หลังค้นหาให้ไปที่ตารางบาร์โค้ด (Barcode Auto Focus)" เพื่อให้เคอร์เซอร์ลงตารางหลังค้นหา มิฉะนั้นกลับไปที่ช่องสแกน
4. กล่องแสดงผลล่าสุด: บาร์โค้ดที่ยิง, รหัสสินค้า, ชื่อสินค้า, หน่วยนับมาตรฐาน, Shelf List และตารางสรุป "หน่วยนับที่ใช้" (หน่วยนับ, ชื่อ, ตัวตั้ง, ตัวหาร) กับ "คลังและที่เก็บ" (คลัง, ชื่อคลัง, ที่เก็บ, Shelf List)
5. **บันทึก** (Ctrl+S ผูกไว้ ไม่มี Esc, `:653`) ปุ่มกดได้เมื่อพบสินค้าและมีสิทธิ์เพิ่ม/แก้ไข (`:696`) ส่ง `barcode/save` พร้อมข้อมูลคลัง/ที่เก็บ (`:640-651`)
- ข้อควรระวัง: หน้าจอนี้เปิดมาอยู่ในโหมดพร้อมแก้ตลอด ไม่มีปุ่ม แก้ไข / ลบ

## 2019 ตรวจสอบบาร์โค้ดตามมาตรฐาน EAN13 (`Ean13CheckerScreen`, `:805-960`)
หาบาร์โค้ดยาว 13 ตัวที่ไม่ผ่านมาตรฐาน (ไม่ใช่ตัวเลขล้วน เป็นเลข 0 ล้วน หรือหลักตรวจสอบผิด `barcode.go:406-414`) แล้วออกเลขใหม่แทน ปุ่ม **นำบาร์โค้ดใหม่ไปใช้แทน** กดได้เมื่อทุกแถวมีบาร์โค้ดใหม่แล้ว (`ready`, `:858`) จอนี้ไม่มีคีย์ลัด Ctrl+S
- เปิดจอแล้วตรวจให้ทันทีเงียบๆ (`check(true)`, `:832-835`) ปุ่ม **เริ่มตรวจสอบ** ตรวจซ้ำ ผลขึ้น `พบบาร์โค้ดผิดมาตรฐาน EAN13 N รายการ` หรือข้อความว่าไม่พบ ผ่าน `POST /api/process/barcode/ean13-check`
- ตารางผล: #, บาร์โค้ด, รหัสสินค้า, รายละเอียด, หน่วยนับ, บาร์โค้ดใหม่ (แถบสถานะ "ผิดมาตรฐาน N รายการ")
- ช่อง "ตัวเลขนำหน้าบาร์โค้ดใหม่" + ปุ่ม **สร้างบาร์โค้ดทดแทนทั้งหมด** (`ean13-generate`) เติมคอลัมน์บาร์โค้ดใหม่
- ปุ่ม **นำบาร์โค้ดใหม่ไปใช้แทน** ถามยืนยัน `เปลี่ยนบาร์โค้ด N รายการเป็นบาร์โค้ดใหม่ ?` แล้วส่ง `POST /api/process/barcode/ean13-apply` สำเร็จขึ้น `เปลี่ยนบาร์โค้ดแล้ว N รายการ`
- หมายเหตุท้ายตาราง: ตรวจเฉพาะบาร์โค้ดยาว 13 ตัวอักษร เลขนำหน้า 2 = บาร์โค้ดใช้ภายในร้าน
- Go ตรวจบาร์โค้ดใหม่ทุกแถว (13 หลักและผ่านมาตรฐาน ไม่ซ้ำกันเอง และยังไม่มีในฐานข้อมูล) แล้วรัน `UPDATE ic_inventory_barcode SET barcode = ใหม่ WHERE barcode = เก่า` ในธุรกรรมเดียว (`barcode.go:531-570`) โค้ดนี้แก้เฉพาะ [[tbl-ic-inventory-barcode]] ไม่แตะแถวส่วนลดตามบาร์โค้ดหรือเอกสารเก่าที่อ้างบาร์โค้ดเดิม
- ปุ่มค้นหา/สร้าง/ตรวจใช้สิทธิ์อ่าน ส่วนนำไปใช้แทนใช้สิทธิ์เขียน (`permission.go:26,40`)
