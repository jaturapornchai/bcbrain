# พิมพ์ป้ายชื่อ/ที่อยู่จัดส่งสินค้า (เมนู 5005 เจ้าหนี้ / 6006 ลูกหนี้)

จอเลือกผู้รับจากทะเบียนที่อยู่จัดส่ง (`ap_ar_transport_label`) เข้าคิว กำหนดจำนวนดวง แล้วดูตัวอย่างป้ายสติ๊กเกอร์ มี 2 เมนูใช้คอมโพเนนต์เดียว ต่างกันที่พารามิเตอร์ `custType`: 5005 = เจ้าหนี้ (`custType={2}`), 6006 = ลูกหนี้ (`custType={1}`) (`screenRegistry.tsx:715-740`) ทะเบียนที่อยู่จัดส่งเองดู [[tbl-ap-ar-transport-label]] ส่วนรายงานที่อยู่จัดส่ง 5004/6005 และการนำเข้า 5006/6007 เป็นเมนูแยก ดู [[scr-universal-report]]

## วิธีเปิด
- เจ้าหนี้ > ทะเบียนเจ้าหนี้ คู่ค้า และที่อยู่จัดส่ง > **พิมพ์ที่อยู่จัดส่งสินค้า** 5005 `menu_ap_transport_label_print` (`bcMenu.json:6112`)
- ลูกหนี้ > ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม > **พิมพ์ที่อยู่จัดส่งสินค้า** 6006 `menu_ar_transport_label_print` (`bcMenu.json:6865`)
- ทั้งสองเมนูไม่จำกัดเฉพาะผู้ดูแลระบบ ชื่อเมนูในเมนูคือ "พิมพ์ที่อยู่จัดส่งสินค้า" ส่วนหัวจอ (แสดงรหัสเมนูกับชื่อจอ `:229-236`) ใช้ข้อความที่ดึงจากชื่อเมนูตามคีย์ในทะเบียนหน้าจอ (`screenRegistry.tsx:722-723,735-736`)
- กลไกเมนูดู [[fe-screen-registry-menu]]

## โครงจอ
- ซ้าย: รายชื่อผู้รับ (รหัสเจ้าหนี้/ลูกหนี้, ชื่อผู้รับ / ร้านค้า, โทรศัพท์ `:163-167`) จาก `ap_ar_transport_label` เรียงรหัส+ลำดับ ดึงสูงสุด 300 แถวต่อครั้ง (`:99-109`) ค้นจากรหัส/ชื่อ/ที่อยู่/โทรศัพท์ (`:85`) กลไกรายการดู [[scr-data-list-and-lookup]]
- ขวาบน: แผงตั้งค่าการพิมพ์ (`:241-317`)
- ขวากลาง: ตารางรายการพิมพ์ (คิว `:320-469`)
- ขวาล่าง: แผงตัวอย่างป้าย เปิด/ปิดได้ (`:472-500`)
- ปุ่มแถบเครื่องมือ (`:192-227`): **แสดงตัวอย่าง** (สลับแผงตัวอย่าง), **พิมพ์**, **ล้างรายการ**, **ปิดหน้าจอ** (มีเมื่อเปิดเป็นแท็บ)

## การเพิ่มเข้าคิว
- **คลิกแถว หรือ ดับเบิลคลิก = เพิ่มเข้าคิวพิมพ์** (`addToQueue`, `:134-147`; ผูกทั้ง `onSelect` และ `onRowDoubleClick` ที่ `:168-169`) ถ้ารายนั้นอยู่ในคิวอยู่แล้ว (รหัสและชื่อตรงกัน) ระบบ **บวกจำนวนดวงอีก 1** แทนการเพิ่มแถวใหม่
- การเลื่อนเลือกแถวแบบอื่นในรายการซ้ายก็เรียก `onSelect` เหมือนกัน (ปุ่มแถวแรก/ก่อนหน้า/ถัดไป/สุดท้าย และคีย์ลูกศร Home End PageUp PageDown ใน `BcDataList.tsx:553-569,615-646`) จึงเพิ่มรายการเข้าคิวหรือบวกจำนวนดวงทุกครั้งที่เลือกเปลี่ยน
- ดับเบิลคลิกจึงบวกได้มากกว่า 1: เบราว์เซอร์ส่งคลิก 2 ครั้ง ตามด้วยดับเบิลคลิก 1 ครั้ง และ `onRowDoubleClick` ส่งต่อให้เฉพาะผู้ที่มีสิทธิ์แก้ไขบนจอนี้ (`BcDataList.tsx:148,1094-1103`) อ่านจากโค้ด ยังไม่ได้ทดสอบในเบราว์เซอร์

## แผงตั้งค่าการพิมพ์
| ช่อง | ตัวเลือก |
|---|---|
| โหมดการพิมพ์ | 0 = พิมพ์ตามแบบฟอร์ม / 1 = พิมพ์สติ๊กเกอร์ต่อเนื่อง (`:243-251`) |
| เครื่องพิมพ์ | ข้อความพิมพ์เอง (ค่าเริ่มต้น "Default Label/A4 Printer" `:53,253-259`) |
| แบบฟอร์ม | FORM-A4-3X8 (A4 24 ดวง) / FORM-A4-2X5 (A4 10 ดวง) / FORM-100X150 (ใบปะหน้า 4x6 นิ้ว) (`:261-272`) |
| กลุ่ม | "-- ทุกกลุ่ม --" หรือกลุ่มเจ้าหนี้/ลูกหนี้ อ่านจาก `ap_group`/`ar_group` สูงสุด 100 กลุ่ม (`:66-80`) กรองรายการซ้ายตาม `group_main` ของ `ap_supplier_detail`/`ar_customer_detail` (`:92-98`) |
| แถวเริ่ม / คอลัมน์เริ่ม | ตัวเลข (ค่าเริ่มต้น 1, 1) ใช้บอกว่าเริ่มวางป้ายที่ช่องไหนของแผ่นสติ๊กเกอร์ แสดงในหัวแผงตัวอย่าง (`:297-316,477`) |

ช่องติ๊ก "พิมพ์กระดาษสติ๊กเกอร์ A4" (ค่าเริ่มต้นติ๊ก) อยู่ในแผงเดียวกัน แต่ค่านี้ไม่ได้ถูกใช้ต่อที่ไหนในไฟล์ (`:55,291`)

## ตารางรายการพิมพ์
คอลัมน์: ลำดับ, รหัสเจ้าหนี้/ลูกหนี้, ชื่อผู้รับ, ที่อยู่จัดส่ง, โทรศัพท์, ขนส่งโดย, จำนวนดวง, จัดการ (`:327-336`) ทุกช่อง **แก้ไขได้ในแถว** (รหัส ชื่อ ที่อยู่ โทรศัพท์ ขนส่ง จำนวนดวง) มีปุ่มเลื่อนแถวขึ้น/ลงและลบแถว (`:425-440`) ปุ่ม **เพิ่มแถว** ที่ท้ายตารางเพิ่มแถวเปล่าให้พิมพ์ที่อยู่เอง (`:448-467`) การแก้ในคิวไม่เขียนกลับตาราง
- เปิดจอครั้งแรก ถ้ารายการซ้ายโหลดได้และคิวว่าง ระบบเติมคิวด้วย **5 แถวแรกของรายการ** ให้เอง (`:121-123`)
- เงื่อนไขเดียวกันนี้ตรวจทุกครั้งที่โหลดรายการ และการโหลดรายการผูกกับจำนวนแถวในคิว (`queue.length` อยู่ในรายการ dependency `:128`, effect `:130-132`) ตามโค้ดจึงเกิดการโหลดรายการซ้ำทุกครั้งที่จำนวนแถวในคิวเปลี่ยน และเมื่อคิวว่างลง (กด **ล้างรายการ** หรือลบแถวสุดท้าย) ระบบจะเติม 5 แถวแรกกลับเข้ามาอีกครั้ง อ่านจากโค้ด ยังไม่ได้ทดสอบในเบราว์เซอร์

## ข้อควรระวัง
- **ปุ่ม "พิมพ์" ยังไม่ได้ส่งงานพิมพ์จริง**: กดแล้วเปิดแผงตัวอย่างและขึ้นข้อความ "สั่งพิมพ์ป้ายชื่อขนส่ง N รายการ เรียบร้อยแล้ว" เท่านั้น (`:203-208`) ไฟล์นี้ไม่มีการเรียก `window.print` หรือ API ใด ๆ ตัวเลือกโหมดพิมพ์/เครื่องพิมพ์ ไม่ถูกใช้ต่อ ส่วนแบบฟอร์มและแถว/คอลัมน์เริ่มปรากฏแค่ในหัวแผงตัวอย่าง ถ้าต้องการป้ายจริงให้ใช้รายงานที่อยู่จัดส่ง 5004/6005 (ชุดรายงานฝั่ง Go อ่านจาก `ap_ar_transport_label` เดียวกัน `report_menu_ap_ar.go:969-983` ดู [[tbl-ap-ar-transport-label]])
- ตัวกรองฝั่งเจ้าหนี้ใช้ `COALESCE(ar_ap_type, 0) IN (0, 2)` ฝั่งลูกหนี้ใช้ `COALESCE(ar_ap_type, 1) = 1` (`:86-89`) ส่วนรายงานฝั่ง Go กรองแค่ชนิด 0 (เจ้าหนี้) และ 1 (ลูกหนี้) (`report_menu_ap_ar.go:950,980`) และ [[tbl-ap-ar-transport-label]] ระบุแค่สองชนิดนี้ จึงไม่เห็นที่มาของค่า 2 ในโค้ดที่อ่าน
- ตัวอย่างป้ายแสดงรหัส ชื่อ ที่อยู่ โทรศัพท์ ขนส่ง และ "xN ดวง" เป็นการ์ดสามคอลัมน์ ไม่ใช่ภาพหน้าตาตามแบบฟอร์มพิมพ์จริง (`:480-498`)
- รหัสเมนูที่จอรับเข้ามา (`menuCode`) มาจาก `getMenuCodeByName` ของแต่ละคีย์ในทะเบียนหน้าจอ (`screenRegistry.tsx:722,735`) ซึ่งตามโครงเมนูปัจจุบันคือ 5005 และ 6006 และแสดงเป็นป้ายรหัสที่หัวจอ (`:230-232`)
