# จอบันทึกเอกสารธุรกรรม มุมมองผู้ใช้ (UniversalTransScreen)

จอเดียวที่ใช้บันทึกเอกสารเกือบทุกชนิดของระบบ (ซื้อ ขาย สต็อก ลูกหนี้ เจ้าหนี้ เงินสด/ธนาคาร เช็ค สมุดรายวัน) หน้านี้อธิบายเฉพาะสิ่งที่ผู้ใช้เห็นและกดได้ กลไกภายใน (ตาราง `ic_trans`/`ap_ar_trans`, `transFlag`, API คำนวณยอด) อยู่ที่ [[fe-transaction-screens]] ไม่ซ้ำที่นี่ ส่วนย่อยของจอแยกเป็น [[scr-trans-header-and-tabs]] (หัวเอกสารและแท็บ), [[scr-trans-item-grid]] (ตารางสินค้า), [[scr-multi-unit-pack-summary]] (แถบสรุปหน่วยนับใต้ตารางสินค้า), [[scr-cancel-confirm]] (จอยกเลิก/อนุมัติ) และกล่องช่วยที่เรียกจากตาราง [[scr-modal-serial-lot-stock]], [[scr-modal-price-credit]], [[scr-modal-document-item]]

## วิธีเปิด
เมนูเอกสารทุกเมนูที่ระบบส่งเข้า `UniversalTransScreen` ผ่าน `config.menuKey` (`UniversalTransScreen.tsx:403-410`; รายชื่อเมนูเต็มดู [[fe-transaction-menu-purchase-sale-stock]] และ [[fe-transaction-menu-debt-cashbank]]; เมนูไหนใช้เลย์เอาต์ไหนดู [[screens-overview]]) กลไกเมนูดู [[fe-screen-registry-menu]] ไฟล์ `TransactionEngineScreen.tsx` และ `UniversalTransactionScreen.tsx` เป็นแค่ทางเข้าอีกชื่อของจอเดียวกัน (re-export, `:3-8` และ `:3-9` ของแต่ละไฟล์) เมนูโหมดยกเลิก/อนุมัติจะไม่เปิดจอนี้ แต่เปิด [[scr-cancel-confirm]] แทน (`UniversalTransScreen.tsx:462-485`) มุมขวาของแถบเครื่องมือแสดงรหัสเมนู (ป้ายสีฟ้า) และชื่อเมนูเป็นหัวจอ (`:3182-3189`)

## โครงจอ
แบ่งซ้าย/ขวาด้วยแถบลากได้ (`ResizableSplit`): ความกว้างซ้ายเริ่มต้น 520 พิกเซล ขั้นต่ำ 320 ขวาขั้นต่ำ 600 จำขนาดที่ลากไว้ในเบราว์เซอร์ตามคีย์ `bc_trans_split` (`UniversalTransScreen.tsx:3000-3005`, `ResizableSplit.tsx:19-26,115-124`)

### ซ้าย รายการเอกสาร (`TransDocListPane`)
- ช่วงวันที่ "วันที่ ... ถึง ..." ค่าเริ่มต้น **ย้อนหลัง 3 เดือนถึงวันนี้** (`UniversalTransScreen.tsx:535-540`; ช่องวันที่ `TransDocListPane.tsx:107-112`)
- คอลัมน์: วันที่, เลขที่เอกสาร, รหัสคู่ค้า, ชื่อคู่ค้า, มูลค่า (`TransDocListPane.tsx:78-91`) หัวคอลัมน์คู่ค้าเปลี่ยนตามชนิด: ลูกหนี้ "รหัสลูกหนี้/ชื่อลูกหนี้", เจ้าหนี้ "รหัสเจ้าหนี้/ชื่อเจ้าหนี้", เช็ค "รหัสคู่ค้า/ธนาคาร", สมุดรายวัน "สมุดรายวัน/คำอธิบาย", อื่น ๆ "รหัสคู่ค้า/ชื่อคู่ค้า" (`UniversalTransScreen.tsx:3012-3022`)
- ค้นหา: พิมพ์แล้วกด Enter หรือเปิดโหมดค้นอัตโนมัติ (ค่าเริ่มต้นเปิด, `TransDocListPane.tsx:76,124-128`) ช่องที่ค้นต่างกันตามชนิดเอกสาร (`UniversalTransScreen.tsx:1068-1137`):

| ชนิดเอกสาร | ค้นจาก | ใช้ช่วงวันที่ | กรองสถานะ |
|---|---|---|---|
| ทั่วไป (`ic_trans`, `ap_ar_trans`, `cb_trans`) | เลขที่เอกสาร, รหัสคู่ค้า, หมายเหตุ (`:1133-1136`) | ใช้ | ซ่อนเอกสารที่ยกเลิก (`last_status = 0`) ยกเว้น `cb_trans` (`:1130`) |
| เช็ค (`cb_chq_list`) | เลขที่เช็ค, เลขเอกสารอ้างอิง (`:1075-1076`) | **ไม่ใช้** แม้ช่องวันที่จะอยู่บนจอ | ไม่กรอง |
| สมุดรายวัน (`gl_journal`) | เลขที่, คำอธิบาย (`:1092-1093`) | ใช้ | ไม่กรอง |
| `pp_trans` | เลขที่, รหัสคู่ค้า (`:1109-1110`) | ใช้ | ไม่กรอง |

- **สูงสุด 150 ใบต่อการค้นหา** ทุกชนิด (`LIMIT 150`, `:1089,1106,1124,1175`) หาเอกสารเก่าให้ใช้ช่วงวันที่หรือคำค้น
- คลิกแถว = เปิดดูเอกสาร (`UniversalTransScreen.tsx:3029`), ดับเบิลคลิกแถวหรือคลิกไอคอนดินสอท้ายแถว = เปิดในโหมดแก้ไข (`:3034`; `BcDataList.tsx:1094-1103,1205-1213`) ไอคอนดินสอและดับเบิลคลิกใช้ไม่ได้ถ้าไม่มีสิทธิ์แก้ไข (`BcDataList.tsx:143-148,1217-1218`) ปุ่มและคีย์ของรายการ (Insert/Alt+N เพิ่มใหม่, ↑↓, Home/End, PageUp/PageDown, Ctrl+F) ดู [[scr-data-list-and-lookup]] แต่ **ระหว่างแก้ไขเอกสาร คีย์เหล่านี้ถูกปิด** (`hotkeysActive={listHotkeysActive && !isEditing}`, `UniversalTransScreen.tsx:3036`) และจอที่ถูกซ่อนอยู่หลังแท็บอื่นก็ไม่รับคีย์ (`:543-544`)
- คลิกเอกสารอื่น หรือเพิ่มใหม่ ขณะที่แก้ไขค้างและข้อมูลเปลี่ยนไปจากที่โหลดมา ระบบถามก่อน (ดูกล่องคำถามด้านล่าง; `:2966-2983,3029-3034`)

### ขวา ฟอร์มเอกสาร
1. แถบหัว "หน้าจอบันทึก/แก้ไขข้อมูล" แสดงข้อความสถานะ (สีเขียว; ข้อความเตือนสีเหลืองอำพัน) และป้ายโหมด: **โหมดดูข้อมูล** (เทา) / **เพิ่มรายการใหม่** (เขียว) / **โหมดแก้ไข** (เหลือง) (`:3042-3066`)
2. แถบเครื่องมือ (ด้านล่าง)
3. หัวเอกสาร (`TransTopForm`) ตามด้วยแถวแท็บ ตารางหลัก และแผงล่างที่สรุปยอด ดู [[scr-trans-header-and-tabs]]

## ปุ่มแถบเครื่องมือ
| โหมด | ปุ่ม | เงื่อนไข / ผล |
|---|---|---|
| ดูข้อมูล | **แก้ไข** | ต้องเลือกเอกสารแล้วและมีสิทธิ์แก้ไข เข้าโหมดแก้ไข (`:3073-3081`) |
| ดูข้อมูล | **เพิ่มใหม่** | ต้องมีสิทธิ์เพิ่ม เริ่มเอกสารใหม่: วันที่และเวลาเป็นวันนี้ เลขที่ขอระบบออกเลขอัตโนมัติ (`generateDocNo`, `:1860-1882`) ภาษีเริ่มที่ 7% คลัง/ที่เก็บเริ่มจากที่บันทึกล่าสุดของเอกสารชนิดนั้น (`:1900-1974`; รายละเอียดดู [[fe-transaction-screens]]) |
| ดูข้อมูล | **ลบ** (สีแดง) | ต้องเลือกเอกสารและมีสิทธิ์ลบ ถามยืนยัน "ยืนยันการลบเอกสาร X ?" (`window.confirm`) สำเร็จขึ้น "ลบเอกสาร X เรียบร้อยแล้ว" แล้วโหลดรายการใหม่ (`:2917-2938`) |
| ดูข้อมูล | **Document Flow** | เปิดผังเอกสารต้นทาง/ปลายทางของเอกสารที่เลือก ดู [[scr-modal-document-item]] คลิกเอกสารในผังที่เป็นจอเดียวกันจะเปิดในรายการนี้ (`:4304-4313`) |
| ดูข้อมูล | **พิมพ์ฟอร์ม / เลือกรูปแบบ** | เปิดกล่องพิมพ์ฟอร์ม ดู [[scr-report-print-modal]] ปุ่มนี้ไม่มีเงื่อนไขปิด กดได้แม้ยังไม่เลือกเอกสาร (`:3109-3117`) |
| ดูข้อมูล | **ปิดหน้าจอ** | มีเมื่อจอเปิดเป็นแท็บ (มี `onClose`) ดู [[fe-tabs-workspace]] (`:3118-3123`) |
| แก้ไข/ใหม่ | **บันทึก** | ปิดเมื่อกำลังบันทึกหรือไม่มีสิทธิ์ (เอกสารใหม่ต้องมีสิทธิ์เพิ่ม เอกสารเดิมต้องมีสิทธิ์แก้ไข; `TabsContext.tsx:57-59`, ปุ่ม `UniversalTransScreen.tsx:3127-3135`) |
| แก้ไข/ใหม่ | **พิมพ์ฟอร์ม / เลือกรูปแบบ** | เปิดกล่องพิมพ์โดยไม่ต้องออกจากโหมดแก้ไข ดูหัวข้อ "พิมพ์ระหว่างแก้ไข" ด้านล่าง (`:3136-3145`) |
| แก้ไข (ไม่ใช่ใหม่) | **Document Flow** | เหมือนด้านบน ขึ้นเฉพาะเมื่อไม่ใช่เอกสารใหม่และมีเลขที่เอกสาร (`:3146-3156`) |
| แก้ไข/ใหม่ | **ปิดหน้าจอ** | ชื่อปุ่มชวนสับสน: จริง ๆ คือ **ยกเลิกการแก้ไข** ออกจากโหมดแก้ไข แล้วโหลดเอกสารเดิมกลับมา (เอกสารใหม่ที่ยังไม่ได้เลือกเอกสารใดไว้ = ล้างเลขที่เอกสาร) ถ้าข้อมูลเปลี่ยนแล้วจะถามก่อน (`:3157-3176`) |

คีย์ลัดมีเพียง **Ctrl+S** (หรือ Cmd+S) = บันทึก เมื่ออยู่ในโหมดแก้ไขและแท็บนี้เป็นแท็บที่เห็นอยู่ (`:2985-2995`) ไม่มีการผูกคีย์ F12 แม้คอมเมนต์เหนือโค้ดจะเอ่ยถึง

### พิมพ์ระหว่างแก้ไข
กล่องพิมพ์รับสถานะ "บันทึกแล้ว" เฉพาะตอนอยู่ในโหมดดูข้อมูลของเอกสารที่มีเลขที่ (`isSavedMode`, `UniversalTransScreen.tsx:4323`) และกล่องต้องยืนยันได้ว่าเอกสารนั้นอยู่ในฐานข้อมูลจริง (`GlobalDocFormPrintModal.tsx:2640`) ถ้าใช่ ปุ่ม **สั่งพิมพ์ / บันทึก PDF (จากข้อมูลที่บันทึกแล้ว)** ใช้ได้ (`GlobalDocFormPrintModal.tsx:5130-5139`) ถ้าไม่ใช่ จะเห็นป้าย "ล็อกการพิมพ์จริง (ป้องกันพิมพ์แล้วไม่ Save)" และเมื่อเปิดกล่องจากโหมดแก้ไขจะมีปุ่ม **บันทึกเอกสารเพื่อพิมพ์จริง** เพิ่ม (`:5141-5165`) ปุ่มนี้สั่งบันทึกเอกสารแล้วเปิดกล่องพิมพ์ใหม่ทันทีโดยไม่ถามซ้ำ (ส่ง `onSaveBeforePrint` เฉพาะตอนแก้ไข, `UniversalTransScreen.tsx:4324`; `:2838-2839`) โหมดดูข้อมูลของเอกสารที่ตรวจไม่พบในฐานข้อมูลจึงไม่มีปุ่มบันทึกให้กด

## แท็บใต้หัวเอกสาร
แท็บที่โชว์ขึ้นกับสวิตช์ของเอกสารชนิดนั้น (`TransLayoutConfig` ใน `transLayouts.ts`) ลำดับตามโค้ด (`UniversalTransScreen.tsx:3365-3482`) ของเอกสารที่มีตาราง:
1. **รายการ** (ตารางแบบจำนวนเงิน) หรือ **รายการสินค้า / เอกสาร** (ตารางสินค้า ใบค้างชำระ มัดจำ) ไม่มีในสมุดรายวัน (`:3365-3377`)
2. **รายละเอียดเพิ่มเติม** (`:3391-3403`)
3. **ภาษีมูลค่าเพิ่ม** (เมื่อเอกสารมีแท็บ VAT อย่างเดียว) หรือ **ข้อมูลภาษี (VAT/WHT)** (เมื่อมีหัก ณ ที่จ่ายด้วย) ไม่แสดงเมื่อเป็นเอกสารที่ใช้แท็บภาษีคู่ในข้อ 5 (`:3404-3416`)
4. **การรับ/จ่ายชำระเงิน** เฉพาะเอกสารที่รับ/จ่ายเงินพร้อมกัน (`:3430-3442`)
5. เอกสารลูกหนี้/เจ้าหนี้ flag 19 (เจ้าหนี้) และ 239 (ลูกหนี้) มีแท็บภาษี 2 แท็บ: 19 = "ภาษีหัก ณ. ที่จ่าย" + "ภาษีซื้อ"; 239 = "ภาษีถูกหัก ณ. ที่จ่าย" + "ภาษีขาย" (`AP_AR_TAX_TABS` ใน `JournalTaxTabs.tsx:38-41`, ป้ายชื่อ `:30-35`; แท็บแสดงที่ `UniversalTransScreen.tsx:3443-3456`)
6. **ใช้เงินมัดจำ** เมื่อเอกสารชนิดนั้นหักมัดจำได้ (`:3457-3469`)
7. **การลงบัญชี (GL)** แสดงเมื่อเอกสารชนิดนั้นมีแท็บ GL **และ** รุ่นของระบบมี GL (`editionCaps.hasGl`; รุ่น Starter ไม่มี; `:3470-3482`)

เอกสารที่ไม่มีตาราง (gridMode `none`) ลำดับเป็น **การลงบัญชี (GL)** (ไม่ตรวจรุ่น, `:3378-3390`), ภาษี, **รายละเอียดเพิ่มเติม** (`:3417-3429`), การรับ/จ่ายชำระเงิน, ใช้เงินมัดจำ

สมุดรายวัน (`gl_journal`) มีแท็บภาษีครบ 4 แท็บ ต่อจากแถวแท็บหลัก: "ภาษีถูกหัก ณ. ที่จ่าย", "ภาษีหัก ณ. ที่จ่าย", "ภาษีซื้อ", "ภาษีขาย" (`:3564-3578`)

## ปุ่มพิเศษที่ปลายแถวแท็บ
ปุ่มกลุ่มนี้อยู่ด้านขวาของแถวเดียวกับแท็บ (`UniversalTransScreen.tsx:3483-3563`):
- **ใบตรวจนับสินค้า (flag 76)**: **เรียกรายการสินค้า** ดึงสินค้า (`item_type` เป็น 0 หรือ 2) จากทะเบียนสินค้า **ไม่เกิน 200 รายการเรียงรหัส** มาแทนที่รายการในตารางทั้งหมด ตั้งจำนวน 0 และใช้ต้นทุนเฉลี่ยเป็นราคา แล้วขึ้น "เรียกรายการสินค้า N รายการแล้ว" (ไม่มีสินค้า = "ไม่พบรายการสินค้าในคลัง") และ **อ้างอิงเอกสารขอตรวจนับ** ดึงรายการจากใบขอตรวจนับ ปุ่มทั้งคู่ใช้ได้เฉพาะโหมดแก้ไข (`:3484-3549`) เอกสารชนิดนี้ดู [[doc-stock-count]] และ [[doc-stock-count-request]]
- **ปุ่มเลือกเอกสารอ้างอิง** เฉพาะ flag 87, 89, 91, 99, 101, 103, 250, 252, 254, 260, 262, 264 (`:3550-3563`): flag 99 และ 250 = "เลือกเอกสารเสนอราคา"; flag 87 และ 260 = "เลือกเอกสารสั่งซื้อสินค้า"; ที่เหลือ = "เลือกเอกสารตั้งหนี้อื่นๆ" ใช้ได้เฉพาะโหมดแก้ไข เอกสารที่เกี่ยวข้อง: [[doc-ap-other-debt]], [[doc-ap-other-debit-credit-note]], [[doc-ar-other-debt]], [[doc-ar-other-debit-credit-note]], [[doc-other-income]], [[doc-other-income-adjust]], [[doc-other-expense]], [[doc-other-expense-adjust]] (ชื่อปุ่มสลับตามกลุ่มข้างต้นเป็นสิ่งที่โค้ดเขียน ไม่ได้ตรวจว่าตรงกับเอกสารต้นทางของ flag นั้นทุกตัว)

## กล่องเลือกเอกสารอ้างอิง
หัวกล่อง "เลือกเอกสารอ้างอิงเพื่อดึงรายการสินค้า" ช่องค้น "ค้นหาเลขที่เอกสาร / รหัส-ชื่อคู่ค้า / หมายเหตุ" (ค้นใหม่ทุกครั้งที่พิมพ์) แต่ละแถวแสดงเลขที่ วันที่ คู่ค้า หมายเหตุ ไม่พบ = "ไม่พบเอกสารอ้างอิงในระบบ" (`:4169-4225`)
- รายการที่เสนอ: เอกสาร `ic_trans` ที่ยังไม่ถูกยกเลิก (`last_status = 0`) ตามชุด flag ต้นทางของเมนู **ไม่เกิน 100 ใบ** เรียงใหม่ไปเก่า (`:2242-2277`) ชุด flag ต้นทางที่เมนูไม่ได้กำหนดจะใช้ค่าสำรอง 2, 6, 30, 32, 34, 36, 44, 12, 310 (`:2243-2246`)
- เงื่อนไขกรองเพิ่มขอจากฝั่ง backend ตาม flag ลูกค้า ประเภทภาษี และสิทธิ์ (`getRefDocLookupFilter`, `:2255-2260`) ถ้าโหลดเงื่อนไขไม่ได้ขึ้นข้อความ "โหลดเงื่อนไขเอกสารอ้างอิงไม่สำเร็จ" แล้วไม่เปิดรายการ
- เลือกแถว: ใส่เลขที่/วันที่ลงช่องเอกสารอ้างอิงของหัวเอกสาร แล้วให้ backend (`transGridRefImport`, `query-client.ts:672`) คืนหัวเอกสารและรายการคงเหลือ ตารางถูกล้างแล้วแทนด้วยรายการที่ดึงมา ถ้าเอกสารนั้นไม่มีรายการคงเหลือจะขึ้นข้อความเตือนและเหลือแถวว่าง ส่วนจอที่ backend ไม่ส่งรายการกลับมาจะเก็บแค่เลขที่อ้างอิง ไม่แตะตาราง ดึงไม่สำเร็จขึ้น "ดึงรายการจากเอกสารอ้างอิงไม่สำเร็จ" (`:2367-2414`)

## บันทึกเอกสาร (ลำดับที่ผู้ใช้เจอ)
1. ต้องมี **เลขที่เอกสาร** ("กรุณาระบุเลขที่เอกสาร") และ **วันที่เอกสาร** ("กรุณาระบุวันที่เอกสาร") และต้องโหลดข้อมูลสกุลเงินสำเร็จ ("โหลดข้อมูลสกุลเงินไม่สำเร็จ กรุณาลองใหม่") มิฉะนั้นขึ้นข้อความแล้วหยุด (`:2584-2600`, ข้อความ `:152`) เลขที่ถูกตัดช่องว่างและแปลงเป็นตัวพิมพ์ใหญ่ก่อนส่ง (`:2586`)
2. เอกสาร `cb_trans` บันทึกจากจอนี้ไม่ได้ ขึ้น "ยังไม่รองรับการบันทึกเอกสาร cb_trans" (`:2656-2658`)
3. เฉพาะเอกสารกลุ่มสินค้า/ซื้อ/ขาย/สต็อก (`ic_trans`, ไม่ใช่เช็ค สมุดรายวัน ลูกหนี้-เจ้าหนี้) ถ้า backend ถามยืนยัน (ข้อความขึ้นต้น `CONFIRM:` เช่น เครดิตเกิน) จะเด้งกล่องยืนยัน กด Cancel = ยกเลิกการบันทึกเงียบ ๆ; ถ้าข้อความขึ้นต้น `CREDIT_PASSWORD:` เปิดกล่องอนุมัติเครดิตให้ผู้มีสิทธิ์ใส่ผู้ใช้และรหัสอนุมัติ ดู [[scr-modal-price-credit]] แล้วลองบันทึกซ้ำ (`:2713-2821`, กล่อง `:4302`)
4. สำเร็จ: ขึ้น "บันทึกเอกสาร X เรียบร้อยแล้ว" ออกจากโหมดแก้ไข รีโหลดรายการ และเด้งกล่อง **"บันทึกเอกสารเรียบร้อยแล้ว"** ถามพิมพ์ (ปุ่ม **พิมพ์แบบฟอร์ม** / **ยังไม่พิมพ์**; `:4356-4368`) ถ้าบันทึกจากปุ่ม "บันทึกเอกสารเพื่อพิมพ์จริง" ในกล่องพิมพ์ จะเปิดกล่องพิมพ์เลยโดยไม่ถาม (`:2830-2842`)
5. ล้มเหลว: แสดงข้อความ error จาก backend ในแถบหัว (หรือ "บันทึกเอกสารไม่สำเร็จ") และค้างโหมดแก้ไขไว้ (`:2843-2847`)
6. ระบบจำคลัง/ที่เก็บล่าสุดที่บันทึกของ flag นั้นไว้ในเบราว์เซอร์ (`ictrans_recent_<flag>`) ใช้เป็นค่าเริ่มของเอกสารใหม่ (เขียน `:2824`, อ่านกลับ `:1953`) เก็บเมื่อบันทึกเอกสารกลุ่ม `ic_trans` สำเร็จเท่านั้น

การลบ: เอกสาร `cb_trans` ลบไม่ได้จากจอนี้ ขึ้น "ยังไม่รองรับการลบเอกสาร cb_trans" (`:2902-2906`) ตัวจัดการลบรองรับหลายใบในคราวเดียว แต่ปุ่ม **ลบ** บนแถบเครื่องมือส่งเฉพาะเอกสารที่เปิดอยู่ (`:2917-2926,3095`)

## ข้อควรระวัง
- ปุ่ม **ปิดหน้าจอ** ในโหมดแก้ไขคือยกเลิกการแก้ ไม่ใช่ปิดแท็บ (`:3157-3176`)
- เอกสารทั่วไปที่ยกเลิกแล้วจะหายจากรายการซ้าย (กรอง `last_status = 0`) ต้องเปิดผ่านจอยกเลิกหรือผังเอกสารถ้าจะดูย้อนหลัง ส่วนเช็ค สมุดรายวัน และ `pp_trans` ไม่ถูกกรองด้วยสถานะ (`:1130`)
- รายการซ้ายตัดที่ 150 ใบ: ค้นไม่เจออาจเป็นเพราะเกินจำนวน ไม่ใช่ไม่มีเอกสาร และรายการอ้างอิงตัดที่ 100 ใบ
- ช่องวันที่บนจอเอกสารเช็คไม่มีผลกับการค้น
- ทุกค่าเงินในจอเป็นข้อความทศนิยม ไม่ใช้ตัวเลขไบนารี ดู [[fe-numeric-money]]
- ยังไม่ได้ตรวจเลย์เอาต์ของทุก flag แยกรายตัว (มีกว่า 160 เมนู): สวิตช์แท็บของแต่ละเอกสารอยู่ใน `transLayouts.ts` ดู [[fe-transaction-screens]]
