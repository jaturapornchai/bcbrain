# รหัสรูปแบบเอกสาร `erp_doc_format` สมุดรายวัน 5 เล่ม และการรันเลขที่อัตโนมัติ

ทุกเอกสารใน BC Ai Account ผูกกับตาราง **`erp_doc_format`** ผ่านคอลัมน์ `doc_format_code` เพื่อกำหนดรูปแบบเลขที่เอกสารอัตโนมัติ (`format`), รหัสหน้าจอแม่แบบบัญชี (`screen_code`), สมุดรายวันที่ใช้ลงบัญชี (`gl_book`) และประเภทภาษีเริ่มต้น (`vat_type`) (ดูรหัส `trans_flag` คู่กันที่ [[doc-trans-flag-catalog]] และภาพรวมที่ [[doctypes-overview]])

---

## 1. สมุดรายวันมาตรฐาน 5 เล่ม (`gl_journal_book`)

เมื่อสร้างฐานข้อมูลบริษัทใหม่หรือกดดึงค่าเริ่มต้น (`SeedStandardDocFormatsTx`) ระบบจะสร้างสมุดรายวันมาตรฐาน 5 เล่มในตาราง `gl_journal_book`:

| `code` | `name_1` (ชื่อภาษาไทย) | `name_2` (ชื่อภาษาอังกฤษ) | เอกสารมาตรฐานที่ผูกเข้าสมุดนี้ (`gl_book`) |
|---|---|---|---|
| `01` | สมุดรายวันทั่วไป (GJ) | General Journal | `JV`, `GJ`, เอกสารคลังสินค้า (`IA, IB, IF, IM, IO, IR, IS`), ค่าเสื่อม/ขายสินทรัพย์ (`ASD, ASS`), เงินสดย่อย (`PCD, PRM`), โอนเงิน (`TM`), บัตรเครดิต/Wallet (`CRD, CRN, WLD`), ใบวางบิล/รับ-จ่ายชำระหนี้ (`DD, DE, ED, EE`) และใบยกเลิกส่วนใหญ่ |
| `02` | สมุดรายวันรับเงิน (RV) | Cash Receipts Journal | ฝากเงิน (`DM`), รับเงินล่วงหน้า/มัดจำขาย (`SD, SRV`), รายได้อื่น (`OI`), เช็ครับ (`CHB, CHD, CHP`), ตั้ง/เพิ่ม/ลดหนี้ยกมาลูกหนี้ (`EA, EB, EC`) |
| `03` | สมุดรายวันจ่ายเงิน (PV) | Cash Payments Journal | ถอนเงิน (`WM`), จ่ายเงินล่วงหน้า/มัดจำซื้อ (`PD, PC`), ค่าใช้จ่ายอื่น (`EPO`), เช็คจ่าย (`CPB, CPP, CHC, CPC, CPE`), ตั้ง/เพิ่ม/ลดหนี้ยกมาเจ้าหนี้ (`DA, DB, DC`) |
| `04` | สมุดรายวันขาย (SJ) | Sales Journal | ขายสินค้า/บริการ (`SI`), ขายหน้าร้าน POS (`SIP`), เพิ่มหนี้ขาย (`SA`), ลดหนี้ขาย (`ST`), เสนอราคา/สั่งจอง/สั่งขาย (`SO, SR, SS`), ตั้ง/เพิ่ม/ลดหนี้อื่นลูกหนี้ (`AOB, ADO, ACO, AOC, AIC, ADC`) |
| `05` | สมุดรายวันซื้อ (PJ) | Purchase Journal | ซื้อสินค้า (`PU`), เพิ่มหนี้ซื้อ (`PA`), ลดหนี้ซื้อ (`PT`), เสนอซื้อ/สั่งซื้อ (`PR, PO`), ทะยอยรับ/ตั้งหนี้ (`PI, PIU, CPIC`), ตั้ง/ยกเลิกหนี้อื่นเจ้าหนี้ (`COB, CCO, COC, CIC, CNO`) |

## 2. โครงสร้างตาราง `erp_doc_format` และกติการันเลขที่เอกสาร

คอลัมน์สำคัญใน `erp_doc_format`:
- `code`: รหัสรูปแบบเอกสาร (Primary Key เช่น `SI`, `SIP`, `PU`, `JV`) — บริษัทหนึ่งสร้างหลายรหัสภายใต้หน้าจอเดียวกันได้ เช่น `SI01`, `SI02` โดยชี้ `screen_code = 'SI'`
- `screen_code`: รหัสหน้าจอมาตรฐาน (ตัวชี้ไปยังแม่แบบผังบัญชีใน [[doc-gl-posting-engine]])
- `format`: รูปแบบเลขที่เอกสารอัตโนมัติ
- `gl_book`: รหัสสมุดรายวัน (`01`–`05`)
- `vat_type`: ประเภทภาษีเริ่มต้น (`0`=แยกนอก, `1`=รวมใน, `2`=อัตราศูนย์, `3`=ยกเว้น) — เช่น `SIP` (ขาย POS) กำหนดค่าเริ่มต้นเป็น `vat_type = 1` (รวมใน)

### กติกาแปลสัญลักษณ์ใน `format` (`nextAutoDocNo` ใน `doc_cancel.go`)

| โทเคนใน `format` | ความหมาย | ตัวอย่างผลลัพธ์ (วันที่ `2026-11-13` ค.ศ. / `2569` พ.ศ.) |
|---|---|---|
| `@YY` | ปี 2 หลักสุดท้าย (พ.ศ. หรือ ค.ศ. ตามตั้งค่าปีของบริษัท) | `69` (พ.ศ.) หรือ `26` (ค.ศ.) |
| `@YYYY` | ปี 4 หลักเต็ม | `2569` หรือ `2026` |
| `@MM` | เดือน 2 หลัก (`01`–`12`) | `11` |
| `@DD` | วันที่ 2 หลัก (`01`–`31`) | `13` |
| `####` หรือ `######` | ลำดับรันอัตโนมัติ (จำนวนหลักตามจำนวนเครื่องหมาย `#`) | `SI-6911-0001` หรือ `EE-000001` |

ระบบค้นหาเลขสูงสุดที่มี prefix ตรงกันในตารางปลายทาง (`ic_trans`, `ap_ar_trans`, `as_trans` หรือ `gl_journal`) แล้วบวก `+1` ภายใต้ Transaction เดียวกันเพื่อกันเลขชนกัน

## 3. สรุปรหัส `erp_doc_format` มาตรฐานทั้ง 163 รายการ (จัดตามหมวด)

### 3.1 หมวดจัดซื้อ (Purchase — 32 รหัส)
- **ใบขอซื้อ/ใบสั่งซื้อ**: `PR` (ใบเสนอซื้อ), `PRA` (อนุมัติ PR), `PRC` (ยกเลิก PR), `PO` (ใบสั่งซื้อ), `POA` (อนุมัติ PO), `POC` (ยกเลิก PO)
- **เงินล่วงหน้า/มัดจำจ่าย**: `PD` (จ่ายเงินล่วงหน้า), `PDB` (จ่ายล่วงหน้ายกมา), `PDC` (ยกเลิก PD), `PDR` (รับคืนเงินล่วงหน้า), `PDRC` (ยกเลิก PDR), `PC` (จ่ายเงินมัดจำ), `PCB` (จ่ายมัดจำยกมา), `PCC` (ยกเลิก PC), `PCR` (รับคืนมัดจำ), `PRT` (ยกเลิก PCR)
- **ซื้อปกติ (รูปแบบเริ่มต้น `PU-@YY@MM-####`)**: `PU` (ใบรับสินค้า/ใบกำกับภาษีซื้อ), `PUC` (ยกเลิกซื้อ), `PA` (เพิ่มหนี้ซื้อ), `PAC` (ยกเลิก PA), `PT` (ส่งคืน/ลดหนี้ซื้อ), `PTC` (ยกเลิก PT)
- **ทะยอยรับสินค้าตาม PO (Partial GRN)**: `PI` (รับสินค้าทะยอยรับ), `CPIC` (ยกเลิก PI), `PIA` (ส่งคืนจากการทะยอยรับ), `PIAC` (ยกเลิก PIA), `PIU` (ตั้งหนี้ซื้อจากการรับ), `PIUC` (ยกเลิก PIU), `PID` (เพิ่มหนี้จากใบตั้งหนี้), `PIDC` (ยกเลิก PID), `PIC` (ลดหนี้จากใบตั้งหนี้), `PICC` (ยกเลิก PIC)

### 3.2 หมวดขายและ POS (Sales & POS — 26 รหัส)
- **ก่อนขาย**: `SO` (ใบเสนอราคาขาย), `SOA` (อนุมัติ SO), `SOC` (ยกเลิก SO), `SR` (ใบสั่งจอง), `SRA` (อนุมัติ SR), `SRC` (ยกเลิก SR), `SS` (ใบสั่งขาย), `SSA` (อนุมัติ SS), `SSC` (ยกเลิก SS)
- **เงินล่วงหน้า/มัดจำรับ**: `SD` (รับเงินล่วงหน้า), `SDB` (รับล่วงหน้ายกมา), `SDC` (ยกเลิก SD), `SDR` (คืนเงินรับล่วงหน้า), `SDRC` (ยกเลิก SDR), `SRV` (รับเงินมัดจำ), `SRVB` (รับมัดจำยกมา), `SCR` (ยกเลิก SRV), `SRT` (คืนเงินมัดจำ), `SCT` (ยกเลิก SRT)
- **ขาย/POS/ลดหนี้/เพิ่มหนี้**: `SI` (`SI-@YY@MM-####` ขายสด/เชื่อ), `SIP` (`SIP-@YY@MM-####` ขายหน้าร้าน POS `vat_type=1`), `SIC` (ยกเลิกขาย), `SA` (เพิ่มหนี้ขาย), `SAC` (ยกเลิก SA), `ST` (รับคืน/ลดหนี้ขาย), `STC` (ยกเลิก ST)

### 3.3 หมวดคลังสินค้า (Inventory — 19 รหัส)
- **รับ-เบิก-โอน-ปรับปรุง**: `IB` (ยกมาสต็อก), `IC` (รหัสสินค้าอัตโนมัติ), `IF` / `IFC` (รับสินค้าสำเร็จรูป / ยกเลิก), `RIO` / `CRO` (ขอเบิก / ยกเลิกขอเบิก), `IO` / `IOC` (เบิกวัตถุดิบ / ยกเลิก), `IR` / `IRC` (รับคืนจากการเบิก / ยกเลิก), `RIM` (ขอโอนสินค้า), `IM` / `IMC` (โอนคลัง / ยกเลิก), `RCO` (ขอตรวจนับ), `CO` (ตรวจนับสินค้า), `IA` / `IAC` (ปรับปรุงเพิ่ม / ยกเลิก), `IS` / `ISC` (ปรับปรุงลด / ยกเลิก)

### 3.4 หมวดเจ้าหนี้ (AP — 13 รหัส) และลูกหนี้ (AR — 13 รหัส)
- **เจ้าหนี้ (AP)**: `DA` (ตั้งหนี้ยกมา), `DB` (เพิ่มหนี้ยกมา), `DC` (ลดหนี้ยกมา), `COB` / `COC` (ตั้งหนี้อื่น / ยกเลิก), `CDO` / `CIC` (เพิ่มหนี้อื่น / ยกเลิก), `CCO` / `CNO` (ลดหนี้อื่น / ยกเลิก), `DD` / `DDC` (ใบรับวางบิล / ยกเลิก), `DE` / `DEC` (จ่ายชำระหนี้ / ยกเลิก)
- **ลูกหนี้ (AR)**: `EA` (ตั้งหนี้ยกมา), `EB` (เพิ่มหนี้ยกมา), `EC` (ลดหนี้ยกมา), `AOB` / `AOC` (ตั้งหนี้อื่น / ยกเลิก), `ADO` / `AIC` (เพิ่มหนี้อื่น / ยกเลิก), `ACO` / `ADC` (ลดหนี้อื่น / ยกเลิก), `ED` / `EDCC` (ใบวางบิล / ยกเลิก), `EE` / `EEC` (รับชำระหนี้ / ยกเลิก)

### 3.5 หมวดเงินสด ธนาคาร เงินสดย่อย เช็ค บัตรเครดิต และ Wallet (51 รหัส)
- **รายได้อื่น & ค่าใช้จ่ายอื่น**: `OI` / `OIC`, `ODN` / `ODC`, `OCN` / `OCC`, `EPO` / `EOC`, `EPD` / `EDC`, `EPC` / `ECC`
- **เงินสด ธนาคาร เงินสดย่อย**: `CAB` (ยกมาเงินสด), `BBL` (ยกมาธนาคาร), `DM` / `DMC` (ฝากเงิน / ยกเลิก), `WM` / `WMC` (ถอนเงิน / ยกเลิก), `TM` / `TMC` (โอนระหว่างธนาคาร / ยกเลิก), `PCD` / `PEC` (คืน/ลดวงเงินสดย่อย / ยกเลิก), `PRM` / `PMC` (รับ/เพิ่มวงเงินสดย่อย / ยกเลิก)
- **เช็ครับ (`chq_type = 1`)**: `CQR` (ทะเบียน), `CHB` (ยกมา), `CHD` / `CDC` (นำฝาก / ยกเลิก), `CHP` / `CCP` (เช็คผ่าน / ยกเลิก), `CRT` / `CTC` (เช็คคืน / ยกเลิก), `CRC` / `DCC` (เช็คขาดสิทธิ์ / ยกเลิก), `CDE` / `CED` (เปลี่ยนเช็ค / ยกเลิก), `CND` (คืนเช็คตั้งหนี้ใหม่)
- **เช็คจ่าย (`chq_type = 2`)**: `CQP` (ทะเบียน), `CPB` (ยกมา), `CPP` / `CPC` (เช็คผ่าน / ยกเลิก), `CPR` / `CEC` (เช็คคืน / ยกเลิก), `CHC` / `DPC` (เช็คขาดสิทธิ์ / ยกเลิก), `CPE` / `CEP` (เปลี่ยนเช็คจ่าย / ยกเลิก)
- **บัตรเครดิต & Wallet**: `CCR` (ทะเบียนบัตรเครดิตรับ), `CRD` (ขึ้นเงินบัตรเครดิต), `CRN` (ยกเลิกบัตรเครดิต), `WLD` (ขึ้นเงิน Wallet)

### 3.6 หมวดบัญชีแยกประเภทและสินทรัพย์ถาวร (9 รหัส)
- **บัญชีแยกประเภท (GL)**: `JV` (`JV-@YY@MM-####` ใบสำคัญทั่วไป), `GJ` (สมุดรายวันทั่วไป), `RV` (สมุดรายวันรับ), `PV` (สมุดรายวันจ่าย), `SJ` (สมุดรายวันขาย), `PJ` (สมุดรายวันซื้อ), `AFC` (ใบปันส่วนค่าใช้จ่ายแฝง)
- **สินทรัพย์ถาวร (FA)**: `ASD` (ใบคิดค่าเสื่อมราคาสินทรัพย์ `1801`), `ASS` (ใบขายสินทรัพย์ `1802`)
