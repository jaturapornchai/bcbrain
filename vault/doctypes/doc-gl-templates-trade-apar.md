# แม่แบบคู่บัญชี Dr/Cr อัตโนมัติ หมวดซื้อ ขาย POS เจ้าหนี้ และลูกหนี้

เอกสารนี้สรุปแม่แบบคู่บัญชีเดบิต/เครดิตมาตรฐานจาก `gl_template_defaults.json` ควบคู่กับสูตรคำนวณใน `gl_template_rules.go` สำหรับหมวดซื้อ ขาย/POS เจ้าหนี้ (AP) และลูกหนี้ (AR) (ดูความหมายตัวแปร `&ACC...&` ที่ [[doc-gl-posting-engine]] และชื่อบัญชี TFRS เต็มที่ [[doc-gl-coa-standard]])

---

## 1. ตารางรหัส `action_code` ที่ใช้ร่วมกันในเอกสารซื้อ-ขาย-รับ-จ่าย

| `action_code` | ยอดเงินที่ดึงมาลงบัญชี | หมายเหตุเงื่อนไขสำคัญ |
|---:|---|---|
| `1` / `1001` / `1002` | ยอดสินค้า/บริการก่อน VAT (`total_before_vat` + ยกเว้นภาษี) | แยกผังบัญชีตามตัวสินค้าได้ผ่าน `&ACC1&` (ซื้อ) หรือ `&ACC3&` (ขาย) |
| `2` | ยอดภาษีมูลค่าเพิ่ม (`total_vat_value`) | ลงเฉพาะกรณีใบกำกับภาษีถึงกำหนด (`vat_type = 0` ในทะเบียนภาษี) |
| `23` | ภาษีมูลค่าเพิ่มยังไม่ถึงกำหนด (บริการ ม.78/1) | ซื้อ: `1152-00` / ขาย: `2125-00` (เมื่อยังไม่ออก/รับใบกำกับภาษี) |
| `3` / `4` | ภาษีหัก ณ ที่จ่าย | ฝั่งซื้อ/จ่าย: `act=3` ภ.ง.ด.3 (`2122-01`), `act=4` ภ.ง.ด.53 (`2122-02`)<br>ฝั่งขาย/รับ: `act=3` ภาษีถูกหัก ณ ที่จ่าย (`1153-00`) |
| `5` | เงินสด (`cash_amount`) | ทำงานเฉพาะบิลเงินสด หรือใบรับ/จ่ายชำระหนี้ (`1111-00`) |
| `6` | เช็ครับ / เช็คจ่าย (`chq_amount`) | แตกตามเช็คใน `cb_trans_detail` `doc_type = 2` (`&ACCBANK&` / `&ACCBANK2&`) |
| `7` | เงินโอนธนาคาร (`tranfer_amount`) | แตกตามสมุดเงินฝาก `cb_trans_detail` `doc_type = 1` (`&ACCBANK1&`) |
| `8` | เงินสดย่อย (`petty_cash_amount`) | แตกตามรหัสวงเงินสดย่อย `doc_type = 4` (`&ACC&`) |
| `9` / `10` | บัตรเครดิต (`credit_card_amount + charge`) / รายได้ค่าชาร์จบัตร (`act=10`) | `act=9` เดบิตลูกหนี้บัตรเครดิต `1123-00`, `act=10` เครดิตรายได้ชาร์จบัตร |
| `11` / `12` | ค่าใช้จ่ายอื่น (`doc_type = 11`) / รายได้อื่น (`doc_type = 12`) | แตกตามรหัสค่าใช้จ่าย/รายได้ในแท็บรับ-จ่ายเงิน |
| `13` / `30` | ชำระด้วยแต้มสะสม (`total_point`) / คูปองส่วนลด (`total_coupon`) | เดบิตค่าส่งเสริมการขาย `5260-00` (นิยมใช้ใน POS `SIP` และ `SI`) |
| `14` / `15` | ตัดเงินมัดจำ (`deposit_amount`) / ตัดเงินล่วงหน้า (`advance_amount`) | ล้างบัญชี `1156-00`/`1155-00` (ซื้อ) หรือ `2132-00`/`2131-00` (ขาย) |
| `16` / `17` / `19` / `31` | ส่วนลดรับ / ส่วนลดจ่าย / ส่วนลดชำระเงิน | ซื้อ: Cr `5112-00` / ขาย: Dr `4120-00` |
| `18` | ยอดลูกหนี้การค้า / เจ้าหนี้การค้าสุทธิ (`total_amount`) | ทำงานเฉพาะบิลเงินเชื่อ (`inquiry_type IN (0, 2)`) |
| `90` / `92` / `93` | ปัดเศษอัตโนมัติ (`4240-00`) / เงินขาด (`5290-00`) / เงินเกิน (`4240-00`) | ปรับสมดุลใบสำคัญระดับสตางค์และเงินทอนหน้าร้าน |
| `101` / `103` | ต้นทุนขาย (`Dr 5110-00`) / ตัดสินค้าคงเหลือ (`Cr 1131-00`) | ทำงานเฉพาะเมื่อตั้งค่าวิธีบันทึกบัญชีสต็อกเป็น **Perpetual** |

## 2. หมวดจัดซื้อ (Purchase & Partial GRN Templates)

### 2.1 ซื้อสินค้า/บริการ (`PU` — `trans_flag = 12`, `glRule43`, สมุด `05`)
- **ด้านเดบิต (Dr)**:
  - `act=1, 30`: `&ACC1&, 5111-00` ซื้อสินค้า/ค่าบริการ (หรือ `1131-00` กรณี Perpetual) — ยอดก่อน VAT
  - `act=2`: `1151-00` ภาษีซื้อ (กรณีใบกำกับภาษีปกติ) **หรือ** `act=23`: `1152-00` ภาษีซื้อยังไม่ถึงกำหนด (กรณีบริการเงินเชื่อยังไม่ได้รับใบกำกับภาษี)
  - `act=11`: `&ACC&` ค่าใช้จ่ายอื่น (ถ้ามี)
- **ด้านเครดิต (Cr)**:
  - **กรณีซื้อเชื่อ (`inquiry_type IN (0, 2)`)**: `act=18` → `&ACCAP&, 2111-00` เจ้าหนี้การค้า (ยอดสุทธิหลังหักมัดจำ)
  - **กรณีซื้อสด (`inquiry_type IN (1, 3)`)**: `act=5` เงินสด `1111-00`, `act=6` เช็คจ่าย `&ACCBANK2&` (`2112-00`), `act=7` เงินโอน `&ACCBANK1&`, `act=8` เงินสดย่อย/บัตร, `act=3` ภ.ง.ด.3 `2122-01`, `act=4` ภ.ง.ด.53 `2122-02`
  - **รายการหักทั้งสดและเชื่อ**: `act=14` ตัดเงินมัดจำจ่าย `1156-00`, `act=15` ตัดเงินล่วงหน้า `1155-00`, `act=16, 17, 31` ส่วนลดรับ `5112-00`

### 2.2 ส่งคืน/ลดหนี้ซื้อ (`PT` — `trans_flag = 16`, `glRule44`) และ เพิ่มหนี้ซื้อ (`PA` — `trans_flag = 14`, `glRule45`)
- **`PT` (ลดหนี้ซื้อ)**:
  - **Dr**: `&ACCAP&, 2111-00` เจ้าหนี้การค้า (ถ้าหักหนี้เชื่อ `act=1`) **หรือ** `1111-00` / `&ACCBANK1&` / `&ACCBANK2&` (ถ้ารับเงินสดคืน `act=5..9`)
  - **Cr**: `5111-00` ส่งคืนสินค้า (`act=18, 30`) + Cr `1151-00` ภาษีซื้อ (`act=2`)
- **`PA` (เพิ่มหนี้ซื้อ)**:
  - **Dr**: `&ACC1&, 5111-00` ซื้อสินค้า (`act=1`) + Dr `1151-00` ภาษีซื้อ (`act=2`)
  - **Cr**: `&ACCAP&, 2111-00` เจ้าหนี้การค้า (`act=18`) (หรือช่องทางจ่ายเงินสด)

### 2.3 วงจรทะยอยรับสินค้าตาม PO (`PI` → `PIU` / `PIA` / `PIC` / `PID`)
ออกแบบมาเพื่อคุมบัญชีพัก **"เจ้าหนี้ยังไม่ถึงกำหนดตั้งหนี้ (`2113-00`)"** (GR/IR Clearing Account):

| หน้าจอ | `trans_flag` | เดบิต (Dr) | เครดิต (Cr) |
|---|---:|---|---|
| **`PI`** (ทะยอยรับสินค้า) | `310` | `5111-00` ซื้อสินค้า (`act=1`)<br>`1152-00` ภาษีซื้อยังไม่ถึงกำหนด (`act=2`) | `2113-00` เจ้าหนี้ยังไม่ถึงกำหนดตั้งหนี้ (`act=18`) |
| **`PIA`** (ส่งคืนจากการรับ) | `311` | `2113-00` เจ้าหนี้ยังไม่ถึงกำหนดตั้งหนี้ (`act=18`) | `5111-00` ซื้อสินค้า (`act=1`)<br>`1152-00` ภาษีซื้อยังไม่ถึงกำหนด (`act=2`) |
| **`PIU`** (ตั้งหนี้จากการรับ) | `315` | `2113-00` ล้างเจ้าหนี้ยังไม่ถึงกำหนด (`act=1`)<br>`1151-00` ภาษีซื้อจริง (`act=2`) | `1152-00` ล้างภาษีซื้อยังไม่ถึงกำหนด (`act=9`)<br>`2111-00` เจ้าหนี้การค้า (`act=18`) หรือเงินสด/โอน/หักมัดจำ (`act=5..8, 14, 15`) |
| **`PID`** (เพิ่มหนี้จากใบตั้งหนี้) | `316` | `2113-00` / ซื้อเพิ่ม (`act=1`) + `1151-00` ภาษีซื้อ (`act=2`) | `2111-00` เจ้าหนี้การค้า (`act=18`) + ล้าง `1152-00` (`act=9`) |
| **`PIC`** (ลดหนี้จากใบตั้งหนี้) | `317` | `2111-00` เจ้าหนี้การค้า (`act=18`) + `1152-00` (`act=5`) | `2113-00` / ส่งคืน (`act=1, 30`) + `1151-00` ภาษีซื้อ (`act=2`) |

### 2.4 เงินล่วงหน้าและเงินมัดจำฝั่งซื้อ (`PD`, `PDR`, `PC`, `PCR`)
- **`PD` (`10` จ่ายเงินล่วงหน้า — ไม่มี VAT)**: `Dr 1155-00 เงินจ่ายล่วงหน้า / Cr เงินสด 1111-00, โอน &ACCBANK1&, เช็คจ่าย &ACCBANK2&` (รับคืน `PDR 20` กลับด้าน Dr ↔ Cr)
- **`PC` (`11` จ่ายเงินมัดจำ — มี VAT)**: `Dr 1156-00 เงินมัดจำจ่าย + Dr 1151-00 ภาษีซื้อ / Cr เงินสด, โอน, เช็คจ่าย, หัก ณ ที่จ่าย 2122-01/02` (รับคืน `PCR 25` กลับด้าน Dr ↔ Cr)

## 3. หมวดขายและหน้าร้าน POS (Sales & POS Templates)

### 3.1 ขายสินค้า/บริการ (`SI`) และ ขายหน้าร้าน POS (`SIP`) — `trans_flag = 44`, `glRule55`, สมุด `04`
- **ด้านเดบิต (Dr)**:
  - **ขายเชื่อ (`inquiry_type IN (0, 2)`)**: `act=18` → `&ACCAR&, 1121-00` ลูกหนี้การค้า
  - **ขายสด / POS (`inquiry_type IN (1, 3)`)**: `act=5` เงินสด `1111-00`, `act=6` เช็ครับ `&ACCBANK&` (`1122-00`), `act=7` เงินโอน `&ACCBANK1&`, `act=8` เงินสดย่อย, `act=9` บัตรเครดิต `&ACCBANK&` (`1123-00`), `act=3` ภาษีถูกหัก ณ ที่จ่าย `1153-00`
  - **ส่วนลด/คูปอง/แต้ม/ตัดมัดจำ**: `act=19, 31` ส่วนลดจ่าย `4120-00`, `act=13, 30` แต้มสะสมและคูปอง `5260-00`, `act=14` ตัดเงินมัดจำรับ `2132-00`, `act=15` ตัดเงินรับล่วงหน้า `2131-00`, `act=11` ค่าใช้จ่ายอื่น
  - **กรณี Perpetual**: `act=101` → `Dr &ACC2&, 5110-00 ต้นทุนขายสินค้า`
- **ด้านเครดิต (Cr)**:
  - `act=1` (หรือ `1001`): `&ACC3&, 4110-00` รายได้จากการขายสินค้า/บริการ (ยอดไม่รวม VAT)
  - `act=2`: `2121-00` ภาษีขาย (หรือ `2125-00` ภาษีขายยังไม่ถึงกำหนดเมื่อเป็นบิลบริการเงินเชื่อ ม.78/1)
  - `act=10`: `4110-00` / `4210-00` รายได้ค่าชาร์จบัตรเครดิต, `act=12` รายได้อื่น
  - **กรณี Perpetual**: `act=103` → `Cr &ACC1&, 1131-00 สินค้าคงเหลือ`

### 3.2 รับคืน/ลดหนี้ขาย (`ST` — `trans_flag = 48`, `glRule56`) และ เพิ่มหนี้ขาย (`SA` — `trans_flag = 46`, `glRule57`)
- **`ST` (ลดหนี้ขาย)**:
  - **Dr**: `&ACC1&, 4110-00` (หรือ `4120-00`) รับคืน/ลดหนี้ (`act=1`) + Dr `2121-00` ภาษีขาย (`act=2`)
  - **Cr**: `&ACCAR&, 1121-00` ลูกหนี้การค้า (กรณีหักหนี้เชื่อ `inquiry_type IN (0, 2, 4)`, `act=18`) **หรือ** เงินสด/เช็คจ่าย/เงินโอน (กรณีคืนเงินสด `inquiry_type IN (1, 3, 5)`, `act=5..8`)
- **`SA` (เพิ่มหนี้ขาย)**: โครงสร้างเหมือน `SI` คือ `Dr &ACCAR&, 1121-00 (หรือเงินสด) / Cr &ACC3&, 4110-00 รายได้ + Cr 2121-00 ภาษีขาย`

### 3.3 เงินรับล่วงหน้าและเงินมัดจำรับฝั่งขาย (`SD`, `SDR`, `SRV`, `SRT`)
- **`SD` (`40` รับเงินล่วงหน้า — ไม่มี VAT)**: `Dr เงินสด/โอน/เช็ค/บัตร / Cr 2131-00 เงินรับล่วงหน้า` (คืนเงิน `SDR 42` กลับด้าน Dr ↔ Cr)
- **`SRV` (`110` รับเงินมัดจำ — มี VAT)**: `Dr เงินสด/โอน/เช็ค/บัตร + Dr 1153-00 ภาษีถูกหัก ณ ที่จ่าย / Cr 2132-00 เงินมัดจำรับ + Cr 2121-00 ภาษีขาย` (คืนเงิน `SRT 112` กลับด้าน Dr ↔ Cr)
