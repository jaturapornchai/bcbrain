# ตารางแม่บทรหัส `trans_flag` ครบทุกโมดูล

คอลัมน์ `trans_flag` (`INTEGER`) คือตัวจำแนกชนิดเอกสารหลักของ BC Ai Account (ดูภาพรวมที่ [[doctypes-overview]] และรหัสฟอร์แมตที่ [[doc-formats-and-books]])

### ความหมายคอลัมน์ควบคุมหลัก
- **`trans_type`**: `0` = รายวันทั่วไป/โอนระหว่างธนาคาร, `1` = ฝั่งซื้อ/เจ้าหนี้/เช็คจ่าย, `2` = ฝั่งขาย/ลูกหนี้/การเงินรับ-จ่ายทั่วไป, `3` = คลังสินค้า/บัตรเครดิตรับ
- **`calc_flag`** (ใน `ic_trans` และ `ic_trans_detail`): `+1` = เพิ่มสต็อกเข้าคลัง, `-1` = ตัดสต็อกออกจากคลัง, `0` = ไม่กระทบจำนวนสต็อกคงเหลือ
- **`orig_flag`**: รหัส `trans_flag` ของเอกสารต้นฉบับ (เฉพาะเอกสารใบยกเลิกและใบอนุมัติ ซึ่งอ้างอิงผ่าน `doc_ref = orig_doc_no`)
