# ตัดเงินมัดจำในใบซื้อไม่ได้

**ข้อความที่เห็น:**
- "ยอดมัดจำมากกว่ามูลค่าสุทธิ"
- "ยอดตัดจ่ายมากกว่ายอดคงเหลือ: เอกสาร ... เกินอยู่ ..."
- "ไม่พบเอกสารเงินมัดจำ ... ของ ... (หรือถูกยกเลิกแล้ว)"
- "เลือกเอกสารเงินมัดจำ ... ซ้ำ"
- "ยอดตัดเงินมัดจำต้องมากกว่า 0"
- "กรุณาระบุรหัสเจ้าหนี้ก่อนดึงเอกสารมัดจำ"
- "เอกสารประเภทนี้ไม่มีแท็บใช้เงินมัดจำ"

**เกิดตอน:** กด "ดึงเอกสารมัดจำ" หรือบันทึกใบซื้อที่ใส่รายการในแท็บ "ใช้เงินมัดจำ"

**สาเหตุ:**
- ยอดที่ตัดมัดจำรวมกัน มากกว่ายอดสุทธิของใบซื้อ (กรณีภาษีแยกนอก ระบบเทียบกับยอดรวมภาษีแล้ว)
- ตัดเกินยอดมัดจำที่ยังเหลือ เพราะใบซื้อใบอื่นตัดไปแล้วบางส่วน หรือรับคืนมัดจำไปแล้ว
- ใบมัดจำถูกยกเลิก หรือเป็นของเจ้าหนี้คนละราย
- เลือกใบมัดจำใบเดียวกันซ้ำสองบรรทัด
- ใส่ยอดตัดเป็น 0 หรือติดลบ
- ยังไม่เลือกรหัสเจ้าหนี้ที่หัวเอกสาร

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เลือกรหัสเจ้าหนี้ที่หัวเอกสารก่อน แล้วค่อยเลือกใบมัดจำ
2. แก้ยอดตัดให้ไม่เกินยอดคงเหลือของใบมัดจำ และรวมกันไม่เกินยอดสุทธิของใบซื้อ
3. ลบบรรทัดที่เลือกใบมัดจำซ้ำ หรือบรรทัดที่ยอดเป็น 0
4. ถ้าใบมัดจำถูกยกเลิก ให้คืนสถานะก่อน หรือเลือกใบอื่น ([[howto-buy-cancel-docs]])
5. แท็บนี้ใช้ได้กับใบมัดจำเท่านั้น เงินจ่ายล่วงหน้าตัดในใบซื้อไม่ได้ ([[faq-buy-advance-vs-deposit]])

**ส่งต่อเจ้าหน้าที่เมื่อ:** ยอดคงเหลือของใบมัดจำที่ระบบแจ้ง ไม่ตรงกับที่ลูกค้าคำนวณจากเอกสารจริง
