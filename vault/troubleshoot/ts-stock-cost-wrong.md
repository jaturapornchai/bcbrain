# ต้นทุนสินค้าเพี้ยน (ต้นทุนเป็น 0 ต้นทุนกระโดด กำไรขั้นต้นแปลก)

**ข้อความที่เห็น:** ไม่มีข้อความ ต้นทุนในบิลขาย ใบเบิก หรือรายงานกำไรขั้นต้นดูผิด

**เกิดตอน:** ดูกำไรขั้นต้น ดูบัญชีคุมพิเศษ หรือดูต้นทุนขายในบัญชี

**สาเหตุที่พบบ่อย:**
| สาเหตุ | อธิบาย |
|---|---|
| ปรับปรุงเพิ่มตอนยังไม่มีต้นทุน | ใบปรับปรุงสต็อก (เพิ่ม) ที่มีจำนวน รับเข้าที่ต้นทุนเฉลี่ยตอนนั้น ราคาที่พิมพ์ไม่ถูกใช้ ถ้าสินค้ายังไม่เคยซื้อ ต้นทุนจะเป็น 0 และรายการบัญชีของใบนี้อาจลงตามยอดเงินที่พิมพ์ มูลค่าสินค้าในบัญชีจึงไม่ตรงกับรายงานสินค้า |
| บันทึกบิลซื้อย้อนหลัง | ต้นทุนเฉลี่ยหลังวันนั้นเปลี่ยน ต้นทุนในบิลขายที่บันทึกไปแล้วเปลี่ยนตาม |
| ราคาซื้อหรือหน่วยนับผิด | บิลซื้อใส่ราคาผิด หรือตัวตั้ง/ตัวหารผิด ทำให้ต้นทุนต่อหน่วยกระโดด |
| ต้นทุนแฝง | ประมวลผลเฉลี่ยต้นทุนแฝงแล้ว ต้นทุนสูงขึ้นตามค่าขนส่งที่ปันมา ([[faq-stock-hidden-cost-effect]]) |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิดเมนู สินค้า › สอบถามและวิเคราะห์ข้อมูลสินค้า (บนหน้าจอ) › บัญชีคุมพิเศษ ของสินค้าตัวนั้น ดูว่าต้นทุนเปลี่ยนที่เอกสารใบไหน ([[howto-stock-inquiry-movement]])
2. แก้เอกสารที่ราคา จำนวน หรือหน่วยนับผิด
3. ถ้าเป็นของที่ได้มาแบบไม่ได้ซื้อ (ยอดยกมาตกหล่น) ให้บันทึกยอดยกมาพร้อมมูลค่า หรือในใบปรับปรุงเพิ่มเลือก ประเภทรายการ = 1 (หน้าจอแสดงคำว่า ขายสด) เพื่อใช้มูลค่าตามที่กรอก ([[howto-stock-adjust]], [[howto-stock-opening-balance]])
4. ให้ผู้ดูแลระบบใช้เมนู คำนวณยอดสต๊อกใหม่ กับสินค้าตัวนั้น ([[howto-stock-recalc]])
5. แจ้งผู้ทำบัญชีตรวจต้นทุนขายในบัญชี เพราะการคำนวณใหม่ไม่ลงบัญชีซ้ำให้ ([[faq-stock-gl-posting]])

**ส่งต่อทีมงานเมื่อ:** เอกสารถูกหมดและคำนวณใหม่แล้ว แต่ต้นทุนยังผิด หรือยอดต้นทุนขายในบัญชีไม่ตรงกับรายงานสินค้า

## ข้อควรรู้
- ระบบคิดต้นทุนแบบถัวเฉลี่ยเคลื่อนที่อย่างเดียว ([[faq-stock-cost-method]]) ช่อง ประเภทต้นทุน ในข้อมูลสินค้ามีให้เลือกหลายแบบ ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผลกับการคิดต้นทุน ทุกแบบคิดถัวเฉลี่ยเหมือนกัน แบบ ต้นทุน LOT กำหนดเอง มีผลแค่บังคับกรอกเลข LOT
- เมนูที่ลงท้ายว่า (รวมต้นทุนแฝง) เช่น บัญชีคุมพิเศษ (รวมต้นทุนแฝง) รุ่นปัจจุบันยังไม่ได้คำนวณต้นทุนส่วนนี้ ต้นทุนอาจเป็น 0 หรือเป็นค่าจากโปรแกรมเดิม ให้ใช้เมนูที่ไม่มีคำนี้แทน เพราะต้นทุนปกติรวมต้นทุนแฝงที่ประมวลผลแล้วอยู่แล้ว ([[howto-stock-inquiry-profit]])
