# แนบรูปหรือไฟล์ไม่ได้

**ข้อความที่เห็น:** (อย่างใดอย่างหนึ่ง)
- "...: รองรับไฟล์รูปภาพ (PNG, JPG, WEBP, GIF, BMP) และไฟล์เอกสาร (PDF, XLS, XLSX, CSV, DOC, DOCX, PPT, PPTX, TXT, ZIP) ขนาดไม่เกิน 25 MB ต่อไฟล์"
- "ไฟล์ที่ ... ใหญ่เกิน 25 MB"
- "ไฟล์ที่ ... ไม่รองรับ (รองรับรูปภาพ PNG, JPG, WEBP, GIF, BMP และไฟล์เอกสาร PDF, XLS, XLSX, CSV, DOC, DOCX, PPT, PPTX, TXT, ZIP)"
- "ไฟล์ที่ ... อ่านไม่ได้" หรือ "อ่านไฟล์ไม่ได้"
- "สินค้านี้ยังไม่พร้อมแก้ไข จึงแนบรูปไม่ได้"
- "มีรูปที่ยังไม่บันทึก กรุณาบันทึกหรือยกเลิกก่อนเปลี่ยนเอกสาร"

**เกิดตอน:** กด "เลือกรูป / ไฟล์แนบ" หรือกด "บันทึก" ในหน้าจอแนบรูปภาพและไฟล์แนบ

**สาเหตุ:**
- ไฟล์ใหญ่กว่า 25 MB ต่อไฟล์
- ชนิดไฟล์ไม่อยู่ในรายการที่รองรับ เช่น RAR, 7Z, HEIC, ไฟล์วิดีโอ
- ไฟล์เสียหรือเปิดค้างอยู่ในโปรแกรมอื่นจนเบราว์เซอร์อ่านไม่ได้
- รูปสินค้า: สินค้านั้นยังไม่ได้เปิดให้แก้ไขรายละเอียดประกอบ (ช่อง "แก้ไขรายละเอียดประกอบ" ในข้อมูลสินค้า)
- เลือกรูปไว้แล้วยังไม่กดบันทึก แต่จะเปลี่ยนไปเอกสารอื่น

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ไฟล์ใหญ่เกิน: ลดขนาดรูป (ถ่ายใหม่ความละเอียดต่ำลง หรือย่อรูป) หรือแบ่ง PDF เป็นหลายไฟล์ แล้วแนบใหม่
2. ชนิดไฟล์ไม่รองรับ: แปลงเป็น JPG หรือ PDF หรือบีบอัดเป็น ZIP แล้วแนบใหม่
3. อ่านไม่ได้: ปิดไฟล์ในโปรแกรมอื่น หรือบันทึกไฟล์ใหม่อีกครั้งแล้วแนบ
4. สินค้ายังไม่พร้อมแก้ไข: ให้ผู้ดูแลข้อมูลสินค้าตรวจช่อง "แก้ไขรายละเอียดประกอบ" ของสินค้านั้นก่อน แล้วกลับมาแนบรูป
5. มีรูปที่ยังไม่บันทึก: กด "บันทึก" ให้เรียบร้อย หรือกดยกเลิกการแก้ไข แล้วค่อยเลือกเอกสารใบอื่น
6. ไม่มีปุ่มแก้ไขเลย ดู [[ts-common-no-permission]]

**ส่งต่อทีมงานเมื่อ:** ไฟล์ถูกชนิดและเล็กกว่า 25 MB แต่บันทึกแล้วยังขึ้นข้อผิดพลาดซ้ำ หรือบันทึกสำเร็จแล้วเปิดดูรูปไม่ขึ้น
