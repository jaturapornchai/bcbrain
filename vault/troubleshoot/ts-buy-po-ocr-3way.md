# แก้ปัญหาใบสั่งซื้อ รับสินค้าเกิน PO งานเทียบเอกสาร 3 ทาง และสัญญาผ่อน

รวมข้อความแจ้งเตือนที่พบในงานจัดซื้อ การดึงใบขอซื้อ/ใบสั่งซื้อ การตรวจบิลด้วยเอกสาร 3 ทาง และการตั้งหนี้งวดสัญญา

## 1. งานเทียบเอกสาร 3 ทาง (3-Way Match: ใบสั่งซื้อ - ใบรับของ - ใบแจ้งหนี้)

เมื่อสแกนหรือนำเข้าบิลผู้ขายมาเทียบกับใบสั่งซื้อ (PO) และใบรับของ ระบบอาจแสดงข้อความแจ้งผลต่างดังนี้:

- **"สินค้ารายการนี้ไม่อยู่ในใบสั่งซื้อ (PO)"** — บรรทัดสินค้าจากบิลผู้ขายจับคู่กับรายการใน PO ไม่ได้ ตรวจสอบรหัสสินค้า ชื่อสินค้า หรือดูว่าผู้ขายส่งของแถม/รายการนอกใบสั่งซื้อมาหรือไม่
- **"จำนวนวางบิลเกินคงเหลือ PO/ใบรับของ (... > ...)"** — จำนวนในบิลผู้ขายมากกว่ายอดที่สั่งซื้อหรือรับของจริงไว้
- **"ราคาต่อหน่วยสูงกว่า PO (... > ... บาท)"** — ราคาที่ผู้ขายเรียกเก็บสูงกว่าราคาที่ตกลงไว้ในใบสั่งซื้อ
- **"ตรวจพบผลต่างจากใบสั่งซื้อ (3-Way Match Variance) กรุณาแก้ไขยอดหรือติ๊กยืนยันอนุมัติผลต่างก่อนตั้งหนี้"** — ระบบตรวจพบความคลาดเคลื่อนด้านรายการ จำนวน หรือราคา หากตรวจสอบแล้วว่าเป็นยอดจริงที่ผู้มีอำนาจยอมรับได้ ให้ติ๊กช่องยืนยันอนุมัติผลต่างก่อนกดตั้งหนี้ หรือแก้ไขตัวเลขให้ตรงกับใบสั่งซื้อและใบรับของ

## 2. ปัญหาดึงรายการจากใบขอซื้อและใบสั่งซื้อ

- **"เอกสาร <เลขที่> ไม่มียอดคงเหลือแล้ว"** — ใบขอซื้อ (PR) หรือใบสั่งซื้อ (PO) ถูกอ้างอิงรับสินค้าครบหมดทั้งใบแล้ว
- **"คำนวณราคาก่อนหักส่วนลด ... ไม่ได้ เพราะลด 100%"** — รายการที่มีส่วนลด 100% ไม่สามารถคำนวณย้อนกลับเป็นราคาเต็มก่อนส่วนลดได้ ให้ตรวจสอบช่องส่วนลดและราคาตั้งต้นใหม่
- **อ้างอิงใบขอซื้อ/ใบสั่งซื้อไม่ขึ้น** — ตรวจว่าบริษัทเปิดข้อเลือก **"อ้างอิงเอกสารสั่งซื้อที่อนุมัติแล้วเท่านั้น"** หรือ **"อ้างอิงเอกสารเสนอซื้อที่อนุมัติแล้วเท่านั้น"** ไว้หรือไม่ หากเปิดไว้ เอกสารต้นทางต้องกดอนุมัติก่อนจึงจะดึงมาทำต่อได้
- **รับสินค้าเกิน PO ไม่ได้** — ปกติระบบห้ามรับสินค้าเกินยอดสั่งซื้อ เว้นแต่บริษัทจะเปิดข้อเลือก **"อนุญาติให้รับสินค้ามากกว่าใบสั่งซื้อได้"** หากต้องการเปิดให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า**

## 3. ปัญหาสัญญาเช่าซื้อ / ผ่อนชำระ (ลูกหนี้-เจ้าหนี้ตามสัญญา)

- **"ไม่สามารถลบสัญญา ... ได้ เนื่องจากงวดที่ N ตั้งหนี้แล้ว (เอกสาร ...) กรุณายกเลิกใบตั้งหนี้ก่อน"** — สัญญามีงวดที่ออกใบตั้งหนี้ไปแล้ว ต้องไปยกเลิกใบตั้งหนี้ของงวดนั้นๆ ก่อนจึงจะลบสัญญาได้
- **"งวดที่ N ยังไม่ได้ตั้งหนี้ กรุณากดตั้งหนี้ก่อนจ่ายชำระเงิน"** — ไม่สามารถตัดรับ-จ่ายชำระค่างวดที่ยังไม่เคยกดสร้างเอกสารตั้งหนี้ได้ ให้กดตั้งหนี้งวดนั้นก่อนแล้วค่อยบันทึกชำระเงิน

## คำถามที่ลูกค้ามักถาม

**ถาม: กดดึงใบขอซื้อ (PR) หรือใบสั่งซื้อ (PO) มารับสินค้าแล้วหาเอกสารไม่เจอ เกิดจากอะไร?**
ตอบ: ตรวจ 2 จุดครับ/ค่ะ (1) ใบขอซื้อ/ใบสั่งซื้อนั้นยังไม่ได้กด **อนุมัติ** (หากบริษัทเปิดบังคับให้อ้างอิงเฉพาะเอกสารที่อนุมัติแล้ว) หรือ (2) เอกสารนั้นถูกรับของครบจำนวนไปแล้วจนขึ้นว่าไม่มียอดคงเหลือ

**ถาม: ซัพพลายเออร์ส่งของแถมหรือส่งของมาเกินกว่าที่สั่งใน PO จะรับเข้าเกินจำนวน PO ได้ไหม?**
ตอบ: โดยปกติระบบจะห้ามรับของเกินยอดสั่งซื้อครับ/ค่ะ หากกิจการอนุญาตให้รับของเกิน PO ได้ ต้องให้ผู้ดูแลระบบเปิดข้อเลือก **"อนุญาติให้รับสินค้ามากกว่าใบสั่งซื้อได้"** ใน **กำหนดข้อเลือกพิเศษต่างๆ** (**1004**) ก่อน

**ถาม: ใช้เมนู 5017 เทียบเอกสาร 3 ทาง (3-Way Match) แล้วติดเตือนผลต่างราคา/จำนวน แต่ผู้จัดการตกลงยอมรับราคานี้แล้ว ต้องทำยังไง?**
ตอบ: หากตรวจสอบแล้วว่าเป็นยอดจริงที่ผู้มีอำนาจยอมรับได้ ให้ติ๊กช่องยืนยัน **อนุมัติผลต่าง** ในหน้าจอก่อนกดตั้งหนี้ครับ/ค่ะ หรือถ้าเป็นความผิดพลาดจากผู้ขายให้แก้ไขยอดให้ตรงกับ PO และใบรับของก่อน

**ถาม: ทำไมกดจ่ายค่างวดสัญญาผ่อนชำระไม่ได้ ระบบเตือน "งวดที่ N ยังไม่ได้ตั้งหนี้"?**
ตอบ: ระบบบังคับให้กดสร้างเอกสาร **ตั้งหนี้ประจำงวด** ก่อนจึงจะนำไปตัดจ่ายชำระเงินได้ครับ/ค่ะ ให้กดตั้งหนี้งวดนั้นให้เรียบร้อยก่อนแล้วค่อยทำจ่ายชำระตามปกติ
