# ประมวลผลปรับปรุงจากการตรวจนับไม่ได้ ขึ้นว่า เอกสารตรวจนับ ... มีเอกสารปรับปรุงแล้ว

**ข้อความที่เห็น:**
- "เอกสารตรวจนับ ... มีเอกสารปรับปรุงแล้ว ต้องยกเลิกเอกสารปรับปรุงเดิมก่อนประมวลผลใหม่"
- "ไม่พบเอกสารตรวจนับบางใบ หรือถูกยกเลิกแล้ว"
- "เอกสารตรวจนับที่เลือกไม่มีรายการสินค้า"
- "รายการตรวจนับมากเกินไป ให้เลือกเอกสารทีละส่วน"
- "มีรายการต่างกัน ... รายการ เกิน ... ให้เลือกเอกสารทีละส่วน"
- "กรุณาเลือกคลังสินค้าอย่างน้อย 1 คลัง" (หน้าต่าง สินค้าที่ไม่มีการตรวจนับและมียอดคงเหลือ)

**เกิดตอน:** กด ประมวลผล ที่เมนู สินค้า › ตรวจนับสต็อกและปรับปรุงจากการตรวจนับ › ปรับปรุงสต็อกสินค้า/วัตถุดิบอัตโนมัติ หรือ ปรับปรุงสต็อกสินค้า/วัตถุดิบอัตโนมัติ (สินค้า Lot)

**สาเหตุ:**
- ใบตรวจนับใบนี้เคยประมวลผลไปแล้ว และใบปรับปรุงที่ได้ยังใช้งานอยู่ ถ้าทำซ้ำ ยอดจะถูกปรับ 2 รอบ ระบบจึงกันไว้
- เลือกใบตรวจนับที่ถูกลบหรือยกเลิกไปแล้ว หรือใบที่ไม่มีรายการ
- เลือกใบตรวจนับหลายใบพร้อมกันจนรายการมากเกิน (รายการต่างกันได้ไม่เกิน 5000 รายการต่อรอบ)

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ถ้าต้องการประมวลผลใหม่จริง ให้ยกเลิกใบปรับปรุงเดิมที่สร้างจากใบตรวจนับนี้ทั้งใบเพิ่มและใบลด ด้วยเมนู สินค้า › ยกเลิกเอกสารคลังสินค้า (รับ/เบิก/โอน/ปรับปรุง) › ยกเลิกปรับปรุงสต๊อกสินค้า/วัตถุดิบ (เกิน) และ ยกเลิกปรับปรุงสต๊อกสินค้า/วัตถุดิบ (ขาด) ([[howto-stock-cancel-doc]])
2. เลขที่ใบลดคือเลขใบเพิ่มที่มีเครื่องหมาย - นำหน้า ใช้หาใบคู่กันได้
3. แก้ใบตรวจนับให้ถูก แล้วกด ประมวลผล อีกครั้ง
4. ถ้าแค่อยากดูว่าใบไหนทำแล้ว ติ๊ก แสดงทั้งหมด (รวมเอกสารนับที่ปรับปรุงแล้ว) แล้วดูช่องสถานะ ปรับปรุงแล้ว / ยังไม่ได้ปรับ
5. ถ้ารายการมากเกินไป เลือกใบตรวจนับทีละน้อยลง แล้วประมวลผลหลายรอบ

**ส่งต่อทีมงานเมื่อ:** ยกเลิกใบปรับปรุงเดิมครบแล้วยังขึ้นข้อความ หรือยอดหลังปรับดูผิด ([[ts-stock-balance-wrong]])
