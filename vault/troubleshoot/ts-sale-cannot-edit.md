# แก้หรือลบเอกสารขายไม่ได้ ขึ้น "ห้ามแก้ไข หรือลบข้อมูล"

**ข้อความที่เห็น:**
- "ห้ามแก้ไข หรือลบข้อมูล"
- "Lock เด็ดขาด : ห้ามแก้ไข หรือลบข้อมูล"
- "เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้" (ใบรับเงินมัดจำ/รับเงินล่วงหน้า)

**เกิดตอน:** กด "บันทึก" หลังแก้ไข หรือกด "ลบ" เอกสารขายที่บันทึกไว้แล้ว

**สาเหตุ:** เอกสารถูกใช้ต่อไปแล้ว ระบบล็อกไว้เพื่อไม่ให้ยอดของเอกสารปลายทางเพี้ยน
| เอกสาร | ล็อกเมื่อ |
|---|---|
| ใบเสนอราคาขาย | ผ่านเมนูอนุมัติแล้ว (ทั้งอนุมัติและไม่อนุมัติ) หรือถูกดึงไปทำใบสั่งจอง/ใบสั่งขาย/ใบขาย หรือมีการยกเลิกรายสินค้า |
| ใบสั่งจองสินค้า / ใบสั่งขายสินค้า | ผ่านเมนูอนุมัติแล้ว (ทั้งอนุมัติและไม่อนุมัติ) หรือถูกดึงไปใช้ หรือมีการยกเลิกรายสินค้า ใบสั่งจองที่ระบบอนุมัติให้เองตอนบันทึก (ไม่เกินวงเงิน เมื่อเปิดตรวจวงเงินใบสั่ง) ก็ถูกล็อกด้วย |
| ขายสินค้า/บริการ | มีใบรับคืน/ลดหนี้ หรือใบเพิ่มหนี้อ้างอิง, เช็คในบิลถูกนำฝากหรือผ่านแล้ว, ออกใบกำกับภาษีเต็มรูปจากบิลนี้แล้ว, ถูกวางบิลหรือรับชำระแล้ว |
| รับคืนสินค้า/ลดหนี้ขาย, เพิ่มหนี้ขาย/ราคาผิด | ถูกวางบิลหรือรับชำระแล้ว |
| รับเงินมัดจำ / รับเงินล่วงหน้า | ถูกหักในเอกสารอื่น หรือถูกคืนเงินแล้ว |
| ทุกเอกสาร | ถูกยกเลิกแล้ว หรือเป็นเอกสารสำเนา |
- "Lock เด็ดขาด" = เอกสารถูกล็อกถาวรโดยระบบ แก้ไขจากหน้าจอนี้ไม่ได้

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. หาว่าเอกสารใบไหนใช้ใบนี้อยู่ เช่น ใบเสร็จ ใบวางบิล ใบลดหนี้ ใบขายที่หักมัดจำ
2. ยกเลิกหรือแก้เอกสารปลายทางก่อน ไล่จากใบล่าสุดย้อนกลับ ([[howto-ar-cancel-docs]], [[howto-sale-cancel-docs]])
3. แล้วจึงกลับมาแก้หรือลบเอกสารต้นทาง
4. ถ้าไม่อยากยกเลิกหลายใบ ให้ออกใบลดหนี้หรือเพิ่มหนี้ปรับยอดแทน ([[howto-sale-credit-note]], [[howto-sale-debit-note]])
5. ใบเสนอราคาที่ต้องแก้บ่อย ผู้ดูแลเปิด "แก้ไขใบเสนอราคาได้ตลอดเวลา" ในแท็บ "4.ระบบขาย" ได้ ([[howto-sale-settings]])
6. ใบสั่งที่อนุมัติแล้ว ให้ "ยกเลิกการอนุมัติ" ที่เมนูอนุมัติก่อน แล้วจึงแก้ ([[howto-sale-order]])

**ส่งต่อทีมงานเมื่อ:**
- ขึ้น "Lock เด็ดขาด : ห้ามแก้ไข หรือลบข้อมูล"
- ใบสั่งจองที่ระบบอนุมัติให้เองตอนบันทึก แล้วต้องการแก้
- ยกเลิกเอกสารปลายทางครบแล้ว แต่ยังแก้ไม่ได้
- งวดบัญชีปิดแล้ว ดู [[ts-common-period-closed]]
