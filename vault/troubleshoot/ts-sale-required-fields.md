# บันทึกเอกสารขายไม่ได้ ขึ้น "กรุณาป้อน..."

**ข้อความที่เห็น:** ข้อความใดข้อความหนึ่งในตารางด้านล่าง

**เกิดตอน:** กด "บันทึก" เอกสารขาย

**สาเหตุและวิธีแก้ (บอกลูกค้าได้เลย):**
| ข้อความ | ช่องที่ขาด | ทำอย่างไร |
|---|---|---|
| "กรุณาเลือก เลขที่เอกสาร" | ยังไม่เลือกรูปแบบเลขที่เอกสาร | เลือกรูปแบบในช่องเลขที่เอกสาร หรือให้ผู้ดูแลตั้งรูปแบบเลขที่ของหน้าจอนี้ |
| "กรุณาป้อนเลขที่ใบกำกับภาษี" / "กรุณาป้อนวันที่ใบกำกับภาษี" | เลขที่/วันที่ใบกำกับภาษี | ใส่ให้ครบ ใช้กับใบขาย ใบเพิ่มหนี้ ใบรับคืน/ลดหนี้ ที่ภาษีแยกนอกหรือรวมใน เมื่อเปิด "ป้อนเลขที่ใบกำกับภาษีทุกครั้ง" |
| "กรุณาป้อน วันที่รับ/ส่งสินค้า" | วันที่รับ/ส่งสินค้า | ใส่วันส่งของ เมื่อเปิด "ใส่วัน รับ/ส่ง สินค้าทุกครั้ง" (ใบเสนอราคา ใบสั่งจอง ใบสั่งขาย ใบขาย) |
| "กรุณาป้อน จำนวนวันหมดอายุ" | อายุใบเสนอราคา | ใส่จำนวนวันมากกว่า 0 เมื่อเปิด "ใช้ระบบหมดอายุใบเสนอราคา" |
| "กรุณาป้อน สาขา" | สาขา | เลือกสาขา เมื่อบริษัทเปิด "ใช้ระบบสาขา" และเปิด "เตือนเมื่อไม่กำหนดสาขา" |
| "กรุณาป้อน แผนก" | แผนก | เลือกแผนก เมื่อเปิด "ใช้ระบบแยกแผนก" และ "เตือนไม่บันทึกแผนก" |
| "รหัส : ... ไม่พบจำนวนสินค้า" | จำนวนในบรรทัด | ใส่จำนวน หรือลบบรรทัดที่ไม่ใช้ เมื่อเปิด "ใส่จำนวนสินค้าทุกครั้ง" |
| "รหัสสินค้า ... ยังไม่บันทึกหมายเลข LOT แบบกำหนดเอง" | หมายเลข Lot | เลือก Lot ของสินค้านั้นในบรรทัด |
| "กรุณาป้อน รหัสลูกค้า" | ลูกหนี้/ลูกค้า | เลือกลูกค้าในหัวเอกสาร ([[ts-sale-customer-inactive]]) |

**ขั้นตอนทั่วไป:**
1. อ่านข้อความว่าขาดช่องไหน
2. ไปกรอกช่องนั้นในหัวเอกสาร ด้านล่าง หรือในบรรทัดสินค้า
3. กด "บันทึก" อีกครั้ง
4. ถ้าร้านไม่ต้องการบังคับช่องนั้น ให้ผู้ดูแลปิดข้อเลือกที่เกี่ยวข้องใน กำหนดข้อเลือกพิเศษต่างๆ ([[howto-sale-settings]])

**ส่งต่อทีมงานเมื่อ:**
- กรอกครบแล้วยังขึ้นข้อความเดิม
- ไม่มีรูปแบบเลขที่เอกสารให้เลือกเลย ต้องให้ผู้ดูแลตั้งค่าเอกสาร ([[start-first-day]])
