# ภาษีหัก ณ ที่จ่ายไม่ขึ้นในรายงาน หรือขึ้นผิด ภ.ง.ด.

**ข้อความที่เห็น:** ไม่มีข้อความ แต่ใบหัก ณ ที่จ่ายไม่อยู่ในรายงาน ภงด.53 / ภงด.3 / ภาษีถูกหัก หรือไปอยู่อีกรายงาน หรือยอดเป็น 0
**เกิดตอน:** เปิดรายงานภาษีหัก ณ ที่จ่าย (ภ.ง.ด.3 / 53)
**สาเหตุ:**
- รายงานดึงตาม วันที่หัก ณ ที่จ่าย ไม่ใช่วันที่เอกสาร
- ประเภทของใบ (นิติบุคคล = ภงด.53, บุคคลธรรมดา = ภงด.3) ระบบดึงจากทะเบียนเจ้าหนี้/ลูกหนี้ตอนบันทึก ช่อง ประเภท บนจอแก้เองไม่ได้ ถ้าทะเบียนตั้งผิด หรือแก้ทะเบียนหลังบันทึก ใบจะไปอยู่ผิดรายงาน ถ้าไม่ได้ใส่รหัสลูกหนี้/เจ้าหนี้ ระบบนับเป็นบุคคลธรรมดา
- บันทึกผิดแท็บ: เราหักคนอื่นต้องอยู่ ภาษีหัก ณ. ที่จ่าย ลูกค้าหักเราต้องอยู่ ภาษีถูกหัก ณ. ที่จ่าย
- บรรทัดรายละเอียดไม่ได้ใส่ รายละเอียด (ประเภทเงินได้) ระบบไม่เก็บบรรทัดนั้น รายงานแสดงทีละบรรทัดรายละเอียด จึงไม่ขึ้น
- เอกสารถูกยกเลิก รายงานแสดงยอด 0 สถานะ ยกเลิก

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิดเอกสาร แท็บ ข้อมูลภาษี (VAT/WHT) หรือใบสำคัญใน ข้อมูลรายวัน แท็บ ภาษีหัก ณ. ที่จ่าย / ภาษีถูกหัก ณ. ที่จ่าย ตรวจว่าอยู่แท็บหักหรือถูกหักถูกต้อง
2. ตรวจ วันที่หัก ณ ที่จ่าย และ ประเภท ของใบ ถ้าประเภทผิด ให้แก้ บุคคลธรรมดา/นิติบุคคล ที่ทะเบียนเจ้าหนี้ (กำหนดเจ้าหนี้) ก่อน แล้วเปิดเอกสารนี้บันทึกใหม่
3. ตรวจว่าทุกบรรทัดมี รายละเอียด ฐานภาษี อัตราภาษี แล้วบันทึกใหม่ ([[howto-tax-wht-entry]])
4. เปิดรายงานใหม่ด้วยช่วงวันที่ที่ครอบวันที่หัก ณ ที่จ่าย ([[howto-tax-wht-report]])

**ส่งต่อทีมงานเมื่อ:** ข้อมูลครบทุกข้อแล้วรายงานยังไม่แสดง
