# เปิดเอกสารขายไม่ได้ ขึ้น "สถานะ ลูกค้าปิดการใช้งาน : ..."

**ข้อความที่เห็น:**
- "สถานะ ลูกค้าปิดการใช้งาน : ..."
- หรือ "กรุณาป้อน รหัสลูกค้า"
- หรือ "ไม่พบข้อมูล : รหัสลูกค้า ..."

**เกิดตอน:** กด "บันทึก" เอกสารใหม่ในหน้าจอ ใบเสนอราคาขาย ใบสั่งจองสินค้า ใบสั่งขายสินค้า ขายสินค้า/บริการ รับคืนสินค้า/ลดหนี้ขาย หรือ เพิ่มหนี้ขาย/ราคาผิด

**สาเหตุ:**
- "สถานะ ลูกค้าปิดการใช้งาน" → ลูกค้ารายนี้ถูกตั้ง "สถานะ" เป็น "ไม่ใช้งาน" ในหน้า กำหนดลูกหนี้ ระบบไม่ให้เปิดเอกสารขายใบใหม่ให้ลูกค้าที่ปิดแล้ว
- "กรุณาป้อน รหัสลูกค้า" → ยังไม่ได้เลือกลูกค้าในหัวเอกสาร
- "ไม่พบข้อมูล : รหัสลูกค้า ..." → รหัสที่พิมพ์ไม่มีในทะเบียน (พิมพ์ผิด หรือถูกลบไปแล้ว)

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิด ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › กำหนดลูกหนี้ เลือกลูกค้ารายนั้น
2. เปลี่ยน "สถานะ" เป็น "ใช้งาน" แล้วบันทึก ([[howto-ar-customer-register]])
3. กลับมาบันทึกเอกสารขายอีกครั้ง
4. ถ้าลูกค้ารายนี้เลิกค้าขายแล้วจริงๆ ให้เปิดใช้งานชั่วคราว บันทึกเอกสาร แล้วปิดกลับ
5. ถ้าขึ้น "ไม่พบข้อมูล" ให้เลือกลูกค้าจากรายการค้นหาแทนการพิมพ์รหัสเอง

**ควรรู้:**
- ตรวจเฉพาะตอนสร้างเอกสารใหม่ เอกสารเก่าของลูกค้าที่ปิดแล้วยังแก้ไขและบันทึกได้
- ลูกค้าเงินสดเริ่มต้นของหน้าร้าน (POS) ไม่ถูกตรวจ ([[sys-pos-overview]])
- เอกสารฝั่งลูกหนี้ เช่น ใบเสร็จรับเงิน ไม่ถูกตรวจสถานะนี้ จึงรับชำระหนี้เก่าของลูกค้าที่ปิดแล้วได้

**ส่งต่อทีมงานเมื่อ:** เปลี่ยนสถานะเป็น "ใช้งาน" แล้วยังขึ้นข้อความเดิม
