# แก้ไขหรือลบเอกสารซื้อ/เจ้าหนี้ไม่ได้

**ข้อความที่เห็น:**
- "ห้ามแก้ไข หรือลบข้อมูล"
- "Lock เด็ดขาด : ห้ามแก้ไข หรือลบข้อมูล"
- "ประเภทเอกสารไม่ตรงกับเอกสารที่บันทึกไว้"
- "ไม่พบเอกสารที่จะแก้ไข : ..."
- ตอนลบ: "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบได้"

**เกิดตอน:** เปิดเอกสารเดิมมาแก้แล้วกด "บันทึก" หรือกด "ลบ" ในเอกสารซื้อหรือเอกสารเจ้าหนี้

**สาเหตุ:**
- "ห้ามแก้ไข หรือลบข้อมูล" เอกสารนี้ถูกเอกสารอื่นดึงไปใช้แล้ว (เช่น ใบเสนอซื้อที่อนุมัติหรือบันทึกไม่อนุมัติแล้ว ใบสั่งซื้อที่ทำใบซื้อแล้ว ใบซื้อที่มีใบลดหนี้หรือจ่ายชำระแล้ว ใบตั้งหนี้ที่รับวางบิลหรือจ่ายแล้ว) หรือใช้ครบแล้ว หรือถูกยกเลิกแล้ว
- "Lock เด็ดขาด : ..." เอกสารถูกล็อกไว้ไม่ให้แก้จากหน้าจอ
- "ประเภทเอกสารไม่ตรงกับเอกสารที่บันทึกไว้" เลขที่เอกสารนี้ถูกใช้ไปแล้วกับเอกสารเจ้าหนี้/ลูกหนี้ชนิดอื่น
- "มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบได้" มีเอกสารอื่นอ้างถึงใบนี้อยู่ ข้อความบอกเลขที่ของเอกสารนั้น
- "ไม่พบเอกสารที่จะแก้ไข" เอกสารถูกลบไปแล้ว หรือมีคนอื่นลบระหว่างที่เปิดค้างไว้
- ถ้าข้อความเป็นเรื่องปิดงวด ดู [[ts-common-period-closed]]
- ข้อควรรู้: ใบเพิ่มหนี้ซื้อ ใบส่งคืน/ลดหนี้ซื้อ ใบเพิ่มหนี้และลดหนี้จากใบตั้งหนี้ และใบส่งคืนสินค้าจากการรับ รุ่นปัจจุบันยังไม่กันการแก้ไข แม้จะจ่ายชำระหรือรับวางบิลไปแล้ว (แต่ลบไม่ได้) ถ้าแก้ใบแบบนี้หลังจ่ายชำระไปแล้ว ให้ส่งต่อเจ้าหน้าที่ตรวจยอด

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิดเอกสาร กด "Document Flow" ดูว่ามีเอกสารไหนดึงไปใช้ต่อ
2. ถ้าต้องแก้จริง ให้ยกเลิกหรือลบเอกสารปลายทางก่อน (ไล่จากใบล่าสุดย้อนกลับ) แล้วค่อยแก้ใบนี้
3. ถ้าไม่อยากยุ่งกับเอกสารปลายทาง ให้ทำเอกสารปรับปรุงแทน เช่น ใบลดหนี้ หรือใบเพิ่มหนี้ ([[howto-buy-return-credit-note]], [[howto-buy-debit-note]])
4. ถ้าเลขที่ชนกับเอกสารชนิดอื่น ให้ใช้เลขที่ใหม่ หรือปล่อยให้ระบบรันเลขให้
5. ถ้าเป็น "ไม่พบเอกสารที่จะแก้ไข" ให้ปิดหน้าจอแล้วเปิดใหม่

**ส่งต่อเจ้าหน้าที่เมื่อ:** เจอ "Lock เด็ดขาด" และลูกค้าจำเป็นต้องแก้ หรือ Document Flow ไม่มีเอกสารปลายทางเลย แต่ยังแก้ไม่ได้
