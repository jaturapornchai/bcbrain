# บันทึกไม่ได้ ขึ้นว่า รหัสสินค้า ... ยังไม่บันทึกหมายเลข LOT แบบกำหนดเอง

**ข้อความที่เห็น:** "รหัสสินค้า ... ยังไม่บันทึกหมายเลข LOT แบบกำหนดเอง"

**เกิดตอน:** บันทึกเอกสารที่รับหรือจ่ายสินค้า เช่น ซื้อ ขาย เบิก โอน ปรับปรุง รับสำเร็จรูป ยอดยกมา ของสินค้าที่ตั้ง ประเภทต้นทุน เป็น 3.ต้นทุน LOT กำหนดเอง

**สาเหตุ:**
- สินค้าแบบ LOT (เลขล็อต ชุดการผลิตที่เข้ามาพร้อมกัน) ต้องรู้ทุกครั้งว่าของที่เข้าหรือออกเป็น LOT ไหน
- แถวสินค้าในเอกสารยังไม่ได้กรอกเลข LOT
- ถ้าเปิดตัวเลือก ใช้ระบบค้นหา LOT อัตโนมัติ ไว้ ระบบจะเติม LOT ให้เฉพาะบิลขายที่สร้างใหม่ ถ้าหา LOT ที่มีของในคลังและที่เก็บนั้นไม่เจอ ช่อง LOT จะว่างและบันทึกไม่ผ่าน

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. หาแถวของรหัสสินค้าที่ระบบบอก แล้วกรอกเลข LOT
2. ตอนรับเข้า ให้ตั้งเลข LOT ใหม่ เช่น ตามวันผลิตหรือเลขบนกล่อง
3. ตอนจ่ายออก ให้เลือก LOT ที่ยังมีของ ดูได้ที่ ยอดคงเหลือสินค้าตาม LOT ([[howto-stock-inquiry-balance]])
4. ถ้าไม่ต้องการคุมตาม LOT แล้ว สินค้าที่มีรายการซื้อขายแล้วเปลี่ยนประเภทต้นทุนเองไม่ได้ ระบบเก็บค่าเดิมไว้ ให้ส่งต่อเจ้าหน้าที่

**ส่งต่อทีมงานเมื่อ:** กรอก LOT แล้วยังขึ้นข้อความ หรือต้องการเปลี่ยนสินค้าที่ใช้งานแล้วออกจากระบบ LOT

## ข้อควรรู้
- ใบขอเบิก ใบขอโอน ใบขอตรวจนับ และใบตรวจนับ ไม่ได้บังคับ LOT แต่ใบเบิก ใบโอน และใบปรับปรุงที่ทำต่อจะบังคับ
- การทำงานของ LOT อัตโนมัติ ดู [[howto-stock-lot]]
