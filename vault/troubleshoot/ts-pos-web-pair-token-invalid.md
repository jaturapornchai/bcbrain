# เครื่อง POS เชื่อมระบบไม่ได้

## ข้อความและวิธีแก้
| ข้อความ | ความหมาย | วิธีแก้ |
|---|---|---|
| รหัสเชื่อมเครื่อง POS ไม่ถูกต้องหรือถูกยกเลิกแล้ว | เครื่องใช้รหัสเก่า รหัสผิด หรือมีการสร้างรหัสใหม่ให้เครื่องนี้ไปแล้ว (รหัสใหม่ทำให้รหัสเก่าใช้ไม่ได้ทันที) | สร้างรหัสเชื่อมเครื่องใหม่ แล้วกรอกในเครื่อง POS ตามที่ [[howto-pos-web-pair-device]] |
| ใช้ได้เฉพาะเครื่อง POS ที่เชื่อมแล้ว | คำสั่งนี้ (เช่น ส่งบิล ซิงก์ข้อมูล) ระบบรับเฉพาะจากเครื่องที่เชื่อมแล้ว หรือจากหน้า POS บนเว็บที่ล็อกอินอยู่ | เชื่อมเครื่องใหม่ หรือเข้าสู่ระบบเว็บใหม่ถ้าใช้หน้า POS บนเว็บ |
| เครื่อง POS ใช้คำสั่งนี้ไม่ได้ | คำสั่งนี้เป็นของหน้าเว็บหลังบ้าน เช่น ตั้งค่าหรือสร้างรหัสเชื่อม | ทำจากหน้าเว็บหลังบ้านด้วยบัญชีผู้ใช้ |
| ไม่พบเครื่อง POS ... ในเมนูกำหนดเครื่อง POS | ตอนสร้างรหัสเชื่อม ยังไม่มีรหัสเครื่องนี้ในทะเบียน | ลงทะเบียนเครื่องก่อน [[howto-pos-web-machine-register]] |
| ระบบหลังบ้านไม่ได้ส่งรหัสเชื่อมเครื่องกลับมา | หน้าเว็บขอรหัสแล้วไม่ได้รับรหัส | กดสร้างอีกครั้ง ถ้ายังเป็นให้แจ้งทีมงาน |

## ข้อควรรู้
- รหัสเชื่อมเครื่องแสดงครั้งเดียวตอนสร้าง คัดลอกเก็บไว้ทันที ถ้าหายต้องสร้างใหม่
- สร้างรหัสใหม่ให้เครื่องใด เครื่องนั้นต้องกรอกรหัสใหม่
- เครื่องที่ถูกยกเลิกรหัสส่งบิลและซิงก์ไม่ได้จนกว่าจะเชื่อมใหม่ ดูสถานะที่ [[howto-pos-web-monitor-sync]]
