# บันทึกไม่ได้ ขึ้นว่า ไม่พบหน่วยนับ ... ของสินค้า ... หรือ กรุณาระบุหน่วยนับขนาน

**ข้อความที่เห็น:**
- "ไม่พบหน่วยนับ ... ของสินค้า ..."
- "กรุณาระบุหน่วยนับขนานของสินค้า ... (...)"
- "กรุณาระบุจำนวนหน่วยขนาน (...) ของสินค้า ... (...)"
- "จำนวนหน่วยขนาน ... ผิดพลาด (...)"
- "Serial Number ... ไม่มีหน่วยนับ" (ตอนตรวจนับด้วย Serial)

**เกิดตอน:** บันทึกเอกสารที่มีรายการสินค้า เช่น เบิก โอน ปรับปรุง รับสำเร็จรูป ยอดยกมา

**สาเหตุ:**
- หน่วยนับในแถวไม่ได้อยู่ในตารางหน่วยนับของสินค้าตัวนั้น เช่น เลือก กล่อง แต่สินค้าตั้งไว้แค่ ชิ้น
- สินค้าใช้หน่วยนับขนาน (นับ 2 หน่วยพร้อมกัน เช่น จำนวนเส้นและน้ำหนัก กก.) แต่แถวไม่ได้กรอกหน่วยที่สองและสินค้าไม่ได้ตั้งหน่วยนับขนานไว้ให้ระบบเติมเอง หรือมีจำนวนหน่วยแรกแต่จำนวนหน่วยที่สองเป็น 0 หรือจำนวนหน่วยที่สองติดลบ
- ข้อมูลหน่วยนับของ Serial หรือของสินค้าตัวนั้นว่างอยู่

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิดข้อมูลสินค้าตัวที่ระบบบอก แล้วดูตารางหน่วยนับ ([[howto-stock-units]])
2. ในเอกสาร เลือกหน่วยนับใหม่จากรายการที่มี หรือเพิ่มหน่วยนับให้สินค้าก่อน แล้วกลับมาบันทึก
3. ถ้าเป็นหน่วยนับขนาน กรอกทั้งหน่วยที่สองและจำนวนหน่วยที่สองให้ครบ จำนวนต้องไม่ติดลบ (ติดลบได้เฉพาะใบปรับปรุงสต็อกสินค้า/วัตถุดิบ (เพิ่ม))
4. ถ้าเป็นสินค้า Serial ให้ตรวจหน่วยนับของสินค้าตัวนั้นก่อน ([[howto-stock-serial]])

**ส่งต่อทีมงานเมื่อ:** หน่วยนับมีในสินค้าแล้วแต่ยังขึ้นข้อความ หรือหลังเปลี่ยนหน่วยนับแล้วยอดย้อนหลังเพี้ยน ([[faq-stock-change-unit-after-use]])
