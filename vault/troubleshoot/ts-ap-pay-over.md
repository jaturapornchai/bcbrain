# ป้อนยอดชำระเกินยอดคงเหลือของบิล

**ข้อความที่เห็น:** "ป้อนยอดชำระเกิน : ... (ยอดคงเหลือ ...)"

**เกิดตอน:** กด "บันทึก" ใบจ่ายชำระหนี้ (เจ้าหนี้) หรือใบรับวางบิล (เจ้าหนี้)

**สาเหตุ:**
- ช่อง "ยอดชำระ" (หรือ "ยอดวางบิล") ของบิลที่ระบบบอก มากกว่ายอดคงเหลือจริง
- บิลนั้นอาจถูกจ่ายไปบางส่วนแล้วในใบจ่ายชำระใบอื่น ยอดคงเหลือจึงน้อยลง
- บรรทัดใบลดหนี้ (ยอดติดลบ) ใส่ได้ตั้งแต่ยอดคงเหลือติดลบจนถึง 0 ถ้าใส่ติดลบมากกว่านั้น หรือใส่เป็นบวก ก็ขึ้นข้อความนี้
- ใส่ยอดติดลบในบิลปกติ ก็ขึ้นข้อความนี้

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูเลขที่เอกสารในข้อความ แล้วหาบรรทัดนั้นในตาราง
2. แก้ยอดชำระให้ไม่เกินตัวเลขในวงเล็บ (ยอดคงเหลือ)
3. ถ้าคิดว่ายังไม่เคยจ่ายบิลนี้ ให้เปิดบิลแล้วกด "Document Flow" ดูว่ามีใบจ่ายชำระใบไหนจ่ายไปแล้ว
4. ถ้าผู้ขายเรียกเก็บเพิ่มจริง ให้ทำใบเพิ่มหนี้ก่อน ([[howto-buy-debit-note]] หรือ [[howto-ap-other-debt]]) แล้วจ่ายทั้งสองใบ
5. ถ้ากิจการตั้งใจจ่ายเกินยอดบิลเป็นปกติ ผู้ดูแลระบบเปิดข้อเลือก "อนุญาติให้ชำระเกินยอดบิลได้" ที่ กำหนดข้อเลือกพิเศษต่างๆ แท็บ 1.ตั้งค่าระบบ ([[howto-buy-options]])

**ส่งต่อทีมงานเมื่อ:** ยอดคงเหลือในข้อความไม่ตรงกับที่ลูกค้าคำนวณ และ Document Flow ไม่มีใบจ่ายชำระอื่น
