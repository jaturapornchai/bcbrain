# กดบันทึกในระบบขนส่งแล้วเงียบ ไม่มีข้อความ

**ข้อความที่เห็น:** ไม่มี (ปกติเมื่อสำเร็จจะมีแถบข้อความ เช่น "บันทึกหลักฐานขนส่ง e-POD รหัส ... สำเร็จ!" ค้างบนจอประมาณ 5 วินาที)
**เกิดตอน:** กดบันทึกส่งมอบ เพิ่มรถ เปิด/ปิดใบสั่งซ่อม

## สาเหตุ
หน้านี้ไม่แสดงข้อความผิดพลาดเมื่อบันทึกไม่ผ่าน จึงดูเหมือนไม่มีอะไรเกิดขึ้น สาเหตุที่เป็นไปได้
- ไม่ได้เลือกรหัสจุดส่ง หรือจุดส่งนั้นไม่มีอยู่แล้ว (ช่องเลือกจุดส่งในฟอร์มตั้งต้นเป็นรหัสตัวอย่างที่อาจไม่มีในระบบ แม้ช่องจะโชว์ชื่อจุดแรกในรายการ)
- เซสชันหมดอายุ ต้องเข้าสู่ระบบใหม่
- ระบบฐานข้อมูลขัดข้องชั่วคราว

## วิธีแก้ (บอกลูกค้าได้เลย)
1. กดปุ่ม "รีเฟรชข้อมูลสด" แล้วดูว่ารายการถูกบันทึกไปหรือยัง
2. ตรวจว่าเลือกรหัสจุดส่งแล้ว โดยเลือกจากรายการเอง (ถ้าต้องการจุดแรกสุด ให้เลือกรายการอื่นแล้วเลือกกลับ)
3. ออกจากระบบและเข้าใหม่ แล้วลองอีกครั้ง
4. อย่ากดซ้ำหลายครั้งโดยไม่ตรวจก่อน เพราะอาจเกิดรายการซ้ำ

**ส่งต่อทีมงานเมื่อ:** ลองแล้วยังเงียบ และรีเฟรชแล้วไม่มีรายการ
