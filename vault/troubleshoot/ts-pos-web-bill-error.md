# บิลจาก POS ขึ้นสถานะผิดพลาด

**อาการ:** หน้าสถานะซิงก์เครื่อง POS ([[howto-pos-web-monitor-sync]]) ขึ้นป้ายแดง "บิลผิดพลาด ... บิล" หรือยอดขายหน้าร้านไม่ไปอยู่ในเอกสารขายและบัญชี
**หมายเหตุ:** บิลไม่หาย ระบบเก็บบิลดิบไว้ทุกบิล แก้สาเหตุแล้วสั่งประมวลผลใหม่ได้

## ข้อความที่พบ สาเหตุ และวิธีแก้
| ข้อความ | สาเหตุ | วิธีแก้ |
|---|---|---|
| บรรทัด n: ไม่พบรหัสสินค้า ... | รหัสสินค้าในบิลไม่มีในทะเบียนสินค้าของหลังบ้าน (เช่น แคชเชียร์เพิ่มสินค้าในเครื่องเอง หรือสินค้าถูกลบ) | เพิ่ม/กู้รหัสสินค้านั้นในทะเบียนสินค้า แล้วประมวลผลใหม่ |
| บรรทัด n: จำนวนต้องมากกว่า 0 | บรรทัดสินค้าจำนวนเป็น 0 หรือติดลบ | แจ้งทีมงานตรวจบิลต้นทางในเครื่อง POS |
| ไม่พบเครื่อง POS ... | รหัสเครื่องของบิลไม่อยู่ในทะเบียนเครื่อง | ลงทะเบียนเครื่องใน "กำหนดรหัสเครื่อง POS" ([[howto-pos-web-machine-register]]) |
| ยอดรับชำระ ... น้อยกว่ายอดบิล ... | ยอดที่รับเงินทุกช่องทางรวมกันน้อยกว่ายอดสุทธิของบิล | ตรวจวิธีชำระของบิลนั้นในเครื่อง POS แล้วแก้ที่ต้นทาง |
| เลขที่บิล ... ซ้ำกับเอกสารขายที่มีอยู่แล้วในระบบ | เลขที่บิลไปตรงกับเอกสารขายอื่นที่ไม่ใช่ของ POS | ตั้งรูปแบบเลขที่บิลของเครื่องให้ไม่ชนกับเอกสารขายปกติ ดู [[ts-pos-web-doc-format]] |
| เลขที่บิล ... ซ้ำกับบิลอื่น — ตรวจรูปแบบเลขที่บิลของเครื่อง POS ให้ไม่ซ้ำกัน | สองเครื่องออกเลขเดียวกัน ระบบจึงรับบิลที่สองไม่ได้ (ไม่ใช่การส่งซ้ำบิลเดิม ซึ่งระบบรับได้ปกติ) | ตั้งรูปแบบเลขที่บิลแต่ละเครื่องให้ต่างกัน ดู [[ts-pos-web-doc-format]] |
| เลขที่บิลต้องมี 1-25 ตัวอักษร | เลขที่บิลว่างหรือยาวเกิน 25 ตัว | ย่อรูปแบบเลขที่บิลของเครื่อง |
| บิลต้องมีรายการสินค้าอย่างน้อย 1 รายการ | บิลที่ส่งมาไม่มีสินค้า | แจ้งทีมงานตรวจบิลต้นทาง |
| ไม่พบบิล POS เลขที่ ... | ตอนยกเลิก ระบบยังไม่มีบิลนี้ (เครื่องยังไม่ส่งขึ้นมา) | รอเครื่องซิงก์ แล้วยกเลิกใหม่ ([[howto-pos-web-bill-list-cancel]]) |
| ยังไม่พบบิล ... ของเครื่องนี้ในระบบ ต้องส่งบิลก่อน | เครื่องส่งรูปสลิปมาก่อนที่บิลจะเข้าระบบ | ให้เครื่องส่งบิลก่อน แล้วค่อยส่งสลิปซ้ำ |

## ขั้นตอนแก้
1. จดข้อความผิดพลาดและเลขที่บิล แก้สาเหตุตามตาราง
2. เปิดหน้า "กำหนดรหัสเครื่อง POS" ส่วนสถานะซิงก์ กด **ประมวลผลบิลที่ผิดพลาดใหม่**
3. ถ้าขึ้น "ประมวลผลบิลใหม่ ... บิล — ยังผิดพลาด ... บิล" แปลว่ายังเหลือสาเหตุอื่น ทำซ้ำข้อ 1
