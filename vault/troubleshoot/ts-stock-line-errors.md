# บันทึกไม่ได้เพราะแถวสินค้าผิด (ไม่พบรหัสสินค้า จำนวนผิดพลาด ไม่พบจำนวนสินค้า ราคาต่ำกว่าทุน)

**ข้อความที่เห็น:** ข้อความใดข้อความหนึ่งในตาราง

**เกิดตอน:** กดบันทึกเอกสารที่มีรายการสินค้า

**สาเหตุ:**
| ข้อความ | แปลว่า |
|---|---|
| "ไม่พบรหัสสินค้า : ..." | รหัสในแถวไม่มีในทะเบียนสินค้า หรือพิมพ์ผิด |
| "จำนวน ... ผิดพลาด (...)" | จำนวนติดลบ (ใส่ติดลบได้เฉพาะใบปรับปรุงสต็อกสินค้า/วัตถุดิบ (เพิ่ม)) ถ้าจำนวนไม่ใช่ตัวเลข จะขึ้นว่า ข้อมูลตัวเลขไม่ถูกต้อง แทน |
| "รหัส : ... ไม่พบจำนวนสินค้า" | บริษัทเปิด ใส่จำนวนสินค้าทุกครั้ง แต่แถวนี้จำนวนเป็น 0 |
| "ราคาขายต่ำกว่าต้นทุน ...:..." | เอกสารขายตั้งราคาต่ำกว่าต้นทุน และบริษัทเปิด เตือนเมื่อขายต่ำกว่าทุน คู่กับ ห้ามขายสินค้าต่ำกว่าทุน |
| "ห้ามขายต่ำกว่าราคากลาง ..." | เปิด ห้ามขายสินค้าต่ำกว่าราคากลาง แล้วราคาต่ำกว่าราคากลางที่ตั้งไว้ในสูตรราคาของสินค้า (สินค้าที่ไม่มีสูตรราคา ระบบไม่ตรวจ) |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ไม่พบรหัสสินค้า: เลือกสินค้าจากรายการค้นหาแทนการพิมพ์ หรือสร้างสินค้าก่อน ([[howto-stock-item-master]])
2. จำนวนผิดพลาด: แก้จำนวนให้เป็นตัวเลขบวก ถ้าต้องการลดสต็อกใช้ใบปรับปรุงลด ([[howto-stock-adjust]])
3. ไม่พบจำนวนสินค้า: ใส่จำนวน หรือลบแถวที่ไม่ใช้
4. ราคาต่ำกว่าทุนหรือราคากลาง: แก้ราคาขาย หรือให้ผู้มีสิทธิ์ตัดสินใจ ([[howto-stock-sale-price]], [[howto-stock-price-formula]])

**ส่งต่อทีมงานเมื่อ:** สินค้ามีอยู่จริงแต่ระบบหาไม่เจอ หรือต้นทุนที่ใช้เทียบดูผิด ([[ts-stock-cost-wrong]])

## ข้อความอื่นที่เกี่ยวกับแถวสินค้า
- หน่วยนับ ดู [[ts-stock-unit-not-found]]
- คลังหรือที่เก็บว่าง ดู [[ts-stock-wh-shelf-incomplete]]
- LOT ว่าง ดู [[ts-stock-lot-required]]
- ตัวเลือก ห้ามใส่จำนวนเกินเอกสารอ้างอิง (แท็บระบบขาย) ทำให้ใส่จำนวนเกินใบที่ดึงมาไม่ได้
