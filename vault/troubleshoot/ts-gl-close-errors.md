# ปิดบัญชีสิ้นงวด/สิ้นปีไม่ผ่าน ขึ้นข้อความเตือน

**ข้อความที่เห็น:** ข้อความใดข้อความหนึ่งในตารางด้านล่าง
**เกิดตอน:** กด ประมวลผล หรือ บันทึก ในหน้าจอประมวลผลสิ้นงวด / ประมวลผลสิ้นปี / ประมวลผลกำไร/ขาดทุน และต้นทุนขาย (ปิดบัญชี = โอนยอดรายได้และค่าใช้จ่ายเข้าบัญชีกำไรขาดทุน)
**สาเหตุ:**

| ข้อความ | แปลว่า | แก้ |
|---|---|---|
| "ไม่พบงวดบัญชีที่ ..." / "ไม่พบงวดบัญชีของปี ..." | งวดหรือปีที่เลือกยังไม่ได้ตั้ง | ตั้งงวดบัญชีก่อน ([[howto-gl-account-period]]) |
| "ต้องระบุงวด/ปีบัญชี หรือช่วงวันที่ให้ถูกต้อง" | ไม่ได้เลือกงวด/ปี หรือช่วงวันที่ | เลือกให้ครบ |
| "ต้องระบุเลขที่เอกสาร (≤25 ตัว), สมุดรายวัน และบัญชีที่ปิดเข้า" | กรอกไม่ครบ | ใส่เลขที่ไม่เกิน 25 ตัว เลือกสมุดรายวันและบัญชีที่ปิดเข้า |
| "ไม่มียอดรายได้/ค่าใช้จ่ายในช่วงวันที่ ... ถึง ..." | ช่วงนี้ไม่มียอดให้ปิด หรือปิดไปแล้ว | ตรวจว่าเคยปิดช่วงนี้แล้วหรือไม่ ([[faq-gl-carry-forward]]) |
| "ไม่พบสมุดรายวัน ..." | สมุดรายวันที่เลือกไม่มีในระบบ | เลือกใหม่ หรือเพิ่มสมุด ([[howto-gl-setup-book-group]]) |
| "ไม่พบบัญชีที่ปิดเข้า ... (ต้องเป็นบัญชีย่อย)" | บัญชีปลายทางไม่มี หรือเป็นบัญชีหลัก | เลือกบัญชีทั่วไป (บัญชีย่อย) ที่มีในผังบัญชี |
| "เลขที่เอกสาร ... ถูกใช้กับเอกสารอื่นแล้ว" | เลขที่นี้มีใบสำคัญอื่นใช้แล้ว | เปลี่ยนเลขที่ |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. อ่านข้อความแล้วแก้ตามตาราง
2. กด ประมวลผล ดูตัวอย่างรายการปิดบัญชีก่อน แล้วจึงกด บันทึก
3. ต้องการปิดใหม่หลังแก้รายการย้อนหลัง ให้ประมวลผลด้วยเลขที่เอกสารปิดงวดเดิม ระบบลบใบเดิมแล้วสร้างใหม่ทับ
4. ถ้าปิดบัญชีทุกเดือนไปแล้ว ตอนสิ้นปีจะขึ้น ไม่มียอดรายได้/ค่าใช้จ่าย เป็นเรื่องปกติ ([[faq-gl-close-vs-lock-period]])
5. ไม่มีข้อความเตือน แต่ "ช่วงวันที่" ในสรุปไม่ใช่งวดที่ต้องการ (เช่น ไปเป็นงวดของปีถัดไป) ให้เว้นช่องงวดว่างแล้วใส่ จากวันที่ ถึงวันที่ เอง ([[howto-gl-end-of-period]])

**ส่งต่อทีมงานเมื่อ:** ยอดหลังปิดบัญชีไม่ตรงกับงบทดลอง หรือแก้ตามตารางแล้วยังไม่ผ่าน
