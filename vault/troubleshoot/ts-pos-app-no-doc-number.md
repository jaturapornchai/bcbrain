# POS กดชำระเงินแล้วออกบิลไม่ได้ เพราะยังไม่มีรูปแบบเลขที่บิล

**ข้อความที่เห็น:** "ยังไม่ได้รับรูปแบบเลขที่บิลของเครื่องนี้ กรุณาซิงก์ข้อมูลก่อนขาย (ตรวจ ... ของเครื่องใน BC Ai Account)" และที่หัวบิลขึ้น "รอซิงก์เลขที่บิล" แทนเลขที่บิล
**เกิดตอน:** กด "ยืนยัน..." ในหน้าชำระเงิน หน้าต่างชำระเงินยังค้างอยู่ ไม่ปิด

## สาเหตุ
เครื่องต้องรู้รูปแบบเลขที่บิลของตัวเองจากระบบหลักก่อน (ได้ตอนซิงก์ครั้งแรกหลังเชื่อมเครื่อง) ถ้ายังไม่ได้ เช่น เพิ่งเชื่อมเครื่อง ซิงก์ยังไม่สำเร็จ หรือผู้ดูแลยังไม่ตั้งรูปแบบเลขที่บิลให้เครื่องนี้ แอปจะไม่ออกบิลเพื่อกันเลขซ้ำ

## วิธีแก้
1. ตรวจว่าเชื่อมเครื่องแล้ว ([[ts-pos-app-not-paired]])
2. ต่ออินเทอร์เน็ต แล้วกดปุ่มซิงก์ที่แถบบน รอเลขที่บิลขึ้นที่หัวบิล
3. ถ้ายังไม่ขึ้น ให้ผู้ดูแลตรวจที่หน้าจอกำหนดค่า POS ในระบบหลักว่ากำหนดรูปแบบเลขที่บิลของเครื่องนี้แล้ว
4. รายการในบิลไม่หาย ซิงก์เสร็จแล้วกดชำระเงินอีกครั้งได้

## ส่งต่อทีมงานเมื่อ
ผู้ดูแลยืนยันตั้งค่าแล้ว ซิงก์สำเร็จแล้ว แต่เลขที่บิลยังว่าง
