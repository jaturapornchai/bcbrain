# รับชำระเงินและปิดบิลไม่สำเร็จ

**อาการ:** กด "รับชำระเงิน & ออกใบกำกับภาษีเข้า BC Account" แล้วขึ้นข้อความผิดพลาด

| ข้อความ | สาเหตุ | แก้ |
|---|---|---|
| **ไม่พบรหัสสินค้า : ...** | บรรทัดมีรหัสสินค้าที่ไม่มีในระบบ | [[ts-autocare-item-not-found]] |
| **ไม่พบข้อมูล : รหัสลูกค้า ...** | รหัสลูกค้าของใบงานไม่มีในทะเบียนลูกหนี้ (ถ้าใบงานไม่ได้ระบุลูกค้า ระบบจะใช้ลูกค้าตัวอย่างแทน จึงไม่ขึ้นข้อความนี้ แต่บิลจะออกชื่อลูกค้าตัวอย่าง) | แก้ใบงาน เลือกรหัสลูกค้าด้วยปุ่มค้นหา แล้วปิดใหม่ |
| **สถานะ ลูกค้าปิดการใช้งาน : ...** | ลูกค้าถูกปิดใช้งานในระบบบัญชี | ให้ผู้ดูแลเปิดใช้งานลูกค้า หรือเลือกลูกค้าอื่น |
| **ไม่พบใบสั่งซ่อม: ...** | ใบงานถูกลบไปแล้วหรือเลขที่ผิด | โหลดหน้าใหม่ แล้วเลือกใบงานอีกครั้ง |
| **วิธีรับชำระเงินไม่ถูกต้อง: ...** | วิธีรับชำระที่ส่งไประบบไม่รู้จัก | เลือกวิธีจากรายการในช่อง "วิธีรับชำระเงิน" (โอน PromptPay QR, บัตรเครดิต, เงินสด, เครดิตลูกหนี้ Fleet 30 วัน) ใหม่ ถ้ายังเกิดซ้ำให้ส่งต่อเจ้าหน้าที่ |
| **วันที่เอกสาร ... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ** | บิลใช้วันที่ของใบงาน ถ้าวันนั้นอยู่ในงวดที่ปิดหรือยังไม่ได้ตั้งงวดบัญชี จะออกบิลไม่ได้ | [[ts-common-period-closed]] |
| **ลูกค้า ... ถูกปิดสถานะเครดิต** หรือ **ยังไม่อนุมัติเปิดสถานะเครดิต** (เลือกวิธีรับชำระ "เครดิตลูกหนี้ Fleet 30 วัน") | ขายเชื่อให้ลูกค้าที่ปิดหรือยังไม่เปิดเครดิต | เลือกวิธีรับชำระอื่น หรือให้ผู้ดูแลเปิดเครดิตลูกค้าในข้อมูลลูกหนี้ |
| **ยอดวงเงินเครดิตของลูกค้า เกินที่กำหนดไว้** (เลือก "เครดิตลูกหนี้ Fleet 30 วัน") | ยอดบิลรวมหนี้ค้างเกินวงเงินของลูกค้า และร้านตั้งห้ามขายเกินวงเงิน | [[ts-sale-credit-over]] ถ้าร้านตั้งให้ใส่รหัสผู้อนุมัติ หน้า AutoCare ไม่มีช่องให้ใส่ ให้ส่งต่อเจ้าหน้าที่ |

## ตรวจว่าแก้แล้ว
ขึ้น "รับชำระเงิน & ปิดบิล ... สำเร็จ!" พร้อมเลขที่ใบกำกับภาษีขาย
