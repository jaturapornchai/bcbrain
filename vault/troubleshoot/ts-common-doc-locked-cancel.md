# แก้ปัญหาเอกสารล็อก แก้ไข ยกเลิก หรือลบไม่ได้

นอกจากเรื่องสิทธิ์ผู้ใช้งานและงวดบัญชีปิดแล้ว ระบบยังมีระบบล็อกเอกสารอัตโนมัติเพื่อป้องกันไม่ให้ข้อมูลเชื่อมโยงข้ามขั้นตอนคลาดเคลื่อน

## ข้อความที่พบบนหน้าจอและวิธีแก้ไข

### 1. เอกสารถูกอ้างอิงหรือปิดรายการไปแล้ว
- **"เอกสาร <เลขที่> มีการอ้างอิงไปแล้วโดยเอกสาร <เลขที่อื่น> ไม่สามารถลบได้"**
- **"เอกสาร <เลขที่> มีการอ้างอิงไปแล้วโดยเอกสาร <เลขที่อื่น> ไม่สามารถนำมายกเลิกได้"**
- **"เอกสาร <เลขที่> ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้"**

**สาเหตุและทางแก้:** เอกสารใบนี้ถูกดึงไปสร้างเอกสารขั้นถัดไปแล้ว (เช่น ใบสั่งขายถูกเปิดบิลขายไปแล้ว ใบรับของถูกตั้งหนี้แล้ว หรือบิลถูกนำไปวางบิล/รับชำระแล้ว) ต้องไปยกเลิกหรือลบ **เอกสารปลายทาง** ที่ระบุอยู่ในข้อความก่อน จึงจะกลับมาแก้ไขหรือยกเลิกเอกสารต้นทางได้

### 2. หน้าจอล็อกเด็ดขาด หรือทำรายการได้เฉพาะเมนูต้นทาง
- **"Lock เด็ดขาด : ห้ามแก้ไข หรือลบข้อมูล"** — เอกสารถูกล็อกปิดตาย (เช่น เอกสารที่ตั้งสถานะล็อกหรือห้ามแก้หลังผ่านกระบวนการแล้ว) หรือเปิดข้อเลือกพิเศษล็อกวันที่/เลขที่ไว้
- **"ห้ามแก้ไข หรือลบข้อมูล"** — พบบ่อยใน 2 กรณี:
  1. เอกสารลูกหนี้/เจ้าหนี้ที่ถูกนำไปใช้งานแล้ว ปิดรายการแล้ว หรือรับ-จ่ายชำระแล้ว
  2. **ใบเสนอราคา** ที่ถูกใช้งานแล้ว ยกเว้นจะเปิดข้อเลือกพิเศษ **"แก้ไขใบเสนอราคาได้ตลอดเวลา"**
- **"เอกสารนี้สร้างจากเมนูประมวลผลเฉลี่ยต้นทุนแฝง ... แก้ไข/ลบได้ที่เมนูนั้นเท่านั้น"** — ห้ามแก้หรือลบในหน้าจอปรับปรุงสต็อกทั่วไป ต้องกลับไปทำที่เมนูประมวลผลเฉลี่ยต้นทุนแฝงโดยตรง
- **"ทะเบียนเช็ค/บัตรเครดิตเป็นหน้าจอดูข้อมูลอย่างเดียว เพิ่ม/แก้ไข/ลบได้จากเอกสารรับ/จ่ายเช็คเท่านั้น"** — ให้ไปแก้หรือยกเลิกที่หน้าจอบันทึกเช็ค/บัตรเครดิตแทน

### 3. เอกสารไม่พบ หรือวันที่/หัวเอกสารไม่ครบ
- **"ไม่พบเอกสารที่จะแก้ไข : <เลขที่เอกสาร>"** — เอกสารอาจถูกลบหรือเปลี่ยนเลขที่ไปแล้ว ให้รีเฟรชรายการค้นหาใหม่
- **"กรุณาเลือก เลขที่เอกสาร"** / **"กรุณาป้อน วันที่รับ/ส่งสินค้า"** / **"กรุณาป้อน สาขา"** / **"กรุณาป้อน แผนก"** / **"กรุณาป้อน จำนวนวันหมดอายุ"** — ระบบตรวจตามข้อเลือกพิเศษที่เปิดบังคับไว้ ให้กรอกช่องที่แจ้งเตือนให้ครบก่อนบันทึก

### 4. ปัญหาหน้าจอยกเลิกและอนุมัติเอกสาร
- **"เอกสาร <เลขที่> ถูกยกเลิกแล้ว"** / **"เอกสาร <เลขที่> ยังไม่ถูกยกเลิก"** — สถานะเอกสารไม่ตรงกับคำสั่งที่กด (เช่น กดยกเลิกซ้ำ หรือกดคืนสถานะใบที่ไม่ได้ยกเลิก)
- **"เอกสาร<เลขที่> ถูกยกเลิกแบบเดิม คืนสถานะจากหน้านี้ไม่ได้"** — เอกสารที่ยกเลิกด้วยวิธีเดิมไม่สามารถกดคืนสถานะจากหน้าจอยกเลิกยุคใหม่ได้
- **"เอกสาร <เลขที่> ถูกยกเลิกแล้ว อนุมัติไม่ได้"** / **"เอกสาร <เลขที่> อนุมัติแล้ว"** / **"เอกสาร <เลขที่> บันทึกไม่อนุมัติแล้ว"** — ตรวจสถานะเอกสารก่อนกดอนุมัติหรือถอนอนุมัติ
- **"เอกสาร <เลขที่> ยังไม่ได้อนุมัติ"** — กดถอนอนุมัติหรืออ้างอิงเอกสารที่ยังไม่ได้ผ่านการอนุมัติ
- **"กรุณาดึงรายการสินค้าและระบุจำนวนที่ต้องการยกเลิก"** / **"รายการที่ ... ไม่มีจำนวนคงเหลือให้ยกเลิก"** / **"รายการที่ ... ยกเลิกได้ไม่เกิน ..."** — กรณียกเลิกบางรายการ (Cancel Item) ต้องดึงรายการเข้ามาก่อนและระบุจำนวนไม่เกินยอดที่เหลืออยู่
- **"เลขที่เอกสารยกเลิกซ้ำกับรายการบัญชีของเอกสารประเภทอื่นในวันเดียวกัน กรุณาแก้รูปแบบเลขที่เอกสารของเมนูนี้ให้ไม่ซ้ำกับเมนูอื่น"** — ใบยกเลิกชนเลขที่กับสมุดรายวันของเมนูอื่นในวันเดียวกัน ให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า** เพื่อแยกรูปแบบคำนำหน้าเลขที่เอกสารไม่ให้ชนกัน
- **"ไม่สามารถยกเลิกเอกสาร <เลขที่> ได้ เนื่องจากเช็ค/บัตรเลขที่ <เลขที่เช็ค> ถูกนำไปดำเนินการแล้ว"** / **"ไม่สามารถแก้ไขเอกสาร <เลขที่> ได้ เนื่องจากเช็ค/บัตรเลขที่ <เลขที่เช็ค> ถูกนำไปดำเนินการแล้ว"** / **"ไม่สามารถลบเอกสาร <เลขที่> ได้ เนื่องจากเช็ค/บัตรเลขที่ <เลขที่เช็ค> ถูกนำไปดำเนินการแล้ว"** / **"ไม่สามารถแก้ไขหรือลบเอกสาร <เลขที่> ได้ เนื่องจากเช็ค/บัตรเลขที่ <เลขที่เช็ค> ถูกนำไปดำเนินการแล้ว"** (หรือขึ้นว่า **เนื่องจากมีเช็ค/บัตรถูกนำไปดำเนินการแล้ว**) — เช็คหรือบัตรเครดิตที่รับ/จ่ายไว้ในเอกสารนี้ถูกนำไปนำฝาก ผ่านเช็ค คืนเช็ค เปลี่ยนเช็ค หรือขึ้นเงินไปแล้ว ต้องไปยกเลิกเอกสารจัดการเช็ค/บัตรใบนั้นก่อน จึงจะกลับมาแก้ไข ลบ หรือยกเลิกเอกสารต้นทางได้

### 5. ปัญหาสินทรัพย์ถาวรที่ขายแล้ว
- **"สินทรัพย์ ... ขายไปแล้วในเอกสาร ..."** / **"เอกสารขายสินทรัพย์ ... มีการรับชำระหนี้แล้วในเอกสาร ... ไม่สามารถลบหรือแก้ไขได้"** — ต้องยกเลิก/ลบเอกสารรับชำระหนี้ก่อน จึงจะแก้เอกสารขายสินทรัพย์ได้

## คำถามที่ลูกค้ามักถาม

**ถาม: หน้าจอขึ้น "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบ/ยกเลิกได้" ต้องแก้ยังไง?**
ตอบ: แปลว่าบิลใบนี้ถูกดึงไปทำขั้นตอนถัดไปแล้วครับ/ค่ะ (เช่น ใบสั่งขายถูกเปิดบิลขายแล้ว หรือบิลขายถูกวางบิล/รับชำระแล้ว) ให้ดูเลขที่เอกสารปลายทางที่ระบบแจ้ง (หรือกดปุ่ม **Document Flow**) แล้วไปยกเลิกหรือลบเอกสารปลายทางนั้นก่อน จึงจะกลับมาแก้หรือยกเลิกใบต้นทางได้

**ถาม: เผลอกดยกเลิกเอกสารผิดใบ จะดึงกลับมาเป็นเอกสารปกติได้ไหม?**
ตอบ: ดึงกลับมาได้ครับ/ค่ะ ให้เข้าเมนูยกเลิกของหมวดนั้น เลือกใบที่ยกเลิกผิดแล้วกดปุ่ม **คืนสถานะเอกสารปกติ** (ยกเว้นเอกสารเก่าที่เคยยกเลิกแบบเดิมจากรุ่นก่อนหน้าซึ่งระบบจะแจ้งเตือนให้ส่งผู้ดูแลระบบช่วยตรวจสอบ)

**ถาม: ขึ้นเตือน "Lock เด็ดขาด : ห้ามแก้ไข หรือลบข้อมูล" แปลว่าอะไร?**
ตอบ: เอกสารใบนั้นถูกตั้งสถานะล็อกถาวรหลังผ่านกระบวนการบัญชี/ตรวจสอบแล้ว หรือสร้างจากเมนูประมวลผลเฉพาะ (เช่น เฉลี่ยต้นทุนแฝง) จึงแก้ไขตรงจากหน้าบิลทั่วไปไม่ได้ครับ/ค่ะ ให้ตรวจสอบที่มาใน **Document Flow** หรือสอบถามผู้ดูแลระบบ

**ถาม: ทำไมกดยกเลิกหรือลบใบเสร็จไม่ได้ ระบบแจ้งว่ามีเช็ค/บัตรถูกนำไปดำเนินการแล้ว?**
ตอบ: เพราะเช็คหรือบัตรเครดิตในบิลนั้นถูกนำไปนำฝาก ผ่านเช็ค คืนเช็ค หรือขึ้นเงินไปแล้วครับ/ค่ะ ต้องไปยกเลิกเอกสารจัดการเช็ค/บัตรใบนั้นในหมวดการเงิน (**7047**–**7059**) ก่อนจึงจะกลับมาแก้หรือยกเลิกใบเสร็จต้นทางได้
