# บันทึกไม่ได้ ขึ้น "จำนวนเกินเอกสารอ้างอิง : ..."

**ข้อความที่เห็น:** "จำนวนเกินเอกสารอ้างอิง : ..." (ต่อท้ายด้วยรหัสสินค้าที่เกิน)

**เกิดตอน:** บันทึกเอกสารที่ดึงรายการมาจากใบอื่น ได้แก่
- ขายสินค้า/บริการ ที่ดึงจากใบเสนอราคา ใบสั่งจอง หรือใบสั่งขาย
- ใบสั่งขายสินค้า ที่ดึงจากใบเสนอราคาหรือใบสั่งจอง
- ใบสั่งจองสินค้า ที่ดึงจากใบเสนอราคา

**สาเหตุ:** จำนวนในบรรทัดนั้นมากกว่าจำนวนที่ใบต้นทางยังเหลือให้ใช้
- จำนวนที่เหลือ = จำนวนในใบต้นทาง หักส่วนที่ถูกดึงไปเปิดเอกสารอื่นแล้ว และหักส่วนที่ยกเลิกรายสินค้าแล้ว (ยกเว้นตอนเปิดใบขายจากใบเสนอราคา ระบบไม่หักส่วนที่ยกเลิกรายสินค้าของใบเสนอราคา)
- ระบบเทียบในหน่วยนับหลักของสินค้า ถ้าเปลี่ยนหน่วยนับในบรรทัด จำนวนอาจกลายเป็นเกินได้
- ใบขาย: ระบบตรวจเสมอ ยกเว้นเปิดข้อเลือก "ปิดการตรวจสอบขายเกินกว่าจอง"
- ใบสั่งจอง/ใบสั่งขาย: ระบบตรวจเมื่อเปิดข้อเลือก "ห้ามใส่จำนวนเกินเอกสารอ้างอิง"

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ลดจำนวนในบรรทัดนั้นให้ไม่เกินที่ใบต้นทางเหลือ แล้วบันทึกใหม่
2. ถ้าลูกค้าสั่งเพิ่มจริง ให้ใส่ส่วนที่เกินเป็นบรรทัดใหม่ที่ไม่อ้างอิงใบเดิม หรือออกใบสั่งใหม่
3. ดูว่าใบต้นทางเหลือเท่าไร: กด "ดึงเอกสาร" อีกครั้ง ระบบแสดงเฉพาะยอดที่ยังค้าง ([[howto-sale-pull-ref-doc]])
4. ถ้าใบต้นทางถูกดึงไปเปิดบิลใบอื่นโดยไม่ตั้งใจ ให้แก้หรือยกเลิกใบนั้นก่อน ([[howto-sale-cancel-docs]])
5. ร้านที่ยอมให้ขายเกินกว่าที่สั่งได้ ให้ผู้ดูแลเปิด "ปิดการตรวจสอบขายเกินกว่าจอง" ในแท็บ "4.ระบบขาย" ([[howto-sale-settings]])

**ส่งต่อทีมงานเมื่อ:**
- จำนวนไม่เกินแน่นอน (นับรวมทุกใบแล้ว) แต่ยังขึ้นข้อความ
- ใบสั่งขาย/ใบสั่งจองเก่าที่เคยบันทึกเกินไว้ตอนยังปิดข้อเลือก แก้อะไรก็บันทึกไม่ได้ เพราะระบบตรวจทุกบรรทัดที่ดึงมาทุกครั้งที่บันทึก
