# ยกเลิกหรืออนุมัติเอกสารซื้อไม่ได้

**ข้อความที่เห็น:**
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ถูกยกเลิกแล้ว" / "เอกสาร ... ถูกยกเลิกแล้ว อนุมัติไม่ได้"
- "เอกสาร ... อนุมัติแล้ว" / "เอกสาร ... บันทึกไม่อนุมัติแล้ว"
- "เอกสาร ... ยังไม่ถูกยกเลิก" / "เอกสาร ... ยังไม่ได้อนุมัติ"
- "เอกสาร... ถูกยกเลิกแบบเดิม คืนสถานะจากหน้านี้ไม่ได้"
- "เลขที่เอกสารยกเลิกซ้ำกับรายการบัญชีของเอกสารประเภทอื่นในวันเดียวกัน ..."

**เกิดตอน:** กด "บันทึกยกเลิก", "บันทึกอนุมัติ", "บันทึกไม่อนุมัติ", "คืนสถานะเอกสารปกติ" หรือ "ยกเลิกการอนุมัติ"

**สาเหตุและวิธีแก้ (บอกลูกค้าได้เลย):**
1. "มีการอ้างอิงไปแล้วโดยเอกสาร ..." มีเอกสารปลายทางใช้ใบนี้อยู่ ให้ยกเลิกหรือลบเอกสารที่ข้อความบอกก่อน แล้วค่อยยกเลิกใบนี้ ถ้าเอกสารที่บอกเป็นใบอนุมัติของใบเสนอซื้อ ให้กด "ยกเลิกการอนุมัติ" ก่อน
2. "ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ)" ใบสั่งซื้อหรือใบเสนอซื้อถูกใช้ครบทุกรายการแล้ว ไม่มีส่วนเหลือให้ยกเลิก
3. "ถูกยกเลิกแล้ว" / "อนุมัติแล้ว" / "บันทึกไม่อนุมัติแล้ว" ทำไปแล้ว ถ้าจะเปลี่ยน ให้กด "คืนสถานะเอกสารปกติ" หรือ "ยกเลิกการอนุมัติ" ก่อน
4. "ยังไม่ถูกยกเลิก" / "ยังไม่ได้อนุมัติ" กดคืนสถานะกับเอกสารที่ยังไม่ได้ยกเลิกหรืออนุมัติ ไม่ต้องทำอะไร
5. "ถูกยกเลิกแบบเดิม ..." เอกสารถูกยกเลิกไว้ด้วยวิธีเก่า ส่งต่อเจ้าหน้าที่
6. "เลขที่เอกสารยกเลิกซ้ำ..." เมนูยกเลิกสองเมนูใช้รหัสเอกสารรูปแบบเดียวกัน ให้ผู้ดูแลแก้รูปแบบเลขที่ของเมนูยกเลิกนี้ให้ไม่ซ้ำ
7. ถ้าแจ้งเรื่องงวดบัญชี ดู [[ts-common-period-closed]] (ต้องเปิดทั้งงวดของเอกสารเดิมและงวดของวันที่ยกเลิก)

**ส่งต่อเจ้าหน้าที่เมื่อ:** เอกสารปลายทางที่ข้อความบอก ถูกยกเลิกไปแล้วแต่ยังยกเลิกใบนี้ไม่ได้ หรือเจอข้อความข้อ 5
