# ใส่ราคาแล้วขึ้น "ราคาขายต่ำกว่าต้นทุน"

**ข้อความที่เห็น:**
- "ราคาขายต่ำกว่าต้นทุน ต้องการใช้ราคานี้หรือไม่" (ถามตอนใส่ราคาหรือส่วนลด)
- "ราคาขายต่ำกว่าต้นทุน" (ราคาในบรรทัดถูกล้างเป็น 0)
- "ราคาขายต่ำกว่าต้นทุน ...:..." (ตอนกดบันทึก ระบบบอกรหัสและชื่อสินค้า)
- "ห้ามขายต่ำกว่าราคากลาง" หรือ "ห้ามขายต่ำกว่าราคากลาง ..."

**เกิดตอน:** ใส่ราคาหรือส่วนลดในตารางสินค้า หรือกดบันทึก ใน ใบเสนอราคาขาย ใบสั่งจองสินค้า ใบสั่งขายสินค้า ขายสินค้า/บริการ และ เพิ่มหนี้ขาย/ราคาผิด

**สาเหตุ:**
- ราคาขายต่อหน่วยหลังหักส่วนลด (ถ้าราคารวมภาษี ระบบถอดภาษีออกก่อน) ต่ำกว่าต้นทุนเฉลี่ยของสินค้า
- เปิดแค่ "เตือนเมื่อขายต่ำกว่าทุน" → ระบบถาม ตอบใช้ราคานี้ได้ ถ้าตอบไม่ ราคาจะเป็น 0
- เปิด "เตือนเมื่อขายต่ำกว่าทุน" คู่กับ "ห้ามขายสินค้าต่ำกว่าทุน" → ใช้ราคานั้นไม่ได้ ระบบล้างราคาเป็น 0 และตอนบันทึกก็ตรวจซ้ำ
- "ห้ามขายต่ำกว่าราคากลาง" → เปิด "ห้ามขายสินค้าต่ำกว่าราคากลาง" และยอดขายบรรทัดนั้นต่ำกว่าราคากลางตามสูตรราคาขายของสินค้า
- บรรทัดที่เป็นสินค้าของแถมไม่ถูกตรวจต้นทุน

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ตรวจราคาและส่วนลดที่ใส่ ว่าพิมพ์ผิดหรือไม่ (เช่น ส่วนลดเป็นจำนวนเงินแทนเปอร์เซ็นต์) ([[howto-sale-discount]])
2. ตรวจหน่วยนับในบรรทัด ราคาต่อหน่วยเล็กแต่ต้นทุนคิดหน่วยใหญ่จะดูต่ำกว่าทุน
3. ถ้าตั้งใจขายต่ำกว่าทุนจริง และร้านเปิดแค่แบบเตือน ให้ตอบใช้ราคานี้
4. ถ้าร้านห้ามเด็ดขาด ให้ผู้มีอำนาจตัดสินใจว่าจะปิดข้อเลือก "ห้ามขายสินค้าต่ำกว่าทุน" ชั่วคราวหรือไม่ ([[howto-sale-settings]])
5. ถ้าต้นทุนเฉลี่ยดูสูงผิดปกติ ให้ตรวจเอกสารซื้อหรือรับสินค้าล่าสุดของสินค้านั้น ([[howto-stock-overview]])

**ส่งต่อทีมงานเมื่อ:** ต้นทุนเฉลี่ยของสินค้าผิด และหาเอกสารต้นเหตุไม่เจอ
