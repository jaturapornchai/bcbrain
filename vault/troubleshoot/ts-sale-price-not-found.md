# เลือกสินค้าแล้วขึ้น "ไม่พบราคาสินค้า"

**ข้อความที่เห็น:**
- "ไม่พบราคาสินค้า" (คำเตือน ราคาในบรรทัดเป็น 0)
- "ไม่พบราคาแยกนอก พบแต่ราคารวมใน คือ : ..." (ถามว่าจะใช้ราคานี้หรือไม่)
- "ไม่พบราคารวมใน พบแต่ราคาแยกนอก คือ : ..."

**เกิดตอน:** เลือกสินค้าในตารางของเอกสารขาย

**สาเหตุ:**
- "ไม่พบราคาสินค้า" → สินค้าตัวนี้ยังไม่ได้ตั้งราคาขาย สำหรับหน่วยนับ ระดับราคา หรือเงื่อนไขที่ใช้ในเอกสารนี้ (คำเตือนขึ้นเมื่อเปิด "เตือนเมื่อไม่พบราคาขาย")
- "ไม่พบราคาแยกนอก..." / "ไม่พบราคารวมใน..." → ตั้งราคาไว้แบบเดียว แต่เอกสารนี้ใช้ประเภทภาษีอีกแบบ (คำถามขึ้นเมื่อเปิด "เตือนราคาขายกับประเภทภาษี")
  - ตอบใช้ราคา ระบบแปลงราคาให้ตามอัตราภาษี เช่น มีแต่ราคารวมภาษี ระบบถอดภาษีออกให้เป็นราคาแยกนอก
- ระดับราคาของลูกค้ามาจากช่อง "ระดับราคาสินค้า" ในหน้า กำหนดลูกหนี้

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ใส่ราคาเองในบรรทัดนั้นได้เลย ถ้าเป็นการขายครั้งเดียว
2. ถ้าขายประจำ ให้ตั้งราคาขายของสินค้า ตามหน่วยนับที่ขายจริง ([[howto-stock-overview]])
3. ตรวจหน่วยนับในบรรทัด ราคาอาจตั้งไว้แค่บางหน่วย
4. ตรวจ "ระดับราคาสินค้า" ของลูกค้ารายนี้ ([[howto-ar-customer-register]])
5. ถ้าขึ้นคำถามเรื่องแยกนอก/รวมใน ตรวจช่อง "ภาษี" ในหัวเอกสารว่าถูกต้องไหม ([[faq-sale-vat-types]])

**ส่งต่อทีมงานเมื่อ:** ตั้งราคาครบแล้วตามหน่วยและระดับราคา แต่ยังขึ้น "ไม่พบราคาสินค้า"
