# แก้ปัญหาหมายเลข LOT, Serial Number, บาร์โค้ด และปรับปรุงตรวจนับไม่ได้

รวมปัญหาที่พบบ่อยเมื่อสินค้าใช้การควบคุมระดับล็อต (LOT) หมายเลขเครื่อง (Serial Number) บาร์โค้ด และการประมวลผลใบตรวจนับสินค้า

## 1. ปัญหาหมายเลข LOT (แบบกำหนดเอง)

- **ข้อความบนหน้าจอ:** **"รหัสสินค้า <รหัส> ยังไม่บันทึกหมายเลข LOT แบบกำหนดเอง"**
- **สาเหตุ:** สินค้ารายการนี้กำหนดวิธีคิดต้นทุนเป็นแบบ **"3.ต้นทุน LOT กำหนดเอง"** แต่ยังไม่ได้เลือกหรือระบุหมายเลขล็อตในบรรทัดเอกสาร (คลัง/ที่เก็บ/ล็อต)
- **วิธีแก้ไข:** กดเลือกหมายเลข LOT ของสินค้ารายการนั้นให้ครบตามจำนวนที่รับเข้าหรือขายออก

## 2. ปัญหา Serial Number (หมายเลขเครื่อง)

- **"Serial Number <เลข> ของสินค้า <รหัส> ซ้ำในเอกสาร"** / **"มีการป้อน Serial Number <เลข> ซ้ำ"** — มีการยิงหรือพิมพ์ Serial เดียวกันซ้ำมากกว่า 1 ครั้งในเอกสารใบเดียวกัน หรือซ้ำกับที่มีในระบบเมื่อไม่ได้เปิดอนุญาตให้ซ้ำ
- **"ไม่พบ Serial Number <เลข> ในทะเบียน Serial"** — นำ Serial ที่ยังไม่เคยรับเข้าคลังมาก่อนมาขาย เบิก โอน หรือตรวจเช็ก ให้ตรวจตัวเลข Serial หรือตรวจว่าใบรับสินค้าของ Serial นั้นถูกบันทึกเรียบร้อยหรือยัง

## 3. ปัญหาบาร์โค้ดสินค้า

- **"บาร์โค้ดซ้ำ: ..."** / **"บาร์โค้ด <เลข> ถูกใช้แล้วกับสินค้า <รหัส>"** — รหัสบาร์โค้ดที่กำลังบันทึกซ้ำกับสินค้าอื่นหรือหน่วยนับอื่นในทะเบียน ให้เปลี่ยนเป็นบาร์โค้ดที่ไม่ซ้ำ หรือไปค้นดูสินค้าที่ใช้อยู่เดิม
- **"บาร์โค้ดใหม่ไม่ถูกต้องตาม EAN13: ..."** — ระบบตรวจสอบหลักตรวจสอบ (Check Digit) ของบาร์โค้ดมาตรฐาน EAN-13 แล้วไม่ถูกต้อง ให้ตรวจตัวเลขทั้ง 13 หลักอีกครั้ง (โดยเฉพาะหลักสุดท้าย)

## 4. ปัญหาประมวลผลปรับปรุงจากใบตรวจนับ

- **"เอกสารตรวจนับ <เลขที่> มีเอกสารปรับปรุงแล้ว ต้องยกเลิกเอกสารปรับปรุงเดิมก่อนประมวลผลใหม่"** — ใบตรวจนับใบนี้เคยกดสร้างใบปรับปรุงสต็อก (เพิ่ม/ลด) ไปแล้ว หากนับใหม่หรือแก้ไขใบตรวจนับ ต้องไปยกเลิกใบปรับปรุงเดิมก่อนจึงจะประมวลผลซ้ำได้
- **"มีรายการต่างกัน ... รายการ เกิน ... ให้เลือกเอกสารทีละส่วน"** — จำนวนรายการสินค้าที่มีผลต่างเกินขีดจำกัดต่อรอบการประมวลผล ให้แบ่งเลือกใบตรวจนับทีละกลุ่มแล้วประมวลผลเป็นรอบๆ

## คำถามที่ลูกค้ามักถาม

**ถาม: กดบันทึกบิลขายแล้วระบบขึ้น "รหัสสินค้า ... ยังไม่บันทึกหมายเลข LOT แบบกำหนดเอง" ต้องกดเลือกตรงไหน?**
ตอบ: สินค้านี้ตั้งวิธีคิดต้นทุนเป็นแบบ **LOT กำหนดเอง** ครับ/ค่ะ ให้คลิกที่ช่องคลัง/ที่เก็บ/ล็อตในแถวสินค้านั้น แล้วเลือกหมายเลข LOT ที่มีของคงเหลือให้ครบตามจำนวนที่ขายก่อนกดบันทึก

**ถาม: ยิง Serial Number ตอนขายแล้วขึ้น "ไม่พบ Serial Number ... ในทะเบียน Serial" ทั้งที่ของอยู่ในมือ เกิดจากอะไร?**
ตอบ: แปลว่าหมายเลขเครื่อง (Serial) นี้ยังไม่เคยถูกบันทึกเข้าคลังในเอกสารรับซื้อหรือเอกสารยอดยกมาครับ/ค่ะ ให้ตรวจตัวเลขว่าสแกนครบทุกหลักไหม และตรวจว่าฝ่ายคลังได้คีย์รับสินค้าพร้อมกรอก Serial เข้าสต็อกเรียบร้อยแล้วหรือยัง

**ถาม: บันทึกบาร์โค้ดใหม่แล้วขึ้น "บาร์โค้ดไม่ถูกต้องตาม EAN13" หรือ "บาร์โค้ดซ้ำ" แก้ยังไง?**
ตอบ: หากขึ้นซ้ำให้ค้นหาดูว่าสินค้าตัวอื่นหรือหน่วยนับอื่นใช้บาร์โค้ดนี้อยู่หรือไม่ครับ/ค่ะ ส่วนกรณีไม่ถูกต้องตาม **EAN-13** ให้ตรวจตัวเลขทั้ง 13 หลัก (โดยเฉพาะหลักสุดท้ายที่เป็น Check Digit) ว่าพิมพ์ผิดหรือขาดหลักใดไปหรือไม่

**ถาม: นับสต็อกใหม่แล้วอยากกดประมวลผลปรับปรุงจากใบตรวจนับเดิม แต่ระบบเตือนว่ามีเอกสารปรับปรุงแล้ว ต้องทำยังไง?**
ตอบ: ต้องไป **ยกเลิกเอกสารปรับปรุงสต็อกเดิม** ที่สร้างจากใบตรวจนับใบนั้นก่อนครับ/ค่ะ จึงจะกลับมาประมวลผลปรับปรุงจากใบตรวจนับใบนั้นซ้ำใหม่ได้
