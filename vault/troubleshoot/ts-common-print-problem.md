# พิมพ์เอกสารไม่ได้ หรือพิมพ์ออกมามีลายน้ำ ตัวอย่าง

**ข้อความที่เห็น:** "ล็อกการพิมพ์จริง (ป้องกันพิมพ์แล้วไม่ Save)" หรือ "โหมดตัวอย่าง (Preview) — ข้อมูลยังไม่ได้บันทึกลงฐานข้อมูล" หรือกระดาษที่พิมพ์ออกมามีลายน้ำคำว่า "ตัวอย่าง"

**เกิดตอน:** เปิดหน้าต่างพิมพ์ด้วยปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ" แล้วจะสั่งพิมพ์

**สาเหตุ:**
- เอกสารยังไม่ได้บันทึก ระบบป้องกันการพิมพ์ฉบับจริงก่อนบันทึก (กันการพิมพ์บิลให้ลูกค้าแล้วไม่บันทึกเข้าระบบ) จึงให้ดูได้แค่ตัวอย่างพร้อมลายน้ำ
- ถ้ากด Ctrl + P ของเบราว์เซอร์ตอนยังไม่บันทึก จะได้กระดาษตัวอย่างที่มีลายน้ำ ไม่ใช่ฉบับจริง
- การสั่งพิมพ์ใช้หน้าต่างพิมพ์ของเบราว์เซอร์ ถ้าเบราว์เซอร์บล็อกหรือตั้งขนาดกระดาษไม่ตรง ผลที่ออกมาจะเพี้ยน

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. กดปุ่ม "บันทึกเอกสารเพื่อพิมพ์จริง" ในหน้าต่างพิมพ์ (ถ้ามี) หรือปิดหน้าต่างพิมพ์แล้วกดบันทึกเอกสารให้เรียบร้อยก่อน แล้วกด "พิมพ์ฟอร์ม / เลือกรูปแบบ" อีกครั้ง ด้านบนต้องขึ้นว่า "จากข้อมูลที่บันทึกแล้ว (ดึงจากฐานข้อมูล)"
2. กดปุ่ม "สั่งพิมพ์ / บันทึก PDF (จากข้อมูลที่บันทึกแล้ว)" อย่าใช้ Ctrl + P ของเบราว์เซอร์
3. ในหน้าต่างพิมพ์ของเบราว์เซอร์ เลือกเครื่องพิมพ์ให้ถูก หรือเลือกบันทึกเป็น PDF และตั้งขนาดกระดาษกับแนวกระดาษให้ตรงกับที่เลือกในหัวข้อ "ขนาดกระดาษ แนวตั้ง/แนวนอน & การจัดหน้า"
4. ถ้าเนื้อหาล้นหรือตัดขอบ ให้ลองเปลี่ยนระยะขอบเป็น "ปกติ" หรือลดขนาดตัวอักษรเป็น "เล็ก (กะทัดรัด)"
5. ถ้ากดแล้วไม่มีหน้าต่างพิมพ์ขึ้นเลย ให้รีเฟรชหน้าเว็บแล้วลองใหม่ หรือลองเปิดด้วยเบราว์เซอร์อื่น
6. ถ้าบันทึก Layout ไว้แล้ว แต่เปิดจากเครื่องอื่นกลับเป็นค่าเดิม (ผู้ใช้ทั่วไปจะจำค่าไว้ได้เฉพาะเครื่องของตัวเอง) ให้ผู้ใช้ระดับ Admin เป็นคนกด "บันทึก Layout หน้าจอนี้" ให้

**ส่งต่อทีมงานเมื่อ:** บันทึกเอกสารแล้วแต่หน้าต่างพิมพ์ยังขึ้นโหมดตัวอย่าง หรือแบบฟอร์มแสดงข้อมูลไม่ตรงกับเอกสาร (ยอดเงิน ภาษี ชื่อลูกค้า) หรือผู้ใช้ Admin เห็นตัวนับพิมพ์ซ้ำกลับเป็นครั้งที่ 1 ทุกครั้ง (ผู้ใช้ทั่วไป Member ตัวนับไม่ถูกจำอยู่แล้ว เป็นข้อจำกัดของรุ่นปัจจุบัน)
