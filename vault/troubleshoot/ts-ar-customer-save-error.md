# บันทึกหรือลบลูกหนี้ไม่ได้

**ข้อความที่เห็น:** ข้อความใดข้อความหนึ่งด้านล่าง

**เกิดตอน:** กดบันทึกหรือลบในหน้า ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › กำหนดลูกหนี้ (หรือ รายละเอียดลูกหนี้ / รายละเอียดสมาชิก)

**สาเหตุและวิธีแก้ (บอกลูกค้าได้เลย):**
| ข้อความ | สาเหตุ | ทำอย่างไร |
|---|---|---|
| "กรุณาระบุ 'รหัสลูกหนี้'" | ช่องรหัสว่าง | ใส่รหัส หรือกดปุ่ม "รันรหัสใหม่" ข้างช่อง |
| "กรุณาระบุ 'ชื่อ 1'" | ช่องชื่อว่าง | ใส่ชื่อลูกค้า |
| "รหัส/เลขที่เอกสาร : ... มีอยู่ในระบบแล้ว ต้องการเปลี่ยนเป็นรหัสใหม่แล้วดำเนินการต่อไป ใช่หรือไม่?" | ตอนเพิ่มใหม่ ใส่รหัสที่มีลูกค้าอื่นใช้แล้ว | กด "ใช่" ระบบรันรหัสใหม่แล้วบันทึกต่อ กด "ไม่" กลับไปแก้รหัสเอง |
| "ไม่สามารถสร้างรหัสใหม่อัตโนมัติได้ กรุณาระบุรหัสอื่น" | กด "ใช่" แล้วระบบหารหัสถัดไปไม่ได้ | พิมพ์รหัสใหม่เอง |
| "เลขประจำตัวผู้เสียภาษีอากร ไม่ครบ 13 หลัก" | ใส่เลขไม่ครบ หรือมีขีด/เว้นวรรคปน | ใส่เป็นตัวเลขล้วน 13 หลัก หรือเว้นว่างถ้าไม่มี |
| "เลขประจำตัวผู้เสียภาษี '...' ซ้ำกับลูกหนี้รหัส '...'" | มีลูกค้ารายอื่นใช้เลขนี้แล้ว ระบบไม่ดูเลขที่สาขา | ถ้าเป็นลูกค้ารายเดียวกันให้ใช้รหัสเดิม ถ้าเป็นคนละสาขาของบริษัทเดียวกันและต้องแยกรหัส รุ่นปัจจุบันบันทึกไม่ได้ แม้ตั้ง "2. สาขา" และเลขที่สาขาต่างกัน ส่งต่อเจ้าหน้าที่ |
| "กรณีเป็น 'สาขา' กรุณาระบุเลขที่สาขาเป็นตัวเลข 5 หลัก และต้องไม่ใช่ 00000" | เลือก "2. สาขา" แต่เลขที่สาขาไม่ถูก | ใส่เลขที่สาขาเป็นตัวเลข 5 หลัก เช่น 00001 หรือเลือก "1. สำนักงานใหญ่" |
| "มีการใช้งานรหัสดังกล่าวในเอกสารหรือรายการขายแล้ว ไม่สามารถลบได้" | ลบจากหน้า กำหนดลูกหนี้ แต่ลูกค้ามีเอกสารแล้ว | ลบไม่ได้ ให้ตั้ง "สถานะ" เป็น "ไม่ใช้งาน" แทน |
| "มีการใช้งานรหัสดังกล่าวในเอกสารขาย/ลูกหนี้/การเงินแล้ว ไม่สามารถลบได้" | ลบจากหน้า รายละเอียดลูกหนี้ แต่ลูกค้ามีเอกสารแล้ว | ลบไม่ได้ ให้ตั้ง "สถานะ" เป็น "ไม่ใช้งาน" แทน |
| "รหัสสมาชิก "..." มีอยู่ในระบบแล้ว" | รหัสสมาชิกซ้ำ (หน้ารายละเอียดสมาชิก) | ใช้รหัสสมาชิกอื่น |

**ขั้นตอนทั่วไป:**
1. อ่านข้อความว่าช่องไหนผิด แก้ตามตาราง
2. กดบันทึกอีกครั้ง ระบบขึ้น "บันทึกข้อมูลลูกหนี้เสร็จเรียบร้อย"
3. ถ้าต้องการเลิกใช้ลูกค้า ใช้ "สถานะ" เป็น "ไม่ใช้งาน" แทนการลบ ([[howto-ar-customer-register]])

**ข้อควรรู้:** หน้า รายละเอียดลูกหนี้ ไม่ได้ตรวจเลขผู้เสียภาษี (ไม่ครบ 13 หลัก หรือซ้ำ ก็บันทึกได้) และไม่ตรวจเลขที่สาขา ให้ตรวจและแก้เลขผู้เสียภาษีที่หน้า กำหนดลูกหนี้

**ส่งต่อทีมงานเมื่อ:**
- ระบบบอกว่าเลขผู้เสียภาษีซ้ำกับรหัสที่หาไม่เจอ
- ลูกค้าไม่มีเอกสารเลย แต่ลบไม่ได้
- ต้องแยกรหัสลูกค้าตามสาขาที่ใช้เลขผู้เสียภาษีเดียวกัน
