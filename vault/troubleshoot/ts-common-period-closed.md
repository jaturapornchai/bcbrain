# บันทึก ลบ หรือยกเลิกเอกสารไม่ได้ ระบบแจ้งว่าปิดงวดไปแล้ว

**ข้อความที่เห็น:** "วันที่เอกสาร ... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ" (ถ้าเอกสารไม่มีวันที่ จะขึ้นเป็น "วันที่ปัจจุบัน ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ")

**เกิดตอน:** กดบันทึก ลบ หรือยกเลิกเอกสารรายวัน เช่น ใบขาย ใบซื้อ ใบรับ-เบิก-โอนสินค้า ตั้งหนี้ วางบิล รับ-จ่ายชำระ สมุดรายวัน และการขายสินทรัพย์

**สาเหตุ:** ทุกครั้งที่บันทึกเอกสาร ระบบจะหา "งวดบัญชี" (ช่วงเวลาบัญชี เช่น รายเดือน ดู [[term-accounting-period]]) ที่ครอบวันที่เอกสาร ถ้าเจอข้อใดข้อหนึ่งนี้ระบบจะไม่ยอมบันทึก
- ยังไม่มีงวดบัญชีที่ครอบวันที่นั้นเลย (พบบ่อยมากในฐานข้อมูลที่เพิ่งสร้าง เพราะฐานข้อมูลใหม่ยังไม่มีงวดบัญชี)
- มีงวดแล้ว แต่ "สถานะงวดบัญชี" เป็น ปิดงวดบัญชี (Closed)

กติกาที่ควรรู้
- **บันทึก:** ดูวันที่ที่กรอกบนเอกสาร
- **ลบ:** ดูวันที่ของเอกสารที่บันทึกไว้เดิม แม้จะแก้วันที่บนจอแล้วก็ตาม
- **ยกเลิก:** ดูทั้งวันที่ของเอกสารต้นฉบับ และวันที่ของใบยกเลิก ต้องเปิดทั้งสองงวด
- เอกสารประเภททะเบียนเช็ค ระบบไม่ได้ตรวจงวด
- เอกสารรับฝากสินค้า บันทึกได้แม้ปิดงวด แต่ตอนลบยังตรวจงวดอยู่
- การลบรายการค่าเสื่อมราคา ห้ามเฉพาะงวดที่ปิดแล้ว ถ้าวันที่นั้นไม่มีงวดเลยยังลบได้

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูวันที่ในข้อความ ว่าเป็นวันที่ที่ตั้งใจจะลงจริงหรือไม่ ถ้าพิมพ์ปีผิด (เช่น ปี พ.ศ. กับ ค.ศ. สลับกัน) ให้แก้วันที่ก่อน ดู [[start-buddhist-year-dates]]
2. ให้ผู้ใช้ระดับ Admin เปิดเมนู เริ่มต้น › ตั้งค่าระบบบัญชีและภาษี › กำหนดงวดบัญชี (มีป้าย Admin)
3. ถ้ายังไม่มีงวดของปีนั้น กด "คำนวณงวดบัญชีอัตโนมัติ (12 งวด)" หรือเพิ่มแถวเอง กรอก งวดที่, วันที่เริ่มต้นงวด, วันที่สิ้นสุดงวด, ปีบัญชี แล้วบันทึก
4. ถ้ามีงวดแล้วแต่ปิดอยู่ และฝ่ายบัญชียืนยันว่าแก้ย้อนหลังได้ ให้เปลี่ยน "สถานะงวดบัญชี" เป็น เปิดใช้งาน (Open) แล้วบันทึก ทำรายการเสร็จแล้วค่อยเปลี่ยนกลับเป็น ปิดงวดบัญชี (Closed)
5. ลองบันทึก ลบ หรือยกเลิกเอกสารใหม่อีกครั้ง

**ส่งต่อทีมงานเมื่อ:** มีงวดที่ครอบวันที่และสถานะเป็นเปิดใช้งานแล้ว แต่ยังขึ้นข้อความเดิม หรือผู้ใช้ไม่มีใครเป็น Admin เลย

> การเปิดงวดที่ปิดไปแล้วกระทบตัวเลขงบการเงินที่ส่งไปแล้ว ควรให้ผู้ทำบัญชีตัดสินใจ เรื่องข้อกฎหมายให้ปรึกษาผู้สอบบัญชี/สรรพากร
