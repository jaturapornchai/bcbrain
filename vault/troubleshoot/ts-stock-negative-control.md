# แก้ปัญหาเตือนสินค้าติดลบ ขายเกินค้างจอง หรือขายเกินค้างส่ง

ข้อความแจ้งเตือนสินค้าติดลบเกิดขึ้นเมื่อเอกสารที่กำลังบันทึก (ขาย เบิก โอน ส่งคืนซื้อ ปรับลด) ทำให้ยอดคงเหลือไม่พอตัดตามระดับการควบคุมที่บริษัทตั้งไว้

## ข้อความที่พบบนหน้าจอและขอบเขตการตรวจ

### 1. สินค้าคงเหลือติดลบ
- **"สินค้า [<รหัส>] ห้ามติดลบ"** — สต็อกรวมทั้งบริษัทไม่พอตัด (ระดับ "ทั้งระบบ")
- **"สินค้า : <รหัส>,คลัง : <คลัง> ห้ามติดลบ"** — สินค้าในคลังที่เลือกไม่พอ แม้คลังอื่นจะมีของ (ระดับ "เฉพาะคลังสินค้า")
- **"สินค้า : <รหัส>,คลัง : <คลัง>,ที่เก็บ : <ที่เก็บ> ห้ามติดลบ"** — สินค้าในชั้นวาง/ที่เก็บที่เลือกไม่พอ (ระดับ "เฉพาะที่เก็บสินค้า")
- หากสินค้าคุมล็อตและเกิดติดลบเฉพาะล็อต จะต่อท้ายด้วย **",Lot : <เลขล็อต> ห้ามติดลบ"**

### 2. ติดลบจากยอดค้างจองและยอดค้างส่ง
- **"สินค้า [<รหัส>] ห้ามขายเกินยอดคงเหลือลบด้วยค้างจอง"** — สต็อกที่เหลือหักยอดใบสั่งจองของลูกค้ารายอื่นออกแล้วไม่พอขายเพิ่ม
- **"สินค้า [<รหัส>] ห้ามขายเกินยอดคงเหลือลบด้วยค้างส่ง"** — สต็อกที่เหลือหักยอดใบสั่งขายที่รอส่งมอบให้ลูกค้ารายอื่นออกแล้วไม่พอขายเพิ่ม

## เกิดจากสาเหตุใดได้บ้าง

1. **ยังไม่บันทึกใบรับสินค้า / ใบซื้อ** — ของมาถึงหน้าร้านแล้วแต่เอกสารรับเข้ายังไม่บันทึก หรือบันทึก **วันที่/เวลาเอกสาร** หลังบิลขาย (ดูวิธีตรวจลำดับเวลาใน [[faq-negative-stock]])
2. **เลือกคลัง ที่เก็บ หรือ Lot ผิด** — สินค้าจริงอยู่ที่คลังอื่นหรือชั้นวางอื่น (ถ้าใช้ระบบเช็กเฉพาะคลัง/ที่เก็บ ระบบจะไม่ดึงจากคลังอื่นมาหักแทนให้ ต้องทำใบโอนคลังก่อน)
3. **เลือกหน่วยนับผิด** — เช่น จะขาย 1 ชิ้น แต่เผลอเลือกเป็น 1 ลัง ทำให้ตัดสต็อกออกมากกว่าที่มี
4. **สต็อกติดล็อกด้วยใบสั่งจองหรือใบสั่งขายเก่าที่ค้างปิด** — มีใบสั่งจอง/สั่งขายเดิมที่ลูกค้ายกเลิกหรือส่งของไปแล้วแต่ยังไม่ได้ปิดรายการหรือยกเลิกเอกสารค้างไว้ ทำให้ยอดพร้อมขายเหลือน้อยกว่าที่เห็นในคลัง

## วิธีตรวจเช็กและแก้ไข

1. เปิดตรวจสอบ **การ์ดคุมสต็อก / รายงานสินค้าคงเหลือ** แยกตาม **คลัง / ที่เก็บ / Lot** เพื่อดูว่าสินค้าคงเหลืออยู่ที่ไหนและมีเอกสารค้างจอง/ค้างส่งอะไรบ้าง
2. ตรวจสอบ **วันและเวลาเอกสาร** ของใบรับเข้ากับใบขาย/ใบเบิกในวันเดียวกัน — ใบรับเข้าต้องมีวันที่และเวลาไม่ช้ากว่าใบขาย
3. หากสินค้าอยู่คนละคลัง ให้ทำเอกสาร **โอนสินค้าระหว่างคลัง** ก่อนออกบิลขาย
4. หากใบสั่งจองหรือใบสั่งขายเก่าถูกยกเลิกไปแล้ว ให้ไปกดยกเลิกหรือปิดรายการใบจอง/ใบสั่งขายนั้นเพื่อคืนยอดพร้อมขาย
5. หากบริษัทต้องการปรับระดับการตรวจ "ประเภทห้ามสินค้าติดลบ" หรือเปิด/ปิดกติกาห้ามโอน/ห้ามเบิก/ห้ามขายติดลบ ให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า** ที่เมนูตั้งค่าข้อเลือกพิเศษ
