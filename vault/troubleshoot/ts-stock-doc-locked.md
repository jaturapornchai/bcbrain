# แก้หรือลบเอกสารสต็อกไม่ได้ ขึ้นว่า ห้ามแก้ไข หรือลบข้อมูล

**ข้อความที่เห็น:**
- "ห้ามแก้ไข หรือลบข้อมูล"
- "เอกสารนี้สร้างจากเมนูประมวลผลเฉลี่ยต้นทุนแฝง (...) แก้ไข/ลบได้ที่เมนูนั้นเท่านั้น"
- "Lock เด็ดขาด : ห้ามแก้ไข หรือลบข้อมูล"

**เกิดตอน:** เปิดเอกสารเดิมแล้วกดบันทึกการแก้ไข หรือกดลบ

**สาเหตุ:**
- "ห้ามแก้ไข หรือลบข้อมูล" = เอกสารถูกเอกสารอื่นดึงไปใช้แล้ว ใช้ครบแล้ว ถูกยกเลิกแล้ว หรือเป็นเอกสารที่คัดลอกมา เช่น ใบขอเบิกที่ถูกดึงไปทำใบเบิกแล้ว
- ข้อความที่พูดถึงต้นทุนแฝง = ใบปรับปรุงสต็อก (เพิ่ม) ที่เมนูประมวลผลเฉลี่ยต้นทุนแฝงสร้างให้เอง
- "Lock เด็ดขาด" = เอกสารถูกตั้งล็อกไว้ ไม่ให้ใครแก้หรือลบ

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ถ้าเอกสารถูกดึงไปใช้แล้ว ให้ยกเลิกหรือลบเอกสารปลายทางที่ดึงไปก่อน แล้วค่อยแก้ใบต้นทาง
2. ถ้าเป็นเอกสารที่ยกเลิกแล้ว ให้คืนสถานะก่อน ([[howto-stock-cancel-doc]]) หรือบันทึกเอกสารใหม่แทน
3. ถ้าเป็นใบปรับปรุงจากต้นทุนแฝง ให้ไปแก้หรือลบที่เมนู ประมวลผลเฉลี่ยต้นทุนแฝง ([[howto-stock-hidden-cost]])
4. ถ้าเอกสารอยู่ในงวดที่ปิดแล้ว ดู [[ts-common-period-closed]]

**ส่งต่อทีมงานเมื่อ:** ขึ้น "Lock เด็ดขาด" กับเอกสารที่ไม่ได้มาจากเมนูต้นทุนแฝง หรือหาเอกสารปลายทางที่ดึงไปใช้ไม่เจอ

## ข้อควรรู้
- ถ้าไม่มีสิทธิ์แก้ไขเอกสาร ข้อความจะต่างออกไป ดู [[ts-common-no-permission]]
- ภาพรวมการแก้ ยกเลิก ลบ ดู [[howto-doc-edit-cancel-delete]]
