# กดปุ่มในระบบจัดซื้อแล้วเงียบ

**ข้อความที่เห็น:** ไม่มี (ปกติเมื่อสำเร็จจะมีแถบข้อความ เช่น "อัปเดตใบสั่งซื้อ ... สำเร็จ!")
**เกิดตอน:** ส่งสืบราคา, วนต่อรอง, ปิดเป็น PO, รับของเข้าคลัง, เปิด PO ด่วน

## สาเหตุ
หน้านี้ไม่แสดงข้อผิดพลาดเมื่อระบบปฏิเสธ ที่ระบบปฏิเสธได้ เช่น ไม่พบใบสืบราคาหรือใบสั่งซื้อนั้น (ถูกเปลี่ยนไปแล้ว) เซสชันหมดอายุ หรือฐานข้อมูลขัดข้องชั่วคราว อีกสาเหตุที่พบบ่อยคือฟอร์มแท็บ "5. เปิด PO / บันทึกรับของเข้าคลัง" ส่งเลข PO ตัวอย่างค้างอยู่ ซึ่งไม่มีในระบบจริง ระบบจึงตอบว่าไม่พบใบสั่งซื้อโดยไม่แสดงข้อความ

## วิธีแก้ (บอกลูกค้าได้เลย)
1. กดปุ่ม "รีเฟรช" แล้วดูว่ารายการเปลี่ยนสถานะหรือยัง
2. ตรวจว่าใบนั้นยังอยู่ และมีคนอื่นไม่ได้ปิดไปแล้ว
3. ออกจากระบบแล้วเข้าใหม่ ลองอีกครั้ง
4. ที่ฟอร์มแท็บ 5 ให้เลือกเลขที่ใบสั่งซื้อ (PO) ใหม่เองจากรายการ (ถ้าเป็นรายการแรก ให้เลือกอย่างอื่นแล้วเลือกกลับ) แล้วกดบันทึกอีกครั้ง ([[howto-procure-open-po-form]])
5. อย่ากดซ้ำรัวๆ โดยไม่ตรวจ เพราะอาจเกิดใบซ้ำ

**ส่งต่อทีมงานเมื่อ:** รีเฟรชแล้วสถานะไม่เปลี่ยน ทั้งที่ลองหลายครั้ง
