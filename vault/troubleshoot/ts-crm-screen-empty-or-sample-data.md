# หน้า CRM ว่าง หรือเจอข้อมูลตัวอย่าง

**ข้อความที่เห็น:** ไม่มีข้อความเตือน — ตารางว่าง ตัวเลขเป็น 0 หรือเห็นชื่อลูกค้า/บริษัทที่ไม่ใช่ของเรา
**เกิดตอน:** เปิดหน้า CRM ในฐานข้อมูลบริษัทจริง หรือในฐานข้อมูลสาธิต

## สาเหตุ (ภาษาคน)
1. **หน้าแชท / ติดตามหนี้ / แคมเปญ ว่าง** — ข้อมูลในสามหน้านี้ไม่ได้ดึงจากบัญชี มีเฉพาะข้อมูลตัวอย่างในฐานข้อมูลสาธิต และยังไม่มีหน้าจอสำหรับเพิ่มห้องแชทหรือรายการหนี้เข้ามาเอง (แคมเปญสร้างเองได้)
2. **กระดานดีล / โปรไฟล์ลูกค้า / ผลงานทีม ว่างหรือน้อย** — ข้อมูลมาจากทะเบียนลูกหนี้ เอกสารขาย และรายชื่อผู้ใช้ ถ้ายังไม่เคยบันทึกก็จะว่าง
3. **เห็นชื่อบริษัทตัวอย่าง** — เป็นข้อมูลสาธิตหรือค่าตัวอย่างที่ระบบใส่ให้เมื่อไม่กรอก เช่น ดีลที่ไม่ใส่ชื่อลูกค้า
4. **ตัวเลขไม่ขึ้นเลย** — การโหลดข้อมูลล้มเหลว หน้าจอไม่แสดงข้อความ error ใดๆ

## วิธีแก้ (บอกลูกค้าได้เลย)
1. โหลดหน้าใหม่ (F5) แล้วรอสักครู่
2. ตรวจว่าเลือกฐานข้อมูลถูกบริษัท (ออกจากระบบแล้วเข้าใหม่ เลือกฐานข้อมูลอีกครั้ง)
3. ถ้าขึ้นว่างเฉพาะแชท/ติดตามหนี้ → เป็นไปตามที่ระบบเป็น ใช้เมนูลูกหนี้ในระบบบัญชีติดตามหนี้แทน [[howto-ar-overview]] และใช้ [[sys-lineoa-overview]] สำหรับแชท
4. ถ้าลูกค้า/เอกสารขายมีอยู่ในบัญชีแต่ CRM ไม่ขึ้นเลย ทั้งที่โหลดใหม่หลายครั้ง ให้แจ้งทีมงาน

**ส่งต่อทีมงานเมื่อ:** ข้อ 4 หรือตัวเลขโหลดไม่ขึ้นเลยหลังเปลี่ยนฐานข้อมูลและโหลดใหม่แล้ว
