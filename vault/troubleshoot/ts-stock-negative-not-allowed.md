# บันทึกไม่ได้ ขึ้นว่า สินค้า ... ห้ามติดลบ

**ข้อความที่เห็น:** แบบใดแบบหนึ่ง ขึ้นกับการตั้งค่า ประเภทห้ามสินค้าติดลบ
- "สินค้า [...] ห้ามติดลบ" (ตรวจยอดรวมทั้งระบบ)
- "สินค้า : ...,คลัง : ... ห้ามติดลบ" (ตรวจแยกคลัง)
- "สินค้า : ...,คลัง : ...,ที่เก็บ : ... ห้ามติดลบ" (ตรวจแยกที่เก็บ)
- ถ้าสินค้าใช้ LOT จะมี ",Lot : ..." ต่อท้าย

**เกิดตอน:** บันทึกเอกสารใหม่ที่ตัดสินค้าออก เช่น ใบเบิก ใบโอน บิลขาย แล้วจำนวนที่ตัดมากกว่ายอดคงเหลือ

**สาเหตุ:** บริษัทเปิดตัวเลือกห้ามสินค้าติดลบไว้ ระบบเลยไม่ยอมให้ยอดคงเหลือต่ำกว่าศูนย์ (ที่คลัง ที่เก็บ หรือ LOT นั้น) ระบบเทียบกับยอดคงเหลือรวมของทุกเอกสารที่บันทึกไว้ ไม่ได้ดูวันที่เอกสาร

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูยอดคงเหลือล่าสุดของสินค้าตามคลังและที่เก็บ ([[howto-stock-inquiry-balance]])
2. ตรวจว่าเลือกคลัง ที่เก็บ หรือ LOT ถูกตัวไหม ถ้าของอยู่อีกคลัง ให้โอนมาก่อน ([[howto-stock-transfer]])
3. ถ้าของมีจริงแต่ยังไม่ได้บันทึกรับ ให้บันทึกซื้อหรือรับเข้าก่อน (เปลี่ยนวันที่เอกสารไม่ช่วย เพราะระบบไม่ได้ดูวันที่)
4. ถ้าของหายจริง ให้ปรับปรุงสต็อกเพิ่มก่อน ([[howto-stock-adjust]])
5. ถ้าบริษัทยอมให้ติดลบได้ ผู้ดูแลระบบปิดตัวเลือกห้ามติดลบในการตั้งค่า ([[howto-stock-options]])

**ส่งต่อทีมงานเมื่อ:** ยอดคงเหลือในหน้าจอสอบถามมีพอ แต่ยังบันทึกไม่ได้ หรือยอดดูไม่ตรงกับเอกสาร ([[ts-stock-balance-wrong]])

## ข้อควรรู้
- ตัวเลือกหลักชื่อ ห้ามเบิกสินค้าติดลบ ถ้าปิดอยู่ ระบบไม่ตรวจติดลบกับเอกสารใดเลย
- ระบบตรวจเฉพาะตอนสร้างเอกสารใหม่ ตอนแก้ไขเอกสารเดิมไม่ตรวจ และใบปรับปรุงลดไม่ตรวจ ([[faq-stock-negative-allowed]])
- สินค้าที่ติ๊ก ควบคุมยอดคงเหลือ ในข้อมูลสินค้าเพิ่มเติม ระบบข้ามการตรวจนี้
- ถ้าข้อความพูดถึงค้างจองหรือค้างส่ง ดู [[ts-stock-reserved-accrued]]
