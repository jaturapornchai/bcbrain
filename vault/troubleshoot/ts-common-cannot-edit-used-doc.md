# แก้ไขหรือลบเอกสารไม่ได้ แจ้งว่า ห้ามแก้ไข หรือลบข้อมูล

**ข้อความที่เห็น:** "ห้ามแก้ไข หรือลบข้อมูล" หรือ "Lock เด็ดขาด : ห้ามแก้ไข หรือลบข้อมูล" หรือ "เอกสารนี้สร้างจากเมนูประมวลผลเฉลี่ยต้นทุนแฝง (...) แก้ไข/ลบได้ที่เมนูนั้นเท่านั้น"

**เกิดตอน:** กดบันทึกหลังแก้ไข หรือกดลบ เอกสารซื้อ ขาย คลังสินค้า หรือเอกสารลูกหนี้/เจ้าหนี้ (กรณีลูกหนี้/เจ้าหนี้ ห้ามเมื่อเอกสารถูกนำไปใช้แล้ว ปิดรายการแล้ว หรือยกเลิกแล้ว)

**สาเหตุ:** เอกสารอยู่ในสถานะที่ระบบห้ามแก้เพื่อไม่ให้ตัวเลขที่ต่อเนื่องกันเพี้ยน ได้แก่
- เอกสารถูกนำไปใช้ต่อแล้ว เช่น ใบสั่งซื้อที่ถูกนำไปรับสินค้าแล้ว ใบสั่งขายที่ถูกนำไปออกบิลแล้ว (ดูว่าถูกนำไปใช้ที่ไหนได้ที่ปุ่ม "Document Flow")
- เอกสารปิดรายการแล้ว (ถูกนำไปใช้ครบ)
- เอกสารถูกยกเลิกแล้ว
- ใบสั่งจองสินค้าที่อนุมัติแล้ว
- เอกสารที่คัดลอกมา
- ใบเสนอราคาที่ถูกนำไปใช้แล้ว (ยกเว้นเปิดข้อเลือก "แก้ไขใบเสนอราคาได้ตลอดเวลา")
- เอกสารที่ล็อกไว้เด็ดขาด ("Lock เด็ดขาด") เช่น เอกสารที่ระบบสร้างจากการประมวลผลเฉลี่ยต้นทุนแฝง ต้องแก้หรือลบที่เมนูประมวลผลนั้นเท่านั้น

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิดเอกสารแล้วกดปุ่ม "Document Flow" ดูว่าเอกสารนี้ถูกเอกสารใบไหนนำไปใช้ต่อ ดู [[howto-common-document-flow]]
2. ถ้าต้องการแก้จริง ให้ยกเลิกหรือลบเอกสารปลายทางก่อน (ไล่จากใบล่าสุดย้อนกลับมา) แล้วค่อยแก้ใบนี้ ดู [[howto-doc-edit-cancel-delete]]
3. ถ้าเอกสารถูกยกเลิกไว้ ให้คืนสถานะก่อนด้วย "คืนสถานะเอกสารปกติ" ที่ใบยกเลิก
4. ถ้าเป็นใบเสนอราคาและกิจการต้องการแก้ได้เสมอ ให้ Admin เปิดข้อเลือก "แก้ไขใบเสนอราคาได้ตลอดเวลา" ในหน้ากำหนดข้อเลือกพิเศษต่างๆ ดู [[howto-setup-options]]
5. ถ้าแก้ย้อนไม่ได้เพราะเอกสารปลายทางส่งให้ลูกค้าแล้ว ให้ออกเอกสารปรับปรุง เช่น ใบลดหนี้ หรือใบเพิ่มหนี้ แทน ดู [[howto-sale-overview]] หรือ [[howto-buy-overview]]

**ส่งต่อทีมงานเมื่อ:** Document Flow ไม่แสดงเอกสารปลายทางเลย แต่ยังแก้ไม่ได้
