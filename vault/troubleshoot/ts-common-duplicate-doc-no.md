# บันทึกไม่ได้ แจ้งว่าเลขที่เอกสารซ้ำ

**ข้อความที่เห็น:** "เลขที่เอกสารซ้ำ" (บางครั้งตอนกดเพิ่มใหม่จะขึ้น "สร้างเลขที่เอกสารไม่สำเร็จ")

**เกิดตอน:** กดบันทึกเอกสารใหม่

**สาเหตุ:** เอกสารประเภทเดียวกันจะใช้เลขที่ซ้ำกันไม่ได้ ที่พบบ่อยคือ
- ระบบรันเลขที่ให้ตั้งแต่ตอนกด "เพิ่มใหม่" ถ้าผู้ใช้ 2 คนกดเพิ่มใหม่พร้อมกันจะได้เลขเดียวกัน คนที่บันทึกก่อนได้เลขนั้นไป อีกคนบันทึกไม่ผ่าน
- ผู้ใช้พิมพ์เลขที่เองแล้วไปตรงกับเอกสารที่มีอยู่แล้ว
- เปลี่ยนรูปแบบเลขที่เอกสาร แล้วเลขชุดใหม่ไปชนกับเลขเก่า

ระบบยังไม่เปลี่ยนเลขให้เองอัตโนมัติเมื่อเลขซ้ำ (แม้จะมีข้อเลือก "กำหนดเลขที่เอกสารขายใหม่เมื่อเลขที่ซ้ำ" ในหน้าข้อเลือกพิเศษ แต่ตอนนี้ยังไม่มีผล)

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ข้อมูลบนจอยังอยู่ ไม่ต้องพิมพ์ใหม่
2. กดปุ่ม "Auto" ข้างช่องเลขที่เอกสาร ("รันเลขที่เอกสารอัตโนมัติตามรูปแบบเอกสาร BC") เพื่อขอเลขถัดไป
3. หรือแก้เลขที่เอกสารเองให้ไม่ซ้ำ (แก้ได้เฉพาะตอนเป็นเอกสารใหม่)
4. กดบันทึกอีกครั้ง
5. ถ้าเกิดบ่อยเพราะหลายคนออกเอกสารพร้อมกัน แนะนำให้กดเพิ่มใหม่เมื่อพร้อมกรอกจริง แล้วบันทึกให้เร็ว หรือแยกรูปแบบเลขที่ตามจุดขายหรือสาขา ดู [[howto-setup-doc-format]]

**ส่งต่อทีมงานเมื่อ:** กด "Auto" แล้วได้เลขเดิมที่ซ้ำทุกครั้ง หรือขึ้น "สร้างเลขที่เอกสารไม่สำเร็จ" ตลอด
