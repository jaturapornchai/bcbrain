# ลบรหัสบัญชีไม่ได้ (ไม่อนุญาตให้ลบ ถูกใช้อยู่)

**ข้อความที่เห็น:** "ไม่อนุญาตให้ลบ ...: ..." ตามด้วยเหตุผล
**เกิดตอน:** กดลบบัญชีที่ บัญชี › ผังบัญชี (Chart of Accounts) › รายละเอียดผังบัญชี
**สาเหตุ:** บัญชีนี้ถูกใช้อยู่ ระบบไม่ให้ลบเพื่อไม่ให้รายการเดิมเสีย

| เหตุผลที่ขึ้น | ถูกใช้ที่ไหน |
|---|---|
| ถูกใช้ในสมุดรายวัน / ถูกใช้ในรายการบัญชี | มีใบสำคัญหรือรายการบัญชีใช้บัญชีนี้ |
| ถูกใช้ในการตั้งค่าปิดบัญชี | ตั้งไว้ในการปิดบัญชี |
| เป็นบัญชีหลักของบัญชีอื่น | มีบัญชีย่อยอยู่ใต้บัญชีนี้ |
| ถูกใช้เป็นบัญชีปิดของบัญชีอื่น | บัญชีอื่นกำหนดให้ปิดเข้าบัญชีนี้ |
| ถูกใช้ในทะเบียนสินทรัพย์ (รวมช่องค่าเสื่อม และค่าเสื่อมสะสม) | ทะเบียนสินทรัพย์ผูกบัญชีนี้ |
| ถูกใช้ในข้อมูลลูกหนี้ / ประเภทบัตรเครดิต / กระเป๋าเงิน | ตั้งค่าเหล่านี้ผูกบัญชีนี้ |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ถ้าบัญชีถูกใช้ในรายการบัญชีแล้ว ไม่ควรลบ ให้เอาติ๊ก ใช้งาน ออกแทน หรือถ้าตั้งรหัสผิด ใช้ เปลี่ยนรหัสบัญชี ([[howto-gl-change-account-code]])
2. ถ้าติดที่ตั้งค่า (บัญชีย่อย ทะเบียนสินทรัพย์ ลูกหนี้ บัตรเครดิต กระเป๋าเงิน) ให้ย้ายไปผูกบัญชีอื่นก่อน แล้วลบใหม่
3. ลบได้เมื่อไม่มีที่ใดใช้บัญชีนี้แล้ว

**ส่งต่อทีมงานเมื่อ:** แก้ทุกจุดแล้วยังลบไม่ได้
