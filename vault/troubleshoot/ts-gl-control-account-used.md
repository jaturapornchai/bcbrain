# ใบสำคัญลงบัญชีไปที่บัญชีหลัก (รหัสบัญชีผิดประเภท)

**ข้อความที่เห็น:**
- หน้าจอ ผ่านรายการ คอลัมน์ หมายเหตุ ขึ้น "รหัสบัญชีผิดประเภท" และติ๊กเลือกใบนั้นไม่ได้ (นับอยู่ในช่อง "มีข้อผิดพลาด")
- หน้าจอ ตรวจสอบความถูกต้อง คอลัมน์ รายการตรวจสอบ ขึ้นหัวข้อ "ตรวจสอบรายวันย่อยที่ใช้ผังบัญชีหลัก" ตามด้วยแถว "พบข้อผิดพลาด" รายละเอียด "วันที่: ... เลขที่เอกสาร: ... สมุดรายวัน: ... รหัสผังบัญชี: ..."

**เกิดตอน:** ผ่านรายการ หรือตรวจสอบความถูกต้อง (เมนู บัญชี › ตรวจสอบ ผ่านรายการ และประมวลผลบัญชี)
**สาเหตุ:** ใบสำคัญมีบรรทัดที่ใช้บัญชีที่ช่อง สถานะบัญชี เป็น บัญชีหลัก (บัญชีหัวข้อรวมยอด) ซึ่งใช้บันทึกรายการไม่ได้ ต้องใช้บัญชีทั่วไป (บัญชีย่อย) แทน ตอนบันทึกใบสำคัญระบบยังไม่กันไว้ จึงมาฟ้องตอนผ่านรายการ
- กรณีที่เจอบ่อย: ใช้แม่แบบผังบัญชี TFRS แล้วเอกสารที่ไม่ได้ผูกบัญชีไว้ที่รูปแบบเอกสาร ระบบลงเงินสดไปที่บัญชี "เงินสดในมือ" ซึ่งในแม่แบบเป็นบัญชีหลัก

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. จดเลขที่ใบสำคัญและรหัสบัญชีที่ขึ้นในข้อความ
2. ถ้าเป็นใบสำคัญที่บันทึกเอง เปิดใบนั้นใน ข้อมูลรายวัน เปลี่ยนเป็นบัญชีย่อยที่ถูกต้อง แล้วบันทึก
3. ถ้าเป็นใบที่ระบบลงเองจากเอกสาร ให้ผูกบัญชีย่อยที่ถูกต้องที่รูปแบบเอกสาร ([[howto-gl-doc-format-posting]]) แล้วสั่ง ประมวลผลจากข้อมูลรายวัน ([[howto-gl-process-from-documents]])
4. ถ้ารหัสนั้นควรเป็นบัญชีทั่วไปจริง (ตั้งผิด) แก้ช่อง สถานะบัญชี ในผังบัญชีเป็น บัญชีทั่วไป ([[howto-gl-chart-of-accounts]])
5. ผ่านรายการหรือตรวจสอบใหม่

**เรื่องใกล้เคียง:** ตอนปิดบัญชี ถ้าเลือกบัญชีปลายทางเป็นบัญชีหลัก จะขึ้น "ไม่พบบัญชีที่ปิดเข้า ... (ต้องเป็นบัญชีย่อย)" → เลือกบัญชีที่ สถานะบัญชี เป็น บัญชีทั่วไป

**ส่งต่อทีมงานเมื่อ:** เป็นใบที่ระบบลงบัญชีเองจากเอกสาร แล้วยังฟ้องหลังแก้การผูกบัญชีและประมวลผลใหม่ หรือพบจำนวนมากหลังใช้แม่แบบผังบัญชี TFRS
