# ผูก LINE กับอีเมลไม่ได้

**ข้อความที่เห็น:** "⚠️ ไม่สามารถผูกบัญชีได้" ตามด้วยสาเหตุ เช่น
- "กรุณาระบุอีเมลพนักงานให้ถูกต้อง"
- "กรุณาระบุ LINE User ID (เช่น U89f...)"
- "คุณสามารถผูก LINE กับอีเมลของตนเอง หรือต้องเป็น Admin ของบริษัทเท่านั้น"
- "ไม่สามารถผูกบัญชี LINE กับอีเมลได้"

**เกิดตอน:** กดปุ่ม "ผูก LINE ID ↔ Email พนักงาน" ในหน้าต่าง LINE MINI App

**สาเหตุ:**
- ไม่ได้กรอกช่อง LINE User ID
- อีเมลที่กรอกไม่ใช่ของคนที่ล็อกอินอยู่ และคนที่ล็อกอินไม่ใช่ผู้ดูแลระบบ
- อีเมลไม่ถูกรูปแบบ หรือระบบหลังบ้านบันทึกไม่ได้

**ข้อควรระวัง:** บางกรณี (ระบบหลังบ้านติดต่อไม่ได้) หน้าจอขึ้นว่าผูกสำเร็จทั้งที่ยังไม่ได้บันทึก ถ้าเปิดหน้าใหม่แล้วป้ายยังเป็น "⏳ รอผูกบัญชี" ให้ส่งต่อเจ้าหน้าที่

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. กรอก LINE User ID ให้ครบ (ขึ้นต้นด้วยตัวอักษร U)
2. ผูกให้อีเมลของตัวเองก่อน ถ้าจะผูกให้คนอื่น ให้ผู้ดูแลระบบ (Admin) ของบริษัทล็อกอินมาทำ
3. ตรวจว่าอีเมลสะกดถูกและเป็นอีเมลที่มีในระบบ แล้วลองใหม่

**ส่งต่อทีมงานเมื่อ:** ทำถูกขั้นตอนแล้วยังไม่ผ่าน หรือเป็น Admin แล้วยังถูกปฏิเสธ
