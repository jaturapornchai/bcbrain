# บันทึกใบขายไม่ได้ ขึ้น "สินค้า [...] ห้ามติดลบ"

**ข้อความที่เห็น:**
- "สินค้า [...] ห้ามติดลบ" หรือแบบระบุที่เก็บ "สินค้า : ...,คลัง : ...,ที่เก็บ : ...,Lot : ... ห้ามติดลบ"
- "สินค้า [...] ห้ามขายเกินยอดคงเหลือลบด้วยค้างจอง" (บางแบบมีบรรทัด คลัง [...] ที่เก็บ [...] ต่อท้าย)
- "สินค้า [...] ห้ามขายเกินยอดคงเหลือลบด้วยค้างส่ง"

**เกิดตอน:** บันทึกเอกสารใหม่ ใบขายสินค้า/บริการ ใบสั่งขายสินค้า หรือใบเพิ่มหนี้ขายประเภทที่ตัดสต็อก

**สาเหตุ:** จำนวนที่ขายมากกว่าสินค้าที่มีในคลัง/ที่เก็บนั้น และร้านเปิดข้อเลือกห้ามติดลบไว้
- "ห้ามติดลบ" → ยอดคงเหลือ ณ คลังและที่เก็บที่เลือก ไม่พอขาย
- "ลบด้วยค้างจอง" → ของมีพอ แต่ถูกจองไว้ในใบสั่งจองที่ยังค้างอยู่ (นับทุกลูกค้า) ตรวจเฉพาะใบขายสินค้า/บริการ เมื่อเปิด "ห้ามขายสินค้าค้างจองทั้งระบบ"
- "ลบด้วยค้างส่ง" → ของมีพอ แต่ติดใบสั่งขายที่ยังไม่ได้ส่ง (เปิด "ห้ามขายสินค้าค้างส่งทั้งระบบ")
- การตรวจทั้งหมดนี้ทำงานเมื่อเปิด "ห้ามเบิกสินค้าติดลบ" (แท็บ "3.สินค้าคงคลัง") และข้อความ "ห้ามติดลบ" ต้องเปิด "ห้ามขายสินค้าติดลบ" (แท็บ "4.ระบบขาย") ด้วย ส่วนใบสั่งขายสินค้าและใบเพิ่มหนี้ ต้องเปิด "เตือนเมื่อสินค้าติดลบ" (แท็บ "3.สินค้าคงคลัง") เพิ่มอีกข้อ
- สินค้าที่ติ๊ก "ควบคุมยอดคงเหลือ" ไว้ที่ สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ข้อมูลสินค้าเพิ่มเติม จะถูกข้าม ไม่ถูกตรวจเรื่องติดลบ
- ตรวจเฉพาะตอนบันทึกเอกสารใหม่ แก้ไขเอกสารเดิมไม่ถูกตรวจ
- ใบสั่งจองสินค้าไม่ถูกตรวจเรื่องนี้

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ตรวจคลังและที่เก็บในบรรทัดนั้น ว่าเลือกถูกที่ที่มีของจริงหรือไม่ เปลี่ยนให้ถูกแล้วบันทึกใหม่
2. ถ้าของมาแล้วแต่ยังไม่ได้บันทึกรับ ให้บันทึกซื้อ/รับสินค้าเข้าก่อน ([[howto-buy-overview]])
3. ถ้าของอยู่อีกคลัง ให้โอนสินค้าเข้าคลังที่จะขายก่อน ([[howto-stock-overview]])
4. ขายเท่าที่มี แล้วออกบิลส่วนที่เหลือเมื่อของเข้า
5. ติดค้างจอง/ค้างส่ง: ตรวจใบสั่งจอง/ใบสั่งขายที่ค้างอยู่ ถ้าไม่ใช้แล้วให้ยกเลิกส่วนที่ค้าง ([[howto-sale-cancel-docs]]) หรือดึงใบสั่งนั้นมาเปิดบิล ([[howto-sale-pull-ref-doc]])
6. ถ้าร้านยอมให้ขายติดลบได้ ให้ผู้ดูแลปิดข้อเลือกที่เกี่ยวข้อง ([[howto-sale-settings]])

**ส่งต่อทีมงานเมื่อ:**
- รายงานสินค้าคงเหลือมีของพอ แต่ระบบยังบอกว่าติดลบ
- สินค้ามี Lot และข้อความระบุ Lot ที่ไม่ได้เลือก
- ใบขายที่ดึงจากใบสั่งจอง ขึ้น "ลบด้วยค้างจอง" ทั้งที่ของพอ ถ้าร้านไม่ได้เปิด "ใช้ระบบจองตามที่เก็บสินค้า" ระบบยังนับยอดจองของใบที่กำลังดึงมาซ้ำ
- ร้านต้องการให้สินค้าที่ติ๊ก "ควบคุมยอดคงเหลือ" ถูกห้ามติดลบ แต่ระบบกลับข้ามสินค้านั้น
