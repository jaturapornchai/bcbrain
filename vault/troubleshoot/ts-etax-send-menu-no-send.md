# ตั้งส่ง e-Tax แล้ว แต่เอกสารไม่ถูกส่ง หรือไม่เห็นในหน้า e-Tax

**ข้อความที่เห็น:** สถานะ "พร้อมส่ง e-Tax" ในเมนู ขาย › ส่งข้อมูล e-Tax ค้างอยู่ตลอด หรือบิลขายไม่ปรากฏในทะเบียนหน้า e-Tax
**เกิดตอน:** หลังตั้งค่า e-Tax INET และออกบิลขาย

**สาเหตุ:**
1. เมนู "ส่งข้อมูล e-Tax" เป็นรายการให้ดู ไม่มีปุ่มส่ง และคำว่า "พร้อมส่ง e-Tax" ขึ้นกับทุกใบที่ไม่ได้ยกเลิก ไม่ใช่ผลการส่ง
2. ค่า Authorization Code / API Key และการติ๊กส่ง e-Tax ในรูปแบบเอกสาร มีบนจอและบันทึกได้ แต่รุ่นปัจจุบันยังไม่มีผล ระบบไม่ได้นำไปส่งเอกสาร
3. หน้า e-Tax เป็นทะเบียนภายในระบบ เอกสารเข้าทะเบียนเฉพาะที่มาจาก POS, Market, จัดซื้อ (ผ่านตรวจ 3 ทาง), งานซ่อมรถ หรือที่กรอกเอง บิลขายที่ออกจากเมนูขายในโปรแกรมบัญชีไม่ได้เข้าทะเบียนอัตโนมัติ → [[sys-etax-registry-sources]]
4. บิล POS ที่บันทึกเข้าทะเบียนไม่สำเร็จ จะไม่มีข้อความเตือน

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. อธิบายว่าขณะนี้ระบบแสดงรายการและทะเบียนภายใน ยังไม่ส่งออกให้สรรพากรหรือผู้ให้บริการอัตโนมัติ
2. ถ้าต้องส่งจริง ให้ใช้ช่องทางของผู้ให้บริการ e-Tax ที่บริษัทใช้อยู่ แล้วใช้รายการในเมนู ส่งข้อมูล e-Tax เป็นรายการอ้างอิง
3. ถ้าต้องการให้เอกสารอยู่ในทะเบียน ให้บันทึกเองที่แท็บ AI OCR (เลือกประเภทใบกำกับภาษีขาย) เอกสารที่กรอกตรงนี้ไม่ได้ลงบัญชีให้ → [[howto-etax-scan-expense-bill]]

**ส่งต่อทีมงานเมื่อ:** ลูกค้าต้องการเชื่อมต่อส่ง e-Tax อัตโนมัติ (สอบถามฝ่ายขาย/ทีมพัฒนา) หรือบิล POS ใหม่ไม่เข้าทะเบียนทุกใบ
