# ขายเชื่อไม่ได้ ขึ้น "ลูกค้า ... : ... ถูกปิดสถานะเครดิต"

**ข้อความที่เห็น:** "ลูกค้า ... : ... ถูกปิดสถานะเครดิต" หรือ "ลูกค้า ... : ... ยังไม่อนุมัติเปิดสถานะเครดิต"

**เกิดตอน:** บันทึกใบขายประเภท "ขายเชื่อ (เครดิต)" ใบตั้งหนี้อื่นๆ รายได้อื่นๆ แบบเงินเชื่อ หรือใบสั่งจอง/ใบสั่งขายเงินเชื่อ (เมื่อเปิดตรวจวงเงินใบสั่ง)

**สาเหตุ:** "สถานะสินเชื่อ :" ของลูกค้าในรายละเอียดลูกหนี้ ไม่ใช่ "เปิดวงเงิน"
- "ปิดวงเงิน" → ขายเชื่อไม่ได้เลย ข้อความนี้ขึ้นแม้ไม่ได้เปิดข้อเลือกตรวจวงเงินใดๆ
- "หยุดขายชั่วคราว" → ขายเชื่อไม่ได้ ขึ้น "ถูกปิดสถานะเครดิต" ยกเว้นเปิด "ตรวจสอบวงเงินรวมรายการสั่งขาย/สั่งจอง" ไว้ (และไม่ได้เปิด "ใช้ระบบขออนุมัติวงเงินเครดิต") จะเปิดบิลได้เฉพาะรายการที่ดึงมาจากใบสั่งจอง/ใบสั่งขายที่มีคำขออนุมัติวงเงินผ่านแล้ว ถ้าไม่ใช่จะขึ้น "ยังไม่อนุมัติเปิดสถานะเครดิต"
- รุ่นปัจจุบันยังไม่มีหน้าจออนุมัติคำขอวงเงิน การกดอนุมัติใบสั่งที่เมนูอนุมัติไม่ทำให้ผ่าน ใบสั่งที่ผ่านได้มีแค่ใบที่เคยถูกบันทึกเป็นใบรออนุมัติวงเงินตอนที่ลูกค้ายังเป็น "เปิดวงเงิน" อยู่

- ใบขายแบบ "ขายสด" ไม่ถูกตรวจสถานะนี้
- ระบบยังไม่ปิดสถานะให้เองอัตโนมัติ สถานะนี้ถูกเปลี่ยนโดยผู้ใช้ที่หน้ารายละเอียดลูกหนี้

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูเหตุผลที่ช่อง "เหตุผลในการระงับ :" ในรายละเอียดลูกหนี้ ส่วน "2. รายละเอียดและสินเชื่อ"
2. ถ้าจะให้ขายเชื่อได้อีก เปลี่ยน "สถานะสินเชื่อ :" เป็น "เปิดวงเงิน" แล้วบันทึก ([[howto-sale-credit-limit]])
3. ลูกค้าหยุดขายชั่วคราว: ถ้าดึงใบสั่ง ([[howto-sale-order]]) มาเปิดบิล ([[howto-sale-pull-ref-doc]]) แล้วยังขึ้น "ยังไม่อนุมัติเปิดสถานะเครดิต" ให้เปลี่ยนสถานะเป็น "เปิดวงเงิน" ตามข้อ 2 หรือส่งต่อเจ้าหน้าที่
4. หรือขายเป็น "ขายสด" รับเงินเต็มจำนวน

**ส่งต่อทีมงานเมื่อ:**
- สถานะสินเชื่อเป็น "เปิดวงเงิน" แล้วแต่ยังขึ้นข้อความเดิม
- ดึงใบสั่งที่อนุมัติแล้วมาเปิดบิล แต่ยังขึ้น "ยังไม่อนุมัติเปิดสถานะเครดิต"
- ลูกค้าไม่รู้ว่าใครเป็นคนปิดสถานะ ให้ทีมงานช่วยดูประวัติ
