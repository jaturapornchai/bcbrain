# บันทึกทะเบียนรถไม่ได้: ข้อมูลไม่สมบูรณ์ / ทะเบียนซ้ำ

**อาการ:** กดบันทึกรถแล้วขึ้นกล่องเตือนหัวข้อ "เตือน" ข้อความอย่างใดอย่างหนึ่ง:
- **"ข้อมูลไม่สมบูรณ์ : ทะเบียนรถ"** → ยังไม่กรอกทะเบียน
- **"ข้อมูลไม่สมบูรณ์ : ยี่ห้อรถ / รุ่นรถยนต์"** → ยังไม่กรอกยี่ห้อหรือรุ่น
- **"ข้อมูลไม่สมบูรณ์ : ชื่อเจ้าของรถ / บริษัท"** → ยังไม่กรอกชื่อเจ้าของ
- **ทะเบียนรถ "..." มีอยู่ในระบบแล้ว** → ทะเบียนนี้เคยบันทึกไว้

## วิธีแก้
1. สามข้อแรก: กรอกช่องที่ระบุให้ครบแล้วบันทึกใหม่
2. ทะเบียนซ้ำ: ค้นหารถคันเดิมในตารางซ้ายแล้วกด "แก้ไข" แทนการเพิ่มใหม่ ตรวจว่าพิมพ์ทะเบียนถูก (ตัวอักษร ตัวเลข จังหวัด)
3. ถ้ารถคนละเจ้าของใช้ทะเบียนเดิม (ขายต่อ) ให้แก้ชื่อเจ้าของที่รถคันเดิม

## ข้อควรรู้
ช่องที่ปล่อยว่างบางช่อง เช่น เลขตัวถัง จะถูกเติมค่าตัวอย่างให้เอง ตรวจหน้าจอหลังบันทึก ดู [[sys-autocare-demo-data-limits]]
