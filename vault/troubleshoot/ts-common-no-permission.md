# แก้ปัญหาไม่มีสิทธิ์ใช้งานเมนู คลังสินค้า หรือข้อมูลบริษัท

หน้าจอจะแสดงข้อความปฏิเสธสิทธิ์เมื่อบัญชีผู้ใช้ปัจจุบันไม่ได้รับอนุญาตให้เปิดดู เพิ่ม แก้ไข ลบ ประมวลผล หรือเข้าถึงคลังสินค้า/ฐานข้อมูลนั้นๆ

## ข้อความที่พบบนหน้าจอ

- **"ไม่มีสิทธิ์เรียกดูข้อมูล กรุณาติดต่อผู้ดูแลระบบเพื่อกำหนดสิทธิ์ผู้ใช้"** — เปิดหน้าจอหรือโหลดรายการไม่ได้
- **"ไม่มีสิทธิ์เพิ่มหรือแก้ไขข้อมูล กรุณาติดต่อผู้ดูแลระบบเพื่อกำหนดสิทธิ์ผู้ใช้"** / **"ไม่มีสิทธิ์บันทึกข้อมูล"** — กดบันทึกหรือแก้ไขเอกสาร/ตั้งค่าไม่ได้ (เช่น หน้าจอข้อมูลกิจการหรือข้อเลือกพิเศษ)
- **"ไม่มีสิทธิ์เพิ่มข้อมูลใหม่ กรุณาติดต่อผู้ดูแลระบบเพื่อกำหนดสิทธิ์ผู้ใช้"** — กดปุ่มเพิ่มรายการใหม่ไม่ได้
- **"ไม่มีสิทธิ์แก้ไขข้อมูล กรุณาติดต่อผู้ดูแลระบบเพื่อกำหนดสิทธิ์ผู้ใช้"** — บันทึกการเปลี่ยนแปลงรายการเดิมไม่ได้
- **"หน้าจอนี้ไม่อนุญาตให้ลบข้อมูล (ไม่มีสิทธิ์ลบ) กรุณาติดต่อผู้ดูแลระบบ"** — กดลบเอกสารหรือข้อมูลหลักไม่ได้
- **"เฉพาะผู้ดูแลระบบ (Admin) เท่านั้นที่สั่งประมวลผลทั้งฐานข้อมูลได้"** — สั่งประมวลผลส่วนกลางทั้งฐานข้อมูลไม่ได้
- **"ไม่มีสิทธิ์ใช้คลัง/ที่เก็บนี้"** — เลือกคลังสินค้าหรือชั้นเก็บในเอกสารไม่ได้ เมื่อเปิดใช้งานระบบคลังตามสิทธิ์พนักงาน
- **"ไม่มีสิทธิ์ดูต้นทุนสินค้า"** — เรียกรายงานที่มีคอลัมน์ต้นทุนหรือกำไรขั้นต้นไม่ได้ หรือถูกจำกัดการปรับเงื่อนไขรายงานที่เกี่ยวกับต้นทุน/คลัง
- **"คุณไม่มีสิทธิ์เข้าใช้งานฐานข้อมูลนี้ (PDPA Access Denied)"** — บัญชีผู้ใช้ยังไม่ได้รับสิทธิ์เข้าฐานข้อมูลบริษัทที่เลือก

## สาเหตุที่พบบ่อย

1. กลุ่มสิทธิ์ของพนักงานถูกกำหนดให้เฉพาะ "อ่าน" โดยปิดสิทธิ์ "เพิ่ม / แก้ไข / ลบ" ในเมนูนั้น
2. เปิดตัวเลือก **ใช้คลังที่เก็บตามสิทธิ์พนักงาน** แต่ยังไม่ได้ผูกสิทธิ์คลัง/ที่เก็บให้ผู้ใช้รายนี้
3. ผู้ใช้ไม่มีสิทธิ์ **ดูต้นทุนสินค้า** หรือสิทธิ์ระดับผู้ดูแลระบบ จึงไม่สามารถดูรายงานต้นทุนหรือสั่งประมวลผลทั้งฐานข้อมูลได้
4. บัญชีผู้ใช้ยังไม่ได้ถูกเพิ่มเข้ากลุ่มผู้มีสิทธิ์เข้าใช้ฐานข้อมูลบริษัทนั้น

## วิธีตรวจเช็กเบื้องต้น

1. ตรวจสอบว่ากำลังเข้าสู่ระบบด้วย **ชื่อผู้ใช้** และ **ฐานข้อมูลบริษัท** ที่ถูกต้องหรือไม่
2. หากใช้งานได้แค่ดูข้อมูลแต่กดบันทึก/ลบไม่ได้ ให้ตรวจว่าหน้าจอนั้นงานประจำวันกำหนดให้เฉพาะตำแหน่งอื่นดำเนินการหรือไม่
3. หากต้องการเปิดสิทธิ์เมนู สิทธิ์คลังสินค้า สิทธิ์ดูต้นทุน หรือสิทธิ์เข้าฐานข้อมูลเพิ่มเติม ให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า** (ผู้ดูแลระบบจะตรวจที่เมนูตั้งค่าสิทธิ์กลุ่มพนักงาน การใช้คลังและที่เก็บ และผู้มีสิทธิ์เข้าใช้ข้อมูล)

## ส่งต่อเจ้าหน้าที่ — ข้อมูลที่ควรแนบ

- ชื่อผู้ใช้ (User) และชื่อบริษัท/ฐานข้อมูลที่พบปัญหา
- ชื่อเมนูหรือหน้าจอที่กดใช้งาน
- ข้อความแจ้งเตือนเต็มบนหน้าจอ (หรือภาพหน้าจอ)
