# ขึ้นข้อความว่าไม่มีสิทธิ์ เปิดจอหรือบันทึกข้อมูลไม่ได้

**ข้อความที่เห็น:** (อย่างใดอย่างหนึ่ง)
- "คุณไม่มีสิทธิ์เปิดหน้าจอ "..." (...) — ผู้ใช้ระดับ Member ต้องได้รับสิทธิ์ "อ่าน (เปิดจอ)" จากผู้ดูแลระบบ (Admin) ก่อน"
- "เมนู "..." (...) เป็นเมนูระดับผู้ดูแลระบบ (Admin เท่านั้น) ผู้ใช้งานทั่วไปไม่สามารถเข้าใช้งานหน้าจอนี้ได้"
- "คุณไม่มีสิทธิ์ "เพิ่มข้อมูลใหม่" ในหน้าจอ "..." กรุณาติดต่อผู้ดูแลระบบ (Admin)" (มีแบบ "แก้ไขข้อมูล" และ "ลบข้อมูล" ด้วย)
- "คุณไม่มีสิทธิ์ "บันทึกข้อมูล" ในหน้าจอ "..." (ได้รับสิทธิ์เฉพาะเปิดอ่านอย่างเดียว)"
- "ไม่มีสิทธิ์เรียกดูข้อมูล กรุณาติดต่อผู้ดูแลระบบเพื่อกำหนดสิทธิ์ผู้ใช้"
- "ไม่มีสิทธิ์เพิ่มหรือแก้ไขข้อมูล กรุณาติดต่อผู้ดูแลระบบเพื่อกำหนดสิทธิ์ผู้ใช้"
- "หน้าจอนี้ไม่อนุญาตให้ลบข้อมูล (ไม่มีสิทธิ์ลบ) กรุณาติดต่อผู้ดูแลระบบ"
- "เฉพาะผู้ดูแลระบบ (Admin) เท่านั้นที่สั่งประมวลผลทั้งฐานข้อมูลได้"
- "ไม่มีสิทธิ์ดูต้นทุนสินค้า" (ตอนเปิดรายงานที่มีต้นทุน)
- "คุณไม่มีสิทธิ์เข้าใช้งานฐานข้อมูลนี้ (PDPA Access Denied)" (ตอนเลือกฐานข้อมูล)

**เกิดตอน:** คลิกเมนู กดเพิ่มใหม่ แก้ไข ลบ บันทึก สั่งประมวลผล หรือเลือกฐานข้อมูล

**สาเหตุ:** ผู้ใช้ในแต่ละฐานข้อมูลมี 2 ระดับ
- **Admin** ทำได้ทุกอย่าง และเป็นคนเดียวที่เพิ่มสมาชิกและกำหนดสิทธิ์ได้ (คนที่สร้างฐานข้อมูลเป็น Admin ทันที)
- **Member** ใช้ได้เฉพาะหน้าจอที่ Admin ติ๊กให้ แยกเป็น "อ่าน (เปิดจอ)", เพิ่ม, แก้ไข, ลบ ทีละหน้าจอ

นอกจากนี้ เมนูที่มีป้าย **Admin** สีเหลือง (เช่น ตั้งค่าองค์กร กำหนดงวดบัญชี จัดการฐานข้อมูล เปลี่ยนรหัสหลัก ประวัติการใช้งาน และงานปิดงวด ปิดปี) ใช้ได้เฉพาะ Admin เท่านั้น Member กดเปิดไม่ได้เลย แม้จะติ๊กสิทธิ์ให้ก็ตาม ส่วนข้อความ "ไม่มีสิทธิ์เข้าใช้งานฐานข้อมูลนี้" แปลว่าอีเมลนี้ยังไม่ได้ถูกเพิ่มเป็นสมาชิกของฐานข้อมูลนั้น

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ถามลูกค้าว่าเข้าด้วยอีเมล Google บัญชีไหน และฐานข้อมูลไหน ให้แน่ใจว่าเข้าถูกบัญชี
2. ให้ Admin ของฐานข้อมูลนั้นไปที่หน้าเลือกฐานข้อมูล กดปุ่ม "สมาชิก & สิทธิ์จอ" ของฐานข้อมูลนั้น
3. ถ้าผู้ใช้ยังไม่อยู่ในรายชื่อ ให้เพิ่มอีเมลก่อน ดู [[howto-user-invite-member]]
4. ไปแท็บ "2. กำหนดสิทธิ์การใช้หน้าจอของ Member (อ่าน/เพิ่ม/แก้ไข/ลบ)" ค้นชื่อจอ ติ๊กสิทธิ์ที่ต้องการ แล้วกด "บันทึกสิทธิ์การใช้จอ" ดู [[howto-user-screen-permission]]
5. ถ้าเป็นเมนูที่มีป้าย Admin ต้องให้ Admin ทำเอง หรือเปลี่ยนระดับผู้ใช้เป็น Admin (ทำได้ทุกอย่าง ควรให้เฉพาะคนที่ไว้ใจ)
6. ให้ผู้ใช้ปิดหน้าจอนั้นแล้วเปิดใหม่ แล้วลองอีกครั้ง

**ส่งต่อทีมงานเมื่อ:** Admin ให้สิทธิ์ครบแล้วแต่ยังขึ้นข้อความเดิม หรือ Admin ของฐานข้อมูลไม่สามารถเข้าระบบได้เลย
