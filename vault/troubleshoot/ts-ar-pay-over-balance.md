# รับชำระหรือวางบิลไม่ได้ ขึ้น "ป้อนยอดชำระเกิน : ... (ยอดคงเหลือ ...)"

**ข้อความที่เห็น:**
- "ป้อนยอดชำระเกิน : ... (ยอดคงเหลือ ...)" (ระบบบอกเลขที่เอกสารหนี้และยอดที่เหลือจริง)
- "... ต้องอ้างอิงใบวางบิล" (บอกเลขที่เอกสารหนี้ทีละบรรทัด)

**เกิดตอน:** กด "บันทึก" ใน รับชำระหนี้/ออกใบเสร็จรับเงิน หรือ ใบวางบิล (ลูกหนี้)

**สาเหตุ:**
- "ป้อนยอดชำระเกิน" → ช่อง "ยอดชำระ" (หรือ "ยอดวางบิล") ของบรรทัดนั้นมากกว่ายอดหนี้ที่ยังค้างของเอกสารนั้น
  - ยอดค้าง = ยอดหนี้ หักที่รับชำระไปแล้วในใบเสร็จใบอื่น
  - ถ้าข้อความบอก "ยอดคงเหลือ 0.00" แปลว่าบิลนั้นรับเงินครบไปแล้ว มักเกิดจากกด "อ้างอิงใบวางบิล" แล้วเลือกใบวางบิลเก่าที่รับเงินไปแล้ว เพราะปุ่มนี้ดึงยอดตามตอนทำใบวางบิล ไม่ใช่ยอดค้างปัจจุบัน
  - ใส่ยอดชำระติดลบในบิลหนี้ ก็ขึ้นข้อความนี้เหมือนกัน
  - ระบบตรวจเรื่องนี้เสมอ ยกเว้นเปิดข้อเลือก "อนุญาติให้ชำระเกินยอดบิลได้" (แท็บ "1.ตั้งค่าระบบ") ถ้าเปิดไว้ ระบบไม่ตรวจยอดเลย รับเงินซ้ำหรือเกินได้โดยไม่มีข้อความเตือน
- "ต้องอ้างอิงใบวางบิล" → ขึ้นเฉพาะตอนบันทึกใบเสร็จ เมื่อร้านเปิด "รับชำระหนี้อ้างอิงวางบิลทุกครั้ง" (แท็บ "2.บัญชีแยกประเภท") และบิลในบรรทัดนั้นยังไม่เคยวางบิล หรือใบวางบิลของบิลนั้นถูกยกเลิกหมดแล้ว
  - บิลที่เคยวางบิลแล้ว กด "ดึงเอกสารค้างชำระ" ก็ผ่าน เพราะระบบใส่เลขที่ใบวางบิลล่าสุดให้เอง

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูยอดคงเหลือในข้อความ แล้วแก้ "ยอดชำระ" ของบรรทัดนั้นให้ไม่เกิน ถ้ายอดคงเหลือเป็น 0.00 ให้ลบบรรทัดนั้นออก
2. ถ้าลูกค้าโอนมาเกิน ส่วนที่เกินให้รับเป็นเงินล่วงหน้า หรือเงินมัดจำแยก ([[howto-sale-advance-receipt]], [[howto-sale-deposit-receipt]])
3. ตรวจว่าบิลนั้นเคยออกใบเสร็จไปแล้วหรือไม่ อาจรับชำระซ้ำ
4. ถ้าขึ้น "ต้องอ้างอิงใบวางบิล" ให้ทำใบวางบิลของบิลนั้นก่อน ([[howto-ar-billing]]) แล้วกลับมาลบบรรทัดนั้นในใบเสร็จ และดึงใหม่ด้วย "ดึงเอกสารค้างชำระ" หรือ "อ้างอิงใบวางบิล" ([[howto-ar-receipt]])

**ส่งต่อทีมงานเมื่อ:**
- ยอดคงเหลือที่ระบบบอกไม่ตรงกับยอดที่ลูกค้าค้างจริง
- ยกเลิกใบเสร็จเดิมแล้ว ยอดคงเหลือยังไม่กลับมา
- ร้านเปิด "อนุญาติให้ชำระเกินยอดบิลได้" แล้วพบว่ามีบิลถูกรับเงินซ้ำ
