# พิมพ์รหัสแล้วขึ้น ไม่พบ และช่องว่างเปล่า

**ข้อความที่เห็น:** หน้าต่าง "เตือน" ข้อความ "ไม่พบ : ..." แล้วช่องที่พิมพ์ถูกล้างว่าง

**เกิดตอน:** พิมพ์รหัสลงในช่องรหัส (เช่น รหัสลูกค้า ผู้จำหน่าย คลัง) แล้วกด Enter หรือ Tab ออกจากช่อง

**สาเหตุ:**
- รหัสที่พิมพ์ไม่มีในระบบ เช่น พิมพ์ผิด มีช่องว่างเกิน หรือยังไม่ได้สร้างข้อมูลนั้น
- เปิดอยู่คนละฐานข้อมูลกับที่สร้างข้อมูลไว้
- ระบบล้างช่องให้เองเพื่อไม่ให้บันทึกรหัสที่ไม่มีอยู่จริงลงเอกสาร

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. กด "ตกลง" ที่หน้าต่างเตือน
2. กดปุ่มแว่นขยายข้างช่อง แล้วพิมพ์ชื่อหรือบางส่วนของรหัสในช่อง "พิมพ์คำค้นหา (ตัดคำไทย/อังกฤษอัตโนมัติ)..." เพื่อหาให้เจอ ดู [[howto-common-lookup-search]]
3. ถ้าค้นด้วยหลายคำแล้วไม่เจอ ให้ลดเหลือคำเดียว ระบบหาเฉพาะรายการที่มีครบทุกคำ ถ้าไม่ครบจะขึ้น "แสดงผลใกล้เคียง" ให้เลือกแทน
4. ถ้ายิงบาร์โค้ดแล้วไม่เจอ ให้ตรวจว่าบาร์โค้ดนั้นผูกไว้กับสินค้าแล้ว
5. ถ้ายังไม่มีข้อมูล ให้สร้างที่หน้าจอข้อมูลหลักก่อน (เช่น ข้อมูลสินค้า กำหนดลูกหนี้ กำหนดเจ้าหนี้) แล้วกลับมาเลือกใหม่ ดู [[howto-common-data-list]]
6. ดูชื่อฐานข้อมูลที่เปิดอยู่ ถ้าไม่ใช่ฐานที่ถูกต้อง ให้เปลี่ยนฐานข้อมูล ดู [[start-select-database]]

**ส่งต่อทีมงานเมื่อ:** ค้นจากหน้าต่างค้นหาแล้วเห็นรายการนั้นอยู่ แต่พิมพ์รหัสเดียวกันตรงๆ แล้วยังขึ้น "ไม่พบ" ทุกครั้ง
