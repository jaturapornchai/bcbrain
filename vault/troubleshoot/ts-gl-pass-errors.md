# ผ่านรายการใบสำคัญไม่ได้ ติ๊กไม่ได้ หรือขึ้นผ่านรายการไม่ได้

**ข้อความที่เห็น:** ช่องหมายเหตุของใบสำคัญขึ้น "ไม่พบผังบัญชี" / "รหัสบัญชีผิดประเภท" / "ยอดไม่ Balance" / "ผ่านรายการแล้ว" หรือกดแล้วขึ้น "ใบสำคัญ ... ผ่านรายการไม่ได้: ..." / "กรุณาเลือกใบสำคัญอย่างน้อย 1 ใบ" / "ต้องเลือกใบสำคัญ 1-5000 ใบ (เลขที่ห้ามว่าง)" / "ต้องระบุช่วงวันที่ (YYYY-MM-DD)"
**เกิดตอน:** หน้าจอ ผ่านรายการ (ผ่านรายการ = ทำเครื่องหมายว่าใบสำคัญตรวจแล้ว)
**สาเหตุ:**

| ข้อความ | แปลว่า | แก้ |
|---|---|---|
| "ไม่พบผังบัญชี" | มีบรรทัดใช้รหัสบัญชีที่ไม่มีในผัง | [[ts-gl-account-not-found]] |
| "รหัสบัญชีผิดประเภท" | มีบรรทัดใช้บัญชีหลัก | [[ts-gl-control-account-used]] |
| "ยอดไม่ Balance" | เดบิตไม่เท่าเครดิต | [[ts-gl-debit-credit-not-equal]] |
| "ผ่านรายการแล้ว" | ใบนี้ผ่านไปแล้ว (ยังติ๊กได้ แต่กดผ่านซ้ำก็ไม่นับเพิ่ม) | ไม่ต้องทำอะไร ถ้าต้องการถอนสถานะใช้ ยกเลิกผ่านรายการ |
| "กรุณาเลือกใบสำคัญอย่างน้อย 1 ใบ" | ยังไม่ได้ติ๊ก | ติ๊กใบที่ต้องการ |
| "ต้องเลือกใบสำคัญ 1-5000 ใบ (เลขที่ห้ามว่าง)" | เลือกเกิน 5000 ใบต่อครั้ง | แบ่งช่วงวันที่ให้แคบลง |
| "ต้องระบุช่วงวันที่ (YYYY-MM-DD)" | วันที่เริ่ม/สิ้นสุดว่างหรือผิด | ใส่ช่วงวันที่ |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. อ่านหมายเหตุของใบที่ติ๊กไม่ได้ แล้วแก้ตามตาราง
2. แก้ใบสำคัญใน ข้อมูลรายวัน หรือเอกสารต้นทาง แล้วกลับมาที่หน้าจอผ่านรายการ ดึงข้อมูลใหม่
3. ติ๊กแล้วกด ผ่านรายการ อีกครั้ง

**ส่งต่อทีมงานเมื่อ:** ใบที่หมายเหตุว่างแต่ยังขึ้น ผ่านรายการไม่ได้
