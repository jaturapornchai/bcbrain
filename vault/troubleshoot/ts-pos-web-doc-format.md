# รูปแบบเลขที่บิลของเครื่อง POS ไม่ผ่าน

**อาการ:** กดบันทึกเครื่อง POS แล้วขึ้นข้อความตามด้านล่าง บันทึกไม่สำเร็จ
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรหัสเครื่อง POS

## ข้อความที่พบ
| ข้อความ | สาเหตุ | วิธีแก้ |
|---|---|---|
| รูปแบบเลขที่บิลของเครื่อง POS ต้องมี # สำหรับเลขลำดับ เช่น ABB1-@YY@MM-##### | ช่องรูปแบบเลขที่บิลไม่มีเครื่องหมาย # ระบบจึงไม่รู้ว่าเลขลำดับอยู่ตรงไหน | ใส่ # แทนหลักเลขลำดับ ยิ่งใส่มากยิ่งเลขยาว เช่น ##### = 5 หลัก |
| รูปแบบเลขที่บิล ... ซ้ำกับเครื่อง ... — ตั้งให้แต่ละเครื่องไม่ซ้ำกัน (เช่น ABB1-@YY@MM-#####) เพื่อไม่ให้เลขบิลชนกันตอนขายออฟไลน์ | มีอีกเครื่องใช้รูปแบบเดียวกันอยู่ | เปลี่ยนส่วนหน้าของเลขให้ต่างกัน เช่น เครื่อง 1 ใช้ ABB1-... เครื่อง 2 ใช้ ABB2-... |

## ทำไมต้องไม่ซ้ำ
แต่ละเครื่องรันเลขลำดับของตัวเองและขายต่อได้แม้ออฟไลน์ ถ้าสองเครื่องใช้รูปแบบเดียวกัน จะออกเลขที่บิลเดียวกันได้ ตอนบิลขึ้นระบบ บิลที่สองจะถูกปฏิเสธ ("เลขที่บิล ... ซ้ำกับบิลอื่น") ดู [[ts-pos-web-bill-error]]
