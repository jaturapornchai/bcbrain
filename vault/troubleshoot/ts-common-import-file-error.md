# นำเข้าไฟล์ไม่สำเร็จ หรือข้อมูลที่นำเข้าเพี้ยน

**ข้อความที่เห็น:**
- "ไม่พบข้อมูลผังบัญชีที่ถูกต้องใน CSV" หรือ "นำเข้าผังบัญชีไม่สำเร็จ"
- "ไม่พบรายการในไฟล์" / "อ่านไฟล์ไม่ได้" / "นำเข้าได้รวมไม่เกิน 5000 รายการ (ไฟล์นี้ ... รายการ)"
- "ไฟล์ JSON ไม่ใช่โครงสร้างแบบฟอร์ม BC FormDesign" / "อ่านไฟล์ JSON ไม่สำเร็จ กรุณาตรวจสอบรูปแบบไฟล์"
- "ไฟล์ JSON ไม่ถูกต้อง: ..."
- หรือไม่มีข้อความผิดพลาด แต่ชื่อภาษาไทยที่นำเข้าเป็นตัวอักษรแปลกๆ

**เกิดตอน:** กด "นำเข้า CSV" ในหน้าจอผังบัญชี, "นำเข้าไฟล์" ในหน้าจอปรับราคาสินค้า, นำเข้าแบบฟอร์ม หรือนำเข้ารายงาน

**สาเหตุ:**
- ไฟล์ผังบัญชีไม่มีแถวที่มีทั้งรหัสบัญชีและชื่อบัญชี หรือคอลัมน์สลับลำดับ
- ไฟล์ผังบัญชีบันทึกจาก Excel แบบ CSV ธรรมดา ไม่ใช่ CSV UTF-8 ระบบอ่านผังบัญชีแบบ UTF-8 เท่านั้น ภาษาไทยจึงเพี้ยน
- ไฟล์ราคาสินค้าว่าง เป็นไฟล์ Excel ที่ยังไม่ได้บันทึกเป็นไฟล์ข้อความ หรือมีรายการเกิน 5,000 รายการ
- ไฟล์แบบฟอร์มหรือรายงานไม่ได้ส่งออกจากระบบนี้ หรือไฟล์ถูกแก้จนเสียรูปแบบ

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ผังบัญชี: กด "ส่งออก CSV / Excel" ก่อน เพื่อได้ไฟล์ตัวอย่างที่ถูกรูปแบบ แก้ข้อมูลในไฟล์นั้น แล้วใน Excel เลือกบันทึกเป็น "CSV UTF-8" จากนั้นนำเข้าใหม่
2. ผังบัญชี: ตรวจว่าคอลัมน์แรกเป็นรหัสบัญชี คอลัมน์ที่สองเป็นชื่อบัญชี และไม่มีแถวว่างที่ไม่มีชื่อ (รหัสบัญชีที่มีอยู่แล้ว ระบบจะแก้ชื่อและค่าต่างๆ ตามไฟล์ ส่วนรหัสใหม่จะถูกเพิ่ม)
3. ราคาสินค้า: บันทึกจาก Excel เป็น CSV หรือไฟล์ข้อความแบบคั่นด้วย Tab ใส่หัวคอลัมน์ให้ตรงกับชื่อคอลัมน์บนหน้าจอ ถ้าเกิน 5,000 รายการให้แบ่งไฟล์
4. ราคาสินค้า: หลังนำเข้า ข้อมูลจะเข้าตารางก่อน กด "ตรวจราคาเก่า" เพื่อเทียบราคาเดิมได้ แล้วกด "บันทึก" และตอบยืนยัน "ปรับราคาสินค้า ... รายการ ใช่หรือไม่?" ถ้ายังไม่บันทึก ราคาจะยังไม่เปลี่ยน
5. แบบฟอร์มและรายงาน: ใช้ไฟล์ที่ส่งออกจากหน้าจอออกแบบแบบฟอร์มหรือออกแบบรายงานของระบบนี้เท่านั้น อย่าเปิดแก้ไฟล์ด้วยโปรแกรมอื่น

**ส่งต่อทีมงานเมื่อ:**
- ใช้ไฟล์ที่ส่งออกจากระบบเองแล้วยังนำเข้าไม่ได้
- ขึ้น "นำเข้าผังบัญชีไม่สำเร็จ" ซ้ำทั้งที่ไฟล์ถูกต้อง (แนบไฟล์และเวลาที่เกิด)
- ต้องการนำเข้าข้อมูลสินค้า ลูกค้า ผู้จำหน่าย หรือยอดยกมาจากไฟล์ เพราะตอนนี้ยังไม่มีหน้าจอนำเข้าแบบนี้
