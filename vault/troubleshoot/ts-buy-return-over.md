# ส่งคืนสินค้าไม่ได้ เพราะเกินจำนวนหรือเกินมูลค่าที่ซื้อ

**ข้อความที่เห็น:**
- "ส่งคืนเกินจำนวน : ..."
- "ส่งคืนเกินมูลค่า : ..."
- "ไม่พบหมายเลขบรรทัดที่อ้างอิง : ..."
- "ไม่พบรายการอ้างอิง : ... ..."

**เกิดตอน:** บันทึก ส่งคืนสินค้า/ลดหนี้ซื้อ (อ้างอิงใบซื้อ) หรือ ส่งคืนสินค้าจากการรับ (ทะยอยรับ) (อ้างอิงใบรับสินค้า)

**สาเหตุ:**
- จำนวนที่คืน มากกว่าจำนวนที่ซื้อหรือรับไว้ ลบด้วยที่คืนไปแล้วในใบคืนอื่น
- มูลค่าที่คืนในบรรทัดนั้น มากกว่ามูลค่าคงเหลือของบรรทัดในใบต้นทาง
- บรรทัดที่ดึงมาจากใบต้นทาง ไม่มีเลขบรรทัดอ้างอิง หรือถูกเปลี่ยนรหัสสินค้าเป็นตัวที่ไม่มีในใบต้นทาง
- ข้อควรรู้: บรรทัดที่พิมพ์เพิ่มเองโดยไม่ได้ดึงจากใบต้นทาง รุ่นปัจจุบันไม่ได้ตรวจว่าคืนเกินที่ซื้อ ให้ดึงจากใบต้นทางทุกครั้ง ถ้าพบว่าบันทึกคืนเกินไปแล้ว ให้ส่งต่อเจ้าหน้าที่

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิดใบซื้อหรือใบรับสินค้าต้นทาง ดูจำนวนที่ซื้อ และกด "Document Flow" ดูว่ามีใบคืนใบไหนอ้างถึงใบนี้แล้ว
2. ลดจำนวนหรือมูลค่าในบรรทัดที่แจ้ง ให้ไม่เกินยอดคงเหลือ
3. ถ้าเจอ "ไม่พบหมายเลขบรรทัดที่อ้างอิง" หรือ "ไม่พบรายการอ้างอิง" ให้ลบบรรทัดนั้น แล้วกด "ดึงเอกสาร" ดึงจากใบต้นทางใหม่ ([[howto-buy-reference-doc]])
4. ถ้าแค่ราคาผิดแต่ไม่ได้คืนของ ให้ใช้ประเภทแบบราคาผิดแทนการคืนสินค้า ([[howto-buy-return-credit-note]])

**ส่งต่อเจ้าหน้าที่เมื่อ:** ยอดที่คืนไม่เกินของที่ซื้อจริง แต่ยังบันทึกไม่ได้ หรือใบคืนเก่าที่ยกเลิกไปแล้วยังถูกนับ
