# เอกสารไม่ขึ้นในรายงานภาษีซื้อ/ภาษีขาย หรือขึ้นผิดเดือน

**ข้อความที่เห็น:** ไม่มีข้อความ แต่หาเอกสารในรายงานภาษีซื้อ/ภาษีขายไม่เจอ หรือไปขึ้นเดือนอื่น
**เกิดตอน:** เปิดรายงานภาษีมูลค่าเพิ่ม (ภ.พ.30) หลังบันทึกเอกสารหรือใบสำคัญ
**สาเหตุ:**
- หัวเอกสารเลือก ภาษี: ไม่กระทบภาษี ระบบไม่สร้างแถวภาษีเลย
- เอกสาร ยกเว้นภาษี ไม่ขึ้นในรายงานแบบปกติ (รายงานปกติแสดงเฉพาะแยกนอกและรวมใน)
- รายงานดึงตาม เดือนภาษี/ปีภาษี ของแถวภาษี ไม่ใช่วันที่เอกสาร ถ้าแถวภาษีใส่เดือนอื่น จะไปขึ้นเดือนนั้น
- แถวภาษีที่บันทึกเองแต่ไม่ได้ใส่เลขที่ใบกำกับ ระบบไม่เก็บแถวนั้น
- ใบสำคัญที่ลงค่าใช้จ่ายเองใน ข้อมูลรายวัน แต่ไม่ได้กรอกแท็บภาษีซื้อ ระบบไม่รู้ว่ามีภาษี
- ภาษีซื้อในข้อมูลรายวันที่เลือก ประเภทภาษี ไม่ถึงกำหนดชำระ ยังไม่ขึ้นในรายงานภาษีซื้อแบบปกติ (ขึ้นเฉพาะรายงานแบบแสดงมูลค่าอัตราภาษีศูนย์)
- รายงานสรุปภาษี ฝั่งภาษีซื้อ รุ่นปัจจุบันไม่นับเอกสารซื้อที่หัวเอกสารเป็น ภาษี: รวมใน หรือ ยกเว้นภาษี และแถวที่ ประเภทภาษี ไม่ใช่ ปรกติ

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เปิดเอกสาร ดูช่อง ภาษี: ที่หัวเอกสาร ถ้าเป็น ไม่กระทบภาษี แต่จริงๆ มีภาษี ให้แก้แล้วบันทึกใหม่
2. ไปแท็บภาษีของเอกสารหรือใบสำคัญ ตรวจ เลขที่ใบกำกับ เดือนภาษี ปีภาษี และ ประเภทภาษี
3. อยากเห็นเอกสารยกเว้นภาษี ให้เปิดรายงานแบบ (แสดงมูลค่าอัตราภาษีศูนย์)
4. ใบสำคัญที่บันทึกเอง ให้กรอกแท็บภาษีซื้อ/ภาษีขาย ([[howto-tax-journal-tax-tabs]])
5. เปิดรายงานใหม่ ใส่ช่วงวันที่ให้ครอบเดือนภาษีที่ต้องการ
6. ยอดภาษีซื้อในรายงานสรุปภาษีน้อยกว่ารายงานภาษีซื้อ ให้ใช้ยอดจากรายงานภาษีซื้อไปก่อน

**ส่งต่อทีมงานเมื่อ:** แถวภาษีครบและเดือนภาษีถูก แต่รายงานยังไม่แสดง หรือลูกค้าต้องใช้ยอดภาษีซื้อจากรายงานสรุปภาษีที่ไม่ตรง
