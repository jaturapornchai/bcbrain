# ปิดบิลไม่ได้: ไม่พบรหัสสินค้า

**อาการ:** กดรับชำระเงินและปิดบิล (หรือส่งใบรับของเข้าบิลซื้อ) แล้วขึ้น **"ไม่พบรหัสสินค้า : (รหัส)"**

**สาเหตุ:** บรรทัดในใบงานใช้รหัสสินค้าที่ไม่มีในข้อมูลสินค้าของระบบบัญชี มักมาจากปุ่มเบิกด่วน 1 คลิก หรือรายการตัวอย่างที่ติดมากับใบใหม่ ซึ่งใช้รหัสตัวอย่าง

## วิธีแก้
1. ดูรหัสที่ระบุในข้อความ
2. ถ้าสินค้าจริงมีอยู่แล้ว: เข้าใบงาน ลบบรรทัดนั้น แล้วเพิ่มใหม่โดยกดปุ่มค้นหาข้าง "รหัสสินค้า BC" เลือกสินค้าจากรายการ [[howto-autocare-add-parts-labor]]
3. ถ้าสินค้ายังไม่มี: ให้ฝ่ายบัญชีเพิ่มข้อมูลสินค้าในระบบบัญชีก่อน แล้วกลับมาปิดบิลใหม่
4. ปิดบิลซ้ำ ใบงานที่ยังไม่ปิดสำเร็จไม่เสียข้อมูล

## ตรวจว่าแก้แล้ว
ปิดบิลสำเร็จและขึ้นเลขที่ใบกำกับภาษีขาย
