# ใบสำคัญใช้รหัสบัญชีที่ไม่มีในผังบัญชี (ไม่พบผังบัญชี)

**ข้อความที่เห็น:**
- หน้าจอ ผ่านรายการ คอลัมน์ หมายเหตุ ขึ้น "ไม่พบผังบัญชี" และติ๊กเลือกใบนั้นไม่ได้
- หน้าจอ ตรวจสอบความถูกต้อง หัวข้อ "ตรวจสอบรายวันย่อยที่ไม่มีผังบัญชี" ตามด้วยแถว "พบข้อผิดพลาด" รายละเอียด "วันที่: ... เลขที่เอกสาร: ... สมุดรายวัน: ... รหัสผังบัญชีที่ไม่พบ: ..."

**เกิดตอน:** ผ่านรายการ หรือตรวจสอบความถูกต้อง (ผังบัญชี = รายการรหัสบัญชีทั้งหมดของกิจการ)
**สาเหตุ:**
- ตอนบันทึกใบสำคัญใน ข้อมูลรายวัน ระบบยังไม่ตรวจว่ารหัสบัญชีมีในผังหรือไม่ จึงบันทึกรหัสที่พิมพ์ผิดได้
- เอกสารที่ยังไม่ได้ผูกบัญชีไว้ที่รูปแบบเอกสาร ระบบลงบัญชีแบบมาตรฐานด้วยรหัสที่ระบบกำหนด ถ้าผังบัญชีไม่มีรหัสนั้น ระบบยังลงรหัสนั้นไว้ (เช่น ใช้แม่แบบผังบัญชี TFRS ชุดธุรกิจบริการ ยอดขายจะลงรหัสที่ไม่มีในผัง)
- บัญชีที่ผูกไว้ในรูปแบบเอกสาร ถูกลบออกจากผัง (ระบบไม่ตรวจจุดนี้ก่อนลบ) หรือถูกเปลี่ยนรหัสด้วยเมนู เปลี่ยนรหัสผังบัญชี (เมนูนั้นไม่ได้ตามแก้รูปแบบเอกสาร) แล้วมีการลงบัญชีจากเอกสารใหม่
- ส่วนใบสำคัญที่บันทึกไว้ก่อนแล้ว ปกติไม่ได้เกิดจากการลบหรือเปลี่ยนรหัส เพราะบัญชีที่ถูกใช้ในใบสำคัญลบไม่ได้ และการเปลี่ยนรหัสตามแก้ใบสำคัญให้แล้ว

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. จดเลขที่เอกสารและรหัสบัญชีที่ขึ้นในข้อความ
2. ถ้าเป็นรหัสที่พิมพ์ผิดในใบสำคัญที่บันทึกเอง เปิดใบนั้นใน ข้อมูลรายวัน แก้เป็นรหัสที่ถูก แล้วบันทึก
3. ถ้าเป็นใบที่ระบบลงจากเอกสาร ให้ผูกบัญชีที่ถูกต้องที่รูปแบบเอกสาร ([[howto-gl-doc-format-posting]]) หรือเพิ่มรหัสนั้นในผังบัญชี ([[howto-gl-chart-of-accounts]]) แล้วสั่ง ประมวลผลจากข้อมูลรายวัน ([[howto-gl-process-from-documents]])
4. กลับไปตรวจสอบหรือผ่านรายการใหม่

**ส่งต่อทีมงานเมื่อ:** ไม่รู้ว่ารหัสนั้นควรเป็นบัญชีอะไร หรือพบจำนวนมากหลังเปลี่ยนรหัสบัญชี หรือหลังใช้แม่แบบผังบัญชี TFRS
