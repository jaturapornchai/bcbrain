# แอปมือถือ AutoCare ขึ้น "เชื่อมต่อ API ขัดข้อง" หรือ "คำสั่งไม่สำเร็จ"

**ข้อความที่เห็น:** ข้อความสีเข้มเด้งขึ้นด้านล่างจอประมาณ 3 วินาทีแล้วหายไป
- "เชื่อมต่อ API ขัดข้อง: ..." (ตอนโหลดข้อมูล เมื่อต่อเครือข่ายไม่ถึงเซิร์ฟเวอร์)
- "คำสั่งไม่สำเร็จ (...)" โดยในวงเล็บเป็นเพียงตัวเลขรหัสตอบกลับจากระบบ ไม่บอกสาเหตุ (ตอนกดบันทึก)
- "เกิดข้อผิดพลาด: ..." (ตอนกดบันทึกแล้วเครือข่ายหลุด)

**เกิดตอน:** เปิดแอป กดปุ่มซิงก์ หรือกดบันทึกงานต่างๆ

**สาเหตุ (พบบ่อย):**
- มือถือ/แท็บเล็ตต่อเครือข่ายไม่ถึงเซิร์ฟเวอร์ (แอปไม่มีโหมดออฟไลน์)
- ล็อกอิน BC Account หมดอายุ หรือยังไม่ได้ล็อกอิน (ถ้าเป็นเช่นนี้แอปอาจเข้าฐานข้อมูลสาธิตแทน ดูป้าย DB) และถ้าระบบปฏิเสธการโหลดข้อมูล แอปจะไม่แจ้งอะไร หน้าจอแค่ว่างหรือค้างข้อมูลเดิม
- ข้อมูลที่กรอกไม่ครบ เช่น ไม่ได้ใส่ทะเบียนรถตอนเปิดใบรับรถ แอปจะขึ้นแค่ "คำสั่งไม่สำเร็จ" พร้อมตัวเลข ไม่บอกว่าขาดช่องไหน

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ตรวจสัญญาณเน็ต/ไวไฟของเครื่อง แล้วกดปุ่มซิงก์ (ไอคอนลูกศรวนมุมขวาบน) ซ้ำ
2. ดูป้าย "DB: ..." ที่หัวจอ ถ้าไม่ใช่ชื่อฐานข้อมูลของร้าน ให้ล็อกอิน BC Account ของร้านที่เครื่องเดียวกัน แล้วเปิดแอปใหม่
3. ถ้ากดบันทึกแล้วขึ้น "คำสั่งไม่สำเร็จ" ให้ตรวจช่องที่ต้องกรอก (เช่น ทะเบียนรถ) แล้วกดใหม่ อย่ากดซ้ำหลายครั้งติดกัน เพราะอาจเปิดใบงานซ้ำ ให้ตรวจที่เว็บ AutoCare ก่อนว่ามีใบเกิดขึ้นแล้วหรือไม่
4. ถ้าข้อมูลในแอปดูเก่า รอสักครู่ แอปดึงข้อมูลใหม่เองทุกประมาณ 8 วินาที หรือกดซิงก์เอง

**ส่งต่อทีมงานเมื่อ:** ล็อกอินบนเว็บได้ปกติและเน็ตดี แต่แอปยังขึ้นข้อความเดิมทุกครั้ง หรือเข้าฐานข้อมูลสาธิตทั้งที่ล็อกอินแล้ว
