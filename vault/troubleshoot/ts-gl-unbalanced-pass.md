# แก้ปัญหาเดบิต-เครดิตไม่สมดุล ผ่านรายการบัญชีไม่ได้ และปิดบัญชีไม่สำเร็จ

รวมสาเหตุและวิธีแก้ไขเมื่อระบบแจ้งเตือนความไม่สมดุลทางบัญชี ใบสำคัญผ่านรายการไม่ได้ หรือสั่งปิดงวด/ปิดบัญชีสิ้นปีไม่ผ่าน

## 1. ยอดเดบิตและเครดิตไม่เท่ากัน

- **ข้อความบนหน้าจอ:**
  - **"ยอดเดบิต (...) และเครดิต (...) ไม่เท่ากัน"**
  - **"ยอดเดบิต (...) ไม่เท่ากับเครดิต (...) ในแท็บบัญชีแยกประเภท"**
  - **"รายการบัญชีไม่สมดุล เดบิต ... ≠ เครดิต ..."**
  - **"เอกสาร <เลขที่>: รายการบัญชีตามรูปแบบ GL (<รหัส>) ไม่สมดุล เดบิต ... เครดิต ..."**
- **วิธีแก้ไข:**
  1. ตรวจบรรทัดบันทึกบัญชีในแท็บ **บัญชีแยกประเภท** ของเอกสารหรือสมุดรายวัน ว่ามีช่องใดลืมกรอกจำนวนเงิน หรือผลต่างจากการปัดเศษทศนิยม (เช่น เศษภาษี/ส่วนลด 0.01 บาท) หรือไม่
  2. หากเกิดจาก **รูปแบบการลงบัญชีอัตโนมัติ (รูปแบบ GL)** ให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า** ผังบัญชีตั้งต้นของกลุ่มสินค้า กลุ่มลูกหนี้/เจ้าหนี้ หรือรายการบัญชีภาษีในรูปแบบนั้น

## 2. เอกสารไม่ลงบัญชีอัตโนมัติ

- **ข้อความบนหน้าจอ:** **"เอกสาร <เลขที่>: ไม่พบงวดบัญชีที่เปิดอยู่ของวันที่ <วันที่> จึงไม่ลงบัญชีตามรูปแบบ GL (<รหัส>)"**
- **สาเหตุและวิธีแก้:** เอกสารบันทึกได้ในบางกรณี แต่งวดบัญชีของวันที่นั้นยังไม่เปิดใช้งาน จึงยังไม่สร้างรายการบัญชีรายวันอัตโนมัติ ให้ตรวจงวดบัญชี (ดู [[ts-common-period-closed]]) แล้วประมวลผลลงบัญชีใหม่

## 3. ผ่านรายการบัญชี (Pass) ไม่สำเร็จ และผลตรวจสอบ 8 จุด

- **ข้อความบนหน้าจอ:** **"ใบสำคัญ <เลขที่> ผ่านรายการไม่ได้: <หมายเหตุ>"**
- ระบบเมนู **ตรวจสอบ ผ่านรายการ และประมวลผลบัญชี** จะตรวจความสมบูรณ์ก่อนปิดงวดใน 8 ด้านต่อไปนี้:
  1. **ขาดรหัสรูปแบบเอกสาร** — เอกสารต้นทางไม่ได้ผูกรหัสเอกสาร
  2. **ขาดรหัสผังบัญชี** — มีรายการที่ยังไม่ได้เลือกรหัสผังบัญชี
  3. **ใช้ผังบัญชีหลักแทนบัญชีย่อย** — ระบบบังคับให้ลงบัญชีใน **บัญชีย่อย (บัญชีระดับล่างสุด)** เท่านั้น ห้ามลงที่บัญชีคุม/ผังบัญชีหลัก
  4. **เดบิตไม่เท่ากับเครดิต** — มียอดใบสำคัญรายวันที่ไม่สมดุล
  5. **ขาดหัวเอกสารสมุดรายวัน** — พบรายการบัญชีรายวันที่ไม่มีหัวเอกสาร
  6. **ขาดรหัสสมุดรายวัน** — เอกสารไม่ได้กำหนดสมุดรายวัน
  7. **เอกสารสินค้า/ซื้อ-ขาย ยังไม่ผ่านเข้าบัญชี** — มีเอกสารรายวันที่ยังไม่ได้ประมวลผลลงบัญชี
  8. **เอกสารรับ-จ่ายชำระหนี้ ยังไม่ผ่านเข้าบัญชี** — มีใบรับ/จ่ายชำระหนี้ที่ยังค้างส่งเข้าบัญชี

**วิธีแก้ไข:** เปิดแก้ไขใบสำคัญที่ระบบแจ้งเตือนเพื่อเปลี่ยนรหัสบัญชีจากผังบัญชีหลักเป็น **บัญชีย่อย** หรือปรับยอดเดบิต-เครดิตให้สมดุล จากนั้นกดประมวลผลผ่านรายการใหม่อีกครั้ง

## 4. ปัญหาปิดบัญชี (ปิดรายได้-ค่าใช้จ่ายเข้ากำไรสะสม / สิ้นปี)

- **"ไม่มียอดรายได้/ค่าใช้จ่ายในช่วงวันที่ ... ถึง ..."** — ช่วงวันที่ที่เลือกไม่มีรายการหมวดรายได้หรือค่าใช้จ่ายให้ปิดยอด ให้ตรวจช่วงวันที่หรือตรวจว่าได้กด **ผ่านรายการ** ครบหรือยัง
- **"ไม่พบบัญชีที่ปิดเข้า <รหัส> (ต้องเป็นบัญชีย่อย)"** — รหัสบัญชีกำไรสะสมที่เลือกปิดยอดเข้าไม่ใช่บัญชีย่อย หรือไม่มีอยู่ในผังบัญชี ให้เปลี่ยนเป็นบัญชีย่อยที่ถูกต้อง
- **"เลขที่เอกสาร <เลขที่> ถูกใช้กับเอกสารอื่นแล้ว"** — เลขที่ใบสำคัญปิดบัญชีซ้ำกับใบสำคัญเดิมที่มีอยู่ ให้เปลี่ยนเลขที่เอกสารปิดบัญชีใหม่
