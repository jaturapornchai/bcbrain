# กดดึงเอกสารแล้วไม่เจอใบสั่งซื้อหรือใบซื้อที่ต้องการ

**ข้อความที่เห็น:**
- "ไม่พบเอกสารอ้างอิงในระบบ"
- "เอกสาร ... ไม่มีรายการคงเหลือให้ดึง"

**เกิดตอน:** กดปุ่ม "ดึงเอกสาร" ในหน้าจอซื้อ ส่งคืน เพิ่มหนี้ รับสินค้า หรือตั้งหนี้

**สาเหตุ (เช็กทีละข้อ):**
- ยังไม่ได้เลือกรหัสเจ้าหนี้ที่หัวเอกสาร หรือเลือกคนละรายกับในใบต้นทาง (ยกเว้นใบสั่งซื้อที่ดึงใบเสนอซื้อ ซึ่งเห็นใบเสนอซื้อของทุกเจ้าหนี้)
- ประเภทภาษีที่หัวเอกสาร ไม่ตรงกับใบต้นทาง (เช่น ใบสั่งซื้อเป็น แยกนอก แต่ใบซื้อเลือก รวมใน) ยกเว้น ใบสั่งซื้อที่ดึงใบเสนอซื้อ, ตั้งหนี้ซื้อจากการรับสินค้า และ ส่งคืนสินค้าจากการรับ ที่ไม่เทียบประเภทภาษี
- ใบต้นทางถูกยกเลิกไปแล้ว หรือถูกใช้ครบแล้ว (เรื่องใช้ครบ มีผลเฉพาะตอนดึงใบเสนอซื้อ ใบสั่งซื้อ และใบรับสินค้า ส่วนใบส่งคืนและใบเพิ่มหนี้ยังเห็นใบเดิมเสมอ)
- ใบเสนอซื้อที่บันทึกไม่อนุมัติไว้ จะไม่ขึ้นให้ใบสั่งซื้อดึง
- เปิดข้อเลือก "อ้างอิงเอกสารสั่งซื้อที่อนุมัติแล้วเท่านั้น" แต่ใบสั่งซื้อยังไม่ได้อนุมัติ
- ผู้ใช้ถูกจำกัดให้เห็นเฉพาะเอกสารสาขาตัวเอง แต่ใบต้นทางอยู่สาขาอื่น
- เลือกเมนูผิดชนิด เช่น ใบที่รับของแบบทะยอยรับ ต้องตั้งหนี้ด้วยเมนู ตั้งหนี้ซื้อจากการรับสินค้า ไม่ใช่ ซื้อสินค้า/ตั้งหนี้ซื้อ

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ตรวจรหัสเจ้าหนี้และประเภทภาษีที่หัวเอกสาร ให้ตรงกับใบต้นทาง แล้วกด "ดึงเอกสาร" ใหม่
2. เปิดใบต้นทาง กด "Document Flow" ดูว่าถูกใช้ครบหรือถูกยกเลิกแล้วหรือยัง
3. ถ้าใบสั่งซื้อยังไม่อนุมัติ ให้ผู้มีสิทธิ์อนุมัติที่เมนู อนุมัติใบสั่งซื้อสินค้า ก่อน ([[howto-buy-purchase-order]])
4. ถ้าเป็นเรื่องสาขา ให้ผู้ใช้ที่มีสิทธิ์สาขานั้นทำเอกสารแทน
5. ตรวจว่าใช้เมนูถูกชนิด ตามตารางใน [[howto-buy-reference-doc]]

**ส่งต่อเจ้าหน้าที่เมื่อ:** ทุกข้อด้านบนถูกต้องแล้ว แต่ใบต้นทางยังไม่ขึ้นในรายการ
