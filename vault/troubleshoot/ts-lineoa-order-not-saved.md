# กดเปิดบิลในแชท LINE OA แล้วขึ้นสำเร็จ แต่หาออเดอร์ไม่เจอ

**ข้อความที่เห็น:** "✅ เปิดบิลขาย ... สำเร็จ!" และ "บันทึกออเดอร์ของ ... ลงฐานข้อมูล ... และส่งใบงานเข้าคลัง WMS เรียบร้อย"

**เกิดตอน:** กดปุ่มเขียว "ยืนยันเปิดบิลขายจริง" บนการ์ดในแชท

**สาเหตุ:** ข้อความสำเร็จขึ้นทุกครั้งโดยไม่ตรวจผลจริง และจากการตรวจโค้ด **ไม่มีการสร้างออเดอร์หรือบันทึกกิจกรรมลูกค้าจริง** เลขที่ที่เห็นบนจอสร้างขึ้นเอง ดู [[howto-lineoa-confirm-order-card]]

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. อย่าถือว่าออเดอร์เกิดแล้ว ให้ตรวจในรายการเอกสารขาย
2. ถ้าไม่พบ ให้ออกเอกสารจากเมนูขายตามปกติ: [[howto-sale-overview]]
3. ถ้าลูกค้าสั่งผ่านตลาด B2B ใช้ [[sys-market-overview]]

**ส่งต่อทีมงานเมื่อ:** ต้องการให้ปุ่มนี้สร้างออเดอร์จริง (เป็นงานแก้ระบบ)
