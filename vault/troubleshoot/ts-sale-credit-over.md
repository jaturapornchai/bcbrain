# บันทึกใบขายไม่ได้ ขึ้น "ยอดวงเงินเครดิตของลูกค้า เกินที่กำหนดไว้"

**ข้อความที่เห็น:** "ยอดวงเงินเครดิตของลูกค้า เกินที่กำหนดไว้" หรือแบบถาม "ยอดวงเงินเครดิตของลูกค้า เกินที่กำหนดไว้ ต้องการดำเนินการต่อหรือไม่" หรือขึ้นหน้าต่าง "ขออนุมัติวงเงินเครดิต"

**เกิดตอน:** กด "บันทึก" ใบขายประเภท "ขายเชื่อ (เครดิต)" ใบตั้งหนี้อื่นๆ ของลูกหนี้ หรือรายได้อื่นๆ แบบเงินเชื่อ

**สาเหตุ:** หนี้ที่ลูกค้าค้างอยู่ บวกยอดบิลนี้ เกิน "วงเงินสินเชื่อ" ที่ตั้งไว้ในรายละเอียดลูกหนี้
- ถ้าเปิด "วงเงินเครดิตรวมเช็คคงค้าง" เช็ครับที่ยังไม่ผ่านก็ถูกนับเป็นหนี้ด้วย
- ถ้าเปิด "วงเงินเครดิตรวมรายการมัดจำ" เงินมัดจำและเงินรับล่วงหน้าที่ลูกค้าวางไว้และยังไม่ได้ใช้ ถูกหักออกจากหนี้
- ข้อความแบบถาม = เปิดแค่ "เตือนเกินวงเงินเครดิต" / ข้อความห้าม = เปิด "ห้ามขายเกินวงเงินเครดิต"
- หน้าต่าง "ขออนุมัติวงเงินเครดิต" = เปิด "ห้ามขายเกินวงเงินเครดิต" คู่กับ "ใช้ระบบรหัสผ่านอนุมัติวงเงินเครดิต"

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ถ้าเป็นแบบถาม กดตกลงเพื่อบันทึกต่อได้เลย
2. ถ้าขึ้นหน้าต่าง "ขออนุมัติวงเงินเครดิต" ให้หัวหน้าที่มีสิทธิ์ใส่ "รหัสผู้อนุมัติ" และ "รหัสผ่าน" ของตัวเองแล้วกด "อนุมัติ"
3. ให้ลูกค้าชำระหนี้เก่าก่อน ([[howto-ar-receipt]]) แล้วบันทึกใบขายใหม่
4. หรือเพิ่ม "วงเงินสินเชื่อ :" ในรายละเอียดลูกหนี้ ([[howto-sale-credit-limit]])
5. หรือเปลี่ยนเป็น "ขายสด" รับเงินเต็มจำนวน ใบขายสดไม่ถูกตรวจวงเงิน

**ส่งต่อทีมงานเมื่อ:**
- ขึ้น "รหัสผู้อนุมัติหรือรหัสผ่านไม่ถูกต้อง" ทั้งที่ใส่ถูก (ผู้อนุมัติต้องมีสิทธิ์ "สามารถถอนอนุมัติวงเงินเครดิตลูกค้า")
- เปิด "ใช้ระบบขออนุมัติวงเงินเครดิต" คู่กับข้อเลือกเตือนหรือห้ามเกินวงเงิน ใบที่เกินวงเงินจะบันทึกไม่ได้ทุกกรณี (ไม่มีหน้าต่างใส่รหัสอนุมัติ) เพราะขั้นตอนขออนุมัติแบบนี้ยังไม่มีในระบบ
- ยอดหนี้ค้างที่ระบบนับดูไม่ตรงกับรายงานลูกหนี้
- ตั้งวงเงินเป็น 0 แล้วยังขึ้นข้อความนี้ (วงเงิน 0 ระบบไม่ตรวจวงเงินใบขาย)
