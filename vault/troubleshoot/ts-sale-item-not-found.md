# ใส่สินค้าในบิลขายไม่ได้ ขึ้น "ไม่พบรหัสสินค้า : ..." หรือ "สินค้า ... เลิกขาย"

**ข้อความที่เห็น:**
- "ไม่พบรหัสสินค้า : ..."
- "สินค้า ... เลิกขาย"
- "ไม่พบรหัสลูกค้า" (ตอนใส่สินค้าก่อนเลือกลูกค้า)

**เกิดตอน:** พิมพ์รหัสหรือบาร์โค้ดสินค้าในตารางของเอกสารขาย

**สาเหตุ:**
- "ไม่พบรหัสสินค้า" → รหัสหรือบาร์โค้ดที่พิมพ์ไม่มีในทะเบียนสินค้า หรือพิมพ์ผิด
- "เลิกขาย" → สินค้าตัวนี้ถูกติ๊ก "ระงับการขาย" ไว้ในหน้า ข้อมูลสินค้าเพิ่มเติม มีผลกับ ใบเสนอราคาขาย ใบสั่งจองสินค้า ใบสั่งขายสินค้า และ ขายสินค้า/บริการ
  - สินค้าที่ระงับการขายจะไม่ขึ้นในหน้าต่างค้นหาสินค้าของหน้าจอขายด้วย
- "ไม่พบรหัสลูกค้า" → ร้านเปิด "เตือนเลือกลูกค้าก่อนทำรายการ" ต้องเลือกลูกค้าก่อนใส่สินค้า (ใช้กับใบเสนอราคา ใบสั่งจอง ใบสั่งขาย ใบรับคืน และใบเพิ่มหนี้)

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. กดค้นหาสินค้าจากรายการแทนการพิมพ์รหัสเอง
2. ถ้าเป็นสินค้าใหม่ ให้เพิ่มในทะเบียนสินค้าก่อน ([[howto-stock-overview]])
3. ถ้าขึ้น "เลิกขาย" และจะกลับมาขาย ให้เอาติ๊ก "ระงับการขาย" ออกในหน้า ข้อมูลสินค้าเพิ่มเติม
4. ถ้าขึ้น "ไม่พบรหัสลูกค้า" ให้เลือก "ลูกหนี้/ลูกค้า" ในหัวเอกสารก่อน แล้วค่อยใส่สินค้า

**ส่งต่อทีมงานเมื่อ:**
- สินค้ามีในทะเบียนและไม่ได้ระงับการขาย แต่ยังขึ้น "ไม่พบรหัสสินค้า"
- ใส่สินค้าไม่ได้ทุกตัว ในทุกเอกสารขาย
