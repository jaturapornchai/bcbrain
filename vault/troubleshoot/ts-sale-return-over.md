# รับคืนสินค้า/ลดหนี้ไม่ได้ ขึ้น "ส่งคืนเกินจำนวน : ..." หรือ "ส่งคืนเกินมูลค่า : ..."

**ข้อความที่เห็น:** "ส่งคืนเกินจำนวน : ..." หรือ "ส่งคืนเกินมูลค่า : ..." (ต่อท้ายด้วยรหัสสินค้า)

**เกิดตอน:** บันทึกใบ รับคืนสินค้า/ลดหนี้ขาย ที่ดึงรายการมาจากใบขายเดิม

**สาเหตุ:**
- "ส่งคืนเกินจำนวน" → จำนวนคืนรวมทุกใบของบรรทัดนี้ มากกว่าจำนวนที่ขายไปในใบขายเดิม
  - ใบประเภท "ลดหนี้จากขายเงินเชื่อ (ไม่กระทบสต๊อก)" และ "ลดหนี้จากขายเงินสด (ไม่กระทบสต๊อก)" ที่ทำไว้ก่อน ไม่ถูกนับเป็นจำนวนคืน
- "ส่งคืนเกินมูลค่า" → มูลค่าที่รับคืน/ลดหนี้รวมทุกใบของบรรทัดนี้ มากกว่ามูลค่าในใบขายเดิม (นับทุกประเภทรวมกัน)
- ระบบเทียบจำนวนในหน่วยนับหลักของสินค้า

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ตรวจว่าบิลขายใบนี้เคยถูกรับคืนหรือลดหนี้ไปแล้วกี่ใบ (ดูจากใบรับคืนเดิมของลูกค้ารายนี้)
2. ลดจำนวนหรือมูลค่าในบรรทัดนั้นให้ไม่เกินที่เหลือ แล้วบันทึกใหม่
3. ถ้าใบรับคืนเดิมออกผิด ให้แก้หรือยกเลิกใบเดิมก่อน ([[howto-sale-cancel-docs]])
4. ถ้าเป็นการลดราคาเพราะคิดราคาผิด ไม่ได้คืนของ ให้เลือกประเภทแบบ "(ไม่กระทบสต๊อก)" ([[howto-sale-credit-note]])
5. ถ้าของที่คืนมาจากบิลขายหลายใบ ให้แยกบรรทัดตามบิลที่ขายจริง

**ส่งต่อทีมงานเมื่อ:**
- ยังไม่เคยมีใบรับคืนของบิลนี้เลย แต่ขึ้นข้อความ
- ยอดเกินเพียงเศษสตางค์จากการปัดเศษ
