# ยอดคงเหลือสินค้าในระบบไม่ตรงกับของจริง หรือไม่ตรงกับเอกสาร

**ข้อความที่เห็น:** ไม่มีข้อความ ยอดในหน้าจอสอบถามหรือในเอกสารดูผิด หรือติดลบ

**เกิดตอน:** ดูยอดคงเหลือ หรือหลังตรวจนับสินค้าจริง

**สาเหตุที่พบบ่อย:**
| สาเหตุ | อธิบาย |
|---|---|
| ดูยอดคนละวัน | ยอดคงเหลือคิด ณ ถึงวันที่ ที่เลือก เอกสารที่ลงวันที่หลังจากนั้นไม่นับ |
| ดูคนละคลังหรือที่เก็บ | ของอยู่อีกคลัง หรือตอนบันทึกเลือกที่เก็บผิด |
| เอกสารที่ไม่เปลี่ยนสต็อก | ใบขอเบิก ใบขอโอน ใบขอตรวจนับ ใบตรวจนับ ไม่เปลี่ยนยอด ([[faq-stock-count-change-stock]]) |
| เอกสารที่ยกเลิกแล้ว | ไม่นับในยอดอีก |
| ประเภทสินค้า | บริการ สินค้าให้เช่า สินค้าชุด สูตรสี ไม่มียอดคงเหลือ ([[faq-stock-service-not-in-stock]]) |
| ปล่อยให้ติดลบได้ | ปิดตัวเลือกห้ามติดลบ หรือแก้เอกสารเก่า หรือใช้ใบปรับปรุงลด ([[faq-stock-negative-allowed]]) |
| หน่วยนับ | ยอดในหน้าจอสอบถามเป็นหน่วยนับหลัก ถ้าตัวตั้ง/ตัวหารผิด จำนวนจะเพี้ยน ([[faq-stock-change-unit-after-use]]) |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูยอดตามคลังและที่เก็บ ณ วันที่ที่ถูกต้อง ([[howto-stock-inquiry-balance]])
2. เปิดเมนู สินค้า › สอบถามและวิเคราะห์ข้อมูลสินค้า (บนหน้าจอ) › เคลื่อนไหวสินค้า ของสินค้าตัวนั้น ไล่ยอดสะสมว่าเริ่มผิดที่เอกสารใบไหน ([[howto-stock-inquiry-movement]])
3. แก้หรือยกเลิกเอกสารที่ผิด ([[howto-stock-cancel-doc]]) หรือโอนย้ายให้ถูกคลัง ([[howto-stock-transfer]])
4. ถ้าเอกสารถูกหมดแล้ว แต่ยอดยังไม่ตรงกับผลรวมเอกสาร ให้ผู้ดูแลระบบใช้เมนู คำนวณยอดสต๊อกใหม่ กับสินค้าตัวนั้น ([[howto-stock-recalc]])
5. ถ้ายอดในระบบถูก แต่ของจริงหาย ให้ตรวจนับแล้วปรับปรุงสต็อก ([[howto-stock-count]], [[howto-stock-count-auto-adjust]])

**ส่งต่อทีมงานเมื่อ:** คำนวณยอดสต๊อกใหม่แล้วยอดยังไม่ตรงกับผลรวมในหน้าจอเคลื่อนไหวสินค้า หรือคำนวณไม่เสร็จ (ข้อมูลมาก ให้แบ่งช่วงรหัสสินค้าก่อน)
