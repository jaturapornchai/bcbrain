# ลบใบจ่ายเงินมัดจำหรือเงินล่วงหน้าไม่ได้

**ข้อความที่เห็น:**
- "ห้ามแก้ไข หรือลบข้อมูล"
- "เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้"
- ตอนยกเลิก: "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"

**เกิดตอน:** กด "ลบ" หรือยกเลิกใบจ่ายเงินมัดจำ ใบจ่ายเงินล่วงหน้า หรือใบยกมาของสองอย่างนี้

**สาเหตุ:**
- ใบมัดจำนี้ถูกใบซื้อหรือใบตั้งหนี้ตัดไปใช้แล้ว (แท็บ "ใช้เงินมัดจำ")
- หรือมีใบรับคืนจ่ายเงินมัดจำ / รับคืนจ่ายเงินล่วงหน้า อ้างถึงใบนี้แล้ว
- ข้อความ "ถูกนำไปใช้/รับคืนแล้ว..." บอกเลขที่เอกสารที่ใช้ใบนี้อยู่ ส่วน "ห้ามแก้ไข หรือลบข้อมูล" ไม่บอกเลขที่

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. จดเลขที่เอกสารที่ข้อความแจ้ง ถ้าข้อความไม่บอก ให้กด "Document Flow" ดูเอกสารที่ใช้ใบนี้
2. ถ้าเป็นใบซื้อหรือใบตั้งหนี้ ให้เปิดใบนั้น เอาบรรทัดในแท็บ "ใช้เงินมัดจำ" ออกแล้วบันทึก (หรือยกเลิกใบนั้น ถ้าผิดทั้งใบ)
3. ถ้าเป็นใบรับคืน ให้ลบหรือยกเลิกใบรับคืนนั้นก่อน
4. กลับมาลบหรือยกเลิกใบมัดจำอีกครั้ง

**ส่งต่อเจ้าหน้าที่เมื่อ:** เอกสารที่ข้อความแจ้งเปิดไม่เจอ หรือถูกยกเลิกไปแล้ว แต่ยังลบไม่ได้
