# บันทึกผังบัญชีไม่ได้ ขึ้นข้อความเตือน

**ข้อความที่เห็น:** ข้อความใดข้อความหนึ่งในตารางด้านล่าง (... คือรหัสที่ระบบหาไม่เจอ หรือรหัสบัญชีที่มีปัญหา)
**เกิดตอน:** กดบันทึกที่ รายละเอียดผังบัญชี หรือ ปรับปรุงผังบัญชีแบบเร็ว
**สาเหตุ:** ข้อมูลบัญชีไม่ครบ หรืออ้างถึงรหัสที่ไม่มีในระบบ

## หน้าจอ รายละเอียดผังบัญชี
| ข้อความ | แปลว่า | แก้ |
|---|---|---|
| "กรุณาระบุรหัส" | ยังไม่ได้ใส่รหัสบัญชี | ใส่รหัส |
| "รหัส ... มีอยู่แล้ว" | ตอนเพิ่มบัญชีใหม่ ใช้รหัสที่มีในผังแล้ว | เปลี่ยนรหัส หรือค้นหาบัญชีเดิมแล้วแก้แทน |
| "กรุณาระบุชื่อบัญชี" | ชื่อบัญชีว่าง | ใส่ชื่อ |
| "บัญชีหลักต้องไม่ใช่บัญชีเดียวกับตัวเอง" | ช่อง ผังบัญชีหลัก ใส่รหัสตัวเอง | ใส่รหัสบัญชีแม่ที่ถูก |
| "ไม่พบบัญชีหลัก: ..." | ช่อง ผังบัญชีหลัก ใส่รหัสที่ไม่มี | กดค้นหาเลือกจากรายการ หรือสร้างบัญชีแม่ก่อน |
| "ไม่พบบัญชีปิด: ..." | ช่อง ปิดเข้าบัญชี ใส่รหัสที่ไม่มี | เลือกบัญชีที่มีอยู่ หรือล้างช่องให้ว่าง |
| "ไม่พบกลุ่มบัญชี: ..." | ช่อง กลุ่มบัญชี ไม่มีในระบบ (รวมกรณีกลุ่มถูกลบไปแล้ว) | เลือกจากรายการ หรือสร้างกลุ่มก่อน ([[howto-gl-setup-book-group]]) |
| "ไม่พบกลุ่มกระแสเงินสด: ..." | ช่อง รหัสบัญชีกระแสเงินสด ไม่มีในระบบ (รวมกรณีกลุ่มถูกลบไปแล้ว) | เลือกจากรายการ หรือล้างช่องให้ว่าง |
| "ไม่พบรหัสที่เลือก: ..." | แท็บ หน่วยงาน แผนก การจัดสรร งาน หรือ โครงการ มีรหัสที่ไม่มีในระบบ | ลบแถวนั้น หรือเลือกใหม่จากรายการ |
| "เลือกรหัสซ้ำ: ..." | แท็บเดียวกันเลือกรหัสเดียวกัน 2 ครั้ง | ลบแถวที่ซ้ำ |

## หน้าจอ ปรับปรุงผังบัญชีแบบเร็ว
| ข้อความ | แปลว่า | แก้ |
|---|---|---|
| "แถวที่แก้ไขต้องมีรหัสบัญชี" | แถวที่แก้ไม่มีรหัส | ใส่รหัส หรือลบแถว |
| "บัญชี ...: กรุณาระบุชื่อบัญชี" | บัญชีนั้นไม่มีชื่อ | ใส่ชื่อ |

หน้าจอแบบเร็วไม่ตรวจรหัส ผังบัญชีหลัก กลุ่มบัญชี กลุ่มกระแสเงินสด และปิดเข้าบัญชี จึงบันทึกรหัสที่ไม่มีอยู่จริงได้ ถ้าภายหลังเปิดบัญชีนั้นในหน้าจอ รายละเอียดผังบัญชี แล้วกดบันทึก จะขึ้นข้อความ "ไม่พบ...: ..." ตามตารางบน

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. อ่านข้อความ แล้วแก้ช่องตามตาราง
2. ช่องที่เป็นรหัสอ้างอิง ให้กดค้นหาเลือก แทนการพิมพ์เอง
3. บันทึกใหม่

**ส่งต่อทีมงานเมื่อ:** ขึ้นข้อความอื่นที่ไม่อยู่ในตาราง หรือแก้ตามตารางแล้วยังบันทึกไม่ได้
