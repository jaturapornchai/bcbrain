# กด "ดึงเอกสาร" แล้วไม่เจอใบที่ต้องการ

**ข้อความที่เห็น:** "ไม่พบเอกสารอ้างอิงในระบบ" ในหน้าต่างเลือกเอกสาร หรือ "เอกสาร ... ไม่มีรายการคงเหลือให้ดึง" หลังเลือกใบ

**เกิดตอน:** กดปุ่ม "ดึงเอกสาร" ในใบขาย ใบสั่งขาย ใบสั่งจอง ใบรับคืน/ลดหนี้ หรือใบเพิ่มหนี้

**สาเหตุ:** ระบบแสดงเฉพาะใบที่เข้าเงื่อนไขทุกข้อ
- ลูกค้าในหัวเอกสารต้องเป็นรายเดียวกับใบต้นทาง ถ้ายังไม่เลือกลูกค้า จะไม่ขึ้นใบใดเลย
- ช่อง "ภาษี" (ประเภทภาษี) ต้องตรงกับใบต้นทาง เช่น ใบต้นทางแยกนอก ใบนี้ต้องแยกนอกด้วย
- ตอนเปิดใบขาย ใบที่ถูกดึงไปใช้ครบแล้วจะไม่ขึ้นอีก ส่วนหน้าจออื่นใบนั้นยังขึ้นให้เลือก แต่เลือกแล้วจะขึ้น "ไม่มีรายการคงเหลือให้ดึง"
- ตอนเปิดใบขาย ถ้าเปิด "เปิดใช้ระบบอ้างอิงใบสั่งจองที่อนุมัติแล้ว..." หรือ "เปิดใช้ระบบอ้างอิงใบสั่งขายที่อนุมัติแล้ว..." ใบที่ยังไม่อนุมัติจะไม่ขึ้น
- ถ้าบริษัทเปิด "ใช้ระบบสาขา" และเปิด "แสดงเอกสารเฉพาะสาขา" และพนักงานไม่มีสิทธิ์เปลี่ยนสาขา จะเห็นเฉพาะใบของสาขาตัวเอง

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. เลือกลูกค้าในหัวเอกสารให้ตรงกับใบต้นทางก่อน แล้วกด "ดึงเอกสาร" ใหม่
2. ตรวจช่อง "ภาษี" ให้ตรงกับใบต้นทาง
3. ถ้าใบต้นทางเป็นใบสั่งที่ยังไม่อนุมัติ ให้อนุมัติก่อน ([[howto-sale-order]])
4. ถ้าใบถูกดึงไปเปิดเอกสารอื่นครบแล้ว ตรวจว่าใบที่ดึงไปนั้นถูกต้องไหม ถ้าผิดให้แก้หรือยกเลิกใบนั้น ([[howto-sale-cancel-docs]])
5. ถ้าเป็นใบของสาขาอื่น ให้ผู้ใช้ที่ดูแลสาขานั้นทำ หรือให้ผู้ดูแลปรับสิทธิ์ ([[ts-common-no-permission]])

**ส่งต่อทีมงานเมื่อ:**
- ทุกเงื่อนไขตรงแล้ว แต่ใบยังไม่ขึ้น
- ใบต้นทางยังค้างอยู่จริง แต่ขึ้น "ไม่มีรายการคงเหลือให้ดึง"
