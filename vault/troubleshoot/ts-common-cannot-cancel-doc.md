# ยกเลิกเอกสารไม่ได้

**ข้อความที่เห็น:** (อย่างใดอย่างหนึ่ง)
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ถูกยกเลิกแล้ว"
- "ใบนี้ไม่มีรายการคงเหลือให้ยกเลิก"
- "ยังไม่มีรายการยกเลิก: กด ดึงรายการ แล้วใส่จำนวนยกเลิก"
- "กรุณาระบุเลขที่เอกสารอ้างอิง"
- "ไม่พบเอกสาร ..."
- "เลขที่เอกสาร ... ยาวเกิน 25 ตัวอักษร กรุณาแก้รูปแบบเลขที่เอกสาร"
- "เอกสาร... ถูกยกเลิกแบบเดิม คืนสถานะจากหน้านี้ไม่ได้"

**เกิดตอน:** กด "บันทึกยกเลิก" หรือ "คืนสถานะเอกสารปกติ" ในเมนูยกเลิกเอกสาร

**สาเหตุ:**
- เอกสารถูกเอกสารใบอื่นนำไปใช้ต่อแล้ว เช่น ใบขายที่ทำใบลดหนี้แล้ว บิลที่วางบิลหรือรับชำระแล้ว เงินมัดจำที่ถูกนำไปหักแล้ว
- ใบสั่งซื้อหรือใบสั่งขายที่ถูกนำไปใช้ครบทุกรายการแล้ว (ถ้าใช้ไปบางส่วน ยังยกเลิกส่วนที่ค้างได้)
- เอกสารนั้นถูกยกเลิกไปก่อนแล้ว
- ยกเลิกรายสินค้า แต่ยังไม่ได้ใส่จำนวนที่จะยกเลิก หรือไม่มีจำนวนค้างเหลือให้ยกเลิก
- ยังไม่ได้เลือกเอกสารที่จะยกเลิก
- รูปแบบเลขที่ของใบยกเลิกยาวเกิน 25 ตัวอักษร

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. กด "ค้นหาเอกสาร" เลือกเอกสารที่จะยกเลิกให้ถูกใบก่อน
2. ถ้าขึ้นว่ามีการอ้างอิงแล้ว ให้ดูชื่อเอกสารปลายทางในข้อความ หรือเปิดปุ่ม "Document Flow" ([[howto-common-document-flow]]) แล้วยกเลิกเอกสารปลายทางก่อน ไล่จากใบล่าสุดย้อนกลับมา
3. ถ้าเลือก "ยกเลิกรายสินค้า" ให้กดดึงรายการ แล้วใส่จำนวนที่จะยกเลิกไม่เกินจำนวนค้าง
4. ถ้าเลขที่ยาวเกิน ให้ Admin แก้รูปแบบเลขที่เอกสารของเมนูยกเลิกนั้นให้สั้นลง ดู [[howto-setup-doc-format]]
5. ถ้าติดงวดบัญชี ดู [[ts-common-period-closed]]

**ส่งต่อทีมงานเมื่อ:** ขึ้น "ถูกยกเลิกแบบเดิม คืนสถานะจากหน้านี้ไม่ได้" หรือขึ้น "เลขที่เอกสารยกเลิกซ้ำกับรายการบัญชีของเอกสารประเภทอื่นในวันเดียวกัน ..." หรือ Document Flow ไม่แสดงเอกสารปลายทางแต่ยังยกเลิกไม่ได้
