# เข้าสู่ระบบไม่ได้

**ข้อความที่เห็น:** (อย่างใดอย่างหนึ่ง)
- "ไม่สามารถเชื่อมต่อ Google Identity Services ได้ในขณะนี้"
- "Google ID Token ไม่ถูกต้องหรือหมดอายุ"
- "Google ID Token ไม่ได้ออกให้ระบบนี้"
- "อีเมล Google นี้ยังไม่ได้ยืนยัน"
- "กรุณาเข้าสู่ระบบด้วยปุ่ม Google"
- "เกิดข้อผิดพลาดในการเข้าสู่ระบบด้วย Google"
- "ยังไม่ได้ตั้งค่า Google OAuth Client ID สำหรับโดเมนนี้"

**เกิดตอน:** กดปุ่ม "เข้าสู่ระบบด้วยบัญชี Google" ที่หน้าเข้าสู่ระบบ

**สาเหตุ:** ระบบใช้ Google ยืนยันตัวตนอย่างเดียว ปัญหาส่วนใหญ่มาจาก
- เบราว์เซอร์บล็อกหน้าต่างหรือคุกกี้ของ Google หรือส่วนเสริมบล็อกโฆษณาไปบล็อกปุ่ม
- อินเทอร์เน็ตไม่เสถียร หรือหน้าเข้าสู่ระบบเปิดค้างไว้นานจนการยืนยันหมดอายุ
- บัญชี Google ยังไม่ได้ยืนยันอีเมล
- เปิดเว็บผ่านที่อยู่เว็บที่ไม่ถูกต้อง (เช่น ลิงก์สำรองหรือพิมพ์ชื่อเว็บผิด)

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. กดรีเฟรชหน้าเข้าสู่ระบบ แล้วกดปุ่ม Google ใหม่อีกครั้ง
2. ตรวจว่าเปิดเว็บจากที่อยู่เว็บที่ได้รับจากทีมงานจริง ไม่ใช่ลิงก์จากที่อื่น
3. อนุญาตป๊อปอัปและคุกกี้ของ Google ในเบราว์เซอร์ ปิดส่วนเสริมบล็อกโฆษณาชั่วคราว หรือลองหน้าต่างไม่ระบุตัวตน
4. ลองเบราว์เซอร์อื่น เช่น Chrome หรือ Edge รุ่นล่าสุด ดู [[faq-general-web-browser]]
5. ถ้าขึ้น "อีเมล Google นี้ยังไม่ได้ยืนยัน" ให้ยืนยันอีเมลที่บัญชี Google ก่อน แล้วเข้าใหม่
6. เข้าได้แล้วแต่ไม่เห็นฐานข้อมูลบริษัท ให้ตรวจว่าใช้อีเมลเดียวกับที่ Admin เพิ่มไว้ ดู [[howto-user-invite-member]]

**ส่งต่อทีมงานเมื่อ:** ขึ้น "ยังไม่ได้ตั้งค่า Google OAuth Client ID สำหรับโดเมนนี้" หรือทำครบทุกข้อแล้วยังเข้าไม่ได้ (แจ้งข้อความที่เห็น เบราว์เซอร์ที่ใช้ และเวลาที่เกิด ห้ามส่งรหัสผ่านให้ทีมงาน)
