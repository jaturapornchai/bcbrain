# ยกเลิกเอกสารขายไม่ได้

**ข้อความที่เห็น:**
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ถูกยกเลิกแล้ว"
- "เอกสาร... ถูกยกเลิกแบบเดิม คืนสถานะจากหน้านี้ไม่ได้"
- "เลขที่เอกสาร ... ยาวเกิน 25 ตัวอักษร กรุณาแก้รูปแบบเลขที่เอกสาร"
- "เลขที่เอกสารยกเลิกซ้ำกับรายการบัญชีของเอกสารประเภทอื่นในวันเดียวกัน กรุณาแก้รูปแบบเลขที่เอกสารของเมนูนี้ให้ไม่ซ้ำกับเมนูอื่น"

**เกิดตอน:** กด "บันทึกยกเลิก" หรือ "คืนสถานะเอกสารปกติ" ในเมนูยกเลิกเอกสารขายหรือเอกสารลูกหนี้

**สาเหตุ:**
- "มีการอ้างอิงไปแล้ว" → มีเอกสารที่ยังใช้งานอยู่อ้างถึงใบนี้ เช่น ใบขายที่มีใบรับคืน/ลดหนี้ ถูกวางบิล หรือรับชำระแล้ว, เงินมัดจำที่ถูกหักในใบขายแล้ว, ใบวางบิลที่ถูกใช้ในใบเสร็จแล้ว ระบบบอกเลขที่ใบที่อ้างอิงอยู่ในข้อความ
- "ปิดรายการไปแล้ว" → ใบสั่งจอง/ใบสั่งขายถูกดึงไปเปิดบิลครบทุกชิ้นแล้ว ไม่มีส่วนค้างให้ยกเลิก
- "ถูกยกเลิกแล้ว" → ใบนี้ยกเลิกไปก่อนแล้ว
- "ถูกยกเลิกแบบเดิม" → ใบนี้ถูกยกเลิกจากระบบเดิมโดยไม่มีใบยกเลิกให้ลบ
- เลขที่ยาวเกินหรือซ้ำ → รูปแบบเลขที่เอกสารของเมนูยกเลิกตั้งไว้ไม่เหมาะ

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูเลขที่เอกสารที่ระบบบอกในข้อความ แล้วยกเลิกใบนั้นก่อน (เช่น ยกเลิกใบเสร็จ แล้วยกเลิกใบวางบิล แล้วจึงยกเลิกใบขาย) ([[howto-ar-cancel-docs]])
2. ใบสั่งที่ดึงไปเปิดบิลครบแล้ว ถ้าบิลผิด ให้ยกเลิกใบขายก่อน แล้วจึงยกเลิกใบสั่ง
3. ใบสั่งที่ดึงไปบางส่วน ใช้ "ยกเลิกรายสินค้า" ยกเลิกเฉพาะส่วนที่ค้างได้ ([[howto-sale-cancel-docs]])
4. เลขที่ยาวเกินหรือซ้ำ ให้ผู้ดูแลแก้รูปแบบเลขที่เอกสารของเมนูยกเลิกนั้นให้สั้นลงและไม่ซ้ำกับเมนูอื่น
5. ยกเลิกในงวดที่ปิดบัญชีแล้วไม่ได้ ดู [[ts-common-period-closed]]

**ส่งต่อทีมงานเมื่อ:**
- ยกเลิกเอกสารปลายทางครบแล้ว แต่ยังขึ้นว่ามีการอ้างอิง
- ขึ้น "ถูกยกเลิกแบบเดิม" แต่ต้องการคืนสถานะเอกสาร
