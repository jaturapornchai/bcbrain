# สร้างหรือลบสินค้าไม่ได้ (รหัสสินค้ามีอยู่แล้ว สินค้ามีการใช้ไปแล้ว ห้ามลบ)

**ข้อความที่เห็น:**
- "รหัสสินค้า "..." มีอยู่แล้วในระบบ ไม่สามารถสร้างซ้ำได้"
- "กรุณาระบุ 'รหัสสินค้า'"
- "รหัสสินค้ายาวเกิน 25 ตัวอักษร"
- "สินค้ามีการใช้ไปแล้ว ห้ามลบ : ..." (หัวข้อ ห้ามลบข้อมูล)
- "หน้าจอนี้ห้ามลบข้อมูลสินค้า (...)"
- "ไม่อนุญาตให้แก้ไขข้อมูลหลัก (กลุ่มผู้ใช้ปิดสิทธิ์แก้ไขข้อมูลหลัก) กรุณาติดต่อผู้ดูแลระบบ"

**เกิดตอน:** เพิ่มสินค้าใหม่ แก้ข้อมูลสินค้า หรือกดลบสินค้า

**สาเหตุ:**
- รหัสสินค้าต้องไม่ซ้ำ ต้องกรอก และยาวไม่เกิน 25 ตัวอักษร
- สินค้าที่มีเอกสารใช้แล้ว (ซื้อ ขาย เบิก ยอดยกมา ฯลฯ) ลบไม่ได้ เพราะประวัติและยอดบัญชีจะเสีย
- หน้าจอบาร์โค้ดหรือข้อมูลเพิ่มเติมของสินค้าไม่ใช่ที่ลบสินค้า
- กลุ่มผู้ใช้ถูกปิดสิทธิ์แก้ข้อมูลหลัก

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. รหัสซ้ำ: ค้นหารหัสนั้นก่อน อาจมีสินค้าตัวเดิมอยู่แล้ว ถ้าเป็นสินค้าใหม่จริงให้ตั้งรหัสอื่น
2. สินค้าใช้แล้ว ลบไม่ได้: เก็บรหัสไว้เพื่อดูประวัติย้อนหลัง ถ้าเลิกขายแล้วก็แค่ไม่ใช้รหัสนี้ในเอกสารใหม่ ([[howto-stock-item-master]])
3. ลบผิดหน้าจอ: ไปลบที่หน้าจอข้อมูลสินค้า หรือลบเฉพาะบาร์โค้ดในตารางบาร์โค้ด
4. ไม่มีสิทธิ์แก้ข้อมูลหลัก: ให้ผู้ดูแลระบบเปิดสิทธิ์ให้ ([[ts-common-no-permission]])

**ส่งต่อทีมงานเมื่อ:** สินค้าไม่เคยใช้เลยแต่ลบไม่ได้ หรือหารหัสที่ระบบบอกว่าซ้ำไม่เจอ

## ข้อควรรู้
- ลบสินค้าแล้วระบบลบข้อมูลที่เกี่ยวข้องทั้งหมดของสินค้านั้นด้วย เช่น บาร์โค้ด หน่วยนับ ราคาขาย ราคาซื้อ คลังและที่เก็บ ระบบจะถามยืนยันก่อน
- บาร์โค้ดซ้ำดู [[ts-stock-barcode-duplicate]]
