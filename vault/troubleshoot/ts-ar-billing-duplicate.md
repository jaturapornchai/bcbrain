# ทำใบวางบิลไม่ได้ ขึ้น "ห้ามวางบิลซ้ำ : ..."

**ข้อความที่เห็น:** "ห้ามวางบิลซ้ำ : ..." (ต่อท้ายด้วยเลขที่เอกสารหนี้ที่ซ้ำ)

**เกิดตอน:** กด "บันทึก" ใน ใบวางบิล (ลูกหนี้)

**สาเหตุ:** เอกสารหนี้ใบนั้น (เช่น ใบขายเงินเชื่อ ใบเพิ่มหนี้) อยู่ในใบวางบิลใบอื่นที่ยังไม่ถูกยกเลิกแล้ว และร้านเปิดข้อเลือก "ห้ามวางบิลขายซ้ำ" (แท็บ "3.สินค้าคงคลัง")
- ถ้าไม่ได้เปิดข้อเลือกนี้ ระบบยอมให้เอกสารหนี้ใบเดียวอยู่ในใบวางบิลหลายใบ

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. หาใบวางบิลเดิมที่มีเอกสารหนี้ใบนี้อยู่
2. ถ้าจะวางบิลใหม่แทนใบเดิม ให้ยกเลิกใบวางบิลเดิมก่อน ([[howto-ar-cancel-docs]]) แล้วจึงบันทึกใบใหม่ ต้องทำตามลำดับนี้ ถ้าบันทึกใบใหม่ไปก่อน ใบเดิมจะยกเลิกไม่ได้ ขึ้น "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"
3. ถ้าแค่ใส่ซ้ำโดยไม่ตั้งใจ ให้ลบบรรทัดนั้นออกจากใบวางบิลใหม่
4. ถ้าไม่อยากเห็นเอกสารที่วางบิลแล้วตอนกด "ดึงเอกสารค้างชำระ" ให้ผู้ดูแลเปิด "ไม่แสดงเอกสารที่วางบิลไปแล้ว" (แท็บ "2.บัญชีแยกประเภท") ที่ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ

**ข้อควรรู้:**
- ใบวางบิลไม่ลดยอดหนี้ ยอดหนี้ลดเมื่อออกใบเสร็จรับเงินเท่านั้น ([[faq-ar-billing-needed]])
- ใบวางบิลที่ยกเลิกแล้วไม่ถูกนับ เอกสารหนี้ในใบนั้นนำมาวางบิลใหม่ได้
- เปิดใบวางบิลเดิมขึ้นมาแก้แล้วบันทึกซ้ำ ไม่ขึ้นข้อความนี้ เพราะเป็นใบเดียวกัน
- ใบวางบิลที่ถูกใช้ในใบเสร็จแล้ว ยกเลิกไม่ได้ แต่รุ่นปัจจุบันยังไม่กันการกดแก้ไขหรือลบ ห้ามแก้หรือลบใบที่รับเงินไปแล้ว ถ้าเผลอทำไปแล้วส่งต่อเจ้าหน้าที่

**ส่งต่อทีมงานเมื่อ:**
- ยกเลิกใบวางบิลเดิมแล้ว แต่ยังขึ้น "ห้ามวางบิลซ้ำ"
- หาใบวางบิลเดิมที่มีเอกสารหนี้ใบนี้ไม่เจอ
- บันทึกใบวางบิลใหม่ไปก่อนแล้ว และต้องการเก็บใบใหม่ไว้แต่ยกเลิกใบเดิมไม่ได้
