# เปิด 3D Monitor TV แล้วแผนที่ว่าง หรือตัวเลขเป็นศูนย์

**ข้อความที่เห็น:** ไม่มีข้อความเตือน แผนที่ขึ้นแต่ไม่มีหมุดคลัง รถ ลูกค้า และตัวเลขเป็น 0
**เกิดตอน:** เปิดหน้านี้ในฐานข้อมูลของกิจการจริง (ไม่ใช่ฐานสาธิต)

**สาเหตุ:** ระบบใส่ข้อมูลตัวอย่างให้เฉพาะฐานข้อมูลสาธิต ฐานข้อมูลจริงจึงว่างจนกว่าจะมีข้อมูลในชุดของหน้านี้ อธิบายที่ [[faq-monitormap-is-data-real]]

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ยืนยันก่อนว่าอยู่ฐานข้อมูลไหน (ดูชื่อฐานข้อมูลที่เลือกตอนเข้าสู่ระบบ)
2. ถ้าเป็นฐานจริง อาการนี้เป็นพฤติกรรมปกติของหน้านี้ ไม่ใช่ข้อมูลหาย
3. ถ้าแผนที่เป็นสีพื้นไม่มีภาพถนน/ดาวเทียม: ตรวจอินเทอร์เน็ต กดปุ่มสลับรูปแบบแผนที่ แล้วกดปุ่ม "ซิงค์" หรือรีเฟรชหน้า ภาพแผนที่มาจากบริการแผนที่ภายนอก
4. ถ้าอยากได้ข้อมูลจริงบนแผนที่ ให้สอบถามทีมงาน/ฝ่ายขาย

**ส่งต่อทีมงานเมื่อ:** ฐานสาธิตก็ยังว่าง หรือแผนที่ไม่ขึ้นภาพแม้อินเทอร์เน็ตปกติ
