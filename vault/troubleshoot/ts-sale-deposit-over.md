# หักเงินมัดจำในใบขายไม่ได้

**ข้อความที่เห็น:**
- "ยอดมัดจำมากกว่ามูลค่าสุทธิ"
- "ยอดตัดจ่ายมากกว่ายอดคงเหลือ: เอกสาร ... เกินอยู่ ..."
- "ยอดตัดเงินมัดจำต้องมากกว่า 0"
- "ไม่พบเอกสารเงินมัดจำ ... ของ ... (หรือถูกยกเลิกแล้ว)"
- "เลือกเอกสารเงินมัดจำ ... ซ้ำ"
- "กรุณาระบุรหัสลูกหนี้ก่อนดึงเอกสารมัดจำ"

**เกิดตอน:** ใช้แท็บ "ใช้เงินมัดจำ" ในใบขาย (หรือใบตั้งหนี้อื่นๆ) แล้วกดบันทึก

**สาเหตุ:**
- "ยอดมัดจำมากกว่ามูลค่าสุทธิ" → ยอดหักมัดจำรวมมากกว่ายอดบิล (ถ้าบิลภาษีแยกนอก ระบบเทียบกับยอดรวมภาษีแล้ว)
- "ยอดตัดจ่ายมากกว่ายอดคงเหลือ" → ใส่ยอดตัดของใบมัดจำนั้นเกินกว่าที่เหลือ (เคยถูกหักในบิลอื่นไปแล้วบางส่วน หรือคืนเงินไปแล้ว)
- "ยอดตัดเงินมัดจำต้องมากกว่า 0" → มีบรรทัดที่ยอดตัดเป็น 0 หรือติดลบ
- "ไม่พบเอกสารเงินมัดจำ" → ใบมัดจำเป็นของลูกค้ารายอื่น หรือถูกยกเลิกไปแล้ว
- "ซ้ำ" → เลือกใบมัดจำใบเดียวกันไว้สองบรรทัด
- "กรุณาระบุรหัสลูกหนี้ก่อนดึงเอกสารมัดจำ" → ยังไม่ได้เลือกลูกค้าในหัวบิล

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ลดยอดตัดให้ไม่เกินยอดบิล และไม่เกินยอดคงเหลือของใบมัดจำแต่ละใบ
2. ถ้าเงินมัดจำมากกว่าบิล ให้หักเท่ายอดบิล ส่วนที่เหลือเก็บไว้หักบิลถัดไป หรือคืนเงินให้ลูกค้า ([[howto-sale-deposit-receipt]])
3. ลบบรรทัดที่ซ้ำหรือยอดเป็น 0 ออก
4. เลือกลูกค้าในหัวบิลก่อน แล้วกดดึงเอกสารมัดจำใหม่ ([[howto-sale-deduct-deposit]])
5. ถ้าใบที่ลูกค้าจ่ายมาเป็น "รับเงินล่วงหน้า" จะหักในแท็บนี้ไม่ได้ ([[faq-sale-deposit-vs-advance]])

**ส่งต่อทีมงานเมื่อ:** ยอดคงเหลือของใบมัดจำที่ระบบบอกไม่ตรงกับที่ใช้ไปจริง
