# บันทึกโอนค่าเสื่อมไม่ผ่าน (ผังบัญชีไม่ครบ ไม่พบสินทรัพย์ สมุดรายวัน เลขที่เอกสาร)

## ข้อความที่เห็น
- "ไม่พบสินทรัพย์ที่ต้องคิดค่าเสื่อมในช่วง ... ถึง ..."
- "ผังบัญชีค่าเสื่อม/ค่าเสื่อมสะสมของสินทรัพย์ไม่ครบ เดบิต ... ≠ เครดิต ..."
- "ไม่พบสมุดรายวัน ..."
- "ต้องระบุเลขที่เอกสาร" / "เลขที่เอกสารยาวเกิน 25 ตัวอักษร" / "เลขที่เอกสาร ... ถูกใช้กับเอกสารอื่นแล้ว"
- "คำนวณค่าเสื่อมสินทรัพย์ ... ไม่ได้: หารด้วยศูนย์ (อายุการใช้งาน/จำนวนวันเป็น 0)"
- "ช่วงวันที่ยาวเกินไป (แบบรายวันไม่เกิน 1 ปี)"
- ตอนลบ: "สินทรัพย์ในเอกสารนี้ขายไปแล้วในเอกสาร ... (ลบเอกสารขายก่อน)"

## เกิดตอน
กด "ประมวลผล" "บันทึก" หรือ "ลบ" ในหน้า โอนข้อมูลเข้าระบบบัญชี

## สาเหตุ
- ไม่พบสินทรัพย์: ช่วงวันที่หรือช่วงรหัส/ประเภท/แผนกที่กรองไม่มีสินทรัพย์ที่ต้องคิดค่าเสื่อม หรือคิดครบอายุ/ขายไปแล้ว
- ผังบัญชีไม่ครบ: สินทรัพย์บางตัวไม่มีผังบัญชีค่าเสื่อมราคาหรือค่าเสื่อมราคาสะสม (มักเป็นข้อมูลที่ยกมาจากระบบเดิม) ระบบไม่ยอมลงบัญชีที่ไม่สมดุล
- ไม่พบสมุดรายวัน: ช่อง "สมุดรายวัน" ว่างหรือพิมพ์รหัสผิด
- เลขที่เอกสารซ้ำ: เลขนี้ถูกใช้กับเอกสารประเภทอื่นแล้ว
- หารด้วยศูนย์: สินทรัพย์ไม่มีอายุการใช้งาน หรือวันเริ่มกับวันสิ้นสุดคิดค่าเสื่อมเป็นวันเดียวกัน
- ลบไม่ได้: สินทรัพย์ในเอกสารถูกขายในวันเดียวกันหรือหลังเอกสารนี้

## วิธีแก้ (บอกลูกค้าได้เลย)
1. ไม่พบสินทรัพย์ → ตรวจ จากวันที่/ถึงวันที่ และล้างช่องกรองช่วงรหัส ประเภท แผนก
2. ผังบัญชีไม่ครบ → เปิด ข้อมูลสินทรัพย์ เลือก "ผังบัญชีค่าเสื่อมราคา" และ "ผังบัญชีค่าเสื่อมราคาสะสม" ให้ครบทุกตัว ([[howto-asset-register]])
3. สมุดรายวัน → เลือกสมุดที่มีอยู่จริง ([[howto-gl-overview]])
4. เลขที่เอกสาร → ใช้เลขใหม่ที่ไม่ซ้ำ ไม่เกิน 25 ตัวอักษร
5. หารด้วยศูนย์ → ใส่ "อายุการใช้งาน" และตรวจ "วันที่เริ่มคิดค่าเสื่อม" กับ "วันที่สิ้นสุดคิดค่าเสื่อม"
6. แบบรายวัน → แบ่งช่วงให้ไม่เกิน 1 ปี หรือเลือกแบบรายเดือน
7. ลบไม่ได้เพราะขายแล้ว → ลบเอกสารขายสินทรัพย์ก่อน ([[howto-asset-sale]])
8. ลบในงวดที่ปิดแล้วไม่ได้ → [[ts-common-period-closed]] (ถ้าวันที่เอกสารยังไม่ได้กำหนดงวดบัญชี ระบบยอมให้ลบ)
9. ตอนบันทึก ระบบไม่ได้ตรวจว่างวดปิดแล้วหรือยัง จึงบันทึกโอนค่าเสื่อมลงงวดที่ปิดแล้วได้ ก่อนกด "บันทึก" ให้ตรวจช่อง "วันที่เอกสาร (ว่าง = ถึงวันที่)" ทุกครั้ง

## ส่งต่อทีมงานเมื่อ
- ผังบัญชีของสินทรัพย์ครบทุกตัวแล้ว แต่ยังขึ้น เดบิต ไม่เท่ากับ เครดิต
- เผลอบันทึกโอนค่าเสื่อมลงงวดที่ปิดไปแล้ว
