# แก้ปัญหาสมองกิจการ (Company Brain) และผู้ช่วย AI / MCP

รวมข้อความแจ้งเตือนเมื่อใช้งานหน้าต่างสมองกิจการ (Company Brain) ในระบบ หรือเชื่อมต่อผู้ช่วย AI ภายนอกผ่านระบบ MCP

## 1. ปัญหาหน้าต่างสมองกิจการ (Company Brain)

- **"ระบบข้อมูลยังเตรียมความพร้อมอยู่ กรุณารอสักครู่"** — ระบบกำลังอัปเดตหรือเตรียมฐานข้อมูลความรู้ของกิจการให้พร้อมใช้งาน ให้รอสักครู่แล้วกดลองถามใหม่อีกครั้ง
- **"เชื่อมต่อสมองกิจการไม่สำเร็จ"** / **"เกิดข้อผิดพลาดระหว่างประมวลผลสมองกิจการ"** — การเชื่อมต่ออินเทอร์เน็ตหรือบริการผู้ช่วย AI ขัดข้องชั่วคราว ให้รีเฟรชหน้าจอหรือเว้นระยะสักครู่แล้วส่งคำถามใหม่ หากยังพบซ้ำต่อเนื่อง ให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า**

## 2. ปัญหาการเชื่อมต่อผู้ช่วย AI ภายนอก (MCP Token และสิทธิ์ฐานข้อมูล)

- **"ระบบ BC Ai Account MCP อนุญาตเฉพาะโหมดอ่านอย่างเดียว (readonly) เท่านั้น"** — ระบบ MCP ออกแบบมาเพื่อให้ AI อ่านและวิเคราะห์ข้อมูลธุรกิจเท่านั้น ไม่อนุญาตให้สั่งเพิ่ม แก้ไข หรือลบข้อมูลจริงในบัญชีเพื่อความปลอดภัย
- **"MCP Token ไม่ถูกต้อง หมดอายุ หรือถูกเพิกถอนแล้ว"** — รหัส Token ที่นำไปวางในโปรแกรม AI ภายนอกพิมพ์ไม่ครบ หมดอายุตามกำหนด หรือถูกผู้ดูแลเพิกถอนไปแล้ว (ระบบจะแสดงรหัส Token เต็มเพียงครั้งเดียวตอนสร้าง หากทำหายต้องสร้างใหม่) ให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า** เพื่อออก Token ใหม่
- **"Token นี้ไม่มีสิทธิ์เข้าถึงฐานข้อมูล ..."** / **"คุณไม่มีสิทธิ์ออก MCP Token สำหรับฐานข้อมูล ..."** — Token ที่ใช้หรือบัญชีผู้ใช้ปัจจุบันไม่ได้รับสิทธิ์เข้าถึงบริษัท/ฐานข้อมูลนั้น
- **"ผู้ใช้โหมดทดลองไม่สามารถเพิกถอนโทเค็นของบริษัทจริงได้"** — บัญชีที่ล็อกอินอยู่ในโหมดทดลองไม่สามารถสั่งยกเลิก Token ของฐานข้อมูลจริงได้ ต้องเข้าสู่ระบบด้วยบัญชีผู้ดูแลจริงของบริษัท
- **"อ่านข้อมูลพร้อมกันได้สูงสุด 20 ฐานข้อมูลต่อคำขอ"** — กรณีส่งคำถามแบบรวมหลายบริษัทพร้อมกัน ระบบจำกัดสูงสุด 20 ฐานข้อมูลต่อ 1 รอบคำสั่ง ให้แบ่งกลุ่มบริษัทเป็นรอบละไม่เกิน 20 ฐานข้อมูล
