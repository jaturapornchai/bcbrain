# แก้ปัญหาขายต่ำกว่าทุน ต่ำกว่าราคากลาง ไม่พบราคา หรืออ้างอิงเกินจำนวน

หน้าจอขายจะตรวจสอบสถานะสินค้า ราคาขายต่อหน่วย ประเภทภาษี และจำนวนที่อ้างอิงจากเอกสารเดิมก่อนบันทึกเพื่อกันความผิดพลาดทางราคาและสต็อก

## ข้อความที่พบบนหน้าจอและวิธีแก้ไข

### 1. สถานะสินค้าและราคาขาย
- **"สินค้า <ชื่อ> เลิกขาย"** / **"สินค้า <ชื่อ> หยุดซื้อ"** — สินค้าถูกตั้งสถานะหยุดจำหน่ายหรือหยุดสั่งซื้อในทะเบียนสินค้า ให้เปลี่ยนเป็นรหัสสินค้าทดแทน หรือ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า** เพื่อตรวจสอบสถานะสินค้า
- **"ราคาขายต่ำกว่าต้นทุน"** / **"ราคาขายต่ำกว่าต้นทุน <รหัส>:<ชื่อสินค้า>"** / **"ราคาขายต่ำกว่าต้นทุน ต้องการใช้ราคานี้หรือไม่"** — ระบบเทียบราคาขายสุทธิหลังหักส่วนลดกับต้นทุนสินค้า หากเปิด "เตือนเมื่อขายต่ำกว่าทุน" สามารถกดยืนยันได้ แต่หากเปิด "ห้ามขายสินค้าต่ำกว่าทุน" ระบบจะไม่อนุญาตให้บันทึก
- **"ห้ามขายต่ำกว่าราคากลาง"** / **"ห้ามขายต่ำกว่าราคากลาง <รหัส>"** — ราคาขายต่ำกว่าราคากลางที่กำหนดไว้ในทะเบียนสินค้า ต้องปรับราคาให้ไม่ต่ำกว่าราคากลาง
- **"ไม่พบราคาสินค้า"** — ยังไม่ได้ตั้งราคาขายในตารางราคาของสินค้ารายการนั้น
- **"ไม่พบราคาแยกนอก พบแต่ราคารวมใน คือ : ..."** / **"ไม่พบราคารวมใน พบแต่ราคาแยกนอก คือ : ..."** — ประเภทภาษีของเอกสาร (แยกนอก/รวมใน) ไม่ตรงกับราคาที่ตั้งไว้ในตารางราคา ระบบจะแจ้งราคาอีกฝั่งให้เห็นเพื่อตรวจสอบหรือสลับประเภทภาษีให้ตรงกัน

### 2. คลังและที่เก็บไม่ครบ
- **"ป้อนข้อมูลคลังสินค้าไม่ครบ (<รหัส>)"** / **"ป้อนข้อมูลที่เก็บสินค้าไม่ครบ (<รหัส>)"** — มีรายการสินค้าที่ยังไม่ได้เลือกคลังสินค้าหรือที่เก็บสินค้า ให้เลือกคลัง/ที่เก็บในตารางรายการให้ครบทุกบรรทัด

### 3. ปัญหาจำนวนและมูลค่าอ้างอิง (ขาย / ส่งคืน / ลดหนี้)
- **"ส่งคืนเกินจำนวน"** — จำนวนรับคืนหรือส่งคืนมากกว่าจำนวนคงเหลือในเอกสารอ้างอิง
- **"ส่งคืนเกินมูลค่า : <รหัส>"** — มูลค่าที่ลดหนี้หรือส่งคืนเกินมูลค่าคงเหลือของเอกสารอ้างอิง
- **"จำนวนเกินเอกสารอ้างอิง"** / **"จำนวนเกินรายการสั่งซื้อ"** — ระบุจำนวนเบิก/ขาย/รับสินค้าเกินยอดคงค้างในใบเสนอราคา ใบสั่งขาย หรือใบสั่งซื้อ
- **"ไม่พบหมายเลขบรรทัดที่อ้างอิง : <รหัส>"** / **"ไม่พบรายการอ้างอิง : <อ้างอิง> <รหัส>"** — รหัสสินค้าหรือบรรทัดที่อ้างอิงไม่ตรงกับเอกสารต้นทาง ให้กดดึงรายการจากเอกสารอ้างอิงใหม่อีกครั้งแทนการพิมพ์รหัสเอง

## วิธีตรวจเช็กก่อนปรับราคาหรือส่งต่อ

1. ตรวจ **หน่วยนับที่ขาย** (เช่น ขายเป็น "ลัง" แต่ไปดูราคาหรือต้นทุนของ "ชิ้น") เพราะหากเลือกหน่วยผิด ราคาต่อหน่วยอาจดูต่ำกว่าต้นทุนได้
2. ตรวจ **ส่วนลดรายบรรทัดและส่วนลดท้ายบิล** ที่ทำให้ราคาสุทธิหลังลดตกลงไปต่ำกว่าทุนหรือราคากลาง
3. หากต้องแก้ไขราคากลาง ราคาขายมาตรฐาน หรือเปิดสิทธิ์ตั้งส่วนลดพิเศษ ให้ **ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า**

## คำถามที่ลูกค้ามักถาม

**ถาม: ตั้งราคาขายมีกำไรชัดเจน แต่ทำไมระบบขึ้นเตือน "ราคาขายต่ำกว่าต้นทุน" บันทึกไม่ได้?**
ตอบ: เช็ก 3 จุดครับ/ค่ะ (1) เลือก **หน่วยนับ** ถูกไหม (เช่น ขายเป็นลังแต่ใส่ราคาของชิ้น), (2) หัก **ส่วนลดรายบรรทัดและส่วนลดท้ายบิล** แล้วราคาสุทธิตกลงต่ำกว่าทุนหรือไม่, และ (3) ต้นทุนเฉลี่ยในระบบอาจเพี้ยนจากการคีย์บิลย้อนหลัง ให้ลองตรวจบัตรคุมสินค้าหรือรันคำนวณสต็อกใหม่ (**2050**)

**ถาม: ขึ้นเตือน "ไม่พบราคาแยกนอก พบแต่ราคารวมใน" หรือสลับกัน ต้องแก้ตรงไหน?**
ตอบ: ประเภทภาษีมูลค่าเพิ่มบนหัวเอกสารขาย (แยกนอก / รวมใน) ไม่ตรงกับราคาที่ตั้งไว้ในตารางราคาสินค้าครับ/ค่ะ ให้ตรวจและเลือกประเภทภาษีบนหัวบิลให้ตรงกัน หรือให้ผู้ดูแลตั้งราคาขายให้ครบทั้งสองแบบในทะเบียนสินค้า (**2001**)

**ถาม: กดบันทึกบิลขายแล้วขึ้นเตือน "ป้อนข้อมูลคลังสินค้าไม่ครบ" หรือ "ป้อนข้อมูลที่เก็บสินค้าไม่ครบ" แก้ยังไง?**
ตอบ: มีแถวรายการสินค้าอย่างน้อย 1 แถวที่ช่อง **คลัง** หรือ **ที่เก็บ** ว่างอยู่ครับ/ค่ะ ให้เลื่อนดูรหัสสินค้าที่ข้อความแจ้งแล้วกดเลือกคลังสินค้าและที่เก็บให้ครบทุกแถวก่อนกดบันทึก

**ถาม: ทำไมกดดึงใบสั่งขายมาเปิดบิล หรือทำใบรับคืนสินค้าแล้วขึ้น "จำนวนเกินเอกสารอ้างอิง" / "ส่งคืนเกินจำนวน"?**
ตอบ: จำนวนที่ระบุมากกว่ายอดคงเหลือที่ยังไม่ได้ส่งของหรือยอดที่เคยขายในเอกสารอ้างอิงครับ/ค่ะ ให้ตรวจยอดคงค้างของบิลอ้างอิงแล้วปรับจำนวนไม่ให้เกินยอดจริง
