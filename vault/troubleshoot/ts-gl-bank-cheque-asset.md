# แก้ปัญหาทะเบียนเช็ค Statement ธนาคาร และค่าเสื่อมราคาสินทรัพย์

รวมข้อความแจ้งเตือนที่พบบ่อยในงานบริหารเช็ครับ-เช็คจ่าย การนำเข้าไฟล์รายการเดินบัญชีธนาคาร (Bank Statement) และการประมวลผลค่าเสื่อมราคาสินทรัพย์

## 1. ทะเบียนเช็คและบัตรเครดิตแก้ไขตรงไม่ได้

- **ข้อความบนหน้าจอ:** **"ทะเบียนเช็ค/บัตรเครดิตเป็นหน้าจอดูข้อมูลอย่างเดียว เพิ่ม/แก้ไข/ลบได้จากเอกสารรับ/จ่ายเช็คเท่านั้น"**
- **สาเหตุและวิธีแก้ไข:** หน้าจอทะเบียนเช็คมีไว้แสดงสถานะล่าสุดของเช็คทุกใบ (เช่น เช็คในมือ นำฝาก ผ่านเช็ค เช็คคืน เปลี่ยนเช็ค) หากต้องการแก้ไขวันครบกำหนด เลขเช็ค ธนาคาร หรือเปลี่ยนสถานะเช็ค ให้กลับไปแก้หรือยกเลิกที่ **เอกสารต้นทาง** (เช่น บันทึกรับชำระเงิน บันทึกนำฝาก หรือบันทึกเช็คผ่าน) แทน

## 2. นำเข้า Statement ธนาคาร (CSV / Excel) ไม่ผ่าน

- **"รหัสธนาคารต้องเป็น KBANK, SCB, BBL, KTB, TTB, BAY หรือ GSB"** — ระบุรหัสธนาคารให้ตรงกับธนาคารหลัก 7 แห่งที่รองรับรูปแบบอัตโนมัติ
- **"ไม่พบรายการฝากหรือถอนที่มีจำนวนเงินมากกว่า 0.00 ใน CSV"** — ไฟล์ Statement ไม่มีคอลัมน์หรือแถวตัวเลขเงินฝาก/ถอนที่ใช้ได้ (เช่น อัปโหลดไฟล์ว่าง แถวหัวตารางคลาดเคลื่อน หรือรูปแบบวันที่/ตัวเลขเพี้ยน)
- **"ไฟล์ .xlsx ไม่ถูกต้อง (ไม่ใช่รูปแบบ ZIP/OpenXML)"** — ไฟล์ที่แนบไม่ได้บันทึกเป็นไฟล์ Excel มาตรฐาน (.xlsx) จริง เช่น เป็นไฟล์ CSV หรือ HTML ที่เปลี่ยนนามสกุลชื่อไฟล์เฉยๆ ให้เปิดในโปรแกรมตารางแล้วกด "บันทึกเป็น (Save As)" เลือกนามสกุล Excel (.xlsx) ใหม่
- **"ไม่พบแผ่นงาน ... ในไฟล์ .xlsx"** — ชื่อชีตในไฟล์ Excel ไม่ตรงกับที่ระบุ ให้ตรวจสอบชื่อแท็บชีตในไฟล์ก่อนอัปโหลด

## 3. ปัญหาค่าเสื่อมราคาและขายสินทรัพย์ถาวร

- **"สินทรัพย์ในเอกสารนี้ขายไปแล้วในเอกสาร ... (ลบเอกสารขายก่อน)"** — ต้องการโอนค่าเสื่อมราคาหรือลบเอกสารโอนค่าเสื่อมราคาของสินทรัพย์ที่ถูกบันทึกขายออกไปแล้ว ระบบป้องกันไว้เพื่อไม่ให้ยอดทางบัญชีย้อนแย้ง ต้องไปจัดการเอกสารขายสินทรัพย์ให้เรียบร้อยก่อน
- **"สินทรัพย์ช่วงวันที่นี้โอนค่าเสื่อมไปแล้วในเอกสาร ... (แก้ไขเอกสารเดิมแทน)"** — สินทรัพย์รายการดังกล่าวถูกโอนค่าเสื่อมราคาในช่วงวันเดียวกันไปแล้วในเอกสารเดิม ให้เปิดแก้ไขเอกสารเดิมแทนการสร้างเอกสารซ้อน
- **"สินทรัพย์ ... ขายไปแล้วในเอกสาร ..."** / **"เอกสารขายสินทรัพย์ ... มีการรับชำระหนี้แล้วในเอกสาร ... ไม่สามารถลบหรือแก้ไขได้"** — ไม่สามารถขายสินทรัพย์ซ้ำใบเดิมได้ และหากใบขายสินทรัพย์มีเอกสารรับชำระเงินแล้ว ต้องลบ/ยกเลิกเอกสารรับชำระหนี้ก่อนจึงจะแก้ไขใบขายสินทรัพย์ได้

## คำถามที่ลูกค้ามักถาม

**ถาม: ทำไมกดแก้ไขหรือลบรายการในหน้าทะเบียนเช็ครับ/เช็คจ่ายไม่ได้ ขึ้นว่าเป็นหน้าจอดูข้อมูลอย่างเดียว?**
ตอบ: ทะเบียนเช็คมีไว้แสดงสถานะล่าสุดของเช็คทุกใบครับ/ค่ะ หากต้องการแก้ไขเลขเช็ค วันครบกำหนด หรือธนาคาร ต้องกลับไปแก้ไขที่ **เอกสารต้นทาง** (เช่น ใบรับชำระหนี้ **6023**, ใบจ่ายชำระหนี้ **5016** หรือใบนำฝากเช็ค **7024**) แต่หากเช็คถูกนำไปผ่านเช็คแล้วต้องยกเลิกใบเช็คผ่านก่อน

**ถาม: ดาวน์โหลดไฟล์ Statement จากแอป/เว็บธนาคารมาแล้ว นำเข้าเมนู 7018 ขึ้น "ไฟล์ .xlsx ไม่ถูกต้อง" แก้ยังไง?**
ตอบ: ไฟล์จากบางธนาคารตั้งนามสกุลเป็น Excel แต่โครงสร้างภายในเป็นไฟล์รูปแบบอื่นครับ/ค่ะ ให้เปิดไฟล์นั้นด้วยโปรแกรมตารางแล้วกด **บันทึกเป็น (Save As)** เลือกเป็นรูปแบบ Excel มาตรฐาน (.xlsx) หรือ CSV ใหม่ แล้วอัปโหลดอีกครั้งจะผ่านทันที

**ถาม: กดโอนค่าเสื่อมราคาสินทรัพย์แล้วขึ้นเตือน "โอนค่าเสื่อมไปแล้วในเอกสาร ..." ต้องทำยังไง?**
ตอบ: สินทรัพย์รายการนั้นถูกคำนวณและโอนค่าเสื่อมในช่วงวันที่เดียวกันไปแล้วครับ/ค่ะ ให้เปิดแก้ไขเอกสารโอนค่าเสื่อมใบเดิมแทนการสร้างซ้อน หรือตรวจช่วงวันที่ที่สั่งประมวลผลใหม่

**ถาม: อยากลบเอกสารขายสินทรัพย์ที่คีย์ผิด แต่ระบบไม่ยอมให้ลบเพราะมีใบรับชำระหนี้แล้ว ต้องแก้ยังไง?**
ตอบ: ให้ไปยกเลิกหรือลบ **เอกสารรับชำระหนี้** ที่อ้างอิงใบขายสินทรัพย์ใบนั้นออกก่อนครับ/ค่ะ จากนั้นจึงกลับมาแก้ไขหรือลบใบขายสินทรัพย์ได้ตามปกติ
