# ยกเลิกเอกสารคลังสินค้าไม่ได้ ขึ้นว่า มีการอ้างอิงไปแล้ว หรือ ถูกยกเลิกแล้ว

**ข้อความที่เห็น:**
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้"
- "เอกสาร ... ถูกยกเลิกแล้ว"
- "เอกสาร ... ยังไม่ถูกยกเลิก"
- "เอกสาร... ถูกยกเลิกแบบเดิม คืนสถานะจากหน้านี้ไม่ได้"
- "ไม่พบเอกสาร ..."

**เกิดตอน:** กด บันทึกยกเลิก หรือ คืนสถานะเอกสารปกติ ในเมนูยกเลิกเอกสารคลังสินค้า

**สาเหตุ:**
| ข้อความ | แปลว่า |
|---|---|
| มีการอ้างอิงไปแล้วโดยเอกสาร ... | มีเอกสารอื่นดึงใบนี้ไปใช้ เช่น ใบขอเบิกถูกดึงไปทำใบเบิก |
| ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) | ใบนี้ถูกดึงไปใช้ครบจำนวนแล้ว |
| ถูกยกเลิกแล้ว | ยกเลิกไปก่อนหน้านี้แล้ว ไม่ต้องทำซ้ำ |
| ยังไม่ถูกยกเลิก | กดคืนสถานะกับใบที่ยังปกติอยู่ |
| ถูกยกเลิกแบบเดิม | ใบนี้ถูกยกเลิกด้วยวิธีเก่าก่อนมีเมนูนี้ |
| ไม่พบเอกสาร | เลขที่เอกสารผิด หรือเลือกเมนูยกเลิกไม่ตรงชนิดเอกสาร |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ดูเลขที่เอกสารปลายทางในข้อความ แล้วยกเลิกหรือลบใบปลายทางนั้นก่อน
2. กลับมายกเลิกใบต้นทางอีกครั้ง
3. ถ้าไม่พบเอกสาร ให้ตรวจว่าเปิดเมนูยกเลิกตรงชนิดเอกสาร เช่น ใบเบิกต้องใช้ ยกเลิกใบเบิกสินค้า/วัตถุดิบ
4. ถ้าวันที่อยู่ในงวดที่ปิดแล้ว ดู [[ts-common-period-closed]]

**ส่งต่อทีมงานเมื่อ:** ใบยกเลิกแบบเดิมที่ต้องการคืนสถานะ หรือหาใบปลายทางที่อ้างอิงไม่เจอ
