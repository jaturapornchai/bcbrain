# บันทึกข้อมูลรายวัน (ใบสำคัญ) ไม่ผ่าน ขึ้นข้อความเตือน

**ข้อความที่เห็น:** ข้อความใดข้อความหนึ่งในตารางด้านล่าง
**เกิดตอน:** กดบันทึกใบสำคัญที่ บัญชี › ข้อมูลรายวัน (ใบสำคัญ = เอกสารบันทึกรายการบัญชี มีเดบิตและเครดิต)
**สาเหตุ:** ข้อมูลหัวใบสำคัญไม่ครบหรือไม่ถูกต้อง

| ข้อความ | แปลว่า | แก้ |
|---|---|---|
| "กรุณาระบุเลขที่เอกสาร" | เลขที่ว่าง | ใส่เลขที่ |
| "เลขที่เอกสารยาวเกิน 25 ตัวอักษร" | เลขยาวเกิน | ย่อเลขที่ |
| "กรุณาระบุวันที่เอกสาร" | วันที่ว่าง | ใส่วันที่ |
| "เลขที่เอกสารซ้ำ" | มีใบสำคัญเลขนี้แล้ว | เปลี่ยนเลข หรือเปิดใบเดิมแก้ |
| "วันที่เอกสาร ... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ" | วันที่อยู่ในงวดที่ปิด หรือยังไม่ได้ตั้งงวดบัญชี | [[ts-common-period-closed]] |
| "ยอดเดบิต (...) และเครดิต (...) ไม่เท่ากัน" | ไม่ดุล | [[ts-gl-debit-credit-not-equal]] |

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. อ่านข้อความแล้วแก้ตามตาราง
2. ถ้าเป็นเรื่องงวดบัญชี ให้ผู้ดูแลระบบตรวจ กำหนดงวดบัญชี ([[howto-gl-account-period]])
3. บันทึกใหม่

**ส่งต่อทีมงานเมื่อ:** แก้ตามตารางแล้วยังบันทึกไม่ได้ หรือขึ้นข้อความอื่นที่ไม่อยู่ในตาราง
