# สร้างฐานข้อมูลใหม่ไม่ได้

**ข้อความที่เห็น:** (อย่างใดอย่างหนึ่ง)
- "กรุณาตั้งชื่อฐานข้อมูล (ภาษาอังกฤษตัวพิมพ์เล็ก/ตัวเลข)"
- "ชื่อฐานข้อมูลต้องขึ้นต้นด้วยตัวอักษรภาษาอังกฤษพิมพ์เล็ก (a-z) และประกอบด้วย a-z, 0-9 หรือ ... ความยาว 3-41 ตัวอักษร" (ตรง ... คือเครื่องหมายขีดล่าง)
- "ชื่อฐานข้อมูลนี้เป็นชื่อสงวนของระบบ กรุณาใช้ชื่ออื่น"
- "ชื่อฐานข้อมูลนี้มีผู้ใช้งานอื่นตั้งไปแล้ว กรุณาตั้งชื่ออื่น"
- "ชื่อฐานข้อมูลนี้มีอยู่ในเซิร์ฟเวอร์แล้ว กรุณาตั้งชื่ออื่น"
- "ไม่สามารถสร้างฐานข้อมูลได้ (อาจมีชื่อซ้ำ): ..."
- "ไม่สามารถสร้างฐานข้อมูลใหม่ได้"

**เกิดตอน:** กด "ยืนยันสร้างฐานข้อมูลใหม่" ในหน้าต่างสร้างข้อมูลใหม่

**สาเหตุ:** ชื่อฐานข้อมูลต้องไม่ซ้ำกับของใครในระบบ และต้องเป็นตัวอักษรภาษาอังกฤษพิมพ์เล็ก ตัวเลข หรือขีดล่างเท่านั้น ขึ้นต้นด้วยตัวอักษร ยาว 3-41 ตัว (ภาษาไทย ช่องว่าง ขีดกลาง จุด ใช้ไม่ได้) บางชื่อระบบสงวนไว้ใช้เอง

**วิธีแก้ (บอกลูกค้าได้เลย):**
1. ตั้งชื่อใหม่เป็นภาษาอังกฤษพิมพ์เล็ก ขึ้นต้นด้วยตัวอักษร เช่น ชื่อย่อร้านตามด้วยปี (ห้ามมีช่องว่างหรือภาษาไทย)
2. รอให้ระบบตรวจชื่อจนขึ้น "สามารถใช้ชื่อฐานข้อมูลนี้ได้" ก่อนกดยืนยัน
3. ถ้าขึ้นว่าชื่อซ้ำหรือชื่อสงวน ให้เติมตัวเลขหรือคำต่อท้ายให้ต่างออกไป
4. ชื่อบริษัทภาษาไทยให้กรอกในช่อง "ชื่อบริษัท / ชื่อกิจการ" แทน

**ส่งต่อทีมงานเมื่อ:** ระบบขึ้นว่าชื่อใช้ได้แล้วแต่กดสร้างไม่สำเร็จ หรือขึ้น "สร้างโครงสร้างตารางไม่สำเร็จ: ..."
