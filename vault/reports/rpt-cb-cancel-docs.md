# รายงานเอกสารยกเลิก (การเงิน/ธนาคาร/เช็ค)

**เมนู:** เงินสด/ธนาคาร › รายงานเอกสารยกเลิก (การเงิน/ธนาคาร/เช็ค) › (เลือกรายงาน)

มีรายงานให้เลือก 21 รายการ แบ่งตามชนิดเอกสารที่ถูกยกเลิก

| กลุ่ม | ชื่อรายงานบนจอ |
|---|---|
| เงินสดย่อย | รายงานยกเลิกเบิกเงินสดย่อย · รายงานยกเลิกรับเงินสดย่อย |
| รายได้อื่น | รายงานยกเลิกรายได้อื่นๆ · รายงานยกเลิกเพิ่มหนี้รายได้อื่นๆ · รายงานยกเลิกลดหนี้รายได้อื่นๆ |
| ค่าใช้จ่ายอื่น | รายงานยกเลิกค่าใช้จ่ายอื่นๆ · รายงานยกเลิกเพิ่มหนี้ค่าใช้จ่ายอื่นๆ · รายงานยกเลิกลดหนี้ค่าใช้จ่ายอื่นๆ |
| ธนาคาร | รายงานยกเลิกฝากเงิน · รายงานยกเลิกถอนเงิน · รายงานยกเลิกการโอนเงินระหว่างธนาคาร · รายงานยกเลิกบัตรเครดิต |
| เช็ครับ | รายงานยกเลิกนำฝากเช็ค · รายงานยกเลิกเช็คผ่าน · รายงานยกเลิกเช็ครับคืน · รายงานยกเลิก ยกเลิกเช็ค · รายงานยกเลิกเปลี่ยนเช็ค |
| เช็คจ่าย | รายงานยกเลิกเช็คจ่ายผ่าน · รายงานยกเลิก ยกเลิกเช็คจ่าย · รายงานยกเลิกเช็คคืน · รายงานยกเลิกเปลี่ยนเช็คจ่าย |

## คอลัมน์ที่เห็น
ทุกรายงานในชุดนี้มี 4 คอลัมน์เท่ากัน คือ เอกสารวันที่ · เลขที่เอกสาร · เอกสารอ้างอิงวันที่ · เอกสารอ้างอิง
ไม่มีคอลัมน์จำนวนเงิน ชื่อลูกค้า/เจ้าหนี้ หรือเลขที่เช็ค และไม่มีปุ่มแสดงรายละเอียด ถ้าต้องการดูจำนวนเงินของเอกสารที่ยกเลิก ให้ส่งต่อเจ้าหน้าที่

## ตัวกรองบนจอ
- **ตั้งแต่วันที่ / ถึงวันที่** นับตามวันที่ของเอกสารยกเลิกนั้น
- **จากเลขที่เอกสาร / ถึงเลขที่เอกสาร** ช่วงเลขที่เอกสาร
- **ค้นหา** พิมพ์เลขที่เอกสาร เลขที่อ้างอิง หรือหมายเหตุ
- **เรียงตาม** เลือกเรียงตามคอลัมน์ใดก็ได้ที่เห็นในรายงาน ถ้าไม่เลือกระบบเรียงตามวันที่เอกสารและเลขที่เอกสาร
- ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" เพราะรายงานชุดนี้แสดงเอกสารยกเลิกอยู่แล้ว

## ข้อควรรู้
- บรรทัดคำอธิบายใต้ชื่อรายงานบนจอขึ้นข้อความว่า "...ที่ไม่ถูกยกเลิก" ทั้งที่รายงานชุดนี้แสดงเอกสารยกเลิก (ข้อความบนหัวรายงานผิด ตัวรายงานทำงานถูกต้อง) ถ้าลูกค้าสอบถามให้อธิบายตามนี้
