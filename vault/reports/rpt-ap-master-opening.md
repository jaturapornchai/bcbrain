# รายงานทะเบียนเจ้าหนี้ ยอดยกมา และตั้งหนี้อื่น ๆ

**เมนู:** เจ้าหนี้ › รายงานทะเบียนเจ้าหนี้ ยอดยกมา และตั้งหนี้อื่นๆ › (เลือกรายงาน)

| ชื่อรายงานบนจอ | ดูอะไรได้ | ใช้ตอนไหน |
|---|---|---|
| รายงานรายละเอียดเจ้าหนี้ | รหัส ชื่อ ที่อยู่ (รวมตำบล อำเภอ จังหวัด) หมายเลขโทรศัพท์ หมายเลขโทรสาร อีเมล์ | ตรวจทะเบียนเจ้าหนี้ ส่งให้ผู้สอบบัญชี |
| รายงานตั้งหนี้ยกมา | เอกสารตั้งหนี้ยกมาตอนเริ่มใช้ระบบ | ตรวจยอดหนี้ตั้งต้น |
| รายงานเพิ่มหนี้ยกมา | เอกสารเพิ่มหนี้ยกมา | ตรวจยอดตั้งต้น |
| รายงานลดหนี้ยกมา | เอกสารลดหนี้ยกมา | ตรวจยอดตั้งต้น |
| รายงานตั้งหนี้อื่นๆ | เอกสารตั้งหนี้อื่นๆ | ตรวจหนี้ค่าใช้จ่ายอื่น |
| รายงานเพิ่มหนี้อื่นๆ | เอกสารเพิ่มหนี้อื่นๆ | ตรวจการเพิ่มหนี้ |
| รายงานลดหนี้อื่นๆ | เอกสารลดหนี้อื่นๆ | ตรวจการลดหนี้ |

## คอลัมน์ของรายงานเอกสาร (6 รายงานล่าง)
เอกสารวันที่ · เอกสารเลขที่ · เอกสารอ้างอิงวันที่ · เอกสารอ้างอิง · รหัสเจ้าหนี้ · ชื่อเจ้าหนี้ · มูลค่าสุทธิ
(สำเนาเอกสารไม่ถูกนับ)

## ตัวกรองบนจอ
- **ตั้งแต่วันที่ / ถึงวันที่** ใช้กับรายงานเอกสาร 6 รายงาน ส่วน "รายงานรายละเอียดเจ้าหนี้" ไม่มีช่วงวันที่
- **จากรหัสเจ้าหนี้ / ถึงรหัสเจ้าหนี้** กรอกรหัสเดียวในช่องใดช่องหนึ่ง ระบบจะหาเฉพาะรหัสนั้น และมีช่อง "ช่วงรหัสเพิ่มเติม" ใส่หลายช่วงได้
- **เรียงตาม** รายงานเอกสารเรียงตามเอกสารวันที่ เอกสารเลขที่ หรือรหัสเจ้าหนี้ ส่วนรายละเอียดเจ้าหนี้เรียงตามรหัสหรือชื่อเจ้าหนี้
- **ค้นหา** เลขที่เอกสาร เลขที่อ้างอิง รหัสหรือชื่อเจ้าหนี้ (รายละเอียดเจ้าหนี้ค้นจากรหัส ชื่อ ที่อยู่ เบอร์โทร)
- **แสดงเอกสารที่ยกเลิก** มีเฉพาะ "รายงานตั้งหนี้อื่นๆ" "รายงานเพิ่มหนี้อื่นๆ" "รายงานลดหนี้อื่นๆ" ปกติไม่ติ๊ก ถ้าติ๊กจะเห็นเอกสารที่ยกเลิกปนกับเอกสารปกติ ส่วนรายงานยกมาทั้งสามไม่มีช่องนี้และไม่แสดงเอกสารที่ยกเลิก

## ข้อควรรู้
- รายงานยกมาแสดงเอกสารตั้งต้น ไม่ใช่ยอดค้างปัจจุบัน ยอดค้างปัจจุบันดู [[rpt-ap-aging]]
- ถ้าต้องการดูเฉพาะเอกสารที่ยกเลิก ใช้ [[rpt-ap-cancel-docs]]
