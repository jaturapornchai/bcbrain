# ระบบคลิกเจาะลึกจากรายงานไปยังเอกสารต้นทางและข้อมูลหลัก 2 จังหวะ

เมื่อตรวจสอบตัวเลขในรายงานหรือในศูนย์แจ้งเตือนยามเช้า แล้วพบรายการที่สงสัย คุณไม่จำเป็นต้องจดเลขที่เอกสารออกไปไล่เปิดเมนูค้นหาใหม่ เพราะระบบรองรับการคลิกเปิดเอกสารต้นทางและข้อมูลหลักได้ทันทีจากเซลล์ในตาราง

## หลักการคลิกเจาะลึก 19 ประเภทข้อมูล

ระบบวิเคราะห์ทั้งชื่อหัวคอลัมน์ รูปแบบค่าในเซลล์ และบริบทของรายงานต้นทางที่เปิดอยู่ เพื่อเปิดหน้าจอให้ถูกประเภทอัตโนมัติ ได้แก่:
1. **เลขที่เอกสาร** — เปิดหน้าจอบันทึกเอกสารรายวันตัวจริง (เช่น ใบเสนอราคา ใบสั่งขาย ใบกำกับภาษี ใบรับสินค้า ใบสั่งซื้อ ใบเสร็จรับเงิน ใบสำคัญรับ-จ่าย)
2. **เลขที่เอกสารอ้างอิง** — ตามเปิดไปยังเอกสารต้นทางที่ถูกอ้างถึง
3. **ลูกหนี้ / ลูกค้า** — เปิดแฟ้มข้อมูลลูกหนี้
4. **เจ้าหนี้ / ผู้ขาย** — เปิดแฟ้มข้อมูลเจ้าหนี้
5. **คู่ค้า (แยกบริบทอัตโนมัติ)** — หากเปิดจากรายงานฝั่งซื้อ/เจ้าหนี้ ระบบค้นหาจากเจ้าหนี้ก่อน หากเปิดจากฝั่งขาย/ลูกหนี้จะค้นหาจากลูกหนี้ก่อน เพื่อไม่ให้รหัสซ้ำกันสับสน
6. **สินค้าและบาร์โค้ด** — เปิดแฟ้มข้อมูลสินค้า (รองรับแม้เซลล์ในรายงานจะแสดงเป็นรหัสบาร์โค้ด หรือรวมรหัสกับชื่อ เช่น รหัส : ชื่อสินค้า)
7. **รหัสผังบัญชี** — เปิดหน้าจอรายละเอียดผังบัญชี
8. **สมุดเงินฝากธนาคาร** — หากอยู่บนรายงานเงินสด-ธนาคารและคลิกคอลัมน์เลขที่บัญชี ระบบจะเปิดหน้าสมุดเงินฝากที่ตรงกับเลขบัญชีนั้น
9. **พนักงาน / คลังสินค้า / พื้นที่เก็บ / หน่วยนับ / สินทรัพย์ / แผนก / โครงการ / สาขา / หน่วยงาน / การจัดสรร / กลุ่มสินค้า** — เปิดหน้าจอข้อมูลหลักแต่ละประเภทโดยตรง

**ฉลาดยิ่งขึ้นด้วยรหัสคู่ในแถว (Paired Code)**: หากคุณคลิกที่คอลัมน์ "ชื่อลูกค้า" หรือ "ชื่อสินค้า" ระบบจะส่งรหัสที่อยู่ในแถวเดียวกันไปช่วยค้นหาควบคู่กัน ทำให้เปิดถูกคน ถูกรายการ แม้มีชื่อคล้ายกัน

## เจาะลึก 2 จังหวะจากสมุดรายวันไปยังเอกสารต้นทางจริง (2-Hop Drill-Down)

กรณีตรวจสอบรายงานฝั่งบัญชีแยกประเภท (GL) หรือสมุดรายวันทั่วไป:
- รายการบัญชีหลายรายการถูกสร้างขึ้นอัตโนมัติจากเอกสารระบบอื่น เช่น ใบกำกับภาษีขาย ใบตั้งหนี้ซื้อ ใบวางบิลรวมลูกหนี้/เจ้าหนี้ รายการบริการต่างประเทศ (ภ.พ.36 / ภ.ง.ด.54) ค่าใช้จ่ายรอตัดบัญชี หรือสัญญาเช่าซื้อสินทรัพย์
- **จังหวะที่ 1**: เมื่อคลิกเลขที่ใบสำคัญรายวัน หรือคลิกคอลัมน์เอกสารอ้างอิง ระบบจะจับคู่ใบสำคัญนั้นกับเอกสารต้นทางที่สร้างรายการบัญชีนี้ขึ้นมา
- **จังหวะที่ 2**: ระบบเปิดข้ามสมุดรายวันไปยัง **เอกสารต้นทางที่แท้จริง** ให้ทันที (หรือให้รายละเอียดทั้งใบสำคัญบัญชีและเอกสารอ้างอิงต้นทางควบคู่กัน) ทำให้ผู้ตรวจสอบบัญชีและเจ้าของกิจการไล่ตรวจที่มาของยอดเงินได้ครบวงจรภายในไม่กี่วินาที

## ค่าแบบไหนที่ระบบจะไม่เปิดให้คลิก

เพื่อป้องกันการคลิกพลาด ระบบจะไม่ทำงานเมื่อคลิกที่:
- ช่องว่าง เครื่องหมายขีดกลาง ยอดยกมา ยอดยกไป แถวรวมทั้งหมด (Grand Total / Subtotal)
- ตัวเลขจำนวนเงินทศนิยมล้วน หรือช่องวันที่

## คำถามที่ลูกค้ามักถาม

- **เห็นตัวเลขแปลกๆ ในรายงานบัญชีแยกประเภทหรือสมุดรายวัน ต้องจดเลขเอกสารออกไปเปิดเมนูอื่นไหม?**
  ไม่ต้องครับ คลิกที่เลขที่ใบสำคัญหรือเอกสารอ้างอิงในตารางรายงานได้เลย ระบบรองรับ **เจาะลึก 2 จังหวะ** ที่จะพาข้ามจากสมุดรายวันเปิดไปยังเอกสารต้นทางตัวจริง (เช่น ใบกำกับภาษีขาย ใบตั้งหนี้ซื้อ หรือใบวางบิล) ให้ทันที
- **นอกจากเลขที่เอกสารแล้ว คลิกดูข้อมูลอะไรจากในตารางรายงานได้อีกบ้าง?**
  รองรับถึง **19 ประเภทข้อมูล** ครับ เช่น คลิกชื่อหรือรหัสลูกค้า/เจ้าหนี้เพื่อเปิดแฟ้มคู่ค้า, คลิกสินค้าหรือบาร์โค้ดเพื่อเปิดทะเบียนสินค้า, คลิกเลขบัญชีธนาคารเปิดสมุดเงินฝาก รวมถึงผังบัญชี คลังสินค้า แผนก สาขา และสินทรัพย์
- **ถ้าคลิกที่คอลัมน์ชื่อลูกค้าหรือชื่อสินค้าที่มีชื่อคล้ายกัน ระบบจะเปิดผิดรายการไหม?**
  ไม่ผิดครับ ระบบมีกลไก **รหัสคู่ในแถว (Paired Code)** ที่ส่งรหัสประจำแถวนั้นไปค้นหาควบคู่กับชื่อ ทำให้เปิดถูกคนและถูกสินค้าแม่นยำ
- **ทำไมคลิกที่แถวรวมยอด (Grand Total) ตัวเลขจำนวนเงิน หรือช่องวันที่แล้วไม่มีอะไรเปิดขึ้นมา?**
  เป็นระบบป้องกันการคลิกพลาดครับ ระบบจะปิดการคลิกในช่องว่าง ยอดยกมา/ยกไป แถวรวมยอด ตัวเลขทศนิยมล้วน และช่องวันที่ เพื่อให้คลิกเปิดเฉพาะเอกสารและข้อมูลหลักจริงเท่านั้น
