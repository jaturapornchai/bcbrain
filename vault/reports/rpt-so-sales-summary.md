# รายงานสรุปยอดขายและรายงาน อย. (ขย.)

เมนู: ขาย > รายงานสรุปยอดขายและรายงาน อย. (ขย.) มี 8 รายงาน

| ชื่อรายงาน | แสดงอะไร |
|---|---|
| รายงานสรุปการขายสินค้าตามพนักงานขาย | บิลขายทีละใบ จัดกลุ่มตามพนักงานขาย |
| รายงานสรุปยอดขายสินค้าสุทธิตามพนักงานขาย | ยอดขายรายสินค้าของพนักงานขายแต่ละคน หักรับคืนแล้ว |
| รายงานสรุปยอดขายสินค้า-สรุปตามวันที่ | ยอดขายรวมต่อวัน |
| รายงานประวัติการขายสินค้า | รายการขายของสินค้าแต่ละตัว ทุกบิล |
| รายงานการขายยาตามที่สำนักงานคณะกรรมการอาหารและยากำหนด (ขย.8) | บัญชีการขายยารายล็อต พร้อมยอดคงเหลือ |
| รายงานการขายยาตามที่สำนักงานคณะกรรมการอาหารและยากำหนด (ขย.13) | บัญชีการขายยารายล็อต แบบ ข.ย.13 |
| บัญชีการผลิตยาและขายยาที่ผลิต (แบบ ผ.ย. ๕) | บัญชีผลิตและขายยาที่ผลิต รายล็อต |
| รายงานเรียกเก็บยาคืน (Recall) | ล็อตยาและผู้ซื้อทุกราย ใช้ตอนต้องเรียกคืน |

ทุกรายงานในกลุ่มนี้คิดจากบิลขายสินค้า/บริการที่ไม่ถูกยกเลิก ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" ไม่มี "แสดงเฉพาะ POS" และไม่มี "ประเภทการขาย" (ตัวเลือกพวกนี้อยู่ในรายงานรายใบที่ [[rpt-so-sales-docs]])

## รายงานยอดขาย 4 รายงานแรก
- รายงานสรุปการขายสินค้าตามพนักงานขาย
  - คอลัมน์: รหัสและชื่อพนักงานขาย, รหัสและชื่อลูกหนี้, เอกสารวันที่, เลขที่, มูลค่าส่วนลด, ยอดก่อนภาษี, ภาษีมูลค่าเพิ่ม, ภาษีหัก ณ ที่จ่าย, มูลค่าสุทธิ
  - ช่วงรหัสคือรหัสพนักงานขาย มีตัวเลือก "เรียงตาม": รหัสพนักงานขาย/วันที่/เวลา, วันที่/เวลา, เลขที่เอกสาร, รหัสลูกหนี้/วันที่ และมีปุ่ม "แสดงรายละเอียดสินค้า" แตกเป็นรายการสินค้า
- รายงานสรุปยอดขายสินค้าสุทธิตามพนักงานขาย
  - คอลัมน์: รหัสและชื่อพนักงานขาย, รหัสและชื่อสินค้า, หน่วยนับ, จำนวนขาย, มูลค่าขาย, จำนวนรับคืน, มูลค่ารับคืน, จำนวนคงเหลือ, มูลค่าคงเหลือ
  - ยอดขายคือบิลขาย ยอดรับคืนคือใบรับคืน/ลดหนี้ขาย ของแถมไม่นับในยอดขาย ช่วงรหัสคือรหัสพนักงานขาย
- รายงานสรุปยอดขายสินค้า-สรุปตามวันที่
  - คอลัมน์: เอกสารวันที่, มูลค่าสินค้า, มูลค่าส่วนลด, มูลค่าหลังหักส่วนลด, มูลค่ายกเว้นภาษี, ยอดก่อนภาษี, ภาษีมูลค่าเพิ่ม, มูลค่าหลังคิดภาษี, มูลค่าไม่กระทบภาษี, มูลค่าสุทธิ
  - นับเฉพาะบิลขาย ไม่หักรับคืน และไม่มีช่วงรหัส
- รายงานประวัติการขายสินค้า
  - คอลัมน์: รหัสและชื่อสินค้า, เลขที่และวันที่เอกสาร, รหัสและชื่อลูกหนี้, หน่วยนับ, ราคา, จำนวน, รวมมูลค่า, หมายเหตุ
  - รายการของบิลที่ถูกยกเลิกจะแสดงด้วย โดยราคา จำนวน มูลค่าเป็น 0 และหมายเหตุเขียนว่า "ยกเลิก" ช่วงรหัสคือรหัสสินค้า

## รายงานยา (ขย.8, ขย.13, ผ.ย. ๕, Recall)
- แสดงรายล็อตของสินค้า แต่ละล็อตมีแถวรับเข้า ตามด้วยแถวการขายแต่ละครั้ง ช่วงวันที่กรองเฉพาะวันที่ขาย ช่วงรหัสคือรหัสสินค้า
- ขย.8: รหัสสินค้า, ชื่อยา, เลขที่ล็อต, วันที่ผลิต, จำนวนผลิต, วันที่ขาย, จำนวนขาย, คงเหลือ, ชื่อผู้ซื้อ, ที่อยู่, ผู้ขาย
- ขย.13: รหัสสินค้า, ชื่อยา, เลขที่ล็อต, จำนวนรับ, วันที่ขาย, ชื่อและที่อยู่ผู้ซื้อ, ประเภทผู้ซื้อ, จำนวนขาย, คงเหลือ, ผู้ขาย
- ผ.ย. ๕: เหมือน ขย.8 แต่ไม่มีคอลัมน์คงเหลือ และวันที่ผลิตแสดงซ้ำทุกแถว
- Recall: รหัสสินค้า, ชื่อยา, เลขที่ล็อต, วันที่ผลิต, จำนวนผลิต, วันที่ขาย, จำนวนขาย, รหัสและชื่อผู้ซื้อ, ที่อยู่, โทรศัพท์, เลขที่เอกสาร, รหัสและชื่อผู้แทนขาย
- เป็นรายงานตามรูปแบบที่ใช้ในระบบ ไม่รับรองว่าตรงแบบฟอร์มทางการของหน่วยงาน ก่อนส่งหน่วยงานให้ตรวจกับแบบฟอร์มจริง และถ้าลูกค้าต้องการแบบฟอร์มทางการให้ส่งต่อเจ้าหน้าที่

## จุดที่มักสับสน
- ยอดขายสรุปตามวันที่รวมขายเชื่อด้วย จึงไม่เท่ายอดเงินสดที่รับ ดูเงินที่รับจริงที่ [[rpt-cb-cash-petty]]
- ถ้ายอดวันนี้ไม่ขึ้น ตรวจ "ถึงวันที่" ดู [[ts-rpt-no-data]]
- ถ้าต้องการยอดขายสุทธิรายวัน ต้องนำยอดรับคืนมาหักเอง เพราะรายงานรายวันไม่หักรับคืน
