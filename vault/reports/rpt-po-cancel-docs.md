# รายงานเอกสารยกเลิก (ระบบซื้อ)

เมนู: ซื้อ > รายงานเอกสารยกเลิก (ระบบซื้อ) มี 9 รายงาน

รายงานกลุ่มนี้แสดง "ใบยกเลิก" ซึ่งเป็นเอกสารที่ระบบออกให้เมื่อยกเลิกเอกสารเดิม ไม่ใช่การดึงเอกสารเดิมที่ถูกยกเลิกกลับมาแสดง

| ชื่อรายงาน | ยกเลิกเอกสารอะไร |
|---|---|
| รายงานยกเลิกใบเสนอซื้อ | ใบเสนอซื้อ |
| รายงานยกเลิกใบสั่งซื้อ | ใบสั่งซื้อ |
| รายงานยกเลิกจ่ายเงินล่วงหน้า | จ่ายเงินล่วงหน้า |
| รายงานยกเลิกรับคืนเงินล่วงหน้า | รับคืนเงินล่วงหน้า |
| รายงานยกเลิกจ่ายเงินมัดจำ | จ่ายเงินมัดจำ |
| รายงานยกเลิกคืนเงินมัดจำ | รับคืนเงินมัดจำ |
| รายงานยกเลิกรับสินค้า/ตั้งหนี้ | ซื้อสินค้า/ตั้งหนี้ซื้อ |
| รายงานยกเลิกส่งคืนสินค้า/ลดหนี้ซื้อ | ส่งคืนสินค้า/ลดหนี้ซื้อ |
| รายงานยกเลิกเพิ่มหนี้ซื้อ/ราคาผิด | เพิ่มหนี้ซื้อ/ราคาผิด |

เอกสารทะยอยรับ (รับสินค้า ตั้งหนี้ เพิ่มหนี้ ลดหนี้ จากใบตั้งหนี้) ไม่มีรายงานยกเลิกในกลุ่มนี้

## ตัวกรองที่มีบนหน้าจอ
- ตั้งแต่วันที่ / ถึงวันที่ (ตามวันที่ของใบยกเลิก)
- จากรหัสเจ้าหนี้ / ถึงรหัสเจ้าหนี้ และ "ช่วงรหัสเจ้าหนี้เพิ่มเติม"
- ช่องค้นหาและ "เรียงตาม"
- ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" เพราะรายงานทั้งกลุ่มคือรายงานเอกสารที่ยกเลิกอยู่แล้ว
- ปุ่ม "แสดงรายละเอียดสินค้า" มีเฉพาะรายงานยกเลิกใบเสนอซื้อและรายงานยกเลิกใบสั่งซื้อ

## คอลัมน์ที่เห็น
- ยกเลิกใบเสนอซื้อ: เอกสารวันที่, เลขที่, เวลา, รหัสและชื่อเจ้าหนี้, ประเภทรายการ, แผนก, กลุ่มเอกสาร, ผู้ขออนุมัติ, ผู้ยกเลิก, ยอดก่อนภาษี
- ยกเลิกใบสั่งซื้อ: เอกสารวันที่, เลขที่, เอกสารอ้างอิง, เจ้าหนี้, มูลค่าสินค้า, มูลค่าส่วนลด, ภาษีมูลค่าเพิ่ม, มูลค่าสุทธิ, ผู้ขออนุมัติ, ผู้ยกเลิก
- รายงานยกเลิกอีก 7 รายงาน (เงินล่วงหน้า เงินมัดจำ ซื้อสินค้า ส่งคืน/ลดหนี้ เพิ่มหนี้) แสดงเพียง เอกสารวันที่, เลขที่, เอกสารอ้างอิงวันที่, เอกสารอ้างอิง, รหัสและชื่อเจ้าหนี้ ไม่มีคอลัมน์จำนวนเงินและไม่มีรายการสินค้า ถ้าลูกค้าต้องการยอดเงินของเอกสารที่ถูกยกเลิก ให้ส่งต่อเจ้าหน้าที่
