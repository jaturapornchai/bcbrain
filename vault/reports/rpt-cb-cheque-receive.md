# รายงานทะเบียนเช็ครับ

เมนู: เมนูเงินสด/ธนาคาร > กลุ่ม "รายงานทะเบียนเช็ครับ"

| ชื่อรายงาน | ดูอะไรได้ | ใช้ตอนไหน |
|---|---|---|
| รายงานเช็ครับยกมา | เอกสารเช็ครับยกมาตอนเริ่มใช้ระบบ ทีละเอกสาร | ตรวจยอดตั้งต้น |
| รายงานทะเบียนเช็ครับ | เช็ครับทุกใบที่รับในช่วงวันที่ แสดงวันที่รับเช็ค เอกสารอ้างอิง ธนาคาร สาขา เลขที่เช็ค วันที่บนเช็ค ลูกหนี้ และจำนวนเงิน (ไม่มีคอลัมน์สถานะ) | ดูรายการเช็คที่รับทั้งหมด |
| รายงานรายละเอียดเช็ครับ - ตามวันที่รับ - ตามสถานะเช็ค | เช็คที่รับในช่วงวันที่ เรียงตามสถานะ มีคอลัมน์ "สถานะเช็ค" | ดูว่าเช็คแต่ละใบอยู่สถานะไหนตอนนี้ |
| รายงานรายละเอียดเช็ครับ - ตามวันที่ครบกำหนด | เช็คที่วันที่บนเช็คอยู่ในช่วงวันที่ มีคอลัมน์ "สถานะ" | วางแผนนำฝากตามวันครบกำหนด |
| รายงานนำฝาก (เช็ครับ) | เอกสารนำฝากเช็คที่บันทึกในช่วงวันที่ | ตรวจเช็คที่นำฝาก |
| รายงานเช็คผ่าน (เช็ครับ) | เอกสารบันทึกเช็คผ่านในช่วงวันที่ | ยืนยันเงินเข้า |
| รายงานรับคืน (เช็ครับ) | เอกสารบันทึกเช็คคืนในช่วงวันที่ | ตามเช็คคืน |
| รายงานเช็คขาดสิทธิ์ (เช็ครับ) | เอกสารบันทึกเช็คขาดสิทธิ์ในช่วงวันที่ | ตรวจเช็คที่ไม่ได้เงิน |
| รายงานการเปลี่ยนเช็ค (เช็ครับ) | เอกสารเปลี่ยนเช็คในช่วงวันที่ | ตรวจประวัติการเปลี่ยนเช็ค |

## ตัวกรองสำคัญ
- ช่วงวันที่: รายงานทะเบียนและรายละเอียดตามวันที่รับ ใช้วันที่รับเช็ค รายงานตามวันที่ครบกำหนด ใช้วันที่บนเช็ค รายงานยกมา นำฝาก ผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค ใช้วันที่เอกสาร
- จากรหัส/ถึงรหัส: รายงานยกมา ทะเบียน และรายละเอียด กรองตามรหัสลูกหนี้ ส่วนรายงานนำฝาก ผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค กรองตามเลขที่เอกสาร
- คำค้นหา
- รายงานยกมา นำฝาก ผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค แสดงหนึ่งแถวต่อเอกสาร กดปุ่ม "แสดงรายละเอียดสินค้า" เพื่อดูเช็คแต่ละใบในเอกสาร
- ไม่มีช่องติ๊กแสดงเอกสารที่ยกเลิก รายงานเอกสารเหล่านี้ไม่นับเอกสารที่ถูกยกเลิก ถ้าต้องการดูเอกสารที่ยกเลิก ใช้กลุ่ม "รายงานเอกสารยกเลิก (การเงิน/ธนาคาร/เช็ค)"

## วิธีอ่านตัวเลขสำคัญ
- สถานะเช็คที่แสดง เช่น เช็คในมือ เช็คนำฝาก เช็คผ่าน เช็ครับคืน เช็คเปลี่ยน เช็คตั้งหนี้ใหม่ ส่วนเช็คที่บันทึกขาดสิทธิ์จะแสดงเป็น "เช็คยกเลิก"
- รายงานนำฝาก ผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค แสดงเอกสารที่บันทึกในช่วงวันที่ ไม่ใช่สถานะปัจจุบันของเช็ค เช็คใบเดียวจึงอาจอยู่ได้หลายรายงาน เช่น นำฝากแล้วผ่าน ถ้าต้องการรู้สถานะล่าสุด ให้ดูรายงานรายละเอียดเช็ครับ
- เช็ครับที่ยังไม่ผ่าน ยังไม่ใช่เงินในบัญชีธนาคาร
