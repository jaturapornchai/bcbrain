# รายงานเอกสารยกเลิก (ระบบขาย)

เมนู: ขาย > รายงานเอกสารยกเลิก (ระบบขาย) มี 10 รายงาน

รายงานกลุ่มนี้แสดง "ใบยกเลิก" ซึ่งเป็นเอกสารที่ระบบออกให้เมื่อยกเลิกเอกสารเดิม ไม่ใช่การดึงเอกสารเดิมที่ถูกยกเลิกกลับมาแสดง

| ชื่อรายงาน | ยกเลิกเอกสารอะไร |
|---|---|
| รายงานยกเลิกใบเสนอราคา | ใบเสนอราคาขาย |
| รายงานยกเลิกใบสั่งจองสินค้า | ใบสั่งจองสินค้า |
| รายงานยกเลิกใบสั่งขาย | ใบสั่งขายสินค้า |
| รายงานยกเลิกรับเงินล่วงหน้า | รับเงินล่วงหน้า |
| รายงานยกเลิกคืนเงินรับล่วงหน้า | คืนเงินรับล่วงหน้า |
| รายงานยกเลิกรับเงินมัดจำ | รับเงินมัดจำ |
| รายงานยกเลิกคืนเงินมัดจำ | คืนเงินมัดจำ |
| รายงานยกเลิกขายสินค้าและบริการ | ขายสินค้า/บริการ |
| รายงานยกเลิกรับคืนสินค้า/ลดหนี้ขาย | รับคืนสินค้า/ลดหนี้ขาย |
| รายงานยกเลิกเพิ่มหนี้ขาย/ราคาผิด | เพิ่มหนี้ขาย/ราคาผิด |

## ตัวกรองที่มีบนหน้าจอ
- ตั้งแต่วันที่ / ถึงวันที่ (ตามวันที่ของใบยกเลิก)
- จากรหัสลูกหนี้ / ถึงรหัสลูกหนี้ และ "ช่วงรหัสลูกหนี้เพิ่มเติม"
- ช่องค้นหาและ "เรียงตาม"
- ไม่มีช่อง "แสดงเอกสารที่ยกเลิก"
- ปุ่ม "แสดงรายละเอียดสินค้า" มีเฉพาะรายงานยกเลิกใบเสนอราคา ใบสั่งจองสินค้า และใบสั่งขาย

## คอลัมน์ที่เห็น
- ยกเลิกใบเสนอราคา: เอกสารวันที่, เลขที่, เวลา, รหัสและชื่อลูกหนี้, ประเภทรายการ, แผนก, กลุ่มเอกสาร, ผู้ขออนุมัติ, ผู้ยกเลิก, ยอดก่อนภาษี
- ยกเลิกใบสั่งจองและใบสั่งขาย: คอลัมน์ชุดเดียวกัน แต่ปิดท้ายด้วย มูลค่ายกเว้นภาษี, อัตราภาษี, ภาษีมูลค่าเพิ่ม, ประเภทภาษี, มูลค่าสุทธิ
- รายงานยกเลิกอีก 7 รายงาน (เงินล่วงหน้า เงินมัดจำ ขายสินค้า รับคืน/ลดหนี้ เพิ่มหนี้) แสดงเพียง เอกสารวันที่, เลขที่, เอกสารอ้างอิงวันที่, เอกสารอ้างอิง, รหัสและชื่อลูกหนี้ ไม่มีคอลัมน์จำนวนเงินและไม่มีรายการสินค้า ถ้าลูกค้าต้องการยอดเงินของบิลที่ถูกยกเลิก ให้ส่งต่อเจ้าหน้าที่
- ถ้าต้องการเห็นบิลขายที่ถูกยกเลิกพร้อมยอดเป็น 0 ใช้ช่อง "แสดงเอกสารที่ยกเลิก" ในรายงานการขายสินค้าและบริการ ดู [[rpt-so-sales-docs]]
