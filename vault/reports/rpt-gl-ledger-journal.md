# รายงานผังบัญชี สมุดรายวัน และบัญชีแยกประเภท

เมนู: บัญชี › รายงานผังบัญชี สมุดรายวัน และบัญชีแยกประเภท

| ชื่อรายงาน | ดูอะไรได้ | ใช้ตอนไหน |
|---|---|---|
| รายงานรายละเอียดผังบัญชี | รหัสบัญชี ชื่อบัญชี ชื่อภาษาอังกฤษ ประเภทบัญชี และระดับ | ตรวจผังบัญชี |
| ใบปะหน้าเอกสาร | ใบสำคัญรายการบัญชีของเอกสาร พร้อมรายการเดบิต-เครดิต | พิมพ์แนบเอกสารให้ผู้สอบบัญชี |
| รายงานข้อมูลรายวัน | รายการสมุดรายวันทีละบรรทัดบัญชี ตามสมุดรายวันที่เลือก | ตรวจการลงบัญชีรายวัน |
| รายงานข้อมูลรายวันแบบสรุป | หนึ่งบรรทัดต่อเอกสาร ช่องจำนวนเงินคือยอดรวมฝั่งเดบิตของเอกสารนั้น | ดูภาพรวมเอกสารที่ลงบัญชี |
| รายงานบัญชีแยกประเภท | ทุกรายการของแต่ละบัญชี ยอดยกมา และยอดคงเหลือ | ไล่ที่มาของยอดบัญชี |
| รายงานบัญชีแยกประเภท (แบบสรุป) | ยอดของแต่ละบัญชีแบบสรุป | ดูยอดรวมต่อบัญชี |

## ตัวกรองสำคัญ
- ช่วงวันที่ ช่วงรหัส และคำค้นหา
- รายงานข้อมูลรายวัน และแบบสรุป: ติ๊กเลือก "สมุดรายวัน" ที่ต้องการได้หลายเล่ม
- รายงานข้อมูลรายวัน: "เรียงตาม" วันที่ หรือ เลขที่เอกสาร และ "ยอดรวมท้ายวัน" (ติ๊กไว้ตั้งต้น)
- รายงานบัญชีแยกประเภท: "สมุดรายวัน (รหัส)" พิมพ์รหัสสมุดเล่มเดียวที่ต้องการ และ "ยอดรวมท้ายวัน" (ติ๊กไว้ตั้งต้น)

## วิธีอ่านตัวเลขสำคัญ
- ในแยกประเภท ยอดคงเหลือ = ยอดยกมา + เดบิต - เครดิต บัญชีที่มียอดด้านเครดิตจะเห็นยอดคงเหลือติดลบ
- ใบปะหน้าเอกสารแสดงรายการเดบิต-เครดิตซึ่งต้องเท่ากันเสมอ
- รายงานกลุ่มนี้รวมรายการที่ยังไม่ได้กดผ่านรายการด้วย
