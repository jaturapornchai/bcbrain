# รายงานทะเบียนเช็คจ่าย

เมนู: เมนูเงินสด/ธนาคาร > กลุ่ม "รายงานทะเบียนเช็คจ่าย"

| ชื่อรายงาน | ดูอะไรได้ | ใช้ตอนไหน |
|---|---|---|
| รายงานเช็คจ่ายยกมา | เอกสารเช็คจ่ายยกมาตอนเริ่มใช้ระบบ ทีละเอกสาร | ตรวจยอดตั้งต้น |
| รายงานทะเบียนเช็คจ่าย | เช็คจ่ายทุกใบที่จ่ายในช่วงวันที่ แสดงวันที่จ่ายเช็ค เอกสารอ้างอิง ธนาคาร สาขา สมุดธนาคาร เลขที่เช็ค วันที่บนเช็ค เจ้าหนี้ และจำนวนเงิน (ไม่มีคอลัมน์สถานะ) | ดูรายการเช็คที่จ่ายทั้งหมด |
| รายงานรายละเอียดเช็คจ่าย - ตามวันที่รับ - ตามสถานะเช็ค | เช็คที่จ่ายในช่วงวันที่ (แม้ชื่อรายงานเขียนว่าวันที่รับ แต่กรองตามวันที่จ่ายเช็ค) มีคอลัมน์ "สถานะเช็ค" | ดูว่าเช็คแต่ละใบขึ้นเงินแล้วหรือยัง |
| รายงานรายละเอียดเช็คจ่าย - วันครบกำหนด | เช็คที่วันที่บนเช็คอยู่ในช่วงวันที่ มีคอลัมน์ "สถานะ" | เตรียมเงินในบัญชีให้พอ |
| รายงานเช็คผ่าน (เช็คจ่าย) | เอกสารบันทึกเช็คผ่านในช่วงวันที่ | ยืนยันเงินออก |
| รายงานเช็คคืน (เช็คจ่าย) | เอกสารบันทึกเช็คจ่ายคืนในช่วงวันที่ | ตรวจเช็คคืน |
| รายงานเช็คขาดสิทธิ์ (เช็คจ่าย) | เอกสารบันทึกเช็คจ่ายขาดสิทธิ์ในช่วงวันที่ | ตรวจเช็คที่หมดอายุ |
| รายงานการเปลี่ยนเช็ค (เช็คจ่าย) | เอกสารเปลี่ยนเช็คจ่ายในช่วงวันที่ | ตรวจประวัติการเปลี่ยนเช็ค |

## ตัวกรองสำคัญ
- ช่วงวันที่: รายงานทะเบียนและรายละเอียดตามสถานะ ใช้วันที่จ่ายเช็ค รายงานวันครบกำหนด ใช้วันที่บนเช็ค รายงานยกมา ผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค ใช้วันที่เอกสาร
- จากรหัส/ถึงรหัส: รายงานยกมา ทะเบียน และรายละเอียด กรองตามรหัสเจ้าหนี้ ส่วนรายงานผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค กรองตามเลขที่เอกสาร
- คำค้นหา
- รายงานยกมา ผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค แสดงหนึ่งแถวต่อเอกสาร กดปุ่ม "แสดงรายละเอียดสินค้า" เพื่อดูเช็คแต่ละใบในเอกสาร
- ไม่มีช่องติ๊กแสดงเอกสารที่ยกเลิก รายงานเอกสารเหล่านี้ไม่นับเอกสารที่ถูกยกเลิก ถ้าต้องการดูเอกสารที่ยกเลิก ใช้กลุ่ม "รายงานเอกสารยกเลิก (การเงิน/ธนาคาร/เช็ค)"

## วิธีอ่านตัวเลขสำคัญ
- เช็คจ่ายที่ยังไม่ขึ้นเงินแสดงสถานะ "เช็คในมือ" เมื่อบันทึกเช็คผ่านแล้วเป็น "เช็คผ่าน" เช็คที่บันทึกขาดสิทธิ์แสดงเป็น "เช็คยกเลิก"
- ยอดคงเหลือในรายงานสมุดเงินฝาก หักเช็คจ่ายเมื่อบันทึกเช็คผ่าน (เช็คจ่าย) แล้วเท่านั้น เช็คที่จ่ายไปแต่ยังไม่บันทึกผ่าน ยอดเงินจึงยังไม่ลด ใช้รายงานวันครบกำหนดเตรียมเงินให้พอ
- รายงานผ่าน คืน ขาดสิทธิ์ และเปลี่ยนเช็ค แสดงเอกสารที่บันทึกในช่วงวันที่ ไม่ใช่สถานะปัจจุบัน ถ้าต้องการรู้สถานะล่าสุด ให้ดูรายงานรายละเอียดเช็คจ่าย
