# รายงานเอกสารยกเลิก (ระบบเจ้าหนี้)

**เมนู:** เจ้าหนี้ › รายงานเอกสารยกเลิก (ระบบเจ้าหนี้) › (เลือกรายงาน)

| ชื่อรายงานบนจอ | ดูอะไรได้ |
|---|---|
| รายงานยกเลิกตั้งหนี้อื่นๆ | รายการยกเลิกใบตั้งหนี้อื่นๆ |
| รายงานยกเลิกเพิ่มหนี้อื่นๆ | รายการยกเลิกใบเพิ่มหนี้อื่นๆ |
| รายงานยกเลิกลดหนี้อื่นๆ | รายการยกเลิกใบลดหนี้อื่นๆ |
| รายงานยกเลิกใบรับวางบิล ( เจ้าหนี้ ) | รายการยกเลิกใบรับวางบิล |
| รายงานยกเลิกจ่ายชำระ (เจ้าหนี้) | รายการยกเลิกใบจ่ายชำระหนี้ |

## คอลัมน์ที่เห็น
เอกสารวันที่ · เอกสารเลขที่ · เอกสารอ้างอิงวันที่ · เอกสารอ้างอิง · รหัสเจ้าหนี้ · ชื่อเจ้าหนี้
(รายงานชุดนี้ไม่มีคอลัมน์จำนวนเงิน และไม่มีปุ่มแสดงรายละเอียด)

## ตัวกรองบนจอ
- **ตั้งแต่วันที่ / ถึงวันที่** นับตามวันที่ของเอกสารยกเลิกนั้น
- **จากรหัสเจ้าหนี้ / ถึงรหัสเจ้าหนี้** กรอกรหัสเดียวในช่องใดช่องหนึ่ง ระบบจะหาเฉพาะรหัสนั้น (ไม่ใช่ช่วงเลขที่เอกสาร) และมีช่อง "ช่วงรหัสเพิ่มเติม" สำหรับใส่หลายช่วงรหัส
- **เรียงตาม** เอกสารวันที่ เอกสารเลขที่ หรือรหัสเจ้าหนี้
- **ค้นหา** พิมพ์เลขที่เอกสาร เลขที่อ้างอิง รหัสหรือชื่อเจ้าหนี้
- ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" เพราะรายงานชุดนี้แสดงเอกสารยกเลิกอยู่แล้ว
