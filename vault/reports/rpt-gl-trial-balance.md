# รายงานงบทดลอง และกระดาษทำการ

เมนู: บัญชี › รายงานงบทดลอง กระดาษทำการ และงบการเงิน

งบทดลอง (Trial Balance) คือตารางยอดของทุกบัญชี ใช้ตรวจว่ายอดเดบิตรวมเท่ากับยอดเครดิตรวม ก่อนทำงบการเงิน รายงานกลุ่มนี้รวมรายการที่ยังไม่ได้กดผ่านรายการด้วย

| ชื่อรายงาน | ดูอะไรได้ | ใช้ตอนไหน |
|---|---|---|
| รายงานงบทดลอง (มาตรฐาน) | ทุกบัญชี: ยอดยกมา ยอดประจำงวด ยอดสะสม ฝั่งเดบิต/เครดิต ท้ายรายงานมีบรรทัด "กำไร (ขาดทุน)" | ตรวจสมดุลบัญชีสิ้นเดือน/สิ้นปี |
| รายงานงบทดลอง (แยกแผนก) | เฉพาะบัญชีรายได้และค่าใช้จ่ายในช่วงวันที่ แยกช่องตามสาขาและแผนก มีช่องรวม | ดูรายได้-ค่าใช้จ่ายของแต่ละแผนก |
| รายงานงบทดลอง (แยกสาขา) | ยอดเดบิต/เครดิตเฉพาะในช่วงวันที่ (ไม่มียอดยกมา) แยกช่องตามสาขา มีช่องรวม | ดูความเคลื่อนไหวของแต่ละสาขา |
| รายงานกระดาษทำการ | ยอดสะสมถึงวันที่สิ้นสุด แบ่งเป็นช่องงบทดลอง ช่องกำไรขาดทุน และช่องงบดุล ท้ายรายงานมีบรรทัด "กำไร (ขาดทุน) สุทธิ" | ใช้ตอนปิดบัญชีประจำปี |

## ตัวกรองสำคัญ
- ช่วงวันที่ (จากวันที่ ถึงวันที่) และช่วงรหัสบัญชี
- "ต้องการแสดงยอดสุทธิ" มีผลกับช่องยอดประจำงวดเท่านั้น ติ๊กแล้วแต่ละบัญชีแสดงด้านเดียวตามยอดสุทธิ ไม่ติ๊กจะแสดงเดบิตและเครดิตรวมแยกกัน (รายงานงบทดลอง (มาตรฐาน) ติ๊กไว้ตั้งต้น หน้าจอแสดงงบทดลองไม่ติ๊กไว้ตั้งต้น)
- "ต้องการแสดงยอดปรับปรุง" "รวมรายการปิดบัญชี" "รวมรายการยกไป" ค่าตั้งต้นติ๊กทั้งสามช่อง มีผลเฉพาะรายการประเภทนั้นที่ลงวันที่ตรงกับ "ถึงวันที่" เท่านั้น รายการก่อนวันนั้นนับเข้ายอดประจำงวดเสมอ

## วิธีอ่านตัวเลขสำคัญ
- ยอดยกมา = ทุกรายการก่อนวันที่เริ่มต้น รวมรายการยอดยกมาที่ลงในช่วงวันที่ และรายการยกไปที่ลงก่อนวันสุดท้าย ยอดยกมาไม่เปลี่ยนตามช่องติ๊ก
- ยอดประจำงวด = รายการระหว่างช่วงวันที่ที่เลือก ตามช่องติ๊กข้างบน
- ยอดสะสม/ยอดยกไป = ยอดยกมา + ยอดประจำงวด
- ท้ายรายงาน ยอดเดบิตรวมต้องเท่ากับยอดเครดิตรวม ถ้าไม่เท่ากันส่งต่อเจ้าหน้าที่

## จุดที่มักสับสน
- ยอดต่างจากรายงานลูกหนี้/เจ้าหนี้/สต็อก ดู [[faq-rpt-ar-vs-ledger]] [[ts-rpt-numbers-mismatch]]
- ถ้าต้องการยอดก่อนปิดบัญชีของวันสิ้นปี ให้ตั้ง "ถึงวันที่" เป็นวันปิดบัญชี แล้วไม่ติ๊ก "รวมรายการปิดบัญชี" และ "รวมรายการยกไป"
- รายการที่ยังไม่ได้กดผ่านรายการก็นับเข้างบทดลองแล้ว ถ้ายอดดูแปลก ตรวจรายการเหล่านั้นก่อน
