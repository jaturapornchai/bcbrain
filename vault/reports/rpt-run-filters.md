# เงื่อนไขกรองรายงาน

## แถบเงื่อนไขที่พบในรายงานส่วนใหญ่
| ช่อง | ความหมาย |
|---|---|
| ตั้งแต่วันที่ / ถึงวันที่ | ช่วงวันที่ของเอกสาร ค่าเริ่มต้นคือ 1 มกราคมของปีปัจจุบัน ถึงวันนี้ รายงานที่เป็นรายชื่อหรือยอด ณ ปัจจุบันจะไม่แสดงช่องวันที่ รายงานอายุหนี้และยอดค้างคิด ณ วันที่ "ถึงวันที่" |
| จาก...: / ถึง...: | ช่วงรหัส ชื่อช่องเปลี่ยนตามรายงาน เช่น จากรหัสสินค้า จากรหัสเจ้าหนี้ จากรหัสลูกหนี้ จากรหัสพนักงานขาย เว้นว่าง = ทั้งหมด |
| เรียงตาม | เลือกลำดับแถว ตัวเลือกคือชื่อคอลัมน์ของรายงานนั้น หรือ "ค่าเริ่มต้นตามระบบ" |
| ช่องค้นหา และปุ่ม "ค้นหา" | พิมพ์บางส่วนของรหัส ชื่อ หรือเลขที่เอกสาร ไม่สนตัวพิมพ์เล็กใหญ่ ช่องที่ค้นได้ต่างกันตามรายงาน |
| ปุ่ม "สรุปตามเอกสาร" / "แสดงรายละเอียดสินค้า" | สลับระหว่างดูรายเอกสารกับดูรายการสินค้าใต้เอกสาร ปุ่มนี้ขึ้นเฉพาะรายงานที่มีรายละเอียด |

กด Enter ในช่องวันที่หรือช่องรหัสก็ประมวลผลได้ ผลลัพธ์ปิดท้ายด้วยแถว "รวมทั้งสิ้น (จำนวนรายการ)" ถ้าไม่มีข้อมูลหน้าจอแจ้งว่าไม่พบข้อมูลตามเงื่อนไข

## เงื่อนไขเพิ่มเติม (มีเฉพาะบางรายงาน)
ช่องเหล่านี้ขึ้นใต้แถบหลักเฉพาะรายงานที่รองรับ ไม่ใช่ทุกรายงาน ต้องเปิดดูรายงานนั้นจริง
- "แสดงเอกสารที่ยกเลิก" มีในรายงานเอกสารฝั่งซื้อ/ขายส่วนใหญ่ แต่ไม่มีในรายงานสรุป รายงานวิเคราะห์ และรายงานยกเลิกเอง ปกติไม่ติ๊ก เอกสารที่ยกเลิกจะไม่รวม ผลเมื่อติ๊กต่างกันตามรายงาน บางรายงานแสดงยอดเป็น 0 บางรายงานแสดงยอดเต็มปนกับเอกสารปกติ ดู [[faq-rpt-cancelled-docs]]
- "ช่วงรหัสเจ้าหนี้เพิ่มเติม" "ช่วงรหัสลูกหนี้เพิ่มเติม" "ช่วงรหัสสินค้าเพิ่มเติม" ใส่หลายช่วงพร้อมกัน คั่นด้วยจุลภาค เช่น A001..A099,B005 (จาก..ถึง หรือรหัสเดียว)
- "คลัง" และ "พื้นที่เก็บ" ในรายงานสต็อก คั่นด้วยจุลภาค เว้นว่าง = ทุกคลัง
- "แสดงสินค้ายอดเป็นศูนย์" ในรายงานยอดคงเหลือสินค้า
- "การแสดงมูลค่าตามประเภทภาษี" (ปรกติ / แยกนอกทั้งหมด / รวมในทั้งหมด) เฉพาะรายงานบิลขาย รับคืน และเพิ่มหนี้ฝั่งขาย
- "แคชเชียร์" หรือ "พนักงานขาย" "ประเภทการขาย" "แสดงเฉพาะ" (POS) เฉพาะรายงานบิลขายรายใบ ดู [[rpt-so-sales-docs]]
- "ตั้งแต่เวลา" "ถึงเวลา" เฉพาะรายงานรับและคืนเงินล่วงหน้า/มัดจำฝั่งขาย ดู [[rpt-so-deposit-advance]]
- หน้าจอรายงานไม่มีช่อง "สาขา"

## ข้อควรรู้
- เงื่อนไขกว้างมากทำให้รายงานช้า ลองแบ่งช่วงวันที่ ดู [[ts-rpt-slow-too-big]]
- ไม่เห็นข้อมูลที่ควรมี ดู [[ts-rpt-no-data]]
- ผลลัพธ์บนหน้าจอเปลี่ยนตามเงื่อนไขทุกครั้งที่กดประมวลผล ปุ่มพิมพ์และส่งออกใช้ผลชุดเดียวกัน ดู [[rpt-print-export]]
