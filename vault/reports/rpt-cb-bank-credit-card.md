# รายงานสมุดเงินฝากธนาคารและบัตรเครดิต

เมนู: เมนูเงินสด/ธนาคาร > กลุ่ม "รายงานสมุดเงินฝากธนาคารและบัตรเครดิต"

| ชื่อรายงาน | ดูอะไรได้ | ใช้ตอนไหน |
|---|---|---|
| รายงานยอดเงินคงเหลือสมุดฝากธนาคาร | ยอดเงินคงเหลือของสมุดเงินฝากแต่ละเล่ม ณ วันที่สิ้นสุด | ดูเงินในบัญชีตามบัญชีบริษัท |
| รายงาน Bank Statement | รายการเงินเข้า เงินออก และยอดคงเหลือของสมุดเงินฝาก เรียงตามวันที่ เริ่มจากยอดยกมา | เทียบกับรายการเดินบัญชีจากธนาคาร |
| รายงาน Statement ล่วงหน้า | เช็ครับและเช็คจ่ายที่ยังไม่ผ่าน (ยังอยู่ในมือหรือนำฝากแล้ว) และบัตรเครดิตที่รอขึ้นเงิน เรียงตามวันที่บนเช็ค แยกยอดรับ ยอดจ่าย | ดูเงินที่จะเข้า-ออกบัญชีในอนาคต |
| รายงานการฝากเงิน | เอกสารฝากเงิน | ตรวจเงินที่นำฝาก |
| รายงานการถอนเงิน | เอกสารถอนเงิน | ตรวจเงินที่ถอน |
| รายงานการโอนเงินระหว่างธนาคาร | เอกสารโอนระหว่างสมุดเงินฝาก ดูรายละเอียดได้ทั้งสมุดต้นทาง ปลายทาง ยอดโอน และค่าธรรมเนียม | ตรวจการโอนระหว่างบัญชี |
| รายงานรายการรับบัตรเครดิต | บัตรเครดิตที่รับชำระในช่วงวันที่ | ตรวจยอดผ่านบัตร |
| รายงานรายละเอียดบัตรเครดิต - ตามวันที่รับ | รายการบัตรเรียงตามวันที่รับ มีคอลัมน์ "สถานะ" (รอขึ้นเงิน / ขึ้นเงินแล้ว) | เทียบกับใบสรุปยอดจากผู้ให้บริการบัตร |
| รายงานขึ้นเงินบัตรเครดิต | เอกสารขึ้นเงินบัตรเครดิตเข้าบัญชี ดูรายละเอียดได้ทั้งยอดบัตร ค่าธรรมเนียม และยอดเข้าบัญชี | ตรวจเงินที่เข้าบัญชีจากบัตร |

## ตัวกรองสำคัญ
- ช่วงวันที่: รายงาน Statement ล่วงหน้า ใช้วันที่บนเช็ค รายงานบัตรเครดิตใช้วันที่รับ รายงานเอกสารใช้วันที่เอกสาร ส่วนยอดคงเหลือใช้วันที่สิ้นสุด
- จากรหัส/ถึงรหัส: ยอดคงเหลือและ Bank Statement กรองตามรหัสสมุด รายงานบัตรเครดิตกรองตามรหัสลูกหนี้ Statement ล่วงหน้ากรองตามเลขที่เอกสารอ้างอิง รายงานฝาก ถอน โอน และขึ้นเงินบัตร กรองตามเลขที่เอกสาร
- คำค้นหา
- รายงานฝาก ถอน โอน และขึ้นเงินบัตร แสดงหนึ่งแถวต่อเอกสาร กดปุ่ม "แสดงรายละเอียดสินค้า" เพื่อดูรายการย่อย
- ไม่มีช่องติ๊กแสดงเอกสารที่ยกเลิก รายงานเอกสารไม่นับเอกสารที่ถูกยกเลิก ถ้าต้องการดูเอกสารที่ยกเลิก ใช้กลุ่ม "รายงานเอกสารยกเลิก (การเงิน/ธนาคาร/เช็ค)"

## วิธีอ่านตัวเลขสำคัญ
- ยอดคงเหลือตามสมุดเงินฝากคือยอดตามบัญชีบริษัท อาจต่างจากยอดที่ธนาคารแจ้งเพราะเช็คยังไม่ขึ้นเงินหรือรายการค้างบันทึก
- Bank Statement สร้างจากรายการในสมุดเงินฝากของระบบ ไม่ใช่ไฟล์ที่ได้จากธนาคาร ค่าธรรมเนียมการโอนนับเป็นเงินออกของสมุดต้นทางด้วย
- **ข้อควรระวัง:** บัตรที่บันทึกด้วย "บันทึกยกเลิกบัตรเครดิต" อาจแสดงสถานะเป็น "ขึ้นเงินแล้ว" ในรายงานรายละเอียดบัตรเครดิต ถ้าเจอกรณีนี้ → ส่งต่อเจ้าหน้าที่
