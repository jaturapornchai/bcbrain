# รายงานสรุปยอดค้างชำระและการจ่ายเงิน (เจ้าหนี้)

**เมนู:** เจ้าหนี้ › รายงานสรุปยอดค้างชำระและการจ่ายเงิน › (เลือกรายงาน)

| ชื่อรายงานบนจอ | ดูอะไรได้ |
|---|---|
| รายงานใบส่งของค้างจ่ายชำระ-ตามวันที่ | เอกสารตั้งหนี้เจ้าหนี้ (ซื้อ เพิ่มหนี้ ลดหนี้ ยอดยกมา ฯลฯ) ที่ลงวันที่ในช่วงที่เลือกและยังจ่ายไม่ครบ |
| รายงานใบส่งของถึงกำหนดชำระ-ตามวันที่ | เอกสารที่ยังค้างจ่ายและมีวันครบกำหนดอยู่ในช่วงวันที่ที่เลือก |
| รายงานใบส่งของค้างชำระแสดงวันที่ถึงกำหนด | ยอดค้างจ่ายพร้อมประเภทเอกสาร เครดิต (วัน) และวันที่ครบกำหนด |
| รายงานใบส่งของเกินกำหนดชำระ-ตามวันที่ | เอกสารที่ยังค้างจ่ายและวันครบกำหนดอยู่ก่อน "ถึงวันที่" (นับตั้งแต่ "ตั้งแต่วันที่") แยกยอดตามช่วงวันที่เกิน |
| รายงานจ่ายชำระค่าสินค้า-ตามใบส่งของ | หนึ่งแถวต่อหนึ่งใบส่งของที่จ่ายไปแล้ว |
| รายงานการจ่ายชำระประจำวัน-ตามวันที่ | ใบจ่ายชำระแต่ละใบ แยกเงินสด เช็ค เงินโอน |
| รายงานการจ่ายเงินประจำวัน-ตามแผนก | เหมือนรายงานก่อนหน้า แต่มีรหัสและชื่อแผนกนำหน้า |

## ตัวกรองบนจอ
- **ตั้งแต่วันที่ / ถึงวันที่** "ถึงวันที่" คือวันที่ที่ใช้คิดยอดค้าง (นับการจ่ายที่ลงวันที่ไม่เกินวันนี้) ส่วน "ตั้งแต่วันที่" ใช้กรองตามวันที่เอกสารหรือวันครบกำหนดของแต่ละรายงานตามตารางข้างบน
- **จากรหัสเจ้าหนี้ / ถึงรหัสเจ้าหนี้** ส่วนรายงานการจ่ายเงินประจำวัน-ตามแผนก ช่องนี้เปลี่ยนเป็น **จากรหัสแผนก / ถึงรหัสแผนก**
- **เรียงตาม** รายงานค้างจ่ายทั้งสี่เลือกเรียงตามวันที่เอกสาร วันที่ครบกำหนด เลขที่เอกสาร หรือรหัสเจ้าหนี้ รายงานจ่ายชำระค่าสินค้า-ตามใบส่งของเรียงตามเลขที่ใบส่งของ วันที่ชำระ หรือรหัสเจ้าหนี้
- **ค้นหา** เลขที่เอกสาร รหัสหรือชื่อเจ้าหนี้
- รายงานชุดนี้ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" และไม่นับเอกสารที่ยกเลิกเลย

## วิธีอ่านตัวเลข
- รายงานค้างจ่าย: ยอดค้าง = ยอดเอกสาร - เงินที่จ่ายถึง "ถึงวันที่" แสดงเฉพาะเอกสารที่ยอดค้างไม่เป็นศูนย์ ใบลดหนี้และส่งคืนสินค้าเป็นยอดติดลบ คอลัมน์ที่เห็น เช่น ยอดตั้งหนี้ ยอดลดหนี้ จ่ายชำระหนี้ ยอดคงเหลือ เกิน(วัน)
- รายงานเกินกำหนด: ยอดคงเหลือถูกแยกเป็นคอลัมน์ "จาก 1-7 วัน" "จาก 8-14 วัน" "จาก 15-21 วัน" "จาก 22-28 วัน" "เกินกว่า 30 วัน" และ "ไม่อยู่ในช่วง" ยอดที่เกินกำหนด 29-30 วันจะถูกใส่ไว้ในคอลัมน์ "ไม่อยู่ในช่วง" ไม่ได้หายไป
- รายงานจ่ายชำระค่าสินค้า-ตามใบส่งของ: คอลัมน์ ยอดรวม ยอดจ่าย กำไร/ขาดทุน
- รายงานจ่ายประจำวัน: คอลัมน์ ยอดเงินสดจ่าย ยอดเช็คจ่าย ยอดเงินโอน เงินสดย่อย เกินใบเสร็จ หักเงินเกิน ปัดเป็นรายได้ ปัดเป็นค่าใช้จ่าย ยอดเงินรวม ถ้าตัวเลขแยกประเภทไม่ตรงกับใบจ่ายชำระให้ส่งต่อเจ้าหน้าที่
