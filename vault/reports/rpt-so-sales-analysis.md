# รายงานวิเคราะห์การขายและกำไร

เมนู: ขาย > รายงานวิเคราะห์การขายและกำไร มี 7 รายงาน ทุกรายงานคิดจากบิลขายสินค้า/บริการที่ไม่ถูกยกเลิก

| ชื่อรายงาน | แสดงอะไร | คอลัมน์หลัก |
|---|---|---|
| รายงานวิเคราะห์การขายแบบแจกแจง-ตามสินค้า | ทุกรายการขายในบิล | รหัสสินค้า, ชื่อสินค้า, เอกสารวันที่, เลขที่, หน่วยนับ, จำนวน, ราคา, มูลค่าส่วนลด, มูลค่าก่อนภาษี, ภาษีมูลค่าเพิ่ม, รวมมูลค่า (ไม่มีต้นทุนและกำไร) |
| รายงานวิเคราะห์การขายแบบสรุป-ตามเอกสาร | บิลขายทีละใบ | วันที่, เลขที่, รหัสและชื่อลูกหนี้, มูลค่าสินค้า, ส่วนลด, ยอดก่อนภาษี, ภาษี, มูลค่าสุทธิ, ภาษีหัก ณ ที่จ่าย, รวมต้นทุน (ไม่มีคอลัมน์กำไร) |
| รายงานกำไรขั้นต้นแสดงหักรับคืน | แต่ละรายการในบิลขาย หักใบรับคืนที่อ้างถึงบิลนั้น | จำนวนสินค้า, มูลค่าขาย, ต้นทุนขาย, จำนวน/มูลค่า/ต้นทุนรับคืน, มูลค่าสุทธิ, ต้นทุนสุทธิ, กำไรขั้นต้น, % ต่อต้นทุน, % ต่อยอดสุทธิ |
| รายงานจัดอันดับยอดขาย-ตามสินค้า | สินค้าขายดี เรียงตามจำนวนที่ขายมากไปน้อย | รหัสสินค้า, ชื่อสินค้า, หน่วยนับ, จำนวน, มูลค่าสุทธิ, รวมต้นทุน, กำไร(ขาดทุน), % ต่อต้นทุน, % ต่อยอดสุทธิ |
| รายงานเปรียบเที่ยบยอดสินค้า12 เดือน | มูลค่าขายรายสินค้า 12 เดือน | รหัสสินค้า, ชื่อสินค้า, หน่วยนับ, มูลค่ารายเดือน 12 ช่อง และรวมมูลค่า |
| รายงานการเทียบการขายกับราคาขาย | ราคาที่ขายจริงเทียบกับราคากลางของสินค้า | วันที่, เลขที่, ลูกหนี้, สินค้า, หน่วยนับ, จำนวน, ราคา, ราคากลาง, ผลต่าง, รหัสพนักงานขาย |
| รายงานสินค้าขายต่ำกว่าทุน | รายการขายที่ยอดก่อนภาษีต่ำกว่าต้นทุน | วันที่, เลขที่, รหัสและชื่อสินค้า, จำนวน, หน่วยนับ, ลูกหนี้, รวมต้นทุน, รวมมูลค่า (ก่อนภาษี) |

## ตัวกรองที่มีบนหน้าจอ
- ตั้งแต่วันที่ / ถึงวันที่ (ตามวันที่บิลขาย)
- ช่วงรหัส: เป็น "รหัสสินค้า" ทุกรายงาน ยกเว้นรายงานแบบสรุป-ตามเอกสารที่เป็น "รหัสลูกหนี้"
- ช่องค้นหา (เลขที่เอกสาร รหัสหรือชื่อสินค้า และบางรายงานค้นชื่อลูกหนี้ได้ด้วย) และ "เรียงตาม"
- ไม่มีปุ่ม "แสดงรายละเอียดสินค้า" ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" และไม่มีตัวเลือกประเภทภาษี

## ข้อควรรู้
- กำไรขั้นต้น = มูลค่าก่อนภาษี ลบ ต้นทุนขาย ยังไม่รวมค่าใช้จ่ายดำเนินงาน
- รายงานจัดอันดับ ไม่หักใบรับคืน ถ้าต้องการกำไรจริงหลังรับคืนใช้ "รายงานกำไรขั้นต้นแสดงหักรับคืน"
- รายงานเทียบกับราคากลาง: ผลต่าง = ราคากลาง ลบ ราคาที่ขาย ถ้าสินค้านั้นไม่มีราคากลางตั้งไว้ ช่องราคากลางจะว่าง แต่ช่องผลต่างจะติดลบเท่ากับราคาขาย อย่าตีความว่าขายแพงกว่าราคากลาง
- รายงานเปรียบเทียบ 12 เดือน แสดงเฉพาะมูลค่า นับย้อนหลัง 12 เดือนจากเดือนของ "ถึงวันที่" โดยไม่สนใจ "ตั้งแต่วันที่" ควรพิมพ์แนวนอน
- รายงานที่มีคอลัมน์ต้นทุน (แบบสรุป-ตามเอกสาร, กำไรขั้นต้นหักรับคืน, จัดอันดับ, ต่ำกว่าทุน) ถ้าลูกค้าต้องการจำกัดว่าใครเห็นต้นทุนในรายงานกลุ่มนี้ ให้ส่งต่อเจ้าหน้าที่ช่วยตั้งค่า ดู [[ts-rpt-no-cost-permission]] สำหรับรายงานสินค้าที่ซ่อนต้นทุนตามสิทธิ์
