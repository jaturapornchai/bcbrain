# รายงานใบเสนอซื้อและใบสั่งซื้อ (PR / PO)

เมนู: ซื้อ > รายงานใบเสนอซื้อและใบสั่งซื้อ (PR / PO) มี 7 รายงาน

| ชื่อรายงาน | ดูอะไรได้ |
|---|---|
| รายงานใบเสนอซื้อ | รายการใบเสนอซื้อ (PR) ที่ไม่ถูกยกเลิก |
| รายงานอนุมัติใบเสนอซื้อ | ใบเสนอซื้อที่ผ่านการอนุมัติแล้ว พร้อมบอกว่า "รอออกใบสั่งซื้อ" หรือ "ออกใบสั่งซื้อเรียบร้อย" |
| รายงานสถานะใบเสนอซื้อ | ใบเสนอซื้อพร้อมสถานะล่าสุด ถ้ากด "แสดงรายละเอียดสินค้า" จะเห็นจำนวน ราคา ส่วนลด และมูลค่าที่อนุมัติของแต่ละรายการ |
| รายงานบันทึกใบสั่งซื้อ | รายการใบสั่งซื้อ (PO) พร้อมสถานะล่าสุด |
| รายงานอนุมัติใบสั่งซื้อ | ใบสั่งซื้อที่ผ่านการอนุมัติ มีคอลัมน์ "ผู้อนุมัติ" แต่ไม่มีคอลัมน์สถานะ |
| รายงานสถานะใบสั่งซื้อ | หน้าตาและตัวเลขเหมือน "รายงานบันทึกใบสั่งซื้อ" ทุกประการ |
| รายงานค้างรับสินค้าตามใบสั่งซื้อ | รายการใบสั่งซื้อพร้อมสถานะล่าสุด (ดูข้อจำกัดด้านล่าง) |

## ตัวกรองที่มีบนหน้าจอ
- ตั้งแต่วันที่ / ถึงวันที่ (กรองตามวันที่ของเอกสาร)
- จากรหัสเจ้าหนี้ / ถึงรหัสเจ้าหนี้
- "ช่วงรหัสเจ้าหนี้เพิ่มเติม" ใส่หลายช่วงได้ คั่นด้วยเครื่องหมายจุลภาค เช่น A001..A099,B005
- ช่องค้นหา (เลขที่เอกสาร เอกสารอ้างอิง รหัสหรือชื่อเจ้าหนี้) และ "เรียงตาม" คอลัมน์ที่ต้องการ
- ปุ่ม "แสดงรายละเอียดสินค้า" ดูรายการสินค้าในแต่ละเอกสาร (ทุกรายงานในกลุ่มนี้มี ยกเว้นรายงานค้างรับ)
- ช่อง "แสดงเอกสารที่ยกเลิก" มีเฉพาะ รายงานใบเสนอซื้อ, รายงานสถานะใบเสนอซื้อ, รายงานบันทึกใบสั่งซื้อ, รายงานอนุมัติใบสั่งซื้อ และรายงานสถานะใบสั่งซื้อ ส่วนรายงานอนุมัติใบเสนอซื้อและรายงานค้างรับไม่มีช่องนี้ ปกติเอกสารที่ยกเลิกจะไม่แสดง
- เอกสารที่เป็นสำเนาจะไม่ถูกนับในรายงานเหล่านี้

## คอลัมน์ที่เห็น
- ใบเสนอซื้อ: เอกสารวันที่, เอกสารเลขที่, เวลา, รหัสเจ้าหนี้, ชื่อเจ้าหนี้, ประเภทรายการ, แผนก, กลุ่มเอกสาร, ผู้ขออนุมัติ, กลุ่มผู้อนุมัติ (ในรายงานอนุมัติเป็น "ผู้อนุมัติ"), สถานะล่าสุด และ ยอดก่อนภาษี
- ใบสั่งซื้อ: เอกสารวันที่, เลขที่, เอกสารอ้างอิงวันที่, เอกสารอ้างอิง, รหัสและชื่อเจ้าหนี้, มูลค่าสินค้า, มูลค่าส่วนลด, มูลค่าหลังหักส่วนลด, มูลค่ายกเว้นภาษี, ภาษีมูลค่าเพิ่ม, มูลค่าสุทธิ, ผู้ขออนุมัติ, กลุ่มผู้อนุมัติ และสถานะล่าสุด
- สถานะล่าสุดที่เป็นไปได้: รออนุมัติ, อนุมัติเรียบร้อย, ไม่อนุมัติ, ระงับชั่วคราว, เอกสารหมดอายุ, ยกเลิก (ใบสั่งซื้อมีเพิ่ม "รับบางส่วน" และ "รับสมบูรณ์")

## ข้อจำกัดที่ต้องบอกลูกค้า
- รายงานค้างรับสินค้าตามใบสั่งซื้อ ไม่ได้คำนวณจำนวนที่ค้างรับ และไม่ได้ตัดใบที่รับครบแล้วออก ให้ดูคอลัมน์สถานะล่าสุด ใบที่ยังไม่ใช่ "รับสมบูรณ์" คือใบที่ยังไม่รับครบ ถ้าลูกค้าต้องการจำนวนที่ค้างรับรายสินค้า ให้ส่งต่อเจ้าหน้าที่
- รายงานสถานะใบสั่งซื้อ แสดงข้อมูลชุดเดียวกับรายงานบันทึกใบสั่งซื้อ ไม่มีข้อมูลเพิ่ม
- รายงานอนุมัติใบเสนอซื้อ ใช้คำว่า "ออกใบสั่งซื้อ" ในคอลัมน์สถานะเสมอ
