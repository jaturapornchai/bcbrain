# รายงานใบวางบิลและการรับชำระหนี้

**เมนู:** ลูกหนี้ › รายงานใบวางบิลและการรับชำระหนี้ › (เลือกรายงาน)

| ชื่อรายงานบนจอ | ดูอะไรได้ |
|---|---|
| รายงานใบวางบิล (ลูกหนี้) | ใบวางบิลที่ออกให้ลูกหนี้ แสดงวันที่ เลขที่ วันที่ครบกำหนด และจำนวนเงินวางบิล |
| รายงานการรับชำระหนี้ประจำวัน | หนึ่งแถวต่อหนึ่งบิลที่ได้รับชำระ แสดงวันที่ออกบิล เลขที่บิล ลูกหนี้ จำนวนเงิน ยอดคงเหลือ ยอดชำระ เลขที่ใบรับชำระ และพนักงานขาย |
| รายงานการรับชำระหนี้/ออกใบเสร็จรับเงิน | ใบรับชำระหนี้/ใบเสร็จรับเงิน แสดงวันที่ เลขที่ ลูกหนี้ และจำนวนเงิน |
| รายงานการรับชำระหนี้/ออกใบเสร็จรับเงิน (แสดงรายละเอียดการรับเงินสด,เงินโอน) | ดูหมายเหตุด้านล่าง |

## ตัวกรองบนจอ
- **ตั้งแต่วันที่ / ถึงวันที่** วันที่ของเอกสาร
- **จากรหัสลูกหนี้ / ถึงรหัสลูกหนี้** กรอกรหัสเดียวในช่องใดช่องหนึ่ง ระบบจะหาเฉพาะรหัสนั้น และมีช่อง "ช่วงรหัสเพิ่มเติม" ใส่หลายช่วงได้
- **เรียงตาม** เอกสารวันที่ เอกสารเลขที่ หรือรหัสลูกหนี้
- **ค้นหา** เลขที่เอกสาร รหัสหรือชื่อลูกหนี้ (รายงานรับชำระประจำวันค้นเลขที่บิลได้ด้วย)
- **แสดงเอกสารที่ยกเลิก** มีเฉพาะ "รายงานใบวางบิล (ลูกหนี้)" และ "รายงานการรับชำระหนี้/ออกใบเสร็จรับเงิน" ปกติไม่ติ๊ก ถ้าติ๊กจะเห็นเอกสารที่ยกเลิกปนกับเอกสารปกติ
- **สรุปตามเอกสาร / แสดงรายละเอียดสินค้า** (ปุ่มสลับ มีใน 2 รายงานข้างบน) แสดงรายการบิลภายในใบวางบิลหรือใบรับชำระ ได้แก่ วันที่ออกบิล เลขที่บิล ประเภทเอกสาร ครบกำหนด จำนวนเงิน ยอดคงเหลือ ยอดชำระ
- เฉพาะ "รายงานการรับชำระหนี้ประจำวัน" มีช่องเพิ่ม: **จากเลขที่ใบรับ / ถึงเลขที่ใบรับ, จากวันที่ใบวางบิล / ถึงวันที่ใบวางบิล, จากเลขที่ใบวางบิล / ถึงเลขที่ใบวางบิล** แต่ละคู่ใช้งานก็ต่อเมื่อกรอกครบทั้งสองช่อง และถ้าบริษัทเปิดใช้สาขา จะมีช่อง "สาขา" (พิมพ์หลายรหัสคั่นด้วยจุลภาค หรือเป็นช่วงด้วยเครื่องหมายโคลอน)
- รายงานชุดนี้ไม่มีช่อง "ยอดรวมท้ายวัน"

## ข้อควรรู้และข้อจำกัด
- รายงานชุดนี้ไม่นับใบเสร็จที่ยกเลิก เว้นแต่ติ๊ก "แสดงเอกสารที่ยกเลิก" ในรายงานที่มีช่องนี้ ดูรายงานยกเลิกที่ [[rpt-ar-cancel-docs]]
- ในมุมมองสรุปของ "รายงานการรับชำระหนี้/ออกใบเสร็จรับเงิน" หัวคอลัมน์ยอดเงินขึ้นว่า "จำนวนเงินวางบิล" แต่ตัวเลขคือยอดรวมของใบรับชำระ (หัวคอลัมน์ติดผิด)
- รายงาน "...(แสดงรายละเอียดการรับเงินสด,เงินโอน)" ในระบบตอนนี้แสดงผลเหมือน "รายงานการรับชำระหนี้ประจำวัน" ทุกประการ ยังไม่มีคอลัมน์แยกเงินสด เงินโอน หรือเช็ค ถ้าลูกค้าต้องการแยกช่องทางรับเงิน ให้ส่งต่อเจ้าหน้าที่
