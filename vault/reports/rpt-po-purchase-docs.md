# รายงานการซื้อ รับสินค้า และเพิ่ม/ลดหนี้ซื้อ

เมนู: ซื้อ > รายงานการซื้อ ทะยอยรับ และเพิ่ม/ลดหนี้ มี 8 รายงาน

| ชื่อรายงาน | ดูอะไรได้ |
|---|---|
| รายงานการซื้อสินค้า/ตั้งหนี้ | เอกสารซื้อสินค้าและบริการ |
| รายงานการส่งคืนสินค้า/ลดหนี้ซื้อ | เอกสารส่งคืนสินค้า/ลดหนี้ซื้อ |
| รายงานการเพิ่มหนี้ซื้อ/ราคาผิด | เอกสารเพิ่มหนี้ซื้อ/ราคาผิด |
| รายงานรับสินค้า | เอกสารรับสินค้าแบบทะยอยรับ (ยังไม่ตั้งหนี้) |
| รายงานส่งคืนสินค้า/ราคาผิด | เอกสารส่งคืนสินค้าจากการรับแบบทะยอยรับ |
| รายงานตั้งหนี้จากการรับสินค้า | เอกสารตั้งหนี้ที่ออกจากการรับสินค้าแบบทะยอยรับ |
| รายงานเพิ่มหนี้จากใบตั้งหนี้ | เอกสารเพิ่มหนี้ที่ออกจากใบตั้งหนี้ทะยอยรับ |
| รายงานลดหนี้จากใบตั้งหนี้ | เอกสารลดหนี้ที่ออกจากใบตั้งหนี้ทะยอยรับ |

แต่ละรายงานแสดงเฉพาะเอกสารชนิดของตัวเอง ใบส่งคืน/ลดหนี้ไม่ถูกหักออกจากรายงานซื้อ ต้องดูแยกในรายงานของมัน

## ตัวกรองที่มีบนหน้าจอ
- ตั้งแต่วันที่ / ถึงวันที่ (ตามวันที่เอกสาร)
- จากรหัสเจ้าหนี้ / ถึงรหัสเจ้าหนี้ และ "ช่วงรหัสเจ้าหนี้เพิ่มเติม" (ใส่หลายช่วงคั่นด้วยจุลภาค)
- ช่องค้นหา (เลขที่เอกสาร เอกสารอ้างอิง รหัสหรือชื่อเจ้าหนี้) และ "เรียงตาม"
- ปุ่ม "แสดงรายละเอียดสินค้า" แตกรายการสินค้าของแต่ละเอกสาร
- ช่อง "แสดงเอกสารที่ยกเลิก"
- ฝั่งซื้อไม่มีตัวเลือก "การแสดงมูลค่าตามประเภทภาษี" (ตัวเลือกนี้มีเฉพาะรายงานฝั่งขาย)
- เอกสารที่เป็นสำเนาไม่ถูกนับ

## คอลัมน์ที่เห็น
- เอกสารวันที่, เอกสารเลขที่, รหัสเจ้าหนี้, ชื่อเจ้าหนี้
- รายงานรับสินค้า แสดง "วันที่ใบกำกับ" และ "เลขที่ใบกำกับ" ส่วนรายงานอื่นแสดง "เอกสารอ้างอิงวันที่" และ "เอกสารอ้างอิง"
- มูลค่าสินค้า, มูลค่าส่วนลด, มูลค่าหลังหักส่วนลด, มูลค่ายกเว้นภาษี, ภาษีมูลค่าเพิ่ม, มูลค่าสุทธิ
- เมื่อกด "แสดงรายละเอียดสินค้า": รหัสสินค้า, ชื่อสินค้า, คลัง, พื้นที่เก็บ, หน่วยนับ, จำนวน, ราคา, ส่วนลด, มูลค่าส่วนลด, รวมมูลค่า และประเภทภาษี (ขึ้น V เมื่อสินค้ามีภาษี)

## จุดที่ต้องระวัง
- ถ้าติ๊ก "แสดงเอกสารที่ยกเลิก" เอกสารที่ถูกยกเลิกจะปนอยู่กับเอกสารปกติ โดยยังแสดงยอดเงินเต็มและไม่มีคอลัมน์บอกว่ายกเลิก ยอดรวมจึงเกินจริง ปกติควรปล่อยช่องนี้ไว้ไม่ติ๊ก
- ยอดรวมรายงานซื้อไม่เท่ายอดเจ้าหนี้ เพราะเจ้าหนี้หักการจ่ายชำระและใบลดหนี้ ดู [[ts-rpt-numbers-mismatch]]
- ดูเอกสารที่ถูกยกเลิกโดยตรงได้ที่ [[rpt-po-cancel-docs]]
