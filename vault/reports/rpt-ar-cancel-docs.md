# รายงานเอกสารยกเลิก (ระบบลูกหนี้)

**เมนู:** ลูกหนี้ › รายงานเอกสารยกเลิก (ระบบลูกหนี้) › (เลือกรายงาน)

| ชื่อรายงานบนจอ | ดูอะไรได้ |
|---|---|
| รายงานยกเลิกตั้งหนี้อื่นๆ | รายการยกเลิกใบตั้งหนี้อื่นๆ |
| รายงานยกเลิกเพิ่มหนี้อื่นๆ | รายการยกเลิกใบเพิ่มหนี้อื่นๆ |
| รายงานยกเลิกลดหนี้อื่นๆ | รายการยกเลิกใบลดหนี้อื่นๆ |
| รายงานยกเลิกใบวางบิล(ลูกหนี้) | รายการยกเลิกใบวางบิล |
| รายงานยกเลิกรับชำระหนี้/ออกใบเสร็จรับเงิน | รายการยกเลิกใบรับชำระหนี้/ใบเสร็จรับเงิน |

## คอลัมน์ที่เห็น
เอกสารวันที่ · เอกสารเลขที่ · เอกสารอ้างอิงวันที่ · เอกสารอ้างอิง · รหัสลูกหนี้ · ชื่อลูกหนี้
(รายงานชุดนี้ไม่มีคอลัมน์จำนวนเงิน และไม่มีปุ่มแสดงรายละเอียด)

## ตัวกรองบนจอ
- **ตั้งแต่วันที่ / ถึงวันที่** นับตามวันที่ของเอกสารยกเลิกนั้น
- **จากรหัสลูกหนี้ / ถึงรหัสลูกหนี้** กรอกรหัสเดียวในช่องใดช่องหนึ่ง ระบบจะหาเฉพาะรหัสนั้น (ไม่ใช่ช่วงเลขที่เอกสาร) และมีช่อง "ช่วงรหัสเพิ่มเติม" ใส่หลายช่วงได้
- **เรียงตาม** เอกสารวันที่ เอกสารเลขที่ หรือรหัสลูกหนี้
- **ค้นหา** เลขที่เอกสาร เลขที่อ้างอิง รหัสหรือชื่อลูกหนี้
- ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" เพราะรายงานชุดนี้แสดงเอกสารยกเลิกอยู่แล้ว
