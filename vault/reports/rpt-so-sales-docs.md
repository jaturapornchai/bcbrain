# รายงานการขาย เพิ่มหนี้ และรับคืน/ลดหนี้

เมนู: ขาย > รายงานการขาย เพิ่มหนี้ และรับคืน/ลดหนี้ มี 4 รายงาน

| ชื่อรายงาน | ดูอะไรได้ |
|---|---|
| รายงานการขายสินค้าและบริการ | บิลขายทีละใบ (ขายสดและขายเชื่อรวมกัน) |
| รายงานการขายและบริการเรียงตามสินค้า | สรุปยอดขายรายสินค้า ไม่ใช่รายบิล |
| รายงานการรับคืนสินค้า/ลดหนี้ขาย | ใบรับคืนสินค้า/ลดหนี้ขายทีละใบ |
| รายงานการเพิ่มหนี้ขาย/ราคาผิด | ใบเพิ่มหนี้ขาย/ราคาผิดทีละใบ |

ใบรับคืนและใบเพิ่มหนี้เป็นรายงานแยก ไม่ถูกหักออกจากรายงานการขาย

## ตัวกรองที่มีบนหน้าจอ (สามรายงานแรกที่เป็นรายใบ)
- ตั้งแต่วันที่ / ถึงวันที่ (ตามวันที่เอกสาร)
- จากรหัสลูกหนี้ / ถึงรหัสลูกหนี้ และ "ช่วงรหัสลูกหนี้เพิ่มเติม"
- "การแสดงมูลค่าตามประเภทภาษี" มี 3 ตัวเลือก: "ปรกติ", "แสดงตัวเลขแบบแยกนอกทั้งหมด", "แสดงตัวเลขแบบรวมในทั้งหมด" (ระบบคำนวณด้วยอัตราภาษี 7 เปอร์เซ็นต์ตายตัว)
- "แคชเชียร์" ใส่รหัสผู้ใช้หลายคนคั่นด้วยจุลภาค เว้นว่าง = ทุกคน (ในรายงานรับคืน/ลดหนี้ขาย ช่องนี้ชื่อ "พนักงานขาย")
- เฉพาะ "รายงานการขายสินค้าและบริการ": "ประเภทการขาย" (ทั้งหมด / ขายเชื่อ / ขายสด) และ "แสดงเฉพาะ" (ทั้งหมด / เฉพาะ POS / เฉพาะที่ไม่ใช่ POS)
- ช่อง "แสดงเอกสารที่ยกเลิก"
- ช่องค้นหา และ "เรียงตาม"
- ปุ่ม "แสดงรายละเอียดสินค้า"
- เอกสารที่เป็นสำเนาไม่ถูกนับ

## คอลัมน์ที่เห็น
- รายงานรายใบ: เอกสารวันที่, เอกสารเลขที่, เวลา, เอกสารอ้างอิงวันที่, เอกสารอ้างอิง, รหัสลูกหนี้, ชื่อลูกหนี้, มูลค่าสินค้า, มูลค่าส่วนลด, มูลค่าหลังหักส่วนลด, มูลค่ายกเว้นภาษี, อัตราภาษี, ภาษีมูลค่าเพิ่ม, ประเภทภาษี, มูลค่าสุทธิ และแคชเชียร์ (รายงานรับคืน/ลดหนี้เป็นพนักงานขาย)
- ประเภทภาษีในรายงานแสดงเป็นตัวอักษร E แยกนอก, I รวมใน, C อัตราศูนย์
- รายงานเรียงตามสินค้า: รหัสสินค้า, ชื่อสินค้า, หน่วยนับ (หน่วยมาตรฐานของสินค้า), จำนวน (แปลงเป็นหน่วยมาตรฐานแล้ว), มูลค่าส่วนลด และรวมมูลค่า (ก่อนภาษี) ตัวกรองมีช่วงรหัสสินค้า ช่องค้นหา และปุ่ม "แสดงรายละเอียดสินค้า" ที่แตกเป็นรายเอกสารของแต่ละสินค้า รายงานนี้ไม่มีช่อง "แสดงเอกสารที่ยกเลิก"

## เมื่อติ๊ก "แสดงเอกสารที่ยกเลิก"
- รายงานการขายสินค้าและบริการ: ใบที่ยกเลิกจะแสดงยอดเงินเป็น 0 และช่องเอกสารอ้างอิงขึ้นคำว่า "ยกเลิก" จึงแยกออกจากใบปกติได้
- รายงานรับคืน/ลดหนี้ขาย และรายงานเพิ่มหนี้ขาย: ใบที่ยกเลิกยังแสดงยอดเงินเต็มและไม่มีเครื่องหมายบอก ยอดรวมจึงเกินจริง ปกติควรปล่อยช่องนี้ไว้ไม่ติ๊ก

- ยอดขายในรายงานไม่เท่ายอดลูกหนี้ เพราะลูกหนี้หักรับชำระและลดหนี้ ดู [[ts-rpt-numbers-mismatch]]
- ดูยอดขายสุทธิหลังหักรับคืนได้ที่ [[rpt-so-sales-summary]] และ [[rpt-so-sales-analysis]]
