# รายงานเงินสด เงินสดย่อย และรายได้/ค่าใช้จ่ายอื่น

เมนู: เมนูเงินสด/ธนาคาร > กลุ่ม "รายงานเงินสด เงินสดย่อย และรายได้/ค่าใช้จ่ายอื่น"

| ชื่อรายงาน | ดูอะไรได้ | ใช้ตอนไหน |
|---|---|---|
| รายงานเคลื่อนไหวเงินสด | ยอดยกมา รายการรับ-จ่ายเงินสด และมูลค่าคงเหลือ | ตรวจเงินสดในมือ |
| รายงานสรุปการรับเงิน | หนึ่งแถวต่อเอกสารรับเงิน แยกคอลัมน์ตามช่องทาง เช่น เงินสด เงินโอน เช็ค บัตรเครดิต เงินสดย่อย ภาษีถูกหัก ณ ที่จ่าย | ปิดยอดรับเงิน |
| รายงานสรุปการจ่ายเงิน | หนึ่งแถวต่อเอกสารจ่ายเงิน แยกคอลัมน์ตามช่องทางแบบเดียวกัน | ปิดยอดจ่ายเงิน |
| รายงานจ่ายเงินสดย่อย | เอกสาร "คืน/ลด วงเงินสดย่อย" | ตรวจการลดวงเงินสดย่อย |
| รายงานรับเงินสดย่อย | เอกสาร "รับ/เพิ่ม วงเงินสดย่อย" | ตรวจการเพิ่มวงเงินสดย่อย |
| รายงานเคลื่อนไหวเงินสดย่อย | ยอดรับ ยอดตัดจ่าย และยอดคงเหลือของแต่ละวงเงินสดย่อย | ไล่ยอดเงินสดย่อย |
| รายงานสถานะเงินสดย่อย | ยอดยกมา ยอดเบิก ยอดคืน ยอดตัดจ่าย ยอดรับ และยอดยกไป ของแต่ละวงเงินสดย่อย | ดูเงินสดย่อยคงเหลือ |
| รายงานรายได้อื่นๆ / เพิ่มหนี้รายได้อื่นๆ / ลดหนี้รายได้อื่นๆ | เอกสารรายได้อื่นนอกจากการขาย | ตรวจรายได้อื่น |
| รายงานค่าใช้จ่ายอื่นๆ / เพิ่มหนี้ค่าใช้จ่ายอื่นๆ / ลดหนี้ค่าใช้จ่ายอื่นๆ | เอกสารค่าใช้จ่ายอื่น | ตรวจค่าใช้จ่ายอื่น |

## ตัวกรองสำคัญ
- ช่วงวันที่ และคำค้นหา
- จากรหัส/ถึงรหัส: รายงานเงินสดย่อยแบบสถานะและเคลื่อนไหว กรองตามรหัสวงเงินสดย่อย รายงานรายได้อื่นและค่าใช้จ่ายอื่น กรองตามรหัสลูกหนี้หรือรหัสเจ้าหนี้ รายงานอื่นกรองตามเลขที่เอกสาร
- รายงานเคลื่อนไหวเงินสดย่อย และรายงานแบบเอกสาร กดปุ่ม "แสดงรายละเอียดสินค้า" เพื่อดูทีละเอกสารหรือรายการย่อย กด "สรุปตามเอกสาร" เพื่อกลับ
- ไม่มีช่องติ๊กแสดงเอกสารที่ยกเลิก รายงานเหล่านี้ไม่นับเอกสารที่ถูกยกเลิก ถ้าต้องการดูเอกสารที่ยกเลิก ใช้กลุ่ม "รายงานเอกสารยกเลิก (การเงิน/ธนาคาร/เช็ค)"

## วิธีอ่านตัวเลขสำคัญ
- ในรายงานสถานะเงินสดย่อย "ยอดเบิก" คือยอดจากเอกสาร คืน/ลด วงเงินสดย่อย (ทำให้ยอดลด) "ยอดคืน" คือยอดจากเอกสาร รับ/เพิ่ม วงเงินสดย่อย (ทำให้ยอดเพิ่ม) ชื่อคอลัมน์จึงไม่ตรงกับชื่อเมนู ให้ดูตามนี้
- "ยอดตัดจ่าย" คือเงินสดย่อยที่ใช้จ่ายในเอกสารอื่น เช่น จ่ายค่าใช้จ่าย "ยอดรับ" คือเงินที่รับเข้าเงินสดย่อยจากเอกสารอื่น
- ยอดรับ-จ่ายรวมในรายงานสรุปรวมหลายช่องทาง ถ้าต้องการเฉพาะเงินสดให้ใช้รายงานเคลื่อนไหวเงินสด
