# รายงานสรุปยอดซื้อ

เมนู: ซื้อ > รายงานสรุปยอดซื้อ มี 8 รายงาน รายงานในกลุ่มนี้ไม่มีช่อง "แสดงเอกสารที่ยกเลิก" เอกสารที่ยกเลิกจะไม่ถูกนับเสมอ

| ชื่อรายงาน | แสดงอะไร | คอลัมน์หลัก |
|---|---|---|
| รายงานซื้อสินค้าแยกตามสินค้า | สรุปยอดซื้อรายสินค้า | รหัสสินค้า, ชื่อสินค้า, หน่วยนับ, จำนวน, มูลค่าส่วนลด, รวมมูลค่า (ก่อนภาษี) |
| รายงานยอดซื้อ(ตามวันที่) | บิลซื้อทีละใบ เรียงตามวันที่ | เอกสารวันที่, รหัสและชื่อเจ้าหนี้, เลขที่เอกสาร, เลขที่ใบกำกับ, ยอดก่อนภาษี, ภาษีมูลค่าเพิ่ม, มูลค่ายกเว้นภาษี, มูลค่าสุทธิ |
| รายงานการซื้อสินค้าสรุปตามประเภทภาษี | รายการสินค้าในบิลซื้อ จัดกลุ่มตามประเภทภาษี | ประเภทภาษี (ภาษีแยกนอก / ภาษีรวมใน / ภาษีอัตราศูนย์ / ไม่กระทบภาษี), เลขที่เอกสาร, สินค้า, ราคา, จำนวน, ส่วนลด, มูลค่าสินค้า, ยอดก่อนภาษี, ภาษีมูลค่าเพิ่ม, ราคารวมภาษี |
| รายงานใบตั้งหนี้จากการซื้อแบบสรุป-ตามวันที่ | บิลซื้อเชื่อทีละใบ เรียงตามวันที่ | เอกสารวันที่, เลขที่, เจ้าหนี้, วันที่ครบกำหนด, เลขที่และวันที่ใบกำกับ, ยอดก่อนภาษี, ภาษีมูลค่าเพิ่ม, มูลค่าสุทธิ |
| รายงานการสั่งซื้อสินค้าแบบสรุป-ตามวันที่ | รายการสินค้าในใบสั่งซื้อ เรียงตามวันที่ (หนึ่งแถวต่อหนึ่งรายการ) | เอกสารวันที่, รหัสสินค้า, ชื่อสินค้า, หน่วยนับ, จำนวน, มูลค่าส่วนลด, รวมมูลค่า (ไม่มีคอลัมน์เลขที่ใบสั่งซื้อ) |
| รายงานใบเพิ่มสินค้า(เจ้าหนี้)แบบสรุป-ตามสินค้า | รายการสินค้าในใบเพิ่มหนี้ซื้อ เรียงตามวันที่ | คอลัมน์ชุดเดียวกับรายงานสั่งซื้อข้างบน |
| รายงานการส่งคืนสินค้า/ลดหนี้แบบสรุป-ตามสินค้า | รายการสินค้าในใบส่งคืน/ลดหนี้ซื้อ เรียงตามรหัสสินค้า | รหัสสินค้า, ชื่อสินค้า, หน่วยนับ, จำนวน, มูลค่าส่วนลด, รวมมูลค่า |
| รายงานใบซื้อสินค้าที่ถึงกำหนดจ่ายเงิน | บิลซื้อเชื่อที่วันครบกำหนดอยู่ในช่วงวันที่ | วันที่ครบกำหนด, เอกสารวันที่, เลขที่, เจ้าหนี้, มูลค่าสินค้า, ภาษีมูลค่าเพิ่ม, มูลค่ายกเว้นภาษี, มูลค่าสุทธิ |

## ตัวกรองที่มีบนหน้าจอ
- ตั้งแต่วันที่ / ถึงวันที่ ยกเว้นรายงาน "ถึงกำหนดจ่ายเงิน" ที่ช่วงวันที่นี้กรองตามวันครบกำหนดของบิล ไม่ใช่วันที่ของบิล
- ช่วงรหัส: รายงานที่แสดงเป็นบิลใช้ "รหัสเจ้าหนี้" รายงานที่แสดงเป็นสินค้าใช้ "รหัสสินค้า"
- ช่องค้นหาและ "เรียงตาม"
- ปุ่ม "แสดงรายละเอียดสินค้า" มีเฉพาะ "รายงานซื้อสินค้าแยกตามสินค้า" (แตกเป็นรายเอกสาร) และ "รายงานใบซื้อสินค้าที่ถึงกำหนดจ่ายเงิน" (แตกเป็นรายการสินค้า)
- ไม่มีตัวเลือก "การแสดงมูลค่าตามประเภทภาษี" และไม่มี "ช่วงรหัสเจ้าหนี้เพิ่มเติม" ในกลุ่มนี้

## ข้อควรรู้
- ชื่อรายงานบางตัวไม่ตรงกับเนื้อหา: "ใบตั้งหนี้จากการซื้อแบบสรุป" แสดงบิลซื้อเชื่อ ไม่ใช่เอกสารตั้งหนี้ของระบบทะยอยรับ และ "ใบเพิ่มสินค้า...ตามสินค้า" เรียงตามวันที่ ไม่ได้เรียงตามสินค้า
- รายงานถึงกำหนดจ่ายนับเฉพาะบิลซื้อเชื่อ ไม่รวมซื้อสด และไม่ได้หักเงินที่จ่ายไปแล้ว ถ้าต้องการยอดค้างจริงดู [[rpt-ap-outstanding]]
- รายงานนี้เป็นการสรุปจากเอกสารซื้อชนิดเดียว ไม่หักใบส่งคืนออกจากยอดซื้อ ถ้าต้องการยอดซื้อสุทธิดู [[rpt-po-purchase-analysis]]
