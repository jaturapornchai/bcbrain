# เพิ่มลูกค้าใหม่ (ลูกหนี้) และตั้งค่าของลูกค้า

**ใช้เมื่อ:** มีลูกค้ารายใหม่ที่จะออกใบเสนอราคา ใบสั่งขาย หรือบิลขาย หรือต้องแก้ข้อมูลลูกค้าเดิม (ลูกหนี้ = ลูกค้าที่อาจค้างชำระเงินกับเรา)
**เมนู:**
- ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › กำหนดลูกหนี้ (ข้อมูลหลัก)
- ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › รายละเอียดลูกหนี้ (ข้อมูลครบทุกส่วน รวมเครดิต)
**ต้องมีก่อน:** ถ้าจะจัดกลุ่ม/ประเภทลูกค้า ให้ตั้งรายการไว้ก่อนที่ เริ่มต้น › ตั้งค่าระบบลูกหนี้ ([[howto-ar-setup]])

## ขั้นตอน
1. เปิดเมนู กำหนดลูกหนี้ กด "เพิ่มใหม่"
2. ใส่ "รหัส" เอง หรือกดปุ่ม "รันรหัสใหม่" ให้ระบบใส่รหัสถัดไป
3. ใส่ "ชื่อ 1" ที่อยู่ จังหวัด อำเภอ/เขต ตำบล/แขวง รหัสไปรษณีย์ และเบอร์ติดต่อ
4. ถ้าลูกค้าต้องการใบกำกับภาษีเต็มรูป ใส่ "เลขประจำตัวผู้เสียภาษี" 13 หลัก และเลือก "สถานประกอบการ"
5. กด "บันทึก" ระบบขึ้น "บันทึกข้อมูลลูกหนี้เสร็จเรียบร้อย"
6. ถ้าจะตั้งเครดิต พนักงานขาย ส่วนลด หรือประเภทการขาย ให้เปิด รายละเอียดลูกหนี้ เลือกลูกค้า แล้วกรอกในส่วนที่ต้องการ
   - ลูกค้าที่เพิ่มจาก กำหนดลูกหนี้ จำนวนวันเครดิตเป็น 0 จนกว่าจะมาตั้งในหน้า รายละเอียดลูกหนี้ (ถ้าเพิ่มลูกค้าจากหน้า รายละเอียดลูกหนี้ ตั้งต้นที่ 30 วัน)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส / ชื่อ 1 | รหัสและชื่อลูกค้า | ต้องกรอกทั้งสองช่อง |
| สถานะลูกหนี้ | บุคคลธรรมดา / นิติบุคคล | |
| สถานะ | ใช้งาน / ไม่ใช้งาน | "ไม่ใช้งาน" = ห้ามออกเอกสารขายใบใหม่ให้ลูกค้านี้ |
| ระดับราคาสินค้า | ราคาที่ลูกค้านี้ได้ เช่น "1: ราคาขายตารางราคา", "3: ราคาขาย1" | ใช้ตอนดึงราคาในบิล |
| เลขประจำตัวผู้เสียภาษี | ตัวเลขล้วน 13 หลัก | หน้า กำหนดลูกหนี้ ไม่ให้ซ้ำกับลูกค้ารายอื่น แม้เลขที่สาขาต่างกัน ([[ts-ar-customer-save-error]]) |
| สถานประกอบการ / เลขที่สาขา | "1. สำนักงานใหญ่" หรือ "2. สาขา" + เลข 5 หลัก | สาขาต้องไม่ใช่ 00000 |

**ส่วนต่างๆ ในหน้า รายละเอียดลูกหนี้** (มีแถบ "ข้ามไปยังส่วน:" ให้กดไปทีละส่วน)
- 1. ข้อมูลทั่วไปลูกหนี้
- 2. รายละเอียดและสินเชื่อ: เขตการขาย พนักงานขาย "ประเภทการขาย" (ขายสด/ขายเชื่อ) "กำหนดประเภทภาษี" ส่วนลดท้ายบิล และวงเงินสินเชื่อ ([[howto-sale-credit-limit]])
- 3. วางบิลและรับเช็ค: วันที่วางบิล วันที่รับเช็ค "ประเภทการส่งมอบ"
- 4. มิติและกลุ่มลูกหนี้
- 5. ผู้ติดต่อ / 6. แคชเชียร์ / 7. สินค้าตามลูกหนี้ / 8. รูปภาพและพิกัด

## บันทึกแล้วระบบทำอะไรให้
- เลือกลูกค้าในใบเสนอราคา ใบสั่งจอง ใบสั่งขาย หรือใบขาย ระบบใส่ค่าที่ตั้งไว้ให้เอง:
  - พนักงานขาย และส่วนลดท้ายบิล
  - ประเภทการขาย (ถ้าตั้งขายสด บิลเป็น "ขายสด" ถ้าตั้งขายเชื่อ บิลเป็น "ขายเชื่อ (เครดิต)")
  - จำนวนวันเครดิตและวันครบกำหนด ([[faq-ar-credit-days]])
  - ประเภทภาษีและอัตราภาษี เฉพาะเมื่อติ๊ก "กำหนดประเภทภาษี" ไว้
  - ใบสั่งขายและใบขาย: ประเภทการส่ง ตาม "ประเภทการส่งมอบ"
- ค่าที่ระบบใส่ให้ แก้ในบิลได้

## แก้ไข ยกเลิก พิมพ์
- แก้ไข: เลือกลูกค้าจากรายการ กด "แก้ไข" แล้ว "บันทึก"
- ลบได้เฉพาะลูกค้าที่ยังไม่มีเอกสาร ถ้ามีแล้วให้ตั้ง "สถานะ" เป็น "ไม่ใช้งาน" แทน
- ลบลูกค้าแล้ว ข้อมูลสมาชิกของลูกค้านั้นถูกลบไปด้วย ([[howto-ar-member-points]])

## ปัญหาที่พบบ่อย
- บันทึกไม่ได้ เลขผู้เสียภาษีซ้ำ/ไม่ครบ เลขสาขาผิด หรือลบไม่ได้ → [[ts-ar-customer-save-error]]
- ออกบิลแล้วขึ้น "สถานะ ลูกค้าปิดการใช้งาน : ..." → [[ts-sale-customer-inactive]]
- ดึงราคาไม่ขึ้น → [[ts-sale-price-not-found]]
