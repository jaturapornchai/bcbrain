# เพิ่มหนี้ ลดหนี้ ของรายได้อื่นๆ และค่าใช้จ่ายอื่นๆ

**ใช้เมื่อ:** ออกเอกสารรายได้อื่นหรือค่าใช้จ่ายอื่นไปแล้ว ต่อมายอดเปลี่ยน
- เพิ่มหนี้ = ยอดเพิ่มขึ้นจากใบเดิม เช่น คิดค่าบริการเพิ่ม
- ลดหนี้ = ยอดลดลงจากใบเดิม เช่น ให้ส่วนลดภายหลัง คืนเงินบางส่วน
**เมนู:** เงินสด/ธนาคาร › เพิ่มหนี้รายได้อื่นๆ / ลดหนี้รายได้อื่นๆ / เพิ่มหนี้ค่าใช้จ่ายอื่นๆ / ลดหนี้ค่าใช้จ่ายอื่นๆ
**ต้องมีก่อน:** เอกสารรายได้อื่นๆ หรือค่าใช้จ่ายอื่นๆ ใบเดิม ([[howto-cash-other-income]], [[howto-cash-other-expense]])

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. เลือกลูกหนี้ (ฝั่งรายได้) หรือเจ้าหนี้ (ฝั่งค่าใช้จ่าย) คนเดียวกับใบเดิม
3. อ้างอิงใบเดิม (ฝั่งรายได้อ้างอิงใบรายได้อื่นๆ ฝั่งค่าใช้จ่ายอ้างอิงใบค่าใช้จ่ายอื่นๆ)
4. ระบุเหตุผลการเพิ่มหนี้/ลดหนี้ และเลือกประเภทรายการ สด หรือ เชื่อ
5. ในตาราง ใส่รหัสรายได้/ค่าใช้จ่าย และยอดที่เพิ่มหรือลด (ใส่เฉพาะส่วนต่าง ไม่ใช่ยอดใหม่ทั้งหมด)
6. ถ้าเป็นแบบสด ใส่ช่องทางเงินในแท็บ "การรับ/จ่ายชำระเงิน" ให้ครบยอด
7. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เอกสารอ้างอิง | ใบเดิม | |
| เหตุผล | สาเหตุที่ปรับยอด | ใช้กับใบเพิ่มหนี้/ลดหนี้ |
| ประเภทรายการ | สด หรือ เชื่อ | เชื่อ = ปรับยอดหนี้ค้าง |
| จำนวนเงิน | ส่วนต่าง | |

## บันทึกแล้วระบบทำอะไรให้
- เพิ่มหนี้ ลงบัญชีทิศเดียวกับใบเดิม
- ลดหนี้ ลงบัญชีกลับด้านกับใบเดิม เช่น ลดหนี้รายได้: เดบิต รายได้ และ ภาษีขาย คู่กับ เครดิต ช่องทางที่คืนเงินในแท็บ "การรับ/จ่ายชำระเงิน"
- แบบเชื่อ ยอดไปเพิ่มหรือลดหนี้ค้างของลูกหนี้/เจ้าหนี้ ใช้ตัดในรับชำระหรือจ่ายชำระได้ ([[howto-ar-overview]], [[howto-ap-overview]])
- **ข้อควรระวัง:** ลดหนี้รายได้อื่นๆ และ ลดหนี้ค่าใช้จ่ายอื่นๆ แม้เลือกแบบเชื่อ ระบบลงบัญชีตามช่องทางในแท็บ "การรับ/จ่ายชำระเงิน" เสมอ ไม่ได้ลงบัญชีลูกหนี้หรือเจ้าหนี้ ทั้งที่ยอดหนี้ค้างของลูกค้าหรือผู้ขายลดลง ก่อนบันทึกแบบเชื่อให้ตรวจแท็บ "การลงบัญชี (GL)" ถ้าไม่ตรงที่ต้องการ → ส่งต่อเจ้าหน้าที่
- ข้อมูลภาษีไปที่รายงานภาษีตามแท็บภาษี ([[howto-tax-overview]])

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกด้วยเมนู ยกเลิกเพิ่มหนี้/ลดหนี้ ที่ตรงกัน ([[howto-cash-cancel-docs]])
- การออกใบเพิ่มหนี้/ลดหนี้ทางภาษีถูกต้องหรือไม่ ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร
