# รับของเข้าคลังและตรวจ 3-Way Match ใบสั่งซื้อ

**ใช้เมื่อ:** ผู้ขายส่งของมาถึงแล้ว หรือต้องการอนุมัติ PO / ปิดการตรวจใบกำกับภาษีซื้อ
**เมนู:** จัดซื้อ PO › แท็บ "5. เปิด PO / บันทึกรับของเข้าคลัง" (ดูผลที่แท็บ "2. กระดานใบสั่งซื้อ PO & 3-Way Matching")
**ต้องมีก่อน:** มี PO แล้ว ([[howto-procure-rfq-to-po]])

## ขั้นตอน (ฟอร์มในแท็บ 5)
1. เลือก "ประเภทคำสั่ง" = "อัปเดตสถานะ PO ที่มีอยู่ (รับเข้าคลัง WMS / ยืนยัน 3-Way Match)"
2. เลือก "เลือกเลขที่ใบสั่งซื้อ (PO)" ให้เลือกใบที่ต้องการเองทุกครั้ง (ถ้าใบที่ต้องการเป็นรายการแรก ให้เลือกอย่างอื่นแล้วเลือกกลับ) เพราะค่าที่ส่งจริงอาจเป็นเลขตัวอย่างค้างอยู่ ดู [[howto-procure-open-po-form]]
3. เลือก "สถานะเป้าหมาย": อนุมัติใบสั่งซื้อ → รับสินค้าเข้าคลัง → ตรวจสอบ 3-Way Match ครบ (ในรายการมีรหัสสถานะภาษาอังกฤษนำหน้า)
4. แนบรูป (ใบ PO / พาเลทรับของ / ใบกำกับภาษี) และหมายเหตุ ถ้าไม่แนบ ระบบสร้างรูปจำลอง
5. กด "บันทึกจัดซื้อ & ซิงค์ข้ามระบบ"

## ปุ่มลัดที่กระดาน PO (แท็บ 2)
ตารางมีคอลัมน์ "คำสั่งซิงค์ข้ามระบบ" ปุ่มเปลี่ยนตามสถานะของ PO: "อนุมัติเปิดใบสั่งซื้อ (Approve PO)", "รับของเข้าคลัง WMS + ถ่ายรูป GRN", "ยืนยัน 3-Way Match + ส่งเข้า e-Tax", และเมื่อครบแล้วเป็น "แนบรูปตรวจรับ/ใบกำกับภาษีเพิ่ม"

## สถานะ PO บนจอ
"ใบขอซื้อ PR รออนุมัติเปิด PO (AI แนะนำ)" → "อนุมัติ PO แล้ว · รอซัพพลายเออร์ส่งของเข้าคลัง" → "2-Way Match · รับเข้าคลัง WMS แล้ว รอตรวจบิลภาษี" → "3-Way Match ครบ 100% (PO = WMS = e-Tax)"

## บันทึกแล้วระบบทำอะไรให้
- รับเข้าคลัง: เพิ่มสต็อกบนชั้นวางปลายทางตามจำนวนใน PO พร้อมบันทึกการเคลื่อนไหว แต่เฉพาะเมื่อสินค้านั้นมีแถวบนชั้นวางนั้นในระบบคลังแล้ว ถ้าไม่มี สต็อกไม่เพิ่ม แต่ PO ยังขึ้นสถานะรับของแล้ว ให้ตรวจสต็อกเองและส่งต่อเจ้าหน้าที่
- ครั้งแรกที่รับของ ระบบสร้างเอกสารรับของฝั่งสต็อก (เป็นเอกสารซื้อที่นับรวมในยอดซื้อของรายงานสรุป) ไม่มีการลงบัญชีหรือตั้งเจ้าหนี้
- 3-Way Match: เพิ่มรายการใบกำกับภาษีซื้อในระบบ e-Tax โดยระบบกำหนดเลขใบกำกับ เลขผู้เสียภาษีของผู้ขาย และความมั่นใจการอ่านเองเป็นค่าตายตัว (ไม่ใช่ของจริง) ถ้ากด "แนบรูปตรวจรับ/ใบกำกับภาษีเพิ่ม" ซ้ำ ระบบจะพยายามเพิ่มรายการนี้อีก อาจซ้ำหรือไม่ผ่านแบบเงียบๆ ไม่ควรกดซ้ำ
- สต็อกและเอกสารถูกบันทึกพร้อมกัน ถ้าขั้นใดล้มเหลวจะไม่บันทึกบางส่วน

## ข้อควรรู้
- ระบบถือว่าจำนวนที่รับ = จำนวนที่สั่งเสมอ ไม่มีช่องให้กรอกจำนวนที่รับจริงหรือจำนวนตามใบกำกับ หากของมาไม่ครบ ให้บันทึกหมายเหตุและแจ้งทีมงาน
- ไม่มีช่องกรอกเลขใบกำกับภาษีซื้อ ระบบสร้างเลขให้เอง จึงไม่ตรงกับใบจริง ต้องเก็บใบจริงไว้ตรวจเอง
- สถานะย้อนกลับได้ (เช่นเลือกอนุมัติกับใบที่รับของแล้ว) แต่สต็อกที่เพิ่มไปแล้วไม่ถูกคืน
- ดูความหมายการตรวจ 3 ฝั่งที่ [[faq-procure-three-way-match]]
