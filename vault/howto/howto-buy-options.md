# ข้อเลือกพิเศษที่มีผลกับงานซื้อและเจ้าหนี้

**ใช้เมื่อ:** ต้องการให้ระบบบังคับหรือผ่อนปรนกติกาตอนบันทึกเอกสารซื้อและจ่ายชำระหนี้
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ
**ต้องมีก่อน:** สิทธิ์ผู้ดูแลระบบ ([[ts-common-no-permission]])

## ขั้นตอน
1. เปิดเมนู "กำหนดข้อเลือกพิเศษต่างๆ"
2. เลือกแท็บตามตารางด้านล่าง ติ๊กหรือเอาติ๊กออก
3. บันทึก แล้วเปิดหน้าจอเอกสารใหม่ เพื่อให้ค่าที่ตั้งมีผล

## ข้อเลือกที่มีผลจริงกับงานซื้อ/เจ้าหนี้
| แท็บ | ข้อเลือก | ผลเมื่อติ๊ก |
|---|---|---|
| 1.ตั้งค่าระบบ | ป้อนเลขที่ใบกำกับภาษีทุกครั้ง | ใบซื้อ ตั้งหนี้ เพิ่มหนี้ และลดหนี้ ต้องกรอกเลขที่และวันที่ใบกำกับ เมื่อภาษีเป็น แยกนอก หรือ รวมใน (ใบรับสินค้าแบบทะยอยรับไม่ถูกบังคับ) |
| 1.ตั้งค่าระบบ | เตือนเมื่อไม่กำหนดสาขา | ต้องเลือกสาขาก่อนบันทึก (ใช้เมื่อกิจการเปิดระบบสาขา) |
| 1.ตั้งค่าระบบ | เตือนไม่บันทึกแผนก | ต้องเลือกแผนก (ใช้คู่กับ "ใช้ระบบแยกแผนก") |
| 1.ตั้งค่าระบบ | อนุมัติรายการเสนอซื้อได้มากกว่า 1 ครั้ง | ใบเสนอซื้อยังไม่ปิดรายการจนกว่าจำนวนที่อนุมัติรวมกับที่ยกเลิกจะครบ จึงยังดึงไปทำใบสั่งซื้อได้ แต่จะนำใบเดิมมาอนุมัติซ้ำอีกครั้งไม่ได้ ระบบตอบ "เอกสาร ... อนุมัติแล้ว" |
| 1.ตั้งค่าระบบ | อนุญาติให้ชำระเกินยอดบิลได้ | จ่ายชำระเกินยอดคงเหลือของบิลได้ |
| 2.บัญชีแยกประเภท | ใช้ระบบแยกแผนก | เปิดช่องแผนกในเอกสาร |
| 2.บัญชีแยกประเภท | ใช้ระบบดึงราคาซื้อ | กรอกจำนวนแล้วระบบดึงราคาจากเมนู สินค้า › กำหนดราคาซื้อ ให้ (เฉพาะบรรทัดที่ไม่ได้ดึงจากเอกสารอื่น) |
| 2.บัญชีแยกประเภท | เสนอซื้อห้ามกำหนดราคา / ปิดช่องราคาเสนอซื้อ | ตอนใบสั่งซื้อดึงใบเสนอซื้อ ระบบหาราคาใหม่ให้ ไม่ใช้ราคาจากใบเสนอซื้อ ถ้าไม่ได้กำหนดราคาซื้อไว้ ราคาจะเป็น 0 (ช่องราคาในใบเสนอซื้อยังกรอกได้) |
| 2.บัญชีแยกประเภท | จ่ายชำระหนี้อ้างอิงวางบิลทุกครั้ง | ใบจ่ายชำระหนี้ต้องจ่ายผ่านใบรับวางบิลเท่านั้น |
| 3.สินค้าคงคลัง | ห้ามรับวางบิลซ้ำ | บิลที่รับวางบิลแล้ว นำมาทำใบรับวางบิลใหม่ไม่ได้ |
| 3.สินค้าคงคลัง | อ้างอิงเอกสารสั่งซื้อที่อนุมัติแล้วเท่านั้น | ปุ่ม "ดึงเอกสาร" แสดงเฉพาะใบสั่งซื้อที่อนุมัติแล้ว |
| 3.สินค้าคงคลัง | อนุญาติให้รับสินค้ามากกว่าใบสั่งซื้อได้ | ใบซื้อและใบรับสินค้า รับเกินจำนวนในใบสั่งซื้อได้ |
| 3.สินค้าคงคลัง | ใส่จำนวนสินค้าทุกครั้ง | ทุกบรรทัดที่มีรหัสสินค้าต้องมีจำนวน |
| 4.ระบบขาย | ใส่วัน รับ/ส่ง สินค้าทุกครั้ง | ตอนบันทึกใบเสนอซื้อและใบสั่งซื้อ ต้องกรอกวันที่รับ/ส่งสินค้า |

## ข้อเลือกที่เห็นบนหน้าจอ แต่ตอนนี้ยังไม่มีผลกับงานซื้อ
ตัวเลือกเหล่านี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผลกับงานซื้อ
- ประเภทภาษีมูลค่าเพิ่ม (ซื้อ)
- เปิดระบบอ้างอิงจากใบเสนอซื้อ
- อ้างอิงเอกสารเสนอซื้อที่อนุมัติแล้วเท่านั้น (ใบสั่งซื้อยังดึงใบเสนอซื้อที่ยังไม่อนุมัติได้)
- ส่งคืน,ลดหนี้ใช้แบบอ้างอิงเอกสารใบเดียว
- อนุมัติใบสั่งซื้อก่อนพิมพ์
- ใบอนุมัติซื้ออ้างอิงได้ครั้งเดียว
- เสนอซื้อสินค้าแสดงช่องคลัง/ที่เก็บ
- ห้ามแก้ไขคลังที่เก็บกรณีอ้างอิงเอกสาร
- ห้ามใส่จำนวนเกินเอกสารอ้างอิง (ใช้กับงานขายเท่านั้น งานซื้อใช้การตรวจ "จำนวนเกินรายการสั่งซื้อ" แทน)

ถ้าลูกค้าต้องการให้ข้อเลือกเหล่านี้ทำงาน ให้ส่งต่อเจ้าหน้าที่
