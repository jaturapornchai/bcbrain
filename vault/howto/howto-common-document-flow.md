# ดูเส้นทางเอกสาร (Document Flow)

**ใช้เมื่อ:** อยากรู้ว่าเอกสารใบนี้อ้างอิงมาจากใบไหน ถูกนำไปออกใบไหนต่อ ชำระเงินแล้วเท่าไร ค้างเท่าไร และลงบัญชีอะไรไว้ หรือหาสาเหตุที่แก้หรือยกเลิกเอกสารไม่ได้
**เมนู:** เปิดเอกสารใบนั้นจากเมนูของระบบงาน › กดปุ่ม "Document Flow" ที่แถบปุ่มด้านบนของเอกสาร
**ต้องมีก่อน:** เลือกหรือเปิดเอกสารที่บันทึกแล้ว (เอกสารใหม่ที่ยังไม่มีเลขที่ ปุ่มนี้จะกดไม่ได้)

## ขั้นตอน
1. เปิดเอกสารที่ต้องการ หรือเลือกเอกสารจากรายการด้านซ้าย
2. กดปุ่ม "Document Flow"
3. ดูส่วน "แผนผังการไหลของเอกสาร" เอกสารต้นทางอยู่ด้านซ้าย เอกสารปัจจุบันอยู่กลาง เอกสารปลายทางอยู่ด้านขวา
4. ดูส่วน "ตรวจสอบที่มาและที่ไปของเอกสารที่เลือก" แยกเป็น ที่มา (ต้นทาง) และ ที่ไป (ปลายทาง) พร้อมยอดรวมเอกสาร ชำระแล้ว และคงค้างชำระ
5. ดูส่วน "ตารางสรุปความเชื่อมโยงทั้งสายงาน" เพื่อเห็นทุกใบที่เกี่ยวข้องกันในสายเดียว
6. ดูรายละเอียดการรับหรือจ่ายชำระเงิน และส่วน "รายการลงบัญชีแยกประเภท ... ที่เชื่อมโยง" เพื่อดูว่าลงบัญชีอะไรไว้
7. ถ้าต้องการเปิดเอกสารใบที่เกี่ยวข้อง กด "เปิดเอกสาร" ที่ใบนั้น ระบบจะเปิดหน้าจอของเอกสารใบนั้นให้

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ที่มา (ต้นทาง) | เอกสารที่ใบนี้อ้างอิงมา เช่น ใบสั่งซื้อที่นำมารับสินค้า | ดูอย่างเดียว |
| ที่ไป (ปลายทาง) | เอกสารที่นำใบนี้ไปใช้ต่อ เช่น ใบวางบิล ใบรับชำระ ใบลดหนี้ | ดูอย่างเดียว |
| ยอดรวมเอกสาร / ชำระแล้ว / คงค้างชำระ | ยอดเงินของเอกสาร | ใช้ตอบลูกค้าว่าบิลนี้ค้างเท่าไร |

## บันทึกแล้วระบบทำอะไรให้
- หน้าต่างนี้ใช้ดูอย่างเดียว ไม่เปลี่ยนข้อมูลใดๆ
- ถ้าเอกสารมีปลายทางแล้ว แปลว่าเอกสารนี้ถูกนำไปใช้ต่อ ระบบจะห้ามแก้ไขหรือยกเลิก จนกว่าจะจัดการเอกสารปลายทางก่อน

## แก้ไข ยกเลิก พิมพ์
- ถ้าต้องการแก้เอกสารที่มีปลายทาง ให้ยกเลิกหรือลบเอกสารปลายทางก่อน ไล่จากใบล่าสุดย้อนกลับมา ดู [[howto-doc-edit-cancel-delete]]
- หน้าจอรายการบางหน้ามีปุ่ม "ลำดับขั้นตอนการทำงาน (Flow)" ซึ่งเป็นคำแนะนำขั้นตอนการใช้หน้าจอแบบทั่วไป ไม่ใช่เส้นทางของเอกสารแต่ละใบ

## ปัญหาที่พบบ่อย
- แก้เอกสารไม่ได้เพราะถูกนำไปใช้แล้ว ดู [[ts-common-cannot-edit-used-doc]]
- ยกเลิกเอกสารไม่ได้เพราะมีการอ้างอิง ดู [[ts-common-cannot-cancel-doc]]
- ขึ้น "ไม่สามารถดึงผังเส้นทางเอกสารได้" ให้ปิดหน้าต่างแล้วลองใหม่ ถ้ายังไม่ได้ให้แจ้งทีมงาน
