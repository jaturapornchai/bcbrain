# ที่อยู่จัดส่งของเจ้าหนี้ การพิมพ์ป้ายชื่อ และข้อมูลคู่ค้า

**ใช้เมื่อ:** ต้องส่งของหรือเอกสารไปหาผู้ขาย (เช่น ส่งคืนสินค้า ส่งเช็ค) และอยากพิมพ์ป้ายชื่อหรือใบปะหน้า
**เมนู:** เจ้าหนี้ › ทะเบียนเจ้าหนี้ คู่ค้า และที่อยู่จัดส่ง › ที่อยู่จัดส่งสินค้า / พิมพ์ที่อยู่จัดส่งสินค้า / นำเข้าที่อยู่จัดส่งเจ้าหนี้ / ข้อมูลคู่ค้า
**ต้องมีก่อน:** มีเจ้าหนี้ในระบบแล้ว ([[howto-ap-supplier]])

## ขั้นตอน
**ก. คัดที่อยู่จากทะเบียนเจ้าหนี้มาทีเดียว**
1. เปิด นำเข้าที่อยู่จัดส่งเจ้าหนี้ กด "เริ่มประมวลผล"
2. ระบบคัดลอก ชื่อ ที่อยู่ โทรศัพท์ โทรสาร อีเมล ของเจ้าหนี้ที่ยังไม่มีที่อยู่จัดส่ง มาสร้างให้
3. เจ้าหนี้ที่มีที่อยู่จัดส่งอยู่แล้ว ระบบไม่เขียนทับ

**ข. เพิ่มหรือแก้ที่อยู่จัดส่งทีละราย**
1. เปิด ที่อยู่จัดส่งสินค้า กด "เพิ่มใหม่" หรือเลือกรายการแล้วกด "แก้ไข"
2. เลือก "รหัสเจ้าหนี้:" ใส่ อาคาร ชั้น ซอย ถนน จังหวัด อำเภอ/เขต ตำบล/แขวง รหัสไปรษณีย์ และเบอร์ มือถือ 1
3. กด "บันทึก"

**ค. พิมพ์ป้ายชื่อ**
1. เปิด พิมพ์ที่อยู่จัดส่งสินค้า (หน้าจอชื่อ พิมพ์ป้ายชื่อขนส่ง)
2. คลิกรายชื่อฝั่งซ้ายเพื่อเพิ่มเข้าคิวพิมพ์ แก้ "จำนวนดวง" ได้
3. กด "แสดงตัวอย่าง" เพื่อดูป้าย ใช้ "ล้างรายการ" เพื่อล้างคิว
4. รุ่นปัจจุบันหน้านี้ยังส่งงานออกเครื่องพิมพ์ไม่ได้ ดูข้อควรรู้ด้านล่าง

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสเจ้าหนี้: | เจ้าหนี้ที่จะส่งของไป | |
| ชื่อ: | ชื่อผู้รับบนป้าย | |
| ที่อยู่ จังหวัด อำเภอ/เขต ตำบล/แขวง รหัสไปรษณีย์ | ที่อยู่ปลายทาง | |
| มือถือ 1:, โทรศัพท์บ้าน: | เบอร์ติดต่อผู้รับ | |
| ประเภทการขนส่ง:, วันที่รับสินค้า:, ช่วงเวลารับสินค้า: | ข้อมูลการส่ง | ไม่บังคับ |
| สถานประกอบการ:, เลขประจำตัวผู้เสียภาษี: | ถ้าต้องการพิมพ์ข้อมูลภาษีบนป้าย | ไม่บังคับ |

## ข้อมูลคู่ค้า
- ใช้ผูกเจ้าหนี้กับระบบของคู่ค้าที่ใช้โปรแกรมเชื่อมกัน มีช่อง "รหัสเชื่อมโยงคู่ค้า:", "รหัสเจ้าหนี้:", "รหัสลูกหนี้ฝั่งคู่ค้า:" และ "วันที่เริ่มใช้งาน:"
- ช่องที่เหลือเป็นค่าทางเทคนิคของการเชื่อมระบบ ถ้าลูกค้าต้องการใช้ ให้ส่งต่อทีมงานช่วยตั้งค่า อย่าให้ลูกค้าเดาค่าเอง

## ข้อควรรู้
- ปุ่ม "พิมพ์" ในหน้านี้แค่เปิดตัวอย่างป้ายและขึ้นข้อความ "สั่งพิมพ์ป้ายชื่อขนส่ง ... รายการ เรียบร้อยแล้ว" แต่ไม่ได้ส่งงานไปเครื่องพิมพ์จริง ถ้าลูกค้าต้องพิมพ์ป้าย ส่งต่อเจ้าหน้าที่
- ช่อง "เครื่องพิมพ์:", "แบบฟอร์ม:" (FORM-A4-3X8, FORM-A4-2X5, FORM-100X150), "พิมพ์กระดาษสติ๊กเกอร์ A4", "แถวเริ่ม:" และ "คอลัมน์เริ่ม:" ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล (แบบฟอร์มและแถว/คอลัมน์แค่แสดงที่หัวตัวอย่าง)
- ที่อยู่จัดส่งแยกจากที่อยู่ในทะเบียนเจ้าหนี้ แก้ที่หนึ่งแล้วอีกที่ไม่เปลี่ยนตาม
