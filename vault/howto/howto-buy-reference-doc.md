# ดึงรายการจากเอกสารก่อนหน้า (ปุ่มดึงเอกสาร) ในงานซื้อ

**ใช้เมื่อ:** ไม่อยากพิมพ์รายการสินค้าซ้ำ ต้องการดึงจากใบเสนอซื้อ ใบสั่งซื้อ ใบรับสินค้า หรือใบซื้อเดิม
**เมนู:** ทุกหน้าจอเอกสารซื้อที่มีช่อง เอกสารอ้างอิง › ปุ่ม "ดึงเอกสาร"
**ต้องมีก่อน:** เลือกรหัสเจ้าหนี้และประเภทภาษีที่หัวเอกสารก่อน

## ขั้นตอน
1. กด "เพิ่มใหม่" เลือกรหัสเจ้าหนี้และประเภทภาษี
2. กด "ดึงเอกสาร" ข้างช่องเลขที่เอกสารอ้างอิง
3. หน้าต่าง "เลือกเอกสารอ้างอิงเพื่อดึงรายการสินค้า" แสดงเอกสารที่ดึงได้ คลิกเลือก 1 ใบ
4. ระบบล้างตารางเดิม แล้วใส่รายการที่ยังคงเหลือของใบนั้นให้ พร้อม "เอกสารอ้างอิงวันที่"
5. แก้จำนวนหรือราคาตามจริง แล้วบันทึก

## เอกสารไหนดึงจากอะไร
| เอกสารที่กำลังทำ | ดึงจาก |
|---|---|
| ใบสั่งซื้อสินค้า (PO) | ใบเสนอซื้อ หรือใบอนุมัติใบเสนอซื้อ |
| รับคืนจ่ายเงินมัดจำ / รับคืนจ่ายเงินล่วงหน้า | ใบจ่ายเงินมัดจำ / ใบจ่ายเงินล่วงหน้า |
| ซื้อสินค้า/ตั้งหนี้ซื้อ, รับสินค้าตามใบสั่งซื้อ (ทะยอยรับ) | ใบสั่งซื้อ |
| ส่งคืนสินค้า/ลดหนี้ซื้อ, เพิ่มหนี้ซื้อ/ราคาผิด | ใบซื้อสินค้า/ตั้งหนี้ซื้อ |
| ส่งคืนสินค้าจากการรับ, ตั้งหนี้ซื้อจากการรับสินค้า | ใบรับสินค้าตามใบสั่งซื้อ |
| เพิ่มหนี้ / ลดหนี้ซื้อจากใบตั้งหนี้ | ใบตั้งหนี้ซื้อจากการรับสินค้า |
| ตั้งหนี้อื่นๆ (เจ้าหนี้) | ใบสั่งซื้อที่ยังไม่ถูกใช้ |
| เพิ่มหนี้อื่นๆ / ลดหนี้อื่นๆ (เจ้าหนี้) | ใบตั้งหนี้อื่นๆ (ดึงเฉพาะยอดเงิน) |

## เงื่อนไขที่ระบบใช้กรองรายการ
- ส่วนใหญ่แสดงเฉพาะเอกสารของเจ้าหนี้รายเดียวกับหัวเอกสาร ถ้ายังไม่เลือกเจ้าหนี้จะไม่มีรายการขึ้น
- ประเภทภาษีต้องตรงกัน ยกเว้น ใบสั่งซื้อที่ดึงใบเสนอซื้อ, ตั้งหนี้ซื้อจากการรับสินค้า และ ส่งคืนสินค้าจากการรับ
- เอกสารที่ถูกยกเลิก จะไม่แสดง
- เอกสารที่ใช้ครบแล้วจะไม่แสดง เฉพาะตอนดึงใบเสนอซื้อ ใบสั่งซื้อ และใบรับสินค้า ส่วนใบส่งคืน ใบลดหนี้ และใบเพิ่มหนี้ ยังเห็นใบเดิมเสมอ แต่ตอนบันทึกระบบไม่ให้คืนเกินที่ซื้อมา ([[ts-buy-return-over]])
- ถ้าเปิดข้อเลือก "อ้างอิงเอกสารสั่งซื้อที่อนุมัติแล้วเท่านั้น" หน้าจอซื้อสินค้า/ตั้งหนี้ซื้อ และรับสินค้าตามใบสั่งซื้อ จะไม่แสดงใบสั่งซื้อที่ยังไม่อนุมัติ
- ใบสั่งซื้อดึงใบเสนอซื้อได้ทุกผู้ขาย แต่ไม่แสดงใบที่ถูกบันทึกไม่อนุมัติ ([[howto-buy-options]])
- ผู้ใช้ที่ถูกจำกัดสาขา จะเห็นเฉพาะเอกสารของสาขาตัวเอง

## บันทึกแล้วระบบทำอะไรให้
- ตัดยอดคงเหลือของเอกสารต้นทาง และเอกสารต้นทางจะแก้ไขหรือลบไม่ได้อีก
- ดูความเชื่อมโยงของเอกสารได้ด้วยปุ่ม "Document Flow"

## ข้อจำกัด
- ดึงได้ครั้งละ 1 ใบ ถ้าดึงใบที่สอง รายการของใบแรกในตารางจะถูกแทนที่ ถ้าต้องรวมหลายใบในเอกสารเดียว ให้แจ้งทีมงาน

## ปัญหาที่พบบ่อย
- "ไม่พบเอกสารอ้างอิงในระบบ" → ไม่มีเอกสารที่เข้าเงื่อนไข ([[ts-buy-ref-doc-not-listed]])
- "เอกสาร ... ไม่มีรายการคงเหลือให้ดึง" → ใบนั้นถูกใช้ครบแล้ว
- "ไม่พบสินค้าในเอกสารอ้างอิง (สินค้า ... เอกสาร ...)" → สินค้าในตารางไม่มีในเอกสารต้นทาง ให้ลบบรรทัดนั้นหรือดึงใหม่
