# เพิ่ม/ลบรายการยาง อะไหล่ และค่าแรงในใบสั่งซ่อม

**ใช้เมื่อ:** ช่างใช้อะไหล่ หรือมีค่าแรง ต้องใส่ลงใบงานเพื่อคิดเงินและตัดสต็อกตอนปิดบิล
**เมนู:** AutoCare › งานรับรถและบริการหน้าร้าน › "บันทึกใบรับรถ" (หรือ "ตรวจสภาพ 35 จุด & เสนอซ่อม") เลือกใบงานทางซ้าย
**ต้องมีก่อน:** สินค้า/ค่าแรงต้องมีรหัสในข้อมูลสินค้าของระบบบัญชี

## ขั้นตอนเพิ่มรายการ
1. เลือกใบงานจากตารางซ้าย เลื่อนไปที่ตาราง "รายการยาง อะไหล่ และค่าแรงในใบสั่งซ่อม"
2. **ทางลัด** กดปุ่มใต้หัวข้อ "เบิกด่วน 1 คลิก (จากคลัง BC)" เช่น ยาง 4 เส้น ตั้งศูนย์ 3D ถ่ายน้ำมันเครื่อง ผ้าเบรก เคลือบแก้ว รายการและราคาในปุ่มเป็นค่าตัวอย่าง ตรวจและแก้ให้ตรงกับของร้านก่อนปิดบิล
3. **เพิ่มเอง** ที่แถบท้ายตาราง: กดปุ่มค้นหาข้าง "รหัสสินค้า BC" เลือกสินค้าจากระบบบัญชี ใส่ชื่อรายการ จำนวน ราคาต่อหน่วย แล้วกด "เพิ่มรายการ" (ช่องทั้งหมดมีค่าตัวอย่างยาง Michelin 4 เส้น มาให้แล้ว ต้องพิมพ์ทับให้ครบ)
4. ตรวจยอดแถบสรุป: อะไหล่ ค่าแรง VAT 7% ยอดสุทธิ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสสินค้า BC | รหัสสินค้าหรือค่าแรงในระบบบัญชี | ต้องมีจริง ไม่งั้นปิดบิลไม่ได้ |
| ชื่อรายการยาง / อะไหล่ / ค่าแรง | ชื่อที่จะพิมพ์ในบิล | |
| จำนวน | จำนวนที่ใช้ | |
| ราคาต่อหน่วย | ราคาขาย | ราคารวม = จำนวน × ราคา |

## ลบรายการ
กดปุ่ม "ลบ" ท้ายแถวรายการ (มีเฉพาะใบงานที่ยังไม่ปิดบิล) ยอดรวมคำนวณใหม่ทันที

## ระบบทำอะไรให้
- แยกยอด "อะไหล่" กับ "ค่าแรง" ตามประเภทรายการ แต่รายการที่ **เพิ่มเอง** ที่แถบท้ายตารางถูกบันทึกเป็นประเภทยางเสมอ (หน่วย "เส้น") จึงนับเป็นยอดอะไหล่ ไม่นับเป็นค่าแรง ถ้าต้องแยกค่าแรงให้ชัด ใช้ปุ่มเบิกด่วนที่เป็นค่าแรง (เช่น ตั้งศูนย์ 3D) หรือส่งต่อเจ้าหน้าที่
- เพิ่มส่วนแบ่งช่างให้เองรายการละค่าคงที่ ไม่ได้คิดตามราคา
- รายการที่เพิ่มด้วยปุ่มนี้ถือว่าลูกค้าอนุมัติแล้ว
- ยังไม่ตัดสต็อกและไม่ลงบัญชีจนกว่าจะปิดบิล

## ปัญหาที่พบบ่อย
- "ไม่พบรหัสสินค้า : ..." ตอนปิดบิล → [[ts-autocare-item-not-found]]
- ไม่เห็นปุ่มลบและแถบเพิ่มรายการ → ใบงานปิดบิลแล้ว แก้รายการไม่ได้ (ปุ่มเบิกด่วนบนจอ "บันทึกใบรับรถ" และ "ตรวจสภาพ 35 จุด & เสนอซ่อม" ยังโผล่แม้ปิดบิลแล้ว อย่ากด เพราะระบบไม่กันการเพิ่มรายการในใบงานที่ปิดบิลแล้ว และการคำนวณใหม่อาจบันทึกบิลขายเลขเดิมซ้ำตามรายการล่าสุด ถ้ากดไปแล้วให้ส่งต่อเจ้าหน้าที่ตรวจ)
