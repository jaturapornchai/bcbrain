# เอกสารซื้อและเจ้าหนี้ ลงบัญชีอะไรให้อัตโนมัติ

**ใช้เมื่อ:** ลูกค้าถามว่าบันทึกเอกสารซื้อแล้ว ระบบลงบัญชีให้อย่างไร หรือต้องการตรวจคู่บัญชี
**เมนู:** หน้าจอเอกสารซื้อ/เจ้าหนี้ › แท็บ "การลงบัญชี (GL)"
**ต้องมีก่อน:** ผังบัญชีของกิจการ ([[howto-gl-overview]])

## ขั้นตอนตรวจ
1. เปิดเอกสาร ไปแท็บ "การลงบัญชี (GL)"
2. ดูรายการเดบิต เครดิต ด้านล่างต้องขึ้น "✓ ดุลบัญชีถูกต้อง (Dr = Cr)"
3. ระบบประมวลผลคู่บัญชีใหม่ทุกครั้งที่บันทึกเอกสาร

## คู่บัญชีมาตรฐาน
เดบิต (Dr) คือฝั่งที่สินทรัพย์หรือค่าใช้จ่ายเพิ่ม เครดิต (Cr) คือฝั่งที่หนี้เพิ่มหรือเงินออก

| เอกสาร | เดบิต | เครดิต |
|---|---|---|
| ซื้อสินค้า/ตั้งหนี้ซื้อ เงินเชื่อ | ซื้อสินค้า, ภาษีซื้อ | เจ้าหนี้การค้า (และ เงินมัดจำจ่าย ถ้าหักมัดจำ) |
| ซื้อสินค้า เงินสด | ซื้อสินค้า, ภาษีซื้อ | เงินสด / เงินฝากธนาคาร / เช็คจ่าย ตามช่องทางที่จ่าย |
| เพิ่มหนี้ซื้อ | ซื้อสินค้า, ภาษีซื้อ | เจ้าหนี้การค้า |
| ส่งคืน/ลดหนี้ซื้อ | เจ้าหนี้การค้า (หรือเงินที่รับคืน) | ซื้อสินค้า, ภาษีซื้อ |
| รับสินค้าตามใบสั่งซื้อ (ทะยอยรับ) | ซื้อสินค้า | เจ้าหนี้ไม่ถึงกำหนดตั้งหนี้ |
| ส่งคืนสินค้าจากการรับ | เจ้าหนี้ไม่ถึงกำหนดตั้งหนี้ | ซื้อสินค้า |
| ตั้งหนี้ซื้อจากการรับสินค้า | เจ้าหนี้ไม่ถึงกำหนดตั้งหนี้, ภาษีซื้อ | เจ้าหนี้การค้า หรือช่องทางที่จ่าย |
| จ่ายเงินล่วงหน้า | เงินจ่ายล่วงหน้า (เต็มจำนวน) | ช่องทางที่จ่าย |
| จ่ายเงินมัดจำ | เงินมัดจำจ่าย (ก่อนภาษี), ภาษีซื้อ | ช่องทางที่จ่าย |
| ตั้งหนี้อื่นๆ (เจ้าหนี้) | บัญชีของรหัสค่าใช้จ่ายที่เลือก, ภาษีซื้อ | เจ้าหนี้การค้า |
| จ่ายชำระหนี้ (เจ้าหนี้) | เจ้าหนี้การค้า | เงินสด / เงินฝากธนาคาร / เช็คจ่าย / ภาษีหัก ณ ที่จ่ายค้างจ่าย |

## ข้อควรรู้
- ชื่อบัญชีจริงเป็นไปตามผังบัญชีของกิจการ ตารางนี้ใช้ชื่อเรียกทั่วไป
- ถ้ากิจการกำหนดรูปแบบการลงบัญชีเองไว้ที่รหัสเอกสาร ระบบจะใช้แบบที่กำหนดก่อนแบบมาตรฐาน
- เอกสารที่ลงท้ายว่า "ยกมา" (ตั้งหนี้ยกมา, จ่ายเงินมัดจำยกมา ฯลฯ) ไม่ลงบัญชี เพราะยอดยกมาควรอยู่ในยอดยกมาของบัญชีแยกประเภทแล้ว
- ใบเสนอซื้อ ใบสั่งซื้อ และใบรับวางบิล ไม่ลงบัญชี
- จ่ายชำระหนี้สกุลเงินต่างประเทศ ระบบบันทึกกำไรหรือขาดทุนจากอัตราแลกเปลี่ยนให้
- ถ้าผังบัญชีไม่มีบัญชี เจ้าหนี้ไม่ถึงกำหนดตั้งหนี้ ระบบสร้างให้อัตโนมัติ
- ถ้าคู่บัญชีที่ได้ไม่ตรงกับที่ผู้สอบบัญชีต้องการ ให้ส่งต่อเจ้าหน้าที่ช่วยตรวจผังบัญชีและรูปแบบการลงบัญชี
