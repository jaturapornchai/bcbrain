# ตั้งค่าเริ่มต้น POS

**ใช้เมื่อ:** เริ่มใช้ POS ครั้งแรก หรือต้องการเปลี่ยนชื่อร้าน/ข้อความบนใบเสร็จ ประเภทภาษี หรือสิทธิ์ของแคชเชียร์
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดค่าเริ่มต้น POS
**ต้องมีก่อน:** มีลูกค้า "ลูกค้าทั่วไป" ในทะเบียนลูกหนี้ (ใช้เป็นรหัสลูกหนี้เริ่มต้น) และกำหนดรหัสเครื่อง POS ([[howto-pos-web-machine-register]])

## ขั้นตอน
1. เปิดเมนูด้านบน กดปุ่ม **แก้ไข** (หน้าจอเริ่มที่ "โหมดดูข้อมูล")
2. กรอกส่วนที่ 1 "ข้อมูลทั่วไปและใบเสร็จรับเงิน"
3. ดูส่วนที่ 3 "สิทธิ์และตัวเลือกควบคุมจุดแคชเชียร์" ติ๊กตามต้องการ
4. กด **บันทึก** ขึ้นข้อความ "บันทึกการกำหนดค่า POS และซิงก์ไปยังเครื่องแคชเชียร์สำเร็จ" เครื่อง POS จะได้รับค่าใหม่ตอนซิงก์ครั้งถัดไป

## ช่องที่ระบบบันทึกจริง
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสชุดกำหนดค่า POS | ชื่อชุดค่า เช่น ชุดเดียวสำหรับทั้งร้าน | ใช้เป็นตัวอ้างอิงชุด |
| ชื่อกิจการที่แสดงบนใบเสร็จรับเงิน POS | ชื่อร้าน | |
| ชื่อสาขาบนใบเสร็จ | เช่น สำนักงานใหญ่ | ถ้าไม่กรอกระบบใส่ "สำนักงานใหญ่ (00000)" |
| เลขประจำตัวผู้เสียภาษี (13 หลัก) | เลขผู้เสียภาษีร้าน | |
| หมายเลขเครื่อง POS สรรพากรเริ่มต้น | เลขเครื่องที่ขึ้นทะเบียนไว้ (ถ้ามี) | |
| รหัสลูกหนี้เริ่มต้น (ลูกค้าทั่วไป Walk-in) | รหัสลูกค้าที่ใช้เมื่อไม่ระบุสมาชิก | บิลของลูกค้านี้ไม่ได้แต้ม |
| ประเภทภาษีมูลค่าเพิ่ม | ราคารวมภาษี / ราคาแยกภาษี / ยกเว้นภาษี | ระบบนำไปคิดภาษีของทุกบิล POS |
| อัตราภาษีมูลค่าเพิ่ม (%) | อัตราที่ใช้ | เรื่องอัตราตามกฎหมายถามผู้สอบบัญชี |
| ข้อความหัว/ท้ายใบเสร็จรับเงิน | ข้อความที่พิมพ์ | |
| ส่วนลดสมาชิกเริ่มต้น (%) | ส่วนลดสมาชิก | |
| ใช้งานระบบสมาชิก | เปิดใช้ / ปิดระบบสมาชิก | |
| เงินสดสูงสุดในลิ้นชักเตือนนำส่งเงิน (บาท) | วงเงินที่ให้เตือน | |
| อัตราค่าบริการ (Service Charge %) | เปอร์เซ็นต์ค่าบริการ | |
| การปัดเศษเงินทอนทศนิยม / รูปแบบการปัดเศษ | ไม่ปัด, ปัดตามหลักคณิตศาสตร์, ปัดลง, ปัดขึ้น / มาตรฐาน 2 ตำแหน่ง, เหรียญสตางค์ 25/50/75, จำนวนเต็มบาท | |
| รูปแบบใบเสร็จเริ่มต้น | ใบกำกับภาษีอย่างย่อ (ABB) หรือใบเสร็จรับเงินทั่วไป | |
| สิทธิ์แก้ไขราคาขาย / แก้ไขส่วนลด / ยกเลิกบิลขาย POS | ห้าม, ทำได้ทันที, ต้องรออนุมัติ | แอปแคชเชียร์เป็นผู้บังคับใช้ แต่แอปรุ่นปัจจุบันถือว่า "ทำได้" เฉพาะเมื่อเลือก "ทำได้ทันที" ถ้าเลือก "ต้องรออนุมัติ" แอปจะห้ามเหมือนเลือก "ห้าม" (ยังไม่มีขั้นตอนขออนุมัติ) |

## ช่องที่หน้าจอมีแต่ระบบยังไม่บันทึก
ส่วนที่ 2 "บาร์โค้ดเครื่องชั่งน้ำหนัก & ข้อกำหนดเพิ่มเติม" (รหัสนำหน้าเครื่องชั่ง ตำแหน่งรหัส/ราคา/น้ำหนัก ช่วงเวลาห้ามขายแอลกอฮอล์ ฯลฯ) และช่องติ๊กส่วนที่ 3 ส่วนใหญ่ เช่น "ตรวจสอบการส่งเงินก่อนปิดกะ", "ใช้งานสินค้าชุด", "ถามรหัสผ่านก่อนเปิดลิ้นชัก" ปัจจุบัน **กดบันทึกแล้วระบบไม่เก็บค่า** ช่องที่เก็บจริงจากส่วนที่ 3 มี 6 ช่อง คือ อนุญาตแก้ไขราคาขาย, อนุญาตแก้ไขส่วนลด, อนุญาตยกเลิกบิล, แสดงรายละเอียดภาษี, แสดงรูปสินค้าตอนสแกน, บังคับรับเงินทอนก่อนขาย ดู [[ts-pos-web-setting-not-applied]]

## ช่องที่บันทึกแล้วแต่ยังไม่มีผลกับแอป POS
ช่องต่อไปนี้มีบนจอและเก็บค่าได้ แต่ไม่ได้ส่งลงเครื่อง POS ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผลกับแอป: ส่วนลดสมาชิกเริ่มต้น, ใช้งานระบบสมาชิก, เงินสดสูงสุดในลิ้นชักเตือนนำส่งเงิน, อัตราค่าบริการ, การปัดเศษเงินทอน/รูปแบบการปัดเศษ, รูปแบบใบเสร็จเริ่มต้น, แสดงรายละเอียดภาษีบนใบเสร็จ, แสดงรูปภาพสินค้าขณะสแกนบาร์โค้ด, บังคับบันทึกเงินทอนเปิดกะก่อนขาย (แอปให้ขายได้โดยไม่เปิดกะ) ส่วนข้อความหัว/ท้ายใบเสร็จ ส่งลงเครื่องแล้วแต่แอปยังไม่ได้นำไปพิมพ์ ถ้าลูกค้าถามว่าตั้งแล้วไม่เห็นผล ให้ส่งต่อเจ้าหน้าที่

## บันทึกแล้วระบบทำอะไรให้
- เก็บเป็นค่าของร้าน (มีชุดเดียวที่ใช้ทั้งร้าน)
- เครื่อง POS ที่เชื่อมแล้วดึงค่าไปใช้ตอนซิงก์ (ชื่อร้าน สาขา เลขผู้เสียภาษี ประเภท/อัตราภาษี ข้อความหัวท้าย สิทธิ์แก้ราคา/ส่วนลด/ยกเลิกบิล) แต่ข้อความภาษีบนใบเสร็จของแอปเขียน 7% ตายตัว
- ประเภทภาษีและอัตราภาษีนี้ใช้คำนวณบิลที่เข้าบัญชีด้วย ([[sys-pos-web-bill-to-accounting]])

## ปัญหาที่พบบ่อย
- "คุณไม่มีสิทธิ์ "เพิ่ม/แก้ไขข้อมูล" ในหน้าจอนี้ กรุณาติดต่อผู้ดูแลระบบ (Admin)" → ผู้ใช้ไม่มีสิทธิ์แก้ไขหน้านี้ ให้ผู้ดูแลระบบเปิดสิทธิ์ให้ ([[ts-common-no-permission]])
- ตั้งค่าแล้วเครื่อง POS ยังเป็นค่าเดิม → ดู [[howto-pos-web-monitor-sync]] ว่าเครื่องซิงก์ล่าสุดเมื่อไร
