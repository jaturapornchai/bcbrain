# ดูรายการบิลขาย POS และยกเลิกบิลจากหลังบ้าน

**ใช้เมื่อ:** อยากตรวจว่าบิลที่แคชเชียร์ขายเข้าระบบหรือยัง หรือต้องยกเลิกบิลที่คีย์ผิด
**เมนู:** ขาย › ระบบขายหน้าร้าน POS › รายการใบกำกับภาษีอย่างย่อ (หรือ ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › รายการใบกำกับภาษีอย่างย่อยกเลิก ซึ่งเป็นหน้าเดียวกัน)
**ต้องมีก่อน:** บิลต้องถูกส่งจากเครื่อง POS ขึ้นระบบแล้ว ([[howto-pos-web-monitor-sync]])

## ดูรายการบิล
หน้าจอแสดง **50 บิลล่าสุด** ของ POS (หัวตาราง "... (n บิล)") คอลัมน์ เลขที่ใบกำกับภาษีอย่างย่อ, วันที่ / เวลา, เครื่อง POS / แคชเชียร์, รหัสลูกค้า / หมายเหตุ, วิธีชำระเงิน, ยอดสุทธิ (บาท), สถานะ / จัดการ
- วิธีชำระเงินที่เห็น เช่น CASH, PROMPTPAY, TRANSFER, CARD ถ้าบิลจ่ายหลายแบบจะขึ้น MIXED
- ถ้ายังไม่มีบิล ขึ้นข้อความว่ายังไม่มีรายการขายจากเครื่อง POS ในวันนี้
- ต้องการดูบิลย้อนหลังนานกว่านี้ ให้ดูที่รายงานขายและเอกสารขายตามปกติ (บิล POS เป็นเอกสารขายสด)

## ยกเลิกบิล
1. หาบิลในรายการ กดปุ่ม **ยกเลิกบิล** ท้ายแถว
2. ระบบยกเลิกทันที **ไม่มีหน้าต่างถามยืนยัน** และเหตุผลที่บันทึกเป็นข้อความตายตัวว่า "ยกเลิกใบกำกับภาษีอย่างย่อจากระบบ BC Ai Account" (หน้า "รายการใบกำกับภาษีอย่างย่อยกเลิก" มีช่อง "ค้นหาเลขที่บิลอย่างย่อที่ต้องการยกเลิก", "สาเหตุการยกเลิกใบกำกับภาษีอย่างย่อ", "ผู้อนุมัติยกเลิกบิลประจำจุดแคชเชียร์" แต่เป็นช่องตัวอย่างที่ยังไม่ถูกส่งไปบันทึก และไม่ได้ใช้กรองรายการ ส่วนหน้า "รายการใบกำกับภาษีอย่างย่อ" ไม่มีช่องเหล่านี้) จึงควรตรวจเลขที่บิลให้ดีก่อนกด
3. สำเร็จขึ้น "ยกเลิกใบกำกับภาษีอย่างย่อเลขที่ ... เรียบร้อยแล้ว" แต่ตรงตำแหน่งเลขที่บิลหน้าจอรุ่นนี้ไม่แสดงเลขบิลจริง (จะขึ้นเป็นข้อความโปรแกรมแปลกๆ แทน) ให้ยืนยันผลจากแถวบิลที่ขึ้นป้าย "ยกเลิกแล้ว" แทน และแจ้งทีมงานเรื่องข้อความนี้
- ถ้าผู้ใช้ไม่มีสิทธิ์เพิ่ม/แก้ไขข้อมูลของหน้านี้ ขึ้น "คุณไม่มีสิทธิ์ "เพิ่ม/แก้ไขข้อมูล" ในหน้าจอนี้ กรุณาติดต่อผู้ดูแลระบบ (Admin)"

## ยกเลิกแล้วระบบทำอะไร
- ทำเครื่องหมายบิลขายเดิมและรายการสินค้าว่ายกเลิก
- ออกเอกสารยกเลิกขึ้นต้น CNM- ตามด้วยเลขที่บิลเดิม
- ตัดรายการบัญชีของบิลนั้นออก ยอดขายและภาษีของบิลจึงไม่อยู่ในบัญชี
- คำนวณสต็อกของสินค้าในบิลใหม่ และคำนวณแต้มสะสมของลูกค้ากับยอดคงเหลือคูปองใหม่
- การยกเลิกถูกบันทึกกับบิลดิบ จึงไม่ถูกยกเลิกกลับหากสั่งประมวลผลบิลใหม่
รายละเอียดดู [[sys-pos-web-bill-to-accounting]]

## ข้อจำกัด
- ปุ่มยกเลิกบนหน้านี้ **ไม่ตรวจ** ตัวเลือก "สิทธิ์ยกเลิกบิลขาย POS" ในค่าเริ่มต้น POS (ตัวเลือกนั้นควบคุมที่แอปแคชเชียร์) ใครมีสิทธิ์แก้ไขหน้านี้ก็ยกเลิกได้ ควรจำกัดสิทธิ์ผู้ใช้ให้เหมาะสม
- ระบบไม่มีปุ่ม "ยกเลิกการยกเลิก" ถ้ากดผิดต้องขายใหม่หรือแจ้งทีมงาน
- ไม่พบบิลจะขึ้น "ไม่พบบิล POS เลขที่ ..." (บิลยังไม่ถูกส่งขึ้นระบบ รอเครื่องซิงก์)
- การรับคืนสินค้าบางส่วนไม่ใช่ฟังก์ชันของหน้านี้ ใช้เมนูรับคืน/ลดหนี้ตามปกติ หรือดูเอกสารฝั่งแอปแคชเชียร์
