# รับเงินล่วงหน้าจากลูกค้า ยอดยกมา และคืนเงินรับล่วงหน้า

**ใช้เมื่อ:** ลูกค้าจ่ายเงินมาก่อนโดยยังไม่มีการส่งของ/ให้บริการ และบันทึกแบบไม่มีภาษีมูลค่าเพิ่มในใบ ถ้าต้องการออกใบกำกับภาษีตอนรับเงิน และหักเงินนี้ในใบขาย ให้ใช้ "รับเงินมัดจำ" แทน ([[faq-sale-deposit-vs-advance]])
**เมนู:** ขาย › รับเงินล่วงหน้า / ขาย › รับเงินล่วงหน้ายกมา / ขาย › คืนเงินรับล่วงหน้า
**ต้องมีก่อน:** ทะเบียนลูกค้า ([[howto-ar-customer-register]]) สมุดเงินฝากถ้ารับเงินโอน ([[howto-cash-bank-overview]])

## ขั้นตอน (รับเงินล่วงหน้า)
1. เปิด ขาย › รับเงินล่วงหน้า กด "เพิ่มใหม่" ใส่วันที่ เลขที่เอกสาร
2. เลือก "ลูกหนี้/ลูกค้า"
3. ในตาราง ใส่รายละเอียดว่ารับเงินค่าอะไร และจำนวนเงิน
4. ถ้าเกี่ยวกับเอกสารอื่น จดเลขไว้ในช่อง "เอกสารอ้างอิง" ได้
5. เปิดแท็บ "การรับ/จ่ายชำระเงิน" ใส่ช่องทางรับเงินให้ครบยอด ([[howto-sale-cash-payment]])
6. กด "บันทึก"

## ขั้นตอน (คืนเงินรับล่วงหน้า)
1. เปิด ขาย › คืนเงินรับล่วงหน้า กด "เพิ่มใหม่"
2. เลือกใบรับเงินล่วงหน้าเดิมที่ช่อง "เลขที่ใบรับล่วงหน้า" ระบบดึงลูกค้าและยอดเดิมมาให้ ("จำนวนจ่ายเงินล่วงหน้า" คือยอดของใบเดิม)
3. ใส่จำนวนที่คืน แล้วใส่ช่องทางจ่ายคืนในแท็บ "การรับ/จ่ายชำระเงิน"
4. กด "บันทึก"

## ขั้นตอน (รับเงินล่วงหน้ายกมา)
- ใช้ตอนเริ่มใช้ระบบ เพื่อยกยอดเงินล่วงหน้าที่ลูกค้าจ่ายไว้ก่อนเริ่มใช้โปรแกรม ใส่ลูกค้า รายละเอียด และจำนวนเงิน แล้วบันทึก ไม่ต้องใส่ช่องทางรับเงิน

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | ลูกค้าที่จ่ายเงิน | ใบคืนเงิน ระบบดึงจากใบเดิม |
| ตารางรายละเอียด / จำนวนเงิน | รับค่าอะไร เท่าไร | ใส่ได้หลายบรรทัด |
| ภายใน (วัน) / ภายในวันที่ | ระยะเวลาที่ตกลงกับลูกค้า (ส่วนล่างของจอ) | ใบคืนเงินใช้ค่าจากใบเดิม แก้ไม่ได้ |
| การรับ/จ่ายชำระเงิน | ช่องทางรับ/คืนเงิน | ใบยกมาไม่มีแท็บนี้ |

## บันทึกแล้วระบบทำอะไรให้
- **ลงบัญชีอัตโนมัติ:** รับเงินล่วงหน้า = เดบิต เงินสด/เงินฝากธนาคาร/เช็ครับ ตามช่องทาง เครดิต เงินรับล่วงหน้า (หนี้สินที่ยังต้องส่งของหรือคืนเงินให้ลูกค้า) / คืนเงิน = กลับข้างกัน
- ใบยกมาไม่ลงบัญชี เก็บเป็นยอดตั้งต้นเท่านั้น
- ใบรับเงินล่วงหน้าไม่มีแท็บภาษีมูลค่าเพิ่ม
- **ข้อจำกัด:** เงินรับล่วงหน้าเอาไปหักในใบขายผ่านแท็บ "ใช้เงินมัดจำ" ไม่ได้ (แท็บนั้นดึงเฉพาะใบรับเงินมัดจำ) ปิดยอดได้ด้วย "คืนเงินรับล่วงหน้า" เท่านั้น

## แก้ไข ยกเลิก พิมพ์
- ใบที่ถูกคืนเงินไปแล้ว แก้/ลบไม่ได้ ขึ้น "เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้"
- ยกเลิก: ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกรับเงินล่วงหน้า / ยกเลิกคืนเงินรับล่วงหน้า ([[howto-sale-cancel-docs]])
- พิมพ์ใบรับเงิน: ปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"
