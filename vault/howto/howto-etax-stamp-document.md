# กดประทับเวลาเอกสาร e-Tax

**ใช้เมื่อ:** เอกสารในทะเบียนขึ้นสถานะรอประทับเวลา หรืออยากออกใบรับรองซ้ำ
**เมนู:** หน้า e-Tax › แท็บ "1. ทะเบียนใบกำกับภาษี e-Tax ..." (คอลัมน์ขวาสุด "คำสั่งประทับเวลา")

## ขั้นตอน
1. เปิดแท็บทะเบียน ค้นหาเอกสารด้วยเลข e-Tax เลขเอกสารอ้างอิง เลขผู้เสียภาษี หรือชื่อคู่ค้า
2. ดูคอลัมน์ "สถานะประทับเวลา ETDA & มาตรฐาน XML": ป้ายสีเหลือง = รอประทับเวลา ป้ายสีเขียว = สถานะอื่น
3. ที่แถวเอกสาร กดปุ่ม "ประทับเวลา ETDA Time Stamp ทันที" (ปุ่มสีแดง ขึ้นเมื่อรอประทับเวลา) หรือ "ออกใบรับรอง Time Stamp ซ้ำ" (ปุ่มกรอบสีเขียว ขึ้นกับเอกสารอื่นทั้งหมด)
4. รอจนมีข้อความแจ้ง "ประทับเวลา ETDA Time Stamp เอกสาร ... สำเร็จ! ..."
5. สถานะของเอกสารเปลี่ยนเป็นประทับเวลาแล้ว และมีรูปเพิ่มในอัลบั้มของเอกสาร

## ระบบทำอะไรให้
- ออกรหัสรับรองจากเวลาเครื่องของระบบเอง และบันทึกสถานะ
- สร้างรูปตัวอย่าง 2 รูปเก็บไว้ในอัลบั้มเอกสาร (ไม่ใช่ไฟล์เอกสารจริง)
- ไม่ได้เรียกหน่วยงานประทับเวลาภายนอก → [[faq-etax-real-stamp-real-ocr]]
- เอกสารที่สร้างจากระบบอื่นหรือกรอกเองส่วนใหญ่ขึ้นเป็นประทับแล้วตั้งแต่สร้าง จึงมักเห็นแต่ปุ่มออกใบรับรองซ้ำ

## ข้อควรระวัง
- เอกสารยกเลิกก็มีปุ่ม "ออกใบรับรอง Time Stamp ซ้ำ" ถ้ากด สถานะยกเลิกจะถูกเปลี่ยนเป็นประทับเวลาแล้ว อย่ากดกับเอกสารยกเลิก ถ้ากดไปแล้ว → ส่งต่อเจ้าหน้าที่
