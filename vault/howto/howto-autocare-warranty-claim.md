# ใบรับประกันดิจิทัลและงานเคลมยางส่งโรงงาน

**ใช้เมื่อ:** ลูกค้านำยางหรืออะไหล่ที่ซื้อไปมาเคลม และศูนย์ต้องส่งต่อโรงงาน
**เมนู:** AutoCare › 3. คลังสินค้า รับฝากยาง และงานเคลม › "บันทึกงานเคลมยาง/อะไหล่ส่งโรงงาน และตัดคูปองสมาชิก" (ชื่อย่อ "บันทึกงานเคลม & ตัดคูปอง")

## ใบรับประกันดิจิทัล
ออก **อัตโนมัติ** ตอนปิดบิล ไม่ต้องกรอกเอง ดู [[howto-autocare-close-bill]] ดูรายการได้ในรายงานใบรับประกันดิจิทัล

## บันทึกงานเคลม
1. เปิดเมนู กด "เพิ่มใหม่" (หน้านี้เป็นฟอร์มใบเคลมอย่างเดียว ปุ่มตัดสิทธิ์คูปองอยู่ที่เมนู 1. ข้อมูลหลักศูนย์บริการ › แพ็กเกจคูปองสมาชิก)
2. กรอกช่องที่บังคับ: เลขที่ใบเคลม, ทะเบียนรถลูกค้า, ชื่อลูกค้าผู้แจ้งเคลม, รหัส DOT / Serial ยางที่เคลม, ชื่อรุ่นยาง / อะไหล่ที่ส่งเคลม, โรงงานผู้ผลิต / ผู้แทนจำหน่าย และอาการเสีย / สาเหตุที่ส่งเคลมโรงงาน **พิมพ์ทับค่าตัวอย่างทุกช่อง**
3. กด "บันทึก" ระบบขึ้น "บันทึกข้อมูลเสร็จเรียบร้อย"
4. เลือกใบเคลมในตาราง จะมีแผง "ติดตามและอัปเดตสถานะงานเคลมโรงงาน" กดปุ่ม "เลื่อนสถานะงานเคลมถัดไป" ระบบเลื่อนตามลำดับ รับเรื่องเคลม ➔ ส่งโรงงาน ➔ โรงงานตรวจสอบ ➔ เปลี่ยนเส้นใหม่สำเร็จ ➔ ปิดงาน และขึ้น "อัปเดตสถานะงานเคลมโรงงาน ... เรียบร้อย" (ช่อง "สถานะงานเคลม" ในรายการอาจแสดงเป็นคำอังกฤษ)
5. ลบใบเคลมที่ผิดได้ด้วยปุ่ม "ลบ" ขึ้นข้อความ "ลบรายการเคลมโรงงาน ... เรียบร้อย"

## ข้อจำกัด
- บันทึกใบเคลมใหม่แล้ว ระบบผูกกับข้อมูลตั้งต้นเดิมเสมอ คือใบงาน JOB-2610-001, รหัสลูกค้า AR-AC01, เบอร์โทรเดิม และสินค้า TIRE-MI-2055516 ไม่ตรงกับรถที่ลูกค้านำมาจริง และแก้ภายหลังก็ไม่เปลี่ยนค่าเหล่านี้ ถ้าต้องใช้ข้อมูลเคลมจริง ให้ **ส่งต่อเจ้าหน้าที่**
- งานเคลมเป็นการติดตามสถานะอย่างเดียว ไม่ลงบัญชี ไม่คืนเงิน ไม่ตัดสต็อกของที่เคลม
- ไม่มีการส่งข้อมูลไปโรงงานจริง
