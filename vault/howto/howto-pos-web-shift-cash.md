# บันทึกรับเงินทอนเปิดกะ และบันทึกส่งเงินปิดกะ

**ใช้เมื่อ:** เจ้าของร้านหรือหัวหน้าอยากบันทึกเงินทอนที่ใส่ลิ้นชักก่อนเริ่มขาย หรือบันทึกยอดเงินที่แคชเชียร์นำส่งตอนปิดกะ จากหน้าเว็บ (ปกติแคชเชียร์ทำจากแอป POS เอง)
**เมนู:** ขาย › ระบบขายหน้าร้าน POS › บันทึกรับเงิน (เงินทอน) และ ขาย › ระบบขายหน้าร้าน POS › บันทึกส่งเงิน POS
**ต้องมีก่อน:** ลงทะเบียนเครื่อง POS ([[howto-pos-web-machine-register]])

## บันทึกรับเงินทอนเปิดกะ
1. เปิดเมนู "บันทึกรับเงิน (เงินทอน)" กด **แก้ไข** (หรือ **เพิ่มใหม่**)
2. เลือก "รหัสเครื่อง POS ที่รับเงินทอน"
3. ใส่ "รหัสแคชเชียร์ผู้รับเงินทอน" และ "จำนวนเงินทอนรับเข้าลิ้นชัก (บาท)"
4. ใส่ "หมายเหตุการรับเงินทอนเปิดกะ" (ถ้าไม่ใส่ ระบบใส่ว่า "รับเงินทอนเข้าลิ้นชักแคชเชียร์ (เปิดกะขาย)")
5. กด **บันทึก** ขึ้น "บันทึกรายการ ... และซิงก์ไปยังจุดแคชเชียร์เรียบร้อยแล้ว"

ระบบออกเลขที่เอกสารขึ้นต้น RCV- ให้ และเปิดกะของเครื่องนั้นให้ถ้าเครื่องนั้นยังไม่มีกะที่เปิดอยู่ (ถ้ามีกะเปิดอยู่แล้วจะไม่เปิดซ้ำ)

## บันทึกส่งเงินปิดกะ
1. เปิดเมนู "บันทึกส่งเงิน POS" กด **แก้ไข**
2. เลือก "รหัสเครื่อง POS ที่นำส่งเงิน" ใส่ "รหัสแคชเชียร์ผู้นำส่งเงินปิดกะ"
3. ใส่ยอดที่นำส่ง: "ยอดเงินสดนำส่งเข้าการเงิน (บาท)", "ยอดสลิปบัตรเครดิต/เดบิตนำส่ง (บาท)", "ยอดโอน QR PromptPay / คูปองนำส่ง (บาท)"
4. ใส่ "หมายเหตุการนำส่งเงินปิดกะ" แล้วกด **บันทึก**

ระบบรวมยอดทุกช่องเป็นยอดนำส่ง และออกเลขที่เอกสารขึ้นต้น SND- ให้ การบันทึกจากหน้าเว็บนี้ **ไม่ปิดกะ** ของเครื่อง (การปิดกะทำจากแอป POS)

## ดูประวัติ
ตารางด้านล่างหน้าจอแสดงประวัติของเมนูนั้น (เมนูรับเงินทอนแสดงเฉพาะรายการรับเงินทอน เมนูส่งเงินแสดงเฉพาะรายการส่งเงิน) โดยดึงมาจาก 50 รายการล่าสุดรวมทั้งสองแบบ (คอลัมน์ เลขที่เอกสาร, วันที่ / เวลา, ประเภทรายการ, เครื่อง POS / แคชเชียร์, หมายเหตุ, จำนวนเงินสด)

## บันทึกแล้วระบบทำอะไรให้
- เก็บเป็นเอกสารควบคุมเงินในลิ้นชักของเครื่องและแคชเชียร์
- **ไม่ลงบัญชีและไม่กระทบยอดขาย** ถ้าต้องบันทึกการนำเงินเข้าธนาคารหรือเงินสดย่อย ให้ทำที่เมนูเงินสด/ธนาคารตามปกติ
- หน้าจอนี้ไม่มีช่องให้กรอกเลขที่เอกสาร ระบบออกเลขให้เองทุกครั้ง

## ปัญหาที่พบบ่อย
- "ต้องระบุรหัสเครื่อง POS" → ยังไม่ได้เลือกเครื่อง
- "จำนวนเงินไม่ถูกต้อง: ..." → ใส่ตัวเลขเท่านั้น
- "คุณไม่มีสิทธิ์ "เพิ่ม/แก้ไขข้อมูล" ในหน้าจอนี้ กรุณาติดต่อผู้ดูแลระบบ (Admin)" → [[ts-common-no-permission]]
