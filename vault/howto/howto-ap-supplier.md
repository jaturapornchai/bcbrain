# เพิ่มและแก้ไขเจ้าหนี้ (ผู้จำหน่าย)

**ใช้เมื่อ:** มีผู้ขายรายใหม่ที่กิจการซื้อของด้วย หรือต้องแก้ชื่อ ที่อยู่ เลขผู้เสียภาษีของผู้ขายเดิม
**เมนู:** เจ้าหนี้ › ทะเบียนเจ้าหนี้ คู่ค้า และที่อยู่จัดส่ง › กำหนดเจ้าหนี้
**ต้องมีก่อน:** สิทธิ์เพิ่มหรือแก้ไขข้อมูลในหน้าจอนี้ ถ้าจะจัดกลุ่มหรือแยกประเภท ให้ตั้งรหัสไว้ก่อนที่ [[howto-ap-setup-codes]]

เจ้าหนี้ (ผู้ที่กิจการค้างเงินอยู่ เช่น ผู้ขายสินค้าให้เรา) ในระบบเรียกว่า ผู้จำหน่าย ใช้รหัสเดียวกันทั้งระบบซื้อและระบบเจ้าหนี้

## ขั้นตอน
1. เปิดเมนู กำหนดเจ้าหนี้ กด "เพิ่มใหม่"
2. ใส่ "รหัสผู้จำหน่าย" เอง หรือกด "รันรหัสใหม่" / "ใส่รหัสถัดไปอัตโนมัติ" ให้ระบบออกรหัส
3. เลือก "สถานะผู้จำหน่าย" เป็น บุคคลธรรมดา หรือ นิติบุคคล
4. ใส่ "ชื่อผู้จำหน่าย 1" ที่อยู่ จังหวัด อำเภอ/เขต ตำบล/แขวง รหัสไปรษณีย์
5. ใส่ "เลขประจำตัวผู้เสียภาษี" และเลือก "สถานประกอบการ" สำนักงานใหญ่ หรือ สาขา
6. กด "บันทึก" ระบบแจ้ง "บันทึกข้อมูลเจ้าหนี้เสร็จเรียบร้อย"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสผู้จำหน่าย * | รหัสที่ใช้เรียกผู้ขาย | ต้องไม่ซ้ำ ใช้ค้นในทุกเอกสารซื้อ |
| ชื่อผู้จำหน่าย 1 * | ชื่อที่จะพิมพ์ในเอกสาร | ช่องบังคับ |
| สถานะผู้จำหน่าย | บุคคลธรรมดา / นิติบุคคล | บุคคลธรรมดาใส่ คำนำหน้า ชื่อ นามสกุล แยกได้ |
| เลขประจำตัวผู้เสียภาษี | 13 หลัก | ใช้ในรายงานภาษีซื้อ |
| สถานประกอบการ / เลขที่สาขา | สำนักงานใหญ่ หรือ สาขา | สาขาต้องเป็นตัวเลข 5 หลัก ห้ามเป็น 00000 |
| ประเภทผู้จำหน่าย | เลือกจากรหัสที่ตั้งไว้ | ใช้จัดกลุ่มในรายงาน |
| สถานะ | ใช้งาน / ไม่ใช้งาน | |
| หมายเลขโทรศัพท์, อีเมล์, เว็บไซต์ | ช่องทางติดต่อ | ไม่บังคับ |

## บันทึกแล้วระบบทำอะไรให้
- รหัสนี้เลือกได้ทันทีในใบเสนอซื้อ ใบสั่งซื้อ ใบซื้อ และเอกสารเจ้าหนี้ทุกใบ
- ระบบตรวจว่าเลขประจำตัวผู้เสียภาษีกับเลขสาขา ซ้ำกับเจ้าหนี้รายอื่นหรือไม่ ถ้าซ้ำจะไม่ให้บันทึก
- ข้อมูลเงื่อนไขการซื้อ เช่น เครดิต ส่วนลด ประเภทภาษี ตั้งต่อที่ [[howto-ap-supplier-detail]]

## แก้ไข ยกเลิก พิมพ์
- แก้ไข: เลือกเจ้าหนี้ กด "แก้ไข" แก้แล้วกด "บันทึก" ถ้าปิดหน้าจอก่อนบันทึก ระบบถาม "มีการแก้ไขข้อมูลที่ยังไม่ได้บันทึก ต้องการละทิ้งการแก้ไขหรือไม่?"
- ลบ: เลือกรายการ กด "ลบ" ลบได้หลายรายการพร้อมกัน แต่ถ้าเคยใช้ในเอกสารแล้วจะลบไม่ได้ ([[ts-ap-supplier-cannot-delete]])
- เจ้าหนี้ที่เลิกซื้อแล้ว แต่มีเอกสารเก่า ให้เปลี่ยน "สถานะ" เป็น ไม่ใช้งาน แทนการลบ

## ปัญหาที่พบบ่อย
- "กรุณาระบุ 'รหัสผู้จำหน่าย'" หรือ "กรุณาระบุ 'ชื่อผู้จำหน่าย 1'" → กรอกช่องที่มีดอกจัน ([[ts-ap-supplier-save-error]])
- "เลขประจำตัวผู้เสียภาษีอากร ไม่ครบ 13 หลัก" → ตรวจเลขให้ครบ ([[ts-ap-supplier-save-error]])
- "เลขประจำตัวผู้เสียภาษี '...' และสาขา '...' ซ้ำกับเจ้าหนี้รหัส [...]" → มีเจ้าหนี้รายนี้อยู่แล้ว ([[ts-ap-supplier-save-error]])
- "คุณไม่มีสิทธิ์ ..." → [[ts-common-no-permission]]
