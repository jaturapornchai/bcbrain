# รายงานภาษีซื้อ ภาษีขาย และสรุปภาษี (ภ.พ.30)

**ใช้เมื่อ:** สิ้นเดือนต้องการรายงานภาษีซื้อ-ภาษีขาย เพื่อตรวจและใช้ประกอบการยื่นแบบ ภ.พ.30 (แบบแสดงรายการภาษีมูลค่าเพิ่มรายเดือน)
**เมนู:** บัญชี › รายงานภาษีมูลค่าเพิ่ม (ภ.พ.30) › เลือกรายงาน
**ต้องมีก่อน:** เอกสารที่มีภาษี ([[howto-tax-vat-from-documents]]) หรือภาษีที่บันทึกในข้อมูลรายวัน ([[howto-tax-journal-tax-tabs]])

## ขั้นตอน
1. เปิดเมนู รายงานภาษีมูลค่าเพิ่ม (ภ.พ.30) เลือกรายงานที่ต้องการ
2. ใส่ "ตั้งแต่วันที่:" และ "ถึงวันที่:" ระบบใช้ "งวดภาษีตามเดือนของวันที่เริ่มต้น-สิ้นสุด" คือดูแค่เดือน/ปีของ 2 วันนั้น แล้วดึงตาม เดือนภาษี/ปีภาษี ของแต่ละรายการ ไม่ใช่วันที่เอกสาร
3. ถ้าต้องการกรองเพิ่ม ใส่ "จากรหัส:" "ถึงรหัส:" (ใช้กับเลขที่เอกสาร) หรือพิมพ์คำค้นหา (เลขที่ใบกำกับ เลขที่เอกสาร หรือชื่อ)
4. กด ประมวลผลรายงาน ตรวจ แล้วพิมพ์หรือส่งออก ([[rpt-print-export]])

## รายงานในกลุ่ม
| รายงาน | แสดงอะไร |
|---|---|
| รายงานภาษีขาย / รายงานภาษีซื้อ | เฉพาะเอกสารภาษีแยกนอกและรวมใน (รวมแถวภาษีจากข้อมูลรายวัน): ลำดับ วันที่ เลขที่ใบกำกับ เลขที่เอกสาร ชื่อผู้ซื้อสินค้า/ผู้รับบริการ (หรือ ชื่อผู้ขายสินค้า/ผู้ให้บริการ) ประเภทระบบ ยื่นเพิ่มเติม มูลค่าสินค้า/บริการ ภาษีมูลค่าเพิ่ม รวม สถานะ |
| รายงาน ภาษีขาย / รายงาน ภาษีซื้อ (แสดงมูลค่าอัตราภาษีศูนย์) | รวมทุกแถวภาษี (รวมเอกสารยกเว้นภาษี) และเพิ่มคอลัมน์ มูลค่ายกเว้นภาษี |
| รายงานภาษีขาย (รูปแบบใหม่) / รายงาน ภาษีซื้อ (รูปแบบใหม่) | เพิ่ม เลขประจำตัวผู้เสียภาษี สำนักงานใหญ่ สาขา |
| รายงานภาษีขาย (รูปแบบใหม่แสดงมูลค่าอัตราภาษีศูนย์) | รวมแบบ รูปแบบใหม่ กับ แสดงมูลค่าอัตราภาษีศูนย์ ช่อง รวม ของเอกสารภาษีรวมในใช้ยอดรวมของเอกสาร |
| รายงานภาษีขาย (มาตรฐาน) / รายงานภาษีซื้อ (มาตรฐาน) | วันที่เอกสาร เลขที่เอกสาร วันที่ใบกำกับ เลขที่ใบกำกับ ชื่อ เลขประจำตัวผู้เสียภาษี สำนักงานใหญ่ สาขาที่ มูลค่าสินค้าหรือบริการ ภาษีมูลค่าเพิ่ม หมายเหตุ · "เรียงตาม:" เลือกได้ วันที่ใบกำกับ / เลขที่ใบกำกับ / วันที่เอกสาร / เลขที่เอกสาร · ไม่มีคอลัมน์ สถานะ |
| รายงานสรุปภาษีขาย | รายการแบบเดียวกับ แสดงมูลค่าอัตราภาษีศูนย์ (ไม่ใช่ยอดสรุป) |
| รายงานสรุปภาษี | รายเดือนภาษี: เดือนภาษี ฐานภาษีขาย ภาษีขาย ฐานภาษีซื้อ ภาษีซื้อ ภาษีที่ต้องชำระ (ขอคืน) |
| รายงานภาษีขายต่างประเทศ, รายงานภาษีซื้อต่างประเทศ, รายงานสรุปภาษีต่างประเทศ | ยังไม่มีข้อมูลในรุ่นนี้ ([[ts-tax-foreign-vat-empty]]) |

## บันทึกแล้วระบบทำอะไรให้
- รายงานดูอย่างเดียว ไม่เปลี่ยนข้อมูล
- เอกสารที่ยกเลิก แสดงยอด 0 และสถานะ ยกเลิก ยกเว้นแบบ (มาตรฐาน) ที่ยังแสดงเต็มยอด ([[faq-tax-cancelled-doc-in-report]])
- คอลัมน์ ยื่นเพิ่มเติม แสดงรายการที่ติ๊กยื่นเพิ่มเติมไว้
- แบบ (มาตรฐาน) ช่อง สำนักงานใหญ่ / สาขาที่ ดึงจากทะเบียนลูกหนี้/เจ้าหนี้ ไม่ได้ดูจากแถวภาษี
- **รายงานสรุปภาษี ฝั่งภาษีซื้อ** รุ่นปัจจุบันไม่นับเอกสารซื้อที่หัวเอกสารเลือก ภาษี: รวมใน หรือ ยกเว้นภาษี และไม่นับแถวที่ ประเภทภาษี ไม่ใช่ ปรกติ ยอดจึงอาจน้อยกว่ารายงานภาษีซื้อ ให้ใช้ยอดจากรายงานภาษีซื้อรายใบ ถ้าลูกค้าต้องใช้ยอดสรุปนี้ → ส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- ตัวเลขผิด ให้แก้ที่เอกสารต้นทาง (แท็บภาษีของเอกสาร) หรือใบสำคัญในข้อมูลรายวัน แล้วเปิดรายงานใหม่

## ปัญหาที่พบบ่อย
- เอกสารไม่ขึ้นในรายงาน → [[ts-tax-doc-not-in-vat-report]]
- รายการขึ้นผิดเดือน → ตรวจ เดือนภาษี/ปีภาษี ของแถวภาษี ([[faq-tax-vat-month]])
- เรื่องการยื่นแบบ อัตราภาษี กำหนดเวลา ให้ปรึกษาผู้สอบบัญชี/สรรพากร
