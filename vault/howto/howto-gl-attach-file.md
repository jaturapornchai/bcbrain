# แนบรูปภาพหรือไฟล์ให้ใบสำคัญ (ระบบบัญชี)

**ใช้เมื่อ:** ต้องการเก็บหลักฐาน (ใบเสร็จ สัญญา ใบแจ้งหนี้ที่สแกน) ไว้กับใบสำคัญในระบบ เพื่อเปิดดูภายหลังหรือให้ผู้สอบบัญชีตรวจ
**เมนู:** บัญชี › บันทึกรูปภาพและไฟล์แนบเอกสาร
**ต้องมีก่อน:** ใบสำคัญที่บันทึกแล้ว ([[howto-gl-journal-entry]])

## ขั้นตอน
1. เปิดเมนู บันทึกรูปภาพและไฟล์แนบเอกสาร
2. เลือกใบสำคัญจากรายการด้านซ้าย (ในระบบบัญชีไม่ต้องเลือกประเภทเอกสาร)
3. กด แก้ไข แล้วกดปุ่ม เลือกรูป / ไฟล์แนบ เลือกไฟล์จากเครื่อง
4. กด บันทึก ระบบขึ้น "บันทึกรูปภาพและไฟล์แนบเอกสารแล้ว"
5. ปุ่ม ก่อนหน้า / ถัดไป ใต้รายการด้านซ้าย ใช้เปลี่ยนหน้ารายการใบสำคัญ (ไม่ได้เลื่อนดูไฟล์) ส่วนปุ่ม ลบ จะลบไฟล์แนบทั้งหมดของใบนั้น โดยถามยืนยัน "ลบรูปภาพทั้งหมดของเอกสาร ... ?" ก่อน

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ไฟล์ | รูปภาพ PNG, JPG, WEBP, GIF, BMP หรือไฟล์ PDF, XLS, XLSX, CSV, DOC, DOCX, PPT, PPTX, TXT, ZIP | ไฟล์ละไม่เกิน 25 MB จำนวนไฟล์ไม่จำกัด |

## บันทึกแล้วระบบทำอะไรให้
- ไฟล์ผูกกับเลขที่ใบสำคัญ เปิดดูได้ที่หน้าจอนี้
- ไม่กระทบยอดบัญชีใดๆ

## แก้ไข ยกเลิก พิมพ์
- ลบไฟล์ทั้งหมดของใบ: ขึ้น "ลบรูปภาพและไฟล์แนบของเอกสารแล้ว"
- ผู้ใช้ที่ไม่มีสิทธิ์เพิ่ม/แก้ไข/ลบ เปิดดูได้อย่างเดียว ([[ts-common-no-permission]])

## ปัญหาที่พบบ่อย
- "มีรูปที่ยังไม่บันทึก กรุณาบันทึกหรือยกเลิกก่อน" → กด บันทึก หรือกด ปิดหน้าจอ เพื่อยกเลิกการแก้ไข ก่อนเปลี่ยนไปใบอื่น
- "ไฟล์ที่ ... ใหญ่เกิน 25 MB" → ย่อไฟล์หรือแยกเป็นหลายไฟล์
- "ไฟล์ที่ ... ไม่รองรับ (...)" → แปลงเป็นชนิดไฟล์ที่รองรับตามตารางด้านบน
- "ไฟล์แนบนี้ถูกเปลี่ยนโดยผู้ใช้อื่น กรุณาเปิดรายการใหม่แล้วทำอีกครั้ง" → มีคนแก้พร้อมกัน เปิดใบนั้นใหม่
- "เอกสารนี้ยังไม่มีรูปภาพหรือไฟล์แนบ" → ใบนี้ยังไม่ได้แนบ
