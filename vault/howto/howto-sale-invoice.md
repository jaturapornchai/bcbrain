# เปิดบิลขาย ออกใบกำกับภาษี (ขายสินค้า/บริการ)

**ใช้เมื่อ:** ขายสินค้าหรือบริการให้ลูกค้าจริง ทั้งขายเชื่อ (ลูกค้าจ่ายทีหลัง) และขายสด (รับเงินทันที) ใบนี้ตัดสต็อก ตั้งหนี้ ขึ้นภาษีขาย และลงบัญชีให้อัตโนมัติ
**เมนู:** ขาย › ขายสินค้า/บริการ
**ต้องมีก่อน:** ทะเบียนลูกค้า ([[howto-ar-customer-register]]), ทะเบียนสินค้า ([[howto-stock-overview]]), ตั้งค่าระบบขาย ([[howto-sale-settings]])

## ขั้นตอน
1. เปิด ขาย › ขายสินค้า/บริการ กด "เพิ่มใหม่"
2. ใส่ "วันที่เอกสาร" และ "เลขที่เอกสาร" (ปุ่ม "Auto" รันเลขให้) ช่อง "เลขที่ใบกำกับภาษี" จะเติมตามเลขที่เอกสารให้ถ้ายังว่าง
3. เลือก "ลูกหนี้/ลูกค้า" ระบบดึงประเภทการขาย ส่วนลด พนักงาน และวันเครดิตของลูกค้ามาให้ (ประเภทภาษีดึงมาเฉพาะลูกค้าที่ติ๊ก "กำหนดประเภทภาษี" ไว้)
4. เลือก "ประเภทรายการ": "ขายเชื่อ (เครดิต)" หรือ "ขายสด"
5. ถ้ามีใบเสนอราคา/ใบสั่งจอง/ใบสั่งขาย ให้กด "ดึงเอกสาร" ([[howto-sale-pull-ref-doc]]) ถ้าไม่มี ให้คีย์สินค้าเองในแท็บ "รายการสินค้า / เอกสาร"
6. ถ้าลูกค้าเคยจ่ายมัดจำไว้ ไปแท็บ "ใช้เงินมัดจำ" ([[howto-sale-deduct-deposit]])
7. ถ้าขายสด ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่เงินที่รับ ([[howto-sale-cash-payment]])
8. ตรวจยอดด้านล่าง แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | รหัสลูกค้า | ลูกค้าที่ตั้งสถานะ "ไม่ใช้งาน" ไม่ขึ้นในรายการให้เลือก และถ้าพิมพ์รหัสเอง ใบใหม่จะบันทึกไม่ได้ ขึ้น "สถานะ ลูกค้าปิดการใช้งาน : ..." |
| ประเภทรายการ | ขายเชื่อ / ขายสด | ขายสดต้องรับเงินให้ครบยอด |
| ภาษี | แยกนอก / รวมใน / ยกเว้นภาษี / ไม่กระทบภาษี | [[faq-sale-vat-types]] |
| เลขที่ใบกำกับภาษี / ลงวันที่ | เลขและวันที่ใบกำกับ | บังคับเมื่อเปิด "ป้อนเลขที่ใบกำกับภาษีทุกครั้ง" |
| เครดิต (วัน) / ครบกำหนด | วันเครดิต และวันครบกำหนดชำระ | ปุ่ม "เครดิต 7 วัน" ช่วยใส่เร็ว |
| พนักงาน/แผนก | พนักงานขาย | ดึงจากลูกค้าได้ |
| ส่วนลดก่อนภาษี | ส่วนลดท้ายบิล เช่น "เช่น 5% หรือ 100" | [[howto-sale-discount]] |
| ประเภทการส่ง | รับเอง / ส่งให้ | ส่วนล่างของจอ |

ยอดด้านล่าง: "รวมมูลค่าสินค้า" → "ส่วนลดก่อนภาษี" → "มูลค่าส่วนลด" → "หักเงินมัดจำ" → "ยอดเงินก่อนภาษี" → "ยอดภาษีมูลค่าเพิ่ม" → "มูลค่าหลังคิดภาษี" → "มูลค่ายกเว้นภาษี" → "รวมมูลค่าทั้งสิ้น"

## บันทึกแล้วระบบทำอะไรให้
- **สต็อก:** ตัดสต็อกสินค้าที่เป็นสินค้าคงคลัง (สินค้าบริการไม่ตัด)
- **ลูกหนี้:** ขายเชื่อ = ตั้งหนี้ (บันทึกว่าลูกค้าค้างเงินเรา) รอรับชำระ ([[howto-ar-receipt]]) / ขายสด = รับเงินจบในใบ
- **ภาษี:** สร้างรายการภาษีขายให้อัตโนมัติ ดูได้ที่แท็บ "ข้อมูลภาษี (VAT/WHT)" ยกเว้นประเภทภาษี "ไม่กระทบภาษี" ที่ไม่สร้างรายการภาษี ถ้าลูกค้าหักภาษี ณ ที่จ่าย บันทึกได้ที่แท็บเดียวกัน
- **ลงบัญชีอัตโนมัติ:** ขายเชื่อ เดบิต ลูกหนี้การค้า เครดิต ขายสินค้า และภาษีขาย / ขายสด เดบิตเงินสด เงินฝากธนาคาร หรือเช็ครับ ตามที่รับจริง (รับด้วยบัตรเครดิตลงเป็นลูกหนี้) ถ้าใช้เงินมัดจำ ระบบเดบิตบัญชีเงินมัดจำรับด้วย ดูที่แท็บ "การลงบัญชี (GL)" ([[faq-sale-gl-posting]])
- ระบบตรวจก่อนบันทึก: วงเงินเครดิต ([[howto-sale-credit-limit]]) สต็อกติดลบ ([[ts-sale-stock-negative]]) ราคาต่ำกว่าทุน ([[ts-sale-low-cost]]) จำนวนเกินใบอ้างอิง ([[ts-sale-qty-over-ref]])

## แก้ไข ยกเลิก พิมพ์
- แก้ได้ด้วยปุ่ม "แก้ไข" จนกว่าบิลจะถูกวางบิล รับชำระ หรือมีใบลดหนี้/เพิ่มหนี้อ้างอิง ([[howto-sale-edit-delete]])
- ยกเลิก: ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกขายสินค้า/บริการ ([[howto-sale-cancel-docs]])
- ลูกค้าคืนของหรือลดราคา ใช้ใบลดหนี้ ([[howto-sale-credit-note]]) ราคาผิดต้องเก็บเพิ่ม ใช้ใบเพิ่มหนี้ ([[howto-sale-debit-note]])
- พิมพ์: หลังบันทึกกด "พิมพ์แบบฟอร์ม" หรือปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ" ([[rpt-print-export]])
