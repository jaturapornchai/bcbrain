# ขอตรวจนับและบันทึกตรวจนับสินค้า

**ใช้เมื่อ:** นับของจริงในคลังเพื่อเทียบกับยอดในระบบ (สิ้นเดือน สิ้นปี หรือสุ่มนับ)
**เมนู:** สินค้า › ตรวจนับสต็อกและปรับปรุงจากการตรวจนับ › ขอตรวจนับสินค้า / ตรวจนับสินค้า
**ต้องมีก่อน:** คลังและที่เก็บ ([[howto-stock-warehouse-shelf]])

## ขั้นตอน
1. (ถ้ามีขั้นอนุมัติ) **ขอตรวจนับสินค้า:** ผู้ขอบันทึกรายการที่จะนับ เลือก ผู้ขออนุมัติ: แล้วบันทึก
2. **ตรวจนับสินค้า:** กดเพิ่ม เลือกคลัง/พื้นที่เก็บที่นับ อ้างอิงใบขอตรวจนับได้
3. ใส่สินค้าและจำนวนที่นับได้จริง (สินค้า LOT ใส่ LOT ด้วย) แล้วบันทึก
4. นับหลายจุดได้หลายใบ เสร็จแล้วไปปรับยอดที่ [[howto-stock-count-auto-adjust]]
5. สินค้ามี Serial Number ใช้หน้าจอยิง Serial แทน ([[howto-stock-serial-count]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| คลังสินค้า / พื้นที่เก็บ | จุดที่นับ | ค่าเริ่มต้นของทุกแถว |
| จำนวน | จำนวนที่นับได้จริง | ไม่ใช่ส่วนต่าง |
| LOT | LOT ที่นับ | ใช้กับการปรับยอดแบบสินค้า Lot |
| เปิดระบบเตือนตรวจนับซ้ำ / เตือนย้อนหลัง (วัน) | ติ๊กและใส่จำนวนวัน | ดูข้อจำกัดด้านล่าง |

## บันทึกแล้วระบบทำอะไรให้
- **ใบขอตรวจนับและใบตรวจนับไม่เปลี่ยนยอดสต็อก และไม่ลงบัญชี** ยอดจะเปลี่ยนเมื่อสร้างใบปรับปรุงเท่านั้น ([[faq-stock-count-change-stock]])
- ใบตรวจนับเป็นข้อมูลตั้งต้นให้เมนูปรับปรุงอัตโนมัติ ซึ่งจะคำนวณส่วนต่างกับยอด ณ วันที่ของใบตรวจนับใบล่าสุดที่เลือก
- **ข้อจำกัด:** ช่อง เปิดระบบเตือนตรวจนับซ้ำ และ เตือนย้อนหลัง (วัน) ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ระบบไม่เตือนเมื่อนับสินค้าซ้ำ ถ้าต้องการหาสินค้าที่นับซ้ำ ใช้ปุ่ม ตรวจสอบสินค้าซ้ำ ที่เมนูปรับปรุงอัตโนมัติ

## แก้ไข ยกเลิก พิมพ์
- ระบบไม่ล็อกใบตรวจนับที่นำไปปรับปรุงแล้ว ยังแก้หรือลบได้ แต่ใบปรับปรุงที่สร้างไปแล้วไม่เปลี่ยนตาม ถ้าจะนับใหม่ ให้ยกเลิกใบปรับปรุงเดิมก่อน แล้วแก้ใบตรวจนับและประมวลผลใหม่ ([[ts-stock-count-already-adjusted]])
- ยังไม่มีเมนูยกเลิกแยกสำหรับใบขอตรวจนับและใบตรวจนับ ใช้การลบแทน
