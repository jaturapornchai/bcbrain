# บันทึกซื้อสินค้า/ตั้งหนี้ซื้อ (รับของพร้อมใบกำกับภาษี)

**ใช้เมื่อ:** ได้รับสินค้าพร้อมใบกำกับภาษีหรือบิลจากผู้ขายในครั้งเดียว
**เมนู:** ซื้อ › รับสินค้า ซื้อ/ตั้งหนี้ และเพิ่ม/ลดหนี้ › ซื้อสินค้า/ตั้งหนี้ซื้อ
**ต้องมีก่อน:** รหัสเจ้าหนี้ รหัสสินค้า คลังและที่เก็บ ถ้ามีใบสั่งซื้อให้เตรียมเลขที่ไว้

## ขั้นตอน
1. เปิดเมนู กด "เพิ่มใหม่"
2. กรอกวันที่เอกสาร เลขที่เอกสาร เลือกรหัสเจ้าหนี้ และ "ประเภทรายการ" (เงินเชื่อ หรือ เงินสด)
3. ถ้ามีใบสั่งซื้อ กด "ดึงเอกสาร" เลือกใบสั่งซื้อ ระบบดึงรายการที่ยังค้างรับมาให้ ([[howto-buy-reference-doc]])
4. ตรวจหรือแก้จำนวน ราคา คลัง ที่เก็บ ของแต่ละบรรทัด
5. ใส่ "เลขที่ใบกำกับภาษี" และ "ลงวันที่" ตามใบของผู้ขาย ([[howto-buy-purchase-vat]])
6. ถ้าซื้อเงินเชื่อ ใส่ "เครดิต (วัน)" ระบบคำนวณ "ครบกำหนด" ให้
7. ถ้าเคยจ่ายเงินมัดจำไว้ ไปแท็บ "ใช้เงินมัดจำ" เพื่อหักออก ([[howto-buy-use-deposit]])
8. ถ้าซื้อเงินสด ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่ช่องทางจ่ายให้ครบยอด ([[howto-ap-payment-methods]])
9. กด "บันทึก" ระบบขึ้น "บันทึกเอกสาร ... เรียบร้อยแล้ว" และถามว่าจะพิมพ์แบบฟอร์มเลยหรือไม่

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสเจ้าหนี้ | ผู้ขาย | บังคับ |
| ประเภทรายการ | ซื้อสินค้าเงินเชื่อ / ซื้อสินค้าเงินสด / แบบสินค้าบริการ | เงินเชื่อ = ตั้งเป็นหนี้ค้างจ่าย ([[faq-buy-cash-vs-credit]]) |
| ภาษี: (ประเภทภาษี) | แยกนอก / รวมใน / ยกเว้นภาษี / ไม่กระทบภาษี | ต้องตรงกับใบสั่งซื้อที่ดึงมา |
| เลขที่ใบกำกับภาษี / ลงวันที่ | ตามใบกำกับของผู้ขาย | ถ้าเว้นว่าง ระบบใช้เลขที่เอกสารแทน |
| จำนวน / ราคา / คลัง / ที่เก็บ | ของที่รับจริง | ห้ามเกินที่สั่งซื้อ ถ้าไม่ได้เปิดข้อเลือก |

## บันทึกแล้วระบบทำอะไรให้
- เพิ่มจำนวนสินค้าเข้าคลังตามคลังและที่เก็บในแต่ละบรรทัด
- ลงบัญชีอัตโนมัติ: ซื้อสินค้า และ ภาษีซื้อ คู่กับ เจ้าหนี้การค้า (เงินเชื่อ) หรือช่องทางที่จ่าย (เงินสด) ถ้าตัดเงินมัดจำ ระบบลดยอดเงินมัดจำจ่ายด้วย ([[howto-buy-gl-posting]])
- ซื้อเงินเชื่อ จะขึ้นเป็นหนี้ค้างจ่ายรอจ่ายชำระ ([[howto-ap-payment]])
- บันทึกภาษีซื้อเข้าทะเบียนภาษีซื้อ
- ตัดยอดค้างรับของใบสั่งซื้อ รับครบแล้วใบสั่งซื้อจะปิด

## แก้ไข ยกเลิก พิมพ์
- แก้ไขได้ถ้ายังไม่ถูกนำไปใช้ต่อ งวดบัญชียังไม่ปิด ([[ts-buy-cannot-edit]], [[ts-common-period-closed]])
- ยกเลิกด้วยเมนู ยกเลิกซื้อสินค้า/ตั้งหนี้ซื้อ ([[howto-buy-cancel-docs]])
- ลบ: กด "ลบ" ระบบถาม "ยืนยันการลบเอกสาร ... ?"
- ดูเอกสารที่เชื่อมกันด้วยปุ่ม "Document Flow"
