# ดูประวัติว่าใครสร้าง ใครแก้ไข และแก้อะไรไปบ้าง

**ใช้เมื่อ:** อยากรู้ว่าใครสร้างหรือแก้ข้อมูลสินค้า ลูกค้า ผู้จำหน่าย หรือเอกสาร และค่าก่อนแก้กับหลังแก้เป็นอะไร
**เมนู:** เปิดหน้าจอข้อมูลหรือหน้าจอเอกสารที่ต้องการ › ปุ่มบนแถบเครื่องมือของรายการด้านซ้าย
**ต้องมีก่อน:** ข้อมูลนั้นถูกบันทึกผ่านหน้าจอในระบบนี้แล้ว

## ขั้นตอน
1. เปิดหน้าจอข้อมูล เช่น ข้อมูลสินค้า กำหนดลูกหนี้ หรือหน้าจอเอกสาร
2. ดูแบบเร็ว: กดปุ่ม "ผู้สร้าง/แก้ไข" ตารางจะเพิ่มคอลัมน์ผู้สร้างและผู้แก้ไขล่าสุดของแต่ละรายการ (กดซ้ำเพื่อซ่อน)
3. ดูละเอียด: เลือกรายการที่ต้องการ แล้วกดปุ่ม "ประวัติแก้ไข" หน้าต่างประวัติการสร้างและแก้ไขข้อมูลจะเปิดขึ้น
4. เลือกขอบเขต "เฉพาะรหัสที่เลือก" หรือ "ประวัติทั้งหมดของหน้าจอนี้ (รวมเพิ่ม/ลบ/แก้ไข)"
5. คลิกแต่ละรายการเพื่อดู "ตารางเปรียบเทียบฟิลด์" ว่าช่องไหนเปลี่ยนจากอะไรเป็นอะไร
6. กด "รีเฟรชประวัติ" เพื่อดึงข้อมูลล่าสุด

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ชนิดของรายการ | เพิ่มข้อมูล / แก้ไขข้อมูล / ลบข้อมูล | ระบบบอกให้ ไม่ต้องกรอก |
| ชื่อช่องข้อมูล (Field) | ชื่อช่องที่ถูกเปลี่ยน | |
| ค่าเดิม (Before) | ค่าก่อนแก้ | |
| ค่าใหม่ (After) | ค่าหลังแก้ | |

## บันทึกแล้วระบบทำอะไรให้
- ทุกครั้งที่บันทึกหรือลบข้อมูลหลักและเอกสารผ่านหน้าจอ ระบบเก็บประวัติให้เองว่าใคร ทำเมื่อไร และเปลี่ยนช่องอะไร
- หน้าต่างนี้ใช้ดูอย่างเดียว แก้หรือลบประวัติไม่ได้
- มีปุ่ม "ตรวจสอบย้อนหลังด้วย AI" ช่วยสรุปประวัติให้อ่านง่ายขึ้น

## แก้ไข ยกเลิก พิมพ์
- ถ้าพบว่าข้อมูลถูกแก้ผิด ให้กลับไปแก้ที่หน้าจอข้อมูลนั้นให้ถูกต้อง แล้วบันทึกใหม่ ประวัติจะเก็บการแก้ครั้งนี้เพิ่มอีกรายการ ดู [[howto-doc-edit-cancel-delete]]

## ปัญหาที่พบบ่อย
- ข้อมูลเก่าที่มีอยู่ก่อนเริ่มใช้ระบบนี้ หรือถูกนำเข้ามาด้วยวิธีอื่น จะเห็นเป็น "ข้อมูลตั้งต้นในฐานข้อมูล (Baseline Record)" โดยไม่มีประวัติย้อนหลังก่อนหน้านั้น
- ประวัติการเข้าสู่ระบบ การเปิดเมนู และการประมวลผล อยู่คนละที่กับหน้าต่างนี้ เป็นเมนูตรวจสอบของ Admin ดู [[howto-setup-audit-log]]
