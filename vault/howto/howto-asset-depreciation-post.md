# โอนค่าเสื่อมราคาเข้าระบบบัญชี (ลงบัญชีค่าเสื่อมประจำงวด)

**ใช้เมื่อ:** สิ้นเดือนหรือสิ้นปี ต้องการให้ระบบคำนวณค่าเสื่อมของสินทรัพย์ทุกตัวในช่วงวันที่ แล้วลงบัญชีให้ในเอกสารเดียว
**เมนู:** ค่าเสื่อม › โอนข้อมูลเข้าระบบบัญชี
**ต้องมีก่อน:** ทะเบียนสินทรัพย์ครบ ([[howto-asset-register]]) และสมุดรายวัน ([[howto-gl-overview]])

## ขั้นตอน
1. เปิดเมนู ใส่ "จากวันที่" และ "ถึงวันที่" ของงวดที่จะลงค่าเสื่อม
2. เลือก "แสดงค่าเสื่อมราคา" (รายวัน / รายเดือน / รายปี) และ "วิธีคำนวณ" (สรรพากร (365 วัน) / บัญชี (30 วัน/360 วัน) / ตามจำนวนวันจริง)
3. ถ้าต้องการเฉพาะบางกลุ่ม ใส่ "จากรหัสสินทรัพย์" "ถึงรหัสสินทรัพย์" "จากประเภทสินทรัพย์" "จากแผนก" ฯลฯ
4. ใส่ "เลขที่เอกสาร" "วันที่เอกสาร (ว่าง = ถึงวันที่)" "สมุดรายวัน" และ "หมายเหตุ"
5. กด "ประมวลผล" ตรวจยอดค่าเสื่อมแต่ละรายการและรายการบัญชี
6. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| จากวันที่ / ถึงวันที่ | ช่วงงวด | รายวันได้ไม่เกิน 1 ปี |
| วิธีคำนวณ | วิธีนับวัน | ใช้วิธีเดียวกันทุกงวด |
| เลขที่เอกสาร | เลขเอกสารโอนค่าเสื่อม | ไม่เกิน 25 ตัวอักษร ห้ามซ้ำเอกสารอื่น |
| สมุดรายวัน | สมุดที่ลงบัญชี | |

## บันทึกแล้วระบบทำอะไรให้
- สร้างเอกสารโอนค่าเสื่อม 1 ใบ มีสินทรัพย์ทุกตัวในช่วง
- ลงบัญชี เดบิต ผังบัญชีค่าเสื่อมราคา คู่กับ เครดิต ผังบัญชีค่าเสื่อมราคาสะสม ของแต่ละสินทรัพย์ รวมตามผังบัญชี
- สินทรัพย์ที่ขายแล้ว คิดค่าเสื่อมถึงวันก่อนวันขาย
- **ข้อควรระวัง:** หน้าจอนี้ไม่ตรวจงวดบัญชีที่ปิดแล้ว ระบบยอมบันทึกในงวดที่ปิดไปแล้ว ให้ตรวจวันที่ก่อนกดบันทึก

## แก้ไข ยกเลิก พิมพ์
- แก้: ใส่เลขที่เอกสารเดิมกับช่วงวันที่เดิม กด "ประมวลผล" แล้ว "บันทึก" ระบบคำนวณใหม่และแทนที่เอกสารเดิมทั้งใบ
- ลบ: ใส่เลขที่เอกสาร แล้วกด "ลบ" ระบบลบทั้งเอกสารและรายการบัญชี ลบไม่ได้ถ้างวดของเอกสารปิดแล้ว หรือมีสินทรัพย์ในเอกสารถูกขายในวันที่เอกสารหรือหลังจากนั้น (ต้องลบเอกสารขายก่อน)
- ดูรายการบัญชีที่ลงไปแล้วได้ที่ระบบบัญชีแยกประเภท
