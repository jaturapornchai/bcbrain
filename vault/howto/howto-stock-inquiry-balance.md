# ดูยอดคงเหลือสินค้า (รวม ตามคลัง ตามที่เก็บ ตาม LOT) สินค้าถึงจุดสั่งซื้อ และสินค้าค้างสต็อก

**ใช้เมื่อ:** อยากรู้ว่าของเหลือเท่าไร อยู่คลังไหน ตัวไหนใกล้หมดต้องสั่งเพิ่ม ตัวไหนค้างสต็อกไม่ขยับ
**เมนู:** สินค้า › สอบถามและวิเคราะห์ข้อมูลสินค้า (บนหน้าจอ) › เลือกหัวข้อ
**ต้องมีก่อน:** บันทึกเอกสารสินค้าแล้ว ([[howto-stock-opening-balance]])

## เลือกหัวข้อให้ตรงคำถาม
| หัวข้อ | ตอบคำถาม |
|---|---|
| ยอดคงเหลือสินค้า | เหลือเท่าไร ณ วันสิ้นสุด รวมทุกคลัง พร้อมยอดรับเข้า/ออกในช่วงวันที่ |
| ยอดคงเหลือสินค้าตามคลัง | แยกเป็นรายคลัง |
| ยอดคงเหลือสินค้าตามที่เก็บ | แยกคลังและพื้นที่เก็บ |
| ยอดคงเหลือสินค้าตาม LOT | ยอดเพิ่ม ยอดลด ยอดเหลือ ของแต่ละ LOT แสดงเฉพาะ LOT ที่ยังมีของ |
| รายงานยอดคงเหลือสินค้า (แสดงทุกสินค้า) แสดงมูลค่าปัจจุบัน | ทุกสินค้าพร้อมมูลค่าตอนนี้ |
| สินค้าถึงจุดสั่งซื้อ | สินค้าที่ยอดคงเหลือปัจจุบันต่ำกว่า จุดสั่งซื้อ พร้อม ยอดค้างรับ |
| สินค้าที่ไม่มีการเคลื่อนไหว | ไม่มีเอกสารเข้าออกเลยในช่วงวันที่ พร้อมวันที่เคลื่อนไหวล่าสุด |
| สินค้าที่ไม่มีการขาย | มีของเหลือแต่ไม่ได้ขายในช่วงวันที่ พร้อม วันที่ซื้อล่าสุด วันที่ขายล่าสุด และ จำนวนวัน |

## ขั้นตอน
1. เปิดหัวข้อที่ต้องการ
2. ใส่ ตั้งแต่วันที่ ถึงวันที่ และช่วงรหัสสินค้า (เว้นว่าง = ทุกสินค้า) เลือก เรียงตาม ได้
3. กด ประมวลผลรายงาน
4. ต้องการพิมพ์หรือส่งออก กด พิมพ์รายงาน หรือ ส่งออก CSV ([[rpt-print-export]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ถึงวันที่ | วันที่ต้องการดูยอด | ยอดคงเหลือคิด ณ วันนี้ |
| ช่วงรหัสสินค้า | จาก ถึง | เว้นว่างได้ |
| ค้นหา | คำบางส่วนของรหัสหรือชื่อ | กรองเพิ่ม |

## ข้อควรรู้
- จุดสั่งซื้อ ตั้งที่หน้าจอข้อมูลสินค้าเพิ่มเติม (บางรุ่นอาจไม่เห็นเมนูนี้ สอบถามฝ่ายขาย) ([[howto-stock-item-master]]) สินค้าที่ไม่ได้ตั้งจุดสั่งซื้อจะไม่ขึ้นในหัวข้อนี้
- สินค้าถึงจุดสั่งซื้อ และ สินค้าที่ไม่มีการขาย ใช้ยอดคงเหลือปัจจุบัน ไม่ใช่ยอด ณ วันที่ที่เลือก
- จำนวนแสดงเป็นหน่วยนับหลัก ([[howto-stock-units]])
- ถ้าบริษัทเลือกไม่แสดงต้นทุน ผู้ใช้ที่ไม่มีสิทธิ์ดูต้นทุนจะไม่เห็นช่องมูลค่า ([[howto-stock-inquiry-movement]])
- ยอดตาม LOT ใช้กับสินค้าที่เปิดใช้ LOT ([[howto-stock-lot]]) รุ่นปัจจุบันยอดตาม LOT นับเฉพาะ LOT ที่บันทึกจากยอดยกมาและหน้าจอจัดการ LOT ยังไม่รวม LOT จากบิลซื้อ บิลขาย หรือใบเบิก จึงอาจไม่ตรงกับยอดคงเหลือรวม ถ้าลูกค้าพบ ให้ส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- หน้าจอสอบถามอ่านอย่างเดียว ไม่แก้ข้อมูล ถ้ายอดผิดต้องแก้ที่เอกสาร
