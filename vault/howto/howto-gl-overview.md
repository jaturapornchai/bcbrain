# ภาพรวมระบบบัญชีแยกประเภท (GL)

ระบบบัญชีแยกประเภทเป็นศูนย์กลางรวบรวมตัวเลขทางการเงินจากทุกระบบย่อย (ซื้อ ขาย สต๊อก ลูกหนี้ เจ้าหนี้ การเงิน เช็ค และสินทรัพย์) เพื่อจัดทำสมุดรายวัน บัญชีแยกประเภท งบทดลอง และงบการเงินประจำงวดและประจำปีของกิจการ


## วิดีโอสอนสมุดรายวัน ออกงบการเงิน และภาพหน้าจอสมุดรายวันจริง

[🎬 EP.8 สอน BC Ai Account: รายงานภาษีรายเดือน (ภ.พ.30, ภ.ง.ด.3, 53) สมุดรายวัน และออกงบการเงินครบวงจร](https://www.youtube.com/watch?v=awlLvfPdwr4&list=PLO9P7tPZLXB0)

![หน้าจอบันทึกสมุดรายวันและการลงบัญชีคู่ใน BC Ai Account](https://bcaccount.com/assets/photos/screen-gl-journal-800.webp)

## ผังงานบัญชีตั้งแต่ตั้งค่าจนปิดงบ

```
[1. ตั้งค่าเริ่มต้น] ผังบัญชี 5 หมวด + สมุดรายวัน + งวดบัญชี
        ↓
[2. เกิดรายการประจำวัน]
   ├─ เอกสารซื้อ/ขาย/รับ-จ่ายเงิน/คลัง/สินทรัพย์ → ลงบัญชีอัตโนมัติตามรูปแบบที่ตั้งไว้
   └─ รายการปรับปรุง/ค้างรับ-ค้างจ่าย → บันทึกใน ข้อมูลรายวัน หรือใช้ต้นแบบรายวันประจำ
        ↓
[3. ตรวจสอบและผ่านรายการ]
   ├─ ตรวจสอบความถูกต้อง (เดบิต=เครดิต, รหัสบัญชี, เอกสารที่ยังไม่ลงบัญชี)
   ├─ ประมวลผลจากข้อมูลรายวัน (สร้าง/คำนวณบัญชีอัตโนมัติใหม่สำหรับเอกสารที่ไม่ได้ลงเอง)
   └─ ผ่านรายการ เพื่อยืนยันความถูกต้องเข้าสู่บัญชีแยกประเภท
        ↓
[4. ปรับปรุงและปิดงวด]
   ├─ ปรับปรุงอัตราแลกเปลี่ยนสิ้นงวด (ถ้ามีลูกหนี้/เจ้าหนี้สกุลต่างประเทศ)
   ├─ สรุปบัญชีสินค้าและต้นทุนขาย / ประมวลผลสิ้นงวด / ประมวลผลสิ้นปี
   └─ ล็อกสถานะงวดบัญชีเป็น "ปิดงวด" เพื่อป้องกันแก้ไขย้อนหลัง
        ↓
[5. ออกงบและนำส่ง]
   └─ สอบถามงบทดลอง กระดาษทำการ งบดุล งบกำไรขาดทุน และจัดเตรียมไฟล์ DBD e-Filing (สบช.3)
```

## คู่มือแยกตามหัวข้อในระบบบัญชีแยกประเภท

| หัวข้อ | เนื้อหาสำคัญ | คู่มือ |
|---|---|---|
| ผังบัญชีและโครงสร้างบัญชี | ผังบัญชี 5 หมวด บัญชีคุม-บัญชีย่อย ชุดผังมาตรฐาน 3 กลุ่มธุรกิจ ปรับปรุงแบบเร็ว นำเข้า/ส่งออกไฟล์ CSV เปลี่ยนรหัสผังบัญชี และจับคู่ DBD e-Filing | [[howto-gl-chart-of-accounts]] |
| บันทึกข้อมูลรายวันและสมุดรายวัน | บันทึกรายวัน 3 รูปแบบ ตั้งค่าสมุดรายวัน 5 ประเภท หลักเดบิต=เครดิต มิติแผนก/โครงการ/จัดสรร รูปแบบลงบัญชีอัตโนมัติ และแนบไฟล์ | [[howto-gl-journal-entry]] |
| ต้นแบบรายวันประจำและกลับรายการ | แม่แบบปรับปรุงสิ้นเดือนมาตรฐาน 5 ชุด บันทึกต้นแบบของกิจการเอง และกดกลับรายการเดบิต-เครดิตต้นงวดถัดไปอัตโนมัติ | [[howto-gl-recurring-entries]] |
| งวดบัญชี ตรวจสอบ ผ่านรายการ และปิดงวด | กำหนดและเปิด-ปิดงวดบัญชี ตรวจความถูกต้องข้อมูลบัญชี ผ่านรายการ/ยกเลิกผ่านรายการ ประมวลผลลงบัญชีใหม่ และปิดงวด/ปิดปี | [[howto-gl-period-open-close]] |
| ปรับปรุงอัตราแลกเปลี่ยนสิ้นงวด | ประเมินมูลค่าลูกหนี้-เจ้าหนี้เงินตราต่างประเทศค้างชำระ ณ สิ้นงวด พร้อมสร้างใบกลับรายการต้นงวดถัดไป | [[howto-gl-fx-revaluation]] |
| สอบถามงบและเตรียมส่ง DBD e-Filing | ดูสรุปยอดบัญชี แยกประเภท งบทดลอง งบทดลองมิติ กระดาษทำการ งบดุล และสร้างไฟล์ สบช.3 | [[howto-gl-trial-balance-inquiry]] |

## เชื่อมโยงกับระบบงานอื่นที่ส่งตัวเลขเข้า GL

- **งานคลังสินค้าและต้นทุนขาย**: ปรับปรุงต้นทุนถัวเฉลี่ยเคลื่อนที่และต้นทุนแฝงก่อนปิดงวด ดูที่ [[howto-stock-overview]]
- **งานเงินสด ธนาคาร และเช็ค**: รายการฝาก-ถอน โอนเงิน กระทบยอดธนาคาร และสถานะเช็คผ่านบัญชี ดูที่ [[howto-cash-bank-overview]]
- **งานภาษี**: แท็บภาษีซื้อ/ภาษีขาย และภาษีหัก ณ ที่จ่ายที่ติดไปกับใบสำคัญรายวันและการยื่นแบบ ดูที่ [[howto-tax-overview]]
- **งานสินทรัพย์ถาวรและเช่าซื้อ**: บันทึกค่าเสื่อมราคารายเดือน ขาย/ตัดจำหน่าย และค่างวดลีสซิ่ง ดูที่ [[howto-asset-overview]]
- **ฟีเจอร์เฉพาะทาง SME ไทยในเมนูบัญชี**:
  - [[howto-sme-prepaid-deferred]] (ตัดจ่ายค่าใช้จ่ายล่วงหน้าและรายได้รอตัดบัญชีเข้า GL รายเดือน)
  - [[howto-sme-director-loan]] (คุมเงินกู้ยืมกรรมการและคำนวณดอกเบี้ยรับขั้นต่ำ)
  - [[howto-sme-expense-claim]] (เบิกค่าใช้จ่ายพนักงานพร้อมบัญชีพักและล้างยอดจ่ายคืน)

## สิ่งที่ควรเช็กก่อนปิดงวดทุกเดือน

1. ตรวจดูเอกสารที่ยังไม่ลงบัญชี และรายการที่ยอดเดบิตไม่เท่ากับเครดิตในเมนู **บัญชี › ตรวจสอบ ผ่านรายการ และประมวลผลบัญชี › ตรวจสอบความถูกต้อง** (รหัสเมนู **9010**)
2. หากแก้ไขผังบัญชีหรือรูปแบบการลงบัญชีหลังบันทึกเอกสารแล้ว ให้ใช้ **ประมวลผลจากข้อมูลรายวัน** เพื่อคำนวณใบสำคัญอัตโนมัติใหม่ (ใบสำคัญที่แก้ด้วยมือโดยตรงจะไม่ถูกเขียนทับ)
3. ตรวจสอบสถานะงวดบัญชีที่ **เริ่มต้น › ตั้งค่าระบบบัญชีและภาษี › กำหนดงวดบัญชี** (รหัสเมนู **1083**) หากขึ้นเตือนว่างวดปิดแล้ว ให้ดูแนวทางแก้ที่ [[ts-common-period-closed]]
4. ตรวจรายงานภาษีและงบการเงินภาพรวมต่อได้ที่ [[rpt-overview]]
