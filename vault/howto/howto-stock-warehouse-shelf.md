# ตั้งคลังสินค้า พื้นที่เก็บ และกลุ่มที่เก็บ

**ใช้เมื่อ:** เริ่มใช้ระบบ เปิดสาขาหรือโกดังใหม่ หรืออยากแยกสต็อกตามชั้นวาง
**เมนู:** เริ่มต้น › ตั้งค่าระบบสินค้าคงคลัง › กำหนดคลังสินค้า / กำหนดพื้นที่เก็บสินค้า และ สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › คลังที่เก็บสินค้า / กำหนดกลุ่มที่เก็บ
**ต้องมีก่อน:** สาขา (ถ้าแยกสาขา)

## ขั้นตอน
1. **กำหนดคลังสินค้า:** เพิ่มรหัสคลัง ชื่อ ที่อยู่ สาขา ผู้จัดการคลัง และปักหมุด ละติจูด/ลองจิจูด บนแผนที่ตำแหน่งคลังสินค้าได้
2. **กำหนดพื้นที่เก็บสินค้า:** เลือก คลังสินค้า ก่อน แล้วเพิ่มที่เก็บ (ชั้น/โซน) ของคลังนั้น ใส่ความกว้าง ความสูง ความลึกได้
3. **ผูกสินค้ากับคลัง:** ในข้อมูลสินค้า ตารางคลังและที่เก็บ หรือเมนู คลังที่เก็บสินค้า เลือกสินค้าแล้วเพิ่มคลังและพื้นที่เก็บที่สินค้าอยู่
4. **กำหนดกลุ่มที่เก็บ (ถ้าต้องการ):** เลือกคลัง ตั้งกลุ่มที่เก็บ แล้วเพิ่มที่เก็บในแท็บ ที่เก็บในกลุ่ม

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส (คลัง) | รหัสคลังที่ไม่ซ้ำ | ต้องกรอก |
| ชื่อ / ชื่อ (ภาษาอังกฤษ) | ชื่อคลัง | |
| สาขา | สาขาที่คลังสังกัด | |
| กลุ่มผู้ใช้งาน | กลุ่มผู้ใช้ที่เห็นคลังนี้ | ใช้คู่กับตัวเลือกคลังตามสิทธิ์ |
| คลังสินค้า (ในหน้าพื้นที่เก็บ) | คลังที่ที่เก็บนี้อยู่ | ต้องเลือกก่อนเพิ่มที่เก็บ |

## บันทึกแล้วระบบทำอะไรให้
- ทุกแถวสินค้าในเอกสารรับ-จ่ายต้องมีคลังและที่เก็บ (ถ้าไม่กรอกในแถว ระบบใช้คลัง/ที่เก็บบนหัวเอกสาร)
- ยอดคงเหลือแยกดูตามคลังและตามที่เก็บได้ ([[howto-stock-inquiry-balance]])
- ตัวเลือก "ใช้คลังที่เก็บตามสิทธิ์พนักงาน" ทำให้หน้าค้นหาคลัง/ที่เก็บแสดงเฉพาะที่กลุ่มผู้ใช้มีสิทธิ์ ถ้าต้องการคุมสิทธิ์การบันทึกตามคลัง ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า
- ตัวเลือก "เปิดใช้ทุกคลังที่เก็บสินค้า" ทำให้ไม่ต้องผูกคลังให้สินค้าทีละตัว ([[howto-stock-options]])

## แก้ไข ยกเลิก พิมพ์
- ลบคลังหรือที่เก็บที่ถูกใช้แล้วไม่ได้ ระบบแจ้ง "มีการใช้งานรหัสดังกล่าวไปแล้ว กรุณาตรวจสอบ" หรือ "มีการใช้งานในสินค้าและพื้นที่เก็บแล้ว" หรือ "มีการใช้งานในเอกสารสินค้าแล้ว"
- เมนู เพิ่มคลังและพื้นที่เก็บอัตโนมัติ รุ่นปัจจุบันแสดงแค่รายการคลังคู่กับที่เก็บที่มีอยู่ให้ตรวจดู ยังไม่ได้เพิ่มคลังให้สินค้าเอง ถ้าต้องการผูกคลังให้สินค้า ให้ทำตามขั้นตอนข้อ 3 หรือเปิดตัวเลือก เปิดใช้ทุกคลังที่เก็บสินค้า

## ปัญหาที่พบบ่อย
- "ข้อมูลไม่สมบูรณ์ : รหัสคลังสินค้า" → กรอกรหัสคลัง
- "ข้อมูลไม่สมบูรณ์ : ชื่อคลังสินค้า (ไทย)" → กรอกช่อง ชื่อ
- "รหัสคลังสินค้า [...] มีอยู่ในระบบแล้ว ไม่สามารถเพิ่มซ้ำได้" → ใช้รหัสอื่น
- "ป้อนข้อมูลคลังสินค้าไม่ครบ (...)" ตอนบันทึกบิล → ([[ts-stock-wh-shelf-incomplete]])
