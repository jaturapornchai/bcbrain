# บันทึกฝากเงิน และถอนเงิน ธนาคาร

**ใช้เมื่อ:** นำเงินสดในมือไปฝากเข้าบัญชีธนาคาร หรือถอนเงินจากบัญชีธนาคารมาเป็นเงินสด
**เมนู:** เงินสด/ธนาคาร › สมุดเงินฝากธนาคาร (ฝาก / ถอน / โอน) › บันทึกฝากเงิน / บันทึกถอนเงิน
**ต้องมีก่อน:** สมุดเงินฝาก ([[howto-bank-passbook]])

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. ในตาราง ช่อง "สมุดบัญชีธนาคาร" เลือกสมุดเงินฝาก (หน้าค้นหา "ค้นหาสมุดบัญชีธนาคาร") ใส่รายละเอียดและจำนวนเงิน
3. ฝากหลายบัญชีพร้อมกันได้ ใส่หลายบรรทัด บรรทัดละสมุด
4. ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่เงินสดให้เท่ายอดเอกสาร
5. ตรวจแท็บ "การลงบัญชี (GL)" แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| สมุดบัญชีธนาคาร | บัญชีที่ฝาก/ถอน | ต่อบรรทัด |
| จำนวนเงิน | ยอดฝาก/ถอน | มากกว่า 0 |
| แท็บการรับ/จ่ายชำระเงิน | เงินสด | ต้องครบยอด |

## บันทึกแล้วระบบทำอะไรให้
- ฝากเงิน: เดบิต เงินฝากธนาคาร (ตามบัญชีของสมุดแต่ละบรรทัด) คู่กับ เครดิต เงินสด
- ถอนเงิน: เดบิต เงินสด คู่กับ เครดิต เงินฝากธนาคาร
- ดูย้อนหลังได้ที่ "รายงานการฝากเงิน" "รายงานการถอนเงิน" และ "รายงาน Bank Statement" ของสมุดเงินฝากนั้น ([[rpt-cb-bank-credit-card]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้ถ้างวดยังไม่ปิด
- ยกเลิกด้วยเมนู บันทึกยกเลิกฝากเงิน / บันทึกยกเลิกถอนเงิน ([[howto-bank-cancel-docs]])

## ปัญหาที่พบบ่อย
- จะฝากเช็คที่รับจากลูกค้า → ไม่ใช้เมนูนี้ ใช้ บันทึกนำฝาก (เช็ครับ) ([[howto-cheque-received-deposit-pass]])
- ย้ายเงินระหว่างบัญชีธนาคารของกิจการเอง → ใช้ บันทึกโอนเงินระหว่างธนาคาร ([[howto-bank-transfer]])
- "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" → [[ts-cash-pay-incomplete]]
- "กรุณาระบุจำนวนเงินมากกว่า 0" → ใส่จำนวนเงินในตาราง
