# ออกแบบรายงาน

**ใช้เมื่อ:** ต้องการสร้างรายงานรูปแบบของกิจการเอง หรือปรับรูปแบบรายงานที่มี เช่น เลือกว่าจะโชว์คอลัมน์ไหน จัดหน้า และดูตัวอย่างก่อนพิมพ์
**เมนู:** เริ่มต้น › ออกแบบรายงาน (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin · รู้ว่ารายงานต้องการข้อมูลอะไร · เป็นงานปรับแต่งขั้นสูง · เริ่มต้นดู [[start-first-day]]

เอกสารนี้อธิบายภาพรวมการใช้งาน หน้าจอมีเครื่องมือปรับแต่งเชิงลึกจำนวนมากที่ไม่ได้ลงรายละเอียดทั้งหมด

## ขั้นตอน
1. เปิดเมนู "ออกแบบรายงาน" หน้าจอเริ่มในโหมดดูอย่างเดียว
2. ถ้าจะสร้างใหม่ กด "เพิ่มใหม่" ถ้าจะแก้ของเดิม เลือกรายงานจากรายการแล้วกด "แก้ไข" (สร้างใหม่ ระบบตั้งรหัสรายงานชั่วคราวให้ ขึ้นต้นด้วย REP)
3. เลือก "ประเภท" ของรายงาน (หมวดรายงาน) จากรายการ
4. เลือกคอลัมน์ที่จะแสดงในส่วนดึงข้อมูล ระบบแจ้ง "เพิ่มฟิลด์ ... เข้า ... แล้ว" ทุกครั้งที่เพิ่ม
5. ดูผลที่กรอบ "Preview (ตัวอย่างกระดาษรายงานสด)" กดปุ่มรีเฟรชตัวอย่างรายงานถ้าต้องการโหลดใหม่
6. กด "บันทึก" เพื่อเก็บรายงานไว้ในฐานข้อมูลของกิจการ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภท | หมวดของรายงาน | เลือกจากรายการ มี 9 หมวด |
| คอลัมน์ที่แสดง | เลือกจากรายการฟิลด์ข้อมูลที่ระบบให้ | ปุ่มล้างฟิลด์ทั้งหมดอยู่ในแต่ละส่วนดึงข้อมูล |
| เงื่อนไขกรอง (ช่วงวันที่ ฯลฯ) | ค่าที่ใช้ทดลองดูตัวอย่าง | เป็นค่าสำหรับตัวอย่างบนหน้าจอ |
| ขยายย่อตัวอย่าง | เปอร์เซ็นต์ซูม | ใช้ดูรายละเอียด |

## บันทึกแล้วระบบทำอะไรให้
- เก็บรายงานที่ออกแบบไว้ในฐานข้อมูล เปิดกลับมาแก้ได้ภายหลัง
- รายงานที่บันทึกไว้เปิดกลับมาดูและแก้ได้ในหน้า "ออกแบบรายงาน" เท่านั้น ยังไม่ขึ้นเป็นเมนูรายงานให้เปิดใช้ที่หน้าอื่น ถ้าลูกค้าต้องการรายงานเฉพาะกิจการแบบใช้งานจริง ให้ส่งต่อเจ้าหน้าที่
- ปุ่มส่งออกโครงสร้างรายงานเก็บเป็นไฟล์สำรอง และปุ่มนำเข้าไฟล์กลับมาแก้ต่อ อยู่บนแถบเครื่องมือ
- "พิมพ์ PDF" สร้างไฟล์ PDF ของรายงานตามที่ออกแบบ ดู [[rpt-print-export]]

## แก้ไข ยกเลิก พิมพ์
- ลบรายงานที่ออกแบบไว้: ระบบแจ้ง "ลบรายงานออกจากฐานข้อมูลเรียบร้อยแล้ว"
- "รีเซ็ต" คืนรูปแบบเป็นค่าเริ่มต้น ระบบแจ้ง "รีเซ็ตรายงานกลับเป็นค่าเริ่มต้นแล้ว"
- ผู้ใช้ที่ไม่มีสิทธิ์แก้ไข กดแก้ไขหรือบันทึกไม่ได้
- ภาพรวมรายงานและการพิมพ์ ดู [[rpt-overview]]

## ปัญหาที่พบบ่อย
- ตัวอย่างไม่ขึ้นข้อมูล: ช่วงวันที่ในเงื่อนไขทดลองอาจไม่มีรายการ ลองเปลี่ยนช่วงแล้วรีเฟรช
- ปุ่มแก้ไข/เพิ่มใหม่/บันทึกกดไม่ได้: ไม่มีสิทธิ์ ดู [[ts-common-no-permission]]
- ทำรายงานที่ต้องคำนวณซับซ้อน สอบถามฝ่ายขายหรือผู้ดูแลระบบ
