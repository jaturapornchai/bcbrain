# ทะเบียนเช็ครับ และบันทึกเช็ครับยกมา

**ใช้เมื่อ:** ต้องการดูเช็คที่รับจากลูกค้าทั้งหมด และดูว่าเช็คแต่ละใบผ่านเอกสารอะไรมาแล้วบ้าง (นำฝาก ผ่าน คืน) หรือต้องบันทึกเช็คที่ค้างอยู่ตอนเริ่มใช้โปรแกรม
**เมนู:** เงินสด/ธนาคาร › ทะเบียนเช็ครับและจัดการเช็ครับ › ทะเบียนเช็ครับ / เช็ครับยกมา
**ต้องมีก่อน:** รหัสลูกหนี้ ธนาคาร และสาขาธนาคาร ([[howto-bank-setup]])

## เช็คเข้าทะเบียนได้ 2 ทาง
1. **อัตโนมัติ** จากเอกสารรับเงิน เช่น ขายสด รับชำระหนี้ รายได้อื่นๆ เมื่อใส่เช็คในส่วน "รายการเช็ครับ (หลายรายการ)" ของแท็บ "การรับ/จ่ายชำระเงิน" (เลขที่เช็ค รหัสธนาคาร สาขา วันถึงกำหนด จำนวนเงิน)
2. **เช็ครับยกมา** สำหรับเช็คที่รับไว้ก่อนเริ่มใช้โปรแกรม

## ขั้นตอน (เช็ครับยกมา)
1. เปิดเมนู เช็ครับยกมา กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. เลือกลูกหนี้เจ้าของเช็ค
3. ในตาราง ใส่ "เลขที่เช็ค" "ธนาคาร" "สาขา" "วันครบกำหนด" และ "จำนวนเงิน" ใบละบรรทัด (บรรทัดที่ไม่มีเลขที่เช็ค ระบบไม่นำเข้าทะเบียน)
4. กด "บันทึก" เช็คจะเข้าทะเบียนในสถานะ เช็คในมือ

## ขั้นตอน (ดูทะเบียน)
1. เปิดเมนู ทะเบียนเช็ครับ ค้นหาด้วยเลขที่เช็คหรือเลขเอกสารอ้างอิง
2. เปิดเช็คแต่ละใบ ช่อง "เอกสารอ้างอิง" คือเอกสารที่รับเช็คนั้นมา
3. ตาราง "ประวัติความเคลื่อนไหวเช็ค / บัตรเครดิต" (วันที่เอกสาร เลขที่เอกสาร ประเภท สมุดบัญชี จำนวนเงิน หมายเหตุ) แสดงเอกสารเช็คที่ทำต่อจากนั้น เช่น นำฝาก ผ่าน คืน ถ้ายังไม่มีจะขึ้น "ยังไม่มีประวัติการผ่านรายการของเช็ค/บัตรเครดิตใบนี้"
4. หน้าทะเบียนไม่มีช่องแสดงสถานะ ถ้าต้องการดูสถานะให้ใช้รายงาน ([[faq-cheque-status]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้ | เจ้าของเช็ค | เช็ครับยกมา |
| เลขที่เช็ค | เลขบนเช็ค | ใช้ค้นหาตอนนำฝาก |
| ธนาคาร / สาขา | ธนาคารของเช็ค | |
| วันครบกำหนด | วันที่บนเช็ค | |

## บันทึกแล้วระบบทำอะไรให้
- เช็ครับยกมา **ไม่ลงบัญชี** (ตามรูปแบบมาตรฐาน) ยอดยกมาของบัญชีเช็ครับล่วงหน้า ต้องตั้งในระบบบัญชีแยกประเภทเอง ([[howto-gl-overview]])
- เช็คจากเอกสารรับเงิน ลงบัญชี เช็ครับล่วงหน้า ไว้ในเอกสารต้นทางแล้ว
- เช็คในมือ (หรือเช็คที่ถูกคืนมา) เลือกได้ในเมนู บันทึกนำฝาก (เช็ครับ) บันทึกการเปลี่ยนเช็ค (เช็ครับ) บันทึกคืนเช็ค/ตั้งหนี้ใหม่ และบันทึกเช็คขาดสิทธิ์ (เช็ครับ) ส่วน บันทึกเช็คผ่าน (เช็ครับ) เลือกได้เฉพาะเช็คที่นำฝากแล้ว และ บันทึกเช็คคืน (เช็ครับ) เลือกได้เฉพาะเช็คที่นำฝากหรือผ่านแล้ว ความหมายสถานะดู [[faq-cheque-status]]
- ข้อควรรู้: ถ้ายกเลิกเอกสารรับเงินต้นทาง ขณะเช็คยังอยู่ในมือ เช็คใบนั้นยังค้างในทะเบียนเป็น เช็คในมือ และยังเลือกไปนำฝากได้ ให้ระวังอย่าเลือกเช็คใบนั้น ถ้าเผลอใช้ไปแล้ว ส่งต่อเจ้าหน้าที่
