# ตั้งค่าสมุดบัญชี ประเภทบัญชี กลุ่มบัญชี กลุ่มกระแสเงินสด

**ใช้เมื่อ:** ตั้งระบบบัญชีครั้งแรก หรือต้องการเพิ่มสมุดรายวัน (สมุดรายวัน = หมวดของรายการบัญชี เช่น สมุดรายวันขาย ซื้อ รับเงิน จ่ายเงิน ทั่วไป)
**เมนู:** เริ่มต้น › ตั้งค่าระบบบัญชีและภาษี › กำหนดสมุดบัญชี / กำหนดประเภทบัญชี / กำหนดกลุ่มบัญชี / กำหนดกลุ่มบัญชีกระแสเงินสด (ทั้ง 4 เมนูมีให้กดที่ บัญชี › ผังบัญชี (Chart of Accounts) ด้วย)
**ต้องมีก่อน:** -

## ขั้นตอน
1. เปิดเมนูที่ต้องการ (ทั้ง 4 เมนูเป็นหน้าจอรหัส-ชื่อแบบเดียวกัน)
2. กดเพิ่ม กรอก "รหัส:" "ชื่อ:" และ "ชื่อภาษาอังกฤษ:" (ถ้ามี)
3. เฉพาะ กำหนดสมุดบัญชี มีช่อง "อักษรย่อสมุดรายวัน:" เพิ่ม
4. กดบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส | รหัสสั้นๆ | ต้องกรอก ห้ามซ้ำ |
| ชื่อ | ชื่อที่จะเห็นในรายการ | |
| ชื่อภาษาอังกฤษ | ชื่ออังกฤษ | ไม่บังคับ |
| อักษรย่อสมุดรายวัน | ตัวย่อของสมุด | เฉพาะสมุดบัญชี ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล |

## บันทึกแล้วระบบทำอะไรให้
- สมุดบัญชี: ใช้เลือกในช่อง สมุดรายวัน ของข้อมูลรายวัน การปิดบัญชี และการผูกบัญชีในรูปแบบเอกสาร
- กลุ่มบัญชี: ใช้เลือกในผังบัญชี แล้วรายงาน งบดุล และ งบกำไรขาดทุน (ในเมนู บัญชี › รายงานงบทดลอง กระดาษทำการ และงบการเงิน) จัดกลุ่มบัญชีตามกลุ่มนี้
- กลุ่มบัญชีกระแสเงินสด: ใช้เลือกในช่อง รหัสบัญชีกระแสเงินสด ของผังบัญชีได้ แต่ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล (ยังไม่มีรายงานที่ใช้)
- ประเภทบัญชี: ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ประเภทบัญชีในผังบัญชีเป็นตัวเลือกคงที่ 5 แบบ (สินทรัพย์ / หนี้สิน / ทุน / รายได้ / ค่าใช้จ่าย) ไม่ได้ดึงจากเมนูนี้

## แก้ไข ยกเลิก พิมพ์
- หน้าจอนี้ไม่มีช่องติ๊กยกเลิกการใช้งาน ถ้าเลิกใช้ ให้เลิกเลือกเอง หรือลบถ้ายังไม่ถูกใช้
- สมุดบัญชีที่ถูกใช้ในใบสำคัญแล้วลบไม่ได้ ขึ้นหัวข้อ "ไม่อนุญาตให้ลบ" ข้อความ "มีการใช้งานในสมุดรายวันแล้ว"
- กลุ่มบัญชี และกลุ่มบัญชีกระแสเงินสด ระบบไม่ตรวจก่อนลบ ถ้าลบกลุ่มที่ผังบัญชีใช้อยู่ ครั้งหน้าที่บันทึกบัญชีนั้นจะขึ้น "ไม่พบกลุ่มบัญชี: ..." หรือ "ไม่พบกลุ่มกระแสเงินสด: ..." ([[ts-gl-chart-save-errors]])

## ปัญหาที่พบบ่อย
- หัวข้อ "รหัสซ้ำ" ข้อความ "รหัส "..." มีอยู่ในระบบแล้ว กรุณาใช้รหัสอื่น" → เปลี่ยนรหัส
- หัวข้อ "ข้อมูลไม่ครบถ้วน" ข้อความ "กรุณาระบุรหัส" → ใส่รหัส
