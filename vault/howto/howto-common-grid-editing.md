# กรอกตารางรายการสินค้าในเอกสาร

**ใช้เมื่อ:** กรอกสินค้าในเอกสารซื้อ ขาย หรือคลังสินค้า เช่น ใบสั่งซื้อ ใบขาย ใบรับสินค้า ใบเบิก
**เมนู:** อยู่ในหน้าจอเอกสารทุกใบที่มีรายการสินค้า (ส่วนตารางด้านล่างของเอกสาร)
**ต้องมีก่อน:** กด "เพิ่มใหม่" หรือ "แก้ไข" ให้เอกสารอยู่ในโหมดแก้ไข และมีข้อมูลสินค้าในระบบแล้ว

## ขั้นตอน
1. กด "เพิ่มบรรทัดรายการใหม่" เพื่อเพิ่มบรรทัด
2. ในช่องรหัสสินค้า พิมพ์รหัสแล้วกด Enter หรือกดปุ่ม "ค้นหาสินค้า" เพื่อเลือกจากหน้าต่างค้นหา ดู [[howto-common-lookup-search]]
3. กรอกคลัง ที่เก็บ หน่วยนับ จำนวน ราคา และส่วนลด
4. ถ้ารู้แค่ยอดรวม ใช้ปุ่ม "สูตร" ข้างช่องจำนวน ราคา หรือส่วนลด (ดูตารางด้านล่าง)
5. ทำซ้ำจนครบทุกรายการ แล้วกดบันทึกเอกสาร

## ช่องสำคัญที่ต้องกรอก
| ช่อง หรือปุ่ม | กรอกอะไร | หมายเหตุ |
|---|---|---|
| สูตรในช่องจำนวน (ยอดรวม ÷ จำนวน) | พิมพ์ ยอดรวม/จำนวน เช่น 1000/4 | ระบบหาราคาต่อหน่วยให้ เศษที่ปัดไปใส่ช่องส่วนลด |
| สูตรในช่องราคา (ยอดรวม ÷ ราคา) | พิมพ์ ยอดรวม/ราคา เช่น 1000/25 | ระบบหาจำนวนให้ เศษที่ปัดไปใส่ช่องส่วนลด |
| สูตรส่วนลด | พิมพ์สูตร เช่น =100*2+50 | ใช้ + - x * / และวงเล็บได้ ผลลัพธ์ใส่ช่องส่วนลด |
| เลือกสูตรราคาขาย | เลือกสูตรราคาที่ตั้งไว้ | มีในเอกสารขาย |
| ดูราคาขาย 3 ตาราง (ปุ่ม "ราคาขาย") | ดูราคาขาย ทั่วไป / ตามกลุ่มลูกค้า / มาตรฐาน | ดูก่อนตัดสินใจราคา มีเฉพาะเอกสารกลุ่มขาย เช่น ใบเสนอราคา ใบสั่งขาย |
| เช็คยอดคงเหลือตามคลัง | ดูยอดคงเหลือของสินค้าบรรทัดนี้แยกตามคลัง | ดูอย่างเดียว |
| Serial Number | ใส่หมายเลขเครื่องของสินค้า | ปุ่มขึ้นทุกบรรทัดที่เลือกสินค้าแล้ว |
| ล็อกต้นทุน | กำหนดต้นทุนของบรรทัดนี้เอง | เมื่อล็อกแล้วปุ่มจะขึ้น "ล็อกต้นทุนอยู่ (กดเพื่อแก้/ปลดล็อก)" |
| ย้ายบรรทัด | กดค้างที่ปุ่มย้ายท้ายบรรทัดแล้วลากขึ้นลงเพื่อสลับลำดับ | ทำได้ตอนอยู่ในโหมดแก้ไข |
| ลบรายการ | ลบบรรทัดนั้นออก | มีผลเมื่อกดบันทึกเอกสาร |

## บันทึกแล้วระบบทำอะไรให้
- ระบบคำนวณยอดเงินแต่ละบรรทัด ยอดรวม ส่วนลด และภาษีของเอกสารให้ตามที่กรอก
- ปุ่มสูตรเป็นตัวช่วยกรอกเท่านั้น ผลที่ได้จะไปอยู่ในช่องจำนวน ราคา หรือส่วนลดตามปกติ ตรวจตัวเลขก่อนบันทึกได้

## แก้ไข ยกเลิก พิมพ์
- แก้บรรทัดที่ผิดได้ทันทีระหว่างอยู่ในโหมดแก้ไข เมื่อบันทึกแล้วต้องกด "แก้ไข" ก่อน ดู [[howto-doc-edit-cancel-delete]]
- ถ้าเอกสารถูกนำไปใช้ต่อแล้ว จะแก้รายการไม่ได้ ดู [[ts-common-cannot-edit-used-doc]]

## ปัญหาที่พบบ่อย
- ไม่เห็นปุ่ม "สูตร" เพราะเอกสารยังไม่อยู่ในโหมดแก้ไข ให้กด "แก้ไข" หรือ "เพิ่มใหม่" ก่อน
- ตารางในเอกสารยังไม่มีเมนูคลิกขวา (เมนูคลิกขวามีเฉพาะหน้าจอสินค้าคงเหลือยกมา) ให้ใช้ปุ่มบนแต่ละบรรทัดแทน
- พิมพ์รหัสสินค้าแล้วขึ้น "ไม่พบ" ดู [[ts-common-lookup-not-found]]
