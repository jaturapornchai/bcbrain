# ภาษีมูลค่าเพิ่ม (ภ.พ.30) และภาษีหัก ณ ที่จ่าย (ภ.ง.ด.3/53) รวมทุกเรื่อง

**ใช้เมื่อ:** ลูกค้าถามเรื่องบันทึกภาษีซื้อ ภาษีขาย หัก ณ ที่จ่าย หรือรายงานภาษีรายเดือน (ภาษีมูลค่าเพิ่ม = VAT ที่บวกในราคาสินค้า/บริการ, ภาษีหัก ณ ที่จ่าย = ภาษีเงินได้ที่ผู้จ่ายหักไว้ก่อน)
**เมนู:** บัญชี › รายงานภาษีมูลค่าเพิ่ม (ภ.พ.30) / รายงานภาษีหัก ณ ที่จ่าย (ภ.ง.ด.3 / 53) · ตั้งค่าที่ เริ่มต้น › ตั้งค่าระบบบัญชีและภาษี
**ต้องมีก่อน:** -

## ลำดับการใช้งาน
1. ตั้งกลุ่มภาษี → [[howto-tax-setup-tax-group]]
2. ภาษีจากเอกสารซื้อขาย (เกิดเองตอนบันทึก) → [[howto-tax-vat-from-documents]]
3. ภาษีจากใบสำคัญที่บันทึกเอง → [[howto-tax-journal-tax-tabs]]
4. บันทึกหัก ณ ที่จ่าย / ถูกหัก ณ ที่จ่าย → [[howto-tax-wht-entry]]
5. รายงานภาษีซื้อ ภาษีขาย สรุปภาษี → [[howto-tax-vat-report]]
6. รายงาน ภงด.3 ภงด.53 ภาษีถูกหัก → [[howto-tax-wht-report]] · ส่งออกไฟล์ [[howto-tax-wht-export]]

## ปัญหาที่พบบ่อย
| ปัญหาที่ลูกค้าเจอ | ดูโน้ต |
|---|---|
| เอกสารไม่ขึ้นรายงานภาษี / ขึ้นผิดเดือน | [[ts-tax-doc-not-in-vat-report]] |
| รายงานภาษีต่างประเทศว่าง | [[ts-tax-foreign-vat-empty]] |
| หัก ณ ที่จ่ายไม่ขึ้น / ขึ้นผิด ภงด. | [[ts-tax-wht-not-in-report]] |

## คำถามที่พบบ่อย
- เข้ารายงานเดือนไหน เปลี่ยนเดือนภาษีได้ไหม → [[faq-tax-vat-month]]
- ยกเลิกใบกำกับแล้วยังอยู่ในรายงาน → [[faq-tax-cancelled-doc-in-report]]
- แยก ภงด.3 กับ ภงด.53 จากอะไร → [[faq-tax-pnd3-vs-pnd53]]
- พิมพ์ 50 ทวิ ได้ไหม → [[faq-tax-wht-certificate]]

## แก้ไข ยกเลิก พิมพ์
- ตัวเลขภาษีผิด แก้ที่เอกสารต้นทางหรือใบสำคัญ แล้วเปิดรายงานใหม่
- พิมพ์และส่งออกรายงาน → [[rpt-print-export]]

## หมายเหตุ
- รุ่น Starter ไม่เห็นรายงานภาษีในหมวดบัญชี → [[faq-gl-starter-no-gl]]
- อัตราภาษี กำหนดยื่น สิทธิ์ขอคืน ให้ปรึกษาผู้สอบบัญชี/สรรพากร
