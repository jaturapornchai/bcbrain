# บันทึกหนี้ลูกค้าที่ค้างอยู่ก่อนเริ่มใช้ระบบ (ยกมา)

**ใช้เมื่อ:** เพิ่งเริ่มใช้ BC Ai Account และมีบิลขายเชื่อเก่าที่ลูกค้ายังค้างจ่าย ต้องการให้บิลเหล่านั้นขึ้นในใบวางบิลและใบเสร็จ (ยกมา = ยอดที่ยกมาจากก่อนเริ่มใช้ระบบ)
**เมนู:** ลูกหนี้ › เลือก
- ตั้งหนี้ยกมา (ลูกหนี้) — บิลขายเชื่อเก่าที่ยังค้าง 1 ใบต่อ 1 เอกสาร
- เพิ่มหนี้ยกมา (ลูกหนี้) — ใบเพิ่มหนี้เก่าที่ยังค้าง
- ลดหนี้ยกมา (ลูกหนี้) — ใบลดหนี้เก่าที่ยังไม่ได้หักกับลูกค้า
**ต้องมีก่อน:** ลูกค้าในทะเบียนลูกหนี้ ([[howto-ar-customer-register]])

## ขั้นตอน
1. เปิดเมนู ตั้งหนี้ยกมา (ลูกหนี้) กดเพิ่มใหม่
2. ใส่เลขที่เอกสารและวันที่ แนะนำให้ใช้เลขที่และวันที่ของบิลเดิม
3. เลือกลูกค้า
4. ใส่ "เลขที่ใบกำกับภาษี" และ "ลงวันที่" ของใบกำกับบิลเดิม (ถ้ามี) และ "เอกสารอ้างอิง"
5. ใส่ "มูลค่าสุทธิ" = ยอดที่ลูกค้ายังค้างจริง
6. ใส่จำนวนวันเครดิต หรือวันครบกำหนด ให้ตรงกับบิลเดิม
7. บันทึก ทำซ้ำทีละบิลจนครบ
8. ถ้ามีใบเพิ่มหนี้ หรือใบลดหนี้เก่าที่ยังค้าง ใช้เมนู เพิ่มหนี้ยกมา / ลดหนี้ยกมา แบบเดียวกัน (ลดหนี้ยกมา ไม่มีช่องเลขที่ใบกำกับภาษีและเอกสารอ้างอิง มีลูกค้า ยอดเงิน "พนักงาน/แผนก" และเครดิต/ครบกำหนด)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | ลูกค้าที่ค้างจ่าย | |
| มูลค่าสุทธิ | ยอดค้างของบิลนั้น | ต้องกรอก ไม่มีตารางรายการสินค้า |
| เลขที่ใบกำกับภาษี | เลขใบกำกับของบิลเดิม | ไม่มีใน ลดหนี้ยกมา |
| เครดิต (วัน) / ครบกำหนด | ตามบิลเดิม | ใช้ดูหนี้ถึงกำหนด/เกินกำหนดในรายงาน |
| พนักงาน/แผนก | คนขายบิลนั้น | ถ้าต้องการดูยอดตามพนักงานขาย |

## บันทึกแล้วระบบทำอะไรให้
- บิลยกมากลายเป็นหนี้ค้างของลูกค้า กด "ดึงเอกสารค้างชำระ" ในใบวางบิลหรือใบเสร็จแล้วจะขึ้นมาให้
- ลดหนี้ยกมา ขึ้นเป็นยอดติดลบ ใช้หักกับบิลอื่นในใบเสร็จเดียวกันได้
- **ไม่ตัดสต็อก และไม่ลงบัญชี (ไม่สร้างรายการบัญชีแยกประเภท)** เพราะเป็นยอดเก่า ยอดลูกหนี้ยกมาฝั่งบัญชีต้องบันทึกยอดยกมาในระบบบัญชีแยกประเภทอีกทาง ([[howto-gl-overview]])
- ไม่สร้างรายการในรายงานภาษีขาย ช่องเลขที่ใบกำกับภาษีมีไว้อ้างอิงบิลเดิมเท่านั้น

## แก้ไข ยกเลิก พิมพ์
- แก้หรือลบได้ ตราบใดที่ยังไม่ถูกนำไปใช้ในใบวางบิลหรือใบเสร็จ
- ถ้าเอาไปวางบิล/รับชำระแล้ว ระบบขึ้น "ห้ามแก้ไข หรือลบข้อมูล" ต้องยกเลิกใบวางบิล/ใบเสร็จที่ใช้บิลนี้ก่อน ([[howto-ar-cancel-docs]])
- เอกสารยกมาไม่มีเมนูยกเลิก ถ้าบันทึกผิดให้แก้หรือลบ ([[howto-doc-edit-cancel-delete]])

## ปัญหาที่พบบ่อย
- ดึงเอกสารค้างชำระแล้วบิลยกมาไม่ขึ้น → ตรวจวันที่ใบเสร็จต้องไม่ก่อนวันที่บิลยกมา [[ts-ar-no-outstanding]]
- ใส่ยอดยกมาเป็นยอดเต็มบิล แต่ลูกค้าจ่ายมาบางส่วนแล้ว → แก้ "มูลค่าสุทธิ" เป็นยอดที่ค้างจริง
- แก้ไม่ได้ ขึ้น "ห้ามแก้ไข หรือลบข้อมูล" → [[ts-sale-cannot-edit]]
