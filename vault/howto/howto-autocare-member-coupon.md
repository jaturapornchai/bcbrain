# ขายแพ็กเกจคูปองสมาชิกและตัดสิทธิ์ทีละครั้ง

**ใช้เมื่อ:** ลูกค้าซื้อแพ็กเกจหลายครั้ง (เช่น ล้างสีหลายครั้ง) หรือมาใช้สิทธิ์
**เมนู:** AutoCare › ตั้งค่าและข้อมูลหลัก › "กำหนดแพ็กเกจคูปองสมาชิก คาร์แคร์ และเงื่อนไขรับประกัน"

## ขั้นตอน
1. กด "เพิ่มใหม่" กรอก "รหัสคูปองสมาชิก" "ทะเบียนรถที่ใช้สิทธิ์" "ชื่อแพ็กเกจคูปองบริการ" "ชื่อลูกค้าสมาชิก" "จำนวนสิทธิ์ทั้งหมด (ครั้ง)" และ "มูลค่าต่อครั้ง (บาท)" ช่องที่เว้นว่างระบบเติมค่าตัวอย่างให้ จึงควรพิมพ์ทับทุกช่อง
2. กด "บันทึก" ขึ้น "บันทึกแพ็กเกจคูปองสมาชิก ... เรียบร้อย"
3. ลูกค้ามาใช้ เลือกคูปองแล้วกด "ตัดสิทธิ์คูปอง 1 ครั้ง" ขึ้น "ตัดสิทธิ์แพ็กเกจคูปองสมาชิก ... เรียบร้อย (1 สิทธิ์)"
4. ลบคูปองที่ผิดได้ด้วยปุ่ม "ลบ" ระบบถามยืนยันก่อน แล้วขึ้น "ลบแพ็กเกจคูปอง ... เรียบร้อย"

## ข้อจำกัด
- การตัดสิทธิ์ **ไม่ลดยอดในใบงานหรือบิลโดยอัตโนมัติ** และไม่ลงบัญชี ต้องคิดส่วนลดหรือเปิดใบงานเองให้สอดคล้อง
- ระบบไม่ตรวจวันหมดอายุ (ตอนสร้างจะตั้งไว้ประมาณ 1 ปีแต่ไม่ได้ใช้ตรวจ) และเมื่อสิทธิ์หมดแล้วกดตัดอีกก็ไม่ขึ้นข้อความเตือน จำนวนคงเหลือค้างที่ 0 และสถานะเป็นใช้ครบ ให้ดูจำนวนครั้งคงเหลือก่อนตัด
- รหัสลูกค้าของคูปองใหม่ระบบกำหนดให้เป็นค่าตัวอย่างเสมอ แม้พิมพ์ในช่อง "รหัสลูกค้า" ถ้าต้องผูกกับลูกค้าจริง ให้ส่งต่อเจ้าหน้าที่ ส่วนชื่อลูกค้าและทะเบียนบันทึกตามที่กรอก
