# บันทึกใบรับวางบิลจากเจ้าหนี้

**ใช้เมื่อ:** ผู้ขายส่งใบวางบิล (ใบสรุปบิลที่ขอเก็บเงิน) มา และกิจการอยากบันทึกว่ารับบิลใบไหนไว้แล้ว เพื่อดึงไปจ่ายทีเดียวตอนทำใบจ่ายชำระ
**เมนู:** เจ้าหนี้ › ใบรับวางบิล (เจ้าหนี้)
**ต้องมีก่อน:** มีเอกสารหนี้ของเจ้าหนี้รายนั้นค้างอยู่ เช่น ใบซื้อเงินเชื่อ ใบตั้งหนี้อื่นๆ หรือหนี้ยกมา

ใบรับวางบิลเป็นเอกสารรวบรวมบิลที่ผู้ขายขอเก็บเงิน ไม่ลดหนี้ และไม่ลงบัญชี ([[faq-ap-billing-reduce-debt]]) การทำใบนี้ไม่บังคับ ยกเว้นกิจการเปิดข้อเลือกให้ต้องอ้างอิงใบรับวางบิลทุกครั้ง

## ขั้นตอน
1. เปิดเมนู กด "เพิ่มใหม่" เลือกเจ้าหนี้
2. ใส่วันที่เอกสาร (จอนี้ไม่มีช่องให้ใส่วันนัดจ่าย)
3. กด "ดึงเอกสารค้างชำระ" ระบบแสดงเอกสารหนี้ที่ยังค้างของเจ้าหนี้รายนี้ ที่ลงวันที่ไม่เกินวันที่ของใบนี้
4. ลบบรรทัดที่ผู้ขายไม่ได้วางบิลออก ด้วยปุ่ม "ลบรายการ" ในช่อง จัดการ
5. แก้ "ยอดวางบิล" ถ้าผู้ขายวางบิลไม่เต็มยอดคงเหลือ
6. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เจ้าหนี้/ผู้จำหน่าย | ผู้ขายที่มาวางบิล | ต้องเลือกก่อนกดดึงเอกสาร |
| ยอดวางบิล | ยอดที่ผู้ขายขอเก็บของแต่ละบิล | ไม่เกินยอดคงเหลือ |

ในตาราง แสดง เลขที่เอกสาร วันที่ ประเภท เลขที่อ้างอิง วันที่อ้างอิง วันครบกำหนด ยอดหนี้ ยอดคงเหลือ ใบลดหนี้ขึ้นเป็นยอดติดลบ เพื่อหักกับบิลอื่น

## บันทึกแล้วระบบทำอะไรให้
- เก็บรายการบิลที่รับวางไว้ ตอนทำใบจ่ายชำระ กด "อ้างอิงใบรับวางบิล" ดึงบิลทั้งชุดมาจ่ายได้เลย ([[howto-ap-payment]])
- ยอดเจ้าหนี้ไม่เปลี่ยน
- เอกสารหนี้ที่ถูกวางบิลแล้ว แก้ไขหรือลบไม่ได้ จนกว่าจะยกเลิกหรือลบใบรับวางบิล

## ข้อเลือกที่เกี่ยวข้อง (กำหนดข้อเลือกพิเศษต่างๆ)
- "ไม่แสดงเอกสารที่วางบิลไปแล้ว" (แท็บ 2.บัญชีแยกประเภท) ตอนกด "ดึงเอกสารค้างชำระ" ในใบรับวางบิล ไม่แสดงบิลที่อยู่ในใบรับวางบิลใบอื่นแล้ว
- "ห้ามรับวางบิลซ้ำ" (แท็บ 3.สินค้าคงคลัง) เมื่อเปิดข้อนี้ ระบบไม่ให้บันทึกบิลที่อยู่ในใบรับวางบิลใบอื่นแล้ว ถ้าไม่เปิด ระบบยอมให้วางบิลซ้ำได้ ([[ts-ap-billing-duplicate]])
- "จ่ายชำระหนี้อ้างอิงวางบิลทุกครั้ง" (แท็บ 2.บัญชีแยกประเภท) บังคับให้ใบจ่ายชำระต้องดึงจากใบรับวางบิล ([[ts-ap-must-ref-billing]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้ ถ้ายังไม่ถูกยกเลิกและงวดบัญชียังไม่ปิด
- ใบที่ใบจ่ายชำระอ้างอิงไปแล้ว ระบบยังยอมให้แก้ไขหรือลบได้ กันไว้แค่ตอนยกเลิก ถ้าเผลอแก้หรือลบใบที่จ่ายไปแล้ว ส่งต่อเจ้าหน้าที่
- ยกเลิกที่ ยกเลิกใบรับวางบิล (เจ้าหนี้) ([[howto-ap-cancel-docs]])
- พิมพ์ด้วยปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"

## ปัญหาที่พบบ่อย
- "กรุณาระบุรหัสลูกหนี้/เจ้าหนี้ก่อนดึงเอกสาร" → เลือกเจ้าหนี้ก่อน
- กดดึงแล้วไม่มีบิลขึ้น → [[ts-ap-no-bills]]
- "ห้ามรับวางบิลซ้ำ : ..." → [[ts-ap-billing-duplicate]]
- "ป้อนยอดชำระเกิน : ... (ยอดคงเหลือ ...)" → ยอดวางบิลเกินยอดคงเหลือ ([[ts-ap-pay-over]])
