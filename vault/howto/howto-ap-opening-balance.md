# บันทึกหนี้ค้างจ่ายยกมา (ตั้งหนี้ เพิ่มหนี้ ลดหนี้ยกมา)

**ใช้เมื่อ:** เริ่มใช้โปรแกรม และมีบิลซื้อที่ยังค้างจ่ายผู้ขายอยู่จากก่อนวันเริ่มระบบ
**เมนู:** เจ้าหนี้ › ตั้งหนี้ยกมา (เจ้าหนี้) / เพิ่มหนี้ยกมา (เจ้าหนี้) / ลดหนี้ยกมา (เจ้าหนี้)
**ต้องมีก่อน:** เจ้าหนี้ในระบบ ([[howto-ap-supplier]]) และรายการบิลค้างจ่ายแยกทีละใบ

ยอดยกมา (ยอดที่ค้างอยู่ก่อนเริ่มใช้โปรแกรม) ควรบันทึกทีละบิล เพื่อให้จ่ายชำระตัดได้ตรงใบ

## เลือกเมนูไหน
| บิลเดิมเป็น | ใช้เมนู |
|---|---|
| บิลซื้อหรือใบตั้งหนี้ที่ยังค้างจ่าย | ตั้งหนี้ยกมา (เจ้าหนี้) |
| ใบเพิ่มหนี้ที่ผู้ขายออกให้ ยังค้างจ่าย | เพิ่มหนี้ยกมา (เจ้าหนี้) |
| ใบลดหนี้ที่ผู้ขายออกให้ ยังไม่ได้หักกับบิลใด | ลดหนี้ยกมา (เจ้าหนี้) |

## ขั้นตอน
1. เปิดเมนูที่เลือก กด "เพิ่มใหม่"
2. เลือกเจ้าหนี้ ใส่วันที่เอกสาร
3. ตั้งหนี้ยกมาและเพิ่มหนี้ยกมา ใส่ "เลขที่ใบกำกับภาษี:" "ลงวันที่:" "เอกสารอ้างอิง:" และ "เอกสารอ้างอิงวันที่:" ของบิลเดิม (ลดหนี้ยกมาไม่มีช่องเหล่านี้)
4. ใส่ "มูลค่าสุทธิ *" เป็นยอดที่ยังค้างจริง
5. ใส่เครดิตหรือวันครบกำหนดของบิลเดิม
6. กด "บันทึก" ทำซ้ำจนครบทุกบิล

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เจ้าหนี้ | ผู้ขายของบิลนี้ | |
| มูลค่าสุทธิ * | ยอดค้างจ่ายของบิล | ใส่ยอดเป็นจำนวนบวกเสมอ ระบบรู้เองว่าลดหนี้เป็นยอดหัก |
| เลขที่ใบกำกับภาษี: / ลงวันที่: | เลขและวันที่ของบิลเดิม | ช่วยให้ค้นหาตอนจ่ายชำระง่าย (ไม่มีในลดหนี้ยกมา) |
| ครบกำหนด: | วันที่ต้องจ่าย | ใช้ในรายงานหนี้ถึงกำหนด |

## บันทึกแล้วระบบทำอะไรให้
- ยอดหนี้ของเจ้าหนี้รายนั้นเพิ่มขึ้น (ลดหนี้ยกมาทำให้ลดลง)
- เอกสารขึ้นในตาราง "ดึงเอกสารค้างชำระ" ของใบรับวางบิลและใบจ่ายชำระหนี้ ใบลดหนี้ยกมาขึ้นเป็นยอดติดลบ
- ไม่ลงบัญชีแยกประเภทให้ เพราะยอดยกมาของบัญชีเจ้าหนี้การค้าต้องบันทึกในยอดยกมาของบัญชีแยกประเภทแยกต่างหาก ([[howto-gl-overview]])
- ไม่มีแท็บภาษี ไม่ลงรายงานภาษีซื้อ

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้ ถ้ายังไม่ถูกนำไปวางบิลหรือจ่ายชำระ ([[ts-buy-cannot-edit]])
- เอกสารยกมาไม่มีเมนูยกเลิก ถ้าบันทึกผิด ให้แก้ไขหรือลบที่หน้าจอเอกสารนั้น
- ถ้าจ่ายชำระไปแล้ว ต้องลบหรือยกเลิกใบจ่ายชำระก่อน ([[howto-ap-cancel-docs]])

## ปัญหาที่พบบ่อย
- ยอดยกมาในรายงานเจ้าหนี้ไม่ตรงกับบัญชีเจ้าหนี้การค้า → ตรวจว่าบันทึกยอดยกมาในบัญชีแยกประเภทแล้ว และรวมทุกบิลเท่ากัน
- "ห้ามแก้ไข หรือลบข้อมูล" → บิลนี้ถูกใช้ต่อแล้ว ([[ts-buy-cannot-edit]])
