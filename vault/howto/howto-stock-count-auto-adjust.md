# ปรับปรุงสต็อกอัตโนมัติจากใบตรวจนับ และปรับมูลค่า Lot คงค้าง

**ใช้เมื่อ:** บันทึกใบตรวจนับแล้ว อยากให้ระบบสร้างใบปรับปรุงเพิ่ม/ลดให้เองตามส่วนต่าง
**เมนู:** สินค้า › ตรวจนับสต็อกและปรับปรุงจากการตรวจนับ › ปรับปรุงสต็อกสินค้า/วัตถุดิบอัตโนมัติ / ปรับปรุงสต็อกสินค้า/วัตถุดิบอัตโนมัติ (สินค้า Lot) / ปรับปรุงมูลค่าสินค้า Lot คงค้าง
**ต้องมีก่อน:** ใบตรวจนับ ([[howto-stock-count]]) และรูปแบบเอกสารของใบปรับเพิ่มและใบปรับลด

## ขั้นตอน (ปรับจากใบตรวจนับ)
1. เปิดเมนูอัตโนมัติ (แบบปกติ เทียบตามคลัง/ที่เก็บ หรือแบบสินค้า Lot เทียบตาม LOT)
2. ใส่ จากวันที่ / ถึงวันที่ (ค่าเริ่มต้นคือวันที่ 1 มกราคมของปีนี้ ถึงวันนี้) แล้วกด Load ระบบแสดงใบตรวจนับพร้อมสถานะ ปรับปรุงแล้ว / ยังไม่ได้ปรับ (ถ้าอยากเห็นใบที่ปรับแล้ว ติ๊กช่อง แสดงทั้งหมด ที่เขียนว่า รวมเอกสารนับที่ปรับปรุงแล้ว)
3. เลือก รหัสเอกสาร (ใบปรับเพิ่ม) และ รหัสเอกสารปรับปรุงลด
4. ติ๊กใบตรวจนับที่ต้องการ (เลือกทั้งหมดได้) กด ตรวจสอบสินค้าซ้ำ เพื่อดูสินค้าที่ถูกนับมากกว่า 1 ครั้ง
5. กด ประมวลผล ระบบแจ้งเลขที่ใบปรับเพิ่มและใบปรับลดที่สร้าง

## ขั้นตอน (สินค้าที่ไม่ได้นับแต่ยังมียอด)
1. ในหน้าจอเดียวกัน กด สินค้าที่ไม่มีการตรวจนับและมียอดคงเหลือ
2. ใส่ เอกสารวันที่ เวลา และเลือกคลังสินค้า กด ประมวลผลค้นหา
3. ตรวจรายการ แล้วกด สร้างเอกสารปรับปรุงเป็น 0

## ขั้นตอน (ปรับปรุงมูลค่าสินค้า Lot คงค้าง)
1. ใส่ ณ วันที่ สินค้าตั้งแต่ ถึง รูปแบบ ปรับเพิ่ม และ ปรับลด แล้วกด โหลดข้อมูล
2. ระบบแสดง LOT ที่จำนวนเหลือ 0 แต่ยังมีมูลค่าค้าง ติ๊กรายการแล้วกด ปรับปรุงมูลค่า

## บันทึกแล้วระบบทำอะไรให้
- นับได้มากกว่าในระบบ → ใบปรับเพิ่ม นับได้น้อยกว่า → ใบปรับลด สินค้าที่นับแต่ไม่มีในระบบ → เพิ่มเต็มจำนวนที่นับ
- ถ้าสินค้าที่นับมียอดอยู่ในที่เก็บ (หรือ LOT) ของใบนับชุดนั้นแต่ไม่ได้นับตรงจุดนั้น ระบบปรับจุดนั้นเป็น 0
- ใบปรับลดใช้เลขเดียวกับใบปรับเพิ่ม แต่มีเครื่องหมายลบนำหน้า
- ยอดในระบบเทียบ ณ วันที่ของใบตรวจนับใบล่าสุดที่เลือก ใบปรับปรุงลงวันที่นั้น (ไม่มีเวลา = 23:59)
- ราคาต่อหน่วยในใบปรับปรุงใช้ต้นทุนเฉลี่ยปัจจุบันของสินค้า ส่วนมูลค่าสต็อกคิดที่ต้นทุนเฉลี่ย ณ วันที่เอกสาร และลงบัญชีแบบใบปรับปรุงทั่วไป ([[howto-stock-adjust]])
- เมนูนี้ยังไม่ตรวจงวดบัญชีที่ปิดแล้ว ถ้าใบตรวจนับลงวันที่ในงวดที่ปิดแล้ว ให้ส่งต่อเจ้าหน้าที่ก่อนประมวลผล
- แบบสินค้า Lot และ ปรับปรุงมูลค่าสินค้า Lot คงค้าง ใช้ยอด LOT จากใบยกมาและใบปรับปรุงที่เมนูนี้สร้างเท่านั้น ยังไม่รวม LOT จากบิลซื้อ บิลขาย หรือใบเบิก ยอด LOT และใบปรับปรุงที่ได้จึงอาจไม่ตรง ถ้าลูกค้าใช้ LOT ให้ส่งต่อเจ้าหน้าที่
- ใบตรวจนับถูกทำเครื่องหมายว่าปรับแล้ว กดซ้ำไม่ปรับซ้ำ แต่ใบตรวจนับยังแก้หรือลบได้ และใบปรับปรุงไม่เปลี่ยนตาม

## แก้ไข ยกเลิก
- อยากประมวลผลใหม่: ยกเลิกใบปรับปรุงเดิมก่อน ([[howto-stock-cancel-doc]]) แล้วกด ประมวลผล อีกครั้ง

## ปัญหาที่พบบ่อย
- "เอกสารตรวจนับ ... มีเอกสารปรับปรุงแล้ว ต้องยกเลิกเอกสารปรับปรุงเดิมก่อนประมวลผลใหม่" → ([[ts-stock-count-already-adjusted]])
- "ไม่พบเอกสารตรวจนับบางใบ หรือถูกยกเลิกแล้ว" → ([[ts-stock-count-already-adjusted]])
- "มีรายการต่างกัน ... รายการ เกิน ... ให้เลือกเอกสารทีละส่วน" หรือ "รายการตรวจนับมากเกินไป ให้เลือกเอกสารทีละส่วน" → เลือกใบตรวจนับน้อยลงต่อรอบ
- "กรุณาเลือกเอกสารนับสต็อกที่ยังไม่ได้ปรับปรุง" → ติ๊กใบตรวจนับก่อนกด ประมวลผล
- "เอกสารตรวจนับที่เลือกไม่มีรายการสินค้า" → เลือกใบที่มีสินค้า
- "กรุณาเลือกคลังสินค้าอย่างน้อย 1 คลัง" → เลือกคลังก่อนค้นหา
- "คุณไม่มีสิทธิ์ "เพิ่ม/แก้ไขข้อมูล" ในหน้าจอนี้ กรุณาติดต่อผู้ดูแลระบบ (Admin)" → ([[ts-common-no-permission]])
