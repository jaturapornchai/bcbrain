# ภาพรวมระบบเจ้าหนี้ ทะเบียนผู้จำหน่าย รับวางบิล และจ่ายชำระหนี้

ระบบ **เจ้าหนี้** ใช้จัดการฐานข้อมูลผู้จำหน่าย ติดตามยอดหนี้ค้างจ่ายจากบิลซื้อเชื่อและตั้งหนี้ค่าใช้จ่าย สัญญาแบ่งงวด ใบรับวางบิล ตรวจจับคู่เอกสาร 3 ทาง จนถึงการจ่ายชำระหนี้และออกหนังสือหัก ณ ที่จ่าย

---

## 1. ส่วนงานหลักในระบบเจ้าหนี้

1. **ทะเบียนเจ้าหนี้ คู่ค้า และที่อยู่จัดส่ง** -> [[howto-ap-supplier-master]] (กำหนดเจ้าหนี้ เลขภาษี 13 หลัก สาขา 5 หลัก วันเครดิต ช่องทางจ่ายเงิน และที่อยู่จัดส่ง)
2. **ตั้งหนี้ยกมา และ ตั้งหนี้/เพิ่มหนี้/ลดหนี้อื่นๆ** -> [[howto-ap-opening-other-debt]] (นำเข้ายอดเจ้าหนี้ย้อนหลังตอนเริ่มระบบ และตั้งหนี้ค่าใช้จ่าย/บริการที่ไม่ผ่านสต็อก)
3. **สัญญาและแบ่งงวดตั้งหนี้อัตโนมัติ (เจ้าหนี้)** (รุ่น Pro) -> [[howto-ap-contract]] (สัญญาผ่อนจ่าย/ค่าบริการรายงวด รองรับ ม.78, ภ.พ.36 และหัก ณ ที่จ่าย ภ.ง.ด. 3/53/54)
4. **ใบรับวางบิล และประมวลผลรับวางบิลรวมอัตโนมัติอัจฉริยะ** -> [[howto-ap-billing-auto]] (รับวางบิลเจ้าหนี้ตามรอบปฏิทินวางบิลและตรวจยอดก่อนถึงวันจ่าย)
5. **จ่ายชำระหนี้ (เจ้าหนี้) และ AI จับคู่ใบสั่งซื้อ 3 ทาง** -> [[howto-ap-payment]] (ดึงบิลค้าง/อ้างอิงใบรับวางบิล, ตัดบิลเก่าสุด FIFO, ลงเช็คจ่าย/โอนเงิน/หัก ณ ที่จ่าย และสแกนใบกำกับภาษีซื้อเทียบ PO ในรุ่น Pro)

---

## 2. การแนบไฟล์และการยกเลิกเอกสารเจ้าหนี้

- **บันทึกรูปภาพและไฟล์แนบเอกสารเจ้าหนี้** -> [[howto-doc-attachments]]
- **ยกเลิกเอกสารเจ้าหนี้ (ตั้งหนี้อื่น/วางบิล/จ่ายชำระ)**: ใช้เมนูเฉพาะใต้ "เจ้าหนี้ > ยกเลิกเอกสารเจ้าหนี้ (ตั้งหนี้อื่น/วางบิล/จ่ายชำระ)" -> ดูหลักการที่ [[howto-doc-edit-cancel-delete]]
