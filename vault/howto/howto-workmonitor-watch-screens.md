# วิธีดูหน้าจอพนักงานแบบสด

**ใช้เมื่อ:** อยากเห็นว่าพนักงานคนไหนเปิดระบบอยู่ และกำลังใช้หน้าจอไหน
**เมนู:** แถบระบบด้านบน › ระบบ 3D จอพนักงาน
**ต้องมีก่อน:** พนักงานเข้าใช้ระบบ BC อยู่ ภาพรวมที่ [[sys-workmonitor-overview]]

## ขั้นตอน
1. เปิด "ระบบ 3D จอพนักงาน" จะเห็นห้อง 3 มิติ แถบด้านบนบอก "ออนไลน์จริง: ... จอ" และ "กำลังเปิดดูพร้อมกัน: ... คน"
2. ตอนเปิดหน้านี้ สวิตช์ดูหน้าจอสดเปิดอยู่แล้ว (แถบบนเป็นสีเขียว) ถ้าเคยปิดสวิตช์ไว้ ระบบจะหยุดส่งภาพจากเครื่องพนักงานเพื่อประหยัดอินเทอร์เน็ต และมีข้อความบนจอ "กดปุ่มด้านล่างเมื่อต้องการเปิดดูหน้าจอสด" ให้กดปุ่ม "เปิดดูหน้าจอสดทันที (WebRTC ON)"
3. กดที่โต๊ะของพนักงานเพื่อดูหน้าจอของคนนั้น
4. เลือกโหมดการเปลี่ยนจอ: "ผู้ควบคุมกดดูเอง (ล็อกจอ)" คือค้างที่คนที่เลือก หรือ "เปลี่ยนจออัตโนมัติตามการใช้งาน" ให้ระบบสลับไปตามคนที่กำลังใช้งาน
5. ปรับการมอง: ปุ่มซูมเข้า/ซูมออก/รีเซ็ตซูม 100%, "กางหน้าจอแสดงครบถึงด้านล่างสุดโดยไม่ต้องเลื่อน", "เลื่อนดูส่วนล่างสุดของหน้าจอพนักงานทันที", "เลื่อนกลับไปด้านบนสุด"
6. จัดห้อง: "จัดผังแยกโซน" "จัดผังวงกลม" "มุมมองทั้งห้อง 3D" และลากโต๊ะ หรือเมื่อเลือกโต๊ะแล้วจะมีปุ่ม "เลื่อนโต๊ะ 3D (+X)" "หมุนโต๊ะ 90°"
7. เลิกดู: กดสวิตช์ที่แถบบน ข้อความเมื่อเปิดอยู่คือ "เปิดดูหน้าจอสดอยู่ (กดเพื่อปิด)" เมื่อปิดคือ "ปิดดูหน้าจอสดอยู่ (ประหยัด Bandwidth 0 KB/s — กดเพื่อเปิดดู)"

## สิ่งที่ต้องรู้
- ภาพที่เห็นคือเนื้อหาหน้า BC ที่พนักงานเปิดอยู่ ไม่ใช่ทั้งเครื่อง อ่านที่ [[faq-workmonitor-what-is-recorded]]
- ถ้าโต๊ะไม่ขึ้นหรือจอดำ ดู [[ts-workmonitor-no-desks-or-blank-screen]]
