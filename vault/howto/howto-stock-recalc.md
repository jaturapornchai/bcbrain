# คำนวณยอดสต๊อกใหม่ (คำนวณยอดคงเหลือและต้นทุนใหม่)

**ใช้เมื่อ:** ยอดคงเหลือหรือต้นทุนเฉลี่ยดูไม่ตรงกับเอกสาร หรือทีมงานแนะนำให้คำนวณใหม่ (ปกติไม่ต้องทำ เพราะระบบคำนวณให้ทุกครั้งที่บันทึก แก้ ลบ หรือยกเลิกเอกสาร)
**เมนู:** สินค้า › คำนวณยอดสต๊อกใหม่
**ต้องมีก่อน:** เป็นผู้ดูแลระบบ (เมนูนี้เปิดได้เฉพาะผู้ดูแลระบบ) ทำตอนไม่มีคนบันทึกเอกสารสินค้าอยู่

## ขั้นตอน
1. เปิดเมนู ที่หัวข้อ Stock Recal — คำนวณยอดคงเหลือและต้นทุนสินค้า
2. ช่อง Process Command เลือกอย่างใดอย่างหนึ่ง
   - เว้นว่าง = คำนวณทุกสินค้า
   - รหัสเริ่ม:รหัสสิ้นสุด = ช่วงสินค้า
   - รหัส1,รหัส2 = ระบุทีละรหัส
   - docno=เลขที่เอกสาร = เฉพาะสินค้าในเอกสารนั้น
3. ดูการติ๊ก ตรวจสอบและปรับปรุง อัตราส่วนหน่วยนับ (อ่านข้อควรรู้ก่อน)
4. กด Start Process แล้วรอจนเสร็จ
   - ปุ่ม Stop Process มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล กดแล้วเปลี่ยนแค่ข้อความสถานะ ระบบยังคำนวณต่อจนเสร็จ

## บันทึกแล้วระบบทำอะไรให้
- ไล่เอกสารทุกใบของสินค้าที่เลือกตามวันที่และเวลา แล้วคำนวณยอดคงเหลือ มูลค่า และต้นทุนเฉลี่ยใหม่ ([[faq-stock-cost-method]])
- อัปเดตต้นทุนขายในเอกสารขายและเบิกตามต้นทุนเฉลี่ยใหม่
- **ไม่ได้ลงบัญชีใหม่** รายการบัญชีของเอกสารจะเปลี่ยนเมื่อเปิดเอกสารนั้นแล้วบันทึกใหม่ ให้แจ้งผู้ทำบัญชีตรวจต้นทุนขายในบัญชีหลังคำนวณ ([[faq-stock-gl-posting]])
- **ข้อควรรู้เรื่องอัตราส่วนหน่วยนับ:** ถ้าติ๊กไว้ (ค่าปกติ) ระบบแก้ตัวตั้ง/ตัวหารในเอกสารเก่าทุกใบให้ตรงกับตารางหน่วยนับของสินค้าตอนนี้ ถ้าเคยแก้ตัวตั้ง/ตัวหารหลังใช้งาน จำนวนย้อนหลังจะเปลี่ยนตาม การแก้ส่วนนี้ทำกับ **สินค้าทุกตัว** แม้จะระบุช่วงรหัสหรือเลขที่เอกสารไว้ในช่อง Process Command ([[faq-stock-change-unit-after-use]])

## ข้อจำกัด
- คำนวณได้ครั้งละไม่เกินประมาณ 1 นาที ถ้าข้อมูลมาก ให้แบ่งทำเป็นช่วงรหัสสินค้า
- ปุ่มอื่นในหน้าจอ เช่น ตรวจสอบ Flow การอ้างอิงเอกสาร เป็นเครื่องมือตรวจสถานะเอกสาร ใช้เมื่อทีมงานแนะนำ

## แก้ไข ยกเลิก พิมพ์
- คำนวณซ้ำได้ไม่จำกัด ผลลัพธ์ขึ้นกับเอกสารที่มีอยู่จริง ไม่มีการย้อนคืน

## ปัญหาที่พบบ่อย

- คำนวณแล้วต้นทุนแปลก → ([[ts-stock-cost-wrong]])
- กดแล้วไม่ทำงาน → ([[ts-common-no-permission]])
