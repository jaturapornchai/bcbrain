# ภาพรวมระบบสินทรัพย์ถาวร ค่าเสื่อมราคา และเช่าซื้อ/ลีสซิ่ง

ระบบสินทรัพย์ถาวรใช้สำหรับขึ้นทะเบียนทรัพย์สินระยะยาวของกิจการ เช่น อาคาร เครื่องจักร ยานพาหนะ และอุปกรณ์สำนักงาน ติดตามการซ่อมบำรุง คำนวณและโอนค่าเสื่อมราคาเข้าบัญชีแยกประเภท รวมถึงบันทึกสัญญาเช่าซื้อรถยนต์และการขายหรือตัดจำหน่ายสินทรัพย์

## วงจรชีวิตสินทรัพย์ในโปรแกรม

```
[1. ตั้งค่าพื้นฐาน & ขึ้นทะเบียน]
   กำหนดประเภทสินทรัพย์ ตำแหน่งที่ตั้ง ผังบัญชี และวันเริ่มคิดค่าเสื่อมใน ข้อมูลสินทรัพย์
   (หากเป็นการผ่อนไฟแนนซ์ ใช้หน้า สัญญาเช่าซื้อ / ลีสซิ่งรถยนต์ คุมตารางงวดและภาษีซื้อ)
        ↓
[2. ใช้งานประจำเดือน & ซ่อมบำรุง]
   ├─ บันทึกการซ่อมบำรุงสินทรัพย์ เพื่อเก็บประวัติค่าใช้จ่ายรายตัว
   └─ โอนข้อมูลเข้าระบบบัญชี คำนวณค่าเสื่อมราคา (รายวัน/รายเดือน/รายปี) และลงบัญชี GL
        ↓
[3. ตรวจสอบและรายงาน]
   แสดงค่าเสื่อมราคาสินทรัพย์รายวัน / รายเดือน / รายปี และรายงานรายละเอียดสินทรัพย์
        ↓
[4. จำหน่ายออก / เลิกใช้]
   บันทึกการขายสินทรัพย์ ระบบคำนวณมูลค่าตามบัญชี กำไร/ขาดทุน และลง GL อัตโนมัติ
```

## คู่มือแยกตามหัวข้อในระบบสินทรัพย์

| หัวข้อ | เนื้อหาสำคัญ | คู่มือ |
|---|---|---|
| ทะเบียนสินทรัพย์ ซ่อมบำรุง และค่าเสื่อมราคา | ตั้งค่าประเภทและหน่วยบำรุงรักษา ลงทะเบียนสินทรัพย์ วิธีคิดค่าเสื่อม 3 แบบ (สรรพากร/บัญชี/วันจริง) และโอนเข้า GL | [[howto-asset-register-depreciation]] |
| ขายสินทรัพย์และตัดจำหน่าย | ขายสินทรัพย์เงินสด/เงินเชื่อ คำนวณมูลค่าตามบัญชี กำไร/ขาดทุนจากการขาย ภาษีขาย และลบคืนสถานะ | [[howto-asset-sale-disposal]] |
| สัญญาเช่าซื้อและลีสซิ่งรถยนต์ | คำนวณตารางผ่อนชำระ แยกเงินต้น-ดอกเบี้ย เพดานต้นทุนและภาษีซื้อต้องห้ามสำหรับรถยนต์นั่ง และลงบัญชีค่างวด | [[howto-asset-hire-purchase]] |

## เชื่อมโยงกับระบบอื่น

- **สมุดรายวันและปิดงวด**: ค่าเสื่อมราคา ค่างวดเช่าซื้อ และกำไร/ขาดทุนขายสินทรัพย์จะสร้างใบสำคัญลงในระบบบัญชีแยกประเภท ตรวจสอบได้ใน [[howto-gl-overview]]
- **ภาษีมูลค่าเพิ่มและนิติบุคคล**: ตรวจข้อจำกัดภาษีซื้อรถยนต์และรายจ่ายทางภาษีร่วมกับ [[howto-tax-overview]]
- **รายงานสินทรัพย์**: ดูรายการสินทรัพย์ ค่าเสื่อมราคา และการซ่อมบำรุงเพิ่มเติมที่ **ค่าเสื่อม › รายงานสินทรัพย์และค่าเสื่อมราคา** (รหัสเมนู **8010-8012**) หรือรวมรายงานใน [[rpt-overview]]
