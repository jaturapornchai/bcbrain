# ภาพรวมระบบสินทรัพย์ถาวรและค่าเสื่อมราคา

**ใช้เมื่อ:** กิจการมีทรัพย์สินที่ใช้งานหลายปี เช่น รถ เครื่องจักร คอมพิวเตอร์ อาคาร และต้องการทำทะเบียน คิดค่าเสื่อมราคา ลงบัญชีค่าเสื่อม และบันทึกตอนขาย
**เมนู:** ค่าเสื่อม (เมนูหลัก) และ เริ่มต้น › ตั้งค่าระบบสินทรัพย์ถาวร
**ต้องมีก่อน:** ผังบัญชีสินทรัพย์ ค่าเสื่อมราคา และค่าเสื่อมราคาสะสม ([[howto-gl-overview]])

## ลำดับการใช้งาน
1. ตั้งค่าพื้นฐาน: ประเภทสินทรัพย์ ที่ตั้ง การบำรุงรักษา หน่วยการบำรุงรักษา → [[howto-asset-setup]]
2. ทำทะเบียนสินทรัพย์ทีละรายการ พร้อมผังบัญชีและข้อมูลค่าเสื่อม แนบรูปได้ → [[howto-asset-register]]
3. บันทึกการซื้อสินทรัพย์ลงบัญชี (ทะเบียนไม่ลงบัญชีให้) → [[faq-asset-buy-asset]]
4. ดูค่าเสื่อมก่อนลงบัญชี รายวัน รายเดือน รายปี → [[howto-asset-depreciation-view]]
5. โอนค่าเสื่อมเข้าระบบบัญชีทุกงวด → [[howto-asset-depreciation-post]]
6. บันทึกการซ่อมบำรุง → [[howto-asset-maintenance]]
7. ขายสินทรัพย์ ระบบคิดกำไรขาดทุนให้ → [[howto-asset-sale]]

## คำถามที่พบบ่อย
- คิดค่าเสื่อมแบบไหนได้บ้าง → [[faq-asset-depreciation-method]]
- ตัดจำหน่าย ทิ้ง หรือสูญหาย ทำอย่างไร → [[faq-asset-write-off]]
- แก้ข้อมูลสินทรัพย์หลังลงค่าเสื่อมแล้ว → [[faq-asset-edit-after-posting]]

## ปัญหาที่พบบ่อย
- "สินทรัพย์ช่วงวันที่นี้โอนค่าเสื่อมไปแล้วในเอกสาร ... (แก้ไขเอกสารเดิมแทน)" → [[ts-asset-depreciation-overlap]]
- บันทึกโอนค่าเสื่อมไม่ผ่าน ผังบัญชีไม่ครบ หรือไม่พบสินทรัพย์ → [[ts-asset-depreciation-save-error]]
- ขายสินทรัพย์แล้วขึ้น "ไม่พบผังบัญชี ... (ต้องสร้างในผังบัญชีก่อนบันทึก)" → [[ts-asset-sale-gainloss-account]]
- ลบสินทรัพย์ไม่ได้ → [[ts-asset-delete-blocked]]

## หมายเหตุ
- ถ้าไม่เห็นเมนู ค่าเสื่อม และ ตั้งค่าระบบสินทรัพย์ถาวร อาจเป็นเพราะใช้รุ่น BC Ai Starter ซึ่งซ่อนเมนูกลุ่มนี้ไว้ (รุ่น BC Ai Account และ BC Ai Account Pro แสดงครบ) หรือไม่มีสิทธิ์ ([[ts-common-no-permission]])
- รายงานสินทรัพย์และค่าเสื่อมราคา ดูที่ [[rpt-overview]]
- การเลือกวิธีและอายุการคิดค่าเสื่อมให้ถูกต้องตามกฎหมาย ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร
