# ลงทะเบียนเครื่อง POS

**ใช้เมื่อ:** เปิดเครื่องแคชเชียร์เครื่องใหม่ หรือแก้คลังที่ตัดสต็อก/รูปแบบเลขที่บิลของเครื่อง
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรหัสเครื่อง POS (หรือ กำหนดคุณสมบัติของเครื่อง POS ซึ่งเป็นหน้าเดียวกัน)
**ต้องมีก่อน:** มีคลังสินค้าและที่เก็บที่จะตัดสต็อก ([[howto-pos-web-startup-config]] ตั้งค่าร้านไว้แล้ว)

## ขั้นตอน
1. เปิดเมนู ไปส่วนที่ 1 "ทะเบียนรหัสเครื่อง POS และอุปกรณ์ประจำจุดขาย"
2. กดปุ่ม **เพิ่มใหม่** (ปุ่ม "เตรียมฟอร์มเครื่อง POS ใหม่") ระบบตั้งชื่อให้ว่า "จุดแคชเชียร์หน้าร้าน #..." แก้ได้
3. กรอกช่องตามตาราง ส่วนที่ 2 "รูปแบบเลขที่เอกสารประจำเครื่อง & KBank QR API" ใช้กำหนดเลขที่เอกสารอื่นของเครื่อง
4. กด **บันทึก**
5. จะเปลี่ยนเครื่องที่มีอยู่ ให้คลิกแถวในตารางแล้วกด **แก้ไข** ลบเครื่องกด **ลบ** (ระบบถามยืนยัน "มีข้อมูลที่ต้องลบจำนวน: 1 รายการ ต้องการลบ ... จริงหรือไม่")

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสเครื่อง POS (Machine Code) | เช่น POS-01 | บังคับ พิมพ์เป็นตัวพิมพ์ใหญ่ให้อัตโนมัติ ถ้าว่างขึ้น "ต้องระบุรหัสเครื่อง POS" |
| ชื่อจุดขาย / เครื่องแคชเชียร์ | ชื่อเรียก | |
| เลขทะเบียนเครื่อง POS (RD Terminal ID) | เลขเครื่องที่ขึ้นทะเบียน | |
| รหัสชุดกำหนดค่า POS | ชุดค่าที่ใช้ | ปกติใช้ชุดเดียวกับหน้าค่าเริ่มต้น |
| คลังสินค้า / ที่เก็บตัดสต็อกประจำเครื่อง | คลังและที่เก็บที่บิลของเครื่องนี้ตัดสต็อก | ถ้าปล่อยว่าง ระบบใส่รหัสคลังตัวอย่างให้เอง ซึ่งอาจไม่ตรงกับคลังจริง ต้องกรอกให้ตรงกับคลังหน้าร้านเสมอ |
| รูปแบบเลขที่เอกสารขายอย่างย่อ | เช่น ABB1-@YY@MM-##### | **ต้องมีเครื่องหมาย # (ที่เป็นเลขรัน)** และ **ห้ามซ้ำกับเครื่องอื่น** ดู [[ts-pos-web-doc-format]] |
| รูปแบบเลขที่ใบกำกับภาษีเต็มรูป / รูปแบบเลขที่เอกสารยกเลิก/รับคืน / รูปแบบเลขที่รับเงินทอนเปิดกะ / รูปแบบเลขที่ส่งเงินปิดกะ | รูปแบบเลขที่ของเอกสารแต่ละชนิด | |
| รหัสสาขา / รหัสแผนกประจำเครื่อง | สาขาและแผนกของบิลที่เครื่องนี้ขาย | ถ้าไม่ตั้ง ใช้สาขา 00000 |
| ระดับราคามาตรฐานที่ใช้ขาย (ระดับ 1-9) | ระดับราคาที่เครื่องนี้ใช้ | |
| ชื่อเครื่องพิมพ์ใบเสร็จ / จอแสดงผลฝั่งลูกค้า | ชื่ออุปกรณ์ | เก็บเป็นค่าตั้งของเครื่อง |
| ลิ้นชักเก็บเงินสดอัตโนมัติ | สั่งเปิดลิ้นชักเมื่อรับเงินสด / ไม่สั่ง | |
| ประเภทการพิมพ์ใบเสร็จ | พิมพ์ทุกบิล / ถามก่อนพิมพ์ / ไม่พิมพ์กระดาษ (e-Slip) | |
| บันทึกสำเนาใบเสร็จอิเล็กทรอนิกส์ | บันทึก / ไม่บันทึก | |
| อนุญาตขายเชื่อ / สถานะเครื่อง POS | อนุญาตขายเชื่อ / งดขายเชื่อ และเปิดใช้งาน / ปิดพักเครื่อง | |

## บันทึกแล้วระบบทำอะไรให้
- เครื่องนี้ปรากฏในตาราง "สถานะการซิงก์ข้อมูลเครื่อง POS" ให้สร้างรหัสเชื่อมเครื่อง ([[howto-pos-web-pair-device]])
- บิลของเครื่องนี้จะตัดสต็อกจากคลัง/ที่เก็บที่กำหนด ถ้าไม่พบรหัสเครื่องตอนส่งบิล บิลจะผิดพลาดว่า "ไม่พบเครื่อง POS ..."
