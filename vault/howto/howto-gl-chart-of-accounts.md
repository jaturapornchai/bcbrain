# ตั้งผังบัญชี เพิ่ม แก้ไข นำเข้าผังบัญชี

**ใช้เมื่อ:** เริ่มใช้ระบบครั้งแรก หรือต้องการเพิ่ม/แก้รหัสบัญชี (ผังบัญชี = รายชื่อบัญชีทั้งหมดของกิจการ เช่น เงินสด ลูกหนี้ ขายสินค้า)
**เมนู:** บัญชี › ผังบัญชี (Chart of Accounts) › รายละเอียดผังบัญชี
**ต้องมีก่อน:** ถ้าจะใช้กลุ่มบัญชี ให้ตั้งไว้ก่อน ([[howto-gl-setup-book-group]])

## ขั้นตอน
1. เปิดเมนู รายละเอียดผังบัญชี
2. เริ่มต้นเร็วที่สุด: กดปุ่ม "แม่แบบผังบัญชี TFRS" แล้วเลือกชุดที่ตรงกับธุรกิจ
   - ธุรกิจซื้อมาขายไป
   - ธุรกิจบริการ
   - ธุรกิจผลิตและโรงงาน
3. ระบบเพิ่มเฉพาะรหัสบัญชีที่ยังไม่มี ไม่ทับรหัสเดิมของกิจการ เสร็จแล้วขึ้น "เพิ่มผังบัญชีมาตรฐาน (...) สำเร็จ ... บัญชี"
4. ถ้าจะเพิ่มทีละบัญชี กดเพิ่ม กรอกช่องตามตารางด้านล่าง แล้วกดบันทึก
5. ถ้ามีผังบัญชีในไฟล์อยู่แล้ว กดปุ่ม "นำเข้า CSV" เลือกไฟล์หรือวางข้อมูล ตรวจคอลัมน์ การดำเนินการ ("อัปเดตรหัสเดิม" หรือ "เพิ่มรหัสใหม่") แล้วกด "นำเข้าผังบัญชี (... รายการ)"
6. ต้องการไฟล์ไปแก้ใน Excel กดปุ่ม "ส่งออก CSV / Excel"

ปุ่มทั้งสามนี้มีที่หน้าจอ ปรับปรุงผังบัญชีแบบเร็ว ด้วย

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสบัญชี | รหัสของบัญชี | ห้ามซ้ำ ยาวไม่เกิน 25 ตัวอักษร ระบบเปลี่ยนเป็นตัวพิมพ์ใหญ่ให้ |
| ชื่อบัญชี | ชื่อบัญชีภาษาไทย | ต้องกรอก |
| ชื่อบัญชี (ภาษาอังกฤษ) | ชื่ออังกฤษ | ไม่บังคับ |
| สถานะบัญชี | บัญชีทั่วไป หรือ บัญชีหลัก | สำคัญมาก บัญชีที่ใช้บันทึกรายการต้องเป็น บัญชีทั่วไป ถ้าใบสำคัญใช้บัญชีที่เป็น บัญชีหลัก จะผ่านรายการไม่ได้ ([[ts-gl-control-account-used]]) |
| ระดับบัญชี | บัญชีหลัก หรือ ระดับที่ 1-7 | ใช้จัดย่อหน้าในรายงานผังบัญชี ไม่ได้กันการบันทึก (ที่กันคือช่อง สถานะบัญชี) |
| ผังบัญชีหลัก | บัญชีแม่ที่บัญชีนี้สังกัด | ต้องเป็นรหัสที่มีอยู่จริง และไม่ใช่รหัสตัวเอง |
| ประเภทบัญชี | สินทรัพย์ / หนี้สิน / ทุน / รายได้ / ค่าใช้จ่าย | ใช้จัดหมวดในรายงาน และตอนปิดบัญชี ยอดของบัญชีประเภท รายได้ และ ค่าใช้จ่าย จะถูกปิดเข้าบัญชีที่เลือกตอนสั่งปิด |
| กลุ่มบัญชี | เลือกจากรายการ | ไม่บังคับ ใช้จัดกลุ่มในรายงาน งบดุล และ งบกำไรขาดทุน |
| ปิดเข้าบัญชี, รหัสบัญชีกระแสเงินสด | เลือกจากรายการ | ระบบตรวจว่ามีรหัสนี้จริง แต่ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล |
| ด้านบัญชี, เกี่ยวข้องกับภาษี, ผลกระทบต่องบการเงิน | เลือกตามจริง | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล |
| แยกหน่วยงาน / แยกแผนก / แยกการจัดสรร / แยกโครงการ / แยกงาน / งานระหว่างทำ (JOB) และแท็บ หน่วยงาน แผนก การจัดสรร งาน โครงการ | ติ๊ก/เลือกรหัส | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ([[howto-gl-dimensions]]) |
| ใช้งาน | ติ๊กไว้ถ้ายังใช้อยู่ | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล เอาติ๊กออกแล้วบัญชียังเลือกใช้ได้ตามปกติ |

## บันทึกแล้วระบบทำอะไรให้
- บัญชีพร้อมให้เลือกในข้อมูลรายวัน และในการผูกบัญชีที่รูปแบบเอกสาร ([[howto-gl-doc-format-posting]])
- เอกสารที่ยังไม่ได้ผูกบัญชีไว้ที่รูปแบบเอกสาร ระบบลงบัญชีแบบมาตรฐาน โดยหาบัญชีจากเลขขึ้นต้นของรหัสที่ระบบกำหนดไว้ เช่น เงินสด 1111 เงินฝากธนาคาร 1112 ลูกหนี้ 1121 เจ้าหนี้ 2111 ขาย 4111 ซื้อ 5111 ภาษีซื้อ 1154 ภาษีขาย 2134 (ถ้าไม่เจอจะลองรหัสสำรอง) ถ้าหาไม่เจอเลย ระบบยังลงรหัสนั้นไว้ แล้วไปฟ้อง "ไม่พบผังบัญชี" ตอนผ่านรายการ ([[ts-gl-account-not-found]])
- ข้อควรรู้เมื่อใช้แม่แบบ TFRS คู่กับการลงบัญชีแบบมาตรฐาน: เงินสดลงที่บัญชี "เงินสดในมือ" ซึ่งเป็นบัญชีหลัก จึงผ่านรายการไม่ได้ (ขึ้น "รหัสบัญชีผิดประเภท") และภาษีซื้อลงที่บัญชี "ค่าใช้จ่ายจ่ายล่วงหน้า" ส่วนชุดธุรกิจบริการ ยอดขายลงรหัสที่ไม่มีในผัง และยอดซื้อลงที่บัญชี "ภาษีซื้อ" → ให้ผูกบัญชีเองที่รูปแบบเอกสาร ([[howto-gl-doc-format-posting]]) และส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- แก้ชื่อหรือข้อมูลอื่นได้ตลอด ถ้าจะเปลี่ยนรหัสใช้ [[howto-gl-change-account-code]]
- ลบไม่ได้ถ้าบัญชีถูกใช้ใน สมุดรายวัน รายการบัญชี การตั้งค่าปิดบัญชี ทะเบียนสินทรัพย์ ข้อมูลลูกหนี้ ประเภทบัตรเครดิต กระเป๋าเงิน หรือเป็นบัญชีหลัก/บัญชีปิดของบัญชีอื่น ระบบขึ้น "ไม่อนุญาตให้ลบ ...: ..." พร้อมบอกเหตุผล ([[ts-gl-delete-account-in-use]])
- บัญชีที่ผูกไว้ในสินค้า เจ้าหนี้ หรือรูปแบบเอกสาร ระบบไม่ตรวจก่อนลบ ควรเช็กเองก่อนลบ ถ้าลบไปแล้วเอกสารที่ใช้บัญชีนั้นจะฟ้อง "ไม่พบผังบัญชี" ตอนผ่านรายการ
- แก้หลายบัญชีพร้อมกันแบบตาราง ใช้ [[howto-gl-chart-fast-edit]]
- นำเข้า CSV ไม่ผ่านการตรวจ ผังบัญชีหลัก และ กลุ่มบัญชี แบบหน้าจอปกติ และทับข้อมูลบัญชีเดิมทุกช่อง ถ้าไฟล์มีแค่รหัสกับชื่อ บัญชีเดิมจะถูกล้างช่อง ผังบัญชีหลัก และกลายเป็น บัญชีหลัก ทั้งหมด → ใช้ไฟล์ที่ส่งออกจากระบบเป็นต้นแบบเสมอ ห้ามสลับคอลัมน์
- ถ้าไฟล์ไม่มีคอลัมน์ประเภทบัญชี ระบบเดาจากเลขตัวแรกของรหัส (1 สินทรัพย์ 2 หนี้สิน 3 ทุน 4 รายได้ 5 ค่าใช้จ่าย)

## ปัญหาที่พบบ่อย
- "ผังบัญชีในชุด "..." มีครบในฐานข้อมูลแล้วทั้งหมด" → ไม่ใช่ข้อผิดพลาด แปลว่ามีครบแล้ว
- "ไม่พบข้อมูลผังบัญชีที่ถูกต้องใน CSV" → ไฟล์ไม่มีแถวที่มีทั้งรหัสและชื่อ ลองส่งออกไฟล์จากระบบก่อนแล้วใช้เป็นต้นแบบ
- "ไม่พบบัญชีหลัก: ..." / "ไม่พบกลุ่มบัญชี: ..." / "รหัส ... มีอยู่แล้ว" → ดู [[ts-gl-chart-save-errors]]
- ไม่เห็นเมนู บัญชี หรือเมนู ตั้งค่าระบบบัญชีและภาษี → บางรุ่นไม่มีเมนูกลุ่มบัญชี สอบถามฝ่ายขาย
