# บันทึกภาษีซื้อและเลขที่ใบกำกับภาษีของผู้ขาย

**ใช้เมื่อ:** บันทึกใบซื้อที่มีใบกำกับภาษี เพื่อให้ภาษีซื้อเข้าทะเบียนภาษีซื้อถูกต้อง
**เมนู:** ซื้อ › ซื้อสินค้า/ตั้งหนี้ซื้อ (และเอกสารซื้อที่มีภาษี) › หัวเอกสาร และแท็บ "ข้อมูลภาษี (VAT/WHT)" หรือ "ภาษีมูลค่าเพิ่ม"
**ต้องมีก่อน:** ใบกำกับภาษีจากผู้ขาย

## ขั้นตอน
1. ที่หัวเอกสาร ช่อง "ภาษี:" เลือกประเภทภาษี (แยกนอก / รวมใน / ยกเว้นภาษี / ไม่กระทบภาษี) ให้ตรงกับใบของผู้ขาย
2. ตรวจอัตราภาษี (%) ในช่องถัดไปทางขวา
3. กรอก "เลขที่ใบกำกับภาษี:" และ "ลงวันที่:" ตามใบของผู้ขาย
4. เปิดแท็บภาษี ตรวจ ฐานภาษี และ ภาษีมูลค่าเพิ่ม ที่ระบบคำนวณ
5. บันทึก

## ประเภทภาษี (ระบบทำงานอย่างไร)
| ประเภทภาษี | ระบบคิดอย่างไร |
|---|---|
| แยกนอก | ราคาสินค้ายังไม่รวมภาษี ระบบบวกภาษีเพิ่ม |
| รวมใน | ราคาสินค้ารวมภาษีแล้ว ระบบถอดภาษีออกมา |
| ยกเว้นภาษี | ไม่มีภาษีซื้อ |
| ไม่กระทบภาษี | ไม่มีภาษีซื้อ และไม่เกี่ยวกับรายงานภาษี |

## บันทึกแล้วระบบทำอะไรให้
- บันทึกภาษีซื้อเข้าทะเบียนภาษีซื้อ และลงบัญชี ภาษีซื้อ ให้อัตโนมัติ ([[howto-buy-gl-posting]])
- ถ้าเว้นเลขที่ใบกำกับภาษีว่าง ระบบใช้เลขที่เอกสารแทน
- เอกสารที่บันทึกภาษีซื้อ: ซื้อสินค้า/ตั้งหนี้ซื้อ, ส่งคืน/ลดหนี้ซื้อ, เพิ่มหนี้ซื้อ, ตั้งหนี้ซื้อจากการรับสินค้า, เพิ่ม/ลดหนี้จากใบตั้งหนี้, จ่ายเงินมัดจำ, รับคืนจ่ายเงินมัดจำ, ตั้งหนี้อื่นๆ และเพิ่ม/ลดหนี้อื่นๆ
- ใบรับสินค้าแบบทะยอยรับ ไม่บันทึกภาษีซื้อ ภาษีซื้อจะเข้าตอนตั้งหนี้ ([[howto-buy-partial-invoice]])
- ใบจ่ายชำระหนี้ มีแท็บ "ภาษีซื้อ" ให้บันทึกภาษีเพิ่มได้ ในกรณีที่ใบกำกับภาษีมาตอนจ่ายเงิน

## ข้อเลือกที่เกี่ยวข้อง
- "ป้อนเลขที่ใบกำกับภาษีทุกครั้ง": บังคับกรอกเลขที่และวันที่ใบกำกับ เมื่อประเภทภาษีเป็น แยกนอก หรือ รวมใน ([[howto-buy-options]])
- ระบบห้ามใช้เลขที่ใบกำกับภาษีซ้ำ ของเจ้าหนี้รายเดียวกันในเอกสารประเภทเดียวกัน

## ปัญหาที่พบบ่อย
- "กรุณาป้อนเลขที่ใบกำกับภาษี" / "กรุณาป้อนวันที่ใบกำกับภาษี" → [[ts-buy-tax-invoice]]
- "เลขที่ใบกำกับภาษีซ้ำ : ... (ใช้แล้วในเอกสาร ...)" → [[ts-buy-tax-invoice]]
- เรื่องสิทธิ์ขอคืนภาษีซื้อ อัตราภาษี และกำหนดยื่นแบบ เป็นเรื่องข้อกฎหมาย ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร
