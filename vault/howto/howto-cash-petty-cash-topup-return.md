# เติมเงินสดย่อย และคืนเงินสดย่อย

**ใช้เมื่อ:** เอาเงินจากเงินสดหรือธนาคารมาเติมกองเงินสดย่อย หรือคืนเงินสดย่อยกลับเข้าเงินสด/ธนาคาร
**เมนู:** เงินสด/ธนาคาร › เงินสดและวงเงินสดย่อย › รับ/เพิ่ม วงเงินสดย่อย หรือ คืน/ลด วงเงินสดย่อย
**ต้องมีก่อน:** รหัสเงินสดย่อยที่ผูกผังบัญชีแล้ว ([[howto-cash-petty-cash-setup]])

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. ในตาราง ช่อง "รหัสเงินสดย่อย" เลือกกองเงินสดย่อย ใส่รายละเอียดและจำนวนเงิน
3. ไปแท็บ "การรับ/จ่ายชำระเงิน" ระบุว่าเงินมาจากไหน (เติม) หรือคืนไปที่ไหน (คืน) เช่น เงินสด เงินโอนธนาคาร เช็ค ให้รวมเท่ายอดเอกสาร
4. ดูแท็บ "การลงบัญชี (GL)" ก่อนบันทึกได้
5. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสเงินสดย่อย | กองที่เติมหรือคืน | ใช้กองเดียวต่อเอกสาร (ระบบใช้บัญชีของบรรทัดแรก) |
| จำนวนเงิน | ยอดที่เติม/คืน | |
| แท็บการรับ/จ่ายชำระเงิน | ช่องทางเงิน | ต้องครบยอด |

## บันทึกแล้วระบบทำอะไรให้
- รับ/เพิ่ม: ลงบัญชี เดบิต เงินสดย่อย คู่กับ เครดิต ช่องทางที่จ่ายออก (เงินสด หรือ เงินฝากธนาคาร หรือ เช็คจ่ายล่วงหน้า)
- คืน/ลด: ลงบัญชีกลับด้าน เดบิต ช่องทางที่รับเงินคืน คู่กับ เครดิต เงินสดย่อย
- ถ้าจ่ายด้วยเงินโอนหรือเช็ค จะไปขึ้นในสมุดเงินฝากหรือทะเบียนเช็คด้วย
- ช่องยอดคงเหลือในหน้าตั้งค่าเงินสดย่อยไม่เปลี่ยนตาม

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้ถ้างวดยังไม่ปิดและไม่มีเอกสารอื่นอ้างถึง
- ยกเลิกด้วยเมนู ยกเลิกรับ/เพิ่ม วงเงินสดย่อย / ยกเลิกคืน/ลด วงเงินสดย่อย ([[howto-cash-cancel-docs]])
