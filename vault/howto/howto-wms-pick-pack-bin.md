# วิธีรับเข้าชั้นวาง หยิบ-แพ็ค-ปล่อยรถ โอนย้าย และตรวจนับคลัง WMS

คู่มือปฏิบัติงานสำหรับเจ้าหน้าที่คลังสินค้าในระบบ **[[sys-wms-warehouse]]** เพื่อคุมสต็อกกายภาพแยกตามโซน แร็ค และชั้นวาง พร้อมถ่ายภาพหลักฐานครบทุกขั้นตอน

## 1. ดูแผนผังจุดเก็บ (Bin Map) และรับของเข้าชั้นวาง (Putaway)
1. เปิดแท็บ **แผนผังจุดเก็บ** เพื่อตรวจสอบว่าสินค้าแต่ละรหัสวางอยู่โซน/ชั้นไหน และเหลือพื้นที่ว่างเท่าไร
2. เมื่อมีของเข้าคลัง เปิดหน้าจอ **บันทึกปฏิบัติการคลัง** เลือกประเภท **รับเข้าชั้นวาง (Putaway)**
3. ระบุรหัสสินค้า จำนวน คลัง และตำแหน่งเก็บปลายทาง พร้อมแนบ **รูปถ่ายพาเลท/สินค้า** เพื่อเป็นหลักฐาน

## 2. จัดการใบงานหยิบ-แพ็ค-ปล่อยรถ (Fulfillment)
1. ในแท็บ **ใบงานจัดส่ง**, สลับดูได้ทั้งแบบกระดาน Kanban และตาราง Wave ตามช่องทางขาย (บิล B2B และออนไลน์)
2. เลือกใบงานที่รอหยิบ กดเปลี่ยนสถานะเป็น **กำลังหยิบ (Picking)** และดูพิกัดชั้นวางบนใบงานเพื่อเดินหยิบให้ตรงตำแหน่ง
3. เมื่อหยิบครบและตรวจสอบสภาพแล้ว กดเปลี่ยนสถานะเป็น **แพ็คและ QC (Packed)** พร้อมอัปโหลดรูปสินค้าในกล่องก่อนปิดเทป
4. เมื่อมอบสินค้าให้สายรถส่งของ ให้กด **ปล่อยรถจัดส่ง (Shipped)** พร้อมรูปถ่ายประกอบ ระบบจะตัดยอดสต็อกกายภาพออกจากชั้นวางใน WMS และส่งงานต่อไปยัง [[sys-tms-transport]]
5. สามารถกดอัปโหลดรูปภาพหลักฐานเพิ่มเติมเข้าใบงานเดิมย้อนหลังได้ตลอดเวลา

## 3. โอนย้ายตำแหน่งเก็บ (Bin Transfer) และตรวจนับปรับปรุง (Cycle Count)
- **โอนย้ายชั้นวาง**: เมื่อต้องการย้ายสินค้าจากโซนเติมสต็อกมาวางที่โซนหยิบด่วน เลือกประเภท **โอนย้ายจุดเก็บ** ระบุตำแหน่งต้นทาง-ปลายทาง และจำนวนที่ย้าย
- **ตรวจนับปรับปรุงสต็อก**: เมื่อนับจริงแล้วพบยอดต่างจากระบบ เลือกประเภท **ตรวจนับและปรับปรุง** ระบุยอดนับจริงและแนบภาพถ่ายประกอบเพื่อให้หัวหน้าคลังตรวจสอบ

## ข้อควรทราบในการปฏิบัติงาน
- ในฐานข้อมูลทดสอบครั้งแรก ระบบมีสินค้าและใบงานตัวอย่าง (เช่น รหัส DEMO) เพื่อให้ทีมคลังซ้อมกดเลื่อนสถานะและลองอัปโหลดรูปภาพก่อนใช้งานจริง ดูเพิ่มเติมที่ [[sales-current-limits]]
- ตรวจสอบรายงานความเคลื่อนไหวและผลต่างตรวจนับในระบบบัญชีได้ที่ [[rpt-stock-cost]]

## คำถามที่ลูกค้ามักถาม

- **ระบบคลังสินค้า WMS ช่วยบอกพิกัดว่าสินค้าวางอยู่โซนไหน ชั้นวางไหน และเหลือที่ว่างเท่าไรไหม?**
  ช่วยได้ครบ ในแท็บ **แผนผังจุดเก็บ (Bin Map)** แสดงพิกัดโซน แร็ค ชั้นวาง และพื้นที่ว่างของแต่ละจุดเก็บ ทำให้ตอนรับเข้าชั้นวาง (**Putaway**) และเดินหยิบสินค้าตามใบงานตรงตำแหน่งไม่หลงชั้น
- **ขั้นตอนหยิบ–แพ็ค–ปล่อยรถ (Fulfillment) ตัดสต็อกกายภาพเมื่อไร และเชื่อมกับระบบขนส่ง TMS ยังไง?**
  ทีมคลังเลื่อนสถานะทีละขั้นจาก **กำลังหยิบ (Picking)** → **แพ็คและ QC (Packed)** พร้อมแนบรูปในกล่อง → เมื่อกด **ปล่อยรถจัดส่ง (Shipped)** ระบบจะตัดยอดสต็อกกายภาพออกจากชั้นวางใน WMS และส่งใบงานต่อไปยังระบบขนส่ง TMS ให้อัตโนมัติ
- **ถ้าลืมถ่ายรูปหลักฐานตอนแพ็คของ สามารถอัปโหลดรูปแนบเข้าใบงานย้อนหลังได้ไหม?**
  ได้ สามารถกดอัปโหลดรูปภาพหลักฐานเพิ่มเติมเข้าใบงานเดิมย้อนหลังได้ตลอดเวลา รวมถึงแนบรูปพาเลทตอนรับเข้าและรูปหลักฐานตอนตรวจนับปรับปรุงสต็อก (**Cycle Count**) ด้วย
- **ทีมคลังเพิ่งเริ่มใช้งานใหม่ อยากลองซ้อมกดเปลี่ยนสถานะและอัปโหลดรูปก่อนใช้ข้อมูลจริงได้ไหม?**
  ได้ ในฐานข้อมูลทดสอบครั้งแรก ระบบเตรียมสินค้าและใบงานตัวอย่าง (เช่น รหัส DEMO) ไว้ให้ทีมคลังซ้อมฝึกใช้งานจริงทั้งแบบกระดาน Kanban และตาราง Wave ก่อนเริ่มงานจริง
