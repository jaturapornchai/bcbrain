# ตั้งค่าระบบลูกหนี้

**ใช้เมื่อ:** เริ่มใช้ระบบ หรือต้องการจัดกลุ่มลูกค้าเพื่อดูรายงานแยกกลุ่ม หรืออยากให้ระบบคิดวันครบกำหนดชำระแบบ "ครบกำหนดทุกวันที่ ... ของเดือนถัดไป"
**เมนู:** เริ่มต้น › ตั้งค่าระบบลูกหนี้ › เลือกรายการ
**ต้องมีก่อน:** สิทธิ์ใช้เมนูเริ่มต้น ([[ts-common-no-permission]])

## รายการในเมนู และใช้ที่ไหน
| เมนู | ใช้ทำอะไร |
|---|---|
| กำหนดประเภทลูกหนี้ | ช่อง "ประเภทลูกหนี้ :" ในหน้า กำหนดลูกหนี้ แสดงเป็นคอลัมน์ในรายงานรายละเอียดลูกค้า-ตามรหัสลูกค้า |
| กำหนดกลุ่มลูกหนี้หลัก | ช่อง "กลุ่มหลัก :" ในส่วน "4. มิติและกลุ่มลูกหนี้" ของ รายละเอียดลูกหนี้ ใช้กับราคาขายที่ตั้งแยกตามกลุ่มลูกค้า และใช้เลือกกลุ่มตอนพิมพ์ที่อยู่จัดส่ง |
| กำหนดกลุ่มลูกหนี้ย่อย | ช่อง "กลุ่มย่อย 1-4" ต้องเลือก "กลุ่มลูกหนี้หลัก" ที่กลุ่มย่อยนี้อยู่ด้วย |
| กำหนดมิติลูกหนี้ | ช่อง "มิติที่ 1-5" ของลูกค้า สำหรับจัดหมวดตามหัวข้อที่ร้านตั้งเอง |
| กำหนดวันครบกำหนดชำระเงิน | ตารางคิดวันครบกำหนดตามจำนวนวันเครดิต (ดูด้านล่าง) |
| กำหนดกลุ่มผู้ติดต่อ / กำหนดเหตุผลอนุมัติวงเงิน / กำหนดเงื่อนไขการวางบิล / กำหนดเงื่อนไขการรับเช็ค / กำหนดเงือนไขการชำระเงิน | เก็บรายการรหัสไว้อ้างอิง ยังไม่มีหน้าจออื่นดึงไปตรวจหรือคำนวณ |

- ชื่อเมนู "กำหนดเงือนไขการชำระเงิน" บนจอสะกดแบบนี้
- วันที่วางบิล และวันที่รับเช็ค ของลูกค้า เลือกในหน้า รายละเอียดลูกหนี้ ส่วน "3. วางบิลและรับเช็ค" เป็นตัวเลือก "ทุกวันที่ ..." ไม่ได้ดึงจากเมนูเงื่อนไขด้านบน

## ขั้นตอน (เพิ่มรายการ)
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่"
2. ใส่รหัสและชื่อ (กลุ่มย่อย: เลือกกลุ่มหลักและ "ลำดับกลุ่มย่อย")
3. บันทึก แล้วไปเลือกใช้ในทะเบียนลูกค้า ([[howto-ar-customer-register]])

## ตารางวันครบกำหนดชำระเงิน
**ใช้เมื่อ:** ร้านนัดลูกค้าจ่ายเป็นวันที่ประจำ เช่น ซื้อเดือนไหนก็ครบกำหนดวันที่ 5 ของเดือนถัดไป
| ช่อง | กรอกอะไร |
|---|---|
| จำนวนวันเครดิต | จำนวนวันเครดิตที่จะใช้แถวนี้ เช่น 30 |
| วันที่ครบกำหนดจ่าย | วันที่ของเดือนที่ครบกำหนด เช่น 5 |
| จำนวนเดือนที่จะครบกำหนดจ่าย | นับไปกี่เดือนจากเดือนของเอกสาร เช่น 1 |
| วันที่/จำนวนเดือนที่จะปิดสถานะเครดิต, วันที่/จำนวนเดือนที่จะออกจดหมายเตือน ครั้งที่ 1/2 | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ระบบไม่ได้ปิดเครดิตหรือออกจดหมายเตือนให้อัตโนมัติ |

- ต้องเปิดข้อเลือก "ใช้ระบบคำนวณวันครบกำหนดชำระบิล" (แท็บ "4.ระบบขาย") ที่ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ
- ตัวอย่าง: แถว 30 วัน / วันที่ 5 / 1 เดือน → บิลลงวันที่ใดก็ได้ในเดือนมีนาคม ครบกำหนด 5 เมษายน
- เมื่อเปิดแล้ว ช่องเครดิตและวันครบกำหนดในใบเสนอราคา ใบสั่งจอง ใบสั่งขาย และใบขาย ถูกล็อกให้คิดตามตาราง (ปุ่ม "เครดิต 7 วัน" ยังกดได้) ใบเสนอราคามีปุ่ม "เปลี่ยนจำนวนวันเครดิต" เลือกแถวอื่นได้
- จำนวนวันเครดิตของลูกค้าที่ไม่มีในตาราง ระบบคิดแบบปกติ (วันที่เอกสาร + จำนวนวัน) ([[faq-ar-credit-days]])

## แก้ไข ยกเลิก พิมพ์
- แก้ชื่อได้ตลอด
- ประเภทลูกหนี้ และกลุ่มลูกหนี้หลัก ที่มีลูกค้าใช้อยู่ ลบไม่ได้ ขึ้น "มีการใช้งานในข้อมูลลูกหนี้แล้ว"
- กลุ่มลูกหนี้หลัก ที่มีกลุ่มย่อยอยู่ ลบไม่ได้ ขึ้น "มีการใช้งานในกลุ่มลูกหนี้ย่อยแล้ว"
- รายการอื่นในเมนูนี้ (กลุ่มย่อย มิติ ตารางวันครบกำหนด และเงื่อนไขต่างๆ) ระบบไม่ได้ตรวจว่ามีลูกค้าใช้อยู่ ลบแล้วหายทันที ให้ตรวจก่อนลบ ถ้าลบไปแล้วส่งต่อเจ้าหน้าที่

## ปัญหาที่พบบ่อย
- ลบประเภท/กลุ่มหลักไม่ได้ → เปลี่ยนลูกค้าที่ใช้รายการนั้นไปใช้รายการอื่นก่อน (กลุ่มหลักต้องลบกลุ่มย่อยที่อยู่ใต้กลุ่มนั้นก่อนด้วย)
- เปิดตารางวันครบกำหนดแล้ววันครบกำหนดยังเป็นวันที่ + จำนวนวัน → ตรวจว่ามีแถวที่ "จำนวนวันเครดิต" ตรงกับลูกค้า และเปิดข้อเลือกแล้ว
