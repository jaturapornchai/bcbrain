# บันทึกยอดยกมาเงินสด และเงินฝากธนาคารยกมา

**ใช้เมื่อ:** เริ่มใช้โปรแกรมกลางทาง และต้องการให้รายงานเงินสดหรือสมุดเงินฝากมียอดตั้งต้น
**เมนู:** เงินสด/ธนาคาร › เงินสดและวงเงินสดย่อย › ยกมาเงินสด
และ เงินสด/ธนาคาร › สมุดเงินฝากธนาคาร (ฝาก / ถอน / โอน) › เงินฝากธนาคารยกมา
**ต้องมีก่อน:** ถ้าเป็นเงินฝาก ต้องสร้างสมุดเงินฝากไว้ก่อน ([[howto-bank-passbook]])

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่"
2. กรอกวันที่เอกสาร (วันก่อนวันเริ่มใช้งานจริง) และเลขที่เอกสาร
3. เฉพาะเงินฝากธนาคารยกมา: เลือกสมุดเงินฝากที่ช่อง "สมุดบัญชีธนาคาร" หัวเอกสาร
4. ใส่ยอดที่ช่อง "มูลค่าสุทธิ" ที่หัวเอกสาร เอกสารยกมาไม่มีตารางรายการ
5. กด "บันทึก" ถ้ามีหลายสมุดเงินฝาก ทำเอกสารยกมาแยกสมุดละใบ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| วันที่เอกสาร | วันที่ของยอดยกมา | ต้องอยู่ในงวดที่ยังไม่ปิด |
| สมุดบัญชีธนาคาร | สมุดเงินฝากที่ยกยอดมา | เฉพาะเงินฝากธนาคารยกมา |
| มูลค่าสุทธิ | ยอดคงเหลือ ณ วันนั้น | ต้องมากกว่า 0 |

## บันทึกแล้วระบบทำอะไรให้
- ยอดไปขึ้นในรายงานเคลื่อนไหวเงินสด หรือรายงานสมุดเงินฝาก เป็นยอดตั้งต้น
- **ไม่ลงบัญชีแยกประเภท** ยอดยกมาของบัญชีเงินสดและเงินฝากในงบการเงิน ต้องตั้งในระบบบัญชีแยกประเภทแยกต่างหาก ([[howto-gl-overview]])
- เช็ครับและเช็คจ่ายที่ค้างอยู่ตอนเริ่มใช้ ให้ใช้เมนู เช็ครับยกมา / เช็คจ่ายยกมา ([[howto-cheque-received-register]], [[howto-cheque-paid-register]])

## แก้ไข ยกเลิก พิมพ์
- เปิดเอกสารเดิม กด "แก้ไข" เปลี่ยนยอด แล้ว "บันทึก" หรือกด "ลบ" ถ้าบันทึกผิดทั้งใบ
- งวดที่ปิดแล้วแก้ไม่ได้ ([[ts-common-period-closed]])

## ปัญหาที่พบบ่อย
- "เอกสารยกมาบันทึกเฉพาะยอดเงินที่หัวเอกสาร ไม่มีรายการ" → ใส่ยอดที่ช่อง "มูลค่าสุทธิ" หัวเอกสารอย่างเดียว ถ้ายังขึ้นข้อความนี้ ให้ส่งต่อเจ้าหน้าที่
- "กรุณาระบุยอดเงินมากกว่า 0" → ยังไม่ได้ใส่ "มูลค่าสุทธิ" หรือใส่ศูนย์/ติดลบ
- "วันที่เอกสาร ... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ" → [[ts-common-period-closed]]
