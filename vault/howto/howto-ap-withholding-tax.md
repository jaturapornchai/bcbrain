# บันทึกภาษีหัก ณ ที่จ่าย ตอนจ่ายเงินเจ้าหนี้

**ใช้เมื่อ:** จ่ายค่าบริการหรือค่าใช้จ่ายที่กิจการต้องหักภาษีไว้ แล้วจ่ายผู้ขายเฉพาะยอดหลังหัก
**เมนู:** เจ้าหนี้ › จ่ายชำระหนี้ (เจ้าหนี้) › แท็บ "ภาษีหัก ณ. ที่จ่าย" (เอกสารซื้อเงินสด กรอกในแท็บ "ข้อมูลภาษี (VAT/WHT)")
**ต้องมีก่อน:** ใบจ่ายชำระที่เลือกบิลแล้ว ([[howto-ap-payment]])

ภาษีหัก ณ ที่จ่าย คือภาษีที่ผู้จ่ายเงินหักไว้จากยอดที่ต้องจ่าย แล้วนำส่งสรรพากรแทนผู้รับเงิน จะต้องหักหรือไม่ และอัตราเท่าไร ขึ้นกับชนิดเงินได้และผู้รับ ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร

## ขั้นตอน
1. ในใบจ่ายชำระ เปิดแท็บ "ภาษีหัก ณ. ที่จ่าย"
2. กด "เพิ่ม" ระบบสร้างรายการให้ ใส่วันที่เป็นวันที่ของเอกสาร และดึงเจ้าหนี้ของใบนี้มาให้
3. ตรวจหรือแก้ "วันที่หัก ณ ที่จ่าย" และ "เอกสารเลขที่"
4. "ประเภท" (บุคคลธรรมดา หรือ นิติบุคคล) "เลขประจำตัวผู้เสียภาษี" และ "เลขที่บัตรประชาชน" ระบบดึงจากทะเบียนเจ้าหนี้ แก้ในหน้านี้ไม่ได้ ถ้าผิด ให้แก้ที่ทะเบียนเจ้าหนี้ก่อน ([[howto-ap-supplier]]) แล้วค่อยกด "เพิ่ม"
5. ใน "รายละเอียดภาษีหัก ณ ที่จ่าย" กด "เพิ่มบรรทัด" ใส่ รายละเอียด ฐานภาษี อัตราภาษี
6. ระบบคำนวณ ภาษีหัก ณ ที่จ่าย ให้ (ฐานภาษี คูณ อัตราภาษี) ถ้าใส่ยอดภาษีเองโดยไม่ใส่อัตรา ระบบคำนวณอัตราย้อนให้
7. กลับไปแท็บ "การรับ/จ่ายชำระเงิน" ยอดนี้ขึ้นที่บรรทัด "8. ภาษีหัก ณ ที่จ่าย (นับเป็นยอดชำระ)" แล้วใส่ยอดที่จ่ายจริงให้ครบ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| วันที่หัก ณ ที่จ่าย | วันที่จ่ายเงิน | ใช้จัดเดือนในรายงาน |
| ประเภท | บุคคลธรรมดา / นิติบุคคล | ดึงจากทะเบียนเจ้าหนี้ รายงานแยก ภ.ง.ด.3 กับ ภ.ง.ด.53 ตามทะเบียนเจ้าหนี้ |
| เลขประจำตัวผู้เสียภาษี | ของผู้ขาย | ดึงจากทะเบียนเจ้าหนี้ |
| รายละเอียด | ชนิดเงินได้ เช่น ค่าบริการ ค่าเช่า | |
| ฐานภาษี | ยอดเงินที่ใช้คิดภาษีหัก | ฐานที่ถูกต้องให้ผู้สอบบัญชียืนยัน |
| อัตราภาษี | อัตราตามชนิดเงินได้ | ระบบไม่เติมให้ ต้องใส่เอง |

## บันทึกแล้วระบบทำอะไรให้
- ยอดภาษีหัก ณ ที่จ่ายนับเป็นส่วนหนึ่งของยอดชำระ เงินที่จ่ายจริงจึงน้อยกว่ายอดหนี้เท่ากับยอดภาษี
- ลงบัญชีภาษีหัก ณ ที่จ่ายที่ต้องนำส่ง ในใบจ่ายชำระเดียวกัน
- ข้อมูลเข้ารายงานภาษีหัก ณ ที่จ่าย ใช้เตรียมยื่นแบบ ([[howto-tax-overview]])

## พิมพ์หนังสือรับรอง
- ระบบมีแบบฟอร์มสำเร็จรูป "หนังสือรับรองการหักภาษี ณ ที่จ่าย (มาตรา 50 ทวิ)" ในเมนู สร้าง/แก้ไขแบบฟอร์ม ผู้ดูแลระบบนำมาตั้งเป็นแบบฟอร์มของกิจการก่อน
- ถ้าลูกค้ากด "พิมพ์ฟอร์ม / เลือกรูปแบบ" แล้วไม่เห็นแบบนี้ ให้ส่งต่อทีมงานช่วยตั้งแบบฟอร์ม ([[rpt-print-export]])

## แก้ไข ยกเลิก พิมพ์
- แก้ที่ใบจ่ายชำระ กด "แก้ไข" แล้วแก้ในแท็บนี้ ต้องให้ยอดชำระรวมยังเท่ายอดสุทธิ
- ยกเลิกใบจ่ายชำระ รายงานภาษีหัก ณ ที่จ่ายยังแสดงใบนั้น แต่ยอดเป็นศูนย์และสถานะ ยกเลิก ส่วนไฟล์ส่งออกไม่รวมใบที่ยกเลิก ([[howto-ap-cancel-docs]])

## ปัญหาที่พบบ่อย
- "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" หลังใส่ภาษีหัก → ลดยอดเงินสดหรือเงินโอนลงเท่ายอดภาษี ([[ts-ap-pay-incomplete]])
