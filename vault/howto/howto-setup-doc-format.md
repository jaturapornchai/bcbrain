# กำหนดรูปแบบเลขที่เอกสาร

**ใช้เมื่อ:** ต้องการกำหนดว่าเลขที่เอกสาร (ใบขาย ใบซื้อ ใบสำคัญ ฯลฯ) หน้าตาเป็นอย่างไร ขึ้นต้นด้วยอะไร รีเซ็ตเลขเมื่อไร
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรูปแบบเลขที่เอกสาร (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin · รู้ว่าต้องการตั้งให้เอกสารชนิดใด (เลือกจาก "รหัสหน้าจอ") · เริ่มต้นดู [[start-first-day]]

## วิธีที่ระบบสร้างเลขที่เอกสาร
ระบบเอาตัวอักษรหน้าเลขตามรูปแบบมาต่อกันเป็น "นำหน้า" แล้วหาเลขสูงสุดของเอกสารชนิดเดียวกันที่นำหน้าเหมือนกัน บวก 1 เติมศูนย์ให้ครบจำนวนช่องเลขรัน

| สัญลักษณ์ | ความหมาย |
|---|---|
| @ | แทนรหัสรูปแบบเอกสาร |
| YYYY | ปี ค.ศ. 4 หลักของวันที่เอกสาร |
| YY | ปี ค.ศ. 2 หลักสุดท้าย |
| MM | เดือน 2 หลัก |
| DD | วัน 2 หลัก |
| ปปปป | ปี พ.ศ. 4 หลัก |
| ปป | ปี พ.ศ. 2 หลักสุดท้าย |
| ดด | เดือน 2 หลัก (แบบไทย) |
| วว | วัน 2 หลัก (แบบไทย) |
| # ต่อกัน | ช่องเลขรัน จำนวน # คือจำนวนหลัก |

ตัวอย่าง (สมมุติรหัสรูปแบบคือ SI และวันที่เอกสารเป็น พฤศจิกายน 2026):
- รูปแบบ @YYMM-#### ได้เลขแรกเป็น SI2611-0001 เลขถัดไป SI2611-0002
- เดือนถัดไปนำหน้าเปลี่ยนเป็น SI2612 เลขรันเริ่มที่ 0001 ใหม่
- ถ้าอยากได้ปี พ.ศ. ใช้ ปปดด เช่น รูปแบบ @ปปดด-#### ได้ SI6911-0001

## ขั้นตอน
1. เปิดเมนู "กำหนดรูปแบบเลขที่เอกสาร" ฝั่งซ้ายคือรายการเดิม (คอลัมน์ รหัสรูปแบบ, รหัสจอ, ชื่อรูปแบบเอกสาร, รูปแบบ)
2. กด "เพิ่มใหม่" (หรือเลือกรายการเดิมแล้วแก้)
3. กรอก "รหัสรูปแบบเอกสาร", "รหัสหน้าจอ (Screen Code)" และ "ชื่อรูปแบบเอกสาร (ไทย)"
4. พิมพ์ "รูปแบบเอกสาร (Format)" ตามสัญลักษณ์ข้างบน ดูผลที่ "ตัวอย่างผลลัพธ์"
5. กดบันทึก ระบบแจ้ง 'บันทึกรูปแบบเอกสาร "..." เรียบร้อยแล้ว'

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสรูปแบบเอกสาร | รหัสสั้น เช่น รหัสที่จะไปแทน @ | ต้องกรอก ห้ามซ้ำ ถ้าซ้ำขึ้น "รหัสรูปแบบเอกสารซ้ำ" |
| รหัสหน้าจอ (Screen Code) | เลือกชนิดเอกสาร เช่น ขายสินค้าและบริการ ซื้อสินค้า/ค่าบริการ โอนสินค้า ใบสำคัญ | ต้องกรอก ไม่งั้นขึ้น "กรุณาระบุรหัสหน้าจอ (Screen Code)" |
| ชื่อรูปแบบเอกสาร (ไทย) / (อังกฤษ) | ชื่อที่เห็นในรายการ | ต้องมีชื่อไทย |
| รูปแบบเอกสาร (Format) | เช่น @YYMM-#### | ค่าที่หน้าจอเสนอให้ตอนเริ่มคือ @YYMM#### (ไม่มีขีด) |
| รูปแบบใบกำกับภาษี (Tax Format) | รูปแบบเลขใบกำกับภาษี | ดูหมายเหตุ |
| การรันเลขที่เอกสาร | ต่อเนื่อง, รายปี, รายเดือน หรือ รายวัน | ดูหมายเหตุ |
| รหัสแบบพิมพ์หลัก และรหัสแบบพิมพ์ 1-5 | แบบฟอร์มพิมพ์ของเอกสารนี้ | ดู [[howto-common-print-document]] |
| สมุดรายวัน (GL Journal Book), คำอธิบายรายวัน GL | สมุดที่ลงบัญชีอัตโนมัติ | ปุ่ม "Get Format" ดึงรูปแบบเริ่มต้นมาให้ (ถามว่า "ต้องการล้างของเก่าหรือไม่") ต้องเลือกรหัสหน้าจอก่อน ไม่งั้นขึ้น "กรุณาเลือกรหัสหน้าจอก่อนดึงรูปแบบ" |
| กำหนดสาขาที่ใช้งาน (Use Branch Select) | จำกัดว่าสาขาไหนใช้รูปแบบนี้ได้ | มีรายชื่อสาขาที่อนุญาต |
| ประเภทภาษี (VAT Type) | ชนิดภาษีของเอกสาร | ปรึกษาผู้สอบบัญชีถ้าไม่แน่ใจ |
| โฟลเดอร์สำหรับจัดเก็บ scan, Computer ID สำหรับ Scan | ที่เก็บไฟล์สแกน | ใช้เมื่อสแกนเอกสารแนบ |
| ส่วน e-Tax | ส่งเอกสารเข้าระบบ e-Tax Invoice / Receipt | กรอกเมื่อใช้งาน e-Tax |

## บันทึกแล้วระบบทำอะไรให้
- เอกสารชนิดนั้นที่สร้างหลังจากนี้จะใช้รูปแบบใหม่ ส่วนเอกสารเดิมไม่เปลี่ยน
- ถ้าไม่พบรูปแบบของเอกสารชนิดนั้น ระบบใช้รูปแบบสำรอง @YYMM-####
- ระบบล็อกการออกเลขต่อนำหน้าหนึ่งๆ ทีละคน เลยไม่ออกเลขซ้ำแม้หลายคนบันทึกพร้อมกัน

## แก้ไข ยกเลิก พิมพ์
- มีปุ่มคัดลอกรูปแบบ ชื่อจะต่อท้าย "(สำเนา)"
- ลบ: ติ๊กเลือกแล้วยืนยัน "คุณต้องการลบรูปแบบเอกสารที่เลือกจำนวน N รายการ ใช่หรือไม่?" ถ้ารหัสถูกใช้ในเอกสารหรือสมุดรายวันแล้วขึ้น "ห้ามลบ" ว่า "รหัสรูปแบบเอกสาร [...] ถูกใช้งาน ... แล้ว ไม่สามารถลบได้"

## ปัญหาที่พบบ่อย
- เลขที่เอกสารไม่รีเซ็ตทุกปี/เดือน: การรีเซ็ตขึ้นกับสัญลักษณ์ในรูปแบบ ถ้ามี MM หรือ ดด เลขรีเซ็ตทุกเดือน ถ้ามีแค่ YY หรือ ปป รีเซ็ตทุกปี ตอนนี้ช่อง "การรันเลขที่เอกสาร" และ "รูปแบบใบกำกับภาษี" ยังไม่มีผลต่อการออกเลขจริง
- ตัวอย่างผลลัพธ์บนหน้าจอและคำอธิบายในหน้าช่วยเหลือ แสดง YY/YYYY เป็นปี พ.ศ. เมื่อเลือกปีแบบ พุทธศักราช แต่เลขจริงใช้ YY/YYYY เป็นปี ค.ศ. เสมอ ถ้าต้องการปี พ.ศ. ในเลขที่ ให้ใช้ ปป/ปปปป ตรวจเลขตัวอย่างจากเอกสารจริงอีกครั้ง
- ขึ้น "เลขที่เอกสาร ... ยาวเกิน 25 ตัวอักษร กรุณาแก้รูปแบบเลขที่เอกสาร": เลขที่ยาวเกิน 25 ตัว ลดตัวอักษรนำหน้าหรือจำนวน #
- เลขรันกลับไปเริ่ม 1 เองเมื่อเลขเต็มจำนวน # เช่น กำหนด #### แล้วถึง 9999 ให้เพิ่มจำนวน # ก่อนถึงตอนนั้น
- ถ้าไม่ใส่ # เลย ระบบใช้เลขรัน 4 หลัก
- ถ้าบันทึกแล้วขึ้นว่าเลขที่เอกสารซ้ำ ดู [[ts-common-duplicate-doc-no]]
- ไม่มีสิทธิ์: ดู [[ts-common-no-permission]]
