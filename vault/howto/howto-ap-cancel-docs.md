# ยกเลิกเอกสารเจ้าหนี้ (ตั้งหนี้อื่น วางบิล จ่ายชำระ)

**ใช้เมื่อ:** บันทึกใบจ่ายชำระ ใบรับวางบิล หรือใบตั้งหนี้อื่นๆ ผิด และต้องการเก็บประวัติไว้ แทนการลบ
**เมนู:** เจ้าหนี้ › ยกเลิกเอกสารเจ้าหนี้ (ตั้งหนี้อื่น/วางบิล/จ่ายชำระ) › เลือกเมนูยกเลิกตามชนิดเอกสาร
**ต้องมีก่อน:** สิทธิ์ใช้เมนูยกเลิก และงวดบัญชียังไม่ปิด

## เมนูยกเลิกที่มี
| เอกสารเดิม | เมนูยกเลิก |
|---|---|
| ตั้งหนี้อื่นๆ (เจ้าหนี้) | ยกเลิกตั้งหนี้อื่นๆ (เจ้าหนี้) |
| เพิ่มหนี้อื่นๆ (เจ้าหนี้) | ยกเลิกเพิ่มหนี้อื่นๆ (เจ้าหนี้) |
| ลดหนี้อื่นๆ (เจ้าหนี้) | ยกเลิกลดหนี้อื่นๆ (เจ้าหนี้) |
| ใบรับวางบิล (เจ้าหนี้) | ยกเลิกใบรับวางบิล (เจ้าหนี้) |
| จ่ายชำระหนี้ (เจ้าหนี้) | ยกเลิกจ่ายชำระหนี้ (เจ้าหนี้) |

หนี้ยกมา (ตั้งหนี้ เพิ่มหนี้ ลดหนี้ยกมา) ไม่มีเมนูยกเลิก ให้แก้ไขหรือลบที่หน้าจอนั้น ([[howto-ap-opening-balance]]) ส่วนเอกสารซื้อ ยกเลิกที่ [[howto-buy-cancel-docs]]

## ขั้นตอน
1. เปิดเมนูยกเลิกของเอกสารชนิดนั้น
2. กดปุ่มค้นหาข้างช่องเลขที่อ้างอิง เลือกเอกสารที่จะยกเลิก
3. ตรวจรายละเอียด ใส่ "หมายเหตุ" เหตุผลการยกเลิก
4. กด "บันทึกยกเลิก" ระบบออกเลขที่ใบยกเลิกให้

## ลำดับการยกเลิก
ต้องยกเลิกจากปลายทางกลับมาต้นทาง
1. ยกเลิกใบจ่ายชำระหนี้ก่อน
2. แล้วจึงยกเลิกใบรับวางบิล (ถ้ามี)
3. แล้วจึงยกเลิกใบตั้งหนี้ หรือใบซื้อ

## บันทึกแล้วระบบทำอะไรให้
- เอกสารเดิมเปลี่ยนเป็นยกเลิก ไม่นับในยอดหนี้และรายงานอีก
- ยกเลิกใบจ่ายชำระ ยอดคงเหลือของบิลที่เคยจ่ายกลับมาค้างเหมือนเดิม ดึงไปจ่ายใหม่ได้
- ยกเลิกใบรับวางบิล บิลในใบนั้นกลับไปวางบิลใหม่ได้ ยอดหนี้ไม่เปลี่ยน
- เอกสารที่เคยลงบัญชี ระบบลงบัญชีกลับรายการ (สลับเดบิตกับเครดิต) ตามวันที่ของใบยกเลิก

## เปลี่ยนใจ (คืนสถานะ)
- เปิดเมนูยกเลิกเดิม เลือกเอกสารที่ยกเลิกไว้ กด "คืนสถานะเอกสารปกติ" ระบบลบใบยกเลิกและรายการกลับรายการออก

## ปัญหาที่พบบ่อย
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้" → มีเอกสารปลายทางใช้อยู่ เช่น บิลที่อยู่ในใบรับวางบิลหรือใบจ่ายชำระ หรือใบรับวางบิลที่ใบจ่ายชำระดึงไปจ่ายแล้ว ให้ยกเลิกเอกสารปลายทางนั้นก่อน ([[ts-buy-cancel-refused]])
- "เอกสาร ... ถูกยกเลิกแล้ว" → ยกเลิกไปแล้ว ไม่ต้องทำซ้ำ
- "... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี ..." → วันที่เอกสารเดิมหรือวันที่ยกเลิกอยู่ในงวดที่ปิด ([[ts-common-period-closed]])
