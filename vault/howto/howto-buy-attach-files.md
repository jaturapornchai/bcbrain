# แนบรูปภาพและไฟล์กับเอกสารซื้อและเอกสารเจ้าหนี้

**ใช้เมื่อ:** ต้องการเก็บรูปหรือไฟล์ของบิลผู้ขาย ใบกำกับภาษี ใบสั่งซื้อ หรือหลักฐานการจ่ายเงิน ไว้คู่กับเอกสารในระบบ
**เมนู:** ซื้อ › บันทึกรูปภาพและไฟล์แนบเอกสารซื้อ หรือ เจ้าหนี้ › บันทึกรูปภาพและไฟล์แนบเอกสารเจ้าหนี้
**ต้องมีก่อน:** เอกสารที่บันทึกแล้วในระบบ

## ขั้นตอน
1. เปิดเมนูตามงาน (ซื้อ หรือ เจ้าหนี้)
2. ช่อง "ประเภทเอกสาร" เลือกรหัสเอกสารที่ต้องการ
3. รายการด้านซ้ายแสดงเอกสารของประเภทนั้น ค้นหาด้วยเลขที่เอกสารได้ แล้วคลิกเลือก
4. กด "แก้ไข" (หรือดับเบิลคลิกที่เอกสาร) เพื่อเข้าโหมดแก้ไข
5. กด "เลือกรูป / ไฟล์แนบ" เลือกไฟล์จากเครื่อง ใส่ได้หลายไฟล์
6. กด "บันทึก" จะขึ้น "บันทึกรูปภาพและไฟล์แนบเอกสารแล้ว"

## ไฟล์ที่แนบได้
| เรื่อง | รายละเอียด |
|---|---|
| รูปภาพ | PNG, JPG, WEBP, GIF, BMP |
| เอกสาร | PDF, XLS, XLSX, CSV, DOC, DOCX, PPT, PPTX, TXT, ZIP |
| ขนาด | ไม่เกิน 25 MB ต่อไฟล์ |
| จำนวน | ไม่จำกัดจำนวนไฟล์ต่อเอกสาร |

## บันทึกแล้วระบบทำอะไรให้
- เก็บไฟล์ผูกกับเลขที่เอกสารนั้น เปิดดูได้จากเมนูเดียวกัน
- ไม่เปลี่ยนตัวเลข ยอดเงิน หรือการลงบัญชีของเอกสาร

## แก้ไข ยกเลิก พิมพ์
- ลบบางไฟล์: เข้า "แก้ไข" เอาไฟล์ที่ไม่ต้องการออก แล้ว "บันทึก"
- ปุ่ม "ลบ" ลบรูปและไฟล์แนบทั้งหมดของเอกสารนั้น (ตัวเอกสารยังอยู่)
- ต้องการแนบกับเอกสารอื่น ให้บันทึกหรือปิดโหมดแก้ไขก่อน

## ปัญหาที่พบบ่อย
- "มีรูปที่ยังไม่บันทึก กรุณาบันทึกหรือยกเลิกก่อนเปลี่ยนเอกสาร" → กด "บันทึก" หรือ "ปิดหน้าจอ" ก่อนเลือกเอกสารใหม่
- "ไฟล์ที่ ... ใหญ่เกิน 25 MB" → ย่อขนาดไฟล์หรือแยกไฟล์ก่อนแนบ
- "ไฟล์ที่ ... ไม่รองรับ (...)" → แปลงเป็นชนิดไฟล์ในตารางด้านบน
- "เลขที่เอกสารยาวเกิน 50 ตัวอักษร เก็บรูปไม่ได้" → ส่งต่อเจ้าหน้าที่
- "คุณไม่มีสิทธิ์ ..." → [[ts-common-no-permission]]
- "ไฟล์แนบนี้ถูกเปลี่ยนโดยผู้ใช้อื่น ..." → มีคนอื่นแก้พร้อมกัน ให้เปิดรายการใหม่แล้วทำอีกครั้ง
