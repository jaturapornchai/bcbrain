# ตั้งบาร์โค้ดสินค้า และเพิ่มบาร์โค้ดแบบเร็ว

**ใช้เมื่อ:** อยากยิงบาร์โค้ดแล้วเจอสินค้าทันทีในบิลหรือหน้าขาย หรือขายหน่วยต่างกันด้วยบาร์โค้ดต่างกัน
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › กำหนดบาร์โค้ดสินค้า / เพิ่มบาร์โค๊ดสินค้าแบบเร็ว / กำหนดรูปภาพตามบาร์โค้ด
**ต้องมีก่อน:** ข้อมูลสินค้าและหน่วยนับ ([[howto-stock-item-master]], [[howto-stock-units]])

## ขั้นตอน (กำหนดบาร์โค้ดสินค้า)
1. เลือกสินค้า
2. เพิ่มแถวบาร์โค้ด ใส่เลขบาร์โค้ดและหน่วยนับ (1 บาร์โค้ดต่อ 1 หน่วย)
3. ถ้ายังไม่มีเลข กด "+ สร้างบาร์โค้ด 13 หลัก (แถวล่าสุด)" ช่องตัวเลขนำหน้า ว่าง = สุ่มทั้งหมด, 2 = บาร์โค้ดใช้ภายในร้าน
4. ใส่ราคาตามบาร์โค้ดได้ (ราคากลุ่มที่ 1-4 แยก ทั่วไป/สมาชิก) แล้วบันทึก

## ขั้นตอน (เพิ่มบาร์โค๊ดสินค้าแบบเร็ว)
1. ยิงบาร์โค้ดหรือพิมพ์รหัสสินค้าในช่อง บาร์โค้ด/รหัสสินค้า แล้วกด Enter
2. ติ๊ก "หลังค้นหาให้ไปที่ตารางบาร์โค้ด (Barcode Auto Focus)" ถ้าอยากให้เคอร์เซอร์ไปที่ตารางเลย
3. ถ้าจะเพิ่มชั้นวางให้สินค้า กรอกช่อง Update Shelf และต้องเลือก คลัง/ที่เก็บ เริ่มต้น ด้วย ระบบเพิ่มค่านี้ต่อท้าย Shelf List ของคลัง/ที่เก็บนั้น
4. บันทึก ขึ้น "บันทึกเรียบร้อย ยิงบาร์โค้ดถัดไปได้เลย" ยิงตัวต่อไปได้ทันที

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| บาร์โค้ด | เลขบาร์โค้ด | ไม่เกิน 50 ตัวอักษร ห้ามซ้ำกับสินค้าอื่น |
| หน่วยนับ | หน่วยที่บาร์โค้ดนี้แทน | ยิงแล้วบิลจะใช้หน่วยนี้ |
| ราคากลุ่มที่ 1-4 (ทั่วไป/สมาชิก) | ราคาขายตามบาร์โค้ด | บิลดึงเฉพาะ ราคากลุ่มที่ 1 ช่อง ทั่วไป และใช้เมื่อไม่มีราคาแบบอื่นที่ตรงกว่า ([[faq-stock-which-price]]) ราคาที่ 1-4 ใช้ตอนพิมพ์ฉลากได้ |
| ไม่แสดง, ไม่สะสมแต้ม, ลดล้างสต๊อก | ตัวเลือกของบาร์โค้ดนั้น | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล |
| จากวันที่ / ถึงวันที่ | ช่วงวันที่ของบาร์โค้ด | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ราคาตามบาร์โค้ดใช้ได้ทุกวัน |

## บันทึกแล้วระบบทำอะไรให้
- ยิงบาร์โค้ดในบิลขาย/ซื้อ ได้สินค้าและหน่วยตามที่ผูกไว้
- กำหนดรูปภาพตามบาร์โค้ด: ใส่รูปแยกตามบาร์โค้ด (เช่น สีต่างกัน)

## แก้ไข ยกเลิก พิมพ์
- แก้หรือลบแถวบาร์โค้ดแล้วบันทึกใหม่
- พิมพ์ฉลากบาร์โค้ด และตรวจบาร์โค้ดผิดมาตรฐาน ดู [[howto-stock-barcode-check-print]]

## ปัญหาที่พบบ่อย
- "บาร์โค้ด ... ถูกใช้แล้วกับสินค้า ..." → ([[ts-stock-barcode-duplicate]])
- "บาร์โค้ดซ้ำ: ..." → ([[ts-stock-barcode-duplicate]])
- "บาร์โค้ดยาวเกิน 50 ตัวอักษร: ..." → ตัดเลขให้สั้นลง
- "ระบุ Update Shelf แล้ว ต้องเลือกคลัง/ที่เก็บเริ่มต้นก่อน" → เลือก คลัง/ที่เก็บ เริ่มต้น ก่อนบันทึก
- "กรุณาเลือกสินค้า" / "ไม่พบสินค้า ..." → เลือกสินค้าที่มีอยู่จริงก่อนเพิ่มบาร์โค้ด
