# ตั้งสินค้าชุด (ขายเป็นชุด ตัดสต็อกตามชิ้นส่วน)

**ใช้เมื่อ:** ขายสินค้าหลายตัวรวมเป็น 1 ชุด เช่น กระเช้า ชุดของขวัญ แล้วอยากให้สต็อกของแต่ละชิ้นลดลงเอง
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › สินค้าชุด
**ต้องมีก่อน:** สร้างรหัสชุดในข้อมูลสินค้า โดยเลือก ประเภทสินค้า = 4.สินค้าชุด และสร้างสินค้าชิ้นส่วนทุกตัวไว้แล้ว ([[howto-stock-item-master]])

## ขั้นตอน
1. เปิดเมนู สินค้าชุด แล้วเลือกรหัสสินค้าชุด
2. ในตาราง รายการสินค้าในชุด เพิ่มชิ้นส่วนทีละแถว
3. กรอกจำนวนต่อ 1 ชุด และราคาของชิ้นส่วน แล้วบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสสินค้า / บาร์โค้ด | ชิ้นส่วนในชุด | ต้องเป็นสินค้าที่มีอยู่แล้ว |
| หน่วยนับ | หน่วยของชิ้นส่วน | ระบบคิดอัตราส่วนตามหน่วยของชิ้นส่วนนั้น |
| จำนวน | จำนวนต่อ 1 ชุด | ต้องมากกว่า 0 |
| ราคา | ราคาของชิ้นส่วน | |
| มูลค่า / อัตราส่วนราคา | ระบบคิดให้ตอนบันทึก | มูลค่า = จำนวน x ราคา อัตราส่วนราคาใช้แบ่งราคาชุดลงชิ้นส่วน ค่าที่พิมพ์เองจะถูกคิดใหม่ |

## บันทึกแล้วระบบทำอะไรให้
- เมื่อใส่รหัสชุดใน ใบเสนอราคาขาย ใบสั่งจองสินค้า ใบสั่งขายสินค้า ขายสินค้า/บริการ เพิ่มหนี้ขาย ขอเบิก เบิก และรับคืนจากการเบิก ระบบแตกแถวชิ้นส่วนให้ใต้แถวชุด
- แก้จำนวนชุด ระบบปรับจำนวนชิ้นส่วนตามให้ และมูลค่าแถวชุด = ผลรวมของชิ้นส่วน
- **สต็อกตัดที่ชิ้นส่วนเท่านั้น** ตัวชุดเองไม่มียอดคงเหลือ
- สินค้าประเภท 6.สูตรสี ทำงานแบบเดียวกัน (แตกแถวตามสูตร)

## แก้ไข ยกเลิก พิมพ์
- แก้ชิ้นส่วนในเมนู สินค้าชุด แล้วบันทึก มีผลกับบิลที่เปิดใหม่หลังจากนั้น
- ลบแถวชุดใน ใบเสนอราคาขาย ใบสั่งจองสินค้า ใบสั่งขายสินค้า ขายสินค้า/บริการ หรือเพิ่มหนี้ขาย แถวชิ้นส่วนที่ผูกกับชุดนั้นจะหายไปด้วย
- ใน ขอเบิก เบิก และรับคืนจากการเบิก ลบแถวชุดแล้วแถวชิ้นส่วนยังอยู่ ต้องลบแถวชิ้นส่วนเอง

## ปัญหาที่พบบ่อย
- "แถวที่ ...: สินค้าชุดห้ามมีตัวเองเป็นส่วนประกอบ" → เอารหัสชุดตัวเองออกจากรายการชิ้นส่วน
- "แถวที่ ...: จำนวนต้องมากกว่า 0" → ใส่จำนวนต่อ 1 ชุดให้มากกว่า 0
- รายงานยอดคงเหลือไม่มีรหัสชุด → ปกติ เพราะชุดไม่เก็บสต็อก ดูยอดที่ชิ้นส่วน ([[faq-stock-service-not-in-stock]])
- รายงานกำไรขั้นต้นไม่แสดงสินค้าชุด → รายงานกำไรตัดสินค้าชุดและสูตรสีออก ([[howto-stock-inquiry-profit]])
