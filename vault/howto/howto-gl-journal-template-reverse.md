# ต้นแบบรายการรายวันประจำ และกลับรายการอัตโนมัติ (Auto-Reverse)

**ใช้เมื่อ:** มีรายการบัญชีที่ลงซ้ำทุกเดือน (เช่น ค่าน้ำค่าไฟค้างจ่าย ค่าเสื่อมราคา) หรือต้องการกลับรายการปรับปรุงในต้นเดือนถัดไป (กลับรายการ = ลงบัญชีสลับเดบิต/เครดิตเพื่อล้างรายการเดิม)
**เมนู:** บัญชี › ข้อมูลรายวัน › แถบต้นแบบด้านบนตารางรายการบัญชี
**ต้องมีก่อน:** [[howto-gl-journal-entry]]

## ขั้นตอน
**ใช้ต้นแบบ**
1. เพิ่มใบสำคัญใหม่ ที่ช่อง "-- เลือกต้นแบบรายการรายวันประจำ --" เลือกต้นแบบ
2. ระบบเติมสมุดรายวัน คำอธิบาย และรหัสบัญชีแต่ละบรรทัดให้
3. กรอกจำนวนเงินเดบิต/เครดิตเอง แล้วบันทึก

**สร้างต้นแบบของกิจการ**
1. กรอกรายการบัญชีในตารางให้เรียบร้อย
2. กด "สร้างต้นแบบ" (ปุ่มนี้ขึ้นเฉพาะตอนกำลังเพิ่มหรือแก้ไขใบสำคัญ) กรอก "รหัสต้นแบบ (Code)" และ "คำอธิบายต้นแบบ (Description)" แล้วกด "บันทึกต้นแบบ"
3. ลบต้นแบบที่ไม่ใช้: เลือกต้นแบบแล้วกด "ลบต้นแบบ"

**กลับรายการอัตโนมัติ**
1. เปิดใบสำคัญเดิมที่บันทึกแล้ว (เช่น ค่าใช้จ่ายค้างจ่ายสิ้นเดือน)
2. กด "กลับรายการอัตโนมัติ (Auto-Reverse)"
3. ระบบเปิดใบสำคัญใหม่ให้ วันที่เป็นวันที่ 1 ของเดือนถัดไป สลับยอดเดบิตกับเครดิตทุกบรรทัด และใส่คำอธิบาย "กลับรายการอัตโนมัติจาก ..." ตามด้วยเลขที่เดิม
4. ใส่เลขที่เอกสารใหม่ ตรวจแล้วกดบันทึก (ระบบยังไม่บันทึกจนกว่าจะกดบันทึกเอง)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสต้นแบบ | รหัสสั้นๆ | ตอนสร้างต้นแบบ |
| คำอธิบายต้นแบบ | ชื่อที่จะเห็นในรายการเลือก | |
| เดบิต / เครดิต | ยอดของเดือนนี้ | ต้นแบบไม่เก็บยอดเงิน ต้องกรอกทุกครั้ง |

## บันทึกแล้วระบบทำอะไรให้
- ต้นแบบมี 2 กลุ่ม: "ต้นแบบของกิจการ" (ที่กิจการสร้างเอง) และ "แม่แบบปรับปรุงบัญชีมาตรฐานรายเดือน (TFRS)" ที่มากับระบบ 5 แบบ ได้แก่ "ตั้งค่าน้ำ-ค่าไฟ-ค่าโทรศัพท์ค้างจ่ายสิ้นเดือน", "บันทึกเงินเดือน ประกันสังคม และภาษีหัก ณ ที่จ่าย (ภ.ง.ด.1)", "ตัดจ่ายค่าใช้จ่ายจ่ายล่วงหน้ารายเดือน (ค่าเช่า/ประกันภัย)", "บันทึกค่าเสื่อมราคาสินทรัพย์ถาวรประจำเดือน", "ปิดบัญชีภาษีซื้อ-ภาษีขายประจำเดือน (ภ.พ.30)" (แม่แบบที่มากับระบบลบไม่ได้)
- แม่แบบมาตรฐานใช้รหัสบัญชีตามผังบัญชีมาตรฐานของระบบ ถ้ากิจการเปลี่ยนรหัสผังเอง ต้องแก้รหัสบัญชีในใบสำคัญก่อนบันทึก

## แก้ไข ยกเลิก พิมพ์
- ใบกลับรายการเป็นใบสำคัญธรรมดา แก้/ลบ/พิมพ์ ได้เหมือนข้อมูลรายวันทั่วไป
- ถ้ากดกลับรายการระหว่างแก้ไขใบเดิม ระบบสลับเดบิต/เครดิตในใบนั้นเลย (ไม่เปิดใบใหม่) ระวังกดผิด

## ปัญหาที่พบบ่อย
- ปุ่มกลับรายการกดไม่ได้ → ตารางยังไม่มีรายการบัญชี หรือผู้ใช้ไม่มีสิทธิ์เพิ่มเอกสาร ([[ts-common-no-permission]])
- วันที่ 1 ของเดือนถัดไปอยู่ในงวดที่ยังไม่ได้สร้าง → บันทึกไม่ได้ ([[howto-gl-account-period]])
