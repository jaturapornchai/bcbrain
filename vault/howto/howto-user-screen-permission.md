# กำหนดสิทธิ์ว่าผู้ใช้แต่ละคนเปิดหน้าจอไหนได้

**ใช้เมื่อ:** ต้องการจำกัดให้ผู้ใช้ระดับ Member เห็นเฉพาะเมนูที่เกี่ยวกับงาน เช่น พนักงานขายเปิดได้แค่เมนูขาย หรือให้ดูได้อย่างเดียวห้ามลบ
**เมนู:** หน้าเลือกฐานข้อมูล › การ์ดฐานข้อมูลของบริษัท › ปุ่ม "สมาชิก & สิทธิ์จอ" › แท็บ "กำหนดสิทธิ์การใช้หน้าจอของ Member (อ่าน/เพิ่ม/แก้ไข/ลบ)" (หรือกด "กำหนดสิทธิ์จอ" ที่แถวของสมาชิกในแท็บแรก)
**ต้องมีก่อน:** คุณเป็น Admin ของฐานข้อมูล และเพิ่มสมาชิกพร้อมผูกรหัสผู้ใช้ไว้แล้ว ดู [[howto-user-invite-member]]

## ขั้นตอน
1. เปิด "สมาชิก & สิทธิ์จอ" แล้วไปแท็บกำหนดสิทธิ์การใช้หน้าจอ หรือกด "กำหนดสิทธิ์จอ" ที่แถวของสมาชิกคนนั้น
2. เลือก "รหัสผู้ใช้ (Member User):" ที่จะกำหนดสิทธิ์
3. เลือก "หมวดเมนู:" หรือพิมพ์ชื่อจอในช่อง "ค้นหาชื่อจอ / รหัสเมนู..." เพื่อหาหน้าจอที่ต้องการ
4. ติ๊กสิทธิ์ของแต่ละหน้าจอ: อ่าน (เปิดจอ) / เพิ่ม / แก้ไข / ลบ
5. หรือใช้ปุ่มลัด "เปิดครบทุกสิทธิ์", "เฉพาะอ่านอย่างเดียว", "ล้างทั้งหมด" ปุ่มเหล่านี้มีผลเฉพาะหน้าจอที่กำลังแสดงตามหมวดหรือคำค้น
6. กด "บันทึกสิทธิ์การใช้จอ" ระบบขึ้น "บันทึกการ Map สิทธิ์หน้าจอของ User "..." จำนวน ... หน้าจอเรียบร้อยแล้ว!"
7. ให้ผู้ใช้คนนั้นรีเฟรชหน้าเว็บ หรือออกจากฐานข้อมูลแล้วเข้าใหม่ เพื่อให้เมนูอัปเดตตามสิทธิ์ใหม่

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| อ่าน (เปิดจอ) | ติ๊กเมื่อให้เปิดหน้าจอนี้ได้ | ไม่ติ๊ก = ไม่เห็นหรือเปิดหน้าจอนี้ไม่ได้ |
| เพิ่ม | ติ๊กเมื่อให้สร้างรายการใหม่ได้ | |
| แก้ไข | ติ๊กเมื่อให้แก้ไขรายการเดิมได้ | |
| ลบ | ติ๊กเมื่อให้ลบรายการได้ | ไม่ติ๊กสำหรับพนักงานทั่วไปเพื่อกันลบเอกสารผิด |

## บันทึกแล้วระบบทำอะไรให้
- ผู้ใช้ Member จะเห็นและใช้ได้เฉพาะหน้าจอที่ได้รับสิทธิ์ ปุ่มเพิ่ม แก้ไข ลบ จะใช้ได้ตามที่ติ๊ก
- สิทธิ์ผูกกับรหัสผู้ใช้ ถ้าหลายอีเมลผูกกับรหัสเดียวกัน จะได้สิทธิ์ชุดเดียวกัน
- ถ้ารหัสผู้ใช้อยู่ในกลุ่มผู้ใช้ ระบบรวมสิทธิ์ของกลุ่มเข้ามาด้วย ดู [[howto-setup-user-group]]
- Admin ใช้ได้ทุกหน้าจอเสมอ ไม่ต้องกำหนดสิทธิ์

## แก้ไข ยกเลิก พิมพ์
- แก้สิทธิ์ได้ตลอด เปิดหน้านี้ ติ๊กใหม่ แล้วกด "บันทึกสิทธิ์การใช้จอ" อีกครั้ง
- ถอนสิทธิ์ทั้งหมดของคนที่ลาออก ใช้วิธีลบสมาชิก ดู [[howto-user-invite-member]]

## ปัญหาที่พบบ่อย
- หน้าจอสำหรับ Admin เท่านั้น (เช่น ตั้งค่ากิจการ งวดบัญชี สำรองข้อมูล เปลี่ยนรหัส ตรวจสอบ ประมวลผลสิ้นงวด) ติ๊กให้ Member ไม่ได้ ระบบตั้งเป็นไม่มีสิทธิ์ให้เสมอ ถ้าจำเป็นต้องใช้ ต้องเปลี่ยนคนนั้นเป็น Admin
- ผู้ใช้แจ้งว่า "คุณไม่มีสิทธิ์ ..." หรือปุ่มบันทึกกดไม่ได้ ดู [[ts-common-no-permission]]
- ขึ้น "บันทึกสิทธิ์การใช้หน้าจอไม่สำเร็จ" ให้ลองใหม่อีกครั้ง ถ้ายังไม่ได้ให้แจ้งทีมงาน
