# แนบรูปภาพและไฟล์ให้เอกสารเงินสด/ธนาคาร

**ใช้เมื่อ:** ต้องการเก็บหลักฐานไว้กับเอกสาร เช่น สลิปโอนเงิน รูปเช็ค ใบเสร็จค่าใช้จ่าย
**เมนู:** เงินสด/ธนาคาร › บันทึกรูปภาพและไฟล์แนบเอกสาร
**ต้องมีก่อน:** เอกสารที่บันทึกไว้แล้ว

## ขั้นตอน
1. เปิดเมนู จะเห็นข้อความ "เลือกประเภทเอกสารด้านซ้ายก่อน" ให้เลือกประเภทเอกสาร
2. เลือกเอกสารจากรายการด้านซ้าย ("เลือกเอกสารจากรายการด้านซ้าย") แล้วกด "แก้ไข" (หรือดับเบิลคลิกที่เอกสาร) จอขึ้น "โหมดแก้ไข"
3. กดปุ่ม "เลือกรูป / ไฟล์แนบ" แล้วเลือกรูปหรือไฟล์ รองรับไฟล์ PDF, XLS, XLSX, CSV, DOC, ZIP และรูปภาพ
4. กด "บันทึก" ระบบแจ้ง "บันทึกรูปภาพและไฟล์แนบเอกสารแล้ว"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทเอกสาร | ชนิดเอกสาร | เลือกทางซ้าย |
| เอกสาร | ใบที่ต้องการแนบ | |
| รูป / ไฟล์ | ไฟล์หลักฐาน | แนบได้หลายไฟล์ |

## บันทึกแล้วระบบทำอะไรให้
- เก็บรูปและไฟล์ไว้กับเอกสารนั้น เปิดดูภายหลังได้จากหน้าจอเดียวกัน
- ไม่กระทบยอดเงินหรือการลงบัญชี

## แก้ไข ยกเลิก พิมพ์
- เปิดเอกสารเดิมเพื่อเพิ่มหรือลบไฟล์แล้วบันทึกใหม่

## ปัญหาที่พบบ่อย
- "มีรูปที่ยังไม่บันทึก กรุณาบันทึกหรือยกเลิกก่อน" → กดบันทึกหรือยกเลิกรูปที่เพิ่งเลือก ก่อนเปลี่ยนไปเอกสารอื่น
- "เอกสารนี้ยังไม่มีรูปภาพหรือไฟล์แนบ" → ยังไม่เคยแนบ ให้กด เลือกรูป / ไฟล์แนบ
