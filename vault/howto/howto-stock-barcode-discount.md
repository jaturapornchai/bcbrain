# กำหนดส่วนลดตามบาร์โค้ด (และข้อจำกัด)

**ใช้เมื่อ:** อยากเก็บตารางส่วนลดของบาร์โค้ดแต่ละตัว เช่น ลดเฉพาะวัน ลดเฉพาะสมาชิก ลดพนักงาน
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › กำหนดส่วนลดตามบาร์โค๊ด / กำหนดส่วนลดตามบาร์โค๊ด (เร็ว)
**ต้องมีก่อน:** บาร์โค้ดของสินค้า ([[howto-stock-barcode]])

> **ข้อจำกัดสำคัญ (บอกลูกค้าตรงๆ):** ตอนนี้ระบบบัญชีบนเว็บเก็บข้อมูลส่วนลดตามบาร์โค้ดไว้เท่านั้น ยังไม่พบว่าบิลขายดึงส่วนลดนี้ไปใช้อัตโนมัติ ถ้าลูกค้าต้องการส่วนลดที่ขึ้นในบิลขาย ให้ใช้ กำหนดส่วนลดสินค้า ([[howto-stock-sale-price]]) แทน

## ขั้นตอน
1. เลือกบาร์โค้ด (เมนูแบบเร็ว: ยิงบาร์โค้ดแล้วทำต่อได้ทันที)
2. ใส่ส่วนลดในตารางตามประเภท ซึ่งแยกเป็น ลดพิเศษทั่วไป / ลดพิเศษสมาชิก / ลดโปรโมชั่น / ลดสมาชิก / ลดพนักงาน
3. ใส่ส่วนลด เช่น 5% หรือ 10 (บาท)
4. กำหนดเงื่อนไข: เฉพาะวัน (ทุกวัน หรือ เลือกวัน) จากจำนวน/ถึงจำนวน จากวันที่/ถึงวันที่
5. ช่อง แบบเฉพาะ เลือก ทุกเครื่องในระบบ หรือ เฉพาะรหัสเครื่อง POS (แล้วใส่ รหัสเครื่อง POS) แล้วบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ส่วนลด | เช่น 5% หรือ 10 | ใส่ % ถ้าเป็นเปอร์เซ็นต์ |
| เฉพาะวัน | ทุกวัน หรือ เลือกวันในสัปดาห์ | |
| จากจำนวน / ถึงจำนวน | ช่วงจำนวนที่ซื้อ | |
| จากวันที่ / ถึงวันที่ | ช่วงเวลาโปร | |
| แบบเฉพาะ / รหัสเครื่อง POS | ทุกเครื่องในระบบ หรือ เฉพาะรหัสเครื่อง POS | |

## บันทึกแล้วระบบทำอะไรให้
- เก็บตารางส่วนลดไว้ในระบบ (ดูข้อจำกัดด้านบน)
