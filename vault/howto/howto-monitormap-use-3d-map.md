# วิธีใช้หน้าจอ 3D Monitor TV

**ใช้เมื่อ:** จะเปิดแผนที่ 3 มิติโชว์บนทีวี หรืออยากเปลี่ยนมุมมอง
**เมนู:** แถบระบบด้านบน › ระบบ 3D Monitor TV
**ต้องมีก่อน:** เข้าสู่ระบบและเลือกฐานข้อมูลแล้ว ภาพรวมที่ [[sys-monitormap-overview]]

## ขั้นตอน
1. เปิดหน้าจอ แล้วรอให้แผนที่โหลดภาพ
2. เปลี่ยนรูปแบบแผนที่: กดปุ่มสลับรูปแบบแผนที่ (ดาวเทียม+ถนน / แผนที่ถนน / ดาวเทียมล้วน)
3. เปลี่ยนมุมกล้อง: ปุ่มด้านล่างจอ "ทั้งประเทศ" "เกาะติดรถ" "คลังสินค้า" "จุดส่ง POS" "เจ้าพระยา" "สุ่มซูมจุดสำคัญ"
4. ซูม: ปุ่ม "ซูมเข้า" "ซูมออก" และ "ทิศเหนือ" (หมุนให้ทิศเหนืออยู่ด้านบน)
5. ดูรายละเอียดจุดหนึ่ง: คลิกที่รายการใน "รายการจุดบนแผนที่ (คลิกเพื่อซูม)" (แท็บ "รถ" "คลัง" "จุดส่ง") มีปุ่ม "จุดก่อนหน้า" "จุดถัดไป" และ "ซูมดูพิกัด"
6. ดูแจ้งเตือน: กดปุ่ม "แจ้งเตือน"
7. ปุ่ม "ซิงค์" ในรายการ ใช้โหลดข้อมูลสดใหม่
8. ปุ่ม "เต็มหน้าจอ" ใช้ขยายเต็มจอทีวี

## คีย์ลัด (ใช้ได้เมื่อไม่ได้พิมพ์ในช่องกรอก)
| ปุ่ม | ทำอะไร |
|---|---|
| 1 | มองทั้งประเทศ |
| 2 | เกาะติดรถคันแรก |
| 3 | ซูมคลังแรก |
| 4 | ซูมจุดลูกค้าแรก |
| 5 | มุมแม่น้ำเจ้าพระยา |
| เว้นวรรค | สุ่มตัดภาพไปจุดสำคัญ |
| + หรือ = / - | ซูมเข้า / ซูมออก |
| ลูกศร หรือ W A S D | เลื่อนแผนที่ |
| H | ซ่อน/แสดงแผงทั้งหมด |
| M | เปิด/ปิดเสียงบรรยาย |

## เสียงบรรยาย
ปุ่มลำโพงมีคำอธิบาย "ปิดเสียงบรรยาย" หรือ "เปิดเสียงบรรยาย" ระบบพยายามเลือกเสียงภาษาไทยของเครื่อง ถ้าเครื่องไม่มีเสียงไทยจะไม่มีเสียงหรือเสียงเพี้ยน ให้ติดตั้งเสียงไทยในเครื่องหรือปิดเสียง

## ปล่อยรถด่วน
ปุ่ม "ปล่อยรถด่วน" (คำอธิบาย: "จำลองการปล่อยรถขนส่งด่วนบนแผนที่") เป็นการจำลองให้ดูบนจอ ไม่ได้ออกเอกสารขนส่งจริง และเมื่อกดจะบวกตัวเลขรายได้ เงินสด บนจอเพิ่มด้วยค่าสุ่ม (ตัวเลขนี้ไม่ใช่ยอดจริง) ระบบอาจเร่งความเร็วจำลองเป็น 3 เท่าอัตโนมัติ
