# ตรวจบาร์โค้ด EAN13 ตรวจจากไฟล์ และพิมพ์ฉลากบาร์โค้ด

**ใช้เมื่อ:** สแกนแล้วบาร์โค้ดอ่านไม่ได้ อยากหาบาร์โค้ดที่ไม่มีในระบบ หรืออยากพิมพ์สติกเกอร์บาร์โค้ดติดสินค้า
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ตรวจสอบบาร์โค๊ดตามมาตรฐาน EAN13 / ตรวจสอบบาร์โค๊ดจาก Text File / พิมพ์บาร์โค๊ดด้วยเครื่องพิมพ์ทั่วไป
**ต้องมีก่อน:** บาร์โค้ดในระบบ ([[howto-stock-barcode]])

## ตรวจสอบบาร์โค๊ดตามมาตรฐาน EAN13
1. กด เริ่มตรวจสอบ ระบบแจ้ง "พบบาร์โค้ดผิดมาตรฐาน EAN13 ... รายการ"
2. ถ้าต้องการเลขใหม่ ใส่ ตัวเลขนำหน้าบาร์โค้ดใหม่ (ตัวเลข 0-11 หลัก) แล้วกด สร้างบาร์โค้ดทดแทนทั้งหมด
3. ตรวจรายการ แล้วกด นำบาร์โค้ดใหม่ไปใช้แทน
- ข้อความที่อาจเจอ: "ตัวเลขนำหน้าต้องเป็นตัวเลข 0-11 หลัก", "บาร์โค้ด ... มีอยู่แล้ว กรุณาสร้างใหม่"
- ระวัง: บาร์โค้ดที่พิมพ์ติดสินค้าไปแล้วต้องพิมพ์ใหม่ทั้งหมดหลังเปลี่ยน

## ตรวจสอบบาร์โค๊ดจาก Text File
1. พิมพ์ในช่อง บาร์โค้ดที่ต้องการตรวจ (บรรทัดละ 1 ค่า) หรือกด นำเข้าไฟล์ (เช่น ไฟล์จากเครื่องเก็บข้อมูล)
2. กด ตรวจสอบ ระบบแสดงสินค้าและราคาของบาร์โค้ดที่พบ และแยกรายการบาร์โค้ดที่ไม่พบไว้ให้ หน้าจอนี้อ่านอย่างเดียว ไม่แก้ข้อมูล
- ตรวจได้ครั้งละไม่เกิน 2,000 บาร์โค้ด ข้อความ "ตรวจได้ครั้งละไม่เกิน ... บาร์โค้ด"
- ไม่ใส่อะไรเลยจะขึ้น "กรุณาป้อนหรือนำเข้าบาร์โค้ดก่อน"

## พิมพ์บาร์โค๊ดด้วยเครื่องพิมพ์ทั่วไป
1. คลิกบาร์โค้ดด้านซ้ายเพื่อเพิ่มลงตาราง รายการที่จะพิมพ์ แล้วใส่ จำนวนดวง หรือใส่เลขที่ในช่อง ดึงจากเอกสารกำหนดราคาเลขที่ แล้วกด นำเข้า
2. เลือก รูปแบบ (ค่าเริ่มต้น A4 14x5) หรือ กำหนดขนาดกระดาษเอง แล้ว บันทึกรูปแบบ ไว้ใช้ครั้งหน้า
3. ตั้ง เริ่มคอลัมน์ที่ / เริ่มแถวที่ (ใช้กระดาษสติกเกอร์ที่เหลือครึ่งแผ่นได้) หน่วยวัด เซนติเมตร หรือ นิ้ว
4. เลือก ราคาที่แสดง (ราคาที่ 1-4 หรือ ราคากลาง (สูตรราคา)) และติ๊ก แสดงราคา / รหัสสินค้า / ชื่อหน่วยนับ / พิมพ์เส้นขอบ
5. กด พิมพ์ ถ้าขึ้น "เบราว์เซอร์บล็อกหน้าต่างพิมพ์ กรุณาอนุญาต Pop-up" ให้อนุญาตป๊อปอัปของเว็บนี้ในเบราว์เซอร์

## เมนูที่ยังไม่ยืนยันการทำงาน
- กำหนดลำดับการค้นหา และ (เร็ว): เก็บระดับ 1-4 ราคาแนะนำ คำแนะนำ และเงื่อนไขต่อบาร์โค้ด ยังไม่ยืนยันว่าส่วนอื่นของระบบนำไปใช้อย่างไร ถ้าลูกค้าถาม ให้ส่งต่อเจ้าหน้าที่
