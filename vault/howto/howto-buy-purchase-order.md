# ทำใบสั่งซื้อ (PO) และอนุมัติใบสั่งซื้อ

**ใช้เมื่อ:** ตกลงซื้อกับผู้ขายแล้ว ต้องการออกใบสั่งซื้อส่งให้ผู้ขาย
**เมนู:** ซื้อ › ขอซื้อและสั่งซื้อ (PR / PO) › ใบสั่งซื้อสินค้า (PO) และ อนุมัติใบสั่งซื้อสินค้า
**ต้องมีก่อน:** รหัสเจ้าหนี้ (ผู้ขาย) และรหัสสินค้า ([[howto-ap-supplier]])

## ขั้นตอน
1. เปิดเมนู ใบสั่งซื้อสินค้า (PO) กด "เพิ่มใหม่"
2. กรอกวันที่เอกสาร เลขที่เอกสาร เลือกรหัสเจ้าหนี้ (บังคับ) และประเภทรายการ
3. ถ้ามีใบเสนอซื้อ กด "ดึงเอกสาร" ที่ช่องเอกสารอ้างอิง เลือกใบเสนอซื้อ ระบบจะดึงรายการมาให้ ([[howto-buy-reference-doc]])
4. ถ้าไม่มีใบเสนอซื้อ ใส่รายการสินค้า จำนวน ราคา เอง
5. ตรวจประเภทภาษีและยอดรวม แล้วกด "บันทึก"
6. ถ้ากิจการต้องอนุมัติใบสั่งซื้อ ผู้อนุมัติเปิดเมนู อนุมัติใบสั่งซื้อสินค้า กด "เลือกเอกสาร" แล้ว "บันทึกอนุมัติ"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสเจ้าหนี้ | ผู้ขาย | บังคับ |
| ประเภทรายการ | ซื้อสินค้าเงินเชื่อ / เงินสด / สินค้าบริการ | ส่งต่อไปเป็นค่าตั้งต้นของใบซื้อ |
| ภาษี: (ประเภทภาษี) | แยกนอก / รวมใน / ยกเว้นภาษี / ไม่กระทบภาษี | ใบซื้อที่ดึงใบนี้ต้องเลือกประเภทภาษีเดียวกัน |
| เอกสารอ้างอิง | ใบเสนอซื้อ หรือใบอนุมัติใบเสนอซื้อ | ไม่บังคับ ระบบไม่ได้บังคับว่าใบเสนอซื้อต้องอนุมัติก่อน |

## บันทึกแล้วระบบทำอะไรให้
- ใบสั่งซื้อ ไม่ลงบัญชี และไม่เพิ่มสต๊อก ([[faq-buy-when-stock-changes]])
- ใบสั่งซื้อจะค้างอยู่ในรายการให้ดึงไปทำ ใบซื้อ หรือ รับสินค้าตามใบสั่งซื้อ (ทะยอยรับ) จนกว่าจะรับครบ
- เอกสารจ่ายเงินมัดจำ/เงินล่วงหน้า บันทึกแยกต่างหาก หน้าจอนั้นไม่มีช่องอ้างอิงใบสั่งซื้อ ([[howto-buy-advance-deposit]])
- ถ้าเปิดข้อเลือก "อ้างอิงเอกสารสั่งซื้อที่อนุมัติแล้วเท่านั้น" ใบที่ยังไม่อนุมัติจะไม่ขึ้นให้ดึงไปทำใบซื้อ ([[howto-buy-options]])
- ตอนดึงใบเสนอซื้อ ใบที่บันทึกไม่อนุมัติหรือใช้ครบแล้วจะไม่ขึ้นในรายการ

## แก้ไข ยกเลิก พิมพ์
- ใบสั่งซื้อที่บันทึกอนุมัติแล้ว หรือถูกดึงไปทำใบซื้อ/รับสินค้าแล้ว แก้ไขหรือลบไม่ได้ ([[ts-buy-cannot-edit]])
- ใบที่รับสินค้าไปบางส่วน ยังยกเลิกส่วนที่ค้างได้ ใช้เมนู ยกเลิกใบสั่งซื้อสินค้า เลือก "ยกเลิกทั้งหมด" หรือ "ยกเลิกรายสินค้า" ([[howto-buy-cancel-docs]])
- พิมพ์ส่งผู้ขายด้วยปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"

## ปัญหาที่พบบ่อย
- "กรุณาป้อน รหัสเจ้าหนี้" → ยังไม่ได้เลือกผู้ขาย ([[ts-buy-supplier-required]])
- ใบเสนอซื้อไม่ขึ้นให้ดึง → ตรวจว่ายังไม่ถูกใช้ครบ และไม่ได้บันทึกไม่อนุมัติไว้ ([[ts-buy-ref-doc-not-listed]])
