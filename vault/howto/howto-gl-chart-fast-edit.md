# แก้ผังบัญชีหลายบัญชีพร้อมกัน และตรวจสอบโครงสร้างผังบัญชี

**ใช้เมื่อ:** ต้องแก้ข้อมูลบัญชีหลายตัวพร้อมกัน เช่น เปลี่ยนประเภทบัญชี สถานะบัญชี หรือเพิ่มบัญชีหลายตัวในครั้งเดียว
**เมนู:** บัญชี › ผังบัญชี (Chart of Accounts) › ปรับปรุงผังบัญชีแบบเร็ว / ตรวจสอบโครงสร้างผังบัญชี
**ต้องมีก่อน:** มีผังบัญชีแล้ว ([[howto-gl-chart-of-accounts]])

## ขั้นตอน (ปรับปรุงผังบัญชีแบบเร็ว)
1. เปิดเมนู ปรับปรุงผังบัญชีแบบเร็ว จะเห็นผังบัญชีเป็นตาราง (แท็บ ผังบัญชี)
2. แก้ค่าในแต่ละแถวได้โดยตรง คอลัมน์ที่มี: รหัสบัญชี, ชื่อบัญชี, ชื่อบัญชี (อังกฤษ), ผังบัญชีหลัก, สถานะบัญชี, ระดับบัญชี, ประเภทบัญชี, ประเภทภาษี, กลุ่มบัญชี, กลุ่มกระแสเงินสด, ปิดเข้าบัญชี, ด้านบัญชี, ผลกระทบงบ, ช่องติ๊กแยกมิติ, งานระหว่างทำ, ใช้งาน
3. จะเพิ่มบัญชีใหม่ พิมพ์ที่แถวว่างท้ายตาราง
4. กดบันทึก ระบบบันทึกเฉพาะแถวที่แก้หรือเพิ่ม

ความหมายของแต่ละช่องเหมือนหน้าจอ รายละเอียดผังบัญชี ช่องที่มีบนจอแต่รุ่นปัจจุบันยังไม่มีผลก็เหมือนกัน ([[howto-gl-chart-of-accounts]])

## ขั้นตอน (ตรวจสอบโครงสร้างผังบัญชี)
1. เปิดเมนู ตรวจสอบโครงสร้างผังบัญชี
2. ระบบแสดงรายการบัญชีเรียงตามรหัส พร้อมช่องค้นหา (ค้นได้ทั้งรหัสและชื่อ) และบอกจำนวน "ผังบัญชีที่ตรวจสอบ ... บัญชี"
3. ใช้ไล่ดูว่าบัญชีอยู่ระดับไหน สังกัดบัญชีหลักตัวไหน เป็นบัญชีหลักหรือบัญชีทั่วไป
4. ถ้าเจอบัญชีที่ต้องแก้ ให้ไปแก้ที่ ปรับปรุงผังบัญชีแบบเร็ว หรือ รายละเอียดผังบัญชี

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสบัญชี | ต้องมีทุกแถวที่แก้ | ห้ามแก้รหัสในแถวที่มีอยู่ ดูหัวข้อด้านล่าง |
| ชื่อบัญชี | ห้ามว่าง | |
| สถานะบัญชี | บัญชีทั่วไป / บัญชีหลัก | บัญชีที่ใช้บันทึกรายการต้องเป็นบัญชีทั่วไป |
| ประเภทบัญชี | สินทรัพย์ / หนี้สิน / ทุน / รายได้ / ค่าใช้จ่าย | มีผลกับรายงานและการปิดบัญชี |

## บันทึกแล้วระบบทำอะไรให้
- ค่าใหม่ใช้ทันทีกับการบันทึกและรายงานครั้งต่อไป
- แถวที่รหัสยังไม่มีในผัง ระบบเพิ่มเป็นบัญชีใหม่ให้

## แก้ไข ยกเลิก พิมพ์
- หน้าจอนี้ไม่ตรวจว่ารหัสในช่อง ผังบัญชีหลัก กลุ่มบัญชี กลุ่มกระแสเงินสด และ ปิดเข้าบัญชี มีอยู่จริง (ต่างจากหน้าจอ รายละเอียดผังบัญชี) ให้กดค้นหาเลือกจากรายการ อย่าพิมพ์เอง
- ถ้าแก้รหัสบัญชีในแถวที่มีอยู่ ระบบจะเพิ่มเป็นบัญชีใหม่ และบัญชีรหัสเดิมยังอยู่ ถ้าจะเปลี่ยนรหัสจริงใช้ [[howto-gl-change-account-code]]
- หน้าจอตรวจสอบโครงสร้างผังบัญชีแสดงได้สูงสุด 250 บัญชีต่อครั้ง ถ้าผังใหญ่กว่านั้นให้ใช้ช่องค้นหา

## ปัญหาที่พบบ่อย
- "แถวที่แก้ไขต้องมีรหัสบัญชี" → แถวที่แก้ยังไม่มีรหัสบัญชี ใส่รหัส หรือลบแถวนั้น
- "บัญชี ...: กรุณาระบุชื่อบัญชี" → ใส่ชื่อบัญชีในแถวที่บอก
- อื่นๆ ดู [[ts-gl-chart-save-errors]]
