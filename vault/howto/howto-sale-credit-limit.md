# ตั้งวงเงินเครดิตลูกค้า และให้ระบบเตือนหรือห้ามขายเกินวงเงิน

**ใช้เมื่อ:** อยากคุมไม่ให้ลูกค้าขายเชื่อ (ซื้อก่อนจ่ายทีหลัง) ค้างเงินเกินยอดที่ตกลงไว้ หรืออยากระงับการขายเชื่อลูกค้าบางราย
**เมนู:** ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › รายละเอียดลูกหนี้ (ส่วน "2. รายละเอียดและสินเชื่อ") และ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ (แท็บ "4.ระบบขาย")
**ต้องมีก่อน:** ทะเบียนลูกค้า ([[howto-ar-customer-register]])

## ขั้นตอน
1. เปิด "รายละเอียดลูกหนี้" เลือกลูกค้า ไปที่ "2. รายละเอียดและสินเชื่อ"
2. ใส่ "วงเงินสินเชื่อ :" (ยอดค้างสูงสุดที่ยอมให้) และ "จำนวนวันเครดิต :"
3. เลือก "สถานะสินเชื่อ :" เป็น เปิดวงเงิน / ปิดวงเงิน / หยุดขายชั่วคราว แล้วบันทึก
4. เปิดข้อเลือกในแท็บ "4.ระบบขาย" ตามที่ต้องการ (ตารางด้านล่าง)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| วงเงินสินเชื่อ : | ยอดหนี้ค้างสูงสุด | ใส่ 0 = ไม่ตรวจวงเงินตอนเปิดบิลขาย |
| จำนวนวันเครดิต : | จำนวนวันให้เครดิต | ใช้คำนวณวันครบกำหนด ([[faq-ar-credit-days]]) |
| สถานะสินเชื่อ : | เปิดวงเงิน / ปิดวงเงิน / หยุดขายชั่วคราว | ปิดวงเงินหรือหยุดขาย = ขายเชื่อไม่ได้ |
| วันที่ปิดวงเงิน : / เหตุผลในการระงับ : | วันที่และเหตุผลที่ระงับ | บันทึกไว้ดูย้อนหลัง |
| แจ้งเตือนเมื่อเกินวงเงินสินเชื่อ | ติ๊กเมื่อต้องการ | ดูข้อสังเกตด้านล่าง |

## ข้อเลือกในแท็บ "4.ระบบขาย" ที่เกี่ยวกับวงเงิน
| ข้อเลือก | ผล |
|---|---|
| เตือนเกินวงเงินเครดิต | ใบขายเกินวงเงิน ระบบถามก่อนบันทึก กดตกลงได้ |
| ห้ามขายเกินวงเงินเครดิต | ใบขายเกินวงเงิน บันทึกไม่ได้ |
| ใช้ระบบรหัสผ่านอนุมัติวงเงินเครดิต | ใช้คู่กับ "ห้ามขาย..." ให้ผู้มีสิทธิ์ใส่รหัสอนุมัติแล้วบันทึกต่อได้ |
| วงเงินเครดิตรวมเช็คคงค้าง | นับเช็ครับที่ยังไม่ผ่านเป็นหนี้ค้างด้วย |
| วงเงินเครดิตรวมรายการมัดจำ | เอาเงินมัดจำที่ลูกค้าวางไว้มาเพิ่มวงเงินให้ |
| ตรวจสอบวงเงินรวมรายการสั่งขาย/สั่งจอง | ตรวจวงเงินตั้งแต่ตอนออกใบสั่งจอง/ใบสั่งขาย ([[howto-sale-order]]) |
| สั่งจอง สั่งขาย เงินเชื่อตรวจสอบวงเงินลูกค้า | ใบสั่งที่เกินวงเงิน บันทึกไม่ได้เลย แทนการส่งรออนุมัติ |

## บันทึกแล้วระบบทำอะไรให้
- ตอนบันทึกใบขายประเภท "ขายเชื่อ (เครดิต)" และใบตั้งหนี้อื่นๆ ระบบเอายอดหนี้ค้างของลูกค้า (รวมเช็คค้าง/หักมัดจำ ตามข้อเลือก) บวกยอดบิลนี้ แล้วเทียบกับวงเงิน
- ใบขายแบบ "ขายสด" ไม่ถูกตรวจวงเงิน
- ลูกค้าสถานะ ปิดวงเงิน หรือ หยุดขายชั่วคราว → ขึ้น "ลูกค้า ... : ... ถูกปิดสถานะเครดิต" ([[ts-sale-credit-closed]])
- เปิด "ห้ามขาย..." คู่ "ใช้ระบบรหัสผ่านอนุมัติวงเงินเครดิต" → ขึ้นหน้าต่าง "ขออนุมัติวงเงินเครดิต" ให้ใส่ "รหัสผู้อนุมัติ" และ "รหัสผ่าน" แล้วกด "อนุมัติ"
- ผู้อนุมัติต้องมีสิทธิ์ "สามารถถอนอนุมัติวงเงินเครดิตลูกค้า" (ตั้งที่ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดพนักงาน ส่วน "สิทธิ์เอกสารและต้นทุน")

## แก้ไข ยกเลิก พิมพ์
- เปลี่ยนวงเงินหรือสถานะได้ทุกเมื่อที่รายละเอียดลูกหนี้ มีผลกับเอกสารที่บันทึกหลังจากนั้น
- ลูกค้าจ่ายหนี้แล้ว ([[howto-ar-receipt]]) ยอดค้างลด วงเงินที่เหลือเพิ่มเอง

## ปัญหาที่พบบ่อย
- "ยอดวงเงินเครดิตของลูกค้า เกินที่กำหนดไว้" → [[ts-sale-credit-over]]
- "ลูกค้า ... : ... ถูกปิดสถานะเครดิต" → [[ts-sale-credit-closed]]
- "เกินวงเงินเครดิตลูกค้า" ตอนออกใบสั่ง → [[ts-sale-order-credit-over]]
- "รหัสผู้อนุมัติหรือรหัสผ่านไม่ถูกต้อง" → ตรวจรหัสผู้อนุมัติ และสิทธิ์อนุมัติวงเงินของพนักงานคนนั้น
- **ข้อสังเกต:** ติ๊ก "แจ้งเตือนเมื่อเกินวงเงินสินเชื่อ" ที่ลูกค้าแล้ว ใบสั่งจอง/ใบสั่งขายที่เกินวงเงินจะถูกห้ามบันทึก ("เกินวงเงินเครดิต ไม่สามารถบันทึกเอกสารได้") ไม่ใช่แค่เตือน
- **ข้อจำกัด:** เปิด "ใช้ระบบขออนุมัติวงเงินเครดิต" (ขออนุมัติทางโทรศัพท์) แล้ว ใบขายที่เกินวงเงินจะบันทึกไม่ได้ เพราะขั้นตอนขออนุมัติแบบนี้ยังไม่มีในระบบ
- **ข้อจำกัด:** ข้อเลือก "ปิดสถานะเครดิตลูกหนี้อัตโนมัติ" ยังไม่มีผล ต้องเปลี่ยนสถานะสินเชื่อเอง
