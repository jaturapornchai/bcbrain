# กำหนดสูตรโปรโมชั่นขายหน้าร้าน POS

**ใช้เมื่อ:** ตั้งโปรลดแลกแจกแถมให้แอป POS คิดส่วนลดเองตอนขาย
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › กำหนดสูตรโปรโมชั่น (เปิดหน้าตั้งค่า POS แท็บโปรโมชั่น)
**ต้องมีก่อน:** สินค้าในทะเบียนสินค้า และสิทธิ์แก้ไขหน้าจอ POS

## รูปแบบโปรโมชั่นที่เลือกได้ (10 แบบ)
| รูปแบบ | ตัวอย่างที่หน้าจอบอก |
|---|---|
| ซื้อครบจำนวน แถมสินค้าฟรี | ซื้อน้ำดื่มแพ็คโหล 5 แพ็ค แถมฟรี 1 แพ็ค |
| ซื้อครบจำนวน ลดเป็นเงิน (บาท) | ปลากระป๋องคละรส 3 กระป๋อง ลดทันที 9 บาท |
| ซื้อครบจำนวน ลดเป็น % | ซื้อครบ 6 ชิ้น ลด 10% |
| ซื้อครบจำนวน ราคาเหมาชุดพิเศษ | น้ำมันพืช ซื้อ 3 ขวด เหลือชุดละ 150 บาท |
| ซื้อสินค้าครบยอดเงิน ลดค่าสินค้า | ซื้อเครื่องดื่มครบ 300 บาท ลด 25 บาท |
| ซื้อครบยอดเงิน แถมฟรีของสมนาคุณ | ซื้อครบ 1,000 บาท แถมฟรีน้ำปลา 1 ขวด |
| ซื้อครบยอดรวมทั้งบิล ลดท้ายบิล (บาท) | ครบ 500 บาท ลด 15 บาท / ครบ 1,500 บาท ลด 60 บาท |
| ส่วนลด % ท้ายบิล / สมาชิก VIP | สมาชิก VIP ครบ 3,000 บาท ลดเพิ่ม 5% |
| คูปองท้ายบิลสินค้า House Brand (HB) | พิมพ์คูปองส่วนลดท้ายบิลเมื่อซื้อสินค้าแบรนด์ร้านครบยอด |
| คูปองท้ายบิลตามแบรนด์/หมวดสินค้า | พิมพ์คูปองไว้ใช้บิลถัดไปเมื่อซื้อหมวดที่กำหนดครบยอด |

รายละเอียดว่าแอปแคชเชียร์คำนวณโปรอย่างไรดู [[sys-pos-overview]]

## ขั้นตอน
1. เปิดแท็บโปรโมชั่น กด **ล้างฟอร์มสร้างโปรใหม่** (หรือคลิกโปรเดิมในตารางเพื่อแก้) หรือเลือกจาก "เทมเพลตโปรโมชั่นสำเร็จรูป" ด้านบนเพื่อเติมค่าตัวอย่างลงฟอร์ม
   - ปุ่มนี้แค่ตั้งรหัสและชื่อใหม่ให้ และเปิดสถานะใช้งาน ช่องเงื่อนไขอื่นยังเป็นค่าของโปรที่เปิดค้างอยู่ ต้องตรวจทุกช่องก่อนบันทึก
2. กรอก "รหัสโปรโมชั่น" และ "ชื่อโปรโมชั่นที่แสดงบนจอแคชเชียร์ & ท้ายใบเสร็จ"
3. เลือก "รูปแบบโปรโมชั่น" แล้วกรอกเงื่อนไข เช่น "จำนวนซื้อขั้นต่ำ", "ยอดเงินซื้อขั้นต่ำ บาท", "ส่วนลด (%)", "จำนวนแถมฟรี (ชิ้น)"
4. เลือก "กลุ่มลูกค้าที่ได้รับสิทธิ์": ลูกค้าทุกคน / เฉพาะสมาชิกทุกระดับ / เฉพาะสมาชิก VIP หรือกลุ่มร้านค้าส่ง
5. เลือก "เงื่อนไขวันจัดรายการ": ทุกวัน / เฉพาะเสาร์-อาทิตย์ / วันหวยออก (วันที่ 1 และ 16) / ช่วงเงินเดือนออก (วันที่ 25 ถึง 5)
6. เลือก "ขอบเขตสินค้าที่ร่วมรายการ": ทั้งบิล / เฉพาะสินค้าที่ระบุ / เฉพาะหมวด / เฉพาะสินค้าแบรนด์ร้าน แล้วเลือกสินค้าหรือหมวด
7. ตั้ง "ช่วงเวลา Happy Hour (เริ่ม - สิ้นสุด)" ถ้าต้องการ (ค่าตั้งต้น 00:00 ถึง 23:59) หน้าจอนี้ไม่มีช่องให้เลือกวันเริ่มและวันสิ้นสุดของโปร
8. กด **บันทึก** ขึ้น "บันทึกโปรโมชั่น ... และซิงก์ไป BC Ai POS เรียบร้อยแล้ว"

## เปิด/ปิด/ลบโปร
- สลับสถานะในตาราง: ขึ้น "เปิดใช้งาน โปรโมชั่น ... เรียบร้อยแล้ว" หรือ "ระงับชั่วคราว โปรโมชั่น ... เรียบร้อยแล้ว" (ปิดโปรชั่วคราวโดยไม่ลบ)
- ลบ: ระบบถาม "มีข้อมูลที่ต้องลบจำนวน: 1 รายการ ต้องการลบ ... จริงหรือไม่" แล้วขึ้น "ลบโปรโมชั่น ... ออกจากระบบเรียบร้อยแล้ว"

## ข้อจำกัดบนหน้าจอ (พูดตรงๆ)
- รายการสินค้าให้เลือกในหน้านี้โหลดมาแค่ **60 รายการแรกเรียงตามรหัส** ถ้าร้านมีสินค้ามากกว่านั้นและสินค้าที่ต้องการไม่อยู่ในรายการ ให้ใช้ขอบเขต "ทั้งบิล" หรือแจ้งทีมงาน
- ตัวเลือกหมวดสินค้าในแบบฟอร์มเป็นตัวอย่างสามหมวดตายตัว (ของชำ เครื่องดื่ม ของใช้ในครัวเรือน) ไม่ได้ดึงจากทะเบียนหมวดสินค้าของบริษัท
- หน้าจอไม่มีช่องวันเริ่ม/สิ้นสุดของโปร โปรที่สร้างใหม่จะเริ่มวันที่บันทึกและสิ้นสุดสิ้นปีตามค่าตั้งต้นของฟอร์ม ถ้าต้องการช่วงวันที่เฉพาะ ให้ "ส่งต่อเจ้าหน้าที่"
- โปรโมชั่นที่ตั้งไว้ในโปรแกรมบัญชีเก่า (BC 5.5) ไม่ถูกนำเข้ามาอัตโนมัติ
- ส่วนลดถูกคิดที่เครื่อง POS ตอนขาย ระบบหลังบ้านรับบิลตามราคา/ส่วนลดที่เครื่องส่งมา ไม่คิดโปรใหม่
