# ตั้งค่าตัวเลือกระบบสินค้า (ห้ามติดลบ ทศนิยม LOT อัตโนมัติ)

**ใช้เมื่อ:** อยากกันไม่ให้ขาย/เบิก/โอนเกินของที่มี ตั้งจำนวนทศนิยม หรือเปิดการเลือก LOT อัตโนมัติ
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ › แท็บ 3.สินค้าคงคลัง และ 4.ระบบขาย
**ต้องมีก่อน:** สิทธิ์ผู้ดูแลระบบ ([[ts-common-no-permission]])

## ชุดห้ามสินค้าติดลบ (ต้องเปิดคู่กันให้ถูก)
| ตัวเลือก | อยู่แท็บ | ผล |
|---|---|---|
| ห้ามเบิกสินค้าติดลบ | 3.สินค้าคงคลัง | **สวิตช์หลัก** ปิดอยู่ = ไม่ตรวจติดลบเลยทุกเอกสาร เปิด = ใบเบิกถูกตรวจทันที |
| ห้ามขายสินค้าติดลบ | 4.ระบบขาย | เปิดคู่สวิตช์หลัก = ขายสินค้า/บริการ ถูกตรวจ |
| เตือนเมื่อสินค้าติดลบ | 3.สินค้าคงคลัง | เปิดคู่ ห้ามขายสินค้าติดลบ = ใบสั่งขายสินค้า และเพิ่มหนี้ขายถูกตรวจด้วย (ชื่อว่าเตือน แต่ระบบห้ามบันทึกจริง) |
| ห้ามโอนสินค้าติดลบ | 3.สินค้าคงคลัง | เปิดคู่ เตือนเมื่อสินค้าติดลบ = ใบโอนถูกตรวจ |
| ประเภทห้ามสินค้าติดลบ | 3.สินค้าคงคลัง | ทั้งระบบ / เฉพาะคลังสินค้า / เฉพาะที่เก็บสินค้า = ตรวจยอดรวม หรือแยกคลัง หรือแยกที่เก็บ |
| ห้ามขายสินค้าค้างจองทั้งระบบ, ใช้ระบบจองตามที่เก็บสินค้า | 4.ระบบขาย | บิลขายห้ามเกินยอดคงเหลือหักยอดในใบสั่งจองสินค้าที่ยังค้าง (ต้องเปิดสวิตช์หลักด้วย) |
| ห้ามขายสินค้าค้างส่งทั้งระบบ, ประเภทห้ามขายเกินค้างส่ง | 4.ระบบขาย | ห้ามเกินยอดคงเหลือหักยอดในใบสั่งขายสินค้าที่ยังไม่ส่ง ตรวจทั้ง บิลขาย ใบสั่งขาย เพิ่มหนี้ ใบเบิก และใบโอน (ต้องเปิดสวิตช์หลักด้วย) |

**ข้อควรรู้:** ระบบตรวจติดลบเฉพาะตอนสร้างเอกสารใหม่ ไม่ตรวจตอนแก้ไขเอกสารเดิม และไม่ตรวจใบปรับปรุงลด ดูรายละเอียด [[faq-stock-negative-allowed]]

## ตัวเลือกอื่นที่ใช้บ่อย
| ตัวเลือก | ผล |
|---|---|
| จุดทศนิยม (จำนวนสินค้า / ราคาสินค้า / มูลค่าสินค้า) | ต้นทุนเฉลี่ยปัดตามทศนิยมราคา มูลค่าต้นทุนปัดตามทศนิยมมูลค่า (ปัดครึ่งขึ้น) |
| ใช้ระบบค้นหา LOT อัตโนมัติ (4.ระบบขาย) | บิลขายเลือก LOT ให้เอง ([[howto-stock-lot]]) |
| ใช้คลังที่เก็บตามสิทธิ์พนักงาน | หน้าค้นหาแสดงเฉพาะคลังที่กลุ่มผู้ใช้มีสิทธิ์ (เรื่องคุมสิทธิ์การบันทึกตามคลัง ส่งต่อเจ้าหน้าที่) |
| เปิดใช้ทุกคลังที่เก็บสินค้า (1.ตั้งค่าระบบ) | สินค้าไม่ต้องผูกคลังทีละตัว |
| ห้ามขายสินค้าต่ำกว่าราคากลาง (4.ระบบขาย) | กันขายต่ำกว่าราคากลางในสูตรราคาขาย |
| ระบบเรียกราคาขายล่าสุด (4.ระบบขาย) | ไม่ใช้ / ราคาขายล่าสุด / ดึงราคาขายเฉลี่ย ของลูกค้ารายนั้น |
| ใช้ระบบต้นทุนแฝง | ใช้กับเมนูประมวลผลเฉลี่ยต้นทุนแฝง ([[howto-stock-hidden-cost]]) |

## ตัวเลือกที่ยังไม่มีผล (บอกลูกค้าตรงๆ)
- ใช้ต้นทุนแยกคลัง, ไม่คำนวณต้นทุนย้อนหลังกรณีสินค้าติดลบ, ปิดระบบคำนวณต้นทุนสินค้า: ตอนนี้เก็บค่าไว้ได้ แต่ยังไม่มีผลกับการคิดต้นทุน ระบบคิดต้นทุนเฉลี่ยรวมทุกคลังเสมอ
- การ Post บัญชีสินค้า (แบบ Periodic / แบบ Perpetual): มีผลกับการลงบัญชีเอกสารสินค้า ให้ปรึกษาทีมงานก่อนเปลี่ยน

## บันทึกแล้วระบบทำอะไรให้
- มีผลกับเอกสารที่บันทึกหลังจากนั้น เอกสารเดิมไม่ถูกตรวจย้อนหลัง
