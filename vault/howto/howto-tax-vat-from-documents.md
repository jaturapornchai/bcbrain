# ภาษีซื้อ ภาษีขาย จากเอกสารซื้อขาย เข้ารายงานภาษีอย่างไร

**ใช้เมื่อ:** ลูกค้าถามว่าเปิดใบกำกับภาษี/บันทึกซื้อแล้ว ภาษีไปขึ้นรายงานภาษีซื้อ-ภาษีขายเองไหม หรือมีใบกำกับภาษีหลายใบในเอกสารเดียว (ภาษีซื้อ = VAT ที่เราจ่ายตอนซื้อ, ภาษีขาย = VAT ที่เราเก็บจากลูกค้า)
**เมนู:** ในเอกสารซื้อ/ขาย/ลดหนี้/เพิ่มหนี้/รายได้-ค่าใช้จ่ายอื่น/มัดจำ › แท็บ "ภาษีมูลค่าเพิ่ม" หรือ "ข้อมูลภาษี (VAT/WHT)"
**ต้องมีก่อน:** ตั้งอัตราภาษีและกลุ่มภาษี ([[howto-tax-setup-tax-group]])

## ขั้นตอน
1. ที่หัวเอกสาร ช่อง "ภาษี:" เลือก แยกนอก, รวมใน, ยกเว้นภาษี หรือ ไม่กระทบภาษี
2. เอกสารซื้อ: กรอกเลขที่และวันที่ใบกำกับภาษีของผู้ขาย (ถ้าว่าง ระบบใช้เลขที่และวันที่ของเอกสาร)
3. บันทึกเอกสาร ระบบสร้างแถวภาษีจากหัวเอกสารให้เอง 1 แถว
4. ถ้าเอกสารเดียวมีใบกำกับภาษีหลายใบ ไปแท็บภาษี ติ๊ก "บันทึกภาษีซื้อเอง / หลายใบกำกับภาษี" (ฝั่งขายเป็น "บันทึกภาษีขายเอง / หลายใบกำกับภาษี") แล้วกด + เพิ่มบรรทัด ใส่ทีละใบ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ภาษี: (หัวเอกสาร) | แยกนอก / รวมใน / ยกเว้นภาษี / ไม่กระทบภาษี | ไม่กระทบภาษี = ไม่มีแถวภาษีเลย |
| เลขที่ใบกำกับ / วันที่ใบกำกับ | ตามใบกำกับภาษีจริง | วันที่นี้กำหนดเดือนภาษี |
| เดือนภาษี / ปีภาษี (ในแถวภาษี) | ถ้าว่าง ระบบใช้เดือน/ปีของวันที่ใบกำกับ | ใช้เมื่อยื่นต่างเดือน ([[faq-tax-vat-month]]) |

## บันทึกแล้วระบบทำอะไรให้
- แถวภาษีไปขึ้นใน รายงานภาษีซื้อ / รายงานภาษีขาย ตามเดือนภาษี ([[howto-tax-vat-report]])
- ถ้าไม่ได้ติ๊กบันทึกเอง ระบบคำนวณแถวภาษีใหม่จากหัวเอกสารทุกครั้งที่บันทึก (แก้ในแท็บภาษีแล้วจะถูกเขียนทับ)
- ถ้าติ๊กบันทึกเอง หรือมีมากกว่า 1 แถว ระบบเก็บตามที่กรอกไว้
- ภาษีลงบัญชีภาษีซื้อ/ภาษีขายอัตโนมัติ ([[howto-gl-auto-posting]])

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกเอกสาร แถวภาษียังอยู่ แต่ในรายงานภาษีแสดงยอดเป็น 0 พร้อมสถานะ ยกเลิก ([[faq-tax-cancelled-doc-in-report]])
- รายการขายที่เป็นสำเนาเอกสาร นับยอดเป็น 0 ในรายงานภาษีขาย

## ปัญหาที่พบบ่อย
- เอกสารไม่ขึ้นในรายงานภาษี → [[ts-tax-doc-not-in-vat-report]]
- เอกสารยกเว้นภาษี ไม่ขึ้นในรายงานภาษีขายปกติ → ใช้รายงานแบบ แสดงมูลค่าอัตราภาษีศูนย์
- เรื่องสิทธิ์ขอคืนภาษีซื้อ หรือเดือนที่ต้องยื่น ให้ปรึกษาผู้สอบบัญชี/สรรพากร
