# ทะเบียนเช็คจ่าย และบันทึกเช็คจ่ายยกมา

**ใช้เมื่อ:** ต้องการดูเช็คที่กิจการสั่งจ่ายผู้ขาย ว่าใบไหนธนาคารตัดเงินแล้ว หรือต้องบันทึกเช็คจ่ายที่ค้างอยู่ตอนเริ่มใช้โปรแกรม
**เมนู:** เงินสด/ธนาคาร › ทะเบียนเช็คจ่ายและจัดการเช็คจ่าย › ทะเบียนเช็คจ่าย / เช็คจ่ายยกมา
**ต้องมีก่อน:** สมุดเงินฝากที่ออกเช็ค ([[howto-bank-passbook]]) และรหัสเจ้าหนี้

## เช็คเข้าทะเบียนได้ 2 ทาง
1. **อัตโนมัติ** จากเอกสารจ่ายเงิน เช่น จ่ายชำระหนี้ ซื้อสด ค่าใช้จ่ายอื่นๆ เมื่อใส่เช็คในส่วน "รายการเช็คจ่าย (หลายรายการ)" ของแท็บ "การรับ/จ่ายชำระเงิน" (เลขที่เช็ค สมุดบัญชีธนาคาร สาขา วันถึงกำหนด จำนวนเงิน)
2. **เช็คจ่ายยกมา** สำหรับเช็คที่สั่งจ่ายไว้ก่อนเริ่มใช้โปรแกรม

## ขั้นตอน (เช็คจ่ายยกมา)
1. เปิดเมนู เช็คจ่ายยกมา กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. เลือกเจ้าหนี้ที่รับเช็ค
3. ในตาราง เลือก "สมุดบัญชี" ที่ออกเช็ค ใส่ "เลขที่เช็ค" "ธนาคาร" "สาขา" "วันครบกำหนด" และ "จำนวนเงิน" ใบละบรรทัด (ถ้าเว้น "ธนาคาร" "สาขา" ระบบใช้ของสมุดบัญชีนั้น)
4. กด "บันทึก" เช็คเข้าทะเบียนในสถานะ เช็คในมือ (ยังไม่ถูกตัดเงิน)

## ขั้นตอน (ดูทะเบียน)
1. เปิด ทะเบียนเช็คจ่าย ค้นหาด้วยเลขที่เช็คหรือเลขเอกสารอ้างอิง
2. เปิดเช็คแต่ละใบ ช่อง "เอกสารอ้างอิง" คือเอกสารที่จ่ายเช็คนั้น และดูตาราง "ประวัติความเคลื่อนไหวเช็ค / บัตรเครดิต" ว่าผ่าน คืน เปลี่ยน หรือขาดสิทธิ์ไปแล้วหรือยัง
3. หน้าทะเบียนไม่มีช่องแสดงสถานะ ถ้าต้องการดูสถานะให้ใช้รายงาน ([[faq-cheque-status]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เจ้าหนี้ | ผู้รับเช็ค | |
| สมุดบัญชี | บัญชีที่ออกเช็ค | ใช้กรองเช็คตอนบันทึกเช็คผ่าน คืน ขาดสิทธิ์ (เมื่อใส่สมุดบัญชีในบรรทัดก่อนกดค้นหา) |
| เลขที่เช็ค / วันครบกำหนด / จำนวนเงิน | ตามเช็ค | |

## บันทึกแล้วระบบทำอะไรให้
- เช็คจ่ายยกมา **ไม่ลงบัญชี** (ตามรูปแบบมาตรฐาน) ยอดยกมาของบัญชีเช็คจ่ายล่วงหน้า ต้องตั้งในระบบบัญชีแยกประเภทเอง ([[howto-gl-overview]])
- เช็คจากเอกสารจ่ายเงิน ลงบัญชี เครดิต เช็คจ่ายล่วงหน้า ไว้ในเอกสารต้นทางแล้ว
- เช็คที่ยังไม่ถูกตัดเงิน (หรือเช็คที่ถูกคืนมา) เลือกได้ในเมนู บันทึกเช็คผ่าน (เช็คจ่าย) บันทึกการเปลี่ยนเช็ค (เช็คจ่าย) และบันทึกเช็คขาดสิทธิ์ (เช็คจ่าย) ส่วน บันทึกเช็คคืน (เช็คจ่าย) เลือกได้เฉพาะเช็คที่ผ่านแล้ว ([[howto-cheque-paid-manage]])
