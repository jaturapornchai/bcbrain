# บันทึกสมาชิก ดูแต้มสะสม ตั้งแต้มยกมา และตัดแต้ม

**ใช้เมื่อ:** ร้านมีบัตรสมาชิกและให้แต้มสะสมกับลูกค้า ต้องการดูว่าลูกค้ามีแต้มเท่าไร ใส่แต้มเดิมก่อนเริ่มใช้ระบบ หรือหักแต้มเมื่อลูกค้าแลกของ
**เมนู:** ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › เลือก
- รายละเอียดสมาชิก
- กำหนดแต้มคงเหลือยกมา
- แต้มสะสม
- บันทึกตัดแต้ม
- คำณวนแต้มสะสม (ชื่อเมนูบนจอสะกดแบบนี้)
**ต้องมีก่อน:** ลูกค้าต้องมีในทะเบียนลูกหนี้แล้ว ([[howto-ar-customer-register]])

## ขั้นตอน: บันทึกสมาชิก
1. เปิด รายละเอียดสมาชิก กด "เพิ่มใหม่"
2. ใส่ "รหัสสมาชิก" (เลขบัตร) "วันที่สมัคร" "วันที่หมดอายุ"
3. เลือก "รหัสลูกหนี้" ที่เป็นเจ้าของบัตร ระบบแสดงชื่อ ที่อยู่ และเลขผู้เสียภาษีของลูกค้าให้ดู
4. ถ้ามีผู้แนะนำ ใส่ "รหัสผู้แนะนำ" ถ้าเป็นพนักงานร้าน ติ๊ก "เป็นพนักงาน"
5. กด "บันทึก"

## ขั้นตอน: ตั้งแต้มยกมา หรือ ตัดแต้ม
1. เปิด กำหนดแต้มคงเหลือยกมา (ใส่แต้มเดิม) หรือ บันทึกตัดแต้ม (หักแต้ม)
2. ใส่ "เลขที่เอกสาร" "วันที่เอกสาร" และ "รหัสลูกหนี้"
3. ใส่ "จำนวนแต้มยกมา" หรือ "จำนวนแต้มที่ตัด" และหมายเหตุ เช่น แลกของรางวัลอะไร
4. กดบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสสมาชิก | เลขบัตรสมาชิก | ห้ามซ้ำ |
| รหัสลูกหนี้ | ลูกค้าเจ้าของบัตร/แต้ม | ต้องมีในทะเบียนลูกหนี้ |
| จำนวนแต้มยกมา / จำนวนแต้มที่ตัด | ตัวเลขแต้ม | |

## บันทึกแล้วระบบทำอะไรให้
- หน้า แต้มสะสม แสดง "ประวัติความเคลื่อนไหวแต้มสะสม" ของลูกค้า: แต้มที่ได้ แต้มที่ใช้ และ "แต้มคงเหลือ" สะสมเรียงตามวันที่
  - แต้มที่ได้ มาจากการขายหน้าร้าน (POS) และแต้มยกมา
  - แต้มที่ใช้ มาจากบันทึกตัดแต้ม และแต้มที่ลูกค้าใช้ตอนชำระเงิน
- แต้มยกมาและตัดแต้ม ไม่กระทบสต็อกและไม่ลงบัญชี
- **ข้อควรรู้:** ระบบไม่ได้ห้ามตัดแต้มเกินแต้มที่มี ให้ดูแต้มคงเหลือก่อนบันทึกตัดแต้ม
- แต้มจากการขายคิดเฉพาะบิลขายหน้าร้าน (POS) บิลขายสินค้า/บริการ ทั่วไปไม่ได้แต้ม

## คำนวณแต้มใหม่ (คำณวนแต้มสะสม)
- ใช้เมื่อแก้เงื่อนไขแต้มย้อนหลัง หรือแต้มของบิลหน้าร้านไม่ตรง: เลือกช่วงวันที่ แล้วสั่งประมวลผล
- ระบบคิดแต้มใหม่เฉพาะบิลขายหน้าร้านที่ไม่ถูกยกเลิกในช่วงวันที่นั้น โดยปัดเศษแต้มทิ้ง
  - ยอดที่ใช้คิด: สินค้าที่ตั้งว่า "สะสมแต้ม" หรือทุกสินค้าถ้าเปิด "เข้าระบบสะสมแต้มทุกรายการ" หรือยอดที่ลูกค้าจ่ายถ้าเปิด "คำนวณแต้มจากยอดชำระ" (แท็บ "3.สินค้าคงคลัง")
  - บิลที่วันที่ไม่อยู่ในช่วงเงื่อนไขแต้ม ระบบข้ามไป
- แต้มยกมาและตัดแต้มที่บันทึกเอง ไม่ถูกแก้
- เงื่อนไขการได้แต้มตั้งที่ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดเงื่อนไขสะสมแต้ม (ส่วนของระบบหน้าร้าน [[sys-pos-overview]])

## แก้ไข ยกเลิก พิมพ์
- แต้มยกมา/ตัดแต้ม ผิด: เปิดเอกสารเดิมแก้จำนวนแล้วบันทึกใหม่ หรือลบเอกสาร
- ดูแต้มคงเหลือทุกคน: รายงานแต้มคงเหลือลูกหนี้ ([[rpt-overview]])

## ปัญหาที่พบบ่อย
- "รหัสสมาชิก "..." มีอยู่ในระบบแล้ว" → ใช้รหัสอื่น
- "กรุณาระบุ รหัสสมาชิก" / "กรุณาระบุ รหัสลูกหนี้" (หน้า รายละเอียดสมาชิก) → กรอกให้ครบ
- "ไม่พบรหัสลูกหนี้ : ..." (หน้า รายละเอียดสมาชิก) หรือ "ไม่พบรหัสลูกหนี้ ..." (แต้มยกมา/ตัดแต้ม) → ลูกค้ายังไม่มีในทะเบียน หรือพิมพ์รหัสผิด
- หน้า กำหนดแต้มคงเหลือยกมา / บันทึกตัดแต้ม ขึ้น "กรุณาระบุรหัส" → ช่อง "เลขที่เอกสาร" ว่าง
- หน้า กำหนดแต้มคงเหลือยกมา / บันทึกตัดแต้ม ขึ้น "กรุณาระบุชื่อ" → ช่อง "รหัสลูกหนี้" ว่าง (ข้อความไม่ตรงชื่อช่อง แต่หมายถึงช่องนี้)
- "เลขที่เอกสารซ้ำ" → เลขที่เอกสารนี้มีแล้ว ใช้เลขอื่น
