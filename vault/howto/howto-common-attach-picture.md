# แนบรูปภาพและไฟล์ให้เอกสารหรือสินค้า

**ใช้เมื่อ:** ต้องการเก็บรูปหรือไฟล์ประกอบไว้กับเอกสาร เช่น รูปบิลจากผู้จำหน่าย ใบเสร็จ สัญญา PDF ไฟล์ Excel หรือเก็บรูปสินค้า
**เมนู:**
- แนบกับเอกสาร: เลือกเมนูของระบบงานนั้น › "บันทึกรูปภาพและไฟล์แนบเอกสาร" (มีในสินค้า ซื้อ ขาย เจ้าหนี้ ลูกหนี้ เงินสด/ธนาคาร และบัญชี เช่น ซื้อ › บันทึกรูปภาพและไฟล์แนบเอกสารซื้อ)
- แนบกับสินค้า: สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › กำหนดรูปภาพและไฟล์แนบ (หรือ กำหนดรูปภาพตามบาร์โค้ด)
- รูปพนักงาน: เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรูปภาพพนักงาน
- รูปสินทรัพย์: ค่าเสื่อม › รายละเอียดสินทรัพย์ › กำหนดรูปภาพและไฟล์แนบ

**ต้องมีก่อน:** บันทึกเอกสารหรือสร้างสินค้านั้นไว้แล้ว และมีสิทธิ์แก้ไขหน้าจอนี้

## ขั้นตอน
1. เปิดเมนูแนบรูปของระบบงานนั้น
2. เลือก "ประเภทเอกสาร" ทางซ้าย แล้วเลือกเอกสารจากรายการ (ค้นด้วยเลขที่เอกสารได้)
3. กด "แก้ไข" เพื่อเข้าโหมดแก้ไข
4. กดปุ่ม "เลือกรูป / ไฟล์แนบ" แล้วเลือกไฟล์จากเครื่อง เลือกหลายไฟล์พร้อมกันได้
5. ตรวจรูปที่แสดง แล้วกด "บันทึก" ระบบขึ้น "บันทึกรูปภาพและไฟล์แนบเอกสารแล้ว"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทเอกสาร | เลือกชนิดเอกสาร เช่น ใบสั่งซื้อ ใบขาย | ต้องเลือกก่อนจึงจะเห็นรายการเอกสาร |
| เอกสาร | เลือกเลขที่เอกสารที่จะแนบ | |
| ไฟล์แนบ | รูป PNG, JPG, WEBP, GIF, BMP หรือไฟล์ PDF, XLS, XLSX, CSV, DOC, DOCX, PPT, PPTX, TXT, ZIP | ขนาดไม่เกิน 25 MB ต่อไฟล์ |

## บันทึกแล้วระบบทำอะไรให้
- เก็บไฟล์ไว้กับเอกสารหรือสินค้านั้น เปิดดูย้อนหลังได้จากหน้าจอเดียวกัน กด "เปิดแท็บใหม่" เพื่อดูไฟล์ขนาดเต็ม หรือ "ดาวน์โหลดไฟล์" เพื่อเก็บลงเครื่อง
- การแนบไฟล์ไม่เปลี่ยนตัวเลขในเอกสาร ยอดเงิน หรือรายงานใดๆ
- แนบไฟล์กับเอกสารได้หลายไฟล์ ระบบไม่ได้จำกัดจำนวน

## แก้ไข ยกเลิก พิมพ์
- ลบรูปทีละรูป: กด "แก้ไข" แล้วกดลบที่รูปนั้น แล้วกด "บันทึก"
- ลบทั้งหมดของเอกสาร: กด "ลบ" ระบบถาม "ลบรูปภาพทั้งหมดของเอกสาร ... ?" ยืนยันแล้วลบออกทั้งหมด
- ถ้าเลือกรูปแล้วยังไม่บันทึก จะเปลี่ยนไปเอกสารอื่นไม่ได้ ระบบขึ้น "มีรูปที่ยังไม่บันทึก กรุณาบันทึกหรือยกเลิกก่อนเปลี่ยนเอกสาร"

## ปัญหาที่พบบ่อย
