# เช็ครับคืน (เช็คเด้ง) เปลี่ยนเช็ค ตั้งหนี้ใหม่ และเช็คขาดสิทธิ์

**ใช้เมื่อ:** เช็คที่รับจากลูกค้ามีปัญหา
- **เช็คคืน**: ธนาคารคืนเช็คที่นำฝาก (เช็คเด้ง)
- **เปลี่ยนเช็ค**: ลูกค้าขอเอาเช็คใบเดิมคืน แล้วจ่ายด้วยเช็คใบใหม่หรือช่องทางอื่นแทน
- **ตั้งหนี้ใหม่**: คืนเช็คให้ลูกค้า แล้วตั้งยอดเป็นหนี้ค้างรับแทน
- **ขาดสิทธิ์**: เช็คใช้ไม่ได้แล้ว เช่น เลยกำหนดขึ้นเงิน (ในรายงานแสดงเป็น "เช็คยกเลิก")
**เมนู:** เงินสด/ธนาคาร › ทะเบียนเช็ครับและจัดการเช็ครับ › บันทึกเช็คคืน (เช็ครับ) / บันทึกการเปลี่ยนเช็ค (เช็ครับ) / บันทึกคืนเช็ค/ตั้งหนี้ใหม่ / บันทึกเช็คขาดสิทธิ์ (เช็ครับ)
**ต้องมีก่อน:** เช็คอยู่ในทะเบียนเช็ครับ ([[howto-cheque-received-register]])

## เลือกเช็คได้เฉพาะสถานะต่อไปนี้
| เมนู | เช็คที่เลือกได้ |
|---|---|
| เช็คคืน | เช็คที่นำฝากแล้ว หรือผ่านแล้ว (ถ้าเลือกสมุดในบรรทัดไว้ก่อน จะแสดงเฉพาะเช็คที่บันทึกผ่านเข้าสมุดนั้น) |
| เปลี่ยนเช็ค | เช็คในมือ หรือเช็คที่ถูกคืน ของลูกหนี้คนเดียวกัน |
| ตั้งหนี้ใหม่ | เช็คในมือ หรือเช็คที่ถูกคืน ของลูกหนี้คนเดียวกัน |
| ขาดสิทธิ์ | เช็คในมือ หรือเช็คที่ถูกคืน |

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. เช็คคืน: ในตาราง ช่อง "สมุดบัญชี" เลือกสมุดเงินฝากที่เช็คผ่านเข้า / เปลี่ยนเช็ค และ ตั้งหนี้ใหม่: เลือกลูกหนี้ที่หัวเอกสาร
3. ในตาราง กดปุ่มค้นหา เลือกเช็คจากหน้าต่าง "ค้นหาเช็ค"
4. เฉพาะเปลี่ยนเช็ค: ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่เช็คใบใหม่หรือเงินที่ลูกค้าจ่ายแทน
5. กด "บันทึก"

## บันทึกแล้วระบบทำอะไรให้
- เช็คคืน: สถานะ "เช็ครับคืน" ลงบัญชี เดบิต เช็ครับล่วงหน้า คู่กับ เครดิต เงินฝากธนาคาร เช็คที่คืนแล้วนำฝากใหม่ได้ หรือไปทำเปลี่ยนเช็ค/ตั้งหนี้ใหม่/ขาดสิทธิ์ต่อ
- ตั้งหนี้ใหม่: สถานะ "เช็คตั้งหนี้ใหม่" ลงบัญชี เดบิต ลูกหนี้ คู่กับ เครดิต เช็ครับล่วงหน้า ยอดไปเป็นหนี้ค้างรับ รับชำระได้ที่ระบบลูกหนี้ ([[howto-ar-overview]])
- ขาดสิทธิ์: สถานะ "เช็คยกเลิก" ลงบัญชี เดบิต ลูกหนี้ คู่กับ เครดิต เช็ครับล่วงหน้า แต่ยอดไม่ไปเป็นหนี้ค้างรับของลูกค้าในระบบลูกหนี้ และเช็คที่ขาดสิทธิ์แล้วนำไปทำตั้งหนี้ใหม่ไม่ได้ ถ้ายังต้องเก็บเงินจากลูกค้า ให้ใช้ บันทึกคืนเช็ค/ตั้งหนี้ใหม่ แทน ถ้าบันทึกขาดสิทธิ์ไปแล้วแต่ต้องตามหนี้ → ส่งต่อเจ้าหน้าที่
- เปลี่ยนเช็ค: สถานะ "เช็คเปลี่ยน" **ข้อควรระวัง:** การลงบัญชีมาตรฐานของเมนูนี้ยังไม่ได้ใช้ข้อมูลในแท็บรับชำระ (ลง เดบิต เงินฝากธนาคาร คู่กับ เครดิต เช็ครับล่วงหน้า) ให้ตรวจแท็บ "การลงบัญชี (GL)" และสอบถามทีมงานก่อนใช้กับข้อมูลจริง

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกด้วย บันทึกยกเลิกเช็ครับคืน / บันทึกยกเลิกเปลี่ยนเช็ค / บันทึกยกเลิกเช็คขาดสิทธิ์ ([[howto-bank-cancel-docs]])
- ตั้งหนี้ใหม่ยังไม่มีเมนูยกเลิก ถ้าบันทึกผิด → ส่งต่อเจ้าหน้าที่

## ปัญหาที่พบบ่อย
- "ไม่พบเช็คที่เลือกได้ในสถานะนี้" → เช็คอยู่ผิดสถานะหรือคนละลูกหนี้ ([[ts-cheque-not-in-picker]])
- การปฏิบัติทางกฎหมายเรื่องเช็คเด้ง ให้ปรึกษาที่ปรึกษากฎหมายหรือผู้สอบบัญชี
