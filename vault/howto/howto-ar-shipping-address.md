# บันทึกที่อยู่จัดส่งสินค้า และพิมพ์ป้ายชื่อขนส่ง

**ใช้เมื่อ:** ส่งของให้ลูกค้าทางขนส่ง ต้องการเก็บที่อยู่ผู้รับไว้ แล้วพิมพ์ใบปะหน้า/สติ๊กเกอร์ที่อยู่ติดกล่อง
**เมนู:** ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › เลือก
- ที่อยู่จัดส่งสินค้า (บันทึก/แก้ที่อยู่)
- นำเข้าที่อยู่จัดส่งลูกหนี้ (ดึงที่อยู่จากทะเบียนลูกค้ามาสร้างให้)
- พิมพ์ที่อยู่จัดส่งสินค้า (หน้าจอ "พิมพ์ป้ายชื่อขนส่ง")
**ต้องมีก่อน:** ลูกค้าในทะเบียนลูกหนี้ ([[howto-ar-customer-register]])

## ขั้นตอน: เตรียมที่อยู่
1. ถ้ามีลูกค้าหลายราย ใช้ นำเข้าที่อยู่จัดส่งลูกหนี้ ก่อน ระบบสร้างที่อยู่จัดส่งให้ลูกค้าทุกรายที่ยังไม่มี โดยคัดชื่อ ที่อยู่ โทรศัพท์ โทรสาร อีเมลจากทะเบียนลูกค้า (รายที่มีอยู่แล้วไม่ถูกทับ)
2. เปิด ที่อยู่จัดส่งสินค้า เลือกลูกค้า แล้วแก้รายละเอียดให้ถูก เช่น อาคาร ชั้น ซอย ถนน มือถือ ประเภทการขนส่ง
3. บันทึก

## ขั้นตอน: จัดคิวป้าย
1. เปิด พิมพ์ที่อยู่จัดส่งสินค้า (ตอนเปิด ระบบใส่ 5 รายชื่อแรกในคิวให้ก่อน ถ้าไม่ต้องการกด "ล้างรายการ")
2. คลิกรายชื่อฝั่งซ้ายเพื่อเพิ่มเข้าคิวพิมพ์ (คลิกชื่อเดิมซ้ำ = เพิ่มจำนวนดวง) แก้ "จำนวนดวง" ต่อรายได้
3. กด "แสดงตัวอย่าง" เพื่อดูหน้าตาป้ายในคิว

**ข้อจำกัดรุ่นปัจจุบัน:**
- กด "พิมพ์" แล้วระบบแค่เปิดตัวอย่างและขึ้นข้อความว่าสั่งพิมพ์เรียบร้อย แต่ยังไม่ได้ส่งงานไปเครื่องพิมพ์ ถ้าลูกค้าต้องการพิมพ์ใบปะหน้าจริง ส่งต่อเจ้าหน้าที่
- "โหมดการพิมพ์" "เครื่องพิมพ์" "แบบฟอร์ม" "พิมพ์กระดาษสติ๊กเกอร์ A4" "แถวเริ่ม" และ "คอลัมน์เริ่ม" ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล (แบบฟอร์ม แถว และคอลัมน์ แค่แสดงเป็นหัวข้อในตัวอย่าง)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ชื่อ / ที่อยู่ / จังหวัด อำเภอ ตำบล รหัสไปรษณีย์ | ผู้รับปลายทาง | |
| มือถือ 1 / มือถือ 2 | เบอร์ผู้รับ | ขนส่งใช้โทรหาผู้รับ |
| ประเภทการขนส่ง / วันที่รับสินค้า / ช่วงเวลารับสินค้า | ข้อมูลการส่ง | |
| แบบฟอร์ม | "FORM-A4-3X8 (A4 24 ดวง)", "FORM-A4-2X5 (A4 10 ดวง)", "FORM-100X150 (ใบปะหน้า 4x6 นิ้ว)" | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล |
| กลุ่ม | กรองรายชื่อฝั่งซ้ายตามกลุ่มลูกหนี้หลักของลูกค้า หรือ "-- ทุกกลุ่ม --" | |

## บันทึกแล้วระบบทำอะไรให้
- ที่อยู่จัดส่งเป็นข้อมูลแยกจากที่อยู่ในทะเบียนลูกค้า แก้ที่หนึ่งไม่เปลี่ยนอีกที่
- ในหน้าเอกสาร (เช่น ใบสั่งขาย ใบขาย) มีส่วน "ข้อมูลการจัดส่งสินค้า / ผู้รับปลายทาง" ให้ใส่ชื่อผู้รับ โทรศัพท์ผู้รับ ที่อยู่จัดส่ง บริษัทขนส่ง และ "เลขพัสดุ (Tracking)" ของบิลนั้น ส่วนนี้กรอกเองต่อบิล ไม่ได้ดึงจาก ที่อยู่จัดส่งสินค้า

## แก้ไข ยกเลิก พิมพ์
- แก้ที่อยู่: เปิด ที่อยู่จัดส่งสินค้า เลือกลูกค้า แก้แล้วบันทึก
- ถ้าลูกค้าย้ายที่อยู่ในทะเบียนลูกค้า ต้องมาแก้ที่อยู่จัดส่งด้วย เพราะการนำเข้าไม่ทับรายการเดิม

## ปัญหาที่พบบ่อย
- รายชื่อฝั่งซ้ายว่าง → ยังไม่มีที่อยู่จัดส่ง ให้บันทึกหรือนำเข้าก่อน
- กด "พิมพ์" แล้วเครื่องพิมพ์ไม่ทำงาน → รุ่นปัจจุบันยังไม่ส่งงานไปเครื่องพิมพ์ ส่งต่อเจ้าหน้าที่
