# บันทึกการซ่อมบำรุงสินทรัพย์

**ใช้เมื่อ:** ต้องการเก็บประวัติการซ่อมหรือบำรุงรักษาสินทรัพย์ เช่น เช็คระยะรถ ซ่อมเครื่องจักร
**เมนู:** ค่าเสื่อม › บันทึกการซ่อมบำรุงสินทรัพย์
**ต้องมีก่อน:** ทะเบียนสินทรัพย์ ([[howto-asset-register]]) รายการและหน่วยการบำรุงรักษา ([[howto-asset-setup]])

## ขั้นตอน
1. กด "เพิ่มใหม่" ใส่ "เอกสารเลขที่" "เอกสารวันที่" และหมายเหตุ
2. แท็บ "รายการบำรุงรักษา": เลือก "รหัสสินทรัพย์" "รหัสบำรุงรักษา" ใส่ "ชื่อการบำรุงรักษา" "หน่วยบำรุงรักษา" "วันที่บำรุงรักษา" "สถานที่บำรุงรักษา" และ "ค่าบำรุงรักษา"
3. หลายสินทรัพย์ในเอกสารเดียวได้ บรรทัดละรายการ
4. กด "บันทึก" ระบบรวม "ค่าบำรุงรักษา" ที่หัวเอกสารให้

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เอกสารวันที่ | วันที่ซ่อม | บังคับกรอก |
| รหัสสินทรัพย์ | สินทรัพย์ที่ซ่อม | บรรทัดที่ไม่ใส่รหัส ระบบข้ามไป |
| ค่าบำรุงรักษา | ค่าซ่อม | |

## บันทึกแล้วระบบทำอะไรให้
- เก็บเป็นประวัติ แสดงที่แท็บ "บำรุงรักษา" ของข้อมูลสินทรัพย์ และในรายงานการซ่อมบำรุงสินทรัพย์
- **ไม่ลงบัญชี และไม่จ่ายเงิน** ค่าซ่อมต้องบันทึกค่าใช้จ่ายแยก เช่น [[howto-cash-other-expense]] หรือผ่านระบบซื้อ/เจ้าหนี้ ([[howto-ap-overview]])
- ค่าซ่อมควรเป็นค่าใช้จ่ายหรือนำไปเพิ่มราคาทุนสินทรัพย์ ให้ปรึกษาผู้สอบบัญชี

## แก้ไข ยกเลิก พิมพ์
- เปิดเอกสาร กด "แก้ไข" หรือ "ลบ" ได้ ([[howto-doc-edit-cancel-delete]])

## ปัญหาที่พบบ่อย
- "กรุณาระบุวันที่เอกสาร" → ใส่ เอกสารวันที่
- "ไม่พบสินทรัพย์" "ไม่พบรายการซ่อมบำรุง" "ไม่พบหน่วยนับ" → รหัสที่พิมพ์ไม่มีในระบบ ให้เลือกจากปุ่มค้นหา
