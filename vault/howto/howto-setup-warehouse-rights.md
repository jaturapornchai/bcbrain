# กำหนดการใช้คลังและที่เก็บ

**ใช้เมื่อ:** อยากให้พนักงานแต่ละกลุ่มเลือกได้เฉพาะคลังและที่เก็บของตัวเอง เช่น หน้าร้านเห็นแค่คลังหน้าร้าน
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดการใช้คลังและที่เก็บ (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin · มีกลุ่มพนักงาน ([[howto-setup-user-group]]) และมีคลังกับที่เก็บแล้ว · เปิดข้อ "ใช้คลังที่เก็บตามสิทธิ์พนักงาน" ที่ [[howto-setup-options]] (หมวดสินค้าคงคลัง) ไม่เปิดข้อนี้ หน้านี้ไม่มีผลอะไร · เริ่มต้นดู [[start-first-day]]

## ขั้นตอน
1. เปิดเมนู "กำหนดการใช้คลังและที่เก็บ" เลือกกลุ่มที่ต้องการ (ถ้ายังไม่มี ให้สร้างกลุ่มก่อน)
2. กด "แก้ไข" ไปแท็บของเอกสารที่จะจำกัด มี 4 แท็บ คือ "1. ซื้อสินค้า (PU)", "2. ขายสินค้า (SI)", "3. โอนสินค้า (IM)", "4. รับคืน/เบิกสินค้า (ST)"
3. ใส่แถวละ 1 คู่ "รหัสคลัง" กับ "รหัสที่เก็บ" ที่กลุ่มนี้ใช้ได้ หรือกด "เลือกทั้งหมด" เพื่อใส่ทุกคลังทุกที่เก็บ
4. กดบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสกลุ่ม / ชื่อกลุ่ม | กลุ่มพนักงานที่จะตั้งสิทธิ์ | เลือกจากกลุ่มที่มี |
| รหัสคลัง (ชื่อคลังสินค้าขึ้นให้เอง) | คลังที่ใช้ได้ | ถ้าไม่มีรหัสนี้ขึ้น "ไม่พบรหัสคลังสินค้า" |
| รหัสที่เก็บ (ชื่อที่เก็บสินค้าขึ้นให้เอง) | ที่เก็บในคลังนั้น | |

## บันทึกแล้วระบบทำอะไรให้
- ในหน้าจอซื้อสินค้า ขายสินค้า โอนสินค้า และรับคืน/เบิกสินค้า ช่องเลือกคลังและที่เก็บจะแสดงเฉพาะที่กลุ่มของผู้ใช้ได้รับสิทธิ์
- ระบบไม่ตรวจซ้ำตอนบันทึกเอกสาร แค่จำกัดรายการที่ให้เลือก
- เอกสารอื่นนอกจาก 4 ชนิดนี้ไม่ถูกจำกัด

## แก้ไข ยกเลิก พิมพ์
- แก้ไข: เลือกกลุ่ม กด "แก้ไข" เพิ่มหรือลบแถว แล้วบันทึก
- หน้านี้ไม่มีปุ่มลบกลุ่ม ถ้าไม่อยากจำกัดแล้ว ให้ลบแถวคลังออกหรือปิดข้อ "ใช้คลังที่เก็บตามสิทธิ์พนักงาน"

## ปัญหาที่พบบ่อย
- ตั้งแล้วพนักงานยังเห็นทุกคลัง: ยังไม่ได้เปิดข้อ "ใช้คลังที่เก็บตามสิทธิ์พนักงาน"
- พนักงานเลือกคลังไม่ได้เลย: กลุ่มนั้นไม่มีแถวคลังในแท็บของเอกสารนั้น หรือพนักงานไม่ได้อยู่ในกลุ่ม ([[howto-setup-staff]])
- ไม่มีสิทธิ์เปิดหน้านี้: ดู [[ts-common-no-permission]]
