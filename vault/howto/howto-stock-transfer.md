# ขอโอนและโอนสินค้าระหว่างคลัง/ที่เก็บ

**ใช้เมื่อ:** ย้ายสินค้าจากคลังหนึ่งไปอีกคลัง (เช่น โกดังไปหน้าร้าน สาขาไปสาขา) หรือย้ายที่เก็บในคลังเดียวกัน
**เมนู:** สินค้า › ขอโอนสินค้า/วัตถุดิบ / โอนสินค้า/วัตถุดิบ
**ต้องมีก่อน:** คลังและที่เก็บทั้งต้นทางและปลายทาง ([[howto-stock-warehouse-shelf]])

## ขั้นตอน
1. (ถ้ามีขั้นขอ) **ขอโอนสินค้า/วัตถุดิบ:** ผู้ขอกรอกรายการ เลือก ผู้ขอโอน: จากคลัง และเข้าคลัง แล้วบันทึก ยังไม่ย้ายสต็อก
2. **โอนสินค้า/วัตถุดิบ:** กดเพิ่ม อ้างอิงใบขอโอนได้
3. เลือก จากคลัง: จากที่เก็บ: และ เข้าคลัง: เข้าที่เก็บ:
4. ใส่สินค้าและจำนวน (ไม่ต้องใส่ราคา) แล้วบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| จากคลัง / จากที่เก็บ | ต้นทาง | |
| เข้าคลัง / เข้าที่เก็บ | ปลายทาง | |
| ผู้ขอโอน | ผู้ขอ | |
| จำนวน | จำนวนที่ย้าย | |

## บันทึกแล้วระบบทำอะไรให้
- **สต็อก:** ลดที่ต้นทาง เพิ่มที่ปลายทาง จำนวนรวมทั้งกิจการไม่เปลี่ยน ย้ายมูลค่าด้วยต้นทุนเฉลี่ย ต้นทุนเฉลี่ยไม่เปลี่ยน
- **บัญชี:** ปกติไม่ลงบัญชี (มูลค่ารวมไม่เปลี่ยน) จะลงบัญชีเฉพาะเมื่อรูปแบบเอกสารตั้งรูปแบบการลงบัญชีไว้
- ใบโอนใหม่ถูกตรวจห้ามติดลบที่ต้นทาง เฉพาะเมื่อเปิด ห้ามเบิกสินค้าติดลบ + ห้ามโอนสินค้าติดลบ + เตือนเมื่อสินค้าติดลบ ([[howto-stock-options]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไข/ลบได้ถ้ายังไม่ถูกอ้างอิงและงวดยังไม่ปิด แก้แล้วระบบย้ายสต็อกใหม่ทั้งสองฝั่ง
- ยกเลิกใบโอนที่เมนู ยกเลิกโอนสินค้า/วัตถุดิบ ([[howto-stock-cancel-doc]])
- **ข้อจำกัด:** ใบขอโอนไม่มีเมนูยกเลิกแยก ถ้ายังไม่ถูกใช้ให้ลบหรือแก้จากเมนู ขอโอนสินค้า/วัตถุดิบ
