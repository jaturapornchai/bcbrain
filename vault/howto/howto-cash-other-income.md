# บันทึกรายได้อื่นๆ

**ใช้เมื่อ:** ได้รับเงินหรือมีรายได้ที่ไม่ใช่การขายสินค้า เช่น ค่าเช่า ดอกเบี้ยรับ ค่าบริการเล็กน้อย ขายเศษวัสดุ
**เมนู:** เงินสด/ธนาคาร › รายได้อื่นๆ
**ต้องมีก่อน:** ประเภทรายได้ที่ผูกผังบัญชีรายได้ ([[howto-cash-income-expense-type-setup]]) และรหัสลูกหนี้/ลูกค้า

## ขั้นตอน
1. เปิดเมนู รายได้อื่นๆ กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. เลือก "ลูกหนี้/ลูกค้า:" ที่เป็นผู้จ่ายเงิน
3. เลือก "ประเภทรายการ": "1: ขายสด" = รับเงินทันที, "0: ขายเชื่อ (เครดิต)" = ยังไม่ได้รับเงิน ตั้งเป็นหนี้ลูกค้า
4. ในตาราง เลือก "รหัสรายได้" (หน้าค้นหา "ค้นหารหัสรายได้") ใส่รายละเอียดและจำนวนเงิน
5. ถ้ามีภาษีมูลค่าเพิ่มหรือภาษีหัก ณ ที่จ่าย ไปที่แท็บ "ข้อมูลภาษี (VAT/WHT)"
6. ถ้าเป็นขายสด ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่ช่องทางรับเงินให้ครบยอด
7. ตรวจแท็บ "การลงบัญชี (GL)" แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | ผู้จ่ายเงิน | |
| ประเภทรายการ | สด หรือ เชื่อ | สด ต้องกรอกแท็บรับชำระ |
| รหัสรายได้ | ประเภทรายได้ | ระบบใช้บัญชีของบรรทัดแรก ([[faq-cash-multi-type-account]]) |
| จำนวนเงิน | ยอดของแต่ละบรรทัด | |

## บันทึกแล้วระบบทำอะไรให้
- ขายสด: เดบิต ช่องทางที่รับ (เงินสด เงินฝากธนาคาร เช็ครับล่วงหน้า ฯลฯ) คู่กับ เครดิต บัญชีรายได้ และ ภาษีขาย (ถ้ามี)
- ขายเชื่อ: เดบิต ลูกหนี้ แทนช่องทางรับเงิน และยอดนี้ไปรอรับชำระที่ระบบลูกหนี้ ([[howto-ar-overview]])
- ถ้ารับเป็นเช็คหรือบัตรเครดิต ระบบลงทะเบียนเช็ค/บัตรให้อัตโนมัติ ([[howto-cheque-received-register]])
- ภาษีขายเข้ารายงานภาษีตามข้อมูลแท็บภาษี ([[howto-tax-overview]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้ถ้างวดยังไม่ปิด และยังไม่มีเอกสารเพิ่มหนี้/ลดหนี้หรือรับชำระอ้างถึง
- ยกเลิกด้วยเมนู ยกเลิกรายได้อื่นๆ ([[howto-cash-cancel-docs]])
- พิมพ์ด้วยปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ" ([[rpt-print-export]])

## ปัญหาที่พบบ่อย
- "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" → [[ts-cash-pay-incomplete]]
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบได้" → ลบหรือยกเลิกเอกสารที่อ้างถึงก่อน
- ชื่อตัวเลือก ขายสด/ขายเชื่อ ใช้กับรายได้ได้ตามปกติ ส่วนจอค่าใช้จ่ายดู [[faq-cash-expense-labels-sale]]
