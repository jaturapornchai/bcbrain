# แนบรูปภาพหรือไฟล์กับเอกสารขายและเอกสารลูกหนี้

**ใช้เมื่อ:** อยากเก็บหลักฐานไว้กับเอกสาร เช่น ใบสั่งซื้อของลูกค้า สลิปโอนเงิน รูปสินค้า ใบรับของที่ลูกค้าเซ็น เพื่อเปิดดูย้อนหลังได้
**เมนู:** ขาย › บันทึกรูปภาพและไฟล์แนบเอกสารขาย / ลูกหนี้ › บันทึกรูปภาพและไฟล์แนบเอกสารลูกหนี้
**ต้องมีก่อน:** เอกสารที่บันทึกแล้ว และสิทธิ์แก้ไขข้อมูลในหน้าจอนี้ ([[ts-common-no-permission]])

## ขั้นตอน
1. เปิดเมนู เลือก "ประเภทเอกสาร" ด้านซ้าย (เช่น ใบขาย ใบเสร็จ)
2. เลือกเอกสารจากรายการ (คอลัมน์ วันที่เอกสาร / เลขที่เอกสาร / เลขที่อ้างอิง / หมายเหตุ) ใช้ปุ่ม "ก่อนหน้า" "ถัดไป" เปลี่ยนหน้า
3. กดปุ่ม "แก้ไข" (จอขึ้น "โหมดแก้ไข")
4. กด "เลือกรูป / ไฟล์แนบ" เลือกไฟล์จากเครื่อง ใส่ได้หลายไฟล์
5. กด "บันทึก" ระบบขึ้น "บันทึกรูปภาพและไฟล์แนบเอกสารแล้ว"
6. ลบไฟล์: กดปุ่มลบบนไฟล์นั้น ("ลบไฟล์นี้") แล้วบันทึก ถ้าลบหมดจะขึ้น "ลบรูปภาพและไฟล์แนบของเอกสารแล้ว" (การลบไฟล์จนหมดต้องมีสิทธิ์ลบข้อมูล)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทเอกสาร | ชนิดเอกสารที่จะแนบ | ต้องเลือกก่อน ไม่งั้นขึ้น "เลือกประเภทเอกสารด้านซ้ายก่อน" |
| ไฟล์แนบ | รูปหรือเอกสาร | ไม่จำกัดจำนวนไฟล์ |

## ไฟล์ที่รองรับ
- รูปภาพ: PNG, JPG, WEBP, GIF, BMP
- เอกสาร: PDF, XLS, XLSX, CSV, DOC, DOCX, PPT, PPTX, TXT, ZIP
- ขนาดไม่เกิน 25 MB ต่อไฟล์

## บันทึกแล้วระบบทำอะไรให้
- เก็บไฟล์ผูกกับเลขที่เอกสารนั้น เปิดดูได้จากหน้าจอนี้
- ไม่มีผลกับยอดเงิน สต็อก ภาษี หรือการลงบัญชี

## แก้ไข ยกเลิก พิมพ์
- เพิ่ม/ลบไฟล์ได้ตลอด ด้วยปุ่ม "แก้ไข" แล้ว "บันทึก"
- ถ้ายังไม่บันทึกแล้วจะเปลี่ยนเอกสาร ระบบเตือน "มีรูปที่ยังไม่บันทึก กรุณาบันทึกหรือยกเลิกก่อนเปลี่ยนเอกสาร"

## ปัญหาที่พบบ่อย
- "ไฟล์ที่ ... ใหญ่เกิน 25 MB" → ย่อไฟล์หรือแยกเป็นหลายไฟล์
- ขึ้นว่าไฟล์ไม่รองรับ → แปลงเป็นชนิดที่รองรับด้านบน เช่น PDF หรือ JPG
- "คุณไม่มีสิทธิ์ "แก้ไขข้อมูล" ในหน้าจอนี้ ..." (หรือ "ลบข้อมูล" เมื่อลบไฟล์จนหมด) → ให้ผู้ดูแลเพิ่มสิทธิ์ ([[ts-common-no-permission]])
- "เลขที่เอกสารยาวเกิน 50 ตัวอักษร เก็บรูปไม่ได้" → เลขที่เอกสารยาวเกินไป ส่งต่อทีมงาน
