# ดูสถานะซิงก์เครื่อง POS บิลค้างส่ง บิลผิดพลาด

**ใช้เมื่อ:** อยากรู้ว่าเครื่อง POS แต่ละเครื่องส่งบิลและรับข้อมูลล่าสุดแล้วหรือยัง หรือมีบิลที่เข้าระบบไม่สำเร็จ
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรหัสเครื่อง POS › ส่วนที่ 3 "สถานะการซิงก์เครื่อง POS & รหัสเชื่อมเครื่อง"
**ต้องมีก่อน:** ลงทะเบียนเครื่องและเชื่อมเครื่องแล้ว ([[howto-pos-web-pair-device]])

## อ่านตารางสถานะ
ตารางรีเฟรชเองทุก 30 วินาทีขณะเปิดหน้านี้ค้างไว้บนจอ (หรือกด **รีเฟรช**) ข้อความล่างตารางบอกเวลาอัปเดตล่าสุด

| คอลัมน์ | ความหมาย |
|---|---|
| เครื่อง POS | รหัสและชื่อเครื่อง |
| สถานะ | "ยังไม่เชื่อมเครื่อง" = ยังไม่เคยสร้าง/ใช้รหัสเชื่อม · "ข้อมูลล่าสุดแล้ว" = เครื่องรับข้อมูลที่เปลี่ยนล่าสุดครบแล้ว · "รอ sync" = เครื่องเชื่อมแล้วแต่ยังไม่ได้รับข้อมูลที่เปลี่ยนล่าสุด (เช่น ปิดเครื่อง เน็ตหลุด) |
| ซิงก์ล่าสุด | เวลาที่เครื่องดึงข้อมูลสำเร็จ เช่น "เมื่อสักครู่", "5 นาทีที่แล้ว", "ยังไม่เคยซิงก์" (ถ้าเกิน 1 วันจะแสดงเป็นวันที่และเวลาเต็ม) |
| พบเครื่องล่าสุด | เวลาที่เครื่องติดต่อระบบครั้งหลังสุด |
| บิลรอส่ง | จำนวนบิลที่เครื่องบอกว่ายังส่งไม่ครบ (เครื่องแจ้งมาพร้อมการซิงก์) |
| บิลผิดพลาด | จำนวนบิลของเครื่องนั้นที่ระบบรับไว้แล้วแต่สร้างเอกสารขายไม่สำเร็จ |
| เวอร์ชันแอป | เวอร์ชันแอป POS บนเครื่อง |

แถบด้านบนตารางมีสองป้ายรวม คือ "รอคำนวณสต็อก ... รายการ" (สินค้าที่รอคำนวณสต็อกใหม่หลังขาย ปกติหมดเองในไม่กี่วินาที) และ "บิลผิดพลาด ... บิล" (ป้ายแดงเมื่อมีบิลผิดพลาด)

## สั่งประมวลผลบิลที่ผิดพลาดใหม่
1. แก้สาเหตุของบิลผิดพลาดก่อน เช่น เพิ่มรหัสสินค้าที่ขาด หรือแก้รูปแบบเลขที่บิล ดูสาเหตุที่พบบ่อยใน [[ts-pos-web-bill-error]]
2. กดปุ่ม **ประมวลผลบิลที่ผิดพลาดใหม่**
3. ระบบประมวลผลบิลที่ยังไม่สำเร็จใหม่ ครั้งละไม่เกิน 5,000 บิล แล้วแสดง "ประมวลผลบิลใหม่ ... บิล — ยังผิดพลาด ... บิล" ถ้ายังผิดพลาดแปลว่ายังมีสาเหตุที่ไม่ได้แก้

บิลไม่ได้หายไปไหน ระบบเก็บบิลดิบจากเครื่องไว้ทุกบิล ประมวลผลซ้ำกี่ครั้งก็ไม่เกิดบิลซ้ำ (ถ้าบิลเคยสำเร็จแล้ว จะถูกสร้างทับของเดิมของ POS เอง ไม่ทับเอกสารขายอื่น)

## ถ้าเครื่อง "รอ sync" นาน
1. ดู "พบเครื่องล่าสุด" ถ้านานมากแปลว่าเครื่องออฟไลน์หรือปิดอยู่ ตรวจอินเทอร์เน็ตที่หน้าร้าน
2. ถ้าเครื่องเปิดอยู่และมีเน็ตแต่ไม่ซิงก์ อาจเพราะรหัสเชื่อมถูกสร้างใหม่ ดู [[ts-pos-web-pair-token-invalid]]
3. เครื่อง POS ขายต่อได้ตามปกติแม้ออฟไลน์ บิลจะสะสมและส่งเมื่อออนไลน์

## ปัญหาที่พบบ่อย
- "โหลดสถานะเครื่องไม่สำเร็จ: ..." → ระบบหลังบ้านตอบไม่ได้ชั่วคราว กดรีเฟรชใหม่
- "ยังไม่มีเครื่อง POS ที่ลงทะเบียน (เพิ่มรหัสเครื่องในตารางด้านล่างก่อน)" → ไปลงทะเบียนเครื่อง [[howto-pos-web-machine-register]]
