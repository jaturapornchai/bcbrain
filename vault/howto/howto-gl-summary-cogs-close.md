# สรุปบัญชีสินค้าและต้นทุนขาย / สรุปยอดบัญชี (ข้อควรระวัง)

**ใช้เมื่อ:** ลูกค้าเปิดเมนูสองเมนูนี้แล้วถามว่าใช้ทำอะไร
**เมนู:** บัญชี › ตรวจสอบ ผ่านรายการ และประมวลผลบัญชี › สรุปบัญชีสินค้าและต้นทุนขาย · บัญชี › สอบถามบัญชีแยกประเภทและงบการเงิน (บนหน้าจอ) › สรุปยอดบัญชี
**ต้องมีก่อน:** งวดบัญชี ([[howto-gl-account-period]]) · เมนู สรุปบัญชีสินค้าและต้นทุนขาย ใช้ได้เฉพาะ Admin ([[faq-gl-who-can-close]])

## ขั้นตอน
1. เปิดเมนู เลือกงวด กรอกเลขที่เอกสาร สมุดรายวัน รหัสบัญชี และหมายเหตุ
2. กด "ประมวลผล" เพื่อดูตัวอย่างรายการ (ยังไม่บันทึกอะไร)
3. **ก่อนกด "บันทึก" ให้อ่านข้อควรระวังด้านล่าง**

## ช่องสำคัญที่ต้องกรอก
| เมนู | ช่องบนจอ |
|---|---|
| สรุปบัญชีสินค้าและต้นทุนขาย | งวดบัญชีปิดต้นทุนขาย, เลขที่เอกสารปิดต้นทุนขาย, สมุดรายวันต้นทุนขาย, รหัสบัญชีต้นทุนขายสินค้า, หมายเหตุการปิดบัญชีต้นทุนขาย |
| สรุปยอดบัญชี | งวดบัญชีที่สรุปรายการ, เลขที่เอกสารสรุปบัญชีแยกประเภท, รหัสสมุดรายวันที่สรุป, รหัสบัญชีพักสรุปรายการ, คำอธิบายรายการสรุปบัญชีแยกประเภท |

## บันทึกแล้วระบบทำอะไรให้
- **ข้อควรระวัง:** ในรุ่นปัจจุบัน ทั้งสองเมนูใช้การคำนวณเดียวกับ ประมวลผลสิ้นงวด คือปิดยอดบัญชีรายได้และค่าใช้จ่ายทั้งหมดของงวด เข้าบัญชีที่กรอกในช่องรหัสบัญชี ยังไม่ได้คำนวณต้นทุนขายหรือสรุปยอดแยกต่างหาก
- ถ้ากดบันทึก จะได้ใบสำคัญที่ปิดรายได้/ค่าใช้จ่ายเข้าบัญชีต้นทุนขายหรือบัญชีพักที่กรอก ซึ่งอาจไม่ใช่สิ่งที่ต้องการ
- ต้นทุนขายของเอกสารขาย ระบบลงบัญชีให้แล้วตอนบันทึกเอกสารขาย/สต็อก ([[howto-gl-auto-posting]])
- ต้องการปิดบัญชีประจำงวด ให้ใช้ [[howto-gl-end-of-period]] แทน

## แก้ไข ยกเลิก พิมพ์
- ถ้าเผลอบันทึกไปแล้ว ใบสำคัญนี้แสดงใน ข้อมูลรายวัน ตามเลขที่ที่กรอก ส่งต่อทีมงานเพื่อช่วยตรวจและลบ
