# ตรวจสอบความถูกต้องของข้อมูลบัญชี

**ใช้เมื่อ:** ก่อนปิดงวด ก่อนส่งงบให้ผู้สอบบัญชี หรือเมื่องบทดลองดูผิดปกติ อยากให้ระบบไล่หาใบสำคัญที่มีปัญหาให้
**เมนู:** บัญชี › ตรวจสอบ ผ่านรายการ และประมวลผลบัญชี › ตรวจสอบความถูกต้อง
**ต้องมีก่อน:** -

## ขั้นตอน
1. เปิดเมนู ตรวจสอบความถูกต้อง
2. กรอก จากวันที่ / ถึงวันที่ ที่ต้องการตรวจ
3. เลือกตัวเลือกเพิ่มถ้าต้องการ: "แสดงทั้งหมด (ไม่กรองวันที่)", "เฉพาะเอกสารที่กำหนดสมุดรายวัน" (มีผลกับหัวข้อเอกสารที่ยังไม่ได้ประมวลผลลงบัญชี (รายวัน) เท่านั้น), "ไม่ตรวจเอกสารที่ยกเลิก" (ติ๊กไว้ก่อน มีผลกับหัวข้อเดบิตกับเครดิตไม่เท่ากันเท่านั้น)
4. กด "เริ่มตรวจสอบ"
5. อ่านผลในตาราง รายการตรวจสอบ / รายละเอียด ถ้าไม่มีปัญหาจะขึ้น "ตรวจสอบเรียบร้อย ไม่พบข้อผิดพลาด"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| จากวันที่ / ถึงวันที่ | ช่วงที่ต้องการตรวจ | ติ๊กแสดงทั้งหมดเพื่อตรวจทุกวันที่ |

## บันทึกแล้วระบบทำอะไรให้
หน้าจอนี้ไม่แก้ยอดเงิน แต่ระหว่างตรวจ ระบบจะปรับ ประเภทรายวัน ของบรรทัดรายการให้ตรงกับหัวใบสำคัญให้เอง ระบบไล่ตรวจตามหัวข้อนี้ แถวที่ผิดจะขึ้นคำว่า "พบข้อผิดพลาด" ในช่อง รายการตรวจสอบ และบอก วันที่ เลขที่เอกสาร สมุดรายวัน (หรือประเภทเอกสาร) ในช่อง รายละเอียด
| หัวข้อที่ขึ้นบนจอ | แปลว่า | ทำอย่างไร |
|---|---|---|
| เอกสารข้อมูลรายวันที่ไม่กำหนดประเภทเอกสาร | เอกสารซื้อ ขาย หรือสต็อก ที่ไม่ได้ระบุรูปแบบเอกสาร ระบบจึงไม่รู้ว่าจะลงบัญชีตามแบบไหน | ส่งต่อทีมงาน |
| ตรวจสอบรายวันย่อยที่ไม่มีผังบัญชี | ใช้รหัสบัญชีที่ไม่มีในผังบัญชี | [[ts-gl-account-not-found]] |
| ตรวจสอบรายวันย่อยที่ใช้ผังบัญชีหลัก | ลงบัญชีไปที่บัญชีหลัก (บัญชีหัวข้อ) แทนบัญชีย่อย | [[ts-gl-control-account-used]] |
| ตรวจสอบรายวันที่ยอดเดบิตกับเครดิตไม่เท่ากัน | ใบสำคัญไม่ดุล | [[ts-gl-debit-credit-not-equal]] |
| ตรวจสอบรายวันที่ไม่พบหัวเอกสาร | มีรายการบัญชีแต่ไม่มีหัวใบสำคัญ | ส่งต่อทีมงาน |
| ตรวจสอบรายวันที่ไม่พบสมุดรายวัน | ใช้สมุดรายวันที่ไม่มีในกำหนดสมุดบัญชี | เพิ่มสมุดนั้น ([[howto-gl-setup-book-group]]) |
| ตรวจสอบเอกสารที่ยังไม่ได้ประมวลผลลงบัญชี (รายวัน) | เอกสารซื้อขาย/สต็อกที่ไม่มีรายการบัญชี | [[ts-gl-document-no-journal]] |
| ตรวจสอบเอกสารรับ/จ่ายชำระที่ยังไม่ได้ประมวลผลลงบัญชี | รับ/จ่ายชำระหนี้ที่ไม่มีรายการบัญชี | [[ts-gl-document-no-journal]] |

## แก้ไข ยกเลิก พิมพ์
- แก้ที่เอกสารต้นทางหรือใบสำคัญ แล้วกลับมากดเริ่มตรวจสอบใหม่จนไม่พบข้อผิดพลาด

## ปัญหาที่พบบ่อย
- แถวที่ขึ้น "พบข้อผิดพลาด" ใต้หัวข้อใด = หัวข้อนั้นมีรายการผิด ดูเลขที่เอกสารในช่อง รายละเอียด
- ข้อความขึ้นต้นด้วย "คำสั่งผิดพลาด: ..." → ระบบตรวจหัวข้อนั้นไม่สำเร็จ ส่งต่อทีมงาน
