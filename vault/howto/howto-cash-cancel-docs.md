# ยกเลิกเอกสารเงินสดย่อย รายได้อื่น และค่าใช้จ่ายอื่น

**ใช้เมื่อ:** เอกสารบันทึกไปแล้ว และต้องการยกเลิกโดยเก็บประวัติไว้ (ไม่ลบทิ้ง)
**เมนู:** เงินสด/ธนาคาร › ยกเลิกเอกสารเงินสดย่อย รายได้อื่น และค่าใช้จ่ายอื่น › เลือกเมนูยกเลิกที่ตรงกับเอกสารเดิม เช่น ยกเลิกรายได้อื่นๆ ยกเลิกค่าใช้จ่ายอื่นๆ ยกเลิกรับ/เพิ่ม วงเงินสดย่อย ยกเลิกคืน/ลด วงเงินสดย่อย และยกเลิกเพิ่มหนี้/ลดหนี้ ของรายได้อื่นและค่าใช้จ่ายอื่น
**ต้องมีก่อน:** เลขที่เอกสารเดิมที่จะยกเลิก

## ขั้นตอน
1. เปิดเมนูยกเลิกที่ตรงกับชนิดเอกสารเดิม จอจะแสดง "โหมดยกเลิกเอกสาร"
2. กด "เลือกเอกสาร" แล้วเลือกเอกสารเดิมที่ต้องการยกเลิก
3. ใส่วันที่ของเอกสารยกเลิก และ "หมายเหตุ" (ระบุเหตุผลการยกเลิก)
4. กด "บันทึกยกเลิก" ระบบแจ้ง "ยกเลิกเอกสาร ... เรียบร้อยแล้ว"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เอกสารอ้างอิง | เอกสารเดิม | ต้องเลือก ไม่งั้นขึ้น "กรุณาระบุเลขที่เอกสารอ้างอิง" |
| วันที่ | วันที่ยกเลิก | ต้องอยู่ในงวดที่ยังไม่ปิด |
| หมายเหตุ | เหตุผล | |

## บันทึกแล้วระบบทำอะไรให้
- เอกสารเดิมถูกทำเครื่องหมายว่ายกเลิก แต่รายการบัญชีเดิมยังอยู่
- เอกสารยกเลิกลงบัญชีกลับด้านของใบเดิม ด้วยวันที่ของเอกสารยกเลิก ยอดสุทธิจึงหักล้างกัน
- ถ้าใบเดิมรับ/จ่ายด้วยเช็คหรือบัตร สถานะในทะเบียนเช็คถูกคำนวณใหม่
- ระบบตรวจงวดบัญชีทั้งวันที่ใบเดิมและวันที่ยกเลิก

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกผิดใบ เปิดเมนูยกเลิกเดิม กด "เลือกเอกสาร" เลือกใบเดิมที่ถูกยกเลิกไว้ แล้วกด "คืนสถานะเอกสารปกติ" ระบบลบใบยกเลิกออก ใบเดิมกลับมาเป็นปกติ
- ถ้ายังไม่มีเอกสารอื่นอ้างถึง จะใช้วิธีลบเอกสารเดิมแทนก็ได้ ([[howto-doc-edit-cancel-delete]])
