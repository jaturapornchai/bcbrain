# กำหนดบัญชีที่จะลงอัตโนมัติ ตามรูปแบบเอกสาร (ส่วนที่ 2 GL)

**ใช้เมื่อ:** อยากให้เอกสารแต่ละแบบลงบัญชีอัตโนมัติไปบัญชีที่กิจการกำหนดเอง แทนบัญชีมาตรฐาน
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรูปแบบเลขที่เอกสาร (เฉพาะ Admin)
**ต้องมีก่อน:** ผังบัญชี ([[howto-gl-chart-of-accounts]]), สมุดบัญชี ([[howto-gl-setup-book-group]])

## ขั้นตอน
1. เปิดรูปแบบเอกสารที่ต้องการ กดแก้ไข
2. ช่อง "สมุดรายวัน (GL Journal Book) :" เลือกสมุดที่จะลง และ "คำอธิบายรายวัน GL (GL Description) :" ใส่คำอธิบายที่จะขึ้นในใบสำคัญ
3. เลื่อนลงไปที่ "ส่วนที่ 2: GL (ผูกบัญชีรายวันอัตโนมัติ)"
4. กด "Get Format" ระบบดึงเงื่อนไขเริ่มต้นของหน้าจอนั้นมาให้ (ถ้ามีของเดิม ระบบถาม "ต้องการล้างของเก่าหรือไม่" เลือก ล้างของเก่า หรือ ไม่ล้าง)
5. ในแต่ละเงื่อนไข เลือก ผังบัญชี (เดบิต) และ ผังบัญชี (เครดิต) ที่ต้องการ หรือกด เพิ่มแถว เอง
6. กดบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| สมุดรายวัน | สมุดบัญชีของเอกสารแบบนี้ | |
| เลขเงื่อนไข / ชื่อเงื่อนไข | ยอดไหนของเอกสาร เช่น มูลค่าสินค้า ภาษี | ได้จาก Get Format |
| ผังบัญชี (เดบิต) / ผังบัญชี (เครดิต) | บัญชีที่จะลง | ใช้บัญชีย่อย |

## บันทึกแล้วระบบทำอะไรให้
- เอกสารที่ใช้รูปแบบนี้ บันทึกครั้งต่อไปจะลงบัญชีตามเงื่อนไขที่ผูกไว้
- เอกสารเก่าไม่เปลี่ยนเอง ต้องสั่ง ประมวลผลจากข้อมูลรายวัน ตามช่วงวันที่ ([[howto-gl-process-from-documents]])
- ถ้าเงื่อนไขที่ผูกไว้ทำให้เดบิตไม่เท่ากับเครดิต ระบบไม่ใช้การผูกนี้ แล้วลงบัญชีแบบมาตรฐานแทน โดยไม่มีข้อความเตือนบนจอ
- ถ้าวันที่เอกสารไม่อยู่ในงวดที่เปิด (เช่น ตอนสั่ง ประมวลผลจากข้อมูลรายวัน ย้อนหลังในงวดที่ปิดแล้ว) ระบบไม่ลงบัญชีให้เอกสารนั้นเลย ไม่ได้ลงแบบมาตรฐานแทน และไม่เตือนบนจอ
- จึงควรเปิดแท็บ การลงบัญชี (GL) ของเอกสารตัวอย่างตรวจดูหลังผูกบัญชีทุกครั้ง

## แก้ไข ยกเลิก พิมพ์
- ลบทุกแถวในส่วนที่ 2 แล้วบันทึก = กลับไปใช้การลงบัญชีมาตรฐาน

## ปัญหาที่พบบ่อย
- "กรุณาเลือกรหัสหน้าจอก่อนดึงรูปแบบ" → เลือกรหัสหน้าจอของรูปแบบเอกสารก่อนกด Get Format
- "ยังไม่มีการผูกเงื่อนไขผังบัญชี GL ..." → ยังไม่ได้ผูก ระบบใช้บัญชีมาตรฐาน
- ไม่เห็นส่วนที่ 2 → รุ่นที่ใช้ไม่มีระบบบัญชีแยกประเภท ([[faq-gl-starter-no-gl]])
