# ประมวลผลสิ้นปี (ปิดบัญชีสิ้นปีเข้ากำไรสะสม)

**ใช้เมื่อ:** สิ้นปีบัญชี ต้องการสร้างใบสำคัญปิดบัญชีรายได้และค่าใช้จ่ายทั้งปี เข้าบัญชีกำไรสะสม (กำไรสะสม = กำไรขาดทุนสะสมของกิจการตั้งแต่เริ่ม)
**เมนู:** บัญชี › ประมวลผลสิ้นปี (เมนู บัญชี › ประมวลผลกำไร/ขาดทุน และต้นทุนขาย เปิดหน้าจอเดียวกันนี้)
**ต้องมีก่อน:** งวดบัญชีของปีนั้น ([[howto-gl-account-period]]), สมุดบัญชีสำหรับปิดปี, บัญชีกำไรสะสมที่เป็นบัญชีย่อย, ผู้ใช้ระดับ Admin ([[faq-gl-who-can-close]])

## ขั้นตอน
1. เปิดเมนู ประมวลผลสิ้นปี
2. กรอก ปีบัญชีที่ปิดสิ้นปี (ระบบใช้วันแรกถึงวันสุดท้ายของงวดในปีนั้น ถ้าเว้นว่าง ระบบใช้ช่อง จากวันที่ และ ถึงวันที่ บนหน้าจอแทน)
3. กรอก เลขที่เอกสารปิดบัญชีสิ้นปี, สมุดรายวันปิดบัญชีสิ้นปี, รหัสบัญชีกำไรสะสมสุทธิ, หมายเหตุการปิดบัญชีสิ้นปีและยกยอด
4. กด "ประมวลผล" ดูตัวอย่างรายการและยอด กำไรสุทธิ/ขาดทุนสุทธิ และตรวจ "ช่วงวันที่" ให้ครบทั้งปี
5. กด "บันทึก" แล้วยืนยัน ระบบขึ้น "บันทึกเอกสาร ... เรียบร้อย (... บรรทัด)"
6. ล็อกปีเก่าไม่ให้แก้ไข: เปลี่ยนสถานะงวดของปีนั้นเป็นปิดที่ กำหนดงวดบัญชี
7. สร้างงวดของปีใหม่ ถ้ายังไม่มี

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ปีบัญชีที่ปิดสิ้นปี | ปีที่จะปิด | ต้องมีงวดของปีนี้ |
| เลขที่เอกสารปิดบัญชีสิ้นปี | เลขใบสำคัญ | ไม่เกิน 25 ตัว ห้ามซ้ำกับเอกสารอื่น |
| สมุดรายวันปิดบัญชีสิ้นปี | สมุดบัญชี | |
| รหัสบัญชีกำไรสะสมสุทธิ | บัญชีที่รับยอด | ต้องเป็นบัญชีย่อย |

## บันทึกแล้วระบบทำอะไรให้
- วิธีคำนวณเหมือนประมวลผลสิ้นงวด แต่ช่วงวันที่เป็นทั้งปี และผลต่างลงบัญชีกำไรสะสม
- ใบสำคัญลงวันที่วันสุดท้ายของปี
- ระบบไม่ล็อกปี และไม่ได้สร้างใบยกยอด ยอดยกมาปีใหม่ของบัญชีงบดุลระบบคำนวณในรายงานเอง ([[faq-gl-carry-forward]])

## แก้ไข ยกเลิก พิมพ์
- ประมวลผลใหม่ด้วยเลขที่เดิม ระบบลบใบเดิมแล้วสร้างใหม่ทับ ตอนกด "ประมวลผล" รอบหลังตารางอาจว่างเพราะนับใบเดิมรวมอยู่ แต่ตอนบันทึกระบบลบใบเดิมก่อนแล้วคำนวณใหม่

## ปัญหาที่พบบ่อย
- ถ้าทำประมวลผลสิ้นงวดครบทุกเดือนแล้ว ยอดรายได้/ค่าใช้จ่ายของทั้งปีจะเป็นศูนย์ ระบบจึงขึ้น "ไม่มียอดรายได้/ค่าใช้จ่ายในช่วงวันที่ ... ถึง ..." ให้เลือกปิดแบบใดแบบหนึ่ง (รายงวด หรือสิ้นปี) ตามที่ผู้สอบบัญชีแนะนำ
