# ตั้งค่าระบบสินทรัพย์ถาวร (ประเภท ที่ตั้ง การบำรุงรักษา ประเภทการตัดจำหน่าย)

**ใช้เมื่อ:** ก่อนเริ่มทำทะเบียนสินทรัพย์ ต้องการแบ่งกลุ่มสินทรัพย์ ระบุสถานที่ตั้ง และเตรียมรายการซ่อมบำรุง
**เมนู:** เริ่มต้น › ตั้งค่าระบบสินทรัพย์ถาวร › กำหนดประเภทสินทรัพย์ / กำหนดตำแหน่งที่ตั้งสินทรัพย์ / กำหนดการบำรุงรักษาสินทรัพย์ / กำหนดหน่วยการบำรุงรักษาสินทรัพย์ / กำหนดประเภทการตัดจำหน่าย
**ต้องมีก่อน:** ไม่มี

## ใช้ทำอะไร
| เมนู | ใช้ที่ไหน |
|---|---|
| กำหนดประเภทสินทรัพย์ | ช่อง "ประเภทสินทรัพย์" ในข้อมูลสินทรัพย์ และใช้กรองช่วงตอนโอนค่าเสื่อม |
| กำหนดตำแหน่งที่ตั้งสินทรัพย์ | ช่อง "ที่ตั้งสินทรัพย์" ในข้อมูลสินทรัพย์ |
| กำหนดการบำรุงรักษาสินทรัพย์ | ช่อง "รหัสบำรุงรักษา" ในบันทึกการซ่อมบำรุง |
| กำหนดหน่วยการบำรุงรักษาสินทรัพย์ | ช่อง "หน่วยบำรุงรักษา" ในบันทึกการซ่อมบำรุง |
| กำหนดประเภทการตัดจำหน่าย | เก็บเป็นข้อมูลอ้างอิง ยังไม่มีหน้าจอใดนำไปใช้ ([[faq-asset-write-off]]) |

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่"
2. ใส่ "รหัส:" "ชื่อ:" และ "ชื่อภาษาอังกฤษ:" (ถ้ามี)
3. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส | รหัสสั้นๆ เช่น ตัวย่อหมวด | ใช้ค้นหาในหน้าจออื่น |
| ชื่อ | ชื่อที่แสดง | |

## บันทึกแล้วระบบทำอะไรให้
- ไม่ลงบัญชี เป็นข้อมูลพื้นฐานให้เลือกในหน้าจออื่น
- ประเภทสินทรัพย์ **ไม่ได้เก็บผังบัญชี** ผังบัญชีสินทรัพย์ ค่าเสื่อม และค่าเสื่อมสะสม กำหนดที่สินทรัพย์แต่ละรายการ ([[howto-asset-register]])

## แก้ไข ยกเลิก พิมพ์
- แก้ชื่อได้ตลอด ([[howto-doc-edit-cancel-delete]])
- **ข้อควรระวัง:** ตอนลบ ระบบไม่ได้ตรวจว่ามีสินทรัพย์หรือบันทึกซ่อมบำรุงใช้รหัสนี้อยู่ ถ้าลบรหัสที่ใช้อยู่ไปแล้ว รายงานสินทรัพย์จะแสดงเป็นรหัสแทนชื่อ และตอนแก้เอกสารที่ใช้รหัสนั้นจะบันทึกไม่ผ่าน ขึ้น "ไม่พบประเภทสินทรัพย์" หรือ "ไม่พบสถานที่" ให้ตรวจก่อนลบ หรือสร้างรหัสเดิมกลับคืน

## ปัญหาที่พบบ่อย
- ข้อมูลสินทรัพย์ขึ้น "ไม่พบประเภทสินทรัพย์" หรือ "ไม่พบสถานที่" → ยังไม่ได้สร้างรหัสนั้นในเมนูนี้ หรือพิมพ์รหัสผิด
