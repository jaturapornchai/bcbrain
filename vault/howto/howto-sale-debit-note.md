# เก็บเงินลูกค้าเพิ่ม (เพิ่มหนี้ขาย/ราคาผิด)

**ใช้เมื่อ:** เปิดบิลขายไปแล้วพบว่าคิดราคาต่ำไป หรือต้องส่งของเพิ่มโดยอ้างบิลเดิม ต้องออกใบเพิ่มหนี้ (เอกสารเพิ่มยอดที่ลูกค้าค้างเรา)
**เมนู:** ขาย › เพิ่มหนี้ขาย/ราคาผิด
**ต้องมีก่อน:** ใบขายเดิม ([[howto-sale-invoice]])

## เลือกประเภทให้ถูก (ช่อง "ประเภทการเพิ่มหนี้")
| ประเภทการเพิ่มหนี้ | ใช้เมื่อ | สต็อก |
|---|---|---|
| เพิ่มหนี้จากการขายเงินเชื่อ | ส่งสินค้าเพิ่ม | ตัดสต็อกเพิ่ม |
| เพิ่มหนี้จากการขายเงินเชื่อ (ไม่กระทบสต๊อก) | ราคาผิด ไม่มีของเพิ่ม | ไม่กระทบ |
| เพิ่มหนี้จากการขายสินค้าเงินเชื่อ (สินค้าบริการ) | เพิ่มค่าบริการ | ไม่กระทบ |

## ขั้นตอน
1. เปิด ขาย › เพิ่มหนี้ขาย/ราคาผิด กด "เพิ่มใหม่" ใส่วันที่ เลขที่เอกสาร
2. เลือก "ลูกหนี้/ลูกค้า" "ภาษี" และ "ประเภทการเพิ่มหนี้"
3. กด "ดึงเอกสาร" เลือกใบขายเดิม ระบบดึงรายการสินค้ามา แต่ช่องจำนวน ราคา ส่วนลด และมูลค่าจะว่างไว้ให้ใส่ใหม่
4. ใส่จำนวน/ราคาส่วนที่เพิ่ม
5. ใส่ "สาเหตุ" และเลขที่ใบกำกับภาษีของใบเพิ่มหนี้
6. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทการเพิ่มหนี้ | 1 ใน 3 แบบด้านบน | กำหนดว่าตัดสต็อกหรือไม่ |
| เอกสารอ้างอิง | ใบขายเดิม | ปุ่ม "ดึงเอกสาร" |
| สาเหตุ | เหตุผลที่เพิ่มหนี้ | ช่องขึ้นว่า "สาเหตุการเพิ่ม/ลดหนี้..." |
| เลขที่ใบกำกับภาษี / ลงวันที่ | เลขของใบเพิ่มหนี้ | บังคับเมื่อเปิด "ป้อนเลขที่ใบกำกับภาษีทุกครั้ง" |
| จำนวน / ราคา | ส่วนที่เพิ่ม | ระบบไม่เติมให้ |

## บันทึกแล้วระบบทำอะไรให้
- **สต็อก:** เฉพาะประเภทแรกที่ตัดสต็อก และถ้าเปิดข้อเลือกห้ามขายติดลบ จะถูกตรวจสต็อกด้วย ([[ts-sale-stock-negative]])
- **ลูกหนี้:** ทั้ง 3 ประเภทเพิ่มยอดค้างของลูกค้า ไปวางบิลและรับชำระต่อได้ ([[howto-ar-billing]])
- **ภาษี:** สร้างรายการภาษีขายเพิ่ม (ยกเว้นประเภทภาษี "ไม่กระทบภาษี")
- **ลงบัญชีอัตโนมัติ:** เดบิต ลูกหนี้การค้า / เครดิต ขายสินค้า และ ภาษีขาย
- หน้าจอนี้ไม่มีแท็บรับเงิน ลูกค้าจ่ายส่วนเพิ่มให้รับที่ใบเสร็จ ([[howto-ar-receipt]])
- **ข้อสังเกต:** ประเภท "เพิ่มหนี้จากการขายเงินเชื่อ (ไม่กระทบสต๊อก)" ระบบลงบัญชีฝั่งเดบิตเป็นเงินสดแทนลูกหนี้การค้า ทั้งที่ยอดถูกนับเป็นหนี้ค้างของลูกค้า ให้ตรวจแท็บ "การลงบัญชี (GL)" และแจ้งทีมงานถ้าต้องการให้ลงลูกหนี้

## แก้ไข ยกเลิก พิมพ์
- แก้ได้จนกว่าจะถูกวางบิลหรือรับชำระ ([[howto-sale-edit-delete]])
- ยกเลิก: ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกเพิ่มหนี้ขาย/ราคาผิด ([[howto-sale-cancel-docs]])
