# บันทึกภาษีหัก ณ ที่จ่าย และภาษีถูกหัก ณ ที่จ่าย

**ใช้เมื่อ:** จ่ายเงินแล้วหักภาษีไว้จากผู้รับเงิน (ภาษีหัก ณ ที่จ่าย) หรือรับเงินจากลูกค้าที่หักภาษีเราไว้ (ภาษีถูกหัก ณ ที่จ่าย) ต้องการให้ขึ้นรายงาน ภ.ง.ด.3 / ภ.ง.ด.53 หรือรายงานภาษีถูกหัก (ภาษีหัก ณ ที่จ่าย = ภาษีเงินได้ที่ผู้จ่ายเงินหักไว้ก่อนแล้วนำส่งสรรพากรแทนผู้รับเงิน)
**เมนู:**
- ในเอกสาร (ซื้อ ขาย ค่าใช้จ่ายอื่น รายได้อื่น มัดจำ ฯลฯ): แท็บ ข้อมูลภาษี (VAT/WHT) ส่วน ภาษีหัก ณ. ที่จ่าย หรือ ภาษีถูกหัก ณ. ที่จ่าย อยู่ใต้ส่วนภาษีมูลค่าเพิ่ม (ฝั่งไหนขึ้นตามชนิดเอกสาร)
- จ่ายชำระหนี้ / รับชำระหนี้: แท็บ ภาษีหัก ณ. ที่จ่าย / ภาษีถูกหัก ณ. ที่จ่าย
- บัญชี › ข้อมูลรายวัน: แท็บ ภาษีหัก ณ. ที่จ่าย (เราหักคนอื่น) หรือ ภาษีถูกหัก ณ. ที่จ่าย (ลูกค้าหักเรา)

**ต้องมีก่อน:** ทะเบียนเจ้าหนี้/ลูกหนี้ของคู่ค้า ที่เลือก บุคคลธรรมดา / นิติบุคคล ไว้ถูกต้อง ([[faq-tax-pnd3-vs-pnd53]])

## ขั้นตอน
1. เปิดเอกสารหรือใบสำคัญ กดแก้ไข ไปแท็บภาษีตามด้านบน
2. กด เพิ่ม ได้ 1 ใบหัก ณ ที่จ่าย กรอก วันที่หัก ณ ที่จ่าย, เอกสารเลขที่ (เลขที่ใบหัก ณ ที่จ่าย) และ รหัสลูกหนี้/เจ้าหนี้ (ในเอกสาร ระบบใส่รหัสของเอกสารให้)
3. ระบบเติม ประเภท เลขประจำตัวผู้เสียภาษี เลขที่บัตรประชาชน จากทะเบียนของรหัสนั้นให้เอง ช่องเหล่านี้แก้บนจอไม่ได้
4. ในตาราง รายละเอียดภาษีหัก ณ ที่จ่าย ใส่ รายละเอียด (ประเภทเงินได้) ฐานภาษี อัตราภาษี ระบบคิด ภาษีหัก ณ ที่จ่าย ให้ (ถ้าพิมพ์ยอดภาษีโดยไม่ใส่อัตรา ระบบคิดอัตราให้) กด เพิ่มบรรทัด ถ้ามีหลายประเภทเงินได้
5. มีหลายใบ กด เพิ่ม อีกใบ (คลิกแถวในรายการด้านบนเพื่อแก้ใบนั้น) แล้วบันทึกเอกสาร

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เอกสารเลขที่ | เลขที่ใบหัก ณ ที่จ่าย | บังคับ และห้ามซ้ำกับเอกสารอื่นทั้งระบบ |
| วันที่หัก ณ ที่จ่าย | วันที่หักภาษี | ตั้งต้นเป็นวันที่เอกสาร · รายงานดึงตามวันนี้ |
| รหัสลูกหนี้/เจ้าหนี้ | คู่ค้า | ในเอกสาร ว่าง = ใช้รหัสของเอกสาร |
| ประเภท | บุคคลธรรมดา / นิติบุคคล (แสดงอย่างเดียว) | มาจากทะเบียนคู่ค้า ใช้แยกรายงาน ภ.ง.ด.3 กับ ภ.ง.ด.53 · ไม่มีรหัส = บุคคลธรรมดา |
| เลขประจำตัวผู้เสียภาษี / เลขที่บัตรประชาชน | (แสดงอย่างเดียว) | มาจากทะเบียนคู่ค้า |
| รายละเอียด / ฐานภาษี / อัตราภาษี / ภาษีหัก ณ ที่จ่าย | ประเภทเงินได้และยอดแต่ละบรรทัด | บรรทัดที่ไม่มีรายละเอียด ระบบไม่เก็บ · อัตราเริ่มที่ 0 ต้องใส่เอง · อัตราตามกฎหมายให้ปรึกษาผู้สอบบัญชี/สรรพากร |

## บันทึกแล้วระบบทำอะไรให้
- ยอดรวมของใบ = ผลรวมบรรทัดรายละเอียด
- ภาษีหัก ณ ที่จ่าย ขึ้นรายงาน ภงด.53 / ภงด.3 · ภาษีถูกหัก ขึ้นรายงานภาษีถูกหัก ณ. ที่จ่าย ([[howto-tax-wht-report]])
- ระบบไม่เติมแถวหัก ณ ที่จ่ายจากหัวเอกสารให้ ต้องกด เพิ่ม และกรอกเองทุกครั้ง
- เอกสารฝั่งซื้อ/จ่าย (ซื้อ ส่งคืน ค่าใช้จ่ายอื่น มัดจำจ่าย จ่ายชำระหนี้) เป็น ภาษีหัก ณ ที่จ่าย · ฝั่งขาย/รับ (ขาย รับคืน รายได้อื่น ขายสินทรัพย์ มัดจำรับ รับชำระหนี้) เป็น ภาษีถูกหัก ณ ที่จ่าย

## แก้ไข ยกเลิก พิมพ์
- แก้แล้วบันทึกเอกสาร ระบบแทนที่แถวหัก ณ ที่จ่ายเดิมของเอกสารทั้งหมด และดึงประเภท/เลขผู้เสียภาษีจากทะเบียนคู่ค้าใหม่
- ลบใบสำคัญ = ลบแถวหัก ณ ที่จ่ายของใบนั้นด้วย · ยกเลิกเอกสาร รายงานแสดงยอด 0 สถานะ ยกเลิก
- หนังสือรับรองการหักภาษี ณ ที่จ่าย → [[faq-tax-wht-certificate]]

## ปัญหาที่พบบ่อย
- "ภาษีหัก ณ ที่จ่าย: กรุณาระบุเลขที่เอกสารหัก ณ ที่จ่าย" (หรือ "ภาษีถูกหัก ณ ที่จ่าย: ...") → มีรายละเอียดหรือรหัสคู่ค้าแล้ว แต่ไม่ได้ใส่ เอกสารเลขที่
- "ภาษีหัก ณ ที่จ่าย: เลขที่เอกสาร ... ซ้ำ" → ใส่เลขเดียวกัน 2 ใบในเอกสารเดียว
- "เลขที่เอกสารหัก ณ ที่จ่าย ... ซ้ำกับเอกสารอื่น" → เลขนี้ใช้ในเอกสารอื่นแล้ว เปลี่ยนเลข
- ประเภทผิด (ควรเป็นนิติบุคคลแต่ขึ้นบุคคลธรรมดา) → แก้ในทะเบียนเจ้าหนี้/ลูกหนี้ แล้วเปิดเอกสารมาบันทึกใหม่ ([[faq-tax-pnd3-vs-pnd53]])
- ไม่ขึ้นรายงาน → [[ts-tax-wht-not-in-report]]
