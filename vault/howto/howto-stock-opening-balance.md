# บันทึกสินค้าคงเหลือยกมา (เริ่มใช้ระบบ)

**ใช้เมื่อ:** เริ่มใช้ระบบครั้งแรก ต้องใส่จำนวนและต้นทุนสินค้าที่มีอยู่ ณ วันเริ่ม
**เมนู:** สินค้า › สินค้า/วัตถุดิบ คงเหลือยกมา
**ต้องมีก่อน:** ข้อมูลสินค้า หน่วยนับ คลังและที่เก็บ ([[howto-stock-item-master]], [[howto-stock-warehouse-shelf]]) ผังบัญชี ([[howto-gl-overview]])

## ขั้นตอน
1. เปิดเมนู สินค้า/วัตถุดิบ คงเหลือยกมา กดเพิ่ม
2. กรอก เลขที่เอกสาร และ วันที่เอกสาร (ใช้วันก่อนวันเริ่มใช้ระบบ)
3. แท็บ รายละเอียด: ใส่สินค้าทีละแถว พร้อมคลัง ที่เก็บ หน่วยนับ จำนวน และต้นทุน/หน่วย (สินค้า LOT ใส่เลข LOT ได้ หน้าจอนี้ไม่บังคับ, สินค้า Serial กดปุ่ม บันทึก/ดู Serial Number)
4. แท็บ GL: ดูรายการบัญชีที่ระบบเตรียมให้ แก้ได้ถ้าติ๊ก บันทึกรายการบัญชีตรง
5. กดบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เลขที่เอกสาร | เลขที่ใบยกมา | ต้องกรอก |
| รายการสินค้า | อย่างน้อย 1 แถว | |
| จำนวน / ต้นทุน/หน่วย | ยอดและต้นทุนจริง ณ วันยกมา | ต้นทุนนี้เป็นจุดเริ่มต้นของต้นทุนเฉลี่ย |
| หน่วยนับขนาน / จำนวนหน่วยขนาน | ถ้าสินค้าเป็นหน่วยนับขนาน | ต้องกรอก |
| แท็บ GL | บัญชีคู่ของยอดยกมา | เดบิตต้องเท่ากับเครดิต |

## บันทึกแล้วระบบทำอะไรให้
- **สต็อก:** เพิ่มจำนวนและมูลค่าตามที่กรอก แล้วคำนวณต้นทุนเฉลี่ยใหม่
- **บัญชี:** ถ้าไม่ติ๊ก บันทึกรายการบัญชีตรง ระบบเตรียมให้ 2 บรรทัด เดบิต สินค้าคงเหลือสำเร็จรูป / เครดิต ทุนเรือนหุ้นสามัญ เท่ามูลค่ารวม คำอธิบาย "สินค้ายกมา" ถ้าบัญชีคู่ของกิจการไม่ใช่ทุน (เช่น ยอดยกมาจากงบเดิม) ให้ติ๊กแล้วแก้บัญชีเอง เรื่องจะใช้บัญชีไหนปรึกษาผู้สอบบัญชี

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้จากเมนูเดียวกัน บันทึกใหม่แล้วระบบคำนวณสต็อกและต้นทุนใหม่
- **ข้อควรรู้:** หน้าจอนี้ไม่ตรวจงวดบัญชีที่ปิดแล้ว ระบบยอมให้แก้หรือลบได้แม้งวดปิดแล้ว ควรแก้ยอดยกมาก่อนปิดงวดแรก และแจ้งผู้ทำบัญชีทุกครั้งที่แก้ ถ้าลูกค้าแก้ไปแล้วหลังปิดงวด ให้ส่งต่อเจ้าหน้าที่

## ปัญหาที่พบบ่อย
- "ยอดเดบิต (...) ไม่เท่ากับเครดิต (...) ในแท็บบัญชีแยกประเภท" → แก้ตัวเลขในแท็บ GL ให้ยอดสองฝั่งเท่ากัน
- "กรุณาระบุรายการสินค้าอย่างน้อย 1 รายการ" → เพิ่มแถวสินค้า
- "กรุณาระบุเลขที่เอกสาร" → กรอกเลขที่
- "ไม่พบรหัสสินค้า ..." → สร้างสินค้าก่อน ([[howto-stock-item-master]])
- "กรุณาระบุหน่วยนับขนานของสินค้า ... (...)" → ([[ts-stock-unit-not-found]])
- "Serial Number ... ของสินค้า ... ซ้ำในเอกสาร" → ([[ts-stock-serial-errors]])
