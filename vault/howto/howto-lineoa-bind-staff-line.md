# ผูกบัญชี LINE ของพนักงานกับอีเมลที่ใช้เข้าระบบ

**ใช้เมื่อ:** อยากให้ระบบรู้ว่า LINE ของพนักงานคนนี้คือใครในระบบ (อีเมลเดียวกับที่ล็อกอินเว็บ)
**เมนู:** แชท LINE OA › แถบด้านบน "ขั้นที่ 1: ผูก LINE ID ↔ Email พนักงาน" (หรือปุ่ม "⚙️ ตั้งค่าหัวบิลร้าน / ผูก LINE OA") › หน้าต่าง LINE MINI App แท็บ "① ลงทะเบียน ... & ตั้งหัวบิล (15 วิ)"
**ต้องมีก่อน:** อีเมลของพนักงานที่มีในระบบ และรหัสผู้ใช้ LINE (LINE User ID) ของพนักงาน — ภาพรวม [[sys-lineoa-overview]]

## ขั้นตอน
1. เปิดหน้าแชท LINE OA กดปุ่มขั้นที่ 1 ที่แถบสีเขียวด้านบน หน้าต่างจะเปิด
2. หาการ์ดสีฟ้า "ผูกบัญชีพนักงาน: LINE User ID ↔ Email"
3. กรอก "Email พนักงาน", "LINE User ID", "ชื่อพนักงานบน LINE"
4. กด "🔗 ผูก LINE ID ↔ Email พนักงาน"
5. สำเร็จแล้วขึ้นข้อความ "🔗 ผูก LINE ID ↔ Email พนักงานสำเร็จ!" และป้ายเปลี่ยนเป็น "✅ เชื่อม LINE ↔ Email แล้ว"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| Email พนักงาน | อีเมลที่ใช้ล็อกอินเว็บ | ต้องมีเครื่องหมาย @ |
| LINE User ID | รหัสผู้ใช้ LINE ขึ้นต้นด้วยตัวอักษร U | **ต้องกรอกเอง** ตอนนี้ระบบไม่ดึงให้อัตโนมัติ |
| ชื่อพนักงานบน LINE | ชื่อที่แสดงใน LINE | ใช้จำว่าเป็นใคร |

## บันทึกแล้วระบบทำอะไรให้
- LINE หนึ่งบัญชีผูกได้กับอีเมลเดียว ถ้าเคยผูกกับอีเมลอื่น ระบบถอนของเดิมออกให้
- เก็บการผูกไว้กับข้อมูลผู้ใช้ของอีเมลนั้น
- ใต้ปุ่มจะเห็นรายชื่อฐานข้อมูลที่อีเมลนี้เข้าได้

## ยกเลิกผูก
กดปุ่ม "🔌 ยกเลิกผูก LINE (กรณีลาออก)" (โผล่เมื่อผูกแล้ว) จะขึ้น "🔌 ยกเลิกการผูก LINE ID กับ Email เรียบร้อย"

## ข้อควรระวัง
บางกรณี (เช่น ระบบหลังบ้านติดต่อไม่ได้ หรือยังไม่ได้ตั้งค่าสิทธิ์ผู้ดูแล) หน้าจอยังขึ้นว่าผูกสำเร็จ **ทั้งที่ยังไม่ได้บันทึกจริง** ให้ตรวจว่าป้ายเปลี่ยนเป็น "✅ เชื่อม LINE ↔ Email แล้ว" หลังเปิดหน้าใหม่ ถ้ากลับเป็น "⏳ รอผูกบัญชี" ให้ส่งต่อเจ้าหน้าที่

## ใครทำได้
ผูกให้อีเมลของตัวเองได้ ถ้าจะผูกให้คนอื่นต้องเป็นผู้ดูแลระบบ (Admin) ของบริษัท

## ข้อจำกัด
การผูกนี้ **ยังไม่ได้ทำให้พนักงานสั่งงานผ่าน LINE จริง** เพราะระบบยังไม่เชื่อม LINE จริง ดู [[faq-lineoa-connect-real-line]]
