# ขายสด รับเงินสด เงินโอน PromptPay เช็ค บัตรเครดิต

**ใช้เมื่อ:** เปิดบิลแบบ "ขายสด" รับเงินมัดจำ/เงินล่วงหน้า คืนเงินลูกค้า หรือออกใบเสร็จรับชำระหนี้ แล้วต้องบันทึกว่ารับเงินมาทางไหนบ้าง จ่ายผสมหลายช่องทางในใบเดียวได้
**เมนู:** แท็บ "การรับ/จ่ายชำระเงิน" ในหน้าจอ ขาย › ขายสินค้า/บริการ (เลือกขายสด), รับเงินล่วงหน้า, รับเงินมัดจำ, รับคืนสินค้า/ลดหนี้ขาย (แบบเงินสด), ลูกหนี้ › รับชำระหนี้/ออกใบเสร็จรับเงิน
**ต้องมีก่อน:** สมุดเงินฝากธนาคาร และรหัสธนาคาร ([[howto-cash-bank-overview]])

## ขั้นตอน
1. คีย์เอกสารให้ครบ (ลูกค้า สินค้า ยอดเงิน) ก่อน
2. เปิดแท็บ "การรับ/จ่ายชำระเงิน" ด้านบนจะเห็น "สรุปยอดการรับ/จ่ายชำระเงิน (รวมตัวเลขจากรายการด้านล่างอัตโนมัติ)"
3. ใส่แต่ละช่องทางในตารางด้านล่าง (กดปุ่มเพิ่มรายการได้หลายแถว)
   - เงินโอน: "เพิ่มรายการเงินโอน" ใส่ สมุดเงินฝาก วันที่โอน เลขอ้างอิง/สลิป จำนวนเงิน
   - PromptPay / QR: "เพิ่มรายการ PromptPay" ใส่ สมุดบัญชี/PromptPay เลขอ้างอิงสลิป วันที่โอน จำนวนเงิน
   - เช็ค: "เพิ่มรายการเช็ค" ใส่ เลขที่เช็ค รหัสธนาคาร สาขา วันถึงกำหนด จำนวนเงิน (ระบบขึ้นทะเบียนเช็คให้อัตโนมัติ)
   - บัตรเครดิต: ใส่ เลขที่บัตร รหัสอนุมัติ สมุดบัญชี/EDC ค่าธรรมเนียม จำนวนเงิน
4. ส่วนที่เหลือเป็นเงินสด กดปุ่ม "คำนวณยอดเงินสด (ส่วนที่เหลือ ...)" ระบบใส่ยอดใน "ชำระด้วยเงินสด:" ให้
5. ถ้าลูกค้าให้แบงก์ใหญ่ ใส่ "รับเงินสดมา:" ระบบคำนวณ "เงินทอน:"
6. ดูบรรทัด "รวมรับ/จ่ายชำระทั้งสิ้น:" ต้องขึ้น "✓ ยอดรับ/จ่ายชำระครบถ้วนตรงตามยอดสุทธิ" แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| 1. ยอดตามเอกสาร | ระบบใส่ให้ | ยอดสุทธิของบิล |
| 3. รวมเงินโอนธนาคาร | รวมจากตารางเงินโอน | โอนหลายบัญชี/หลายสลิปได้ |
| 4. รวมชำระด้วย PromptPay / QR | รวมจากตาราง PromptPay | |
| 5. รวมชำระด้วยเช็ค | รวมจากตารางเช็ค | หลายใบได้ |
| 6. รวมชำระด้วยบัตรเครดิต | รวมจากตารางบัตร | หลายใบได้ |
| 8. ภาษีหัก ณ ที่จ่าย (นับเป็นยอดชำระ) | ภาษีที่ลูกค้าหักไว้ | บันทึกที่แท็บภาษี นับรวมเป็นยอดที่รับแล้ว |
| ชำระด้วยเงินสด | ยอดเงินสด | ใช้ปุ่มคำนวณได้ |
| รายได้อื่น / ค่าใช้จ่ายอื่น | แท็บย่อย สำหรับยอดรับหรือหักอื่นๆ ที่ไม่ใช่ค่าสินค้า | แถวที่ไม่ใส่รหัสจะไม่ถูกนับยอด |

## บันทึกแล้วระบบทำอะไรให้
- ลงบัญชีอัตโนมัติแยกตามช่องทาง: เงินสด → บัญชีเงินสด / เงินโอนและ PromptPay → บัญชีเงินฝากธนาคารตามสมุดเงินฝาก (ถ้าใบเดียวใช้หลายสมุด ระบบรวมยอดโอนไปลงบัญชีของสมุดแถวแรก) / เช็ค → เช็ครับ / ภาษีที่ถูกหัก → ภาษีถูกหัก ณ ที่จ่าย
- ยอดที่รับด้วยบัตรเครดิต ระบบลงไว้ที่บัญชีลูกหนี้ (ดูข้อสังเกตใน [[faq-sale-gl-posting]])
- เช็คที่รับ ถูกขึ้นทะเบียนเช็ครับให้ ไปติดตามเช็คต่อที่ระบบเงินสด-ธนาคาร ([[howto-cash-bank-overview]])

## แก้ไข ยกเลิก พิมพ์
- แก้ช่องทางรับเงินได้ด้วยการแก้เอกสาร (ถ้าเอกสารยังไม่ถูกล็อก) ([[howto-sale-edit-delete]])
- ใบที่มีเช็คถูกนำไปผ่านรายการเช็คแล้ว จะแก้ไม่ได้

## ปัญหาที่พบบ่อย
- "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" → ยอดรับยังไม่เท่ายอดบิล ([[ts-sale-payment-incomplete]])
- "ยอดรับ/จ่ายชำระต้องไม่ติดลบ" → มีแถวใส่ยอดติดลบ ([[ts-sale-payment-incomplete]])
- บิล "ขายเชื่อ (เครดิต)" แท็บนี้ยังกรอกได้ แต่ตอนบันทึก ระบบไม่เก็บช่องทางรับเงินที่กรอกไว้ ขายเชื่อให้รับเงินทีหลังที่ใบเสร็จ ([[faq-sale-cash-vs-credit]])
