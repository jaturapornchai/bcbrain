# เปลี่ยนรหัสผังบัญชี

**ใช้เมื่อ:** ตั้งรหัสบัญชีผิด หรือต้องการจัดรหัสใหม่ โดยไม่ต้องตามแก้ใบสำคัญเก่าทีละใบ
**เมนู:** บัญชี › ผังบัญชี (Chart of Accounts) › เปลี่ยนรหัสผังบัญชี หรือ เริ่มต้น › เปลี่ยนรหัสหลัก (สินค้า/เจ้าหนี้/ลูกหนี้/บัญชี) › เปลี่ยนรหัสผังบัญชี
**ต้องมีก่อน:** สิทธิ์ผู้ดูแลระบบ (เจ้าของหรือผู้ดูแล) เท่านั้น ([[ts-common-no-permission]])

## ขั้นตอน
1. เปิดเมนู เปลี่ยนรหัสผังบัญชี ด้านล่างมีตารางรายชื่อบัญชี (ค้นหาได้ด้วยรหัสหรือชื่อ)
2. คลิกแถวบัญชีในตาราง ระบบใส่รหัสนั้นในช่อง รหัสผังบัญชีเดิม ให้ หรือพิมพ์เอง
3. พิมพ์ รหัสผังบัญชีใหม่ (ระบบเปลี่ยนเป็นตัวพิมพ์ใหญ่ให้) กดปุ่ม + เพื่อเพิ่มแถวถัดไป ทำได้หลายคู่
4. กดปุ่ม "เริ่มเปลี่ยนรหัส"
5. ระบบถามยืนยัน "ต้องการเปลี่ยนรหัสผังบัญชี ... รายการจริงหรือไม่" กดตกลง
6. เมื่อเสร็จ ระบบแสดงผลเป็น "รหัสเดิม → รหัสใหม่ (... แถวใน ... ตาราง)"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสผังบัญชีเดิม | รหัสที่มีอยู่ในผังบัญชี | ต้องพิมพ์ตรงกับรหัสในผังทุกตัวอักษร คลิกเลือกจากตารางจะชัวร์กว่า |
| รหัสผังบัญชีใหม่ | รหัสที่ต้องการ | ต้องยังไม่มีในผังบัญชี และไม่ซ้ำกันเองในรายการ |

## บันทึกแล้วระบบทำอะไรให้
- เปลี่ยนรหัสในผังบัญชี รวมถึงบัญชีอื่นที่อ้างรหัสนี้เป็นผังบัญชีหลักหรือบัญชีปิด
- เปลี่ยนรหัสในใบสำคัญที่บันทึกไว้แล้วทุกใบ และข้อมูลมิติของบัญชี
- เปลี่ยนรหัสบัญชีที่ผูกไว้ในสินค้า ลูกหนี้ และเจ้าหนี้ด้วย
- ทั้งหมดทำในครั้งเดียว ถ้ามีจุดใดไม่สำเร็จจะไม่เปลี่ยนเลย
- จุดที่ระบบยังไม่เปลี่ยนให้ (ยังเป็นรหัสเดิม): ทะเบียนสินทรัพย์ (บัญชีสินทรัพย์ ค่าเสื่อม ค่าเสื่อมสะสม), ประเภทบัตรเครดิต, กระเป๋าเงิน, การตั้งค่าปิดบัญชี และบัญชีที่ผูกไว้ในรูปแบบเอกสาร → หลังเปลี่ยนรหัส ต้องเข้าไปแก้จุดเหล่านี้เองเป็นรหัสใหม่ ไม่อย่างนั้นเอกสารที่ลงบัญชีจากจุดเหล่านี้จะฟ้อง "ไม่พบผังบัญชี" ([[ts-gl-account-not-found]]) ถ้าไม่แน่ใจให้ส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- ไม่มีปุ่มย้อนกลับ ถ้าเปลี่ยนผิดให้ทำซ้ำโดยสลับรหัสใหม่กลับเป็นรหัสเดิม
- ทำได้ครั้งละ 1-500 คู่

## ปัญหาที่พบบ่อย
- "กรุณาระบุรหัสเดิมและรหัสใหม่" → ยังไม่ได้กรอกแถวใดเลย
- "ต้องระบุรหัสเดิม/รหัสใหม่ 1-500 รายการ" → กรอกเกิน 500 คู่ แบ่งทำหลายรอบ
- "แถว ...: ต้องระบุทั้งรหัสเดิมและรหัสใหม่" → กรอกให้ครบทั้งสองช่อง
- "แถว ...: รหัสใหม่ต้องไม่เหมือนรหัสเดิม"
- "แถว ...: รหัสใหม่ ... ซ้ำกันในรายการ" → มีสองแถวใช้รหัสใหม่เดียวกัน
- "แถว ...: รหัสยาวเกิน 50 ตัวอักษร"
- "แถว ...: ไม่พบรหัสผังบัญชีเดิม ..." → รหัสเดิมพิมพ์ผิด หรือไม่มีในผังบัญชี
- "แถว ...: รหัสผังบัญชีใหม่ ... มีอยู่แล้ว" → รหัสใหม่ถูกใช้แล้ว เลือกรหัสอื่น
- เข้าเมนูไม่ได้ → ต้องเป็นผู้ดูแลระบบ ([[ts-common-no-permission]]) ถ้าไม่เห็นเมนูเลย บางรุ่นไม่มีเมนูนี้ สอบถามฝ่ายขาย
