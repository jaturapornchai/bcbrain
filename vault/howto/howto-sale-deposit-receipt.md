# รับเงินมัดจำจากลูกค้า ยอดมัดจำยกมา และคืนเงินมัดจำ

**ใช้เมื่อ:** ลูกค้าวางเงินมัดจำก่อนรับของ แล้วจะนำยอดนี้ไปหักตอนเปิดบิลขาย ใบรับเงินมัดจำมีส่วนภาษีมูลค่าเพิ่มและเลขที่ใบกำกับภาษีในตัว
**เมนู:** ขาย › รับเงินมัดจำ / ขาย › รับเงินมัดจำยกมา / ขาย › คืนเงินมัดจำ
**ต้องมีก่อน:** ทะเบียนลูกค้า ([[howto-ar-customer-register]]) สมุดเงินฝากถ้ารับเงินโอน ([[howto-cash-bank-overview]])

## ขั้นตอน (รับเงินมัดจำ)
1. เปิด ขาย › รับเงินมัดจำ กด "เพิ่มใหม่" ใส่วันที่ เลขที่เอกสาร
2. เลือก "ลูกหนี้/ลูกค้า" และ "ภาษี" (ประเภทภาษี) ใส่ "เลขที่ใบกำกับภาษี" ถ้าต้องการให้ต่างจากเลขที่เอกสาร
3. ในตาราง ใส่รายละเอียดและจำนวนเงินมัดจำ
4. ถ้าลูกค้าหักภาษี ณ ที่จ่าย ใส่ที่แท็บ "ข้อมูลภาษี (VAT/WHT)"
5. เปิดแท็บ "การรับ/จ่ายชำระเงิน" ใส่ช่องทางรับเงินให้ครบยอด ([[howto-sale-cash-payment]])
6. กด "บันทึก"

## ขั้นตอน (คืนเงินมัดจำ)
1. เปิด ขาย › คืนเงินมัดจำ กด "เพิ่มใหม่"
2. เลือกใบเดิมที่ช่อง "เลขที่ใบรับเงินมัดจำ" ระบบดึงลูกค้าและ "จำนวนเงินรับมัดจำ" ของใบเดิมมาให้
3. ใส่ยอดที่คืน ใส่ช่องทางจ่ายคืนในแท็บ "การรับ/จ่ายชำระเงิน" แล้วบันทึก

## ขั้นตอน (รับเงินมัดจำยกมา)
- ใช้ตอนเริ่มใช้ระบบ ยกยอดมัดจำที่ลูกค้าวางไว้ก่อนเริ่มใช้โปรแกรม ใส่ลูกค้า ภาษี เลขที่ใบกำกับ รายละเอียดและยอดเงิน แล้วบันทึก ไม่มีแท็บรับเงินและไม่ลงบัญชี
- ยอดมัดจำยกมาเอาไปหักในใบขายได้เหมือนใบรับมัดจำปกติ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | ลูกค้าที่วางมัดจำ | ต้องตรงกับลูกค้าในใบขายที่จะหัก |
| ภาษี | ประเภทภาษีของมัดจำ | [[faq-sale-vat-types]] |
| เลขที่ใบกำกับภาษี / ลงวันที่ | เลขใบกำกับของมัดจำ | ว่างไว้ระบบใช้เลขที่เอกสาร |
| ตารางรายละเอียด / จำนวนเงิน | ค่ามัดจำ | |
| ภายใน (วัน) / ภายในวันที่ | ระยะเวลาที่ตกลง | ใบคืนใช้ค่าจากใบเดิม |

## บันทึกแล้วระบบทำอะไรให้
- **ภาษี:** สร้างรายการภาษีขายของมัดจำ ใบคืนมัดจำสร้างเป็นยอดลดภาษีขาย
- **ลงบัญชีอัตโนมัติ:** เดบิต เงินสด/เงินฝากธนาคาร/เช็ครับ ตามช่องทาง เครดิต เงินมัดจำรับ (ยอดก่อนภาษี) และ ภาษีขาย / คืนมัดจำกลับข้างกัน
- ยอดคงเหลือของมัดจำ รอนำไปหักในใบขาย ([[howto-sale-deduct-deposit]])
- ถ้าเปิดข้อเลือก "วงเงินเครดิตรวมรายการมัดจำ" ยอดมัดจำคงเหลือจะช่วยเพิ่มวงเงินให้ลูกค้า ([[howto-sale-credit-limit]])
- เรื่องภาษีของเงินมัดจำในกรณีของกิจการ ให้ปรึกษาผู้สอบบัญชี/สรรพากร

## แก้ไข ยกเลิก พิมพ์
- มัดจำที่ถูกหักในใบขายหรือถูกคืนแล้ว แก้/ลบไม่ได้ ขึ้น "เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้"
- ยกเลิก: ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกรับเงินมัดจำ / ยกเลิกคืนเงินมัดจำ ([[howto-sale-cancel-docs]])
