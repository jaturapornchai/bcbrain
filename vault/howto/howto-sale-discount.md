# ใส่ส่วนลดในบิลขาย ส่วนลดต่อรายการ และส่วนลดท้ายบิล

**ใช้เมื่อ:** ต้องการลดราคาให้ลูกค้า เป็นเปอร์เซ็นต์ เป็นจำนวนเงิน หรือลดหลายต่อ ทั้งรายสินค้าและทั้งบิล
**เมนู:** ช่องส่วนลดในตารางสินค้า และช่อง "ส่วนลดก่อนภาษี" ด้านล่างของหน้าจอ ขาย › ใบเสนอราคาขาย / ใบสั่งจองสินค้า / ใบสั่งขายสินค้า / ขายสินค้า/บริการ / รับคืนสินค้า/ลดหนี้ขาย / เพิ่มหนี้ขาย/ราคาผิด
**ต้องมีก่อน:** ถ้าอยากให้ส่วนลดขึ้นเองตามลูกค้า ตั้งไว้ในรายละเอียดลูกหนี้ ([[howto-ar-customer-register]])

## วิธีพิมพ์ส่วนลด
| พิมพ์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| ตัวเลขอย่างเดียว | ลดเป็นจำนวนเงิน | 100 = ลด 100 บาท |
| ตัวเลขตามด้วย % | ลดเป็นเปอร์เซ็นต์ของยอด | 5% = ลด 5 เปอร์เซ็นต์ |
| @ ตามด้วยตัวเลข | ลดต่อหน่วย (ใช้ในบรรทัดสินค้า) | @10 ซื้อ 3 ชิ้น = ลด 30 บาท |
| หลายขั้นคั่นด้วยจุลภาค | ลดต่อเนื่อง ขั้นถัดไปคิดจากยอดที่เหลือ | 10%,5% = ลด 10% แล้วลดอีก 5% จากยอดที่เหลือ |

ในช่องส่วนลดของตารางสินค้า มีปุ่มสูตร (ขึ้นคำอธิบาย "ใส่ส่วนลดด้วยสูตร เช่น =100*2+50") ให้คำนวณตัวเลขก่อนใส่

## ขั้นตอน
1. ส่วนลดรายสินค้า: ใส่ในช่องส่วนลดของบรรทัดนั้นในแท็บ "รายการสินค้า / เอกสาร"
2. ส่วนลดทั้งบิล: ใส่ที่ช่อง "ส่วนลดก่อนภาษี" ด้านล่าง (ช่องขึ้นว่า "เช่น 5% หรือ 100")
3. ดูยอดที่ช่อง "มูลค่าส่วนลด" แล้วตรวจ "ยอดเงินก่อนภาษี" และ "รวมมูลค่าทั้งสิ้น"
4. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ส่วนลด (ในตารางสินค้า) | ส่วนลดของบรรทัด | ใช้รูปแบบตามตารางด้านบน |
| ส่วนลดก่อนภาษี | ส่วนลดท้ายบิล | หักก่อนคิดภาษีมูลค่าเพิ่ม |
| มูลค่าส่วนลด | ระบบคำนวณให้ | แก้ไม่ได้ |

## บันทึกแล้วระบบทำอะไรให้
- ส่วนลดท้ายบิลถูกหักก่อนคิดภาษี ภาษีมูลค่าเพิ่มจึงคิดจากยอดหลังหักส่วนลด
- เลือกลูกค้าแล้ว ระบบเติม "ส่วนลดสินค้า" และ "ส่วนลดท้ายบิล" ที่ตั้งไว้ในรายละเอียดลูกหนี้ให้อัตโนมัติ
- ส่วนลดไม่ได้แยกบัญชีส่วนลดจ่ายในการลงบัญชีมาตรฐาน ยอดขายลงตามยอดหลังหักส่วนลด ([[faq-sale-gl-posting]])

## แก้ไข ยกเลิก พิมพ์
- แก้ส่วนลดได้ตอนแก้ไขเอกสาร ถ้าเอกสารยังไม่ถูกล็อก ([[howto-sale-edit-delete]])

## ปัญหาที่พบบ่อย
- ใส่ส่วนลดแล้วขึ้น "ราคาขายต่ำกว่าต้นทุน" → ราคาหลังลดต่ำกว่าทุน ([[ts-sale-low-cost]])
- ส่วนลดขึ้นเองทั้งที่ไม่ได้ใส่ → เป็นค่าตั้งต้นของลูกค้า แก้ที่รายละเอียดลูกหนี้
- **ข้อจำกัด:** ข้อเลือก "ใช้ระบบรหัสผ่านแก้ไขส่วนลด" มีบนจอตั้งค่า แต่ยังไม่มีผลกับการแก้ส่วนลด
