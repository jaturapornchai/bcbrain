# ปรับปรุงสต็อกสินค้า/วัตถุดิบ (เพิ่ม) และ (ลด)

**ใช้เมื่อ:** ยอดในระบบไม่ตรงของจริง เช่น ของหาย ของเสีย ของเกิน หรือแก้ยอดหลังตรวจนับ
**เมนู:** สินค้า › ปรับปรุงสต็อกสินค้า/วัตถุดิบ (เพิ่ม) / ปรับปรุงสต็อกสินค้า/วัตถุดิบ (ลด)
**ต้องมีก่อน:** สินค้า คลังและที่เก็บ ([[howto-stock-warehouse-shelf]])

## ขั้นตอน
1. เลือกเมนู (เพิ่ม) ถ้าของจริงมากกว่าในระบบ หรือ (ลด) ถ้าของจริงน้อยกว่า
2. กดเพิ่ม กรอกวันที่ เลือกคลัง/พื้นที่เก็บ (ช่อง เอกสารอ้างอิง พิมพ์เลขที่ใบตรวจนับหรือเอกสารอื่นไว้อ้างอิงได้)
3. ใส่สินค้าและจำนวนที่ต่าง แล้วบันทึก
4. ถ้าปรับจากผลตรวจนับหลายรายการ ใช้เมนูอัตโนมัติจะเร็วกว่า ([[howto-stock-count-auto-adjust]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| คลังสินค้า / พื้นที่เก็บ | จุดที่ยอดต่าง | ต้องกรอก |
| จำนวน | ส่วนต่างที่ปรับ | ใบเพิ่มใส่ติดลบได้ (ระบบตัดออกที่ต้นทุนเฉลี่ย) |
| ประเภทรายการ (ใบเพิ่ม) | ปกติเว้นไว้ที่ 0: ขายเชื่อ (เครดิต) | ป้ายบนจอเป็นคำว่า 0: ขายเชื่อ (เครดิต) / 1: ขายสด ซึ่งไม่ใช่ความหมายจริง ดูหัวข้อถัดไป |
| ต้นทุน/หน่วย | ใส่ได้ | ดูผลกับต้นทุนด้านล่าง |

## บันทึกแล้วระบบทำอะไรให้
- **ใบลด:** ลดจำนวน มูลค่าสต็อก = จำนวน × ต้นทุนเฉลี่ย ลงบัญชีปกติ เดบิต ต้นทุนขาย / เครดิต สินค้าคงเหลือ ด้วยยอดรวมของเอกสาร
- **ใบเพิ่ม:** เพิ่มจำนวน ลงบัญชีกลับด้าน เดบิต สินค้าคงเหลือ / เครดิต ต้นทุนขาย
- **ต้นทุนของใบเพิ่ม (สำคัญ):**
  - แถวที่มีจำนวน และ ประเภทรายการ เป็น 0: ขายเชื่อ (เครดิต): มูลค่าเข้า = จำนวน × ต้นทุนเฉลี่ยปัจจุบัน ราคาที่พิมพ์ไม่ถูกใช้กับสต็อก ต้นทุนเฉลี่ยจึงไม่เปลี่ยน
  - ประเภทรายการ เลือก 1: ขายสด: ใช้มูลค่าตามที่กรอก ต้นทุนเฉลี่ยจึงเปลี่ยนตามราคาที่กรอก
  - แถวจำนวน 0 แต่มีมูลค่า: ปรับเฉพาะมูลค่า
- **ข้อควรรู้:** บัญชีของใบเพิ่มและใบลดใช้ยอดรวมเอกสาร (ราคาตั้งต้นคือต้นทุนเฉลี่ยปัจจุบัน แก้ได้) แต่สต็อกใช้ต้นทุนเฉลี่ย ณ วันที่เอกสาร ถ้ากรอกราคาเองหรือคีย์ย้อนหลัง ตัวเลขสองฝั่งอาจไม่เท่ากัน ให้ผู้ทำบัญชีตรวจ หรือส่งต่อเจ้าหน้าที่ ([[faq-stock-gl-posting]])
- ถ้ารูปแบบเอกสารตั้งรูปแบบการลงบัญชีไว้ ระบบใช้รูปแบบนั้นแทน
- ระบบไม่ตรวจห้ามติดลบกับใบลด ([[faq-stock-negative-allowed]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไข/ลบได้ถ้างวดยังไม่ปิด ใบเพิ่มที่สร้างจากเมนูประมวลผลเฉลี่ยต้นทุนแฝงแก้ที่นี่ไม่ได้ ([[ts-stock-doc-locked]])
- ยกเลิกที่เมนู ยกเลิกปรับปรุงสต๊อกสินค้า/วัตถุดิบ (เกิน) สำหรับใบเพิ่ม และ (ขาด) สำหรับใบลด ([[howto-stock-cancel-doc]])

## ปัญหาที่พบบ่อย
- "จำนวน ... ผิดพลาด (...)" → ใบลดใส่จำนวนติดลบไม่ได้ ([[ts-stock-line-errors]])
- "ป้อนข้อมูลคลังสินค้าไม่ครบ (...)" → ([[ts-stock-wh-shelf-incomplete]])
- "เอกสารนี้สร้างจากเมนูประมวลผลเฉลี่ยต้นทุนแฝง (...) แก้ไข/ลบได้ที่เมนูนั้นเท่านั้น" → ([[ts-stock-doc-locked]])
- ปรับเพิ่มแล้วต้นทุนเป็น 0 → สินค้ายังไม่เคยมีต้นทุน ([[ts-stock-cost-wrong]])
