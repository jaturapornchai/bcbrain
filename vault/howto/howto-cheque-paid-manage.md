# เช็คจ่ายผ่าน เช็คจ่ายคืน เปลี่ยนเช็คจ่าย และเช็คจ่ายขาดสิทธิ์

**ใช้เมื่อ:** จัดการเช็คที่กิจการสั่งจ่ายผู้ขาย
- **เช็คผ่าน**: ธนาคารตัดเงินจากบัญชีของเราแล้ว
- **เช็คคืน**: เช็คที่ผ่านไปแล้วถูกคืนกลับ
- **เปลี่ยนเช็ค**: ผู้ขายคืนเช็คใบเดิม แล้วเราจ่ายใหม่ด้วยเช็คใบอื่นหรือช่องทางอื่น
- **ขาดสิทธิ์**: เช็คใช้ไม่ได้แล้ว (ในรายงานแสดงเป็น "เช็คยกเลิก")
**เมนู:** เงินสด/ธนาคาร › ทะเบียนเช็คจ่ายและจัดการเช็คจ่าย › บันทึกเช็คผ่าน (เช็คจ่าย) / บันทึกเช็คคืน (เช็คจ่าย) / บันทึกการเปลี่ยนเช็ค (เช็คจ่าย) / บันทึกเช็คขาดสิทธิ์ (เช็คจ่าย)
**ต้องมีก่อน:** เช็คอยู่ในทะเบียนเช็คจ่าย ([[howto-cheque-paid-register]])

## เลือกเช็คได้เฉพาะสถานะต่อไปนี้
| เมนู | เช็คที่เลือกได้ |
|---|---|
| เช็คผ่าน | เช็คที่ยังไม่ถูกตัดเงิน หรือเช็คที่ถูกคืน |
| เช็คคืน | เฉพาะเช็คที่ผ่านแล้ว |
| ขาดสิทธิ์ | เช็คที่ยังไม่ถูกตัดเงิน หรือเช็คที่ถูกคืน |
| เปลี่ยนเช็ค | เช็คที่ยังไม่ถูกตัดเงิน หรือเช็คที่ถูกคืน ของเจ้าหนี้คนเดียวกัน |

เมนูผ่าน คืน ขาดสิทธิ์: ถ้ากรอกช่อง "สมุดบัญชี" ในแถวไว้ก่อนกดค้นหา จะแสดงเฉพาะเช็คที่ออกจากสมุดนั้น (ช่อง "สมุดบัญชีธนาคาร" ที่หัวเอกสารไม่ได้ใช้กรอง)

เช็คที่เลือกไว้แล้วในแถวอื่นของเอกสารเดียวกันจะไม่แสดงซ้ำ

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. เมนูผ่าน คืน ขาดสิทธิ์: ใส่ "สมุดบัญชีธนาคาร" ที่หัวเอกสาร / เปลี่ยนเช็ค: เลือกเจ้าหนี้ที่หัวเอกสาร
3. ในตาราง (เมนูผ่าน คืน ขาดสิทธิ์) ใส่ช่อง "สมุดบัญชี" ที่ออกเช็คทุกแถว ถ้าเว้นว่าง แถวนั้นจะไม่ถูกบันทึก
4. กดปุ่มค้นหาในช่อง "เลขที่เช็ค" แล้วคลิกเลือกเช็คจากหน้าต่าง "ค้นหาเช็ค" ระบบเติมวันครบกำหนดและจำนวนเงินให้ เลือกได้ครั้งละใบ ใบถัดไปกด "เพิ่มบรรทัดรายการใหม่" แล้วเลือกเหมือนเดิม
5. เฉพาะเปลี่ยนเช็ค: ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่เช็คใบใหม่หรือเงินที่จ่ายแทน
6. กด "บันทึก"

## บันทึกแล้วระบบทำอะไรให้
- เช็คผ่าน: สถานะ "เช็คผ่าน" ลงบัญชี เดบิต เช็คจ่ายล่วงหน้า คู่กับ เครดิต เงินฝากธนาคาร
- เช็คคืน: สถานะในรายงานแสดงเป็น "เช็ครับคืน" ลงบัญชี เดบิต เงินฝากธนาคาร คู่กับ เครดิต เจ้าหนี้ (ยอดกลับไปเป็นหนี้ค้างจ่าย)
- ขาดสิทธิ์: สถานะ "เช็คยกเลิก" **ข้อควรระวัง:** การลงบัญชีมาตรฐานของเมนูนี้ลง เดบิต เงินฝากธนาคาร คู่กับ เครดิต เจ้าหนี้ ทั้งที่เช็คยังไม่เคยถูกตัดเงิน ให้ตรวจแท็บ "การลงบัญชี (GL)" ก่อนบันทึก และส่งต่อเจ้าหน้าที่
- เปลี่ยนเช็ค: สถานะ "เช็คเปลี่ยน" **ข้อควรระวัง:** การลงบัญชีมาตรฐานลง เดบิต เช็คจ่ายล่วงหน้า คู่กับ เครดิต เจ้าหนี้ โดยไม่ได้ลงเงินหรือเช็คใบใหม่ที่ใส่ในแท็บ "การรับ/จ่ายชำระเงิน" ยอดเจ้าหนี้จึงกลับมาค้างจ่าย ให้ตรวจแท็บ "การลงบัญชี (GL)" และส่งต่อเจ้าหน้าที่ก่อนใช้กับข้อมูลจริง
- การลงบัญชีข้างต้นเป็นแบบมาตรฐาน ถ้ากิจการตั้งรูปแบบการลงบัญชีของเอกสารเหล่านี้ไว้เอง ระบบจะใช้รูปแบบที่ตั้งไว้แทน

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกที่เมนู เงินสด/ธนาคาร › ยกเลิกเอกสารธนาคาร เช็ครับ เช็คจ่าย และบัตรเครดิต › บันทึกยกเลิกเช็คจ่ายผ่าน / บันทึกยกเลิกเช็คคืน / บันทึกยกเลิกเช็คขาดสิทธิ์ / บันทึกยกเลิกเปลี่ยนเช็คจ่าย ([[howto-bank-cancel-docs]])

## ปัญหาที่พบบ่อย
- "ไม่พบเช็คที่เลือกได้ในสถานะนี้" → ช่อง "สมุดบัญชี" ในแถวไม่ตรงกับสมุดที่ออกเช็ค หรือเช็คอยู่ผิดสถานะ ([[ts-cheque-not-in-picker]])
