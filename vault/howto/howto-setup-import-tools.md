# นำเข้าข้อมูล แบบฟอร์ม รายงาน และรูปภาพ

**ใช้เมื่อ:** ต้องการนำผังบัญชี ราคาสินค้า แบบฟอร์มเอกสาร หรือรูปแบบรายงาน เข้าระบบจากไฟล์ หรือต้องการรู้ว่าข้อมูลใดยังนำเข้าจากไฟล์ไม่ได้
**เมนู:** เริ่มต้น › นำเข้าข้อมูล แบบฟอร์ม และรูปภาพ › เลือกเมนูย่อย (และปุ่ม "นำเข้า" ในบางหน้าจอ ดูตารางด้านล่าง)
**ต้องมีก่อน:** เมนูในกลุ่มนี้ส่วนใหญ่ใช้ได้เฉพาะ Admin (ยกเว้น หน้าจอเริ่มต้น และ นำเข้ารูปภาพสินค้า)

## ขั้นตอน
**นำเข้าผังบัญชีจากไฟล์**
1. เปิด บัญชี › ผังบัญชี (Chart of Accounts) › รายละเอียดผังบัญชี
2. ที่แถบ "เครื่องมือแม่แบบผังบัญชีมาตรฐานไทย & นำเข้า/ส่งออก Excel (CSV)" กด "ส่งออก CSV / Excel" เพื่อได้ไฟล์ตัวอย่างไปแก้ใน Excel
3. แก้ไฟล์แล้วบันทึกเป็นแบบ CSV UTF-8 (ลำดับคอลัมน์: รหัสบัญชี, ชื่อบัญชีภาษาไทย, ชื่อบัญชีภาษาอังกฤษ, ผังบัญชีหลัก ตามไฟล์ที่ส่งออก) กด "นำเข้า CSV" เลือกไฟล์
   แถวที่ไม่มีรหัสบัญชีหรือชื่อบัญชีจะถูกข้าม
4. ตรวจจำนวน "ตรวจพบ ... แถวพร้อมนำเข้า" แล้วกด "นำเข้าผังบัญชี (... รายการ)" ระบบขึ้น "นำเข้าและอัปเดตผังบัญชีจาก CSV สำเร็จ ... รายการ"

**นำเข้าแบบฟอร์มหรือรายงาน**
1. เปิด "นำเข้าแบบฟอร์ม" หรือ "นำเข้ารายงาน" / "นำเข้ารายงานสาขา"
2. แบบฟอร์ม: เลือกไฟล์แบบฟอร์มที่ส่งออกจากระบบนี้ ระบบขึ้น "นำเข้าไฟล์แบบฟอร์ม JSON "..." สำเร็จ"
3. รายงาน: เลือกรายงานจากรายการต้นแบบ แล้วกด "นำเข้ารายงานที่เลือก" หรือกด "นำเข้าจากไฟล์ .json ในเครื่อง" ระบบขึ้น "นำเข้ารายงานมาตรฐาน (JSON) เข้าสู่ระบบเรียบร้อยแล้ว"

## ช่องสำคัญที่ต้องกรอก
| เมนูหรือปุ่ม | นำเข้าอะไรได้จริง | หมายเหตุ |
|---|---|---|
| ผังบัญชี › ปุ่ม "นำเข้า CSV" | ผังบัญชีจากไฟล์ CSV | รหัสที่มีอยู่แล้วจะถูกอัปเดต มีแม่แบบผังบัญชีสำเร็จรูปให้เลือกด้วย เช่น ธุรกิจซื้อมาขายไป ธุรกิจบริการ ธุรกิจผลิตและโรงงาน |
| ปรับราคาสินค้า › ปุ่ม "นำเข้าไฟล์" | ราคาสินค้าจากไฟล์ข้อความหรือ CSV | ไฟล์คั่นด้วย Tab จุลภาค อัฒภาค หรือขีดตั้ง ถ้าบรรทัดแรกเป็นชื่อคอลัมน์ ระบบจับคู่ให้เอง ข้อมูลเข้าตารางก่อน ต้องกดบันทึกเอง |
| ตรวจสอบบาร์โค๊ดจาก Text File › ปุ่ม "นำเข้าไฟล์" | รายการบาร์โค้ดเพื่อตรวจสอบ | ตรวจอย่างเดียว ไม่บันทึกข้อมูล |
| นำเข้าแบบฟอร์ม | แบบฟอร์มพิมพ์เอกสาร | ใช้ไฟล์ที่ส่งออกจากระบบนี้ ดู [[howto-setup-form-designer]] |
| นำเข้ารายงาน / นำเข้ารายงานสาขา | รูปแบบรายงาน | ดู [[howto-setup-report-designer]] |
| นำเข้ารูปภาพสินค้า | รูปสินค้าทีละสินค้า | เลือกสินค้า กด "แก้ไข" เพิ่มรูป แล้ว "บันทึก" ดู [[howto-common-attach-picture]] |
| นำเข้าข้อมูลหลัก | ยังนำเข้าไม่ได้ | หน้าจอแสดงหมวดข้อมูลหลักอย่างเดียว |
| นำเข้าข้อมูลจากรูปภาพ / ย้ายรูปภาพสินค้า | ยังทำงานไม่ได้ | หน้าจอแสดงรายการรูปภาพในระบบอย่างเดียว |
| แสดง Resource Language | ดูอย่างเดียว | แสดงข้อความภาษาในระบบ |
| หน้าจอเริ่มต้น | ดูอย่างเดียว | แสดงสรุปข้อมูลระบบเริ่มต้น |

## บันทึกแล้วระบบทำอะไรให้
- ผังบัญชีที่นำเข้าจะใช้งานได้ทันทีในหน้าจอบัญชี
- แบบฟอร์มและรายงานที่นำเข้า จะเลือกใช้ได้ตอนพิมพ์เอกสารหรือเปิดรายงาน ดู [[howto-common-print-document]]

## แก้ไข ยกเลิก พิมพ์
- นำเข้าผังบัญชีผิด ให้แก้ไฟล์แล้วนำเข้าซ้ำ หรือแก้รายบัญชีในหน้าจอผังบัญชี
- ข้อมูลสินค้า ลูกค้า ผู้จำหน่าย และยอดยกมา ตอนนี้ยังไม่มีหน้าจอนำเข้าจากไฟล์ ต้องคีย์ทีละรายการ ดู [[faq-general-import-old-data]]

## ปัญหาที่พบบ่อย
- ขึ้น "ไม่พบข้อมูลผังบัญชีที่ถูกต้องใน CSV" หรือ "อ่านไฟล์ JSON ไม่สำเร็จ กรุณาตรวจสอบรูปแบบไฟล์" ดู [[ts-common-import-file-error]]
- กด "เริ่มประมวลผล" ในเมนูนำเข้าข้อมูลหลัก แล้วขึ้น "ประมวลผล ... เรียบร้อยแล้ว" แต่ไม่มีข้อมูลเข้า ดู [[ts-common-menu-not-ready]]
- เปิดเมนูไม่ได้ ดู [[ts-common-no-permission]]
