# ทำใบเสนอซื้อ (PR) และอนุมัติใบเสนอซื้อ

**ใช้เมื่อ:** พนักงานต้องการขอซื้อสินค้า และต้องให้หัวหน้าอนุมัติก่อนออกใบสั่งซื้อ
**เมนู:** ซื้อ › ขอซื้อและสั่งซื้อ (PR / PO) › ใบเสนอซื้อสินค้า (PR) และ อนุมัติใบเสนอซื้อสินค้า
**ต้องมีก่อน:** รหัสสินค้าในระบบ ส่วนรหัสเจ้าหนี้ (ผู้ขาย) ไม่บังคับในใบเสนอซื้อ

## ขั้นตอน
1. เปิดเมนู ใบเสนอซื้อสินค้า (PR) กด "เพิ่มใหม่"
2. กรอกวันที่เอกสาร เลขที่เอกสาร (กดรันเลขอัตโนมัติได้) เลือกประเภทรายการ
3. ใส่รหัสเจ้าหนี้ถ้ารู้ว่าจะซื้อจากใคร ถ้ายังไม่รู้เว้นไว้ได้
4. ใส่รายการสินค้า จำนวน และราคาที่ประมาณไว้
5. กด "บันทึก" (หรือ Ctrl+S)
6. ผู้อนุมัติเปิดเมนู อนุมัติใบเสนอซื้อสินค้า กด "เลือกเอกสาร" เลือกใบเสนอซื้อที่รออนุมัติ
7. ตรวจรายการ แก้ "จำนวนอนุมัติ" หรือ "ราคาอนุมัติ" ได้ถ้าอนุมัติไม่เต็มตามที่ขอ
8. กด "บันทึกอนุมัติ" ถ้าไม่อนุมัติให้ติ๊ก "ไม่อนุมัติ" แล้วกด "บันทึกไม่อนุมัติ"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| วันที่เอกสาร / เลขที่เอกสาร | วันที่ขอซื้อ และเลขที่ใบ | ช่องบังคับ |
| ประเภทรายการ | ซื้อเงินเชื่อหรือเงินสด สินค้าหรือสินค้าบริการ | ใช้เป็นค่าตั้งต้นตอนดึงไปทำใบสั่งซื้อ |
| รหัสเจ้าหนี้ | ผู้ขายที่ตั้งใจจะซื้อ | ไม่บังคับ |
| จำนวนอนุมัติ / ราคาอนุมัติ | ในหน้าจออนุมัติ | ไม่แก้ = อนุมัติตามที่ขอ |

## บันทึกแล้วระบบทำอะไรให้
- ใบเสนอซื้อ ไม่ลงบัญชี ไม่ตัดหรือเพิ่มสต๊อก เป็นเอกสารภายในเท่านั้น
- สถานะในหน้าจออนุมัติจะแสดงเป็น รออนุมัติ / อนุมัติแล้ว / ไม่อนุมัติ / ยกเลิกแล้ว
- นำไปดึงทำใบสั่งซื้อได้ ([[howto-buy-purchase-order]]) ถ้าดึงจากใบอนุมัติ ระบบจะใช้จำนวนและราคาที่อนุมัติ
- ข้อควรรู้: ระบบไม่ได้บังคับว่าต้องอนุมัติก่อนจึงดึงไปทำใบสั่งซื้อได้ ถ้ากิจการต้องการคุมเรื่องนี้ ให้ตกลงขั้นตอนกันภายใน
- ถ้าเปิดข้อเลือก "อนุมัติรายการเสนอซื้อได้มากกว่า 1 ครั้ง" ใบเสนอซื้อจะยังไม่ปิดรายการจนกว่าจำนวนที่อนุมัติรวมกับที่ยกเลิกจะครบ แต่ใบเดิมนำมาอนุมัติซ้ำอีกครั้งไม่ได้ ระบบจะตอบ "เอกสาร ... อนุมัติแล้ว" ถ้าลูกค้าต้องการอนุมัติหลายรอบจริง ให้ส่งต่อเจ้าหน้าที่ ([[howto-buy-options]])

## แก้ไข ยกเลิก พิมพ์
- อนุมัติผิด: เปิดหน้าจออนุมัติ เลือกเอกสาร กด "ยกเลิกการอนุมัติ" แล้วอนุมัติใหม่
- ใบเสนอซื้อที่บันทึกอนุมัติหรือไม่อนุมัติไปแล้ว หรือถูกดึงไปทำใบสั่งซื้อแล้ว แก้ไขหรือลบไม่ได้ ([[ts-buy-cannot-edit]])
- ยกเลิกทั้งใบหรือยกเลิกบางรายการ ใช้เมนู ยกเลิกใบเสนอซื้อสินค้า ([[howto-buy-cancel-docs]]) ใบที่อนุมัติแล้วต้องกด "ยกเลิกการอนุมัติ" ก่อน ไม่อย่างนั้นระบบตอบ "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"
- พิมพ์ด้วยปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"

## ปัญหาที่พบบ่อย
- "เอกสาร ... อนุมัติแล้ว" → ใบนี้อนุมัติไปแล้ว ถ้าจะแก้ให้กด "ยกเลิกการอนุมัติ" ก่อน
- "เอกสาร ... บันทึกไม่อนุมัติแล้ว" → ใบนี้ถูกบันทึกไม่อนุมัติไว้ ต้องยกเลิกการอนุมัติก่อนจึงอนุมัติใหม่ได้
- "เอกสาร ... ถูกยกเลิกแล้ว อนุมัติไม่ได้" → ใบถูกยกเลิกไปแล้ว ให้ทำใบเสนอซื้อใหม่
