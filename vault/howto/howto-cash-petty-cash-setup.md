# ตั้งค่าวงเงินสดย่อย

**ใช้เมื่อ:** กิจการมีเงินสดย่อย (เงินสดก้อนเล็กที่เก็บไว้จ่ายค่าใช้จ่ายจุกจิก) และต้องการแยกเป็นกอง เช่น กองสำนักงาน กองสาขา
**เมนู:** เริ่มต้น › ตั้งค่าระบบการเงินและธนาคาร › กำหนดวงเงินสดย่อย
**ต้องมีก่อน:** บัญชีเงินสดย่อยในผังบัญชี ([[howto-gl-overview]])

## ขั้นตอน
1. เปิดเมนู กำหนดวงเงินสดย่อย กด "เพิ่มใหม่"
2. ใส่รหัสและชื่อกองเงินสดย่อย
3. ใส่ "วงเงินสดย่อย" (เพดานเงินของกองนี้)
4. เลือก "รหัสผังบัญชีเงินสดย่อย" ให้ตรงกับบัญชีเงินสดย่อยในผังบัญชี
5. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| วงเงินสดย่อย | เพดานเงินของกอง | ใช้อ้างอิง |
| ยอดคงเหลือ | ยอดตั้งต้นตอนเริ่มใช้ | พิมพ์เอง ระบบไม่ปรับให้จากเอกสาร |
| รหัสสกุลเงิน | สกุลเงินของกอง | ถ้าใช้หลายสกุลเงิน |
| รหัสผังบัญชีเงินสดย่อย | บัญชีเงินสดย่อย | สำคัญที่สุด ใช้ตอนลงบัญชีอัตโนมัติ |
| หมายเหตุ | ข้อความเพิ่มเติม | |

## บันทึกแล้วระบบทำอะไรให้
- รหัสนี้จะเลือกได้ในเมนู รับ/เพิ่ม วงเงินสดย่อย และ คืน/ลด วงเงินสดย่อย ([[howto-cash-petty-cash-topup-return]])
- ตอนลงบัญชีอัตโนมัติ ระบบใช้บัญชีที่ผูกกับรหัสนี้
- ถ้าไม่ผูกผังบัญชี ระบบจะหาบัญชีให้เอง ซึ่งอาจไปลงบัญชีเงินสดหรือเงินฝากแทนบัญชีเงินสดย่อย จึงควรผูกไว้ทุกกอง
- ช่องยอดคงเหลือ ไม่เปลี่ยนตามเอกสารเติมหรือคืนเงินสดย่อย ดูยอดจริงจากรายงานเคลื่อนไหวเงินสดย่อย ([[rpt-overview]])
- รายงานเคลื่อนไหวเงินสดย่อยและรายงานสถานะเงินสดย่อย ใช้ยอดในช่องนี้เป็นยอดตั้งต้น แล้วบวกลบตามเอกสาร จึงควรใส่ครั้งเดียวตอนเริ่มใช้ ถ้าไปแก้ให้ตรงยอดปัจจุบันภายหลัง ยอดในรายงานจะนับซ้ำ

## แก้ไข ยกเลิก พิมพ์
- แก้ชื่อ วงเงิน หรือบัญชีได้ตลอด การแก้บัญชีมีผลกับเอกสารที่บันทึกหลังจากนั้น

## ปัญหาที่พบบ่อย
- ลงบัญชีเติมเงินสดย่อยไปผิดบัญชี → ตรวจว่ารหัสเงินสดย่อยผูก "รหัสผังบัญชีเงินสดย่อย" แล้ว
- ยอดคงเหลือในหน้าตั้งค่าไม่ขยับ → เป็นช่องพิมพ์เอง ดู [[faq-cash-petty-cash-spending]]
