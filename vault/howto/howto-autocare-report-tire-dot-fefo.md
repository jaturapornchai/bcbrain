# รายงานสต็อกยางตามสัปดาห์ผลิต DOT และแจ้งเตือนยางค้างปี

**ใช้เมื่อ:** อยากรู้ว่ายางแต่ละรุ่นเหลือเท่าไรในแต่ละล็อตที่ผลิต และล็อตไหนเก่าควรเร่งขายหรือลดราคา
**เมนู:** AutoCare › 4. รายงานและวิเคราะห์ผล › รายงานสต็อกยางตามสัปดาห์ผลิต (DOT) และแจ้งเตือนยางค้างปี (FEFO) (ชื่อย่อ "รายงานอายุยาง DOT & FEFO")
**ต้องมีก่อน:** มีข้อมูลยางและล็อต DOT ในเมนูข้อมูลหลักของ AutoCare ดู [[sys-autocare-overview]]

DOT คือเลขสัปดาห์และปีที่ผลิตปั๊มที่แก้มยาง FEFO คือหลักขายล็อตเก่าก่อน

## ขั้นตอน
1. เปิดเมนู (รายงานนี้ไม่มีตัวกรองวันที่ เพราะเป็นยอดคงเหลือปัจจุบัน)
2. พิมพ์ในช่องค้นหา (ข้อความในช่องว่า "ค้นหารหัส / ชื่อ / เงื่อนไขเพิ่มเติม...") ค้นด้วยรหัสสินค้า ชื่อรุ่น ยี่ห้อ ขนาดยาง รหัส DOT หรือตัวเลขไซส์ติดกัน เช่น 2055516 แทน 205/55 R16 ได้ แล้วกดปุ่ม "ค้นหา" (หน้ารายงานนี้ไม่มีแผงปุ่มไซส์ด่วนแบบที่อยู่หน้าทะเบียนยาง)
3. ใช้ "จากรหัสสินค้า ถึงรหัสสินค้า" ดูเป็นช่วง
4. กด "ประมวลผลรายงาน" แล้ว "พิมพ์รายงาน" หรือ "ส่งออก CSV" ตามต้องการ
5. คำอธิบายใต้ชื่อรายงานระบุว่า "ซ่อนราคาทุนหน้าร้าน 100%" รายงานนี้ไม่แสดงราคาทุน

## คอลัมน์
รหัสสินค้า · ชื่อรุ่นยาง / อะไหล่ · ยี่ห้อ · ขนาดยาง · สัปดาห์ผลิต (DOT) · คลัง/ที่เก็บ · สถานะอายุยาง (FEFO) · จำนวนคงเหลือ · หน่วยนับ · ราคาขายต่อหน่วย · มูลค่าสต็อกราคาขายรวม

## วิธีอ่านตัวเลข
- เรียงล็อตที่ค้างปีที่สุดขึ้นก่อน แล้วล็อตที่เริ่มเตือน แล้วล็อตใหม่ จากนั้นเรียงตามปีและสัปดาห์ผลิต
- มูลค่าสต็อกราคาขายรวม = จำนวนคงเหลือ x ราคาขายต่อหน่วย เป็นมูลค่าตามราคาขาย (ราคาโปรโมชัน) **ไม่ใช่มูลค่าทุน** จึงใช้ประเมินมูลค่าสต็อกทางบัญชีโดยตรงไม่ได้
- เลข DOT 4 หลักอ่านเป็น สัปดาห์ 2 หลัก + ปี 2 หลัก เช่น 3524 = สัปดาห์ที่ 35 ปี 2024

## ข้อควรระวัง (ข้อมูลสถานะ FEFO)
- คอลัมน์ "สถานะอายุยาง (FEFO)" เป็นข้อความที่บันทึกไว้กับล็อตนั้น ไม่ได้คำนวณใหม่ตามวันที่วันนี้
- เมื่อสั่ง "ประมวลผลคำนวณข้อมูลใหม่" ระบบจัดลำดับความเก่าด้วยเกณฑ์ตายตัว (ปี 2024 หรือเก่ากว่า = ค้างปี, ปี 2025 สัปดาห์ 30 ลงมา = เริ่มเตือน) ซึ่งเป็นปีที่ตั้งไว้ในโปรแกรม ไม่เลื่อนตามเวลา ลำดับการเรียงในรายงานจึงอาจไม่ตรงกับอายุยางจริงในอนาคต ให้ดูปีและสัปดาห์ผลิตในคอลัมน์ DOT ประกอบเสมอ
