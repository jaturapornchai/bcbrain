# ใช้ Serial Number กับสินค้า

**ใช้เมื่อ:** สินค้าที่ต้องติดตามทีละเครื่อง เช่น มือถือ เครื่องใช้ไฟฟ้า ต้องรู้ว่าเลขเครื่องไหนเข้า-ออกเมื่อไร
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ทะเบียน Serial Number
**ต้องมีก่อน:** ข้อมูลสินค้า ([[howto-stock-item-master]])

## ขั้นตอน
1. ตอนรับสินค้าเข้า (เช่น ซื้อ หรือยอดยกมา) กดปุ่ม Serial Number (รูปบาร์โค้ด) ที่แถวสินค้า ระบบเปิดหน้าต่าง Serial ของสินค้านั้น
2. สแกนหรือพิมพ์ Serial ทีละเลข แล้วกด Enter หรือปุ่ม เพิ่ม S/N ให้ครบตามจำนวนสินค้าในแถว
3. ตอนขายหรือเบิก เปิดหน้าต่างเดียวกัน แล้วสแกนเลข หรือไปแท็บ ซีเรียลในคลัง แล้วกด เลือก ที่ Serial สถานะ พร้อมใช้
4. กด บันทึก S/N แล้วบันทึกเอกสาร
5. ดูรายละเอียดและประวัติความเคลื่อนไหวของแต่ละเลขได้ที่เมนู ทะเบียน Serial Number

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| หมายเลข Serial | เลขเครื่อง | ยาวไม่เกิน 50 ตัวอักษร ห้ามซ้ำในเอกสารเดียวกัน |
| รหัสสินค้า / หน่วยนับ | สินค้าของเลขนี้ | |
| รหัสคลัง / รหัสที่เก็บ | ตอนนี้อยู่ที่ไหน | ระบบปรับให้เองตามเอกสารรับเข้าล่าสุดของเลขนี้ |
| สถานะ | 0 = พร้อมใช้ / 1 = ตัดจ่ายแล้ว | ระบบปรับให้เองตามเอกสารล่าสุดของเลขนี้ |
| วันที่หมดประกัน, ปีที่ผลิต, สัปดาห์ที่ผลิต | ข้อมูลประกัน | ไม่บังคับ |

## บันทึกแล้วระบบทำอะไรให้
- หน้าต่าง Serial แสดง จำนวนในแถวบิล: และ ระบุซีเรียลแล้ว: ให้เทียบว่าครบหรือยัง
- **ข้อจำกัด:** ระบบไม่บังคับว่าจำนวน Serial ต้องเท่าจำนวนสินค้าในแถว ตรวจเพียงห้ามซ้ำในเอกสาร ห้ามยาวเกิน 50 ตัวอักษร และรวมไม่เกิน 20,000 เลขต่อเอกสาร พนักงานต้องดูตัวเลขให้ครบเอง
- ตอนขายหรือเบิก ระบบไม่ตรวจว่าเลขที่สแกนมีในทะเบียนหรือยังอยู่ในคลัง ถ้าสงสัยให้ตรวจที่ ตรวจสอบ Serial มีปัญหา ([[howto-stock-serial-count]])
- ทุกครั้งที่บันทึก แก้ หรือลบเอกสารที่มี Serial ของสินค้านั้น ระบบสร้างทะเบียน Serial ของสินค้านั้นใหม่จากเอกสาร: คลัง ที่เก็บ สถานะ และข้อมูลประกันถูกปรับตามเอกสาร และเลขที่เพิ่มเองในทะเบียนโดยไม่มีเอกสารรองรับจะถูกลบออก ถ้าลูกค้าเจอข้อมูลในทะเบียนหายหรือเปลี่ยนเอง ส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- แก้ Serial ในบิล: เปิดบิล แก้ในหน้าต่าง Serial แล้วบันทึกบิลใหม่
- ตรวจนับสต็อกด้วย Serial และหา Serial ที่ผิดปกติ ดู [[howto-stock-serial-count]]
