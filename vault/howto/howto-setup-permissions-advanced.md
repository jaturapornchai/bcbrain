# ตั้งค่ากลุ่มพนักงาน สิทธิ์คลังและที่เก็บ สิทธิ์อนุมัติ และสิทธิ์ฐานข้อมูล

เมื่อธุรกิจมีหลายฝ่ายงาน หลายคลังสินค้า หรือหลายบริษัทในระบบเดียวกัน ควรกำหนดสิทธิ์เชิงลึกทั้ง 3 ด้านนี้ควบคู่กัน เพื่อควบคุมทั้งเมนูที่เปิดได้ คลังที่เบิก-จ่ายได้ และผู้มีสิทธิ์อนุมัติเอกสารสำคัญ

---

## 1. กำหนดกลุ่มพนักงาน และบทบาทอนุมัติ (PO / SO / เสนอซื้อ / ข้อมูลหลัก)

เข้าเมนู "เริ่มต้น > ตั้งค่าองค์กร พนักงาน และเอกสาร > กำหนดกลุ่มพนักงาน"

1. สร้างรหัสกลุ่มและชื่อกลุ่มพนักงาน (เช่น จัดซื้อ, ขาย, คลังสินค้า, ผู้จัดการ)
2. ติ๊กเลือกหน้าที่ของกลุ่ม:
   - บทบาทงานหลัก: **กลุ่มจัดซื้อ (PO)**, **กลุ่มขาย (SO)**, **กลุ่มคลังสินค้า (WH)**, **กลุ่มพนักงานขาย (Sale Group)**
   - บทบาทอนุมัติและความปลอดภัย: **อนุมัติใบขอซื้อ (PR Approve)**, **อนุมัติใบสั่งซื้อ (PO Approve)**, **อนุมัติใบเสนอราคา/ราคาขาย**, **อนุมัติใบสั่งขาย (SO Approve)**, **แก้ไขข้อมูลหลัก (Master Data)**
3. ใช้แท็บด้านล่างทั้ง 4 แท็บเพื่อผูกคนให้ตรงหน้าที่:
   - **1. รายชื่อพนักงานในกลุ่ม**
   - **2. ผู้อนุมัติใบสั่งซื้อ (PO)**
   - **3. ผู้อนุมัติใบสั่งขาย (SS)**
   - **4. ผู้อนุมัติใบขอซื้อ (SR/PR)**

---

## 2. จำกัดสิทธิ์การใช้คลังสินค้าและพื้นที่เก็บตามกลุ่มพนักงาน

เข้าเมนู "เริ่มต้น > ตั้งค่าองค์กร พนักงาน และเอกสาร > กำหนดการใช้คลังและที่เก็บ"

- ใช้กำหนดว่า **กลุ่มพนักงาน** ใดมีสิทธิ์ใช้งานกับ **คลังสินค้า** และ **พื้นที่เก็บสินค้า** ใดบ้าง
- เหมาะสำหรับร้านหลายสาขาหรือคลังที่แบ่งโซนรับผิดชอบ ป้องกันพนักงานสาขาหนึ่งหยิบหรือตัดสต็อกผิดคลังของอีกสาขาหนึ่ง

---

## 3. สิทธิ์กลุ่มใช้งานรายหน้าจอ และสิทธิ์เข้าถึงฐานข้อมูล (Admin เท่านั้น)

ในส่วนจัดการระบบสำหรับผู้ดูแลระบบ (Admin):
1. **จัดกลุ่มผู้ใช้** และ **กำหนดสิทธิ์กลุ่มใช้งาน**: กำหนดสิทธิ์รายเมนูแบบแยกย่อยเป็น **ดูข้อมูล**, **เพิ่มใหม่**, **แก้ไข**, และ **ลบ** โดยเมนูที่มีป้าย **"สงวนสิทธิ์เฉพาะผู้ดูแลระบบ (Admin เท่านั้น)"** จะล็อกให้ Admin เท่านั้นที่ใช้งานได้
2. **กำหนดการเข้าถึงข้อมูล**: เลือกติ๊กฐานข้อมูลที่อนุญาตให้ผู้ใช้ระดับสมาชิก (Member) แต่ละรายเปิดเข้าทำงานได้ (เหมาะสำหรับสำนักงานบัญชีหรือกลุ่มบริษัทที่มีหลายนิติบุคคล)
