# วิธีถาม AI และสั่งทำรายงาน

**ใช้เมื่อ:** อยากให้ผู้ช่วย AI วิเคราะห์ตัวเลขหรือทำรายงาน
**เมนู:** แถบระบบด้านบน › ระบบ ถามตอบ AI
**ต้องมีก่อน:** เข้าสู่ระบบและเลือกฐานข้อมูล ผู้ดูแลระบบตั้งค่าการเชื่อมต่อ AI ไว้แล้ว ภาพรวมที่ [[sys-ai-overview]]

## ขั้นตอน
1. เลือกห้องทางซ้ายให้ตรงเรื่อง เช่น ห้องบัญชีภาษี หรือห้องจัดซื้อสต็อก
2. ตรวจสวิตช์ "เชื่อมฐานข้อมูลสด" ว่า "เปิดใช้งาน" ถ้าอยากให้ผู้ช่วยเห็นตัวเลขจริงของกิจการ
3. เลือก "รูปแบบคำตอบ" ที่ต้องการ: "มุมมอง A4 / PDF (แนะนำ)", "ข้อความ & ตาราง", "รายงาน HTML สวยๆ", "ตาราง CSV/Excel"
4. พิมพ์คำถามในช่อง ("พิมพ์คำถาม สั่งทำรายงาน HTML / PDF / ตารางบัญชี หรือกด Ctrl+V วางรูปภาพที่นี่... (กด Enter เพื่อส่ง)") หรือกดปุ่มคำถามลัด
5. ถ้าต้องการแนบ: "แนบรูปภาพ" หรือ "แนบไฟล์/CSV" (รับ CSV, TXT, JSON, MD, SQL และรูป)
6. กด "ส่งคำถาม" รอข้อความ "กำลังประมวลผลคำตอบ..." แล้วอ่านคำตอบ
7. ปุ่มด้านบนของคำตอบ: "มุมมอง A4 / PDF", "ข้อความ", "พรีวิว HTML สด", "ส่งออก PDF" (เปิดหน้าต่างพิมพ์ แล้วเลือกบันทึกเป็น PDF), "CSV" (มีเมื่อคำตอบมีตาราง), "ดาวน์โหลดไฟล์ .html" (มีเมื่อคำตอบมีรายงาน HTML), ไอคอนคัดลอกข้อความ, "แสดงทั้งหมดทันที" (ขึ้นระหว่างคำตอบกำลังพิมพ์) ข้ามแอนิเมชัน

## ตัวอย่างคำถาม
- "สรุปยอดขายเดือนนี้ และสินค้าที่ควรสั่งเพิ่ม"
- "ลูกหนี้รายไหนค้างนานที่สุด" (ถ้าข้อมูลที่แนบมีข้อมูลนี้)
- "ทำตารางวิเคราะห์สินค้าและแผนสั่งซื้อ ส่งออก CSV"

## ข้อจำกัดของการแนบและการสนทนา
- แนบรูปครั้งละไม่เกิน 4 ไฟล์ ระบบอ่านข้อความจากไฟล์ตัวอักษรได้ส่วนต้นเท่านั้น (ส่วนยาวถูกตัด) และส่งให้ผู้ช่วยอย่างมาก 5 ไฟล์ต่อคำถาม
- ผู้ช่วยเห็นข้อความล่าสุดในห้องไม่เกิน 20 ข้อความ เรื่องเก่ากว่านั้นอาจไม่ถูกนำมาพิจารณา
- รูปภาพ ผู้ช่วยได้รับเพียงชื่อ ขนาด โทนสี และข้อความที่อ่านได้ ไม่ได้ดูภาพเต็ม
- ตัวเลขในรายงานต้องตรวจกับรายงานในระบบก่อนนำไปใช้จริง
