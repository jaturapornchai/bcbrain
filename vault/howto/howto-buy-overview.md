# ภาพรวมระบบจัดซื้อ ขอซื้อ สั่งซื้อ และรับสินค้า

ระบบ **ซื้อ** ครอบคลุมงานจัดซื้อครบวงจร ตั้งแต่ใบขอซื้อภายใน ใบสั่งซื้อ จ่ายเงินมัดจำ รับสินค้าทั้งแบบจบในบิลเดียวและแบบทยอยรับหลายรอบ ไปจนถึงส่งคืน ลดหนี้ และเพิ่มหนี้ซื้อ

---


## วิดีโอสอนวงจรจัดซื้อเต็มระบบ และภาพหน้าจอใบสั่งซื้อจริง

[🎬 EP.3 สอนใช้งานวงจรจัดซื้อเต็มระบบ: สั่งซื้อ (PO) จ่ายมัดจำ รับของเข้าคลัง และส่งคืนลดหนี้](https://www.youtube.com/watch?v=74csOGLdjJk&list=PLO9P7tPZLXB0)

![หน้ารายการบันทึกใบสั่งซื้อสินค้าใน BC Ai Account](https://bcaccount.com/manual/images/05-purchase-order-list.png)

## 1. เลือกเส้นทางจัดซื้อให้เหมาะกับหน้างาน

- **ซื้อของด่วน / รับของพร้อมใบกำกับภาษีในใบเดียว**: เปิด "ซื้อ > ซื้อสินค้า/ตั้งหนี้ซื้อ" (รหัสเมนู **3011**) ได้เลย -> [[howto-buy-invoice]]
- **มีขั้นตอนขอซื้อ-อนุมัติ-สั่งซื้อเป็นระบบ**: ทำตามลำดับ **ใบเสนอซื้อสินค้า (PR)** -> **อนุมัติ** -> **ใบสั่งซื้อสินค้า (PO)** -> **อนุมัติ** -> **ซื้อสินค้า/ตั้งหนี้ซื้อ** -> [[howto-buy-pr-po]]
- **รับของเข้าคลังมาก่อนหลายรอบ แล้วค่อยวางบิลตั้งหนี้ทีหลัง**: ใช้ชุด 5 หน้าจอของ **ซื้อสินค้าแบบทะยอยรับ (รับของก่อนตั้งหนี้)** -> [[howto-buy-partial-receive]]

---

## 2. คู่มือเฉพาะเรื่องในระบบซื้อ

1. **ใบเสนอซื้อ (PR) และใบสั่งซื้อสินค้า (PO)** -> [[howto-buy-pr-po]] (การขอซื้อ ระงับชั่วคราว อนุมัติ และบังคับอนุมัติก่อนสั่งซื้อ)
2. **จ่ายเงินล่วงหน้า และจ่ายเงินมัดจำเจ้าหนี้** -> [[howto-buy-deposit-advance]] (จ่ายล่วงหน้า จ่ายมัดจำ ยกมา รับคืน และนำมาหักในใบซื้อ)
3. **ซื้อสินค้า/ตั้งหนี้ซื้อ** -> [[howto-buy-invoice]] (ซื้อสด/ซื้อเชื่อ ดึงจาก PO กรอกเลขที่ใบกำกับภาษีซื้อ คุม Lot และลงภาษีซื้อ)
4. **ซื้อสินค้าแบบทะยอยรับ (รับของก่อนตั้งหนี้)** -> [[howto-buy-partial-receive]] (รับสินค้าตาม PO ก่อนแล้วค่อยตั้งหนี้เมื่อได้รับใบกำกับภาษี)
5. **ส่งคืนสินค้า/ลดหนี้ซื้อ และ เพิ่มหนี้ซื้อ/ราคาผิด** -> [[howto-buy-return-cn-dn]] (ลดหนี้/เพิ่มหนี้ทั้งแบบกระทบสต็อกและไม่กระทบสต็อก)

- **บันทึกรูปภาพและไฟล์แนบเอกสารซื้อ** -> [[howto-doc-attachments]]
- **ยกเลิกเอกสารซื้อ มัดจำ และทะยอยรับ** -> [[howto-doc-edit-cancel-delete]]

## คำถามที่ลูกค้ามักถาม

**ถาม: ร้านค้าที่ซื้อของด่วนรับของพร้อมบิลเลย จำเป็นต้องทำใบขอซื้อ (PR) และใบสั่งซื้อ (PO) ก่อนไหม?**
ตอบ: ไม่จำเป็นครับ สามารถเปิดเมนู **ซื้อ > ซื้อสินค้า/ตั้งหนี้ซื้อ** (รหัสเมนู **3011**) เพื่อรับของเข้าคลังและตั้งหนี้จบในใบเดียวได้เลย ส่วนกิจการที่ต้องการระบบขอซื้อและอนุมัติก็สามารถเริ่มจาก PR → อนุมัติ → PO → อนุมัติ → ซื้อสินค้าได้ตามขั้นตอนครับ

**ถาม: หากซัพพลายเออร์ส่งของเข้าโกดังมาก่อนหลายรอบ แล้วค่อยออกใบกำกับภาษีรวมใบเดียวทีหลัง ระบบรองรับไหม?**
ตอบ: รองรับครับ ใช้ชุดเมนู **ซื้อสินค้าแบบทะยอยรับ (รับของก่อนตั้งหนี้)** ซึ่งแยกขั้นตอนรับสินค้าเข้าสต็อกก่อน แล้วค่อยดึงหลายใบรับของมาออกใบตั้งหนี้ซื้อเมื่อได้รับใบกำกับภาษีจริงโดยไม่เพิ่มสต็อกซ้ำครับ

**ถาม: ระบบจัดซื้อเชื่อมยอดสต็อกและยอดหนี้เจ้าหนี้ให้อัตโนมัติไหม?**
ตอบ: เชื่อมให้อัตโนมัติครับ เมื่อบันทึกบิลซื้อ/ตั้งหนี้ซื้อ ระบบจะเพิ่มยอดสต็อกและต้นทุนเข้าคลังสินค้า พร้อมส่งยอดค้างจ่ายไปที่ระบบเจ้าหนี้เพื่อรับวางบิลและจ่ายชำระหนี้ต่อทันที

**ถาม: ระบบจัดซื้อรองรับการจ่ายมัดจำและการส่งคืนสินค้า/ลดหนี้ซื้อด้วยไหม?**
ตอบ: รองรับครบครับ ทั้งการจ่ายเงินล่วงหน้า/จ่ายเงินมัดจำเพื่อนำไปหักในบิลซื้อ การส่งคืนสินค้า/ลดหนี้ซื้อ และการเพิ่มหนี้ซื้อ/ราคาผิดทั้งแบบกระทบสต็อกและไม่กระทบสต็อก รวมถึงแนบรูปภาพและไฟล์ประกอบเอกสารซื้อได้ด้วย
