# แยกบัญชีตามหน่วยงาน โครงการ งาน การจัดสรร (มิติ)

**ใช้เมื่อ:** อยากรู้รายได้/ค่าใช้จ่ายแยกตามหน่วยงาน แผนก โครงการ หรืองาน (มิติ = มุมมองเพิ่มเติมนอกจากรหัสบัญชี)
**เมนู:** เริ่มต้น › ตั้งค่าระบบบัญชีและภาษี › กำหนดหน่วยงาน / กำหนดโครงการ / กำหนดงาน / กำหนดการจัดสรร · แผนกอยู่ที่ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรายละเอียดแผนก · รายงานอยู่ที่ บัญชี › ข้อมูลรายวันเชิงวิเคราะห์
**ต้องมีก่อน:** ผังบัญชี ([[howto-gl-chart-of-accounts]])

## สถานะในรุ่นปัจจุบัน (อ่านก่อน)
- ตั้งรหัสมิติ และติ๊กแยกมิติในผังบัญชีได้ แต่ระบบยังไม่ได้เก็บยอดแยกตามมิติจริง
- คอลัมน์ มิติ ในตารางรายการบัญชีของ ข้อมูลรายวัน พิมพ์ได้ แต่บันทึกแล้วค่าไม่ถูกเก็บ
- ใบสำคัญที่ระบบลงจากเอกสารอัตโนมัติ ก็ยังไม่แยกยอดตามแผนก/โครงการ/การจัดสรร
- ผลคือ รายงาน ข้อมูลรายวันเชิงวิเคราะห์ จะไม่มีรายการขึ้น (แสดงเฉพาะข้อมูลมิติที่มีอยู่เดิม)
- ถ้าลูกค้าต้องใช้รายงานแยกมิติจริง ให้ส่งต่อเจ้าหน้าที่

## ขั้นตอน (ตั้งรหัสมิติ)
1. เปิดเมนู กำหนดหน่วยงาน / กำหนดโครงการ / กำหนดงาน / กำหนดการจัดสรร แล้วกดเพิ่ม กรอก "รหัส:" "ชื่อ:" กดบันทึก
2. แผนก ตั้งที่ กำหนดรายละเอียดแผนก มีช่อง "รหัสฝ่าย:" ให้เลือกหน่วยงานที่แผนกสังกัด
3. ในผังบัญชี ([[howto-gl-chart-of-accounts]]) มีช่องติ๊ก แยกหน่วยงาน / แยกแผนก / แยกการจัดสรร / แยกโครงการ / แยกงาน และแท็บ หน่วยงาน แผนก การจัดสรร งาน โครงการ ให้เลือกรหัส ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส / ชื่อ | เช่น รหัสโครงการ ชื่อโครงการ | ห้ามรหัสซ้ำ |
| รหัสฝ่าย (เฉพาะแผนก) | หน่วยงานที่แผนกสังกัด | ไม่บังคับ |

## รายงาน ข้อมูลรายวันเชิงวิเคราะห์
- เลือกช่วงวันที่ แสดงคอลัมน์ มิติ วันที่ เลขที่เอกสาร รหัสบัญชี ชื่อบัญชี รหัสมิติ ชื่อมิติ ร้อยละ จำนวนเงิน
- คอลัมน์ มิติ แสดงเป็น แผนก / ฝ่าย (คือหน่วยงาน) / โครงการ / งาน / การจัดสรร
- พิมพ์/ส่งออกได้ตามวิธีของรายงานทั่วไป ([[rpt-print-export]])

## แก้ไข ยกเลิก พิมพ์
- แผนกที่ถูกใช้ในเอกสารสินค้าแล้วลบไม่ได้ ขึ้น "มีการใช้งานในเอกสารสินค้าแล้ว"
- หน่วยงาน โครงการ งาน การจัดสรร ระบบไม่ตรวจก่อนลบ

## ปัญหาที่พบบ่อย
- ใส่มิติในใบสำคัญแล้ว รายงานไม่ขึ้น หรือเปิดใบเดิมแล้วช่องมิติว่าง → เป็นข้อจำกัดของรุ่นปัจจุบัน (ดูหัวข้อสถานะด้านบน) ส่งต่อเจ้าหน้าที่
- ไม่เห็นเมนูข้อมูลรายวันเชิงวิเคราะห์ หรือเมนูกำหนดหน่วยงาน/โครงการ/งาน/การจัดสรร → บางรุ่นไม่มีเมนูกลุ่มนี้ สอบถามฝ่ายขาย
