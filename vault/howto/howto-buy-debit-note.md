# บันทึกเพิ่มหนี้ซื้อ เมื่อผู้ขายคิดราคาเพิ่มหรือส่งของเพิ่ม

**ใช้เมื่อ:** ผู้ขายออกใบเพิ่มหนี้ เพราะราคาในบิลเดิมต่ำไป หรือส่งของเพิ่มจากบิลเดิม
**เมนู:** ซื้อ › รับสินค้า ซื้อ/ตั้งหนี้ และเพิ่ม/ลดหนี้ › เพิ่มหนี้ซื้อ/ราคาผิด
**ต้องมีก่อน:** ใบซื้อสินค้า/ตั้งหนี้ซื้อ เดิมของผู้ขายรายนั้น

## ขั้นตอน
1. เปิดเมนู กด "เพิ่มใหม่" เลือกรหัสเจ้าหนี้และประเภทภาษีให้ตรงกับใบซื้อเดิม
2. เลือกประเภท (บนจอช่องนี้ชื่อ "ประเภทการส่งคืน") เป็น "เพิ่มหนี้เจ้าหนี้, เพิ่มสินค้า" หรือ "เพิ่มหนี้เจ้าหนี้, ราคาผิด (ไม่มีผลกับสต๊อกสินค้า)"
3. กด "ดึงเอกสาร" เลือกใบซื้อเดิม แล้วแก้จำนวนหรือยอดเงินเป็นส่วนที่เพิ่ม
4. ใส่ "สาเหตุ:" และเลขที่ใบเพิ่มหนี้ของผู้ขาย
5. ตรวจแท็บ "ภาษีมูลค่าเพิ่ม" แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภท | เพิ่มสินค้า หรือ ราคาผิด | ราคาผิด = จำนวนสินค้าในคลังไม่เปลี่ยน |
| เอกสารอ้างอิง | ใบซื้อเดิม | รหัสเจ้าหนี้และประเภทภาษีต้องตรงกัน |
| จำนวน / ยอดเงิน | เฉพาะส่วนที่เพิ่ม | ไม่ใช่ยอดรวมใหม่ทั้งใบ |

## บันทึกแล้วระบบทำอะไรให้
- เพิ่มยอดหนี้ค้างจ่ายของผู้ขาย เสมอ (ใบเพิ่มหนี้ไม่มีแบบจ่ายเงินสด ไม่มีแท็บจ่ายเงิน)
- ลงบัญชี: ซื้อสินค้า และ ภาษีซื้อ คู่กับ เจ้าหนี้การค้า
- แบบเพิ่มสินค้า จะเพิ่มจำนวนสินค้าเข้าคลังด้วย
- เพิ่มภาษีซื้อในทะเบียนภาษีซื้อ

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกด้วยเมนู ยกเลิกเพิ่มหนี้ซื้อ/ราคาผิด ([[howto-buy-cancel-docs]])
- จ่ายเงินตามใบเพิ่มหนี้ ใช้เมนู จ่ายชำระหนี้ (เจ้าหนี้) ([[howto-ap-payment]])

## ปัญหาที่พบบ่อย
- ไม่พบใบซื้อเดิมให้ดึง → ตรวจรหัสเจ้าหนี้และประเภทภาษี ([[ts-buy-ref-doc-not-listed]])
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบได้" → ใบเพิ่มหนี้ถูกนำไปวางบิลหรือจ่ายชำระแล้ว ลบไม่ได้ ([[ts-buy-cannot-edit]])
- ข้อควรรู้: รุ่นปัจจุบันยังไม่กันการแก้ไขใบเพิ่มหนี้ที่จ่ายชำระไปแล้ว ถ้าลูกค้าต้องแก้ใบที่จ่ายแล้ว อย่าแก้เอง ให้ส่งต่อเจ้าหน้าที่
