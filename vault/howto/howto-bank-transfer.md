# บันทึกโอนเงินระหว่างธนาคาร

**ใช้เมื่อ:** ย้ายเงินจากบัญชีธนาคารหนึ่งของกิจการไปอีกบัญชีหนึ่งของกิจการเอง (ไม่ใช่โอนจ่ายผู้ขาย)
**เมนู:** เงินสด/ธนาคาร › สมุดเงินฝากธนาคาร (ฝาก / ถอน / โอน) › บันทึกโอนเงินระหว่างธนาคาร
**ต้องมีก่อน:** สมุดเงินฝากอย่างน้อย 2 สมุด ([[howto-bank-passbook]])

## ขั้นตอน
1. เปิดเมนู กด "เพิ่มใหม่" ใส่วันที่และเลขที่เอกสาร
2. ในตาราง ช่อง "สมุดบัญชี (โอนออก)" เลือกบัญชีต้นทาง
3. ช่อง "สมุดบัญชี (โอนเข้า)" เลือกบัญชีปลายทาง (ต้องเป็นคนละสมุด)
4. ใส่จำนวนเงิน และ "ค่าธรรมเนียม" ถ้ามี
5. ช่อง "ยอดโอน" ถ้าเว้นว่าง ระบบคิดให้ = จำนวนเงิน หัก ค่าธรรมเนียม
6. ตรวจแท็บ "การลงบัญชี (GL)" แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| สมุดบัญชี (โอนออก) | บัญชีต้นทาง | |
| สมุดบัญชี (โอนเข้า) | บัญชีปลายทาง | ห้ามซ้ำกับโอนออก |
| จำนวนเงิน | ยอดที่ตัดจากต้นทาง | |
| ค่าธรรมเนียม | ค่าธรรมเนียมธนาคาร | ห้ามติดลบ |
| ยอดโอน | ยอดที่เข้าปลายทาง | เว้นว่างได้ |

## บันทึกแล้วระบบทำอะไรให้
- สร้างรายการ "โอนเงินเข้า" ให้สมุดปลายทางอัตโนมัติ ด้วยเลขที่เอกสารเดียวกัน ไม่ต้องบันทึกฝั่งรับเอง
- ลงบัญชีแบบมาตรฐาน: เดบิต เงินฝากของสมุดโอนเข้า คู่กับ เครดิต เงินฝากของสมุดโอนออก ด้วยยอดเต็มจำนวนเงิน
- **ค่าธรรมเนียมไม่ถูกลงบัญชีในแบบมาตรฐาน** ถ้าต้องการให้ลง ดู [[faq-bank-transfer-fee]]
- แบบมาตรฐานใช้คู่สมุดของบรรทัดแรก ถ้าต้องโอนหลายคู่สมุด แนะนำแยกเอกสารคู่ละใบ

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้ถ้างวดยังไม่ปิด รายการโอนเข้าจะถูกสร้างใหม่ตาม
- ยกเลิกด้วยเมนู บันทึกยกเลิกโอนเงินระหว่างธนาคาร ([[howto-bank-cancel-docs]])
