# ดูการเคลื่อนไหวสินค้า บัญชีคุมพิเศษ และประวัติการซื้อขาย

**ใช้เมื่อ:** อยากรู้ว่าสินค้าตัวนี้เข้าออกด้วยเอกสารอะไรบ้าง ยอดสะสมเปลี่ยนตอนไหน ต้นทุนต่อหน่วยเป็นเท่าไรในแต่ละครั้ง
**เมนู:** สินค้า › สอบถามและวิเคราะห์ข้อมูลสินค้า (บนหน้าจอ) › เลือกหัวข้อ
**ต้องมีก่อน:** มีเอกสารสินค้าในช่วงวันที่ที่จะดู

## เลือกหัวข้อให้ตรงคำถาม
| หัวข้อ | แสดงอะไร |
|---|---|
| เคลื่อนไหวสินค้า | ทุกรายการเข้าออก (จำนวน) พร้อมยอดคงเหลือสะสม |
| บัญชีคุมพิเศษ | จำนวน ต้นทุน และมูลค่า พร้อมยอดสะสม (คล้ายสต็อกการ์ดที่ใช้ตรวจต้นทุน) |
| สรุปการเคลื่อนไหวตามปริมาณ | ยอดรวมแยกตามประเภทเอกสาร เป็นจำนวน |
| สรุปการเคลื่อนไหวตามมูลค่า | ยอดรวมแยกตามประเภทเอกสาร เป็นมูลค่าต้นทุน |
| ประวัติการซื้อสินค้า | ซื้อสินค้าและค่าบริการ รับสินค้าแบบแบ่งรับ |
| ประวัติการขายสินค้า | ขายสินค้าและบริการ |

## ขั้นตอน
1. เปิดหัวข้อที่ต้องการ
2. ใส่ ตั้งแต่วันที่ ถึงวันที่ และช่วงรหัสสินค้า (ควรระบุสินค้าเพื่อให้เร็ว)
3. กด ประมวลผลรายงาน
4. พิมพ์หรือส่งออกด้วยปุ่ม พิมพ์รายงาน / ส่งออก CSV ([[rpt-print-export]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ตั้งแต่วันที่ / ถึงวันที่ | ช่วงที่ต้องการดู | ยอดยกมาคิดก่อนวันเริ่ม |
| ช่วงรหัสสินค้า | จาก ถึง | เว้นว่าง = ทุกสินค้า |

## ใช้หาสาเหตุอะไรได้บ้าง
- ยอดติดลบหรือยอดหาย: ไล่ดูยอดสะสมว่าเริ่มผิดที่เอกสารใบไหน ([[ts-stock-balance-wrong]])
- ต้นทุนกระโดด: ดูในบัญชีคุมพิเศษว่าใบไหนทำให้ต้นทุนเฉลี่ยเปลี่ยน ([[ts-stock-cost-wrong]], [[faq-stock-cost-method]])
- จำนวนแสดงเป็นหน่วยนับหลัก

## ทำไมบางคนไม่เห็นต้นทุน
- ถ้าบริษัทติ๊ก ไม่แสดงต้นทุนสินค้า ในการตั้งค่า (หมวดสินค้าคงคลัง) ผู้ใช้จะไม่เห็นช่องต้นทุนและมูลค่าในหน้าจอสอบถาม
- ยกเว้นผู้ใช้ที่ได้สิทธิ์ สามารถดูต้นทุนสินค้า ในหน้าจอกำหนดพนักงาน ([[howto-stock-options]])

## แก้ไข ยกเลิก พิมพ์
- หน้าจอสอบถามอ่านอย่างเดียว ถ้าพบเอกสารผิดให้เปิดเอกสารนั้นแก้ หรือยกเลิก ([[howto-stock-cancel-doc]])
