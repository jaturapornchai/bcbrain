# ดึงใบเสนอราคา/ใบสั่งจอง/ใบสั่งขาย มาเปิดบิลต่อ

**ใช้เมื่อ:** มีเอกสารขั้นก่อนหน้าแล้ว อยากต่อเป็นเอกสารขั้นถัดไปโดยไม่ต้องคีย์สินค้าใหม่ และให้ระบบตัดยอดคงค้างของใบเดิมให้
**เมนู:** ในหน้าจอ ขาย › ใบสั่งจองสินค้า / ใบสั่งขายสินค้า / ขายสินค้า/บริการ / รับคืนสินค้า/ลดหนี้ขาย / เพิ่มหนี้ขาย/ราคาผิด ใช้ปุ่ม "ดึงเอกสาร"
**ต้องมีก่อน:** เอกสารต้นทางที่บันทึกแล้ว ([[howto-sale-quotation]], [[howto-sale-order]], [[howto-sale-invoice]])

## ดึงอะไรมาเป็นอะไรได้บ้าง
| เอกสารที่กำลังทำ | ดึงจากเอกสาร |
|---|---|
| ใบสั่งจองสินค้า | ใบเสนอราคาขาย |
| ใบสั่งขายสินค้า | ใบเสนอราคาขาย, ใบสั่งจองสินค้า |
| ขายสินค้า/บริการ | ใบเสนอราคาขาย, ใบสั่งจองสินค้า, ใบสั่งขายสินค้า |
| รับคืนสินค้า/ลดหนี้ขาย | ขายสินค้า/บริการ |
| เพิ่มหนี้ขาย/ราคาผิด | ขายสินค้า/บริการ |

## ขั้นตอน
1. เปิดเอกสารใหม่ (กด "เพิ่มใหม่")
2. เลือก "ลูกหนี้/ลูกค้า" และ "ภาษี" ให้ตรงกับใบต้นทางก่อน
3. กดปุ่ม "ดึงเอกสาร" ข้างช่อง "เอกสารอ้างอิง"
4. หน้าต่าง "เลือกเอกสารอ้างอิงเพื่อดึงรายการสินค้า" แสดงรายการ พิมพ์ค้นด้วยเลขที่เอกสาร ชื่อลูกค้า หรือหมายเหตุได้
5. คลิกเลือกใบที่ต้องการ ระบบดึงรายการที่ยังเหลือคงค้างมาใส่ในตาราง
6. แก้จำนวนให้ตรงกับที่ส่งจริง (ส่งบางส่วนได้) แล้วกด "บันทึก"

## รายการไหนจะขึ้นให้เลือก
ระบบแสดงเฉพาะใบที่:
- เป็นลูกค้าคนเดียวกับที่เลือกไว้ (ถ้ายังไม่เลือกลูกค้า รายการจะว่าง)
- ประเภทภาษีเดียวกัน
- ไม่ถูกยกเลิก
- ตอนทำ "ขายสินค้า/บริการ" ระบบซ่อนใบที่ถูกดึงไปครบแล้ว ส่วนหน้าจออื่นอาจยังเห็นใบที่ดึงครบแล้ว ถ้าเลือกจะขึ้น "เอกสาร ... ไม่มีรายการคงเหลือให้ดึง"
- ถ้าบริษัทใช้ระบบสาขา ตั้งให้แสดงเฉพาะเอกสารของสาขา และผู้ใช้ไม่มีสิทธิ์เปลี่ยนสาขา จะเห็นเฉพาะใบของสาขาที่เข้าระบบ
- ถ้าเปิด "เปิดใช้ระบบอ้างอิงใบสั่งจองที่อนุมัติแล้วเท่านั้น" หรือ "เปิดใช้ระบบอ้างอิงใบสั่งขายที่อนุมัติแล้วเท่านั้น" จะเห็นเฉพาะใบที่อนุมัติแล้ว (มีผลตอนทำ "ขายสินค้า/บริการ" เท่านั้น)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เอกสารอ้างอิง | ระบบใส่ให้เมื่อดึง | กดปุ่ม "ดึงเอกสาร" ข้างช่อง |
| จำนวน | จำนวนที่ส่ง/ขายจริงรอบนี้ | ห้ามเกินยอดคงเหลือของใบต้นทาง |
| คอลัมน์ "ประเภทเอกสาร" และ "เอกสารอ้างอิง" ในตารางสินค้า | ระบบใส่ให้ต่อบรรทัดเมื่อดึง | กดปุ่ม "เอกสารอ้างอิง" เพื่อแสดงคอลัมน์ ประเภทเอกสารขึ้นเป็น "ใบเสนอราคา", "ใบสั่งซื้อ/ใบสั่งจอง" หรือ "ใบสั่งขาย" (คอลัมน์ประเภทเอกสารมีเฉพาะใบสั่งขายสินค้าและขายสินค้า/บริการ ส่วนใบสั่งจองสินค้ามีแค่คอลัมน์ "เลขที่ใบเสนอราคา") |

## บันทึกแล้วระบบทำอะไรให้
- ตัดยอดคงค้างของใบต้นทาง ดึงไม่ครบก็ยังดึงส่วนที่เหลือได้อีก ([[faq-sale-partial-delivery]])
- ใบต้นทางที่ถูกดึงไปแล้วจะแก้ไข/ลบไม่ได้ ([[ts-sale-cannot-edit]])
- ตอนทำ "ใบสั่งขายสินค้า" หรือ "ขายสินค้า/บริการ" เมื่อดึงแล้ว ช่อง "ประเภทรายการ" และ "ภาษี" จะถูกล็อกตามใบต้นทาง

## แก้ไข ยกเลิก พิมพ์
- ถ้าดึงผิดใบ ยังไม่บันทึก ให้ปิดหรือล้างเอกสาร แล้วเริ่มใหม่
- ใบต้นทางที่เหลือค้างและไม่ต้องการแล้ว ใช้เมนูยกเลิกรายสินค้า ([[howto-sale-cancel-docs]])

## ปัญหาที่พบบ่อย
- "ไม่พบเอกสารอ้างอิงในระบบ" → ลูกค้า/ประเภทภาษีไม่ตรง หรือ (ตอนทำใบขาย) ใบถูกใช้ครบแล้ว ([[ts-sale-ref-doc-not-found]])
- "เอกสาร ... ไม่มีรายการคงเหลือให้ดึง" → ใบนั้นถูกดึงครบแล้ว ([[ts-sale-ref-doc-not-found]])
- "จำนวนเกินเอกสารอ้างอิง : ..." → [[ts-sale-qty-over-ref]]
- "ส่งคืนเกินจำนวน : ..." → [[ts-sale-return-over]]
