# ออกใบเสนอราคาขายให้ลูกค้า และอนุมัติใบเสนอราคา

**ใช้เมื่อ:** ต้องการเสนอราคาสินค้า/บริการให้ลูกค้าก่อนตกลงซื้อ ใบนี้ยังไม่ตัดสต็อก ไม่ตั้งหนี้ (ยังไม่บันทึกว่าลูกค้าค้างเงิน) และไม่ลงบัญชี
**เมนู:** ขาย › ใบเสนอราคาขาย (อนุมัติที่ ขาย › อนุมัติใบเสนอราคาขาย)
**ต้องมีก่อน:** ทะเบียนลูกค้า ([[howto-ar-customer-register]]) และทะเบียนสินค้าพร้อมราคาขาย ([[howto-stock-overview]])

## ขั้นตอน
1. เปิด ขาย › ใบเสนอราคาขาย กดปุ่ม "เพิ่มใหม่"
2. ใส่ "วันที่เอกสาร" และ "เลขที่เอกสาร" (กดปุ่ม "Auto" ให้ระบบรันเลขที่ตามรูปแบบเอกสาร)
3. เลือก "ลูกหนี้/ลูกค้า" ระบบดึงค่าตั้งต้นของลูกค้ามาให้ เช่น ประเภทภาษี ส่วนลด พนักงานขาย จำนวนวันเครดิต
4. เลือก "ประเภทรายการ" (ขายเชื่อ หรือ ขายสด) และ "ภาษี" (ประเภทภาษี)
5. ในแท็บ "รายการสินค้า / เอกสาร" ใส่รหัสสินค้า จำนวน ราคา/หน่วย และส่วนลด
6. ตรวจยอดด้านล่าง แล้วกด "บันทึก"
7. ระบบขึ้น "บันทึกเอกสารเลขที่ ... ลงฐานข้อมูลเรียบร้อยแล้ว ต้องการพิมพ์แบบฟอร์มเอกสารเลยหรือไม่?" กด "พิมพ์แบบฟอร์ม" หรือ "ยังไม่พิมพ์"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | รหัสลูกค้า | ลูกค้าที่ตั้งสถานะ "ไม่ใช้งาน" จะเปิดใบใหม่ไม่ได้ |
| ผู้ติดต่อ | คนที่ติดต่อฝั่งลูกค้า | ไม่บังคับ |
| ประเภทรายการ | ขายเชื่อ (เครดิต) / ขายสด | ส่งต่อไปใบสั่งขาย/ใบขายเมื่อดึงอ้างอิง |
| ภาษี | แยกนอก / รวมใน / ยกเว้นภาษี / ไม่กระทบภาษี | ดู [[faq-sale-vat-types]] |
| จำนวนวันหมดอายุ / วันที่หมดอายุ | อายุของใบเสนอราคา | บังคับกรอกเมื่อเปิดข้อเลือก "ใช้ระบบหมดอายุใบเสนอราคา" |
| รับ/ส่ง ภายใน(วัน) / วันที่รับ/ส่งสินค้า | กำหนดส่งของ | บังคับเมื่อเปิดข้อเลือก "ใส่วัน รับ/ส่ง สินค้าทุกครั้ง" |
| ผู้ขออนุมัติ / กลุ่มผู้อนุมัติ | คนขออนุมัติ และกลุ่มที่อนุมัติ | ใช้คู่กับเมนูอนุมัติ |
| พนักงานขาย | ผู้รับผิดชอบ | ดึงจากทะเบียนลูกค้าได้ |
| เครดิต (วัน) | จำนวนวันเครดิตที่เสนอ | ใบเสนอราคามีปุ่ม "เปลี่ยนจำนวนวันเครดิต" |

## บันทึกแล้วระบบทำอะไรให้
- ไม่ตัดสต็อก ไม่ตั้งหนี้ ไม่ลงบัญชี ไม่ขึ้นภาษีขาย (ใบเสนอราคาไม่มีแท็บภาษีและแท็บการลงบัญชี)
- ใบนี้ดึงต่อเป็น ใบสั่งจองสินค้า ใบสั่งขายสินค้า หรือ ขายสินค้า/บริการ ได้ ([[howto-sale-pull-ref-doc]])

## อนุมัติใบเสนอราคา
1. เปิด ขาย › อนุมัติใบเสนอราคาขาย กดปุ่ม "เลือกเอกสาร" แล้วเลือกใบเสนอราคา
2. ใส่ "หมายเหตุ" (ช่องขึ้นว่า "ระบุหมายเหตุการอนุมัติ")
3. กด "บันทึกอนุมัติ" ระบบขึ้น "อนุมัติเอกสาร ... เรียบร้อยแล้ว"
4. ถ้าไม่อนุมัติ ติ๊กช่อง "ไม่อนุมัติ" แล้วกด "บันทึกไม่อนุมัติ" ระบบขึ้น "บันทึกไม่อนุมัติเอกสาร ... เรียบร้อยแล้ว"
5. อนุมัติผิด กด "ยกเลิกการอนุมัติ"
- สถานะที่เห็นบนจอ: "รออนุมัติ" / "อนุมัติแล้ว" / "ไม่อนุมัติ"

## แก้ไข ยกเลิก พิมพ์
- แก้ได้ด้วยปุ่ม "แก้ไข" จนกว่าใบจะผ่านเมนูอนุมัติแล้ว (ทั้งอนุมัติและไม่อนุมัติ) ถูกดึงไปใช้ หรือถูกยกเลิกบางรายการ หลังจากนั้นขึ้น "ห้ามแก้ไข หรือลบข้อมูล" ([[ts-sale-cannot-edit]])
- ถ้าอยากแก้ใบเสนอราคาได้ตลอด ให้เปิดข้อเลือก "แก้ไขใบเสนอราคาได้ตลอดเวลา" ([[howto-sale-settings]])
- ยกเลิกทั้งใบหรือบางรายการ: ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกใบเสนอราคาขาย ([[howto-sale-cancel-docs]])
- พิมพ์: ปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ" ([[rpt-print-export]])

## ปัญหาที่พบบ่อย
- "สถานะ ลูกค้าปิดการใช้งาน : ..." → เปิดใช้งานลูกค้าก่อน ([[ts-sale-customer-inactive]])
- "กรุณาป้อน จำนวนวันหมดอายุ" → ใส่อายุใบเสนอราคา ([[ts-sale-required-fields]])
- "ราคาขายต่ำกว่าต้นทุน ต้องการใช้ราคานี้หรือไม่" → ([[ts-sale-low-cost]])
- "ไม่พบราคาสินค้า" → ([[ts-sale-price-not-found]])
