# ออกใบสั่งจองสินค้า / ใบสั่งขายสินค้า และอนุมัติใบสั่ง

**ใช้เมื่อ:** ลูกค้าตกลงซื้อแล้ว แต่ยังไม่ส่งของหรือยังไม่เปิดบิล ต้องการกันสินค้าไว้ให้ลูกค้า (ใบสั่งจอง) หรือบันทึกคำสั่งซื้อที่รอส่ง (ใบสั่งขาย)
**เมนู:** ขาย › ใบสั่งจองสินค้า / ขาย › ใบสั่งขายสินค้า (อนุมัติที่ ขาย › อนุมัติใบสั่งจองสินค้า / อนุมัติใบสั่งขายสินค้า)
**ต้องมีก่อน:** ทะเบียนลูกค้า ([[howto-ar-customer-register]]) ถ้าจะให้ตรวจวงเงินต้องตั้งวงเงินลูกค้าก่อน ([[howto-sale-credit-limit]])

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่" ใส่ "วันที่เอกสาร" และ "เลขที่เอกสาร" (ปุ่ม "Auto" รันเลขให้)
2. เลือก "ลูกหนี้/ลูกค้า" "ประเภทรายการ" (ขายเชื่อ/ขายสด) และ "ภาษี"
3. ถ้ามีเอกสารก่อนหน้า กดปุ่ม "ดึงเอกสาร" ข้างช่อง "เอกสารอ้างอิง" เพื่อดึงรายการมา ([[howto-sale-pull-ref-doc]])
   - ใบสั่งจองดึงได้จากใบเสนอราคา
   - ใบสั่งขายดึงได้จากใบเสนอราคา หรือใบสั่งจอง
4. ใส่หรือแก้รายการสินค้า จำนวน ราคา ส่วนลด
5. เลือก "ประเภทการส่ง" ด้านล่าง: "รับเอง" หรือ "ส่งให้"
6. กด "บันทึก" ถ้าเกินวงเงิน ระบบจะถามก่อน (ดูหัวข้อวงเงินด้านล่าง)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | รหัสลูกค้า | ลูกค้าที่ตั้งสถานะ "ไม่ใช้งาน" ไม่ขึ้นในรายการให้เลือก และถ้าพิมพ์รหัสเอง ใบใหม่จะบันทึกไม่ได้ ขึ้น "สถานะ ลูกค้าปิดการใช้งาน : ..." |
| ประเภทรายการ | ขายเชื่อ (เครดิต) / ขายสด | มีผลกับการตรวจวงเงิน |
| ภาษี | ประเภทภาษี | ต้องตรงกับใบที่จะดึงต่อ |
| รับ/ส่ง (วัน) / วันที่รับ/ส่ง | วันนัดส่ง (อยู่ส่วนล่างของจอ) | บังคับเมื่อเปิด "ใส่วัน รับ/ส่ง สินค้าทุกครั้ง" |
| ผู้ขออนุมัติ / กลุ่มผู้อนุมัติ | ผู้ขอ และกลุ่มผู้อนุมัติ | ใช้คู่กับเมนูอนุมัติ |
| ประเภทการส่ง | รับเอง / ส่งให้ | อยู่ส่วนล่างของจอ |

## บันทึกแล้วระบบทำอะไรให้
- ไม่ตัดสต็อก ไม่ตั้งหนี้ ไม่ลงบัญชี
- ยอดในใบถูกนับเป็นยอดค้างจอง/ค้างส่ง (สั่งไว้แล้วแต่ยังไม่เปิดบิล) ใช้กับข้อเลือก "ห้ามขายสินค้าค้างจองทั้งระบบ" และ "ห้ามขายสินค้าค้างส่งทั้งระบบ"
- ดึงไปเปิดบิลบางส่วนได้ ใบเดิมยังเหลือยอดให้ดึงครั้งต่อไป ([[faq-sale-partial-delivery]])
- ถ้าเปิดข้อเลือกห้ามขายติดลบ ใบสั่งขายจะถูกตรวจสต็อกด้วย ([[ts-sale-stock-negative]])

## วงเงินเครดิตและการอนุมัติ
- ระบบตรวจวงเงินของใบสั่งเฉพาะเมื่อเปิดข้อเลือก "ตรวจสอบวงเงินรวมรายการสั่งขาย/สั่งจอง"
  - ขายเชื่อ ยอดไม่เกินวงเงิน → ระบบอนุมัติให้อัตโนมัติ
  - ขายเชื่อ เกินวงเงิน หรือลูกค้ายังไม่ได้ตั้งวงเงิน → ถาม "เกินวงเงินเครดิตลูกค้า ต้องการบันทึกเพื่อขออนุมัติหรือไม่" ตอบตกลงแล้วใบจะถูกพักไว้รออนุมัติวงเงิน
  - ถ้าเปิดข้อเลือก "สั่งจอง สั่งขาย เงินเชื่อตรวจสอบวงเงินลูกค้า" ด้วย กรณีเกินวงเงินจะไม่ถาม แต่บันทึกไม่ได้ ขึ้น "เกินวงเงินเครดิตลูกค้า"
  - ใบสั่งจองขายสด → บันทึกได้ แต่ใบจะถูกพักไว้รออนุมัติ / ใบสั่งขายขายสด → ไม่ต้องรออนุมัติวงเงิน
  - รายละเอียดข้อความอื่น ดู [[ts-sale-order-credit-over]]
- ถ้าเปิด "เปิดใช้ระบบอ้างอิงใบสั่งจองที่อนุมัติแล้วเท่านั้น" หรือ "เปิดใช้ระบบอ้างอิงใบสั่งขายที่อนุมัติแล้วเท่านั้น" ตอนเปิดบิลจะดึงได้เฉพาะใบที่อนุมัติแล้ว

## อนุมัติใบสั่ง
1. เปิด ขาย › อนุมัติใบสั่งจองสินค้า (หรือ อนุมัติใบสั่งขายสินค้า) กด "เลือกเอกสาร"
2. ใส่หมายเหตุ กด "บันทึกอนุมัติ" หรือติ๊ก "ไม่อนุมัติ" แล้วกด "บันทึกไม่อนุมัติ"
3. อนุมัติผิด กด "ยกเลิกการอนุมัติ"

## แก้ไข ยกเลิก พิมพ์
- ใบที่อนุมัติแล้ว ถูกดึงไปใช้แล้ว หรือถูกยกเลิกแล้ว แก้/ลบไม่ได้ ขึ้น "ห้ามแก้ไข หรือลบข้อมูล" ([[ts-sale-cannot-edit]])
- ยกเลิกทั้งใบหรือยกเลิกรายสินค้าที่ค้างอยู่: ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ ([[howto-sale-cancel-docs]])
- พิมพ์: ปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"
