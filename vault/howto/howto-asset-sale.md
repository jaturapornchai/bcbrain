# บันทึกการขายสินทรัพย์ (คิดกำไรขาดทุนจากการขายให้อัตโนมัติ)

**ใช้เมื่อ:** ขายสินทรัพย์ถาวรออกไป ทั้งขายเงินสดและขายเงินเชื่อ
**เมนู:** ค่าเสื่อม › บันทึกการขายสินทรัพย์
**ต้องมีก่อน:** ทะเบียนสินทรัพย์ที่มีผังบัญชีครบ ([[howto-asset-register]]) ลงค่าเสื่อมถึงก่อนวันขาย ([[howto-asset-depreciation-post]]) และผังบัญชีกำไรขาดทุนจากการขายสินทรัพย์ ([[ts-asset-sale-gainloss-account]])

## ขั้นตอน
1. กด "เพิ่มใหม่" ใส่ "เลขที่เอกสาร" "วันที่เอกสาร" และ "สมุดรายวัน"
2. เลือก "ประเภทการขาย": ขายเงินสด หรือ ขายเงินเชื่อ และเลือกลูกหนี้ (เงินเชื่อใส่ "จำนวนวันเครดิต" ได้)
3. เลือก "ประเภทภาษี" (ภาษีแยกนอก / ภาษีรวมใน / ภาษีอัตราศูนย์ / ไม่กระทบภาษี) ใส่ "อัตราภาษี (%)" "เลขที่ใบกำกับภาษี" "วันที่ใบกำกับภาษี"
4. ในตาราง "รายการสินทรัพย์ที่ขาย" เลือก "รหัสสินทรัพย์" (ค้นหาได้เฉพาะสินทรัพย์ที่ยังไม่ขาย) แล้วใส่ "ราคาขาย"
5. ระบบแสดง "มูลค่าสินทรัพย์" "ค่าเสื่อมราคาสะสม" "มูลค่าตามบัญชี" และกำไร/ขาดทุน ให้เอง
6. ดูตาราง "รายการบัญชี" ต้องขึ้น "เดบิต = เครดิต (สมดุล)" แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทการขาย | ขายเงินสด / ขายเงินเชื่อ | เงินเชื่อเป็นหนี้ค้างรับ |
| ลูกหนี้ | ผู้ซื้อ (บังคับกรอก) | เงินเชื่อลงบัญชีลูกหนี้ของผู้ซื้อ ถ้าไม่ได้กำหนดใช้บัญชีลูกหนี้มาตรฐาน |
| ราคาขาย | ราคาที่ตกลงขาย | ใส่ศูนย์ได้ ห้ามติดลบ |
| ประเภทภาษี | ตามใบกำกับ | ภาษีการขายสินทรัพย์ปรึกษาผู้สอบบัญชีหรือสรรพากร |

## บันทึกแล้วระบบทำอะไรให้
- ลงบัญชี: เดบิต เงินสดหรือลูกหนี้ (ยอดรวมภาษี) และ เดบิต ค่าเสื่อมราคาสะสม / เครดิต ราคาทุนสินทรัพย์ และ ภาษีขาย ส่วนต่างลงบัญชีกำไรหรือขาดทุนจากการขายสินทรัพย์
- ค่าเสื่อมสะสมที่ใช้ = ค่าเสื่อมสะสมยกมา + ค่าเสื่อมที่โอนเข้าบัญชีแล้ว จึงควรโอนค่าเสื่อมถึงก่อนวันขายก่อน
- สินทรัพย์ถูกทำเครื่องหมายว่าขายแล้ว ค่าเสื่อมงวดหลังคิดถึงวันก่อนวันขาย และแสดงในแท็บ "ขาย" ของข้อมูลสินทรัพย์
- ขายเงินเชื่อ ยอดไปเป็นหนี้ค้างรับ รับชำระได้ที่ระบบลูกหนี้ ([[howto-ar-overview]])
- ขายเงินสด หน้าจอนี้ยังไม่มีแท็บรับชำระ ระบบถือว่ารับเป็นเงินสดเต็มจำนวน และลงบัญชีเงินสดของกิจการให้เอง ถ้ารับเป็นเงินโอนหรือเช็ค → ส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- เปิดเอกสาร กด "แก้ไข" แล้วบันทึกใหม่
- กด "ลบ" ระบบถาม "ลบเอกสารขายสินทรัพย์ ... ใช่หรือไม่? (ลบรายการบัญชีและคืนสถานะสินทรัพย์)"
- แก้หรือลบในงวดที่ปิดแล้วไม่ได้ ([[ts-common-period-closed]])

## ปัญหาที่พบบ่อย
- "ไม่พบผังบัญชี ... (ต้องสร้างในผังบัญชีก่อนบันทึก)" "สินทรัพย์ ... ยังไม่กำหนดรหัสบัญชีสินทรัพย์/ค่าเสื่อมราคาสะสม" "สินทรัพย์ ... ขายไปแล้วในเอกสาร ..." → [[ts-asset-sale-gainloss-account]]
- "กรุณาเลือกสินทรัพย์ที่ขายอย่างน้อย 1 รายการ" → เพิ่มบรรทัดและเลือกสินทรัพย์
- "กรุณาป้อน รหัสลูกค้า" → ต้องเลือกลูกหนี้ทุกครั้ง แม้ขายเงินสด
