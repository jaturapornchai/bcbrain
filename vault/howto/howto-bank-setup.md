# ตั้งค่าธนาคาร สาขาธนาคาร ประเภทสมุดเงินฝาก และตัวย่อ

**ใช้เมื่อ:** เริ่มใช้ระบบธนาคารหรือเช็ค ต้องมีรายชื่อธนาคารและสาขาไว้เลือกในสมุดเงินฝากและรายการเช็ค
**เมนู:** เริ่มต้น › ตั้งค่าระบบการเงินและธนาคาร › กำหนดธนาคาร / กำหนดสาขาธนาคาร / ประเภทสมุดเงินฝาก / ตัวย่อในสมุดเงินฝาก
**ต้องมีก่อน:** ไม่มี (ทำเป็นอย่างแรกของระบบธนาคาร)

## ขั้นตอน
1. กำหนดธนาคาร: ใส่รหัสและชื่อธนาคาร ใส่ "รหัสบัญชีเช็ครับล่วงหน้า:" ถ้ามี และเลือก "โลโก้ธนาคาร:" ได้
2. กำหนดสาขาธนาคาร: เลือก "ธนาคาร" ก่อน แล้วใส่รหัสและชื่อสาขา
3. ประเภทสมุดเงินฝาก: ใส่รหัสและชื่อ เช่น ออมทรัพย์ กระแสรายวัน ฝากประจำ พร้อม "หมายเหตุ:"
4. ตัวย่อในสมุดเงินฝาก: ใส่รหัสและชื่อตัวย่อที่ธนาคารพิมพ์ในสมุด (ถ้าต้องการเก็บไว้อ้างอิง)
5. บันทึกแต่ละหน้า แล้วไปสร้างสมุดเงินฝากต่อ ([[howto-bank-passbook]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส / ชื่อธนาคาร | ธนาคารที่ใช้ | ใช้ในสมุดเงินฝากและรายการเช็ค |
| รหัสบัญชีเช็ครับล่วงหน้า | บัญชีเช็ครับของธนาคารนั้น | ใช้เฉพาะเมื่อกำหนดรูปแบบการลงบัญชีเอง |
| ธนาคาร (ในหน้าสาขา) | ธนาคารแม่ของสาขา | บังคับเลือก |
| ประเภทสมุดเงินฝาก | ชนิดบัญชี | เลือกในสมุดเงินฝาก |

## บันทึกแล้วระบบทำอะไรให้
- ชื่อธนาคารและสาขาไปแสดงในสมุดเงินฝาก รายการเช็ค และรายงานเช็ค
- การลงบัญชีแบบมาตรฐานใช้บัญชีเช็ครับล่วงหน้าตั้งต้นของระบบ ไม่ได้ใช้บัญชีที่ใส่ในหน้าธนาคาร
- ตัวย่อในสมุดเงินฝาก เป็นข้อมูลอ้างอิงเท่านั้น

## แก้ไข ยกเลิก พิมพ์
- แก้ชื่อหรือข้อมูลได้ตลอด ควรเลี่ยงการลบธนาคารที่มีสมุดเงินฝากหรือเช็คใช้อยู่

## ปัญหาที่พบบ่อย
- "กรุณาเลือกธนาคารก่อนบันทึก" ตอนบันทึกสาขา → หน้า กำหนดสาขาธนาคาร ต้องเลือกธนาคารจากช่อง "ธนาคาร:" ด้านบนก่อน (ค่าเริ่มต้นขึ้นว่า "กรุณาเลือกธนาคาร") รายการสาขาและการเพิ่มสาขาจะผูกกับธนาคารที่เลือก
- ไม่เจอธนาคารให้เลือกในรายการเช็ค → ยังไม่ได้สร้างในหน้า กำหนดธนาคาร
