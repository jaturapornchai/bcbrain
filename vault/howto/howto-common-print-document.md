# พิมพ์เอกสารและเลือกแบบฟอร์ม

**ใช้เมื่อ:** ต้องการพิมพ์เอกสารที่บันทึกแล้ว เช่น ใบกำกับภาษี ใบเสร็จรับเงิน ใบสั่งซื้อ ใบวางบิล หรือบันทึกออกมาเป็นไฟล์ PDF ส่งลูกค้า
**เมนู:** เปิดเอกสารใบนั้นจากเมนูของระบบงาน (ขาย ซื้อ สินค้า เจ้าหนี้ ลูกหนี้ เงินสด/ธนาคาร) › กดปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"
**ต้องมีก่อน:** บันทึกเอกสารเรียบร้อยแล้ว (ถ้ายังไม่บันทึก ระบบให้ดูได้แค่ตัวอย่าง พิมพ์ฉบับจริงไม่ได้)

## ขั้นตอน
1. บันทึกเอกสาร ระบบจะถามว่า "บันทึกเอกสารเลขที่ ... ลงฐานข้อมูลเรียบร้อยแล้ว ต้องการพิมพ์แบบฟอร์มเอกสารเลยหรือไม่?" กด "พิมพ์แบบฟอร์ม" ได้ทันที หรือกด "ยังไม่พิมพ์" แล้วค่อยพิมพ์ทีหลัง
2. ถ้าจะพิมพ์ทีหลัง ให้เปิดเอกสารใบนั้นแล้วกดปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"
3. หน้าต่าง "พิมพ์แบบฟอร์มมาตรฐานสรรพากร & เลือกธีมเอกสาร" จะเปิดขึ้น ด้านบนบอกโหมดว่า "จากข้อมูลที่บันทึกแล้ว (ดึงจากฐานข้อมูล)" หรือเป็นโหมดตัวอย่าง
4. เลือกแบบฟอร์มในหัวข้อ "เลือกแบบฟอร์มสำเร็จรูปพร้อมใช้" (มีให้เลือกหลายแบบ เช่น ใบกำกับภาษี/ใบส่งของ/ใบเสร็จรับเงิน, ใบกำกับภาษีอย่างย่อ/ใบเสร็จรับเงิน, ใบเสนอราคา, ใบวางบิล/ใบแจ้งหนี้, ใบลดหนี้/ใบกำกับภาษี, ใบสั่งซื้อสินค้า, ใบสำคัญจ่าย)
5. ปรับขนาดกระดาษ แนวตั้งหรือแนวนอน ขนาดตัวอักษร ระยะขอบ จำนวนบรรทัดต่อหน้า
6. เลือกรูปแบบดีไซน์ ธีมสีเอกสาร และเลือกพิมพ์ ต้นฉบับ สำเนา หรือพิมพ์คู่
7. กด "สั่งพิมพ์ / บันทึก PDF (จากข้อมูลที่บันทึกแล้ว)" หน้าต่างพิมพ์ของเบราว์เซอร์จะเปิดขึ้น ให้เลือกเครื่องพิมพ์ หรือเลือกบันทึกเป็น PDF
8. ถ้าต้องการให้ครั้งหน้าใช้แบบฟอร์มนี้เลย กด "บันทึก Layout หน้าจอนี้"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| แบบฟอร์มสำเร็จรูป | เลือกชื่อแบบฟอร์มให้ตรงกับเอกสาร | เช่น ขายเชื่อใช้ใบกำกับภาษี/ใบส่งของ/ใบแจ้งหนี้ ขายสดใช้ใบกำกับภาษี/ใบส่งของ/ใบเสร็จรับเงิน |
| ขนาดกระดาษ และแนวกระดาษ | แนวตั้ง (Portrait) หรือแนวนอน (Landscape) | |
| ขนาดตัวอักษร | เล็ก (กะทัดรัด) / มาตรฐาน / ใหญ่ชัดเจน | |
| ระยะขอบ | แคบ / ปกติ / กว้าง | |
| จำนวนบรรทัดต่อหน้า | พอดีรายการจริง หรือ 5 / 8 / 12 / 15 บรรทัด | |
| ชุดเอกสาร | ต้นฉบับ (Original) / สำเนาใบกำกับภาษี/สำเนา / พิมพ์คู่ ต้นฉบับ + สำเนา (2 หน้า) | อยู่ในหัวข้อ "หัวเอกสาร & ชุดต้นฉบับ/สำเนาตามกฎหมาย" |
| ธีมสีเอกสาร | เลือกสีหัวเอกสาร | |

## บันทึกแล้วระบบทำอะไรให้
- ผู้ใช้ระดับ Admin: ครั้งแรกที่พิมพ์ หน้าต่างจะแสดง "พิมพ์ครั้งแรก (ครั้งที่ 1)" ครั้งต่อไปแสดง "พิมพ์ซ้ำครั้งที่ ..." เพื่อให้รู้ว่าเอกสารใบนี้ถูกพิมพ์ไปกี่ครั้งแล้ว
- ผู้ใช้ทั่วไป (Member): รุ่นปัจจุบันยังไม่จำจำนวนครั้งที่พิมพ์ ป้ายอาจขึ้น "พิมพ์ครั้งแรก" ทุกครั้ง ถ้าลูกค้าต้องการนับจำนวนครั้ง ให้ส่งต่อเจ้าหน้าที่
- กด "บันทึก Layout หน้าจอนี้" แล้ว ครั้งหน้าที่เปิดหน้าต่างพิมพ์จากหน้าจอเดียวกัน ระบบจะเลือกแบบฟอร์ม ขนาดกระดาษ และธีมสีนี้ให้เอง (จำไว้ในเครื่องที่ใช้อยู่เสมอ ส่วนการจำให้ทุกเครื่องในบริษัท ต้องให้ผู้ใช้ระดับ Admin เป็นคนกดบันทึก)

## แก้ไข ยกเลิก พิมพ์
- ถ้าพิมพ์แล้วพบว่าข้อมูลผิด ให้แก้เอกสารแล้วบันทึกก่อน จากนั้นพิมพ์ใหม่ ดู [[howto-doc-edit-cancel-delete]]
- ต้องการออกแบบฟอร์มเอง (ใส่โลโก้ ย้ายตำแหน่งช่อง) ให้ Admin ใช้เครื่องมือออกแบบฟอร์ม ดู [[howto-setup-form-designer]]
- การพิมพ์รายงาน (ไม่ใช่ตัวเอกสาร) ดู [[rpt-print-export]]

## ปัญหาที่พบบ่อย
- ปุ่มสั่งพิมพ์กดไม่ได้ หรือเอกสารขึ้นลายน้ำ "ตัวอย่าง" เพราะยังไม่ได้บันทึก ระบบล็อกไว้ ("ล็อกการพิมพ์จริง (ป้องกันพิมพ์แล้วไม่ Save)") ให้บันทึกเอกสารก่อน
- กดแล้วไม่มีหน้าต่างพิมพ์ขึ้น หรือพิมพ์ออกมาเพี้ยน ดู [[ts-common-print-problem]]
