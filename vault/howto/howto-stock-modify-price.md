# ปรับราคาสินค้าทีละมากจากไฟล์ และตรวจราคาด้วยบาร์โค้ด

**ใช้เมื่อ:** ผู้ขายขึ้นราคา ต้องแก้ราคาหลายร้อยรายการพร้อมกัน หรือพนักงานยิงบาร์โค้ดเช็คราคาหน้าชั้น
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ปรับราคาสินค้า / ตรวจสอบราคาสินค้า
**ต้องมีก่อน:** สินค้า หน่วยนับ และบาร์โค้ด ([[howto-stock-barcode]])

## ขั้นตอน (ปรับราคาสินค้า)
1. เลือก ชนิดราคา: ราคาบาร์โค้ด / ราคาตามสูตร / ราคามาตรฐาน / ราคาทั่วไป (ราคาทั่วไปเลือกต่อได้ว่า ราคาขายทั่วไป / ราคาตามกลุ่มลูกค้า / ราคาตามลูกค้า)
2. กด นำเข้าไฟล์ (ไฟล์ข้อความแบบคั่นด้วยจุลภาคหรือแท็บ) หรือกด เพิ่มแถว แล้วกรอกเอง
3. กด ตรวจราคาเก่า เพื่อดูราคาเดิมเทียบราคาใหม่
4. ปกติช่องราคาที่ว่างหรือพิมพ์ 0 ระบบจะไม่เปลี่ยนราคาเดิม ถ้าต้องการให้ช่องที่พิมพ์ 0 ถูกบันทึกเป็น 0 จริง ให้ติ๊ก (Option) แก้ไขราคาให้เป็น 0 (ช่องว่างยังไม่เปลี่ยนราคา)
5. กด บันทึก ระบบแก้ราคาแถวที่มีอยู่แล้ว และเพิ่มแถวใหม่ถ้ายังไม่มี (ดูได้ในช่อง ผลตรวจ ว่าเป็น แก้ไขราคา หรือ เพิ่มราคาใหม่)
6. ล้างตาราง เพื่อเริ่มชุดใหม่

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสสินค้า + หน่วยนับ | ต้องมีทุกแถว | |
| ตั้งแต่วันที่ / ถึงวันที่ | รูปแบบ วว/ดด/ปปปป (หรือ ปปปป-ดด-วว) | ใส่ปีเป็น พ.ศ. ได้ ระบบแปลงให้ |
| จำนวนแถว | ครั้งละไม่เกิน 5,000 แถว | มากกว่านี้ให้แบ่งไฟล์ |

## ตรวจสอบราคาสินค้า
1. ยิงบาร์โค้ด ระบบแสดงราคาปัจจุบันของบาร์โค้ดนั้น
2. ถ้าต้องแก้ ใส่ราคาใหม่แล้วบันทึก (แก้ราคาตามบาร์โค้ด)
- ข้อความ: "กรุณายิง Barcode ก่อน", "ไม่พบบาร์โค้ด ...", "ราคาใหม่ต้องมากกว่า 1"

## บันทึกแล้วระบบทำอะไรให้
- ราคาใหม่มีผลกับบิลที่เลือกสินค้าหลังจากนั้น บิลเดิมไม่เปลี่ยน

## ปัญหาที่พบบ่อย
- "กรุณาเลือกประเภทราคาที่ต้องการปรับปรุง" → เลือก ชนิดราคา ก่อน
- "กรุณาอัพโหลดข้อมูลก่อนดำเนินการ" / "ยังไม่มีรายการราคา กรุณานำเข้าไฟล์หรือเพิ่มแถวก่อน" → นำเข้าไฟล์หรือเพิ่มแถวก่อน
- "ทำได้ครั้งละไม่เกิน ... แถว" → แบ่งไฟล์
- "ต้องมีรหัสสินค้าและหน่วยนับ" → เติมรหัสสินค้าและหน่วยนับให้ครบทุกแถว
- "แถวที่ ...: ... "..." ต้องเป็นรูปแบบ วว/ดด/ปปปป" → แก้วันที่ในไฟล์
- "ไม่มีบาร์โค้ด" → ชนิดราคา ราคาบาร์โค้ด ต้องมีบาร์โค้ดทุกแถว
