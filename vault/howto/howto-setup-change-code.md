# เปลี่ยนรหัสสินค้า ลูกหนี้ เจ้าหนี้ หรือผังบัญชี

**ใช้เมื่อ:** ตั้งรหัสผิด หรืออยากจัดรูปแบบรหัสใหม่ หลังจากมีเอกสารใช้รหัสนั้นไปแล้ว ทำให้แก้ในหน้าจอข้อมูลหลักตรงๆ ไม่ได้
**เมนู:** เริ่มต้น › เปลี่ยนรหัสหลัก (สินค้า/เจ้าหนี้/ลูกหนี้/บัญชี) › เลือก เปลี่ยนรหัสสินค้า / เปลี่ยนรหัสเจ้าหนี้ / เปลี่ยนรหัสลูกหนี้ / เปลี่ยนรหัสผังบัญชี
**ต้องมีก่อน:**
- คุณเป็น Admin ของฐานข้อมูล (เมนูนี้ Member ใช้ไม่ได้)
- แจ้งผู้ใช้คนอื่นให้หยุดบันทึกเอกสารชั่วคราว และตรวจรหัสใหม่ให้แน่ใจก่อน เพราะเป็นงานที่มีผลทั้งฐานข้อมูล

## ขั้นตอน
1. เปิดเมนูเปลี่ยนรหัสตามประเภทที่ต้องการ ตารางด้านล่างจะแสดงรายการรหัสและชื่อ (ค้นหาด้วยรหัสหรือชื่อได้)
2. ในส่วน "รายการ...ที่ต้องการเปลี่ยน" คลิกแถวในตารางด้านล่างเพื่อใส่รหัสเดิม หรือพิมพ์รหัสเดิมเอง
3. พิมพ์รหัสใหม่ในช่องคู่กัน (ระบบเปลี่ยนเป็นตัวพิมพ์ใหญ่ให้)
4. ถ้าจะเปลี่ยนหลายรหัสพร้อมกัน กดปุ่มเครื่องหมายบวกเพื่อเพิ่มแถว กดปุ่มถังขยะเพื่อลบแถวที่ไม่ใช้
5. กด "เริ่มเปลี่ยนรหัส" ระบบถาม "ต้องการเปลี่ยน... ... รายการจริงหรือไม่" ตรวจจำนวนแล้วกดตกลง
6. รอผลลัพธ์ ระบบแสดงแต่ละคู่ว่า รหัสเดิม → รหัสใหม่ และปรับไปกี่แถวในกี่ส่วนของข้อมูล

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสเดิม | รหัสที่มีอยู่ในระบบ | ต้องมีอยู่จริง ไม่อย่างนั้นขึ้น "แถว ...: ไม่พบ...เดิม ..." |
| รหัสใหม่ | รหัสที่ต้องการใช้แทน | ต้องยังไม่มีในระบบ ไม่ซ้ำกับรหัสเดิม และยาวไม่เกิน 50 ตัวอักษร |

## บันทึกแล้วระบบทำอะไรให้
- เปลี่ยนรหัสในข้อมูลหลัก และเปลี่ยนตามไปในเอกสารและข้อมูลที่อ้างอิงรหัสนั้นทั้งหมด เอกสารเก่าจะแสดงรหัสใหม่
- ทำทุกคู่ในครั้งเดียว ถ้ามีคู่ใดผิดพลาด ระบบยกเลิกทั้งชุด ไม่มีการเปลี่ยนไปครึ่งๆ กลางๆ
- เปลี่ยนได้ครั้งละไม่เกิน 500 คู่
- ระบบบันทึกประวัติว่าใครเปลี่ยนรหัสอะไรเป็นอะไร ดูได้ที่เมนูตรวจสอบข้อมูลหลัก ดู [[howto-setup-audit-log]]

## แก้ไข ยกเลิก พิมพ์
- ไม่มีปุ่มย้อนกลับ ถ้าเปลี่ยนผิดให้ทำซ้ำโดยใส่รหัสใหม่เป็นรหัสเดิม แล้วใส่รหัสที่ถูกต้องเป็นรหัสใหม่
- รายงานหรือเอกสารที่พิมพ์ออกไปก่อนเปลี่ยน จะยังเป็นรหัสเดิม

## ปัญหาที่พบบ่อย
- ขึ้น "กรุณาระบุรหัสเดิมและรหัสใหม่" แปลว่ายังไม่ได้กรอกคู่รหัส
- ขึ้น "แถว ...: ต้องระบุทั้งรหัสเดิมและรหัสใหม่" มีบางแถวกรอกไม่ครบ ให้กรอกหรือลบแถวนั้น
- ขึ้น "แถว ...: รหัสใหม่ต้องไม่เหมือนรหัสเดิม" หรือ "แถว ...: รหัสใหม่ ... ซ้ำกันในรายการ" ให้ตรวจรหัสใหม่ในแต่ละแถว
- ขึ้น "แถว ...: ...ใหม่ ... มีอยู่แล้ว" รหัสใหม่มีอยู่แล้วในระบบ ระบบไม่รวมสองรหัสเข้าด้วยกัน ให้ใช้รหัสอื่น
- ขึ้นว่าไม่มีสิทธิ์ ดู [[ts-common-no-permission]]
