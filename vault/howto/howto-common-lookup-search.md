# ค้นหาและเลือกข้อมูลจากหน้าต่างค้นหา

**ใช้เมื่อ:** ต้องกรอกรหัส เช่น รหัสสินค้า รหัสลูกค้า รหัสผู้จำหน่าย รหัสคลัง แต่จำรหัสไม่ได้
**เมนู:** ใช้ได้ทุกหน้าจอที่มีช่องรหัสพร้อมปุ่มแว่นขยายด้านขวา
**ต้องมีก่อน:** มีข้อมูลหลักนั้นในระบบแล้ว เช่น สร้างสินค้าหรือลูกค้าไว้ก่อน

## ขั้นตอน
1. ถ้าจำรหัสได้ พิมพ์รหัสลงในช่องแล้วกด Enter หรือ Tab ระบบจะเติมชื่อให้ (ช่องจะแสดงเป็น รหัส~ชื่อ)
2. ถ้าจำไม่ได้ กดปุ่มแว่นขยายข้างช่อง หน้าต่างค้นหาจะเปิดขึ้น
3. พิมพ์คำค้นในช่อง "พิมพ์คำค้นหา (ตัดคำไทย/อังกฤษอัตโนมัติ)..." พิมพ์ได้ทั้งรหัสหรือชื่อบางส่วน พิมพ์หลายคำได้ ระบบจะหาเฉพาะรายการที่มีครบทุกคำ ช่อง "Auto" ที่ติ๊กไว้ตั้งแต่เปิดหน้าต่าง ทำให้ผลค้นหาเปลี่ยนตามที่พิมพ์ทันที ถ้าเอาติ๊กออก ให้กด Enter หรือปุ่มแว่นขยาย "ค้นหาข้อมูล" เมื่อพิมพ์เสร็จ
4. ใช้ลูกศรขึ้นลงเลือกแถว แล้วกด Enter หรือคลิกที่แถวนั้นครั้งเดียวเพื่อเลือก
5. ถ้ารายการเยอะ ใช้ปุ่มหน้าก่อนหน้า หน้าถัดไป หน้าสุดท้าย ด้านล่าง หรือกด PageUp / PageDown
6. กด Esc หรือปุ่ม "ปิดหน้าต่าง (Esc)" หรือปุ่ม "ยกเลิก" เพื่อปิดโดยไม่เลือก (ปุ่ม "ตกลง" ใช้เลือกแถวที่แถบสีเหลืองอ่อนอยู่)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ช่องคำค้นหา | รหัส ชื่อ หรือบางส่วนของคำ | พิมพ์หลายคำคั่นด้วยเว้นวรรคได้ |
| ช่องบาร์โค้ด | ยิงหรือพิมพ์บาร์โค้ดแล้วกด Enter | เปิดด้วยปุ่ม "ค้นหาสินค้าด้วยบาร์โค้ด (Ctrl+B)" มีเฉพาะหน้าต่างค้นหาสินค้า |
| เลือกตามคลัง/ที่เก็บ | เลือกสินค้าพร้อมคลังและที่เก็บในครั้งเดียว | มีในตารางรายการสินค้าของเอกสาร |
| เลือกตามคลัง/ที่เก็บ/หน่วยนับ | เลือกสินค้าพร้อมคลัง ที่เก็บ และหน่วยนับ | |
| ยอดคงเหลือตามคลัง | ดูยอดคงเหลือของสินค้าแถวนี้แยกตามคลัง | ดูอย่างเดียว |

## บันทึกแล้วระบบทำอะไรให้
- เลือกแล้วระบบเติมรหัสและชื่อลงช่อง และเติมค่าที่ผูกกับรหัสนั้นให้ เช่น เลือกลูกค้าแล้วเติมเงื่อนไขของลูกค้าคนนั้น
- ถ้าหาคำที่พิมพ์ไม่เจอครบทุกคำ ระบบจะขึ้น "แสดงผลใกล้เคียง" เพื่อให้เลือกรายการที่ใกล้เคียงแทน
- ลากปรับความกว้างคอลัมน์ในหน้าต่างค้นหาได้ ถ้าอยากกลับเป็นแบบเดิม กดปุ่ม "ค่าเริ่มต้น"

## แก้ไข ยกเลิก พิมพ์
- เลือกผิด ให้ลบข้อความในช่องแล้วเลือกใหม่
- หน้าต่างค้นหาใช้เลือกข้อมูลอย่างเดียว ถ้าต้องการแก้ข้อมูลสินค้าหรือลูกค้า ให้ไปที่หน้าจอข้อมูลหลักนั้น ดู [[howto-common-data-list]]

## ปัญหาที่พบบ่อย
- พิมพ์รหัสแล้วขึ้น "ไม่พบ : ..." แล้วช่องว่างเปล่า ดู [[ts-common-lookup-not-found]]
- ผู้ที่เคยใช้โปรแกรมรุ่นติดตั้งในเครื่อง ปุ่ม F3 F4 F8 บนคีย์บอร์ดยังไม่ทำงาน ให้คลิกปุ่มบนจอแทน ดู [[start-keyboard-shortcuts]]
