# ตั้งหนี้ค่าใช้จ่ายอื่น ๆ และเพิ่ม/ลดหนี้อื่น ๆ (เจ้าหนี้)

**ใช้เมื่อ:** ได้บิลค่าใช้จ่ายที่ไม่ใช่สินค้าเข้าสต๊อก เช่น ค่าเช่า ค่าขนส่ง ค่าซ่อม และจะจ่ายทีหลัง
**เมนู:** เจ้าหนี้ › ตั้งหนี้อื่นๆ (เจ้าหนี้) / เพิ่มหนี้อื่นๆ (เจ้าหนี้) / ลดหนี้อื่นๆ (เจ้าหนี้)
**ต้องมีก่อน:** เจ้าหนี้ ([[howto-ap-supplier]]) และรหัสค่าใช้จ่ายที่ผูกบัญชีแล้ว ที่ เริ่มต้น › ตั้งค่าระบบการเงินและธนาคาร › กำหนดประเภทค่าใช้จ่าย (ช่อง "รหัสผังบัญชีค่าใช้จ่าย:")

## เลือกเมนูไหน
| สถานการณ์ | เมนู |
|---|---|
| บิลค่าใช้จ่ายใหม่ ค้างจ่าย | ตั้งหนี้อื่นๆ (เจ้าหนี้) |
| ผู้ขายเรียกเก็บเพิ่มจากบิลที่ตั้งหนี้ไว้ | เพิ่มหนี้อื่นๆ (เจ้าหนี้) |
| ผู้ขายลดยอดให้จากบิลที่ตั้งหนี้ไว้ | ลดหนี้อื่นๆ (เจ้าหนี้) |

## ขั้นตอน
1. เปิดเมนู กด "เพิ่มใหม่" เลือกเจ้าหนี้ (ตั้งหนี้อื่นๆ ให้ "ประเภทรายการ" เป็น 0: ซื้อเชื่อ (เครดิต))
2. ตั้งหนี้อื่นๆ กดปุ่ม "เลือกเอกสารสั่งซื้อสินค้า" ดึงใบสั่งซื้อที่ยังไม่เคยใช้ได้ ถ้าไม่มีใบสั่งซื้อก็ข้ามได้ ([[howto-buy-reference-doc]])
3. เพิ่มหนี้และลดหนี้ กดปุ่ม "เลือกเอกสารตั้งหนี้อื่นๆ" ดึงใบตั้งหนี้อื่นๆ ใบเดิม และใส่ "สาเหตุ:"
4. ในตาราง เลือก "รหัสค่าใช้จ่าย" ใส่จำนวนเงินแต่ละบรรทัด
5. ใส่ "เลขที่ใบกำกับภาษี:" และ "ลงวันที่:" ถ้าได้ใบกำกับภาษี เลือกช่อง "ภาษี:" ให้ตรงบิล ([[howto-buy-purchase-vat]])
6. ถ้าเคยจ่ายมัดจำผู้ขายรายนี้ หักได้ที่แท็บ "ใช้เงินมัดจำ" (เฉพาะตั้งหนี้อื่นๆ) ([[howto-buy-use-deposit]])
7. ตรวจแท็บ "การลงบัญชี (GL)" แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เจ้าหนี้ | ผู้เรียกเก็บเงิน | ช่องบังคับ |
| รหัสค่าใช้จ่าย | ชนิดค่าใช้จ่าย | กำหนดบัญชีที่จะลงให้ |
| ประเภทรายการ | 0: ซื้อเชื่อ (เครดิต) | เฉพาะตั้งหนี้อื่นๆ |
| ภาษี: | ตามบิลจริง | แยกนอก รวมใน ยกเว้นภาษี หรือไม่กระทบภาษี |
| เลขที่ใบกำกับภาษี: | เลขที่ในบิล | ใช้ในรายงานภาษีซื้อ |
| ปุ่ม เลือกเอกสารตั้งหนี้อื่นๆ | ใบตั้งหนี้อื่นๆ ใบเดิม | เฉพาะเพิ่มหนี้และลดหนี้ |
| สาเหตุ: | เหตุผลที่เพิ่มหรือลดหนี้ | เฉพาะเพิ่มหนี้และลดหนี้ |

## บันทึกแล้วระบบทำอะไรให้
- ยอดเจ้าหนี้รายนั้นเพิ่ม (ลดหนี้อื่นๆ ทำให้ลด) รอจ่ายที่ [[howto-ap-payment]]
- ลงบัญชีให้อัตโนมัติ เดบิตค่าใช้จ่ายและภาษีซื้อ เครดิตเจ้าหนี้ ลดหนี้อื่นๆ ลงกลับด้าน
- ไม่เปลี่ยนสต๊อกสินค้า
- ข้อมูลภาษีเข้ารายงานภาษีซื้อ

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบได้ ถ้ายังไม่ถูกวางบิล จ่ายชำระ หรือเพิ่ม/ลดหนี้อ้างถึง ([[ts-buy-cannot-edit]])
- ยกเลิกที่ เจ้าหนี้ › ยกเลิกเอกสารเจ้าหนี้ (ตั้งหนี้อื่น/วางบิล/จ่ายชำระ) ([[howto-ap-cancel-docs]])
- พิมพ์ด้วยปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ" ([[rpt-print-export]])

## ข้อควรรู้
- การลงบัญชีตามค่าตั้งต้น ใช้บัญชีของรหัสค่าใช้จ่ายบรรทัดแรกกับทั้งใบ ถ้าในบิลเดียวมีค่าใช้จ่ายหลายชนิดที่ลงคนละบัญชี ให้ตรวจแท็บ "การลงบัญชี (GL)" หรือแยกเป็นหลายใบ
- ถ้ารหัสค่าใช้จ่ายยังไม่ผูกบัญชี ระบบลงบัญชีซื้อสินค้าตั้งต้นแทน ให้ผูกบัญชีก่อนบันทึก
- ถ้าเลือก "ประเภทรายการ" เป็น 1: ซื้อสด ระบบลงบัญชีฝั่งเครดิตเป็นเงินสดแทนเจ้าหนี้ แต่ใบนี้ยังขึ้นเป็นยอดค้างจ่ายให้ดึงไปจ่ายซ้ำได้ ถ้าเจอแบบนี้ ส่งต่อเจ้าหน้าที่
