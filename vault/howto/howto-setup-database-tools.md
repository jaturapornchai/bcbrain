# เครื่องมือจัดการฐานข้อมูล

**ใช้เมื่อ:** ยอดสินค้าคงเหลือหรือต้นทุนดูไม่ถูกต้อง ต้องการตรวจความสมบูรณ์ของข้อมูล หรือต้องการดูข้อมูลระดับลึกสำหรับทีมงาน
**เมนู:** เริ่มต้น › จัดการฐานข้อมูลและสิทธิ์ผู้ใช้ › เลือกเครื่องมือ และ สินค้า › คำนวณยอดสต๊อกใหม่
**ต้องมีก่อน:** คุณเป็น Admin ของฐานข้อมูล (ยกเว้น ผังการทำงานระบบ และ กำหนดรูปแบบการค้นหาข้อมูล ที่ Member เปิดได้ถ้าได้รับสิทธิ์)

## ขั้นตอน
**ตรวจสอบและปรับปรุงข้อมูล**
1. เปิดเมนู ระบบแสดงหัวข้อตรวจสอบทั้งหมด พร้อมจำนวนรายการที่ผิดปกติของแต่ละหัวข้อ ด้านบนแสดง "หัวข้อตรวจสอบความสมบูรณ์ของฐานข้อมูล"
2. ติ๊กช่อง "เลือก" เฉพาะหัวข้อที่ต้องการปรับปรุง (หรือกด "เลือกทั้งหมด")
3. กด "เริ่มประมวลผล" ระบบถาม "ยืนยันการปรับปรุงข้อมูล" กดตกลง
4. ระบบขึ้น "ตรวจสอบและปรับปรุงเรียบร้อย (ปรับปรุง ... แถว" และถ้ามีหัวข้อที่ทำไม่สำเร็จจะบอกจำนวนที่ผิดพลาด

**คำนวณยอดสต๊อกใหม่**
1. เปิด สินค้า › คำนวณยอดสต๊อกใหม่
2. ถ้าจะคำนวณเฉพาะบางสินค้า พิมพ์รหัสสินค้าในช่อง "ค้นหาในตารางรายการสินค้า" คั่นด้วยเครื่องหมายจุลภาค ถ้าเว้นว่างจะคำนวณทุกสินค้า
3. กด "คำนวณยอดสต๊อกใหม่" รอจนขึ้น "คำนวณยอดสต๊อกใหม่สำเร็จ (... รายการ / ปรับปรุง ... แถว)"

## ช่องสำคัญที่ต้องกรอก
| เครื่องมือ | ทำอะไรได้จริง | หมายเหตุ |
|---|---|---|
| ตรวจสอบและปรับปรุงข้อมูล | ตรวจข้อมูลสินค้าและรายการเคลื่อนไหวสินค้า แล้วปรับปรุงหัวข้อที่เลือก | เปลี่ยนข้อมูลจริง บางหัวข้อเป็นการลบข้อมูลที่ไม่สมบูรณ์ออก ควรปรึกษาทีมงานก่อนใช้ |
| คำนวณยอดสต๊อกใหม่ | คำนวณยอดคงเหลือและต้นทุนสินค้าใหม่จากเอกสาร | ควรทำตอนที่ไม่มีคนบันทึกเอกสาร |
| แสดงโครงสร้างฐานข้อมูลทั้งหมด | แสดงรายการส่วนเก็บข้อมูลและช่องข้อมูลทั้งหมด | ดูอย่างเดียว สำหรับทีมงาน |
| ใช้คำสั่ง Query / สร้างคำสั่ง Query / ตรวจสอบโครงสร้างฐานข้อมูล | เปิดหน้าจอรายงานที่ผู้ชำนาญเขียนคำสั่งค้นข้อมูลเองได้ | ดูข้อมูลอย่างเดียว ไม่เปลี่ยนข้อมูล ตอนนี้ "ตรวจสอบโครงสร้างฐานข้อมูล" เปิดหน้าจอเดียวกันนี้ ยังไม่ได้ตรวจโครงสร้างจริง |
| ลดขนาดข้อมูล | แสดงขนาดข้อมูลแต่ละส่วน | ยังไม่ได้ลดขนาดจริง ดู [[ts-common-menu-not-ready]] |
| สำรองข้อมูล / นำข้อมูลสำรองกลับมาใช้ | แสดงขนาดข้อมูล | ยังไม่ได้สำรองหรือกู้คืนจริง ดู [[howto-setup-backup-restore]] |
| ผังการทำงานระบบ | แสดงภาพรวมระบบงานหลัก 6 ระบบ | ดูอย่างเดียว |
| กำหนดผู้มีสิทธิเข้าใช้ข้อมูล / กำหนดสิทธิการใช้งาน | แสดงรายชื่อผู้ใช้งานระบบ | การกำหนดสิทธิ์จริงทำที่ "สมาชิก & สิทธิ์จอ" ดู [[howto-user-screen-permission]] |
| กำหนดรูปแบบการค้นหาข้อมูล | บันทึกรูปแบบการค้นหาได้ | ตอนนี้ค่าที่บันทึกยังไม่มีผลกับหน้าจอค้นหา |

## บันทึกแล้วระบบทำอะไรให้
- ตรวจสอบและปรับปรุงข้อมูล ทำแต่ละหัวข้อแยกกัน ถ้าหัวข้อหนึ่งผิดพลาด หัวข้ออื่นยังทำต่อ และระบบบันทึกประวัติการประมวลผลไว้ ดู [[howto-setup-audit-log]]
- คำนวณยอดสต๊อกใหม่ ปรับยอดคงเหลือและต้นทุนให้ตรงกับเอกสารที่บันทึกไว้ หลังทำเสร็จให้ตรวจรายงานสินค้าคงเหลืออีกครั้ง ดู [[howto-stock-overview]]

## แก้ไข ยกเลิก พิมพ์
- การปรับปรุงข้อมูลไม่มีปุ่มย้อนกลับ และระบบยังไม่มีการสำรองข้อมูลจากหน้าจอ จึงควรแจ้งทีมงานก่อนใช้กับข้อมูลจริง
- ผลจากหน้าจอคำสั่งค้นข้อมูลและโครงสร้างฐานข้อมูล พิมพ์หรือส่งออกได้แบบรายงาน ดู [[rpt-print-export]]

## ปัญหาที่พบบ่อย
- ขึ้น "กรุณาเลือกรายการที่ต้องการปรับปรุง" ให้ติ๊กหัวข้ออย่างน้อย 1 หัวข้อก่อนกด
- กดปุ่มแล้วขึ้น "ประมวลผล ... เรียบร้อยแล้ว" ในเครื่องมือที่ยังไม่ได้ทำงานจริง (เช่น ลดขนาดข้อมูล) ดู [[ts-common-menu-not-ready]]
- ปุ่มกดไม่ได้หรือเปิดเมนูไม่ได้ ดู [[ts-common-no-permission]]
