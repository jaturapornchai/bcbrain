# สร้างสมุดเงินฝาก (บัญชีธนาคารของกิจการ)

**ใช้เมื่อ:** กิจการมีบัญชีธนาคาร และต้องการบันทึกฝาก ถอน โอน นำฝากเช็ค หรือรับเงินโอนเข้าบัญชีนั้น
**เมนู:** เงินสด/ธนาคาร › สมุดเงินฝากธนาคาร (ฝาก / ถอน / โอน) › กำหนดสมุดเงินฝาก
**ต้องมีก่อน:** ธนาคาร สาขา ประเภทสมุดเงินฝาก ([[howto-bank-setup]]) และบัญชีเงินฝากในผังบัญชี ([[howto-gl-overview]])

## ขั้นตอน
1. เปิดเมนู กำหนดสมุดเงินฝาก กด "เพิ่มใหม่"
2. ใส่รหัสสมุดและชื่อ (เช่น ชื่อธนาคาร + ชนิดบัญชี)
3. ใส่ "เลขที่บัญชีธนาคาร:" เลือก "รหัสธนาคาร:" "สาขาธนาคาร:" "ประเภทสมุดเงินฝาก:" และ "สกุลเงิน:"
4. เลือก "รหัสผังบัญชีเงินฝาก:" ให้ตรงกับบัญชีเงินฝากของสมุดนี้ในผังบัญชี
5. กด "บันทึก" ทำซ้ำให้ครบทุกบัญชีธนาคาร

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เลขที่บัญชีธนาคาร | เลขบัญชีจริง | |
| รหัสผังบัญชีเงินฝาก | บัญชีเงินฝากของสมุดนี้ | สำคัญที่สุด ใช้ตอนลงบัญชีอัตโนมัติ |
| รหัสผังบัญชีพัก | บัญชีพัก | ใช้เฉพาะเมื่อกำหนดรูปแบบการลงบัญชีเอง |
| รหัสธนาคาร / สาขาธนาคาร | ธนาคารของบัญชี | ไปแสดงในรายงาน |
| เลขประจำตัวผู้เสียภาษี | ถ้าต้องการเก็บไว้ | |
| ช่องค่าธรรมเนียมเช็ค (อัตรา ขั้นต่ำ สูงสุด) | ข้อมูลค่าธรรมเนียม | เก็บไว้อ้างอิง ระบบยังไม่ได้คำนวณให้ |

## บันทึกแล้วระบบทำอะไรให้
- สมุดนี้เลือกได้ในเอกสารฝาก ถอน โอน นำฝากเช็ค เช็คผ่าน ขึ้นเงินบัตรเครดิต และในแท็บรับ/จ่ายชำระเงิน (เงินโอน)
- เอกสารที่ใช้สมุดนี้ จะลงบัญชีด้วย "รหัสผังบัญชีเงินฝาก" ของสมุด ถ้าไม่ได้ผูก ระบบใช้บัญชีเงินฝากธนาคารตั้งต้นแทน
- ยอดยกมาของสมุด ทำที่เมนู เงินฝากธนาคารยกมา ([[howto-cash-beginning-balance]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไขข้อมูลได้ การเปลี่ยนบัญชีมีผลกับเอกสารที่บันทึกหรือลงบัญชีใหม่หลังจากนั้น

## ปัญหาที่พบบ่อย
- ลงบัญชีเงินฝากทุกสมุดเป็นบัญชีเดียวกัน → สมุดยังไม่ได้ผูก "รหัสผังบัญชีเงินฝาก"
- ใส่ค่าธรรมเนียมเช็คแล้วไม่ถูกหักอัตโนมัติ → ช่องนี้ยังเป็นข้อมูลอ้างอิงเท่านั้น
