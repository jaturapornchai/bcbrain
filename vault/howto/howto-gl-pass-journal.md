# ผ่านรายการ และยกเลิกผ่านรายการ ใบสำคัญ

**ใช้เมื่อ:** ผู้ตรวจบัญชีภายในต้องการทำเครื่องหมายว่าใบสำคัญได้ตรวจแล้ว (ผ่านรายการ = ยืนยันว่าใบสำคัญถูกต้อง) หรือต้องการถอนเครื่องหมายนั้น
**เมนู:** บัญชี › ตรวจสอบ ผ่านรายการ และประมวลผลบัญชี › ผ่านรายการ · ยกเลิก: บัญชี › ยกเลิกผ่านรายการ
**ต้องมีก่อน:** ใบสำคัญที่บันทึกแล้ว · ยกเลิกผ่านรายการ ใช้ได้เฉพาะ Admin ([[faq-gl-who-can-close]])

## ขั้นตอน
1. เปิดเมนู ผ่านรายการ
2. กรอก จากวันที่ / ถึงวันที่ และถ้าต้องการ "จากเลขที่ใบสำคัญ (รออนุมัติผ่านรายการ)" / "ถึงเลขที่ใบสำคัญ (รออนุมัติผ่านรายการ)"
3. หน้าจอแสดงจำนวน ใบสำคัญ / เลือกได้ / มีข้อผิดพลาด
4. ติ๊กเลือกใบสำคัญที่จะผ่านรายการ (ใบที่มีข้อผิดพลาดติ๊กไม่ได้ ส่วนใบที่หมายเหตุ ผ่านรายการแล้ว ยังติ๊กได้ แต่ไม่นับซ้ำ)
5. กด "ผ่านรายการ" ระบบถาม "ต้องการผ่านรายการจริงหรือไม่ (... ใบ)" กดตกลง
6. ขึ้น "ผ่านรายการเรียบร้อย ... ใบ" (นับเฉพาะใบที่สถานะเปลี่ยนจริง)

**ยกเลิกผ่านรายการ:** ทำแบบเดียวกันที่เมนู ยกเลิกผ่านรายการ (ช่องเลขที่จะเป็น "...เลขที่ใบสำคัญ (ที่ผ่านรายการแล้ว)") กด "ยกเลิกผ่านรายการ" แล้วยืนยัน

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| จากวันที่ / ถึงวันที่ | ช่วงของใบสำคัญ | |
| จากเลขที่ / ถึงเลขที่ใบสำคัญ | ใส่ช่องเดียว = ใบเดียว ใส่ทั้งสอง = ช่วง | ว่างได้ |

## บันทึกแล้วระบบทำอะไรให้
- ใบสำคัญที่เลือกได้สถานะ ผ่านรายการแล้ว
- หมายเหตุของใบที่ติ๊กไม่ได้: "ไม่พบผังบัญชี", "รหัสบัญชีผิดประเภท" (ใช้บัญชีหลัก), "ยอดไม่ Balance" (เดบิตไม่เท่าเครดิต)
- การผ่านรายการเป็นแค่เครื่องหมายว่าตรวจแล้ว รายงานบัญชีแสดงทั้งใบที่ผ่านและยังไม่ผ่าน และยังแก้ไขใบสำคัญได้ แต่ถ้าแก้แล้วบันทึกใหม่ สถานะจะกลับเป็นยังไม่ผ่าน ([[faq-gl-pass-journal-needed]])
- รายการที่ขึ้นมาให้ผ่านรวมใบสำคัญทุกใบในช่วงวันที่ ทั้งที่บันทึกเองและที่ระบบลงบัญชีให้จากเอกสาร

## แก้ไข ยกเลิก พิมพ์
- ต้องการแก้หมายเหตุว่าผ่านแล้ว ใช้ ยกเลิกผ่านรายการ
