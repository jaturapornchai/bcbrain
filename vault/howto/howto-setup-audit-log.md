# ดูประวัติการใช้งานและตรวจสอบระบบ (Audit Log)

**ใช้เมื่อ:** ต้องการตรวจว่าใครเพิ่ม แก้ไข หรือลบข้อมูลหลัก (เช่น ลูกค้า ผู้จำหน่าย สินค้า ราคา) หรือใครสั่งประมวลผลอะไร เมื่อไร
**เมนู:** เริ่มต้น › ประวัติการใช้งานและตรวจสอบระบบ (Audit Log) › เลือกเมนูย่อย
**ต้องมีก่อน:** คุณเป็น Admin ของฐานข้อมูล (เมนูกลุ่มนี้ Member ใช้ไม่ได้)

## ขั้นตอน
1. เปิดเมนูย่อยที่ต้องการ (ดูตารางด้านล่าง)
2. ใส่ "จากวันที่" และ "ถึงวันที่" ช่วงที่ต้องการตรวจ
3. ถ้าต้องการกรอง พิมพ์คำค้นในช่องค้นหา เช่น รหัสผู้ใช้ เลขที่เอกสาร หรือรหัสสินค้า แล้วกด "ค้นหา"
4. ดูผลในตาราง รายการล่าสุดอยู่บนสุด ด้านบนแสดง "จำนวนรายการ"

## ช่องสำคัญที่ต้องกรอก
| เมนูย่อย | แสดงอะไร | หมายเหตุ |
|---|---|---|
| ข้อมูลหลัก | การเพิ่ม แก้ไข ลบ ข้อมูลหลัก เช่น ลูกค้า ผู้จำหน่าย สินค้า ราคาสินค้า รูปสินค้า และการเปลี่ยนรหัส | มีคอลัมน์ รหัสผู้ใช้ วันที่/เวลา รหัส ชื่อ ข้อมูลเดิม ข้อมูลใหม่ (บางรายการ) |
| ข้อมูลรายวัน | งานประมวลผลที่สั่งจากระบบ เช่น ยกเลิกเอกสาร คิดค่าเสื่อมราคา ยอดสินค้ายกมา ปรับปรุงสินค้า ตรวจสอบและปรับปรุงข้อมูล | ไม่ได้แสดงการบันทึกเอกสารทั่วไปทุกใบ |
| ประวัติการแก้ไขรายวัน | ประวัติการแก้เอกสารแบบละเอียดจากโปรแกรมเดิม | ฐานข้อมูลส่วนใหญ่ไม่มีข้อมูลส่วนนี้ ระบบจะแจ้งว่าไม่พบตารางประวัติในฐานข้อมูลนี้ และไม่แสดงรายการ |
| เข้าใช้ฐานข้อมูล / เข้าออกระบบ / แสดงหน้าจอการใช้งาน / แสดงหน้าจอการใช้งาน (ย้อนหลัง) | ประวัติการเข้าระบบและการเปิดหน้าจอ | ระบบบนเว็บยังไม่ได้บันทึกข้อมูลส่วนนี้ จึงมักไม่มีรายการ (ถ้ามีจะเป็นข้อมูลจากโปรแกรมเดิม) |
| รายงานพนักงานเรียงตามกลุ่ม | รายชื่อพนักงาน พร้อมตำแหน่งหรือกลุ่ม สาขา และโทรศัพท์ | เป็นรายงาน ดู [[rpt-print-export]] |

## บันทึกแล้วระบบทำอะไรให้
- หน้าจอกลุ่มนี้ใช้ดูอย่างเดียว ไม่มีการแก้ไขหรือลบประวัติ
- แสดงได้สูงสุด 5,000 รายการต่อครั้ง ถ้าข้อมูลเยอะให้แคบช่วงวันที่ลง
- คอลัมน์ "การทำงาน" แสดงเป็นคำว่า เพิ่ม, แก้ไข หรือ ลบ

## แก้ไข ยกเลิก พิมพ์
- ต้องการดูว่าใครสร้างหรือแก้เอกสารใบไหน ใช้ปุ่ม "ผู้สร้าง/แก้ไข" หรือ "ประวัติแก้ไข" ที่หน้าจอเอกสารนั้นแทน ดู [[howto-common-record-history]]

## ปัญหาที่พบบ่อย
- เปิดแล้วไม่มีรายการเลย ให้ขยายช่วงวันที่ และล้างคำค้น ถ้าเป็นเมนูเข้าใช้ฐานข้อมูล เข้าออกระบบ หรือแสดงหน้าจอการใช้งาน การไม่มีรายการถือเป็นปกติของระบบตอนนี้
- ขึ้นว่าต้องระบุช่วงวันที่ ให้ใส่ทั้งจากวันที่และถึงวันที่ ดู [[ts-common-date-input-error]]
- เปิดเมนูไม่ได้ ดู [[ts-common-no-permission]]
