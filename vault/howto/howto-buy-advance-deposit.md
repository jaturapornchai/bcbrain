# จ่ายเงินมัดจำ จ่ายเงินล่วงหน้า และรับคืนเงินมัดจำจากผู้ขาย

**ใช้เมื่อ:** ต้องจ่ายเงินให้ผู้ขายก่อนได้รับสินค้า หรือผู้ขายคืนเงินที่จ่ายไว้ก่อน
**เมนู:** ซื้อ › เงินล่วงหน้าและเงินมัดจำจ่าย › จ่ายเงินมัดจำ / จ่ายเงินล่วงหน้า / รับคืนจ่ายเงินมัดจำ / รับคืนจ่ายเงินล่วงหน้า / จ่ายเงินมัดจำยกมา / จ่ายเงินล่วงหน้ายกมา
**ต้องมีก่อน:** รหัสเจ้าหนี้ (ผู้ขาย) หน้าจอนี้ไม่มีช่องอ้างอิงใบสั่งซื้อ ([[howto-buy-purchase-order]])

## ขั้นตอน (จ่ายเงินมัดจำ หรือ จ่ายเงินล่วงหน้า)
1. เปิดเมนูที่ต้องการ กด "เพิ่มใหม่"
2. กรอกวันที่ เลขที่เอกสาร เลือกรหัสเจ้าหนี้
3. ในตาราง ใส่ "รายละเอียด" และ "จำนวนเงิน" ของเงินมัดจำหรือเงินล่วงหน้า
4. ใบจ่ายเงินมัดจำ มีแท็บ "ข้อมูลภาษี (VAT/WHT)" ให้บันทึกใบกำกับภาษีของเงินมัดจำและภาษีหัก ณ ที่จ่ายถ้ามี
5. ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่ช่องทางจ่าย เงินสด เงินโอน เช็ค ให้ครบยอด ([[howto-ap-payment-methods]])
6. กด "บันทึก"

## ขั้นตอน (รับคืน)
1. เปิดเมนู รับคืนจ่ายเงินมัดจำ หรือ รับคืนจ่ายเงินล่วงหน้า กด "เพิ่มใหม่"
2. เลือกรหัสเจ้าหนี้ แล้วดึงใบจ่ายเงินมัดจำหรือใบจ่ายล่วงหน้าที่จะรับคืน
3. ระบบแสดง "เลขที่ใบจ่ายล่วงหน้า" และ "จำนวนจ่ายเงินล่วงหน้า" ของใบเดิม ใส่ยอดที่ได้รับคืน
4. ใส่ช่องทางรับเงินที่แท็บ "การรับ/จ่ายชำระเงิน" แล้วบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสเจ้าหนี้ | ผู้ขาย | ใช้ค้นหาใบมัดจำตอนตัดในใบซื้อ |
| รายละเอียด / จำนวนเงิน | ข้อความและยอดเงิน | ในตารางของใบมัดจำ |
| ภาษี: (ประเภทภาษี) | เฉพาะใบจ่ายเงินมัดจำ | ใบจ่ายเงินล่วงหน้าไม่มีแท็บภาษี |

## บันทึกแล้วระบบทำอะไรให้
- จ่ายเงินล่วงหน้า: ลงบัญชี เงินจ่ายล่วงหน้า (เต็มจำนวน) คู่กับช่องทางที่จ่าย
- จ่ายเงินมัดจำ: ลงบัญชี เงินมัดจำจ่าย (ยอดก่อนภาษี) และ ภาษีซื้อ คู่กับช่องทางที่จ่าย
- รับคืน: ลงบัญชีกลับด้าน เงินเข้า คู่กับ เงินมัดจำจ่าย หรือ เงินจ่ายล่วงหน้า
- เมนูที่ลงท้ายด้วย "ยกมา" ใช้บันทึกยอดที่จ่ายไว้ก่อนเริ่มใช้โปรแกรม ไม่มีแท็บจ่ายเงินและไม่ลงบัญชี
- ยอดคงเหลือของใบมัดจำ = ยอดที่จ่าย หัก ยอดที่รับคืน หัก ยอดที่ตัดไปในใบซื้อแล้ว
- การตัดเงินมัดจำออกจากใบซื้อ ดู [[howto-buy-use-deposit]] และความต่างของมัดจำกับล่วงหน้า ดู [[faq-buy-advance-vs-deposit]]

## แก้ไข ยกเลิก พิมพ์
- ใบที่ถูกนำไปตัดในใบซื้อหรือรับคืนแล้ว แก้ไขหรือลบไม่ได้ ([[ts-buy-deposit-cannot-delete]])
- ยกเลิกด้วยเมนู ยกเลิกจ่ายเงินมัดจำ / ยกเลิกจ่ายเงินล่วงหน้า / ยกเลิกรับคืน... ([[howto-buy-cancel-docs]])

## ปัญหาที่พบบ่อย
- "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" → ช่องทางจ่ายรวมกันยังไม่เท่ายอดเอกสาร ([[ts-ap-pay-incomplete]])
- "ห้ามแก้ไข หรือลบข้อมูล" หรือ "เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้" → ดู [[ts-buy-deposit-cannot-delete]]
