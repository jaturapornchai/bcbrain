# กำหนดสกุลเงิน

**ใช้เมื่อ:** กิจการซื้อขายหรือรับจ่ายเป็นเงินตราต่างประเทศ ต้องมีสกุลเงินและอัตราแลกเปลี่ยนในระบบ
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดสกุลเงิน (ไม่จำกัดเฉพาะ Admin)
**ต้องมีก่อน:** ถ้าจะใช้ในเอกสารจริง ให้เปิดข้อ "ใช้ระบบหลายสกุลเงิน (Multi-Currency)" ที่ [[howto-setup-options]] และเลือก "สกุลเงินหลัก" · เริ่มต้นใช้งานดู [[start-first-day]]

## ขั้นตอน
1. เปิดเมนู "กำหนดสกุลเงิน" กด "เพิ่มใหม่"
2. กรอกรหัสและชื่อสกุลเงิน
3. กรอก "สัญลักษณ์สกุลเงิน" และ "อัตราแลกเปลี่ยนปัจจุบัน"
4. กดบันทึก (หรือ F12 หรือ Ctrl+S)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส | รหัสสั้นของสกุลเงิน | ห้ามซ้ำ ถ้าซ้ำขึ้น "รหัสซ้ำ" |
| ชื่อ / ชื่อภาษาอังกฤษ | ชื่อสกุลเงิน | ต้องกรอกชื่อ |
| สัญลักษณ์สกุลเงิน | สัญลักษณ์ที่ใช้แสดง | |
| อัตราแลกเปลี่ยนปัจจุบัน | อัตราเทียบเงินบาท | ปรับให้ตรงกับอัตราที่ใช้จริง |
| ยกเลิกการใช้งาน | ติ๊กเมื่อเลิกใช้สกุลเงินนี้ | เก็บรายการไว้ ไม่ต้องลบ |

## บันทึกแล้วระบบทำอะไรให้
- สกุลเงินใหม่พร้อมให้เลือกในหน้าที่ใช้หลายสกุลเงิน
- ขึ้นข้อความ "กรุณาระบุรหัส" หรือ "กรุณาระบุชื่อ" ถ้ายังไม่กรอก

## แก้ไข ยกเลิก พิมพ์
- แก้ไข: เลือกรายการ กด "แก้ไข" แก้แล้วบันทึก ถ้าเปลี่ยนรายการทั้งที่ยังไม่บันทึก ระบบถาม "มีการเปลี่ยนแปลงข้อมูลที่ยังไม่ได้บันทึก ต้องการสลับรายการหรือไม่?"
- ลบ: กด "ลบ" แล้วยืนยัน "ต้องการลบรายการ ... หรือไม่?" ถ้ามีการใช้งานแล้วระบบอาจขึ้น "ไม่อนุญาตให้ลบ" ให้ติ๊ก ยกเลิกการใช้งาน แทน
- ปิดหน้าจอ: ปุ่ม "ปิดหน้าจอ" หรือ Esc

## ปัญหาที่พบบ่อย
- ขึ้นรหัสซ้ำ: รหัสนี้มีอยู่แล้ว ใช้รหัสอื่น
- ไม่มีสิทธิ์เพิ่ม/แก้ไข: ดู [[ts-common-no-permission]]
- ตอนนี้หน้านี้เก็บอัตราแลกเปลี่ยนปัจจุบันเพียงค่าเดียวต่อสกุลเงิน ไม่มีตารางประวัติอัตรารายวันในหน้านี้
