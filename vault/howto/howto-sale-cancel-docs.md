# ยกเลิกเอกสารขายและเงินมัดจำรับ

**ใช้เมื่อ:** เอกสารขายที่บันทึกไปแล้วไม่ใช้แล้ว หรือออกผิด ต้องการยกเลิกโดยเก็บประวัติไว้ (ระบบสร้าง "ใบยกเลิก" แยก ไม่ลบเอกสารเดิมทิ้ง)
**เมนู:** ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › เลือกเมนูตามเอกสาร
- ยกเลิกใบเสนอราคาขาย / ยกเลิกใบสั่งจองสินค้า / ยกเลิกใบสั่งขายสินค้า
- ยกเลิกรับเงินล่วงหน้า / ยกเลิกคืนเงินรับล่วงหน้า / ยกเลิกรับเงินมัดจำ / ยกเลิกคืนเงินมัดจำ
- ยกเลิกขายสินค้า/บริการ / ยกเลิกรับคืนสินค้า/ลดหนี้ขาย / ยกเลิกเพิ่มหนี้ขาย/ราคาผิด
**ต้องมีก่อน:** สิทธิ์ใช้เมนูยกเลิก ([[ts-common-no-permission]])

## ขั้นตอน (ยกเลิกทั้งใบ)
1. เปิดเมนูยกเลิกของเอกสารนั้น (จอขึ้นว่า "โหมดยกเลิกเอกสาร")
2. กด "เลือกเอกสาร" เลือกใบที่จะยกเลิก ระบบแสดงรายละเอียดเดิมแบบอ่านอย่างเดียว
3. ใส่ "หมายเหตุ" (ช่องขึ้นว่า "ระบุเหตุผลการยกเลิก")
4. กด "บันทึกยกเลิก" ระบบขึ้น "ยกเลิกเอกสาร ... เรียบร้อยแล้ว"

## ขั้นตอน (ยกเลิกรายสินค้า เฉพาะใบเสนอราคา ใบสั่งจอง ใบสั่งขาย)
1. เลือกเอกสาร แล้วเลือก "ประเภทการยกเลิก" เป็น "ยกเลิกรายสินค้า"
2. กดปุ่ม "ดึงรายการ" ระบบดึงรายการที่ยังค้างอยู่
3. แก้ช่อง "จำนวนยกเลิก" ของแต่ละบรรทัด แล้วกด "บันทึกยกเลิก"
4. ใบยกเลิกที่ทำไว้ จะแสดงในกล่อง "ใบยกเลิกของเอกสารนี้"
- เหมาะกับลูกค้าสั่ง 100 ชิ้น ส่งไปแล้ว 60 ชิ้น ส่วนที่เหลือไม่เอาแล้ว ให้ยกเลิกส่วนที่ค้างเพื่อปิดใบ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทการยกเลิก | ยกเลิกทั้งหมด / ยกเลิกรายสินค้า | รายสินค้าใช้ได้กับใบเสนอราคา ใบสั่งจอง ใบสั่งขาย |
| จำนวนยกเลิก | จำนวนที่ยกเลิกต่อบรรทัด | กด "ดึงรายการ" ก่อน |
| หมายเหตุ | เหตุผลการยกเลิก | |

## บันทึกแล้วระบบทำอะไรให้
- เอกสารเดิมยังอยู่ สถานะเปลี่ยนเป็น "ยกเลิกแล้ว" และใบยกเลิกถูกบันทึกเป็นเอกสารใหม่
- ใบที่ลงบัญชีไว้ (ใบขาย ใบลดหนี้ ใบเพิ่มหนี้ เงินมัดจำ เงินล่วงหน้า) ระบบกลับรายการบัญชีให้ตามวันที่ของใบยกเลิก
- ระบบคำนวณสต็อกและยอดค้างของลูกค้าใหม่ โดยไม่นับเอกสารที่ยกเลิก
- ยกเลิกใบขายที่หักมัดจำไว้ ยอดมัดจำกลับมาคงเหลือให้ใช้ได้อีก

## ยกเลิกผิด ต้องการคืน
- ยกเลิกทั้งใบ: เลือกเอกสาร แล้วกด "คืนสถานะเอกสารปกติ" ระบบขึ้น "คืนสถานะเอกสาร ... (ลบใบยกเลิก ...) เรียบร้อยแล้ว"
- ยกเลิกรายสินค้า: กด "คืนสถานะ" ที่บรรทัดของใบยกเลิกในกล่อง "ใบยกเลิกของเอกสารนี้"

## ยกเลิกไม่ได้เมื่อ
- มีเอกสารอื่นอ้างอิงอยู่ เช่น ใบขายที่มีใบลดหนี้/เพิ่มหนี้ ถูกวางบิล หรือรับชำระแล้ว → "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้" ต้องยกเลิกเอกสารปลายทางก่อน
- ใบสั่งที่ถูกดึงไปเปิดบิลครบแล้ว → "เอกสาร ... ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้" (ถ้ายังดึงไม่ครบ ยกเลิกส่วนที่ค้างได้)
- ยกเลิกไปแล้ว → "เอกสาร ... ถูกยกเลิกแล้ว"
- ดูวิธีแก้ทีละกรณีที่ [[ts-sale-cannot-cancel]]

## ปัญหาที่พบบ่อย
- "ยังไม่มีรายการยกเลิก: กด ดึงรายการ แล้วใส่จำนวนยกเลิก" → เลือกยกเลิกรายสินค้าแล้วยังไม่ได้ดึงรายการ
- "ใบนี้ไม่มีรายการคงเหลือให้ยกเลิก" → ทุกบรรทัดถูกใช้หรือยกเลิกไปหมดแล้ว
- "เลขที่เอกสาร ... ยาวเกิน 25 ตัวอักษร กรุณาแก้รูปแบบเลขที่เอกสาร" → ให้ผู้ดูแลแก้รูปแบบเลขที่ของใบยกเลิกให้สั้นลง
- ยกเลิกในงวดที่ปิดแล้ว → [[ts-common-period-closed]]
