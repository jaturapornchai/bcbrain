# ทำทะเบียนสินทรัพย์ (ข้อมูลสินทรัพย์) และแนบรูปภาพ

**ใช้เมื่อ:** ได้สินทรัพย์มาใหม่ หรือเริ่มใช้โปรแกรมและต้องยกทะเบียนสินทรัพย์เดิมเข้ามา
**เมนู:** ค่าเสื่อม › รายละเอียดสินทรัพย์ › ข้อมูลสินทรัพย์ / กำหนดรูปภาพและไฟล์แนบ
**ต้องมีก่อน:** ผังบัญชีสินทรัพย์ ค่าเสื่อมราคา ค่าเสื่อมราคาสะสม ([[howto-gl-overview]]) และประเภท/ที่ตั้งสินทรัพย์ ([[howto-asset-setup]])

## ขั้นตอน
1. เปิด ข้อมูลสินทรัพย์ กด "เพิ่มใหม่"
2. แท็บ "ทั่วไป": ใส่ "รหัส" "ชื่อ 1" เลือก "ประเภทสินทรัพย์" "ที่ตั้งสินทรัพย์" แผนก และเลือกผังบัญชีทั้ง 3 ช่อง
3. แท็บ "ได้มา": ใส่ "วันที่ซื้อเข้า" "ราคาซื้อเข้า" "ซื้อจาก" และเอกสารอ้างอิงซื้อ
4. แท็บ "ค่าเสื่อม": ใส่ "อายุการใช้งาน" (ปี) และ "วันที่เริ่มคิดค่าเสื่อม" ระบบเติม "อัตราค่าเสื่อม" และ "วันที่สิ้นสุดคิดค่าเสื่อม" ให้ แก้เองได้
5. ถ้าเป็นสินทรัพย์เดิมที่คิดค่าเสื่อมมาแล้ว ใส่ "มูลค่าคงเหลือยกมา" และ "ค่าเสื่อมสะสมยกมา"
6. แท็บ "ประกัน" และ "อื่น ๆ" กรอกตามต้องการ
7. กด "บันทึก"
8. แนบรูป: เปิด กำหนดรูปภาพและไฟล์แนบ เลือกสินทรัพย์จากรายการด้านซ้าย กด "แก้ไข" กดปุ่ม เลือกรูป แล้วกด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสผังบัญชี | บัญชีสินทรัพย์ (ราคาทุน) | บังคับกรอก |
| ผังบัญชีค่าเสื่อมราคา | บัญชีค่าใช้จ่ายค่าเสื่อม | บังคับกรอก |
| ผังบัญชีค่าเสื่อมราคาสะสม | บัญชีค่าเสื่อมสะสม | บังคับกรอก |
| ราคาซื้อเข้า | ราคาทุน | ใช้คิดค่าเสื่อมถ้าไม่ใส่ มูลค่าที่คิดค่าเสื่อม |
| มูลค่าที่คิดค่าเสื่อม | ฐานคิดค่าเสื่อม (ถ้าต่างจากราคาซื้อ) | |
| ราคาซาก | มูลค่าที่เหลือเมื่อหมดอายุ | ว่างหรือศูนย์ ระบบใส่ 1 ให้ ระบบหักราคาซากออกเสมอ แม้ไม่ได้ติ๊ก "คิดค่าซาก" |
| อายุการใช้งาน / วันที่เริ่มคิดค่าเสื่อม / วันที่สิ้นสุดคิดค่าเสื่อม | อายุเป็นปี วันเริ่ม และวันสิ้นสุด | ระบบคิดค่าเสื่อมตั้งแต่วันเริ่มถึงวันสิ้นสุด ถ้าแก้อายุ ให้ตรวจวันสิ้นสุดให้ตรงด้วย |
| วิธีคิดค่าเสื่อม | เส้นตรง / ลดน้อยถอยลง | ตอนคำนวณจริงระบบคิดแบบเส้นตรงเสมอ ไม่ว่าเลือกแบบไหน |
| อัตราค่าเสื่อม | ระบบเติมให้จากอายุ | ใช้ดูเท่านั้น ตัวเลขในช่องนี้ไม่ได้ใช้คำนวณ |
| หักค่าเสื่อมเบื้องต้น | | ยังไม่ถูกนำไปใช้คำนวณ |
| สถานะ | ปรกติ / ชำรุด / สูญหาย | เป็นข้อมูลแสดงผล |

## บันทึกแล้วระบบทำอะไรให้
- **ไม่ลงบัญชี** ทะเบียนเป็นข้อมูลสำหรับคิดค่าเสื่อม การซื้อต้องลงบัญชีแยก ([[faq-asset-buy-asset]])
- แท็บ "ขาย" และ "บำรุงรักษา" แสดงประวัติการขายและการซ่อมบำรุงของสินทรัพย์นี้
- ค่าเสื่อมคิดแบบเส้นตรงเสมอ ([[faq-asset-depreciation-method]])

## แก้ไข ยกเลิก พิมพ์
- แก้ได้ตลอด ถ้าลงค่าเสื่อมไปแล้ว ดู [[faq-asset-edit-after-posting]]
- ลบไม่ได้ถ้ามีเอกสารอ้างอิง ([[ts-asset-delete-blocked]])

## ปัญหาที่พบบ่อย
- "กรุณาระบุชื่อสินทรัพย์" "กรุณาระบุบัญชีสินทรัพย์" "กรุณาระบุบัญชีค่าเสื่อมราคา" "กรุณาระบุบัญชีค่าเสื่อมราคาสะสม" → กรอกชื่อและเลือกผังบัญชีทั้ง 3 ช่องในแท็บ "ทั่วไป"
- "วันที่สิ้นสุดคิดค่าเสื่อมต้องมากกว่าหรือเท่ากับวันที่เริ่มคิดค่าเสื่อมเท่านั้น" → แก้วันที่ในแท็บ "ค่าเสื่อม"
- "กรุณาบันทึก อายุการใช้งาน ก่อน แล้วโปรแกรมจะทำการคำนวณอัตราค่าเสื่อมให้โดยอัตโนมัติ" → ใส่อายุการใช้งานก่อน
- "มีรูปที่ยังไม่บันทึก กรุณาบันทึกหรือยกเลิกก่อนเปลี่ยนรายการ" → กด "บันทึก" ก่อนเลือกสินทรัพย์ตัวถัดไป
