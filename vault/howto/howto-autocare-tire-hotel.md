# รับฝากยางลูกค้า (Tire Hotel) และบันทึกตำแหน่งชั้นวาง

**ใช้เมื่อ:** ลูกค้านำยางชุดสำรองมาฝากเก็บที่ศูนย์
**เมนู:** AutoCare › 3. คลังสินค้า รับฝากยาง และงานเคลม › "บันทึกรับฝากยางลูกค้า (Tire Hotel) และเทิร์นยางเก่า" (ชื่อย่อ "รับฝากยาง Tire Hotel")

## ขั้นตอน
1. กด "เพิ่มใหม่" พิมพ์ทับค่าตัวอย่าง
2. กรอกช่องที่บังคับ: ทะเบียนรถลูกค้า, ชื่อลูกค้าผู้ฝากยาง, ยี่ห้อและรุ่นยางที่รับฝาก, ขนาดยาง และพิกัดจัดเก็บ (Zone / Rack / Bin) ช่องอื่นที่มีให้กรอก ได้แก่ รหัสลูกค้า, เบอร์โทรศัพท์, ยี่ห้อ / รุ่นรถยนต์, สัปดาห์ผลิต (DOT) และความลึกดอกยาง / สภาพยาง
3. กด "บันทึก" ระบบขึ้น "บันทึกข้อมูลเสร็จเรียบร้อย"
4. ถ้าฝากผิด เลือกรายการแล้วกด "ลบ" ได้

## ข้อควรรู้
- ใบรับฝากใหม่ ระบบออก "เลขที่ใบรับฝากยาง" ให้เองขึ้นต้นด้วย TH- เลขที่ที่พิมพ์เองจะไม่ถูกใช้ตอนเพิ่มใหม่
- ระบบบันทึกเป็นยาง 4 เส้น และตั้งวันครบกำหนดฝาก 180 วันนับจากวันที่ฝากให้อัตโนมัติ (ไม่มีช่องให้แก้บนจอ)

## ข้อจำกัด
- บันทึกรับฝากได้อย่างเดียว **ยังไม่มีปุ่มรับยางคืน** หรือคิดค่าฝาก ถ้าลูกค้ามารับ ให้แจ้งทีมงานเพื่อจัดการตามขั้นตอนของร้าน
- ไม่ลงบัญชีและไม่ตัดสต็อก ยางฝากเป็นของลูกค้า
