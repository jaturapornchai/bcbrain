# หักเงินมัดจำในใบขาย (แท็บใช้เงินมัดจำ)

**ใช้เมื่อ:** ลูกค้าเคยวางเงินมัดจำไว้ ([[howto-sale-deposit-receipt]]) แล้วตอนเปิดบิลขายต้องการหักยอดมัดจำออกจากบิล
**เมนู:** ขาย › ขายสินค้า/บริการ › แท็บ "ใช้เงินมัดจำ" (มีในหน้าจอ ลูกหนี้ › ตั้งหนี้อื่นๆ (ลูกหนี้) ด้วย)
**ต้องมีก่อน:** ใบรับเงินมัดจำ หรือรับเงินมัดจำยกมา ของลูกค้าคนเดียวกันที่ยังมียอดคงเหลือ

## ขั้นตอน
1. เปิดใบขายตามปกติ เลือก "ลูกหนี้/ลูกค้า" และคีย์สินค้าให้ครบ ([[howto-sale-invoice]])
2. ไปแท็บ "ใช้เงินมัดจำ" กดปุ่ม "ดึงเอกสารมัดจำ"
3. ระบบแสดงใบมัดจำของลูกค้าที่ยังมียอดคงเหลือ ในคอลัมน์ เลขที่เอกสาร / วันที่ / ยอดเงิน / คงเหลือ
4. ใส่ "ยอดตัด" ของแต่ละใบ (ตัดบางส่วนได้ ไม่เกินคงเหลือ)
5. ดู "รวมยอดตัดเงินมัดจำ:" ยอดนี้จะไปแสดงที่ช่อง "หักเงินมัดจำ" ด้านล่างของบิล
6. ถ้าขายสด รับเงินส่วนที่เหลือในแท็บ "การรับ/จ่ายชำระเงิน" แล้วกด "บันทึก"

บนจอมีคำอธิบายว่า "ดึงใบมัดจำของลูกหนี้ที่ยังมียอดคงเหลือ แล้วกรอกยอดตัด (ยอดหักมัดจำท้ายบิลคิดจากแท็บนี้)"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ยอดตัด | ยอดมัดจำที่จะหักในบิลนี้ | ต้องมากกว่า 0 และไม่เกิน "คงเหลือ" |
| หมายเหตุ | หมายเหตุต่อบรรทัด | ไม่บังคับ |
| หักเงินมัดจำ (ด้านล่าง) | ระบบคิดให้จากแท็บ | หักก่อนคิดภาษี |

## บันทึกแล้วระบบทำอะไรให้
- ยอดหักมัดจำถูกหักก่อนคำนวณ "ยอดเงินก่อนภาษี" และ "ยอดภาษีมูลค่าเพิ่ม" ของบิล
- ตัดยอดคงเหลือของใบมัดจำ ใบที่ตัดครบจะไม่ขึ้นให้ดึงอีก
- **ลงบัญชีอัตโนมัติ:** เดบิต เงินมัดจำรับ (ยอดที่หัก) คู่กับ เดบิต ลูกหนี้การค้า หรือเงินที่รับ ส่วนเครดิต ขายสินค้า เต็มมูลค่าก่อนหักมัดจำ และ ภาษีขาย ([[faq-sale-gl-posting]])
- ใบมัดจำที่ถูกหักแล้ว แก้/ลบไม่ได้จนกว่าจะยกเลิกใบขายนี้

## แก้ไข ยกเลิก พิมพ์
- แก้ยอดตัดได้ตอนแก้ไขใบขาย (ถ้าใบขายยังไม่ถูกล็อก) ([[howto-sale-edit-delete]])
- ยกเลิกใบขาย ยอดมัดจำจะกลับมาคงเหลือให้ใช้ใหม่ ([[howto-sale-cancel-docs]])

## ปัญหาที่พบบ่อย
- "กรุณาระบุรหัสลูกหนี้ก่อนดึงเอกสารมัดจำ" → เลือกลูกค้าในหัวบิลก่อน
- "ยอดมัดจำมากกว่ามูลค่าสุทธิ" → ยอดตัดเกินยอดบิล ([[ts-sale-deposit-over]])
- "ยอดตัดจ่ายมากกว่ายอดคงเหลือ: เอกสาร ... เกินอยู่ ..." → ([[ts-sale-deposit-over]])
- "เลือกเอกสารเงินมัดจำ ... ซ้ำ" → ใบเดียวกันอยู่สองบรรทัด ลบออกหนึ่งบรรทัด
- กดดึงแล้วไม่เจอใบที่ลูกค้าจ่ายมา → ถ้าเป็นใบ "รับเงินล่วงหน้า" จะไม่ขึ้นในแท็บนี้ ([[faq-sale-deposit-vs-advance]])
