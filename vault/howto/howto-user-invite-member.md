# เพิ่มพนักงานหรือผู้ใช้ใหม่ให้เข้าใช้ฐานข้อมูลบริษัท

**ใช้เมื่อ:** ต้องการให้พนักงาน ผู้ทำบัญชี หรือหุ้นส่วน เข้าใช้ข้อมูลบริษัทเดียวกัน หรือต้องการถอนสิทธิ์คนที่ลาออก
**เมนู:** หน้าเลือกฐานข้อมูล › การ์ดฐานข้อมูลของบริษัท › ปุ่ม "สมาชิก & สิทธิ์จอ" › แท็บ "เพิ่มอีเมลสมาชิก & ผูก Gmail กับ User"
**ต้องมีก่อน:**
- คุณเป็น Admin ของฐานข้อมูลนั้น (การ์ดมีป้าย "ทำได้ทุกอย่าง + จัดการสมาชิก/สิทธิ์จอ") ถ้าไม่ใช่ Admin จะไม่เห็นปุ่มนี้
- ผู้ที่จะเชิญมีบัญชี Google (อีเมล Gmail) เพราะการเข้าสู่ระบบใช้บัญชี Google

## ขั้นตอน
1. เข้าสู่ระบบ ไปที่หน้าเลือกฐานข้อมูล (ถ้าอยู่ในระบบแล้ว ให้ออกมาที่หน้าเลือกฐานข้อมูล ดู [[start-select-database]])
2. ที่การ์ดฐานข้อมูลของบริษัท กด "สมาชิก & สิทธิ์จอ"
3. แท็บแรก กรอก "อีเมลผู้ใช้งาน (Google / Gmail)"
4. เลือก "ระดับสิทธิ์ (Role)" เป็น "Member (สมาชิกตามสิทธิ์จอ)" หรือ "Admin (ทำได้ทุกอย่าง)"
5. กรอก "ผูกกับรหัสผู้ใช้ (BC User)" เช่น USER01 หรือ SALE01 (ถ้ายังไม่มีรหัสนี้ ระบบสร้างให้เอง)
6. กด "เพิ่ม/บันทึก" ระบบขึ้น "บันทึกสิทธิ์ของ ... เป็น ... เรียบร้อยแล้ว"
7. ถ้าเลือกเป็น Member ให้ไปกำหนดว่าเปิดหน้าจอไหนได้บ้าง ดู [[howto-user-screen-permission]]
8. แจ้งผู้ใช้ให้เข้าสู่ระบบด้วยบัญชี Google ของอีเมลนั้น ฐานข้อมูลบริษัทจะขึ้นในหน้าเลือกฐานข้อมูลของเขา

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| อีเมลผู้ใช้งาน (Google / Gmail) | อีเมลบัญชี Google ของผู้ใช้ | ต้องเป็นอีเมลที่เขาใช้เข้าสู่ระบบจริง |
| ระดับสิทธิ์ (Role) | Member หรือ Admin | Admin ทำได้ทุกอย่าง รวมถึงเพิ่มลบสมาชิก Member ใช้ได้เฉพาะจอที่ได้รับสิทธิ์ |
| ผูกกับรหัสผู้ใช้ (BC User) | รหัสผู้ใช้ในระบบ | สิทธิ์หน้าจอผูกกับรหัสนี้ ถ้าผูกหลายอีเมลกับรหัสเดียวกัน ทุกคนจะได้สิทธิ์เหมือนกัน |

## บันทึกแล้วระบบทำอะไรให้
- ผู้ใช้คนนั้นจะเห็นฐานข้อมูลนี้ในหน้าเลือกฐานข้อมูลของเขา
- รายชื่อสมาชิกแสดงในตาราง อีเมล (Gmail) / ระดับสิทธิ์ / รหัส User ที่ผูก / การจัดการ
- เอกสารที่ผู้ใช้บันทึก จะบันทึกชื่อผู้สร้างและผู้แก้ไขเป็นรหัสผู้ใช้ที่ผูกไว้ ดู [[howto-common-record-history]]

## แก้ไข ยกเลิก พิมพ์
- เปลี่ยนระดับสิทธิ์: เลือกในช่องระดับสิทธิ์ของแถวนั้นในตาราง ระบบขึ้น "อัปเดตสิทธิ์ของ ... เป็น ... เรียบร้อย"
- ถอนสิทธิ์คนที่ลาออก: กดปุ่ม "ลบสมาชิกออกจากฐานข้อมูลนี้" ที่แถวนั้น ระบบลบทันทีโดยไม่ถามยืนยันซ้ำ จึงควรตรวจอีเมลให้ถูกแถวก่อนกด
- การลบสมาชิกไม่ลบเอกสารที่คนนั้นเคยบันทึก

## ปัญหาที่พบบ่อย
- ขึ้น "กรุณากรอกอีเมล (Gmail) ของผู้ใช้งานให้ถูกต้อง" ให้ตรวจรูปแบบอีเมล
- ขึ้น "เฉพาะผู้ดูแลฐานข้อมูล (Admin) เท่านั้นที่สามารถเพิ่มหรือแก้ไขสมาชิกได้" แปลว่าคุณเป็น Member ให้ Admin ของบริษัททำให้ ดู [[ts-common-no-permission]]
- ผู้ใช้เข้าสู่ระบบแล้วไม่เห็นฐานข้อมูล ให้ตรวจว่าเขาเข้าสู่ระบบด้วยอีเมลเดียวกับที่เชิญไว้ ดู [[ts-common-cannot-login]]
- ควรมี Admin อย่างน้อย 2 คน และระวังอย่าลบหรือลดสิทธิ์ Admin คนสุดท้าย เพราะระบบไม่ได้กันไว้
