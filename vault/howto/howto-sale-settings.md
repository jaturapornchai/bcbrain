# ตั้งค่าระบบขาย

**ใช้เมื่อ:** เริ่มใช้ระบบขาย หรืออยากเปลี่ยนวิธีที่ระบบเตือน/ห้ามตอนออกเอกสารขาย
**เมนู:**
- เริ่มต้น › ตั้งค่าระบบขายและ POS (รหัสพื้นฐานของงานขาย)
- เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ › แท็บ "4.ระบบขาย"
**ต้องมีก่อน:** สิทธิ์ผู้ดูแลระบบ ([[ts-common-no-permission]]) ข้อเลือกมีผลกับทุกคนในบริษัท

## เมนู ตั้งค่าระบบขายและ POS
| เมนู | ใช้ทำอะไร |
|---|---|
| กำหนดเขตการขาย | ช่อง "เขตการขาย" ของลูกค้า ([[howto-ar-customer-register]]) |
| กำหนดรายได้อื่นๆ | "รหัสรายได้" ใน ตั้งหนี้อื่นๆ ([[howto-ar-other-debt]]) และตารางรายได้อื่นในแท็บรับชำระ ช่อง "รหัสผังบัญชี:" ใช้ลงบัญชีเมื่อใส่ในตารางรายได้อื่นของแท็บรับชำระ |
| กำหนดกลุ่มอนุมัติวงเงิน | เก็บผู้อนุมัติและช่วง "วงเงินอนุมัติจาก:" "วงเงินอนุมัติถึง:" ไว้อ้างอิง ยังไม่ได้ใช้ส่งขออนุมัติ |
| ออกแบบหน้าจอขาย POS / Download ระบบเสียงพูด | ส่วนของระบบขายหน้าร้าน [[sys-pos-overview]] |

## ข้อเลือกแท็บ "4.ระบบขาย" ที่ระบบใช้จริง
**ราคาและทุน**
- "เตือนเมื่อไม่พบราคาขาย" / "เตือนราคาขายกับประเภทภาษี" ([[ts-sale-price-not-found]])
- "เตือนเมื่อขายต่ำกว่าทุน" / "ห้ามขายสินค้าต่ำกว่าทุน" / "ห้ามขายสินค้าต่ำกว่าราคากลาง" ([[ts-sale-low-cost]])
- "ระบบเรียกราคาขายล่าสุด" (ไม่ใช้ระบบราคาขายล่าสุด / ราคาขายล่าสุด / ดึงราคาขายเฉลี่ย) และ "ดึงราคาขายแบบคำนวณส่วนลดทันที" ([[howto-sale-discount]])

**สต็อกและการจอง**
- "ห้ามขายสินค้าติดลบ" / "ห้ามขายสินค้าค้างส่งทั้งระบบ" / "ห้ามขายสินค้าค้างจองทั้งระบบ" / "ประเภทห้ามขายเกินค้างส่ง" / "ใช้ระบบจองตามที่เก็บสินค้า" ทำงานเมื่อเปิด "ห้ามเบิกสินค้าติดลบ" ในแท็บ "3.สินค้าคงคลัง" ด้วย ([[ts-sale-stock-negative]])
- "ใช้ระบบค้นหา LOT อัตโนมัติ"

**วงเงินเครดิต** ([[howto-sale-credit-limit]])
- "เตือนเกินวงเงินเครดิต" / "ห้ามขายเกินวงเงินเครดิต" / "ใช้ระบบรหัสผ่านอนุมัติวงเงินเครดิต" / "ใช้ระบบขออนุมัติวงเงินเครดิต"
- "วงเงินเครดิตรวมเช็คคงค้าง" / "วงเงินเครดิตรวมรายการมัดจำ" / "ตรวจสอบวงเงินรวมรายการสั่งขาย/สั่งจอง" / "สั่งจอง สั่งขาย เงินเชื่อตรวจสอบวงเงินลูกค้า"

**เอกสารและการอ้างอิง**
- "ประเภทการขาย (เริ่มต้น)" (ไม่เลือก / ขายเงินเชื่อ / ขายเงินสด) ค่าเริ่มต้นของบิลใหม่ ([[faq-sale-cash-vs-credit]])
- "แก้ไขใบเสนอราคาได้ตลอดเวลา" / "ใช้ระบบหมดอายุใบเสนอราคา" ([[howto-sale-quotation]])
- "เปิดใช้ระบบอ้างอิงใบสั่งขายที่อนุมัติแล้วเท่านั้น" / "เปิดใช้ระบบอ้างอิงใบสั่งจองที่อนุมัติแล้วเท่านั้น" / "ห้ามใส่จำนวนเกินเอกสารอ้างอิง" ([[howto-sale-pull-ref-doc]])
- "ปิดการตรวจสอบขายเกินกว่าจอง" ปิดการตรวจจำนวนเกินใบต้นทางตอนเปิดใบขาย ([[ts-sale-qty-over-ref]])
- "เตือนเลือกลูกค้าก่อนทำรายการ" (ไม่มีผลกับหน้าขายสินค้า/บริการ) / "ป้อนจำนวนขายเริ่มต้นอัตโนมัติ" / "ใส่วัน รับ/ส่ง สินค้าทุกครั้ง"
- "ใช้ระบบคำนวณวันครบกำหนดชำระบิล" ([[howto-ar-setup]])

## ข้อเลือกที่มีบนจอ แต่ระบบยังไม่ทำงาน
ติ๊กแล้วไม่มีผล อย่าแนะนำลูกค้าว่าใช้ได้:
- เรื่องเกินกำหนดชำระทั้งหมด: "เตือนเมื่อเกินกำหนดชำระ" "ห้ามขายเมื่อเกินกำหนดชำระ" "ตรวจสอบเกินกำหนดชำระ (สั่งจอง)" "ตรวจสอบเกินกำหนดชำระ (สั่งขาย)" "ไม่ตรวจสอบวันครบกำหนด ใบลดหนี้ (ขาย)" ([[faq-sale-overdue-check]])
- "ลดหนี้ต้องอ้างอิงเอกสารทุกครั้ง" "ส่งคืน,ลดหนี้ใช้แบบอ้างอิงเอกสารใบเดียว" "ใบสั่งขายอ้างอิงเสนอราคาเท่านั้น" "จอขายปิดอ้างอิงใบเสนอราคา"
- "ห้ามเปลี่ยนรหัสลูกค้า" "ใช้ระบบรหัสผ่านแก้ไขส่วนลด" "พิมพ์ใบเสร็จครั้งเดียว" "ปิดสถานะเครดิตลูกหนี้อัตโนมัติ"
- "วิธีอนุมัติวงเงิน" "หมายเลขโทรศัพท์ขออนุมัติวงเงิน" "ผู้อนุมัติ Sale Hub"
- "กำหนดเลขที่เอกสารขายใหม่เมื่อเลขที่ซ้ำ" "ใบกำกับภาษีขายให้ตรงกับเลขที่เอกสาร" "เปลี่ยนหน่วยนับอัตโนมัติ (จอขาย)"
- "ดึงรายการมัดจำคงค้าง" "ดึงต้นทุนปัจจุบัน กรณีรับคืนสินค้าไม่อ้างบิล" "ไม่แสดงตารางราคาตามสูตร" "เปิดเลือกราคาขายตามสูตร" "ไม่แสดงราคาสินค้าชุด" "อนุมัติใบสั่งซื้อก่อนพิมพ์" "ใช้ระบบแจ้งเตือนการมัดจำหน้าตั้งหนี้จากการรับสินค้า"
- "ตรวจสอบสถานะการพิมพ์ใบสั่งจอง" "ตรวจสอบการป้อนเขตขนส่งกรณีส่งให้" "แสดงจำนวนสินค้าพร้อมขาย ใบสั่งขาย"
- ข้อเลือกที่เกี่ยวกับหน้าร้าน เช่น "ใช้ระบบคูปองรับคืนสินค้า" "เปิดลิ้นชักเก็บเงินหลังทำการขาย" "เปิดใช้งาน barcode ลดราคา" "เปิดช่องบันทึกยอดชาร์จบัตรเครดิต" "ใช้ระบบ running เอกสารเงินมัดจำจาก POS" "พิมพ์สรุปยอดใบส่งเงิน" "ใช้ระบบรอบการขาย" สอบถามทีมงานก่อนแนะนำ ([[sys-pos-overview]])

## บันทึกแล้วระบบทำอะไรให้
- ระบบตรวจตามข้อเลือกตอนกดบันทึกเอกสาร เอกสารที่บันทึกไว้ก่อนแล้วไม่ถูกตรวจย้อนหลัง

## ปัญหาที่พบบ่อย
- ติ๊กข้อเลือกแล้วระบบไม่เตือน → ตรวจว่าอยู่ในรายการ "ยังไม่ทำงาน" ด้านบนหรือไม่
- ลูกค้าถามเรื่องราคา แพ็กเกจ หรือการเปิดใช้ระบบหน้าร้าน → สอบถามฝ่ายขาย
