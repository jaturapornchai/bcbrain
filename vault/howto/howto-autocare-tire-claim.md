# วิธีคุมคลังยาง DOT รับของปิดต้นทุน ฝากยางโรงแรม และเคลมรับประกัน

คู่มือจัดการสต็อกเฉพาะทางใน **[[sys-autocare-garage]]** สำหรับร้านยางและศูนย์บริการที่ต้องการคุมคุณภาพยาง ป้องกันข้อมูลต้นทุนรั่ว และดูแลงานฝาก-งานเคลมครบวงจร

## 1. การค้นหายางและคุมสัปดาห์ผลิต (DOT / FEFO)
- **ค้นหาขนาดยางทันใจ**: ในช่องค้นหาสต็อกยาง พิมพ์ตัวเลขขนาดยางติดกันโดยไม่ต้องใส่เครื่องหมาย เช่น พิมพ์ 2055516 เพื่อหาขนาด 205/55R16 ได้ทันที
- **เรียงล็อตตามสัปดาห์ผลิต (DOT) และเบิกของเก่าก่อน (FEFO)**: เมื่อรับยางเข้าหรือขายออก ให้ระบุรหัส DOT (4 หลัก สัปดาห์และปีที่ผลิต) ระบบจะเตือนรายการยางที่ผลิตนานแล้วเพื่อให้ทีมหน้าลานหยิบล็อตเก่าออกไปติดตั้งก่อนเสมอ
- ตรวจสอบอายุยางคงคลังทั้งหมดได้ในรายงานอายุยาง DOT/FEFO ที่ [[rpt-autocare]]

## 2. การรับของเข้าคลังแบบปิดราคาทุน 100% (Blind Receiving)
1. เปิดเมนู **รับของเข้าคลังหน้าลาน** เมื่อมีรถส่งอะไหล่หรือยางมาส่งที่ศูนย์
2. พนักงานหน้าลานตรวจนับจำนวนชิ้น ยี่ห้อ ขนาด และรหัส DOT ที่มาส่งจริง **หน้าจอนี้จะซ่อนช่องราคาทุนซื้อทั้งหมด 100%**
3. เมื่อกดยืนยันรับของ สต็อกจะเพิ่มขึ้นพร้อมใช้งานซ่อมทันที และระบบจะสร้างเอกสารรับสินค้าส่งต่อไปให้ฝ่ายบัญชีเปิดใส่ราคาทุนและตั้งหนี้เจ้าหนี้ใน [[sys-account-overview]] ต่อไป

## 3. บริการโรงแรมฝากยาง (Tire Hotel)
1. เมื่อลูกค้าเปลี่ยนชุดยางฤดูกาล ล้อแม็กแต่ง หรือฝากยางสำรอง ให้เปิดเมนู **โรงแรมฝากยาง**
2. บันทึกรหัสลูกค้า ทะเบียนรถ ยี่ห้อ/ขนาดยาง ดอกยางคงเหลือ และระบุตำแหน่งเก็บชัดเจน (โซน / แร็ค / ชั้น / ลึก)
3. เมื่อลูกค้ากลับมาเปลี่ยนสลับยาง ค้นหาจากทะเบียนรถเพื่อไปเบิกจากตำแหน่งเก็บเดิมได้ทันที

## 4. ระบบเคลมรับประกันโรงงาน และคูปองดูแลรถ
- **เปิดใบเคลมโรงงาน**: กรณียางบวม แตก หรืออะไหล่มีปัญหาในระยะประกัน เปิดบันทึกใบเคลมอ้างอิงทะเบียนรถ ใบงานเดิม และรหัสยาง เพื่อติดตามผลเคลมกับผู้ผลิตจนกว่าจะปิดเคส
- **คูปองดูแลรถ**: ออกและตัดสิทธิ์คูปองบริการ (เช่น สลับยาง-ถ่วงล้อฟรี หรือส่วนลดเช็กระยะ) ตอนปิดบิลที่หน้าจอบริการ
