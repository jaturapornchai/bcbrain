# บันทึกข้อมูลรายวัน (ลงบัญชีด้วยมือ ใบสำคัญทั่วไป)

**ใช้เมื่อ:** ต้องลงบัญชีรายการที่ไม่ได้เกิดจากเอกสารซื้อขาย เช่น ปรับปรุงค่าใช้จ่ายค้างจ่าย ค่าเสื่อมราคา ยอดยกมา แก้ไขรายการบัญชี (ใบสำคัญ = เอกสารลงบัญชี 1 ชุด ที่มีเดบิตและเครดิตเท่ากัน)
**เมนู:** บัญชี › ข้อมูลรายวัน หรือ บัญชี › บันทึกข้อมูลรายวันแบบเร็ว (สองเมนูเปิดหน้าจอแบบเดียวกัน)
**ต้องมีก่อน:** ผังบัญชี ([[howto-gl-chart-of-accounts]]), สมุดบัญชี ([[howto-gl-setup-book-group]]), งวดบัญชีที่เปิดอยู่ ([[howto-gl-account-period]])

## ขั้นตอน
1. เปิดเมนู ข้อมูลรายวัน กดเพิ่มเอกสารใหม่
2. กรอกเลขที่เอกสาร วันที่เอกสาร
3. ช่อง สมุดรายวัน เลือกสมุดที่จะลง (ถ้าไม่เลือก ระบบใช้สมุด JV) ช่อง คำอธิบาย ใส่เรื่องของรายการ
4. แท็บ "การลงบัญชี (GL)" กรอกทีละบรรทัด: รหัสบัญชี, คำอธิบายรายการ, เดบิต (Dr) หรือ เครดิต (Cr) (เดบิต/เครดิต = ฝั่งซ้าย/ขวาของการลงบัญชีคู่ ยอดรวมสองฝั่งต้องเท่ากัน)
5. ดูแถบสถานะใต้ตาราง ต้องขึ้น "✓ ดุลบัญชีถูกต้อง (Dr = Cr)" ก่อนบันทึก
6. ถ้ามีภาษีซื้อ ภาษีขาย หรือหัก ณ ที่จ่าย ในรายการนี้ ไปกรอกที่แท็บ ข้อมูลภาษี (VAT/WHT) ([[howto-tax-journal-tax-tabs]])
7. กดบันทึก ระบบถาม "บันทึกเอกสารเลขที่ ... ลงฐานข้อมูลเรียบร้อยแล้ว ต้องการพิมพ์แบบฟอร์มเอกสารเลยหรือไม่?"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เลขที่เอกสาร | เลขใบสำคัญ | บังคับ ยาวไม่เกิน 25 ตัวอักษร ห้ามซ้ำ |
| วันที่เอกสาร | วันที่ลงบัญชี | ต้องอยู่ในงวดที่เปิด |
| สมุดรายวัน | สมุดบัญชี | ว่างได้ ระบบใช้ JV |
| รหัสบัญชี | บัญชีย่อยในผังบัญชี | แถวที่ไม่มีรหัสบัญชีระบบข้ามไป ไม่บันทึก |
| เดบิต (Dr) / เครดิต (Cr) | จำนวนเงิน | ควรใส่ฝั่งเดียวต่อบรรทัด (ระบบไม่ได้กันถ้าใส่ทั้งสองฝั่ง) |
| มิติ | - | ช่องนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ค่าที่กรอกไม่ถูกบันทึก ([[howto-gl-dimensions]]) |

## บันทึกแล้วระบบทำอะไรให้
- บันทึกเป็นใบสำคัญในบัญชีแยกประเภท ใช้ในงบทดลอง บัญชีแยกประเภท และงบการเงินทันที (ไม่ต้องผ่านรายการก่อน [[faq-gl-pass-journal-needed]])
- ประเภทรายวันของใบที่บันทึกจากหน้าจอนี้เป็น "0: ทั่วไป" เสมอ เลือกเป็นประเภทอื่นไม่ได้
- ตอนบันทึก ระบบตรวจแค่เลขที่ วันที่ งวดบัญชี และยอดเดบิตเท่ากับเครดิต ยังไม่ตรวจว่ารหัสบัญชีมีในผังหรือเป็นบัญชีย่อย
- ถ้ากรอกภาษีในแท็บภาษี รายการภาษีจะไปขึ้นในรายงานภาษีซื้อ/ขาย หรือรายงานหัก ณ ที่จ่าย ด้วย

## แก้ไข ยกเลิก พิมพ์
- รายการด้านซ้ายแสดงใบสำคัญล่าสุด 150 ใบ ค้นด้วยเลขที่หรือคำอธิบายได้ (รายการที่ระบบลงบัญชีอัตโนมัติจากเอกสารอื่นก็ขึ้นในรายการนี้ด้วย [[faq-gl-edit-auto-journal]])
- แก้ไข: เปิดเอกสาร กดแก้ไข แล้วบันทึกซ้ำ ระบบเขียนทับทั้งใบ
- ลบ: ลบทั้งใบพร้อมข้อมูลภาษีที่กรอกไว้ในใบนั้น (งวดต้องยังเปิดอยู่)
- พิมพ์: ปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ" ([[rpt-print-export]])
- อยากใช้รายการซ้ำทุกเดือน หรือกลับรายการต้นเดือนถัดไป ดู [[howto-gl-journal-template-reverse]]
