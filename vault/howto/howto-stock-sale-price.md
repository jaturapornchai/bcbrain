# ตั้งราคาขายและส่วนลดสินค้า (ทั่วไป กลุ่มลูกค้า รายลูกค้า)

**ใช้เมื่อ:** อยากให้บิลขายดึงราคาและส่วนลดขึ้นมาเอง ต่างกันตามลูกค้า กลุ่มลูกค้า จำนวนที่ซื้อ หรือช่วงเวลา
**เมนู:** สินค้า › กำหนดราคาขายมาตรฐาน / กำหนดราคาขายทั่วไป / กำหนดส่วนลดสินค้า / ราคาขายสินค้า
**ต้องมีก่อน:** สินค้าและหน่วยนับ ([[howto-stock-units]]) ลูกค้าและกลุ่มลูกค้า ([[howto-ar-overview]])

## ขั้นตอน
1. เปิด กำหนดราคาขายทั่วไป (หรือ กำหนดราคาขายมาตรฐาน) แล้วเลือกสินค้า
2. เลือกแท็บ: ราคาขายทั่วไป (ทุกลูกค้า) / ราคาขายตามกลุ่มลูกค้า / ราคาขายตามลูกค้า
3. เพิ่มแถวราคา ใส่หน่วยนับ ราคาแยกภาษี ราคารวมภาษี ช่วงจำนวน ช่วงวันที่ และประเภทการขาย แล้วบันทึก
4. ส่วนลดตั้งที่ กำหนดส่วนลดสินค้า แบบเดียวกัน (ทั่วไป / ตามกลุ่มลูกค้า / ตามลูกค้า)
5. ดูราคาทุกแบบของสินค้ารวมในจอเดียวได้ที่ ราคาขายสินค้า

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| หน่วยนับ | หน่วยที่ราคานี้ใช้ | ราคาแยกตามหน่วย ต้องตั้งทุกหน่วยที่ขาย |
| ราคาแยกภาษี / ราคารวมภาษี | ราคาขาย | บิลภาษีแยกนอกใช้ราคาแยกภาษี บิลแบบอื่นใช้ราคารวมภาษี |
| จากจำนวน / ถึงจำนวน | ช่วงจำนวนที่ซื้อ | ทำราคาขั้นบันไดได้ |
| จากวันที่ / ถึงวันที่ | ช่วงเวลาที่ราคานี้ใช้ | เทียบกับวันที่ของบิล |
| ประเภทการขาย | ไม่เลือก / ขายเงินสด / ขายเงินเชื่อ | ไม่เลือก = ใช้ได้ทั้งสองแบบ |
| ปุ่ม ลบ | ล้างราคาของสินค้านี้ในเมนูที่เปิดอยู่ ทั้ง 3 แท็บ | ระบบถาม "ล้างราคาของสินค้านี้: ... ใช่หรือไม่?" ก่อน ระวัง ลบทั้งชุด |

## บันทึกแล้วระบบทำอะไรให้
- ตอนเลือกสินค้าในบิลขาย ระบบหาราคาตามลำดับ: ราคาตามลูกค้า → ราคาตามกลุ่มลูกค้า → ราคาขายทั่วไป → ราคาขายมาตรฐาน → สูตรราคาขาย → ราคาตามบาร์โค้ด ([[faq-stock-which-price]])
- แถวราคาต้องตรงทั้งหน่วยนับ วันที่ จำนวน และประเภทการขาย จึงจะถูกเลือก
- แถวที่ราคาแยกภาษีและราคารวมภาษีเป็น 0 ทั้งคู่ ระบบไม่บันทึกแถวนั้น
- ถ้าไม่เจอราคาเลย และเปิดตัวเลือก "ระบบเรียกราคาขายล่าสุด" ไว้ ระบบใช้ ราคาขายล่าสุด หรือ ราคาขายเฉลี่ย ที่เคยขายให้ลูกค้ารายนั้น
- ส่วนลดหาแยก: ตามลูกค้า → ตามกลุ่มลูกค้า → ส่วนลดทั่วไป

## แก้ไข ยกเลิก พิมพ์
- แก้ราคาแล้วมีผลกับบิลที่เลือกสินค้าหลังจากนั้น บิลเดิมไม่เปลี่ยน
- ปรับราคาจำนวนมากพร้อมกันจากไฟล์ ใช้ ปรับราคาสินค้า ([[howto-stock-modify-price]])
- **ข้อควรรู้:** ช่อง ไม่ใช้งาน ในตารางราคา ตอนนี้ระบบหาราคายังไม่ได้ข้ามแถวที่ติ๊กไว้ ถ้าจะเลิกใช้ราคาไหน ให้ลบแถวนั้นหรือแก้ช่วงวันที่ให้หมดอายุแทน

## ปัญหาที่พบบ่อย
- ราคาไม่ขึ้นในบิล → ตรวจหน่วยนับ ช่วงวันที่ ช่วงจำนวน และประเภทการขายของแถวราคา
- "ห้ามขายต่ำกว่าราคากลาง ..." → เปิดตัวเลือก ห้ามขายสินค้าต่ำกว่าราคากลาง ไว้ และราคาที่ขายต่ำกว่าราคากลางในสูตรราคาขาย ([[howto-stock-price-formula]])
