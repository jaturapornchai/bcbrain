# ร่างเอกสารขายด้วยการพิมพ์สั่งในแชท

**ใช้เมื่อ:** อยากลองร่างใบเสนอราคา/ใบวางบิล/ใบกำกับภาษีให้ลูกค้าอย่างเร็วจากแชท
**เมนู:** แชท LINE OA › ห้องแชทของลูกค้า › ช่องพิมพ์ข้อความ (หรือหน้าต่าง LINE MINI App แท็บ "② แก้ไขเอกสารขาย & ส่งเข้าแชท")
**ต้องมีก่อน:** เลือกลูกค้าทางซ้ายแล้ว — ภาพรวม [[sys-lineoa-overview]]

**สำคัญ:** เอกสารที่ได้เป็น **ร่างบนหน้าจอ** ไม่ใช่เอกสารขายจริงในบัญชี ไม่ตัดสต็อก ไม่ลงบัญชี และหายเมื่อปิดหรือรีเฟรชหน้า

## ขั้นตอน
1. เลือกลูกค้า แล้วพิมพ์สั่ง เช่น "ออกใบเสนอราคา ... รายการ ... 25,000 บาท"
2. ระบบสร้างเอกสารร่างพร้อมเลขที่เอกสารชั่วคราว และคิดยอดให้
3. พิมพ์สั่งแก้ต่อได้เรื่อยๆ เช่น เพิ่มรายการ, "ลดราคา ... บาท", เปลี่ยนเป็นใบวางบิล/ใบกำกับภาษี
4. กดปุ่ม "🖨️ ใบจริงพื้นขาว A4" เพื่อเปิดดู/พิมพ์
5. หรือเปิด "📱 เปิด LINE MINI App" แท็บ ② เลือกชนิดเอกสารด้วยปุ่ม และเพิ่มรายการด่วน (ชื่อ จำนวน ราคา/หน่วย)

## ช่องสำคัญที่ต้องกรอก (คำที่ระบบเข้าใจ)
| พิมพ์ว่า | ได้เอกสาร | หมายเหตุ |
|---|---|---|
| ออกใบเสนอราคา / ทำใบเสนอราคา / เปิดบิลใหม่ พร้อมรายการและราคา | ใบเสนอราคา | ล้างส่วนลดเป็น 0 และเริ่มรายการใหม่ |
| เพิ่มรายการ ... / เพิ่มค่า ... | เพิ่มบรรทัดสินค้า | |
| ใบแจ้งหนี้ / ใบวางบิล | ใบวางบิล | |
| ใบเสร็จ / ใบกำกับภาษี / โอนเงินแล้ว / ชำระแล้ว | ใบกำกับภาษี | |
| นักท่องเที่ยว / ขอคืนภาษี / passport / ภ.พ.10 / vrt | เอกสารสำหรับนักท่องเที่ยว | ถ้าหาเลขพาสปอร์ตในข้อความไม่เจอ ระบบใส่เลขตัวอย่างให้เอง ต้องแก้เอง |
| ลดราคา / ส่วนลด (ระบุเป็น % หรือ บาท) | ใส่ส่วนลด | ถ้าอ่านตัวเลขไม่ออก ระบบใส่ส่วนลดตัวอย่าง 1,500 บาทให้เอง ควรตรวจ |

## บันทึกแล้วระบบทำอะไรให้
ไม่มีการบันทึก เป็นร่างบนจอ ยอดคิดแบบ: ยอดรวมรายการ − ส่วนลด = ฐานภาษี แล้วบวกภาษีมูลค่าเพิ่มอัตราเดียวคงที่ให้อัตโนมัติ (ไม่มีให้เลือกอัตราอื่นหรือยกเว้นภาษี) ได้ยอดสุทธิ ปัดเศษ 2 ตำแหน่ง ตรวจตัวเลขทุกครั้งก่อนส่งลูกค้า เรื่องคืนภาษีนักท่องเที่ยวและข้อกฎหมายให้ปรึกษาผู้สอบบัญชี/สรรพากร

## แก้ไข ยกเลิก พิมพ์
พิมพ์สั่งแก้ในแชทได้ต่อเนื่อง พิมพ์ผ่านปุ่ม "🖨️ ใบจริงพื้นขาว A4"

## ข้อจำกัด
- ร่างอยู่ในหน้าจอเท่านั้น เอกสารจริงให้ออกจากเมนูขาย ดู [[howto-sale-overview]]
- ไม่ได้ส่งถึง LINE ลูกค้าจริง ดู [[faq-lineoa-connect-real-line]]
- ชื่อร้าน เลขประจำตัวผู้เสียภาษี รหัสสาขา เบอร์โทร ที่กรอกในหน้าต่างตั้งค่าหัวบิล ยังไม่ถูกบันทึกถาวร
