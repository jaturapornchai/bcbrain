# ย้ายสินค้าไปช่องชั้นวางอื่นในคลัง

**ใช้เมื่อ:** ย้ายของจากชั้นหนึ่งไปอีกชั้น เช่น จัดโซนใหม่ ย้ายของขายดีมาใกล้จุดแพ็ค
**เมนู:** ระบบ คลัง WMS › แท็บ "4. รับเข้า · ย้ายช่อง · ตรวจนับ" › ปุ่ม "ขนย้ายช่อง Bin" หรือแท็บ "3. แผนผังโซน & ชั้นวาง (Bin Map)" › กด "ย้ายช่อง Bin" ที่ช่องนั้น (ระบบพามาหน้าฟอร์มพร้อมใส่ช่องต้นทางให้)
**ต้องมีก่อน:** สินค้ามีอยู่ในรายการสต็อกของ WMS

## ขั้นตอน
1. เลือก "ขนย้ายช่อง Bin"
2. เลือกสินค้า
3. ใส่ช่องต้นทางในช่อง "จากพิกัด (From Bin)" และช่องปลายทางในช่อง "ไปยังพิกัดชั้นวาง (To Bin)"
4. ใส่จำนวนที่ย้ายในช่อง "จำนวนหน่วย" (ช่องนี้มีเลข 50 ใส่ไว้ให้ก่อน ต้องแก้เป็นจำนวนที่ย้ายจริง ถ้าลบจนว่าง ระบบจะใช้ 50)
5. ใส่ "เจ้าหน้าที่คลังผู้ปฏิบัติงาน" (มีชื่อตัวอย่างใส่ไว้ให้ ต้องแก้เป็นชื่อจริง) หมายเหตุ แนบรูป (ดู [[howto-wms-evidence-photos]]) แล้วกดปุ่มบันทึกปฏิบัติการคลังที่ท้ายฟอร์ม

## ข้อควรรู้
- ชื่อช่องปลายทางที่ขึ้นต้นด้วยตัว B, C หรือ D ระบบจัดเข้าโซน B, C, D ตามลำดับ ช่องที่ขึ้นต้นอย่างอื่นจัดเข้าโซน A
- ถ้าจำนวนเป็น 0 ระบบถือว่าย้ายทั้งหมดที่มีในช่องต้นทาง
- ระบบไม่ได้เช็กว่าจำนวนที่ย้ายเกินยอดในช่องต้นทางหรือไม่ ถ้าใส่เกิน ยอดช่องต้นทางจะติดลบ ให้ตรวจยอดก่อนกดบันทึก
- หลังบันทึก จอแสดงข้อความสำเร็จเสมอ แม้ระบบบันทึกไม่สำเร็จ ให้เปิดประวัติเช็กว่ามีรายการจริง ถ้าไม่มีให้ส่งต่อเจ้าหน้าที่
- ถ้าช่องปลายทางยังไม่เคยมีสินค้านี้ ระบบเปิดช่องใหม่ให้
- ยอดช่องต้นทางลดลงตามที่ย้าย ยอดแต่ละช่องคำนวณใหม่จากประวัติการเคลื่อนไหว ตรวจย้อนได้ในตารางประวัติ
- เป็นการเปลี่ยนเฉพาะในคลัง WMS ไม่กระทบสต็อกบัญชี
