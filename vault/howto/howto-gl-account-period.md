# กำหนดงวดบัญชี เปิดงวด ปิดงวด (ล็อกงวด)

**ใช้เมื่อ:** เริ่มใช้ระบบ ขึ้นปีบัญชีใหม่ หรือต้องการล็อกเดือนที่ปิดบัญชีแล้วไม่ให้ใครแก้เอกสาร (งวดบัญชี = ช่วงเวลาของบัญชี ปกติคือรายเดือน)
**เมนู:** เริ่มต้น › ตั้งค่าระบบบัญชีและภาษี › กำหนดงวดบัญชี (หรือ บัญชี › ผังบัญชี (Chart of Accounts) › กำหนดงวดบัญชี)
**ต้องมีก่อน:** สิทธิ์ผู้ดูแลระบบ (เจ้าของหรือผู้ดูแล) เท่านั้น

## ขั้นตอน
1. เปิดเมนู กำหนดงวดบัญชี
2. ถ้ายังไม่มีงวดเลย (เริ่มใช้ครั้งแรก) กดปุ่ม "คำนวณงวดบัญชีอัตโนมัติ (12 งวด)" ระบบเติมงวดรายเดือนของปีปัจจุบัน (ตามปีปฏิทิน ปีเป็น ค.ศ.) ให้ 12 งวด
   - **ระวัง:** ปุ่มนี้แทนที่ทุกแถวในตาราง (ขึ้นถาม "ต้องการดึงข้อมูลใหม่มาแทนของเดิมหรือไม่") ถ้ากดตอนที่มีงวดของปีเก่าอยู่แล้วแล้วบันทึก งวดของปีเก่าจะหายทั้งหมด เอกสารของปีเก่าจะบันทึก แก้ ลบไม่ได้
3. ตรวจในตารางงวดบัญชีว่าวันเริ่มต้น-วันสิ้นสุดของแต่ละงวดถูกต้อง แก้ได้ถ้ารอบบัญชีไม่ตรงกับปีปฏิทิน
4. **ปิดงวด (ล็อก):** ที่งวดที่ต้องการ เปลี่ยน สถานะงวดบัญชี เป็น ปิดงวดบัญชี (Closed) แล้วบันทึก
5. **เปิดงวดกลับ:** เปลี่ยนสถานะกลับเป็น เปิดใช้งาน (Open) แล้วบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| งวดที่ | ลำดับงวด | |
| วันที่เริ่มต้นงวด / วันที่สิ้นสุดงวด | ช่วงวันของงวด | ห้ามเว้นช่วง ไม่งั้นวันที่ตกช่องจะบันทึกเอกสารไม่ได้ |
| ปีบัญชี (พ.ศ./ค.ศ.) | ปีของงวด | |
| สถานะงวดบัญชี | เปิดใช้งาน (Open) / ปิดงวดบัญชี (Closed) | ตัวนี้คือการล็อกงวดจริง |

## บันทึกแล้วระบบทำอะไรให้
- ทุกครั้งที่บันทึก ระบบเก็บตารางงวดทั้งตารางตามที่เห็นบนจอ แถวที่ลบออกจากตารางจะหายไป
- งวดที่ปิดแล้ว ระบบไม่ให้บันทึก แก้ไข ลบ หรือยกเลิกเอกสารที่วันที่อยู่ในงวดนั้น ทั้งเอกสารซื้อ ขาย สต็อก รับ/จ่ายชำระหนี้ และข้อมูลรายวัน
- ที่ไม่ถูกกัน: ประมวลผลสิ้นงวด/สิ้นปี และการบันทึกค่าเสื่อมราคา ยังสร้างใบสำคัญลงวันที่ในงวดที่ปิดได้
- ถ้าวันที่เอกสารไม่อยู่ในงวดใดเลย ก็บันทึกไม่ได้เช่นกัน
- ข้อความที่ขึ้น: "วันที่เอกสาร ... ได้ถูกปิดงวดไปแล้ว หรือยังไม่ได้กำหนดงวดบัญชี กรุณาตรวจสอบ" ([[ts-common-period-closed]])

## แก้ไข ยกเลิก พิมพ์
- ต้องการแก้เอกสารเก่าในงวดที่ปิด: ผู้ดูแลเปิดงวดกลับเป็น Open ชั่วคราว แก้เสร็จแล้วปิดกลับ
- เมนู ประมวลผลสิ้นงวด ไม่ได้ล็อกงวดให้ ต้องมาเปลี่ยนสถานะที่หน้านี้เอง ([[faq-gl-close-vs-lock-period]])

## ปัญหาที่พบบ่อย
- ขึ้นปีใหม่แล้วบันทึกเอกสารไม่ได้เลย → ยังไม่ได้สร้างงวดของปีใหม่ ให้เพิ่มแถวงวดของปีใหม่ต่อท้ายตารางเอง (งวดที่ วันเริ่มต้น วันสิ้นสุด ปีบัญชี) แล้วบันทึก อย่ากดปุ่มคำนวณงวดอัตโนมัติ เพราะจะลบงวดของปีเก่า
- เผลอกดคำนวณอัตโนมัติแล้วบันทึกไปแล้ว งวดปีเก่าหาย → ต้องเพิ่มแถวงวดของปีเก่ากลับเข้าไปเอง ถ้าไม่แน่ใจวันที่เดิม ส่งต่อเจ้าหน้าที่
- พนักงานไม่เห็นเมนูนี้ → เป็นเมนูสำหรับผู้ดูแลเท่านั้น ([[ts-common-no-permission]])
