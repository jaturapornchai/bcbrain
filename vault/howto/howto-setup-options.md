# กำหนดข้อเลือกพิเศษต่างๆ

**ใช้เมื่อ:** ต้องการเปลี่ยนวิธีทำงานของโปรแกรมทั้งระบบ เช่น แสดงปีเป็น พ.ศ. จำนวนทศนิยม ห้ามสินค้าติดลบ หรือประเภทภาษีเริ่มต้น
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin เท่านั้น · ควรให้ผู้ดูแลระบบหรือผู้สอบบัญชีตัดสินใจก่อนเปลี่ยน เพราะกระทบทุกเอกสาร · เริ่มต้นดู [[start-first-day]]

หน้านี้เป็นหน้าเดียวยาว แบ่งเป็นหมวด มีแถบ "ข้ามไปยังส่วน:" ด้านบนให้กดกระโดดไปหมวดที่ต้องการ

## ขั้นตอน
1. เปิดเมนู "กำหนดข้อเลือกพิเศษต่างๆ"
2. ส่วนบนสุดคือ "เลือกประเภทธุรกิจ" ติ๊กประเภทที่ตรงกับกิจการ ("ธุรกิจทั่วไป" เปิดอยู่เสมอ) มีปุ่ม "ตั้งค่าข้อเลือกแนะนำอัตโนมัติ" ให้ระบบตั้งค่าเริ่มต้นตามประเภทธุรกิจ และปุ่ม "ซ่อนช่องเฉพาะทางทั้งหมด (เหลือธุรกิจทั่วไป)"
3. เลื่อนไปหมวดที่ต้องการ แล้วติ๊กหรือเลือกค่า
4. กดบันทึก ระบบแจ้ง "บันทึกข้อมูลเสร็จเรียบร้อย โปรแกรมจะปิดหน้าจอนี้ให้"

## ช่องสำคัญที่ต้องกรอก
หมวดที่ไม่มีในรุ่นที่ใช้อยู่จะถูกซ่อน เช่น หมวดบัญชีแยกประเภทจะไม่ขึ้นถ้ารุ่นไม่มีบัญชี

| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทปี | คริสต์ศักราช หรือ พุทธศักราช | บันทึกแล้วหน้าจอเปลี่ยนการแสดงปีทันที ดู [[start-buddhist-year-dates]] |
| ประเภทภาษีมูลค่าเพิ่ม (ขาย) / (ซื้อ) | แยกนอก, รวมใน หรือ ภาษีศูนย์ | เป็นค่าเริ่มต้นของเอกสารขาย/ซื้อ อัตราภาษีให้ปรึกษาผู้สอบบัญชีหรือสรรพากร |
| จุดทศนิยม (บัญชี) | 0 ถึง 6 ตำแหน่ง | |
| จุดทศนิยม (จำนวนสินค้า) / (ราคาสินค้า) / (มูลค่าสินค้า) | 0 ถึง 6 ตำแหน่งแต่ละช่อง | แยกกันตามชนิดตัวเลข |
| ใช้ระบบหลายสกุลเงิน (Multi-Currency) | ติ๊กถ้าซื้อขายเป็นเงินตราต่างประเทศ | มีช่อง "สกุลเงินหลัก" ดู [[howto-setup-currency]] |
| เตือนเมื่อสินค้าติดลบ | ติ๊กเพื่อคุมสต็อกติดลบ | ดูหัวข้อ "บันทึกแล้วระบบทำอะไรให้" |
| ห้ามขายสินค้าติดลบ / ห้ามเบิกสินค้าติดลบ / ห้ามโอนสินค้าติดลบ | ติ๊กตามเอกสารที่ต้องการห้าม | |
| ประเภทห้ามสินค้าติดลบ | ทั้งระบบ, เฉพาะคลังสินค้า หรือ เฉพาะที่เก็บสินค้า | เลือกว่าตรวจยอดคงเหลือระดับไหน |
| ใช้คลังที่เก็บตามสิทธิ์พนักงาน | ติ๊กถ้าจะจำกัดคลังตามกลุ่มพนักงาน | ต้องเปิดข้อนี้ ถึงจะใช้ [[howto-setup-warehouse-rights]] ได้ |
| ใช้กลุ่มเอกสาร | ติ๊กถ้าจะแยกเอกสารเป็นกลุ่ม | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล ดู [[howto-setup-doc-group]] |
| ห้ามแก้ไขวันที่และเลขที่เอกสาร | ติ๊กเพื่อล็อกการแก้วันที่/เลขที่ | ก่อนใช้ล็อกจริง ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า |
| ห้ามคัดลอกเอกสาร | ติ๊กเพื่อปิดการคัดลอกเอกสาร | ตัวเลือกนี้มีบนจอ แต่รุ่นปัจจุบันยังไม่มีผล |

## บันทึกแล้วระบบทำอะไรให้
- ค่าที่บันทึกมีผลกับทั้งระบบ ส่วนปีและทศนิยมเปลี่ยนการแสดงผลทันที
- ถ้าเปิดห้ามสินค้าติดลบ แล้วมีเอกสารทำให้ยอดต่ำกว่าศูนย์ ระบบไม่ให้บันทึกเอกสารนั้น และขึ้นข้อความเช่น "สินค้า ... ห้ามติดลบ" (บางกรณีบอกคลังและที่เก็บด้วย)
- ตอนนี้ข้อ "เตือนเมื่อสินค้าติดลบ" ทำงานแบบห้ามบันทึกเช่นกัน ไม่ใช่แค่เตือนตามชื่อข้อ

## แก้ไข ยกเลิก พิมพ์
- เปิดหน้าเดิมแก้ใหม่ได้ทุกเมื่อ ถ้าปิดหน้าจอโดยไม่บันทึกระบบถามยืนยันก่อน
- เอกสารที่บันทึกไปแล้วไม่ถูกแก้ตามอัตโนมัติ

## ปัญหาที่พบบ่อย
- เปิดห้ามติดลบแล้วบันทึกเอกสารไม่ได้ ให้ตรวจยอดคงเหลือสินค้าก่อน หรือปิดข้อเลือกถ้าตั้งใจให้ขายล่วงหน้า
- ตั้งสิทธิ์คลังแล้วไม่มีผล แปลว่ายังไม่ติ๊ก "ใช้คลังที่เก็บตามสิทธิ์พนักงาน"
- หาข้อเลือกไม่เจอ อาจถูกซ่อนตามประเภทธุรกิจหรือรุ่นที่ใช้ ถามฝ่ายขายหรือผู้ดูแลระบบ
- ไม่มีสิทธิ์เปิด ดู [[ts-common-no-permission]]
