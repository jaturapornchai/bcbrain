# รับสินค้าสำเร็จรูปเข้าคลัง

**ใช้เมื่อ:** ผลิตสินค้าเสร็จ (เอง หรือจ้างผลิต) แล้วนำเข้าสต็อก
**เมนู:** สินค้า › รับสินค้าสำเร็จรูป
**ต้องมีก่อน:** สินค้าสำเร็จรูปในข้อมูลสินค้า คลังและที่เก็บ ผู้จำหน่าย (ถ้าจ้างผลิต)

## ขั้นตอน
1. เปิดเมนู รับสินค้าสำเร็จรูป กดเพิ่ม
2. กรอกวันที่ เลือก เจ้าหนี้/ผู้จำหน่าย (ถ้ามี) แล้วเลือก คลังสินค้า และ พื้นที่เก็บ
3. ใส่สินค้าสำเร็จรูป จำนวน และ ต้นทุน/หน่วย
4. กดบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| คลังสินค้า / พื้นที่เก็บ | ที่จะเก็บของ | ใช้เป็นค่าเริ่มต้นของทุกแถว |
| จำนวน | จำนวนที่ผลิตได้ | |
| ต้นทุน/หน่วย | ต้นทุนผลิตต่อหน่วย | เมื่อเลือกสินค้า ระบบใส่ต้นทุนเฉลี่ยปัจจุบันให้ก่อน แก้ได้ ถ้าใส่เป็นศูนย์ สต็อกจะใช้ต้นทุนเฉลี่ยปัจจุบันแทน |

## บันทึกแล้วระบบทำอะไรให้
- **สต็อก:** เพิ่มจำนวนและมูลค่า แล้วคำนวณต้นทุนเฉลี่ยใหม่
- **บัญชี (ค่าปกติ):** เดบิต สินค้าคงเหลือ / เครดิต ต้นทุนขาย ตามยอดรวมเอกสาร (ถ้ารูปแบบเอกสารตั้งรูปแบบการลงบัญชีไว้ ระบบใช้รูปแบบนั้นแทน) ถ้ายอดรวมเป็นศูนย์ ระบบไม่ลงบัญชี ([[faq-stock-gl-posting]])
- **ข้อจำกัด:** ระบบไม่ได้ตัดวัตถุดิบให้อัตโนมัติ ต้องบันทึกใบเบิกวัตถุดิบแยก ([[howto-stock-issue]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไข/ลบได้ถ้ายังไม่ถูกอ้างอิงและงวดบัญชียังไม่ปิด
- ยกเลิกที่เมนู ยกเลิกรับสินค้าสำเร็จรูป ([[howto-stock-cancel-doc]])
