# ใช้หน้าจอรายการข้อมูล

**ใช้เมื่อ:** ต้องการหา เพิ่ม แก้ไข หรือลบ ข้อมูลหลัก เช่น สินค้า ลูกค้า ผู้จำหน่าย ผังบัญชี หรือหาเอกสารเก่าในหน้าจอเอกสาร
**เมนู:** ทุกหน้าจอข้อมูลหลักและหน้าจอเอกสาร (รายการอยู่ด้านซ้าย รายละเอียดอยู่ด้านขวา) เช่น สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ข้อมูลสินค้า, ลูกหนี้ › ทะเบียนลูกหนี้ สมาชิก และแต้มสะสม › กำหนดลูกหนี้, เจ้าหนี้ › ทะเบียนเจ้าหนี้ คู่ค้า และที่อยู่จัดส่ง › กำหนดเจ้าหนี้
**ต้องมีก่อน:** มีสิทธิ์เปิดหน้าจอนั้น (ถ้าจะเพิ่ม แก้ไข หรือลบ ต้องมีสิทธิ์นั้นด้วย)

## ขั้นตอน
1. เปิดเมนูที่ต้องการ รายการข้อมูลจะแสดงด้านซ้าย
2. ค้นหา: พิมพ์คำค้นในช่องค้นหา (กด Ctrl + F เพื่อไปที่ช่องค้นหา) แล้วกด Enter หรือปุ่ม "ค้นหา / ซูมข้อมูล" พิมพ์หลายคำได้ ระบบหาเฉพาะรายการที่มีครบทุกคำ กดปุ่ม "ล้างคำค้นหา" เพื่อดูทั้งหมด
3. กรองละเอียด: กดปุ่ม "ตัวกรองข้อมูลขั้นสูง" แล้วกำหนดช่วงรหัส (จากรหัส ถึงรหัส) หรือคำค้นในช่อง ชื่อ 1 และ ชื่อ 2 จากนั้นกด Enter หรือ "กรองข้อมูล"
4. หน้าจอเอกสาร: เลือกช่วงวันที่ วันที่ ถึง เพื่อหาเอกสารในช่วงนั้น
5. เรียงข้อมูล: คลิกที่หัวคอลัมน์
6. เลือกรายการ: คลิกที่แถว หรือใช้ลูกศรขึ้นลง Home End รายละเอียดจะแสดงด้านขวา
7. เพิ่มใหม่: กดปุ่มเพิ่มใหม่ (หรือ Insert) กรอกข้อมูล แล้วกดบันทึก (หรือ Ctrl + S)
8. แก้ไข: เลือกรายการ กด "แก้ไข" แก้ข้อมูล แล้วกดบันทึก
9. ลบ: เลือกรายการ กดลบ แล้วยืนยัน

## ช่องสำคัญที่ต้องกรอก
| ปุ่ม | ใช้ทำอะไร | หมายเหตุ |
|---|---|---|
| ค้นหา / ซูมข้อมูล | ค้นตามคำที่พิมพ์ | ค้นได้ทั้งรหัสและชื่อ |
| ตัวกรองข้อมูลขั้นสูง | กรองช่วงรหัส และคำค้นในชื่อ 1 ชื่อ 2 | มีจุดสีขึ้นที่ปุ่มเมื่อกำลังกรองอยู่ |
| ปรับคอลัมน์ | เปิดปิดคอลัมน์ เรียงลำดับคอลัมน์ จัดชิดซ้ายขวา รูปแบบตัวเลข | บันทึกแยกตามผู้ใช้ กด "คืนค่าเริ่มต้น (Reset Default)" เพื่อกลับเป็นแบบเดิม |
| รีเซ็ตความกว้างคอลัมน์ | คืนความกว้างคอลัมน์เป็นค่าเริ่มต้น | ใช้เมื่อลากคอลัมน์จนแคบหรือกว้างเกิน |
| ผู้สร้าง/แก้ไข | แสดงผู้สร้างและผู้แก้ไขล่าสุด | ดู [[howto-common-record-history]] |
| ประวัติแก้ไข | ดูว่าใครแก้อะไร เมื่อไร | |
| คำแนะนำการใช้งาน (Help) | ดูคู่มือคีย์ลัด | ดู [[start-keyboard-shortcuts]] |
| ปิดหน้าจอ | ปิดแท็บหน้าจอนี้ | |

## บันทึกแล้วระบบทำอะไรให้
- บันทึกแล้วรายการด้านซ้ายจะอัปเดตทันที และระบบเก็บประวัติว่าใครเพิ่มหรือแก้ไข
- ระหว่างที่คุณกด "แก้ไข" ระบบล็อกรายการนั้นไว้ไม่ให้คนอื่นแก้ทับ ถ้าเปิดโหมดแก้ไขทิ้งไว้โดยไม่ขยับประมาณ 5 นาที ระบบจะออกจากโหมดแก้ไขให้เอง

## แก้ไข ยกเลิก พิมพ์
- ระหว่างแก้ไข กด Escape เพื่อยกเลิกการแก้ไขโดยไม่บันทึก
- การแก้ไขและลบเอกสาร ดู [[howto-doc-edit-cancel-delete]]
- พิมพ์รายงานรายชื่อ เช่น รายชื่อสินค้า รายชื่อลูกค้า ใช้เมนูรายงาน ดู [[rpt-overview]]

## ปัญหาที่พบบ่อย
- แก้ไขไม่ได้เพราะมีคนอื่นกำลังแก้อยู่ ดู [[ts-common-record-locked]]
- ไม่มีปุ่มเพิ่ม แก้ไข หรือลบ ดู [[ts-common-no-permission]]
- ค้นหาไม่เจอ ให้ลดคำค้นเหลือคำเดียว หรือกด "ล้างคำค้นหา" และตรวจว่าไม่ได้เปิดตัวกรองขั้นสูงค้างไว้
- ต้องการนำเข้าสินค้า ลูกค้า หรือผู้จำหน่ายทีละมากๆ ตอนนี้ยังไม่มีหน้าจอนำเข้าแบบไฟล์ ดู [[faq-general-import-old-data]]
