# จัดการ MCP Token เชื่อมต่อ AI (Read-Only)

**ใช้เมื่อ:** ต้องการให้ผู้ช่วย AI ภายนอก (เช่น Claude, Cursor) เข้ามาอ่านข้อมูลบัญชีของกิจการ เช่น ถามภาพรวมยอดขาย ตรวจงบทดลอง โดยที่ AI อ่านได้อย่างเดียว แก้หรือลบข้อมูลไม่ได้
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › จัดการ MCP Token เชื่อมต่อ AI (Read-Only) (ไม่จำกัดเฉพาะ Admin)
**ต้องมีก่อน:** สิทธิ์เปิดหน้านี้ · โปรแกรม AI ที่รองรับการเชื่อมต่อแบบ MCP · เริ่มต้นดู [[start-first-day]]

Token คือรหัสลับยาวๆ ที่ใช้แทนรหัสผ่านให้ AI เข้ามาอ่านข้อมูล ใครถือรหัสนี้ก็อ่านข้อมูลบริษัทได้ จึงต้องเก็บเป็นความลับ

## ขั้นตอน
1. เปิดเมนู ฝั่งซ้ายคือรายการ Token ที่มีอยู่ (ค้นหาจากชื่อการเชื่อมต่อหรือฐานข้อมูลได้) ถ้ายังไม่มีขึ้น "ยังไม่มีรายการ MCP Token"
2. กด "+ เพิ่ม MCP Token ใหม่ (Read-Only)"
3. ตั้งชื่อการเชื่อมต่อ เช่น "Claude Desktop ตรวจงบทดลอง" และใส่อายุการใช้งาน (1 ถึง 365 วัน)
4. เลือกฐานข้อมูลบริษัทที่อนุญาตให้ AI อ่าน
5. กด "บันทึก / สร้าง Token" ระบบแจ้ง 'สร้าง Read-Only MCP Token "..." สำเร็จ' พร้อมแสดงรหัสยาวให้คัดลอก
6. กด "คัดลอก MCP Token" เก็บไว้ทันที เพราะรหัสเต็มแสดงให้เห็นเพียงครั้งเดียว
7. นำรหัสไปใส่ในโปรแกรม AI ฝั่งขวามีกล่อง "การตั้งค่าเชื่อมต่อกับ AI ภายนอก" ให้กด "คัดลอก URL" และ "คัดลอกโค้ด" ไปวางตามที่โปรแกรม AI ต้องการ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ชื่อการเชื่อมต่อ AI | ชื่อไว้จำว่า Token นี้ให้ใคร | ต้องกรอก ไม่งั้นขึ้น "กรุณาระบุชื่อการเชื่อมต่อ AI" |
| สิทธิ์การเข้าถึง | อ่านข้อมูลอย่างเดียว 100% | ล็อกไว้ เปลี่ยนไม่ได้ ป้ายบนหัวหน้าจอเขียน "บังคับสิทธิ์ Read-Only 100%" |
| อายุการใช้งาน (1 ถึง 365 วัน) | จำนวนวันที่ Token ใช้ได้ | ถ้านอกช่วงขึ้น "กรุณาระบุอายุการใช้งาน Token ระหว่าง 1 ถึง 365 วัน" |
| ฐานข้อมูลบริษัทที่อนุญาต | เลือกอย่างน้อย 1 ฐาน | ไม่เลือกขึ้น "กรุณาเลือกฐานข้อมูลบริษัทที่อนุญาตอย่างน้อย 1 ฐานข้อมูล" |

เมื่อเลือกรายการเดิม จะเห็น ผู้สร้าง Token, วันที่สร้าง, วันหมดอายุ และใช้งานล่าสุดเมื่อ

## บันทึกแล้วระบบทำอะไรให้
- ออก Token ใหม่ผูกกับฐานข้อมูลที่เลือก AI ที่ถือรหัสนี้ใช้เครื่องมือแบบอ่านอย่างเดียวได้ 9 อย่าง คือ ภาพรวมกิจการและตัวเลขสำคัญ, รายชื่อฐานข้อมูลที่ได้รับอนุญาต, ค้นหารายการข้อมูล, ดูโครงสร้างข้อมูล, อ่านข้อมูลแบบกระชับ, อ่านหลายชุดพร้อมกัน, เจาะดูเอกสารครบทั้งหัว สินค้า และบัญชี, สรุปงบการเงิน ภาษี และงบบริหาร, และรันรายงานมาตรฐาน
- กล่อง "ทดสอบเรียก MCP Tool" ในหน้านี้ ใช้วางรหัสแล้วเลือกเครื่องมือเพื่อลองเรียกดูผล ก่อนนำไปใช้จริง

## แก้ไข ยกเลิก พิมพ์
- เพิกถอน: เลือก Token ที่ไม่ใช้แล้ว กด "ลบ / เพิกถอน Token" ขึ้น 'เพิกถอน MCP Token "..." เรียบร้อยแล้ว' หลังจากนั้นรหัสนั้นใช้ไม่ได้อีก
- ถ้ารหัสหลุดหรือคัดลอกไม่ทัน ให้เพิกถอนแล้วสร้างใหม่ ตอนนี้ไม่มีทางเรียกดูรหัสเดิมซ้ำ
- ถ้าคัดลอกอัตโนมัติไม่ได้ ขึ้น "ไม่สามารถคัดลอกอัตโนมัติได้ กรุณาคลุมดำแล้วคัดลอกด้วยตนเอง"
- ปุ่ม "โหลดใหม่" รีเฟรชรายการ

## ปัญหาที่พบบ่อย
- AI ต่อไม่ติด: ตรวจว่า Token ยังไม่หมดอายุและยังไม่ถูกเพิกถอน (ดูคอลัมน์วันหมดอายุ)
- ทดสอบแล้วขึ้น "กรุณาวาง MCP Token ... หรือกดสร้าง Token ใหม่ก่อนทดสอบ": ยังไม่ได้วางรหัสในกล่องทดสอบ
- ขึ้น "สร้าง MCP Token ไม่สำเร็จ": ลองใหม่ ถ้ายังไม่ได้ติดต่อผู้ดูแลระบบ
- ความปลอดภัย: ห้ามโพสต์รหัสในแชทสาธารณะ ห้ามส่งทางอีเมลที่ไม่เข้ารหัส ถ้าสงสัยว่าหลุดให้เพิกถอนทันที
- ไม่มีสิทธิ์: ดู [[ts-common-no-permission]]
