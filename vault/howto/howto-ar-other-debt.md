# ตั้งหนี้ลูกค้าจากรายได้อื่น (ตั้งหนี้ เพิ่มหนี้ ลดหนี้อื่นๆ)

**ใช้เมื่อ:** เรียกเก็บเงินลูกค้าเป็นเงินเชื่อ จากรายการที่ไม่ใช่สินค้าในสต็อก เช่น ค่าบริการ ค่าเช่า ค่าขนส่ง ค่าปรับ แล้วรอรับชำระภายหลัง
**เมนู:** ลูกหนี้ › เลือก
- ตั้งหนี้อื่นๆ (ลูกหนี้) — เรียกเก็บครั้งแรก
- เพิ่มหนี้อื่นๆ (ลูกหนี้) — เก็บเพิ่มเพราะคิดขาด
- ลดหนี้อื่นๆ (ลูกหนี้) — ลดยอดให้ลูกค้าเพราะคิดเกินหรือให้ส่วนลดภายหลัง
**ต้องมีก่อน:**
- ลูกค้าในทะเบียนลูกหนี้ ([[howto-ar-customer-register]])
- รหัสรายได้ ตั้งไว้ที่ เริ่มต้น › ตั้งค่าระบบขายและ POS › กำหนดรายได้อื่นๆ ([[howto-sale-settings]])

## ขั้นตอน
1. เปิดเมนู ตั้งหนี้อื่นๆ (ลูกหนี้) กดเพิ่มใหม่
2. เลือกลูกค้า ใส่วันที่ และ "เลขที่ใบกำกับภาษี" (ถ้าออกใบกำกับให้ลูกค้า)
3. เลือกประเภทภาษี ([[faq-sale-vat-types]])
4. ในตาราง ใส่ "รหัสรายได้" ระบบแสดง "ชื่อรายได้" แล้วใส่จำนวนเงิน เพิ่มได้หลายบรรทัด
5. ใส่ "เครดิต (วัน)" หรือ "ครบกำหนด"
6. ถ้าลูกค้าเคยจ่ายเงินมัดจำไว้ หักในแท็บ "ใช้เงินมัดจำ" ได้ (มีเฉพาะ ตั้งหนี้อื่นๆ) ([[howto-sale-deduct-deposit]])
7. ตรวจแท็บ "ภาษีมูลค่าเพิ่ม" และแท็บ "การลงบัญชี (GL)" แล้วบันทึก
8. เพิ่มหนี้อื่นๆ / ลดหนี้อื่นๆ ทำแบบเดียวกัน และใส่ "สาเหตุ" ของการเพิ่ม/ลดหนี้

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | ลูกค้าที่ต้องจ่าย | |
| เลขที่ใบกำกับภาษี | เลขใบกำกับที่ออกให้ลูกค้า | |
| รหัสรายได้ / จำนวนเงิน | ชนิดรายได้และยอดเงิน | ต้องมีใน กำหนดรายได้อื่นๆ |
| เครดิต (วัน) / ครบกำหนด | วันที่ลูกค้าต้องจ่าย | |
| สาเหตุ | เหตุผลที่เพิ่มหรือลดหนี้ | เฉพาะ เพิ่มหนี้/ลดหนี้อื่นๆ |

## บันทึกแล้วระบบทำอะไรให้
- กลายเป็นหนี้ค้างของลูกค้า ขึ้นใน "ดึงเอกสารค้างชำระ" ของใบวางบิลและใบเสร็จ (ลดหนี้อื่นๆ ขึ้นเป็นยอดติดลบ)
- ไม่ตัดสต็อก
- ลงบัญชี (บัญชีแยกประเภท) ให้อัตโนมัติ: เดบิต ลูกหนี้ (และเงินมัดจำที่หัก) / เครดิต รายได้อื่น และภาษีขาย ส่วนลดหนี้อื่นๆ กลับข้างกัน ([[faq-sale-gl-posting]])
  - ถ้าร้านตั้งรูปแบบการลงบัญชีของเอกสารไว้ ระบบลงตามรูปแบบนั้นก่อน
  - ถ้าไม่ได้ตั้ง บัญชีรายได้ที่ใช้เป็นบัญชีรายได้อื่นมาตรฐานของระบบ ไม่ได้แยกตาม "รหัสผังบัญชี" ของแต่ละรหัสรายได้
- ถ้ามีภาษี เข้ารายงานภาษีขาย
- ตั้งหนี้อื่นๆ ระบบตรวจวงเงินเครดิตของลูกค้าเหมือนการขายเชื่อ ส่วน เพิ่มหนี้อื่นๆ ไม่ได้ตรวจ ([[howto-sale-credit-limit]])

## แก้ไข ยกเลิก พิมพ์
- แก้หรือลบได้จนกว่าจะถูกนำไปวางบิลหรือรับชำระ หลังจากนั้นขึ้น "ห้ามแก้ไข หรือลบข้อมูล"
- ตั้งหนี้อื่นๆ ที่มี เพิ่มหนี้อื่นๆ หรือ ลดหนี้อื่นๆ อ้างถึงแล้ว ก็แก้หรือลบไม่ได้เช่นกัน
- ยกเลิก: ลูกหนี้ › ยกเลิกเอกสารลูกหนี้ (ตั้งหนี้อื่น/วางบิล/รับชำระ) › ยกเลิกตั้งหนี้อื่นๆ (ลูกหนี้) / ยกเลิกเพิ่มหนี้อื่นๆ (ลูกหนี้) / ยกเลิกลดหนี้อื่นๆ (ลูกหนี้) ([[howto-ar-cancel-docs]])
- พิมพ์ฟอร์มจากหน้าเอกสาร ([[rpt-print-export]])

## ปัญหาที่พบบ่อย
- บันทึกไม่ได้ ขึ้นเรื่องวงเงินหรือปิดสถานะเครดิต → [[ts-sale-credit-over]] / [[ts-sale-credit-closed]]
- หารหัสรายได้ไม่เจอ → ยังไม่ได้ตั้งใน กำหนดรายได้อื่นๆ
- แก้ไม่ได้ → [[ts-sale-cannot-edit]]
- ต้องการให้ลงบัญชีรายได้ตามบัญชีอื่น → ส่งต่อทีมงานตรวจการตั้งรูปแบบบัญชีของเอกสาร
