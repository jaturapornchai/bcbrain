# รับชำระหนี้จากลูกค้า และออกใบเสร็จรับเงิน

**ใช้เมื่อ:** ลูกค้าที่ซื้อเงินเชื่อมาจ่ายเงิน (เงินสด โอน เช็ค หรือบัตร) ต้องการตัดหนี้และออกใบเสร็จให้ลูกค้า
**เมนู:** ลูกหนี้ › รับชำระหนี้/ออกใบเสร็จรับเงิน
**ต้องมีก่อน:** มีหนี้ค้างของลูกค้า ([[howto-sale-invoice]], [[howto-ar-other-debt]], [[howto-ar-opening-balance]]) ถ้าร้านใช้ใบวางบิล ให้ทำใบวางบิลก่อน ([[howto-ar-billing]])

## ขั้นตอน
1. เปิดเมนู รับชำระหนี้/ออกใบเสร็จรับเงิน กด "เพิ่มใหม่"
2. ใส่วันที่ แล้วเลือกลูกค้าในช่อง "ลูกหนี้/ลูกค้า"
3. ดึงบิลที่จะรับเงิน (ปุ่มอยู่ใต้ตาราง) เลือกวิธีใดวิธีหนึ่ง
   - กด "ดึงเอกสารค้างชำระ" ระบบใส่หนี้ค้างทุกใบของลูกค้าให้ทีเดียว แล้วลบใบที่ลูกค้ายังไม่จ่ายออก
   - กด "อ้างอิงใบวางบิล" ติ๊กเลือกใบวางบิล (เลือกได้หลายใบ) แล้วกด "ดึงรายการที่เลือก (...)" ระบบดึงบิลในใบวางบิลนั้นมาให้
   - หน้าต่างเลือกใบวางบิลแสดงทุกใบที่ยังไม่ยกเลิก รวมใบที่รับเงินครบไปแล้ว ระวังเลือกใบเก่าซ้ำ
4. ตรวจ "ยอดชำระ" ของแต่ละบรรทัด ถ้าดึงด้วย "ดึงเอกสารค้างชำระ" ระบบใส่เท่ากับยอดคงเหลือ ถ้าดึงด้วย "อ้างอิงใบวางบิล" ระบบใส่ยอดตามใบวางบิล (ถ้าเคยรับเงินบิลนั้นไปบางส่วนแล้ว ต้องแก้ลดเอง) ลูกค้าจ่ายไม่ครบ แก้ให้ตรงยอดที่จ่ายจริง ([[faq-ar-partial-payment]])
5. ไปแท็บ "การรับ/จ่ายชำระเงิน" ใส่เงินที่รับตามช่องทางจริง (เงินสด เงินโอน PromptPay / QR เช็ค บัตรเครดิต) ([[howto-sale-cash-payment]])
6. ถ้าลูกค้าหักภาษี ณ ที่จ่ายไว้ ใส่ในแท็บ "ภาษีถูกหัก ณ. ที่จ่าย" ยอดนี้นับเป็นยอดชำระด้วย (ช่อง "8. ภาษีหัก ณ ที่จ่าย (นับเป็นยอดชำระ)")
7. ตรวจว่ายอดรับรวมเท่ากับ "ยอดสุทธิที่ต้องรับ/จ่ายชำระ (1 + 2)" (ขึ้น "✓ ยอดรับ/จ่ายชำระครบถ้วนตรงตามยอดสุทธิ") แล้วกด "บันทึก"
8. พิมพ์ใบเสร็จรับเงินให้ลูกค้า กด "พิมพ์ฟอร์ม / เลือกรูปแบบ" ([[rpt-print-export]])

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ลูกหนี้/ลูกค้า | ลูกค้าที่จ่ายเงิน | ต้องเลือกก่อนดึงบิล |
| ยอดชำระ (ต่อบิล) | ยอดที่ลูกค้าจ่ายของบิลนั้น | ห้ามเกิน "ยอดคงเหลือ" |
| แท็บ การรับ/จ่ายชำระเงิน | เงินที่รับแยกตามช่องทาง | ต้องรวมได้เท่ายอดสุทธิ |
| ภาษีถูกหัก ณ. ที่จ่าย | ยอดที่ลูกค้าหักไว้ ตามหนังสือรับรองที่ลูกค้าให้ | |

## บันทึกแล้วระบบทำอะไรให้
- ยอดค้างของแต่ละบิลลดลงตาม "ยอดชำระ" บิลที่รับครบจะไม่ขึ้นใน "ดึงเอกสารค้างชำระ" อีก
- ลงบัญชี (บัญชีแยกประเภท) ให้อัตโนมัติ แบบมาตรฐาน: เดบิต เงินสด / ธนาคาร (เงินโอน และ PromptPay) / เช็ครับ / ภาษีถูกหัก ณ ที่จ่าย ตามที่รับมา เครดิต ลูกหนี้ ([[faq-sale-gl-posting]])
  - บัญชีธนาคารใช้บัญชีของสมุดบัญชีธนาคารบรรทัดแรกที่เลือกในแท็บรับเงิน ถ้าไม่ได้เลือกใช้บัญชีธนาคารมาตรฐาน
  - ส่วนที่รับเป็นบัตรเครดิต ระบบลงเดบิตที่บัญชีลูกหนี้ไว้ก่อน (รอเงินจากธนาคารผู้ออกบัตร) แล้วย้ายเข้าธนาคารตอน บันทึกขึ้นเงินบัตรเครดิต
  - ถ้าผู้ดูแลตั้งรูปแบบบัญชีไว้กับรูปแบบเอกสารของใบเสร็จ ระบบลงบัญชีตามที่ตั้งแทนแบบมาตรฐาน
- บิลสกุลเงินต่างประเทศ (เมื่อเปิดใช้หลายสกุลเงิน): ส่วนต่างอัตราแลกเปลี่ยนระหว่างวันขายกับวันรับเงิน ลงเป็นกำไรหรือขาดทุนจากอัตราแลกเปลี่ยนให้
- รับเป็นเช็คที่ใส่เลขที่เช็ค เช็คเข้าทะเบียนเช็ครับ รอนำฝากต่อ รับเป็นบัตรเครดิต รายการเข้าทะเบียนบัตรเครดิต รอบันทึกขึ้นเงิน ([[howto-cash-bank-overview]])

## แก้ไข ยกเลิก พิมพ์
- แก้หรือลบ: เปิดใบเสร็จเดิม กด "แก้ไข" หรือ "ลบ" ([[howto-doc-edit-cancel-delete]])
- ยกเลิก: ลูกหนี้ › ยกเลิกเอกสารลูกหนี้ (ตั้งหนี้อื่น/วางบิล/รับชำระ) › ยกเลิกชำระหนี้/ยกเลิกใบเสร็จรับเงิน ระบบกลับรายการบัญชีให้ และบิลกลับมาค้างชำระ ([[howto-ar-cancel-docs]])

## ปัญหาที่พบบ่อย
- "ป้อนยอดชำระเกิน : ... (ยอดคงเหลือ ...)" หรือ "... ต้องอ้างอิงใบวางบิล" → [[ts-ar-pay-over-balance]]
- "กรุณาเลือกเอกสารอย่างน้อย 1 รายการ" → ตารางยังไม่มีบิล ให้ดึงบิลก่อนบันทึก
- "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" → [[ts-sale-payment-incomplete]]
- ดึงแล้วไม่มีบิลขึ้น หรือ "ไม่พบใบวางบิลของลูกหนี้รายนี้" → [[ts-ar-no-outstanding]]
- ลูกค้าโอนมาเกินยอดบิล → รับส่วนเกินเป็นเงินรับล่วงหน้า ([[howto-sale-advance-receipt]])
