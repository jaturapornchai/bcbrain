# ยกเลิกเอกสารคลังสินค้า (รับ เบิก โอน ปรับปรุง)

**ใช้เมื่อ:** บันทึกเอกสารสต็อกผิด แต่ไม่อยากลบทิ้ง อยากเก็บร่องรอยว่ายกเลิกเพราะอะไร
**เมนู:** สินค้า › ยกเลิกเอกสารคลังสินค้า (รับ/เบิก/โอน/ปรับปรุง) › เลือกเมนูยกเลิกตามชนิดเอกสาร
**ต้องมีก่อน:** สิทธิ์ใช้เมนูยกเลิก ([[ts-common-no-permission]]) งวดบัญชีของวันที่เอกสารเดิมและวันที่ยกเลิกยังไม่ปิด

## เมนูยกเลิกที่มี
| เมนูยกเลิก | ใช้กับ |
|---|---|
| ยกเลิกรับสินค้าสำเร็จรูป | [[howto-stock-finished-goods]] |
| ยกเลิกขอเบิกสินค้า/วัตถุดิบ, ยกเลิกใบเบิกสินค้า/วัตถุดิบ, ยกเลิกรับคืนสินค้า/วัตถุดิบ จากการเบิก | [[howto-stock-issue]] |
| ยกเลิกโอนสินค้า/วัตถุดิบ | [[howto-stock-transfer]] |
| ยกเลิกปรับปรุงสต๊อกสินค้า/วัตถุดิบ (เกิน) | ใบปรับปรุงเพิ่ม ([[howto-stock-adjust]]) |
| ยกเลิกปรับปรุงสต๊อกสินค้า/วัตถุดิบ (ขาด) | ใบปรับปรุงลด |

ใบขอโอน ใบขอตรวจนับ ใบตรวจนับ และสินค้ายกมา ยังไม่มีเมนูยกเลิก ใช้การแก้ไข/ลบจากเมนูของเอกสารนั้นแทน

## ขั้นตอน
1. เปิดเมนูยกเลิกที่ตรงชนิดเอกสาร
2. กดปุ่มค้นหาเอกสาร (รูปแว่นขยาย) แล้วเลือกเอกสารที่จะยกเลิก ระบบแสดงรายละเอียดให้ตรวจ
3. ใส่วันที่ยกเลิก พิมพ์เหตุผลในช่อง ระบุเหตุผลการยกเลิก
4. กด บันทึกยกเลิก ระบบออกเลขที่เอกสารยกเลิกให้เอง
5. ยกเลิกผิดใบ: เปิดเอกสารเดิมในเมนูยกเลิก แล้วกด คืนสถานะเอกสารปกติ

## บันทึกแล้วระบบทำอะไรให้
- เอกสารเดิมสถานะเป็นยกเลิก ไม่ถูกลบ และไม่นับในยอดสต็อกและต้นทุนอีก ระบบคำนวณสต็อกและต้นทุนเฉลี่ยของสินค้าในเอกสารนั้นใหม่ทันที
- รายการบัญชีของเอกสารเดิมยังอยู่ ระบบลงรายการกลับด้านให้ในวันที่ของเอกสารยกเลิก
- เอกสารคลังสินค้ายกเลิกได้ทั้งใบเท่านั้น ยกเลิกทีละรายการไม่ได้
- คืนสถานะ: ระบบลบเอกสารยกเลิก แล้วคำนวณสต็อกและบัญชีกลับเหมือนเดิม

## แก้ไข
- เอกสารที่ยกเลิกแล้วแก้ไขไม่ได้ ถ้าต้องการรายการใหม่ให้บันทึกเอกสารใหม่
- ภาพรวมการแก้ ยกเลิก ลบ ของทุกระบบ ดู [[howto-doc-edit-cancel-delete]]
