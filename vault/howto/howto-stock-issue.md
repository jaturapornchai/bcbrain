# ขอเบิก เบิก และรับคืนสินค้า/วัตถุดิบจากการเบิก

**ใช้เมื่อ:** นำสินค้าออกจากคลังไปใช้ภายใน หรือเบิกวัตถุดิบไปผลิต แล้วอาจมีของเหลือส่งคืนคลัง
**เมนู:** สินค้า › ขอเบิกสินค้า/วัตถุดิบ / เบิกสินค้า/วัตถุดิบ / รับคืนสินค้า/วัตถุดิบ จากการเบิก
**ต้องมีก่อน:** สินค้ามียอดคงเหลือ ([[howto-stock-opening-balance]])

## ขั้นตอน
1. (ถ้ามีขั้นอนุมัติ) **ขอเบิกสินค้า/วัตถุดิบ:** ผู้ขอกรอกรายการ เลือก ผู้ขออนุมัติ: แล้วบันทึก เอกสารนี้ยังไม่ตัดสต็อก (บางรุ่นอาจไม่เห็นเมนูนี้ สอบถามฝ่ายขาย)
2. **เบิกสินค้า/วัตถุดิบ:** กดเพิ่ม เลือก คลังสินค้า: และ พื้นที่เก็บ: ถ้าเบิกตามใบขอเบิก ให้กดปุ่มค้นหาข้างช่อง เอกสารอ้างอิง: เพื่อดึงรายการจากใบขอเบิก แล้วใส่สินค้าและจำนวน กดบันทึก
3. **รับคืนสินค้า/วัตถุดิบ จากการเบิก:** ของเหลือกลับเข้าคลัง ดึงรายการจากใบเบิกเดิมด้วยช่อง เอกสารอ้างอิง: ใส่จำนวนที่คืน แล้วบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| คลังสินค้า / พื้นที่เก็บ | เบิกจากที่ไหน | ค่าเริ่มต้นของทุกแถว |
| เอกสารอ้างอิง | เลขที่ใบขอเบิก (ใบเบิก) หรือใบเบิก (ใบรับคืน) | ไม่บังคับ |
| จำนวน | จำนวนที่เบิก/คืน | ใบเบิกไม่มีช่องราคา ระบบใส่ต้นทุนเฉลี่ยตอนเลือกสินค้าให้เอง |
| ต้นทุน/หน่วย (ใบรับคืน) | ต้นทุนของที่คืน | ระบบใส่ต้นทุนเฉลี่ยปัจจุบันให้ก่อน แก้ได้ ถ้าใส่เป็นศูนย์ สต็อกจะใช้ต้นทุนเฉลี่ยปัจจุบันแทน |

## บันทึกแล้วระบบทำอะไรให้
- **ใบขอเบิก:** ไม่เปลี่ยนสต็อก ไม่ลงบัญชี
- **ใบเบิก:** ลดสต็อก มูลค่าในสต็อก = จำนวน × ต้นทุนเฉลี่ย ณ วันที่เอกสาร ลงบัญชีปกติ เดบิต ต้นทุนขาย / เครดิต สินค้าคงเหลือ ตามยอดรวมเอกสาร (คิดจากต้นทุนเฉลี่ยตอนกรอกเอกสาร) ถ้าบันทึกย้อนหลังหรือต้นทุนเปลี่ยนภายหลัง ยอดบัญชีกับมูลค่าสต็อกอาจไม่เท่ากัน ถ้าลูกค้าพบ ให้ส่งต่อเจ้าหน้าที่
- **ใบรับคืน:** เพิ่มสต็อกกลับ ลงบัญชีกลับด้าน เดบิต สินค้าคงเหลือ / เครดิต ต้นทุนขาย
- ถ้ารูปแบบเอกสารมีรูปแบบการลงบัญชีของตัวเอง ระบบใช้รูปแบบนั้นแทน ([[faq-stock-gl-posting]])
- ใบเบิกใหม่ถูกตรวจห้ามติดลบเมื่อเปิด ห้ามเบิกสินค้าติดลบ ([[howto-stock-options]])

## แก้ไข ยกเลิก พิมพ์
- ใบขอเบิกที่ถูกดึงไปทำใบเบิกแล้ว และใบเบิกที่ถูกดึงไปทำใบรับคืนแล้ว ลบหรือยกเลิกไม่ได้ ระบบแจ้ง "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบได้" แต่รุ่นปัจจุบันยังแก้ไขเอกสารนั้นได้ ควรระวัง
- ยกเลิกที่เมนู ยกเลิกขอเบิกสินค้า/วัตถุดิบ, ยกเลิกใบเบิกสินค้า/วัตถุดิบ, ยกเลิกรับคืนสินค้า/วัตถุดิบ จากการเบิก ([[howto-stock-cancel-doc]])
