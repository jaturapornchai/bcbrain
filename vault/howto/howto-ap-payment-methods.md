# ใส่ช่องทางจ่ายเงิน เงินสด โอน เช็ค บัตร PromptPay

**ใช้เมื่อ:** บันทึกใบจ่ายชำระหนี้ หรือเอกสารซื้อเงินสด แล้วต้องบอกระบบว่าจ่ายเงินทางไหน
**เมนู:** แท็บ "การรับ/จ่ายชำระเงิน" ในหน้าจอ เจ้าหนี้ › จ่ายชำระหนี้ (เจ้าหนี้) และเอกสารซื้อที่จ่ายทันที
**ต้องมีก่อน:** สมุดเงินฝากธนาคาร (และเครื่องรูดบัตร ถ้าใช้) ตั้งไว้ในระบบเงินสดและธนาคาร ([[howto-cash-bank-overview]])

## ขั้นตอน
1. เปิดแท็บ "การรับ/จ่ายชำระเงิน" ด้านบนเป็นสรุปยอด ด้านล่างเป็นตารางแต่ละช่องทาง
2. เงินโอน: เพิ่มแถว เลือก "สมุดเงินฝาก" ใส่ วันที่โอน เลขอ้างอิง/สลิป จำนวนเงิน (โอนหลายบัญชีหลายสลิปในใบเดียวได้)
3. PromptPay: เลือก "สมุดบัญชี/PromptPay" ใส่ เลขอ้างอิงสลิป และจำนวนเงิน
4. เช็ค: ที่ "รายการเช็คจ่าย (หลายรายการ)" เลือกสมุดบัญชีธนาคาร ใส่ เลขที่เช็ค สาขา วันถึงกำหนด จำนวนเงิน (หลายใบได้)
5. บัตรเครดิต: ใส่ เลขที่บัตร รหัสอนุมัติ สมุดบัญชี/EDC ค่าธรรมเนียม จำนวนเงิน
6. ค่าใช้จ่ายเพิ่ม เช่น ค่าธรรมเนียม ใส่ที่ "จ่ายอื่น ๆ" ส่วนที่ได้หักลด ใส่ที่ "หักอื่น ๆ"
7. ส่วนที่เหลือจ่ายเงินสด ใส่ที่ "ชำระด้วยเงินสด:" หรือกด "คำนวณยอดเงินสด (ส่วนที่เหลือ ...)" ให้ระบบเติมให้
8. ตรวจข้อความ "✓ ยอดรับ/จ่ายชำระครบถ้วนตรงตามยอดสุทธิ" ก่อนบันทึก

## ช่องสำคัญที่ต้องกรอก
| บรรทัดในสรุปยอด | ความหมาย |
|---|---|
| 1. ยอดตามเอกสาร | ยอดรวมบิลที่จ่ายในใบนี้ |
| 2. บวก จ่ายอื่น ๆ | ค่าใช้จ่ายเพิ่มที่จ่ายพร้อมกัน |
| ยอดสุทธิที่ต้องรับ/จ่ายชำระ (1 + 2) | ยอดที่ต้องจ่ายทั้งหมด |
| 3. รวมเงินโอนธนาคาร ถึง 6. รวมชำระด้วยบัตรเครดิต | ยอดรวมจากแต่ละตาราง |
| 7. หักอื่น ๆ | ยอดที่หักออกจากการจ่าย |
| 8. ภาษีหัก ณ ที่จ่าย (นับเป็นยอดชำระ) | ยอดจากแท็บภาษีหัก ณ ที่จ่าย ([[howto-ap-withholding-tax]]) |
| ส่วนที่เหลือเป็นเงินสด | ยอดสุทธิ หักรายการที่ 3 ถึง 8 |
| รวมรับ/จ่ายชำระทั้งสิ้น: | ต้องเท่ากับยอดสุทธิ |

## บันทึกแล้วระบบทำอะไรให้
- ลงบัญชีตามช่องทาง เงินสดลงบัญชีเงินสด เงินโอนและบัตรเครดิตลงบัญชีของสมุดเงินฝากที่เลือก เช็คลงบัญชีเช็คจ่าย
- ถ้าโอนเข้าหลายสมุดเงินฝากในใบเดียว ระบบรวมยอดธนาคารทั้งหมดลงบัญชีของสมุดเล่มแรกเล่มเดียว ถ้าต้องแยกบัญชีให้ถูก ให้แยกเป็นใบจ่ายละสมุด หรือส่งต่อเจ้าหน้าที่
- เช็คจ่ายขึ้นทะเบียนเช็คอัตโนมัติ ใช้ติดตามวันเช็คผ่านบัญชีต่อ
- ภาษีหัก ณ ที่จ่ายนับเป็นยอดจ่ายด้วย เพราะเป็นเงินที่กิจการหักไว้นำส่งแทนผู้ขาย

## แก้ไข ยกเลิก พิมพ์
- แก้ช่องทางจ่าย ให้กด "แก้ไข" ที่เอกสารต้นทาง (ใบจ่ายชำระหรือใบซื้อ) แล้วบันทึกใหม่
- ยกเลิกทั้งใบที่ [[howto-ap-cancel-docs]]

## ปัญหาที่พบบ่อย
- "ยอดการจ่ายเงินไม่สมบูรณ์ (ยอดสุทธิ ... ยอดชำระ ...)" → ยอดรวมยังไม่เท่ายอดสุทธิ ([[ts-ap-pay-incomplete]])
- ขึ้น "ชำระเกินยอดสุทธิ ..." → ใส่เงินรวมเกิน ลดยอดช่องใดช่องหนึ่ง
- "ยอดรับ/จ่ายชำระต้องไม่ติดลบ" → ช่องทางจ่ายห้ามใส่ยอดติดลบ
