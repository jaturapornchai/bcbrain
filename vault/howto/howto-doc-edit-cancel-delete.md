# แก้ไข ยกเลิก และลบเอกสาร

**ใช้เมื่อ:** บันทึกเอกสารไปแล้วพบว่าผิด ต้องการแก้ ยกเลิก หรือลบทิ้ง
**เมนู:** เปิดจากเมนูของเอกสารนั้นโดยตรง (เช่น ขาย › ขายสินค้า/บริการ) ส่วนการยกเลิกใช้เมนูกลุ่ม "ยกเลิก..." ของแต่ละระบบ
**ต้องมีก่อน:** สิทธิ์ "แก้ไข" หรือ "ลบ" ของหน้าจอนั้น ([[howto-user-screen-permission]]) · งวดบัญชีของวันที่เอกสารยังเปิดอยู่ ([[ts-common-period-closed]])

## เลือกวิธีไหนดี
| วิธี | ผลที่ได้ | เหมาะกับ |
|---|---|---|
| แก้ไข | เปลี่ยนข้อมูลในเอกสารเดิม เลขที่เดิม | พิมพ์ผิดเล็กน้อย เอกสารยังไม่ถูกนำไปใช้ต่อ |
| ยกเลิก (Cancel) | สร้าง "ใบยกเลิก" แยกอีกใบ อ้างถึงเอกสารเดิม เอกสารเดิมยังอยู่ให้ตรวจย้อนได้ | ออกเอกสารให้ลูกค้าหรือผู้ขายไปแล้ว เช่น ใบกำกับภาษี ต้องมีหลักฐานการยกเลิก |
| ลบ (Delete) | ลบเอกสารออกจากระบบ | บันทึกผิดและยังไม่ได้ส่งให้ใคร |

> เรื่องเอกสารภาษีที่ออกไปแล้วควรยกเลิกหรือออกใบลดหนี้ ให้ปรึกษาผู้สอบบัญชี/สรรพากร

## ขั้นตอน
**แก้ไขเอกสาร**
1. เปิดเมนูของเอกสาร เลือกเอกสารจากรายการด้านซ้าย (ค้นหาได้ด้วยช่องค้นหา ดู [[howto-common-data-list]])
2. กด "แก้ไข" หัวจอจะเปลี่ยนเป็น "โหมดแก้ไข"
3. แก้ข้อมูล แล้วกด "บันทึก" หรือกด Ctrl+S
4. ระบบถามว่าจะพิมพ์ฟอร์มเลยหรือไม่ เลือก "พิมพ์แบบฟอร์ม" หรือ "ยังไม่พิมพ์"

**ลบเอกสาร**
1. เลือกเอกสารจากรายการ กด "ลบ"
2. ระบบถาม "ยืนยันการลบเอกสาร ... ?" กดยืนยัน
3. สำเร็จจะขึ้น "ลบเอกสาร ... เรียบร้อยแล้ว"

**ยกเลิกเอกสาร**
1. เปิดเมนูยกเลิกของระบบนั้น (ดูตารางด้านล่าง) เช่น ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกขายสินค้า/บริการ
2. กดเพิ่มใหม่ ช่องเลขที่เอกสารจะขึ้น "สร้างอัตโนมัติ"
3. กด "ค้นหาเอกสาร" เลือกเอกสารเดิมที่จะยกเลิก
4. บางจอของซื้อและคลังสินค้าให้เลือก "ประเภทการยกเลิก" เป็น ยกเลิกทั้งหมด หรือ ยกเลิกรายสินค้า
5. พิมพ์เหตุผลในช่อง "ระบุเหตุผลการยกเลิก" แล้วกด "บันทึกยกเลิก"
6. สำเร็จจะขึ้น "ยกเลิกเอกสาร ... เรียบร้อยแล้ว"
7. ถ้ายกเลิกผิดใบ เปิดใบยกเลิกนั้นแล้วกด "คืนสถานะเอกสารปกติ" เอกสารเดิมจะกลับมาใช้ได้

## เมนูยกเลิกของแต่ละระบบ
| ระบบ | กลุ่มเมนูยกเลิก |
|---|---|
| สินค้า | ยกเลิกเอกสารคลังสินค้า (รับ/เบิก/โอน/ปรับปรุง) |
| ซื้อ | ยกเลิกเอกสารซื้อ มัดจำ และทะยอยรับ |
| ขาย | ยกเลิกเอกสารขายและเงินมัดจำรับ |
| เจ้าหนี้ | ยกเลิกเอกสารเจ้าหนี้ (ตั้งหนี้อื่น/วางบิล/จ่ายชำระ) |
| ลูกหนี้ | ยกเลิกเอกสารลูกหนี้ (ตั้งหนี้อื่น/วางบิล/รับชำระ) |
| เงินสด/ธนาคาร | ยกเลิกเอกสารเงินสดย่อย รายได้อื่น และค่าใช้จ่ายอื่น · ยกเลิกเอกสารธนาคาร เช็ครับ เช็คจ่าย และบัตรเครดิต |
| บัญชี | ยกเลิกผ่านรายการ (เฉพาะ Admin) |

## บันทึกแล้วระบบทำอะไรให้
- แก้ไข: ข้อมูลใหม่แทนข้อมูลเดิมของเอกสารทั้งใบ เลขที่เอกสารคงเดิม รายงานจะแสดงตามข้อมูลล่าสุด
- ลบ: เอกสารหายไปจากรายการและรายงาน
- ยกเลิก: เอกสารเดิมแสดงสถานะ "ยกเลิกแล้ว" ใบยกเลิกเก็บเหตุผลและอ้างถึงเลขที่เดิม ดูความเชื่อมโยงได้ที่ปุ่ม "Document Flow" ([[howto-common-document-flow]])
- ทุกการแก้ไขดูย้อนหลังได้ว่าใครแก้ช่องไหน ([[howto-common-record-history]])

## แก้ไข ยกเลิก พิมพ์
- พิมพ์ซ้ำ: เลือกเอกสาร กด "พิมพ์ฟอร์ม / เลือกรูปแบบ" ดู [[howto-common-print-document]]
- แนบรูปหรือไฟล์ประกอบเอกสาร ดู [[howto-common-attach-picture]]

## ปัญหาที่พบบ่อย
- แจ้งว่าปิดงวดไปแล้ว → [[ts-common-period-closed]]
- แจ้งว่าไม่มีสิทธิ์แก้ไขหรือลบ → [[ts-common-no-permission]]
- แจ้ง "ห้ามแก้ไข หรือลบข้อมูล" เพราะเอกสารถูกนำไปใช้ต่อแล้ว → [[ts-common-cannot-edit-used-doc]]
- มีคนอื่นเปิดแก้เอกสารเดียวกันอยู่ → [[ts-common-record-locked]]
- ยกเลิกไม่ได้ เช่น "ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ)" → [[ts-common-cannot-cancel-doc]]
- เลขที่เอกสารซ้ำ → [[ts-common-duplicate-doc-no]]
