# ตั้งรูปแบบเอกสารให้ส่ง e-Tax และค่าตั้ง e-Tax INET

**ใช้เมื่อ:** ต้องการระบุว่าเอกสารรูปแบบไหน (เช่น ใบเสร็จ/ใบกำกับภาษี) เป็นชนิดที่ส่ง e-Tax
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรูปแบบเลขที่เอกสาร (หัวข้อ "e-Tax INET (การส่งภาษีอิเล็กทรอนิกส์)") และ เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดข้อเลือกพิเศษต่างๆ (แท็บ "8.e-Tax INET")
**ต้องมีก่อน:** สิทธิ์แก้ไขข้อมูลบนหน้านี้ (ถ้าไม่มีสิทธิ์ ปุ่ม "แก้ไข" จะกดไม่ได้)

## ส่วนที่ 1: ตั้งต่อรูปแบบเอกสาร
1. เปิด "กำหนดรูปแบบเลขที่เอกสาร" เลือกรูปแบบเอกสารที่ต้องการ แล้วกด "แก้ไข"
2. ไปที่หัวข้อ "e-Tax INET (การส่งภาษีอิเล็กทรอนิกส์)" (ในแถบหัวข้อเขียนว่า "ส่วนที่ 3: e-Tax INET (การส่งภาษีอิเล็กทรอนิกส์)")
3. ติ๊ก "ส่งเอกสารไปยังระบบ e-Tax Invoice / Receipt ผ่าน INET" (ถ้าไม่ติ๊ก ช่องที่เหลือจะกรอกไม่ได้)
4. เลือก "ประเภทเอกสาร e-Tax (e-Tax Document Type)" จากรายการ
5. กรอก "ชื่อประเภทเอกสาร e-Tax (e-Tax Document Name)" และ "รหัสฟอร์มพิมพ์ e-Tax (e-Tax Form Code)"
6. กด "บันทึก"

ประเภทเอกสารที่เลือกได้: -- ไม่ระบุ -- · ใบเสร็จรับเงิน/ใบกำกับภาษี · ใบส่งของ/ใบกำกับภาษี · ใบกำกับภาษี (Tax Invoice) · ใบเพิ่มหนี้ (Debit Note) · ใบลดหนี้ (Credit Note) · ใบแจ้งหนี้ (Invoice) · ใบรับ (Receipt) · ใบส่งของ (Delivery Slip) แต่ละแบบมีรหัสนำหน้าชื่อ ให้เลือกตามที่ผู้ให้บริการ e-Tax ของบริษัทกำหนด

## ส่วนที่ 2: ค่าตั้งการเชื่อมต่อ (แท็บ 8.e-Tax INET)
ช่องที่มี: Authorization Code · API Key (ทั้งสองช่องแสดงเป็นจุดปิดไว้) · แนบไฟล์ PDF (PDF Attach) · โหมดทดสอบ (UAT Mode) · Email สำหรับทดสอบ UAT (กรอกได้เมื่อติ๊กโหมดทดสอบ)
ขอรหัสและคีย์จากผู้ให้บริการ e-Tax ของบริษัทเอง และไม่ควรส่งต่อให้ผู้อื่น

## ข้อจำกัด
- ตัวเลือกทั้งสองส่วนนี้มีบนจอและบันทึกได้ แต่รุ่นปัจจุบันยังไม่มีผล ระบบยังไม่ได้นำไปส่งเอกสารจริง และไม่ได้ใช้กรองรายการในเมนู ส่งข้อมูล e-Tax → [[ts-etax-send-menu-no-send]]
- เมื่อบันทึกรูปแบบเอกสาร ค่า e-Tax เดิมของรูปแบบนั้นจะถูกแทนที่ด้วยค่าบนจอทั้งชุด
- ประเภทเอกสารที่ถูกต้องตามกฎหมาย: ปรึกษาผู้สอบบัญชีหรือผู้ให้บริการ e-Tax
