# กำหนดรายละเอียดบริษัท

**ใช้เมื่อ:** เริ่มใช้โปรแกรมครั้งแรก หรือต้องแก้ชื่อ ที่อยู่ เลขประจำตัวผู้เสียภาษีของกิจการ ข้อมูลนี้ใช้เป็นหัวเอกสารและรายงาน
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรายละเอียดบริษัท (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin เท่านั้น (ดู [[ts-common-no-permission]]) · เริ่มใช้งานวันแรกดู [[start-first-day]]

หน้านี้มีข้อมูลบริษัทเพียงชุดเดียว ไม่มีรายการให้เลือกหลายแถว

## ขั้นตอน
1. เปิดเมนู "กำหนดรายละเอียดบริษัท" รอข้อความ "กำลังโหลดข้อมูลบริษัท..." หายไป
2. กดแก้ไข แล้วกรอกส่วนที่ 1 "ข้อมูลบริษัท"
3. เลื่อนลงกรอกส่วนที่ 2 "ข้อมูลอย่างละเอียด (ที่อยู่อย่างละเอียด)" เช่น เลขที่ ซอย ถนน ตำบล อำเภอ จังหวัด รหัสไปรษณีย์
4. ถ้าต้องการ ปักตำแหน่งสำนักงานใหญ่บนแผนที่ในกล่อง "ตำแหน่งสำนักงานใหญ่ / บริษัท"
5. กดบันทึก ระบบแจ้ง "บันทึกข้อมูลเสร็จเรียบร้อย โปรแกรมจะปิดหน้าจอนี้ให้" แล้วปิดหน้าจอให้เอง

## ช่องสำคัญที่ต้องกรอก

| ชื่อ (ภาษาอังกฤษ) | ชื่อบริษัทภาษาอังกฤษ | ใช้กับแบบฟอร์มสองภาษา |

## บันทึกแล้วระบบทำอะไรให้
- เก็บข้อมูลบริษัทชุดใหม่แทนชุดเดิมทั้งชุด (ไม่เก็บประวัติของค่าเก่า)
- ปิดหน้าจอให้เองหลังบันทึก
- ข้อมูลนี้ถูกนำไปใช้เป็นหัวเอกสารและรายงาน

## แก้ไข ยกเลิก พิมพ์
- แก้ไขได้โดยเปิดเมนูเดิมแล้วแก้ใหม่ ถ้าปิดหน้าจอทั้งที่ยังแก้ไม่บันทึก ระบบถาม "มีการแก้ไขปรับปรุง ต้องการออกจากหน้าจอนี้หรือไม่"
- ผู้ใช้ที่ไม่มีสิทธิ์แก้ไข (เช่น สมาชิกทั่วไป) เปิดดูได้อย่างเดียว

## ปัญหาที่พบบ่อย
- ขึ้น "ข้อมูลไม่สมบูรณ์ : ..." แปลว่าช่องบังคับยังว่าง กรอกให้ครบแล้วกดบันทึกใหม่
- ขึ้นข้อความ ไม่มีสิทธิ์ ... ให้ติดต่อผู้ดูแลระบบ (Admin) ดู [[ts-common-no-permission]]
- ไม่แน่ใจว่าต้องใช้เลขผู้เสียภาษีหรือสาขาแบบไหน ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร
