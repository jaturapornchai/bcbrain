# บันทึกทะเบียนรถลูกค้าและเลขตัวถัง (VIN) ใน AutoCare

**ใช้เมื่อ:** มีลูกค้าใหม่ ต้องการเก็บข้อมูลรถ เจ้าของ ขนาดยาง และกำหนดเช็กระยะ เพื่อเปิดใบรับรถได้เร็วในครั้งต่อไป
**เมนู:** AutoCare › ข้อมูลหลักศูนย์บริการ › "ทะเบียนรถยนต์ & VIN"
**ต้องมีก่อน:** ลูกค้าในระบบบัญชี (ลูกหนี้) ถ้าต้องการให้บิลออกชื่อลูกค้าจริง

## ขั้นตอน
1. เปิดเมนู "ทะเบียนรถยนต์ & VIN" ตารางซ้ายคือรถทั้งหมด
2. กด "เพิ่มใหม่"
3. กรอกหมวด "ข้อมูลทะเบียนรถยนต์และเลขตัวถัง (VIN)": ทะเบียนรถ จังหวัด เลขตัวถัง ประเภทขุมพลัง ยี่ห้อรถ รุ่นรถยนต์ ปีรุ่นรถ (ค.ศ.) สีรถ เลขไมล์สะสม (กม.)
4. กรอกหมวด "ข้อมูลเจ้าของรถและลูกหนี้": รหัสลูกค้า (กดปุ่มค้นหาเลือกจากลูกหนี้ในระบบบัญชี) ชื่อเจ้าของรถ / บริษัท เบอร์โทรศัพท์มือถือ LINE OA ID ระดับสมาชิก คะแนนสะสม
5. ถ้าเป็นรถบริษัท ติ๊ก "เป็นรถบริษัท / ลูกหนี้ Fleet" แล้วใส่ชื่อบริษัท
6. หมวด "ข้อมูลยางรถยนต์และกำหนดเช็กระยะอัตโนมัติ": ขนาดยางล้อหน้า ขนาดยางล้อหลัง สัปดาห์ผลิตยางล่าสุด (DOT) บริษัทประกันภัยรถยนต์ วันหมดอายุ พ.ร.บ. วันหมดอายุภาษีป้ายวงกลม วันหมดอายุประกันภัย
7. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ทะเบียนรถ | เช่น 1กก-1234 | บังคับ ระบบแปลงเป็นตัวพิมพ์ใหญ่ และห้ามซ้ำ |
| ยี่ห้อรถ / รุ่นรถยนต์ | ตามจริง | บังคับ |
| ชื่อเจ้าของรถ / บริษัท | ชื่อลูกค้า | บังคับ |
| เลขตัวถัง (VIN 17 หลัก) | จากเล่มทะเบียน | **ควรกรอกเอง** ถ้าเว้นว่างระบบใส่เลขตัวอย่างให้ และหน้าจอไม่ตรวจว่าครบ 17 หลัก |
| กำหนดสลับยางถัดไป / ถ่ายน้ำมันเครื่องถัดไป (กม.) | เลขไมล์ที่ต้องเช็ก | เว้นว่างระบบตั้งให้ = เลขไมล์ปัจจุบัน + 10,000 กม. |
| ระดับสมาชิก | MEMBER, SILVER, GOLD, PLATINUM, FLEET VIP (ลูกหนี้องค์กร) | เป็นป้ายระดับ ไม่ได้ลดราคาอัตโนมัติ |

## บันทึกแล้วระบบทำอะไรให้
- เก็บข้อมูลรถไว้ใช้ตอนเปิดใบรับรถ
- ไม่ได้สร้างลูกค้าในระบบบัญชีให้ ต้องมีรหัสลูกค้าอยู่แล้ว
- ไม่ลงบัญชี

## แก้ไข ลบ
- กด "แก้ไข" แก้ข้อมูลได้ ยกเว้นช่อง "ทะเบียนรถ" ที่เปลี่ยนไม่ได้
- ลบ: ติ๊กเลือกรถ (เลือกหลายคันได้) แล้วกด "ลบ" จะมีข้อความ "ต้องการลบ [ทะเบียน] จริงหรือไม่" ลบแล้วกู้ไม่ได้ ใบงานเดิมไม่ถูกลบ
