# กำหนดรหัสจังหวัด / อำเภอ / ตำบล

**ใช้เมื่อ:** ต้องมีรายชื่อจังหวัด อำเภอ ตำบล และรหัสไปรษณีย์ไว้เลือกในที่อยู่ลูกค้า เจ้าหนี้ และเอกสาร
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรหัสจังหวัด / อำเภอ / ตำบล (ไม่จำกัดเฉพาะ Admin)
**ต้องมีก่อน:** สิทธิ์เพิ่ม/แก้ไขข้อมูลในหน้านี้ · เริ่มต้นดู [[start-first-day]]

## ขั้นตอนที่ 1 ดึงรายชื่อมาตรฐาน (แนะนำตอนเริ่มใช้)
1. เปิดเมนู ถ้ายังว่างจะขึ้น "ยังไม่มีข้อมูลจังหวัดในฐานข้อมูล"
2. กดปุ่ม "ดึงจังหวัดอัตโนมัติ" หน้าต่างชื่อ "ดึงรายชื่อจังหวัด / อำเภอ / ตำบล มาตรฐานอัตโนมัติ (ครบ 77 จังหวัด)" เปิดขึ้น
3. ติ๊กจังหวัดที่ต้องการ หรือกด "เลือกทั้งหมด" (ล้างด้วย "ยกเลิกทั้งหมด") ดูจำนวนที่ "เลือกแล้ว N จังหวัด"
4. กด "นำเข้าข้อมูล (N จังหวัด)" ถ้าไม่ติ๊กเลยขึ้น "กรุณาเลือกจังหวัดอย่างน้อย 1 จังหวัด"
5. สำเร็จขึ้น "ดึงรายชื่อจังหวัดอัตโนมัติสำเร็จ" และ "นำเข้าข้อมูลมาตรฐานเรียบร้อย: N จังหวัด · N อำเภอ · N ตำบล" ถ้าไม่สำเร็จขึ้น "ดึงข้อมูลไม่สำเร็จ"

ชุดมาตรฐานมีครบ 77 จังหวัด 928 อำเภอ/เขต และ 7,436 ตำบล/แขวง พร้อมรหัสไปรษณีย์และพิกัด

## ขั้นตอนที่ 2 เพิ่มหรือแก้เอง
1. หน้าจอเป็นผัง "ผังโครงสร้าง จังหวัด / อำเภอ / ตำบล" ค้นหาได้จากช่อง "ค้นหารหัส / ชื่อจังหวัด / อำเภอ / ตำบล / รหัสไปรษณีย์..." และมีปุ่ม กางจังหวัด, ขยายทั้งหมด, ยุบทั้งหมด
2. เพิ่มจังหวัดด้วย "เพิ่มจังหวัด" เพิ่มอำเภอด้วย "+อำเภอ" (ต้องเลือกจังหวัดก่อน) เพิ่มตำบลด้วย "+ตำบล" (ต้องเลือกอำเภอก่อน)
3. กรอกช่องแล้วบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสจังหวัด | เช่น 10 | ห้ามซ้ำ ขึ้น 'รหัสจังหวัด "..." มีอยู่ในระบบแล้ว' |
| รหัสอำเภอ | เช่น 1001 | ห้ามซ้ำในจังหวัดเดียวกัน |
| รหัสตำบล | เช่น 100101 | ห้ามซ้ำในอำเภอเดียวกัน |
| รหัสไปรษณีย์ | เลข 5 หลัก | มีเฉพาะระดับตำบล |
| ชื่อ (ไทย) | ชื่อภาษาไทย | ต้องกรอก ไม่งั้นขึ้น "กรุณาระบุชื่อ (ภาษาไทย)" |
| ชื่อภาษาอังกฤษ | ชื่ออังกฤษ | ไม่บังคับ |
| ละติจูด, ลองจิจูด | พิกัด | ไม่บังคับ |

## บันทึกแล้วระบบทำอะไรให้
- รายการใหม่ให้เลือกในช่องที่อยู่ของทะเบียนต่างๆ และ [[howto-setup-company-profile]]
- การดึงอัตโนมัติจะเขียนทับจังหวัดที่ติ๊กใหม่ทั้งชุด ชื่อไทย/อังกฤษถูกเขียนทับด้วยชื่อมาตรฐาน แต่พิกัดที่เคยกรอก รหัสไปรษณีย์ที่มีอยู่ และสถานะของรายการเดิมจะถูกเก็บไว้
- จังหวัดที่ไม่ได้ติ๊กไม่ถูกแตะต้อง

## แก้ไข ยกเลิก พิมพ์
- แก้ไข: คลิกรายการในผัง แก้แล้วบันทึก
- ลบ: ขึ้น "ยืนยันการลบข้อมูล" ถ้าลบจังหวัดหรืออำเภอ ข้อความบอก "พร้อมอำเภอและตำบลภายใต้..." แปลว่าลูกๆ ถูกลบไปด้วย ถ้าลบไม่สำเร็จขึ้น "ลบไม่สำเร็จ"

## ปัญหาที่พบบ่อย
- ปุ่มเพิ่มอำเภอ/ตำบลกดไม่ได้หรือขึ้น "กรุณาเลือกจังหวัด" / "กรุณาเลือกอำเภอ/เขต": เลือกระดับแม่ในผังก่อน
- ชื่อที่แก้เองหายหลังดึงอัตโนมัติ: การดึงเขียนทับชื่อ ตั้งชื่อเองเสร็จแล้วอย่าดึงจังหวัดนั้นซ้ำ
- ไม่มีสิทธิ์นำเข้า: ต้องมีสิทธิ์เพิ่มและแก้ไข ดู [[ts-common-no-permission]]
