# แก้ไขหรือลบเอกสารขายที่บันทึกไปแล้ว

**ใช้เมื่อ:** บันทึกเอกสารขายไปแล้วพบว่าผิด อยากแก้ตัวเลข/รายการ หรือลบทิ้ง
**เมนู:** หน้าจอเอกสารนั้นๆ ในเมนู ขาย (ปุ่ม "แก้ไข" และ "ลบ" บนแถบเครื่องมือ)
**ต้องมีก่อน:** สิทธิ์แก้ไข/ลบในหน้าจอนั้น ([[ts-common-no-permission]])

## ขั้นตอน (แก้ไข)
1. เปิดหน้าจอเอกสาร เลือกเอกสารจากรายการด้านซ้าย
2. กดปุ่ม "แก้ไข" แก้ข้อมูลที่ต้องการ (เลขที่เอกสารแก้ไม่ได้หลังบันทึก)
3. กด "บันทึก" ระบบขึ้น "บันทึกเอกสาร ... เรียบร้อยแล้ว" และคำนวณสต็อก ยอดลูกหนี้ และการลงบัญชีใหม่ให้
- ถ้าเลือกเอกสารอื่นทั้งที่ยังไม่บันทึก ระบบถาม "มีการเปลี่ยนแปลงข้อมูลที่ยังไม่ได้บันทึก ต้องการสลับรายการหรือไม่?"

## ขั้นตอน (ลบ)
1. เลือกเอกสาร กดปุ่ม "ลบ"
2. ระบบถาม "ยืนยันการลบเอกสาร ... ?" กดยืนยัน
3. ระบบขึ้น "ลบเอกสาร ... เรียบร้อยแล้ว" เอกสารหายจากระบบ ไม่มีใบยกเลิกเก็บไว้
- ถ้าเป็นเอกสารที่ส่งให้ลูกค้าไปแล้ว ใช้ "ยกเลิก" แทนเพื่อเก็บประวัติ ([[faq-sale-cancel-vs-delete]])

## เมื่อไรแก้/ลบไม่ได้ (ขึ้น "ห้ามแก้ไข หรือลบข้อมูล")
| เอกสาร | ล็อกเมื่อ |
|---|---|
| ใบเสนอราคาขาย | อนุมัติแล้ว หรือถูกดึงไปทำใบสั่งจอง/ใบสั่งขาย/ใบขาย (ยกเว้นเปิด "แก้ไขใบเสนอราคาได้ตลอดเวลา") |
| ใบสั่งจองสินค้า / ใบสั่งขายสินค้า | อนุมัติแล้ว หรือถูกดึงไปใช้ หรือดึงครบแล้ว |
| ขายสินค้า/บริการ | มีใบลดหนี้/เพิ่มหนี้อ้างอิง, เช็คในบิลถูกนำฝาก/ผ่านแล้ว, บัตรเครดิตในบิลถูกบันทึกขึ้นเงินแล้ว, ออกใบกำกับภาษีเต็มรูปจากบิลนี้แล้ว, ถูกวางบิลหรือรับชำระแล้ว |
| รับคืนสินค้า/ลดหนี้ขาย, เพิ่มหนี้ขาย/ราคาผิด | ถูกวางบิลหรือรับชำระแล้ว |
| รับเงินมัดจำ / รับเงินล่วงหน้า | ถูกหักในใบขายหรือถูกคืนเงินแล้ว |
| ทุกเอกสาร | ถูกยกเลิกแล้ว หรือเป็นเอกสารสำเนา |

## ถ้าต้องแก้เอกสารที่ล็อกแล้ว
1. หาเอกสารปลายทางที่ใช้มันอยู่ (ใบเสร็จ ใบวางบิล ใบลดหนี้ ฯลฯ)
2. ยกเลิกหรือแก้เอกสารปลายทางก่อน ตามลำดับย้อนกลับ ([[howto-sale-cancel-docs]], [[howto-ar-cancel-docs]])
3. แล้วจึงแก้เอกสารต้นทาง
- หรือไม่แก้ใบเดิม แต่ออกใบลดหนี้/เพิ่มหนี้ปรับยอดแทน ([[howto-sale-credit-note]], [[howto-sale-debit-note]])

## บันทึกแล้วระบบทำอะไรให้
- ทุกครั้งที่บันทึกแก้ไข ระบบคำนวณสต็อกและสร้างรายการลงบัญชีของเอกสารนั้นใหม่ทั้งใบ
- ลบเอกสาร ระบบถอนสต็อก ยอดลูกหนี้ และรายการบัญชีของใบนั้นออก

## ปัญหาที่พบบ่อย
- "ห้ามแก้ไข หรือลบข้อมูล" → [[ts-sale-cannot-edit]]
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบได้" → มีเอกสารอื่นใช้ใบนี้อยู่ ต้องจัดการเอกสารนั้นก่อน
- "เอกสาร ... ถูกนำไปใช้/รับคืนแล้วโดยเอกสาร ... ลบไม่ได้" (เงินมัดจำ/ล่วงหน้า) → [[ts-sale-cannot-edit]]
- แก้เอกสารในงวดที่ปิดแล้ว → [[ts-common-period-closed]]
