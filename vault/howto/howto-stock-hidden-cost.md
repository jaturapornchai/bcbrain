# ประมวลผลเฉลี่ยต้นทุนแฝง (ค่าขนส่ง ค่านำเข้า เข้าต้นทุนสินค้า)

**ใช้เมื่อ:** มีค่าใช้จ่ายที่ควรรวมในต้นทุนสินค้า เช่น ค่าขนส่ง ค่าชิปปิ้ง อากรขาเข้า แล้วอยากเฉลี่ยเข้าสินค้าในบิลซื้อ
**เมนู:** สินค้า › ประมวลผลเฉลี่ยต้นทุนแฝง (บางรุ่นอาจไม่เห็นเมนูนี้ สอบถามฝ่ายขาย)
**ต้องมีก่อน:** บิลซื้อ/รับสินค้าที่จะปันส่วน และเอกสารค่าใช้จ่าย (ตั้งหนี้อื่น ๆ หรือ ค่าใช้จ่ายอื่น ๆ) ([[howto-buy-overview]], [[howto-ap-overview]])

## ขั้นตอน
1. กด เพิ่มใหม่ กรอกวันที่และหมายเหตุ (เลขที่เว้นว่างได้ ระบบออกให้)
2. ตาราง เอกสารค่าใช้จ่ายอ้างอิง (ตั้งหนี้ค่าขนส่ง / ค่าชิปปิ้ง / ค่าใช้จ่ายอื่น): เลือกเอกสาร ตั้งหนี้อื่น ๆ(เจ้าหนี้) หรือ ค่าใช้จ่ายอื่น ๆ หรือกรอกช่อง ค่าขนส่ง/ระวางเรือ-รถ, ค่าประกันภัยขนส่ง, อากรขาเข้าศุลกากร, ค่าชิปปิ้ง/พิธีการ/ท่าเรือ ในส่วน ข้อมูลค่าขนส่ง & นำเข้าสินค้าจากต่างประเทศ
3. ตาราง เอกสารซื้อ/รับสินค้าเข้าคลังที่ต้องการปันส่วนต้นทุนแฝง: เลือก ซื้อสินค้า, รับสินค้า หรือ รับสินค้าสำเร็จรูป
4. เลือก คำนวณต้นทุนแฝงจาก (มูลค่าสุทธิ / มูลค่าก่อนภาษี) และ เฉลี่ยต้นทุนตาม
5. กด ประมวลผล แล้วดูคอลัมน์ ต้นทุนแฝงปันส่วน และ ต้นทุนใหม่/หน่วย ของแต่ละสินค้า (ปุ่มนี้แค่คำนวณให้ดู ยังไม่บันทึก)
6. กด บันทึก

## วิธีเฉลี่ย (เฉลี่ยต้นทุนตาม)
| ตัวเลือก | แบ่งค่าใช้จ่ายตาม |
|---|---|
| มูลค่าสินค้า (FOB/Value) | สัดส่วนมูลค่าของแต่ละแถว |
| จำนวนหน่วย (Qty) | สัดส่วนจำนวน |
| น้ำหนักจริง/หน่วยขนาน (Weight kg) | จำนวนหน่วยขนานของแถว ถ้าแถวไม่มี ใช้จำนวนแทน |
| เท่ากันทุกรายการ (Equal) | แบ่งเท่ากันทุกแถว |

เศษสตางค์จากการปัดถูกใส่ไว้ที่แถวที่มีสัดส่วนมากที่สุด ยอดรวมจึงเท่ากับค่าใช้จ่ายพอดี

## บันทึกแล้วระบบทำอะไรให้
- สร้างเอกสารต้นทุนแฝง และสร้างใบปรับปรุงสต็อก (เพิ่ม) แบบเพิ่มเฉพาะมูลค่าให้เอง จำนวนสินค้าไม่เปลี่ยน
- ต้นทุนเฉลี่ยของสินค้าสูงขึ้นตามส่วนที่ปันมา มีผลกับต้นทุนขายหลังจากวันที่นั้น
- ใบปรับปรุงที่สร้างลงบัญชีแบบใบปรับปรุงเพิ่ม ([[faq-stock-hidden-cost-effect]])

## แก้ไข ลบ
- แก้หรือลบได้ที่เมนูนี้เท่านั้น ลบแล้วระบบลบใบปรับปรุงที่อ้างอิงและคำนวณต้นทุนใหม่
- ใบปรับปรุงที่เมนูนี้สร้าง แก้ที่เมนูปรับปรุงสต็อกไม่ได้ ([[ts-stock-doc-locked]])
- เมนูนี้ยังไม่ตรวจงวดบัญชีที่ปิดแล้ว ถ้าลูกค้าบันทึกหรือลบเอกสารลงวันที่ในงวดที่ปิดแล้ว ให้ส่งต่อเจ้าหน้าที่

## ปัญหาที่พบบ่อย
- "กรุณาเลือกเอกสารค่าใช้จ่ายและเอกสารซื้ออย่างน้อยอย่างละ 1 ใบ" → ต้องมีเอกสารซื้อ และมีเอกสารค่าใช้จ่ายหรือค่านำเข้าที่กรอก
- "เอกสารซื้อที่เลือกไม่มีรายการสินค้า" → เลือกบิลที่มีสินค้า
- "ไม่พบเอกสาร ... หรือเอกสารถูกยกเลิกแล้ว" → เลือกเอกสารที่ยังใช้งาน
- "เอกสารซ้ำ: ..." → ลบแถวที่ซ้ำ
- "ค่าขนส่ง ค่าประกันภัย อากรขาเข้า และค่าพิธีการศุลกากร ต้องไม่ติดลบ" → แก้ตัวเลข
