# ลูกค้าคืนสินค้า หรือลดราคาให้ลูกค้า (รับคืนสินค้า/ลดหนี้ขาย)

**ใช้เมื่อ:** ลูกค้าคืนสินค้าที่ซื้อไป หรือเราลดราคาให้หลังเปิดบิลแล้ว ต้องออกใบลดหนี้ (เอกสารลดยอดที่ลูกค้าค้างเรา หรือคืนเงินให้ลูกค้า)
**เมนู:** ขาย › รับคืนสินค้า/ลดหนี้ขาย
**ต้องมีก่อน:** ใบขายเดิม ([[howto-sale-invoice]])

## เลือกประเภทให้ถูก (ช่อง "ประเภทการรับคืน")
| ประเภทการรับคืน | ใช้เมื่อ | สต็อก | เงิน |
|---|---|---|---|
| รับคืนจากขายเงินเชื่อ | คืนของ บิลเดิมขายเชื่อ | รับสินค้ากลับเข้าสต็อก | ลดยอดลูกหนี้ |
| รับคืนจากขายเงินสด | คืนของ บิลเดิมขายสด | รับสินค้ากลับเข้าสต็อก | คืนเงินในแท็บรับ/จ่ายชำระ |
| ลดหนี้จากขายเงินเชื่อ (ไม่กระทบสต๊อก) | ลดราคา ไม่มีของคืน | ไม่กระทบ | ลดยอดลูกหนี้ |
| ลดหนี้จากขายเงินสด (ไม่กระทบสต๊อก) | ลดราคา บิลเดิมขายสด | ไม่กระทบ | คืนเงินในแท็บรับ/จ่ายชำระ |
| รับคืนจากขายสินค้าเงินเชื่อ (สินค้าบริการ) | คืนค่าบริการ ขายเชื่อ | ไม่กระทบ | ลดยอดลูกหนี้ |
| รับคืนจากขายสินค้าเงินสด (สินค้าบริการ) | คืนค่าบริการ ขายสด | ไม่กระทบ | คืนเงินในแท็บรับ/จ่ายชำระ |

## ขั้นตอน
1. เปิด ขาย › รับคืนสินค้า/ลดหนี้ขาย กด "เพิ่มใหม่" ใส่วันที่ เลขที่เอกสาร
2. เลือก "ลูกหนี้/ลูกค้า" และ "ภาษี" ให้ตรงกับใบขายเดิม แล้วเลือก "ประเภทการรับคืน"
3. กด "ดึงเอกสาร" เลือกใบขายเดิม ระบบดึงรายการสินค้ามา ([[howto-sale-pull-ref-doc]])
4. แก้จำนวนให้เหลือเฉพาะที่คืน (หรือแก้มูลค่าที่ลด)
5. ใส่ "สาเหตุ" (ช่องขึ้นว่า "สาเหตุการเพิ่ม/ลดหนี้...") และเลขที่ใบกำกับภาษีของใบลดหนี้
6. ถ้าเป็นประเภทเงินสด ใส่การคืนเงินที่แท็บ "การรับ/จ่ายชำระเงิน" ([[howto-sale-cash-payment]])
7. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ประเภทการรับคืน | 1 ใน 6 แบบด้านบน | กำหนดว่าคืนสต็อก/คืนเงินหรือไม่ |
| เอกสารอ้างอิง | ใบขายเดิม | ใช้ปุ่ม "ดึงเอกสาร" |
| สาเหตุ | เหตุผลที่ลดหนี้ | |
| เลขที่ใบกำกับภาษี / ลงวันที่ | เลขของใบลดหนี้ | บังคับเมื่อเปิด "ป้อนเลขที่ใบกำกับภาษีทุกครั้ง" |
| จำนวน / ราคา | ที่คืนจริง | ห้ามเกินใบขายเดิม |

## บันทึกแล้วระบบทำอะไรให้
- **สต็อก:** เฉพาะประเภท "รับคืนจากขายเงินเชื่อ" และ "รับคืนจากขายเงินสด" ที่รับสินค้ากลับเข้าสต็อก
- **ลูกหนี้:** ประเภทเงินเชื่อ ลดยอดค้างของลูกค้า ([[faq-ar-partial-payment]])
- **ภาษี:** สร้างรายการลดภาษีขาย (ยกเว้นประเภทภาษี "ไม่กระทบภาษี")
- **ลงบัญชีอัตโนมัติ:** เดบิต ขายสินค้า และ ภาษีขาย / เครดิต ลูกหนี้การค้า (เงินเชื่อ) หรือ เงินสด/เงินฝากธนาคาร ตามช่องทางที่คืน (เงินสด)
- ใบขายเดิมที่ถูกอ้างอิงด้วยใบลดหนี้ จะแก้ไข/ลบไม่ได้

## แก้ไข ยกเลิก พิมพ์
- แก้ได้จนกว่าใบลดหนี้จะถูกนำไปวางบิลหรือรับชำระ ([[howto-sale-edit-delete]])
- ยกเลิก: ขาย › ยกเลิกเอกสารขายและเงินมัดจำรับ › ยกเลิกรับคืนสินค้า/ลดหนี้ขาย ([[howto-sale-cancel-docs]])
- พิมพ์ใบลดหนี้: ปุ่ม "พิมพ์ฟอร์ม / เลือกรูปแบบ"

## ปัญหาที่พบบ่อย
- "ส่งคืนเกินจำนวน : ..." / "ส่งคืนเกินมูลค่า : ..." → คืนเกินใบขายเดิม ([[ts-sale-return-over]])
- "สถานะ ลูกค้าปิดการใช้งาน : ..." → [[ts-sale-customer-inactive]]
- "กรุณาป้อนเลขที่ใบกำกับภาษี" → [[ts-sale-required-fields]]
- เรื่องเงื่อนไขการออกใบลดหนี้ตามกฎหมาย ให้ปรึกษาผู้สอบบัญชี/สรรพากร
