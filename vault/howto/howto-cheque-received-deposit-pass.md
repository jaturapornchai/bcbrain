# นำเช็ครับฝากธนาคาร และบันทึกเช็คผ่าน

**ใช้เมื่อ:** นำเช็คที่รับจากลูกค้าไปฝากธนาคาร (นำฝาก) และเมื่อธนาคารเรียกเก็บเงินได้แล้ว (เช็คผ่าน)
**เมนู:** เงินสด/ธนาคาร › ทะเบียนเช็ครับและจัดการเช็ครับ › บันทึกนำฝาก (เช็ครับ) / บันทึกเช็คผ่าน (เช็ครับ)
**ต้องมีก่อน:** เช็คอยู่ในทะเบียนเช็ครับ ([[howto-cheque-received-register]]) และสมุดเงินฝาก ([[howto-bank-passbook]])

## ขั้นตอน (นำฝาก)
1. เปิด บันทึกนำฝาก (เช็ครับ) กด "เพิ่มใหม่" ใส่วันที่นำฝากและเลขที่เอกสาร
2. ในตาราง ช่องแรก "สมุดบัญชี" เลือกสมุดเงินฝากที่นำเช็คไปฝาก (ระบบลงบัญชีตามสมุดในบรรทัดนี้ ช่อง "สมุดบัญชีธนาคาร:" ที่หัวเอกสารใส่สมุดเดียวกันไว้ได้)
3. ช่อง "เลขที่เช็ค" ในบรรทัดเดียวกัน กดปุ่ม "ค้นหาเช็ค" เลือกเช็คที่จะฝาก (แสดงเฉพาะเช็คในมือหรือเช็คที่ถูกคืนมา)
4. ฝากหลายใบในเอกสารเดียวได้ ใบละบรรทัด กด "เพิ่มบรรทัดรายการใหม่"
5. กด "บันทึก"

## ขั้นตอน (เช็คผ่าน)
1. เปิด บันทึกเช็คผ่าน (เช็ครับ) กด "เพิ่มใหม่" ใส่วันที่เช็คผ่าน
2. ในตาราง ช่อง "สมุดบัญชี" เลือกสมุดเงินฝากเดียวกับตอนนำฝาก
3. กด "ค้นหาเช็ค" เลือกเช็คที่นำฝากไว้ (ถ้าเลือกสมุดในบรรทัดไว้ก่อน จะแสดงเฉพาะเช็คที่นำฝากเข้าสมุดนั้น)
4. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| สมุดบัญชี | บัญชีที่ฝากเช็ค | นำฝากกับผ่านต้องสมุดเดียวกัน |
| เลขที่เช็ค | เลือกจากหน้าค้นหาเช็ค | พิมพ์เองไม่ได้ ต้องเลือกจากทะเบียน |
| วันที่เอกสาร | วันนำฝาก / วันเช็คผ่าน | |

## บันทึกแล้วระบบทำอะไรให้
- นำฝาก: สถานะเช็คเป็น "เช็คนำฝาก" ลงบัญชี เดบิต เงินฝากธนาคาร คู่กับ เครดิต เช็ครับล่วงหน้า
- เช็คผ่าน: สถานะเป็น "เช็คผ่าน" ลงบัญชี เดบิต เงินฝากธนาคาร คู่กับ เครดิต เช็ครับระหว่างเรียกเก็บ และระบบปรับรายการของใบนำฝากเป็น เดบิต เช็ครับระหว่างเรียกเก็บ ให้อัตโนมัติ ([[faq-cheque-in-transit-account]])
- บัญชี "เช็ครับระหว่างเรียกเก็บ" ระบบสร้างในผังบัญชีให้เองถ้ายังไม่มี

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกด้วย บันทึกยกเลิกเช็คผ่าน แล้วค่อย บันทึกยกเลิกนำฝากเช็ค (ย้อนจากขั้นล่าสุด) ([[howto-bank-cancel-docs]])
