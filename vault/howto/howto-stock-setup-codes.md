# ตั้งรหัสกลุ่มสินค้า หมวด ยี่ห้อ และรหัสพื้นฐานอื่นของสินค้า

**ใช้เมื่อ:** อยากจัดกลุ่มสินค้าไว้ค้นหาและดูรายงานแยกกลุ่ม หรือเตรียมรายการให้เลือกในหน้าจอสินค้า
**เมนู:** เริ่มต้น › ตั้งค่าระบบสินค้าคงคลัง › (เมนูกำหนดต่างๆ)
**ต้องมีก่อน:** ไม่มี ตั้งก่อนสร้างสินค้าจะสะดวกที่สุด

## เมนูในกลุ่มนี้
| เมนู | ใช้ทำอะไร |
|---|---|
| กำหนดกลุ่มสินค้าหลัก / ย่อย / ย่อย2 | จัดกลุ่มสินค้าเป็นชั้น (กลุ่มย่อยต้องเลือกกลุ่มหลักก่อน) |
| กำหนดหมวดสินค้า, ยี่ห้อ, รุ่น, สี, ขนาด, รูปแบบ, เกรด, รูปทรง, ระดับ | รายการให้เลือกในข้อมูลสินค้า |
| กำหนดชื่อมิติสินค้า / กำหนดมิติสินค้า | ตั้งมิติเพิ่มเติมของสินค้า |
| กำหนดผู้ผลิต | รายชื่อผู้ผลิต |
| กำหนดกลุ่มบัญชีสินค้า | เก็บ รหัสบัญชีรายได้ / รหัสบัญชีสินค้า / รหัสบัญชีต้นทุน ของกลุ่ม |
| กำหนดประเภทการเบิก, กำหนดสาเหตุการปรับปรุง, กำหนดเหตุผลการปิดสินค้า | รายการรหัสเหตุผลไว้เลือกใช้ |
| กำหนดพิกัดศุลกากร | รหัสพิกัดสินค้านำเข้า |

## ขั้นตอน
1. เปิดเมนูที่ต้องการ กดเพิ่ม
2. กรอก รหัส และ ชื่อ (ชื่อภาษาอังกฤษถ้ามี) แล้วบันทึก
3. ไปเลือกใช้รหัสเหล่านี้ในข้อมูลสินค้า ([[howto-stock-item-master]])

## บันทึกแล้วระบบทำอะไรให้
- รหัสพร้อมให้เลือกในหน้าจอสินค้าและใช้กรองรายงาน
- **ข้อควรรู้ เรื่องกลุ่มบัญชีสินค้า:** การลงบัญชีอัตโนมัติแบบปกติของเอกสารสินค้า ไม่ได้ดึงบัญชีจากกลุ่มบัญชีสินค้า ถ้าต้องการแยกบัญชีตามสินค้า ให้ใส่รหัสผังบัญชีในข้อมูลสินค้า และตั้งรูปแบบการลงบัญชีของเอกสารให้ดึงบัญชีตามสินค้า ([[faq-stock-gl-posting]])

## แก้ไข ยกเลิก พิมพ์
- แก้ชื่อได้ รหัสห้ามซ้ำ
- เมนูกลุ่มสินค้าหลัก / ย่อย / ย่อย2 หมวด ยี่ห้อ รุ่น สี ขนาด รูปแบบ เกรด รูปทรง และระดับ ลบรหัสที่ถูกใช้แล้วไม่ได้ จะขึ้นหน้าต่าง ไม่อนุญาตให้ลบ พร้อมเหตุผล เช่น "มีการใช้งานในข้อมูลสินค้าแล้ว"
- **ข้อควรรู้:** เมนูชื่อมิติสินค้า มิติสินค้า ผู้ผลิต กลุ่มบัญชีสินค้า ประเภทการเบิก สาเหตุการปรับปรุง เหตุผลการปิดสินค้า และพิกัดศุลกากร ระบบไม่ได้ตรวจว่ารหัสถูกใช้อยู่ กดลบแล้วลบได้เลย ก่อนลบให้ตรวจเองว่าไม่มีสินค้าหรือเอกสารใช้รหัสนั้น

## ปัญหาที่พบบ่อย
- "รหัส "..." มีอยู่ในระบบแล้ว กรุณาใช้รหัสอื่น" → เปลี่ยนรหัส
- "กรุณาระบุรหัส" / "กรุณาระบุชื่อ" → กรอกให้ครบ
- "คุณไม่มีสิทธิ์ "เพิ่มข้อมูลใหม่" ในหน้าจอนี้ กรุณาติดต่อผู้ดูแลระบบ (Admin)" → ([[ts-common-no-permission]])
