# กำหนดรายละเอียดสาขา

**ใช้เมื่อ:** กิจการมีหลายสาขา หรืออยากแยกเอกสารตามสาขา
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดรายละเอียดสาขา (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin · ติ๊ก "ใช้ระบบสาขา" ที่ [[howto-setup-company-profile]] · เริ่มต้นดู [[start-first-day]]

## ขั้นตอน
1. เปิดเมนู "กำหนดรายละเอียดสาขา" กด "เพิ่มใหม่"
2. กรอกรหัสและชื่อสาขา
3. เลือก "สถานประกอบการ" ว่าเป็นสำนักงานใหญ่หรือสาขา และใส่ "ลำดับที่สาขา"
4. กรอกที่อยู่ เบอร์โทร แล้วกดบันทึก (F12 หรือ Ctrl+S)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัส / ชื่อ / ชื่อภาษาอังกฤษ | รหัสสั้นและชื่อสาขา | รหัสห้ามซ้ำ |
| สถานประกอบการ | สำนักงานใหญ่ หรือ สาขา | |
| ลำดับที่สาขา | เลขลำดับของสาขา | ตามที่จดทะเบียน |
| ที่อยู่ 1, ที่อยู่ 2, โทรศัพท์, โทรสาร, หมายเหตุ | ข้อมูลติดต่อสาขา | |
| ละติจูด, ลองจิจูด | พิกัดแผนที่ | ไม่บังคับ |
| Serial เครื่องที่อนุญาตใช้งาน | หมายเลขเครื่องที่อนุญาตของสาขา | ใช้เมื่อกำหนดเครื่องเฉพาะสาขา |
| เบอร์โทรศัพท์แจ้งอนุมัติ, รหัสผู้อนุมัติ Sale Hub | ข้อมูลฝั่งงานอนุมัติ | กรอกเมื่อใช้งานส่วนนั้น |
| ยกเลิกการใช้งาน | ติ๊กเมื่อปิดสาขา | ใช้แทนการลบ |

## บันทึกแล้วระบบทำอะไรให้
สาขาใหม่ให้เลือกได้ในเอกสาร ในหน้าพนักงาน ([[howto-setup-staff]]) และในรูปแบบเลขที่เอกสาร ([[howto-setup-doc-format]])

## แก้ไข ยกเลิก พิมพ์
- แก้ไข: เลือกรายการ กด "แก้ไข" แล้วบันทึก
- ลบ: ยืนยัน "ต้องการลบรายการ ... หรือไม่?" ถ้าสาขาถูกใช้แล้วจะขึ้น "ไม่อนุญาตให้ลบ" พร้อมเหตุผล "มีการใช้งานในเอกสารสินค้าแล้ว" หรือ "มีการใช้งานในสมุดรายวันแล้ว" ให้ติ๊ก "ยกเลิกการใช้งาน" แทน

## ปัญหาที่พบบ่อย
- ลบสาขาไม่ได้: เหตุผลข้างบน ใช้ยกเลิกการใช้งาน
- ขึ้น "กรุณาระบุรหัส" หรือ "กรุณาระบุชื่อ": กรอกช่องบังคับให้ครบ
- ไม่มีสิทธิ์: ดู [[ts-common-no-permission]]
- เรื่องสถานะสำนักงานใหญ่/สาขาตามกฎหมาย ให้ปรึกษาผู้สอบบัญชีหรือสรรพากร
