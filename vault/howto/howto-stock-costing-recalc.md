# วิธีคิดต้นทุน ล็อกต้นทุน และคำนวณยอดสต๊อกและต้นทุนใหม่

ความถูกต้องของต้นทุนขายและมูลค่าสินค้าคงเหลือในงบการเงินขึ้นอยู่กับการตั้งค่าประเภทต้นทุนในทะเบียนสินค้า การบันทึกเอกสารตามลำดับเวลา และการประมวลผลคำนวณยอดสต๊อกใหม่เมื่อมีการแก้ไขหรือบันทึกเอกสารย้อนหลัง

## 1. ประเภทต้นทุนสินค้าที่มีให้เลือก

ในหน้าจอ **ข้อมูลสินค้า** ช่อง **ประเภทต้นทุน** เลือกได้ 6 รูปแบบ:

1. **1.ต้นทุนเฉลี่ย** — คำนวณต้นทุนถัวเฉลี่ยเคลื่อนที่ทุกครั้งที่มีรายการรับเข้า/จ่ายออกตามลำดับวันและเวลาเอกสาร
2. **2.ต้นทุน LOT FIFO** — ตัดต้นทุนตามลำดับล็อตที่เข้าก่อนออกก่อน
3. **3.ต้นทุน LOT กำหนดเอง** — ผู้ใช้เลือกล็อตและต้นทุนเฉพาะของล็อตนั้นตอนจ่ายออกเอง
4. **4.ต้นทุน FEFO (วันหมดอายุ)** — ตัดจ่ายตามลำดับวันหมดอายุก่อนหลัง
5. **5.ต้นทุนมาตรฐาน** — ใช้ราคาต้นทุนมาตรฐานที่กำหนดไว้ในแท็บ **3. ต้นทุนมาตรฐาน**
6. **6.ต้นทุนแบบพิเศษ 1** — ใช้สำหรับสินค้าที่คำนวณต้นทุนตามโครงสร้างเฉพาะของกิจการ

## 2. การล็อกต้นทุนรายบรรทัดเอกสาร

ในเอกสารรับเข้า จ่ายออก หรือปรับปรุงบางรายการที่ต้องการตรึงต้นทุนไว้ไม่ให้เปลี่ยนตามสูตรถัวเฉลี่ย:

- ในตารางรายการสินค้าของเอกสาร สามารถเปิดหน้าต่าง **ล็อกต้นทุน** ของบรรทัดนั้นได้
- เมื่อเปิดสถานะล็อกต้นทุนพร้อมระบุยอดต้นทุนที่กำหนดไว้ ระบบจะแสดงสถานะว่า **ล็อกต้นทุนอยู่ — ประมวลผลสต็อกจะใช้ต้นทุนนี้แทนต้นทุนเฉลี่ย** และเมื่อรันคำนวณสต๊อกใหม่ ระบบจะยึดมูลค่าที่ล็อกไว้สำหรับบรรทัดนั้น

## 3. เครื่องมือ "คำนวณยอดสต๊อกใหม่"

เมื่อมีการแก้ไข/ลบ/เพิ่มเอกสารซื้อ ขาย เบิก โอน ปรับปรุงย้อนหลัง หรือปรับอัตราส่วนหน่วยนับ ให้รันเครื่องมือที่ **สินค้า › คำนวณยอดสต๊อกใหม่** (รหัสเมนู **2050**) เพื่อเรียงลำดับความเคลื่อนไหวใหม่ทั้งหมดให้ยอดคงเหลือและต้นทุนถูกต้อง

หน้าจอแบ่งเป็น **4 ส่วนการทำงาน**:

### ส่วนที่ 1: คำนวณยอดคงเหลือและต้นทุนสินค้า (Stock Recal)
1. **ช่องคำสั่ง (Process Command)** — เลือกรันได้ทั้งระบบหรือจำกัดขอบเขตให้เร็วขึ้น:
   - **เว้นว่าง**: คำนวณใหม่ทุกสินค้าในฐานข้อมูล
   - **ระบุเลขที่เอกสาร**: ประมวลผลเฉพาะสินค้าที่อยู่ในเอกสารนั้น
   - **ระบุช่วงรหัสสินค้า**: ใช้เครื่องหมายทวิภาคคั่น (เช่น รหัสเริ่ม:รหัสสิ้นสุด)
   - **ระบุหลายรหัส**: ใช้เครื่องหมายจุลภาคคั่น (เช่น รหัส1,รหัส2)
2. ตัวเลือก **ตรวจสอบและปรับปรุง อัตราส่วนหน่วยนับ** — เมื่อติ๊กไว้ ระบบจะปรับค่าตัวตั้ง/ตัวหารของหน่วยนับในเอกสารเคลื่อนไหวให้ตรงกับตารางหน่วยนับล่าสุดในทะเบียนสินค้าก่อนคำนวณยอดและต้นทุน
3. กด **Start Process** แล้วรอจนแถบสถานะขึ้น **(Success)** (หากต้องการหยุดระหว่างทางกด **Stop Process**)

### ส่วนที่ 2: ตรวจสอบรายการเคลื่อนไหว (Check Transection)
- มีปุ่มคำนวณทบทวนรายละเอียดบรรทัดเอกสาร (มูลค่าก่อนภาษี ส่วนลด ภาษี และรายการโอนย้าย) ให้สอดคล้องกันทั้งเอกสาร

### ส่วนที่ 3: ตรวจสอบสถานะเอกสารอ้างอิง (Document Flow Process)
- **ตรวจสอบ Flow การอ้างอิงเอกสาร**: ตรวจและปรับสถานะการดึงอ้างอิงข้ามเอกสารให้ตรงกับความจริง
- **Check SO Doc Success Status**: ตรวจสถานะใบสั่งขายว่าตัดส่งครบแล้วหรือยัง

### ส่วนที่ 4: ตรวจสอบ Flow ตามคำสั่ง (Recheck Flow)
- สำหรับผู้ดูแลระบบระบุเลขที่เอกสารหรือคำสั่งเงื่อนไขเฉพาะจุดแล้วกด **Process** (จำกัดสิทธิ์เฉพาะระดับผู้ดูแลระบบ)

## 4. ปรับปรุงมูลค่าสินค้า Lot คงค้าง (ปัดเศษหรือล้างมูลค่าค้าง)

กรณีสินค้าแบบ **LOT** มีปริมาณคงเหลือเป็น 0 แล้ว แต่มูลค่าคงเหลือค้างอยู่ (เช่น ผลต่างทศนิยม หรือปรับต้นทุนย้อนหลัง) ให้ใช้เมนู **สินค้า › ตรวจนับสต็อกและปรับปรุงจากการตรวจนับ › ปรับปรุงมูลค่าสินค้า Lot คงค้าง** (รหัสเมนู **2048**):

1. เลือกวันที่ **ณ วันที่** และช่วงรหัสสินค้า (**สินค้าตั้งแต่ – ถึง**) แล้วกด **โหลดข้อมูล**
2. เลือกรายการ LOT ที่มีมูลค่าคงเหลือค้าง แล้วกำหนด **รูปแบบ ปรับเพิ่ม** และ **รูปแบบ ปรับลด**
3. กดบันทึกและยืนยันเพื่อสร้างเอกสารปรับปรุงมูลค่าให้เหลือ 0 พอดี

> [!TIP]
> หากมีค่าขนส่ง ค่านำเข้า หรืออากรขาเข้าที่ต้องบวกเพิ่มเข้าต้นทุนสินค้าที่ซื้อมาแล้ว ควรใช้เมนู **ประมวลผลเฉลี่ยต้นทุนแฝง** ใน [[howto-stock-hidden-cost]] แทนการปรับมือ ดูแนวทางแก้เมื่อพบปัญหาต้นทุน/ยอดคงเหลือเพี้ยนเพิ่มเติมใน [[ts-overview]]

## คำถามที่ลูกค้ามักถาม

- **BC Ai Account รองรับวิธีคิดต้นทุนสินค้าแบบไหนบ้าง?**
  เลือกกำหนดแยกตามรหัสสินค้าได้ **6 รูปแบบ** ในหน้าข้อมูลสินค้า ได้แก่ ต้นทุนเฉลี่ย (เคลื่อนที่), ต้นทุน LOT FIFO, ต้นทุน LOT กำหนดเอง, ต้นทุน FEFO (วันหมดอายุ), ต้นทุนมาตรฐาน และต้นทุนแบบพิเศษ 1
- **แทรกบิลซื้อ–ขายย้อนหลังหรือแก้เอกสารเก่าแล้วต้นทุนไม่ตรง ต้องรันคำนวณสต็อกใหม่ทั้งฐานเลยไหม?**
  เข้าเมนู **คำนวณยอดสต๊อกใหม่ (รหัสเมนู 2050)** โดยเลือกขอบเขตได้เองว่าจะเว้นว่างเพื่อรันทั้งระบบ หรือระบุเฉพาะเลขที่เอกสาร ช่วงรหัสสินค้า (รหัสเริ่ม:รหัสสิ้นสุด) หรือหลายรหัสคั่นด้วยลูกน้ำเพื่อให้ประมวลผลเร็วขึ้น
- **ถ้าต้องการตรึงต้นทุนของบางบรรทัดไม่ให้เปลี่ยนตามต้นทุนเฉลี่ยเวลาคำนวณสต็อกใหม่ ทำได้ไหม?**
  ได้ เปิดหน้าต่าง **ล็อกต้นทุน** บนบรรทัดรายการสินค้าในเอกสารนั้นและกำหนดมูลค่าต้นทุนไว้ เมื่อรันเมนู **2050** ระบบจะยึดมูลค่าที่ล็อกไว้สำหรับบรรทัดนั้นแทนต้นทุนเฉลี่ย
- **สินค้าคุม Lot มีจำนวนคงเหลือเป็น 0 แล้ว แต่ยังเหลือเศษมูลค่าค้างในรายงาน ต้องแก้ที่เมนูไหน?**
  ใช้เมนู **ปรับปรุงมูลค่าสินค้า Lot คงค้าง (รหัสเมนู 2048)** เลือกวันที่และช่วงสินค้า กดโหลดข้อมูลรายการที่ค้าง แล้วระบุรูปแบบปรับเพิ่ม–ปรับลดเพื่อล้างมูลค่าค้างให้เหลือ 0 พอดี
