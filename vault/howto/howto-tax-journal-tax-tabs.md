# บันทึกภาษีซื้อ ภาษีขาย ในข้อมูลรายวัน (แท็บภาษี)

**ใช้เมื่อ:** ลงบัญชีค่าใช้จ่ายหรือรายได้ผ่าน ข้อมูลรายวัน แล้วมีใบกำกับภาษี ต้องให้ภาษีไปขึ้นรายงานภาษีซื้อ/ภาษีขายด้วย
**เมนู:** บัญชี › ข้อมูลรายวัน › แท็บ ภาษีซื้อ หรือ ภาษีขาย (อยู่แถวเดียวกับแท็บ การลงบัญชี (GL), ภาษีถูกหัก ณ. ที่จ่าย, ภาษีหัก ณ. ที่จ่าย)
**ต้องมีก่อน:** [[howto-gl-journal-entry]], กลุ่มภาษี ([[howto-tax-setup-tax-group]])

## ขั้นตอน
1. เปิด/สร้างใบสำคัญ กดแก้ไข แล้วกดแท็บ ภาษีซื้อ หรือ ภาษีขาย
2. กด เพิ่มบรรทัด กรอกวันที่ เลขที่ใบกำกับ ฐานภาษี (ช่อง "คำนวณภาษีอัตโนมัติ" ติ๊กไว้ให้แล้ว ระบบคิดเงินภาษีให้)
3. กรอกชื่อและเลขประจำตัวผู้เสียภาษีของคู่ค้า สถานประกอบการ (สำนักงานใหญ่/สาขา) และเลขที่สาขา (ฝั่งภาษีขายเรียกว่า ลำดับที่สาขา) ในข้อมูลรายวันต้องพิมพ์เอง ระบบไม่ดึงจากทะเบียนให้
4. มีหลายใบ: กด เพิ่มบรรทัด ต่อ ถ้า "ช่วยบันทึกแบบต่อเนื่อง" ติ๊กอยู่ (ติ๊กไว้ให้แล้ว) ระบบเติมวันที่ กลุ่มภาษี รายละเอียดจากบรรทัดก่อน และเลขที่ใบกำกับถัดไปให้
   - ภาษีซื้อ: ขึ้นเลขที่ใบกำกับถัดไป และเลขที่ออกใหม่ถัดไปเสมอ
   - ภาษีขาย: ขึ้นเลขถัดไปเฉพาะเมื่อติ๊ก "สร้างเลขที่ใบกำกับภาษีแบบต่อเนื่อง" ถ้าไม่ติ๊ก ระบบใช้เลขเดิมซ้ำ ต้องแก้เลขเองก่อนบันทึก
5. บันทึกใบสำคัญ

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| วันที่ / เลขที่ใบกำกับ | ตามใบกำกับภาษี | แถวที่ไม่มีเลขที่ใบกำกับ ระบบไม่เก็บแถวนั้น |
| เลขที่ออกใหม่ | (ภาษีซื้อ) เลขที่ภายในของกิจการ | ไม่บังคับ |
| เดือนภาษี / ปีภาษี | เดือนที่จะเข้ารายงาน | ว่าง = เดือนของวันที่ ([[faq-tax-vat-month]]) |
| กลุ่มภาษี / ฐานภาษี / อัตราภาษี / เงินภาษี (ภาษีขายเรียก ยอดภาษี) | ยอดภาษี | ภาษีซื้อกรอก ยอดรวม แล้วระบบแยกฐานกับภาษีให้ได้ (เมื่อติ๊กคำนวณภาษีอัตโนมัติ) |
| ประเภทภาษี | ภาษีซื้อ: ปรกติ / ขอคืนไม่ได้ / ไม่ถึงกำหนดชำระ · ภาษีขาย: ปรกติ / ไม่ถึงกำหนดชำระ | สิทธิ์ขอคืนให้ปรึกษาผู้สอบบัญชี/สรรพากร |
| ยื่นเพิ่มเติม | ติ๊กเมื่อเป็นรายการยื่นเพิ่มเติม | แสดงในคอลัมน์ ยื่นเพิ่มเติม ของรายงาน |
| ยอดยกเว้น / เฉลี่ยภาษี | ยอดที่ยกเว้น และการเฉลี่ยภาษี (เฉลี่ยภาษีมีเฉพาะภาษีซื้อ) | ตามใบกำกับ |

## บันทึกแล้วระบบทำอะไรให้
- แถวภาษีขึ้นใน รายงานภาษีซื้อ/ภาษีขาย ตามเดือนภาษี ([[howto-tax-vat-report]])
- ภาษีซื้อที่เลือกประเภท ไม่ถึงกำหนดชำระ ในข้อมูลรายวัน ไม่ขึ้นในรายงานภาษีซื้อแบบปกติ (รูปแบบใหม่ / มาตรฐาน) ดูได้ในแบบ (แสดงมูลค่าอัตราภาษีศูนย์)
- การลงบัญชีภาษีซื้อ/ภาษีขาย ต้องลงเองในแท็บ การลงบัญชี (GL) ของใบสำคัญ แท็บภาษีไม่ได้สร้างรายการบัญชีให้

## แก้ไข ยกเลิก พิมพ์
- แก้แท็บภาษีได้เฉพาะใบสำคัญที่บันทึกเองใน ข้อมูลรายวัน ใบที่ระบบลงบัญชีจากเอกสารต้องแก้ที่เอกสารต้นทาง ([[howto-tax-vat-from-documents]])
- ลบใบสำคัญ = ลบแถวภาษีของใบนั้นด้วย

## ปัญหาที่พบบ่อย
- "ภาษีซื้อ: เลขที่ใบกำกับภาษี ... ซ้ำ" (หรือ "ภาษีขาย: ...") → ใส่เลขเดียวกัน 2 แถวในใบเดียว เปลี่ยนเลขให้ไม่ซ้ำ
- "เลขที่ใบกำกับภาษีซื้อ ... ซ้ำกับเอกสารอื่น" → เลขนี้บันทึกไว้ในเอกสารอื่นแล้ว ตรวจว่าบันทึกซ้ำหรือไม่
- **ภาษีที่ไม่ถึงกำหนดชำระ** (เช่น ค่าบริการที่ใบกำกับออกตอนจ่ายเงิน): ในข้อมูลรายวันไม่มีปุ่มดึงใบเดิม ปุ่ม "ค้นหาใบกำกับภาษีไม่ถึงกำหนดชำระ" มีในแท็บภาษีของเอกสารที่มีรหัสลูกหนี้/เจ้าหนี้ เช่น จ่ายชำระหนี้ / รับชำระหนี้ ถ้ายังไม่ใส่รหัส ปุ่มจะกดไม่ได้ (ชี้เมาส์ขึ้น "ยังไม่ได้ใส่รหัสลูกหนี้/เจ้าหนี้") ถ้าไม่มีใบให้เลือกจะขึ้น "ไม่มีใบกำกับภาษีไม่ถึงกำหนดชำระที่ยังชำระไม่ครบ"
- รายการไม่ขึ้นในรายงาน → [[ts-tax-doc-not-in-vat-report]]
