# ตั้งค่าธนบัตร และรายละเอียดคูปอง

**ใช้เมื่อ:** ต้องการรายการชนิดธนบัตร/เหรียญไว้อ้างอิง หรือต้องการตั้งคูปองส่วนลดสำหรับหน้าร้าน
**เมนู:** เริ่มต้น › ตั้งค่าระบบการเงินและธนาคาร › กำหนดธนบัตร / รายละเอียดคูปอง
**ต้องมีก่อน:** ไม่มี

## ขั้นตอน (กำหนดธนบัตร)
1. เปิดเมนู กำหนดธนบัตร กด "เพิ่มใหม่"
2. ใส่รหัส ชื่อ (เช่น "ธนบัตรหนึ่งพัน") เลือก "สกุลเงิน:" และใส่ "มูลค่าธนบัตร:"
3. กด "บันทึก"

## ขั้นตอน (รายละเอียดคูปอง)
1. เปิดเมนู รายละเอียดคูปอง จะเปิดหน้าจอ "รายละเอียดคูปองส่วนลด POS"
2. หน้าจอนี้เป็นส่วนของระบบหน้าร้าน วิธีใช้ดูที่ [[sys-pos-overview]]

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| สกุลเงิน | สกุลเงินของธนบัตร | |
| มูลค่าธนบัตร | มูลค่าต่อใบ/เหรียญ | |

## บันทึกแล้วระบบทำอะไรให้
- รายการธนบัตรเป็นข้อมูลอ้างอิง ระบบบัญชีไม่ได้นำไปคำนวณยอดเงินสดหรือลงบัญชี
- คูปองส่วนลดมีผลกับการขายหน้าร้านตามที่ตั้งในระบบหน้าร้าน

## แก้ไข ยกเลิก พิมพ์
- แก้ไขหรือลบรายการได้จากหน้าจอเดียวกัน

## ปัญหาที่พบบ่อย
- ตั้งธนบัตรแล้วไม่เห็นยอดเงินสดเปลี่ยน → เป็นปกติ ยอดเงินสดมาจากเอกสารรับจ่ายเงินเท่านั้น
