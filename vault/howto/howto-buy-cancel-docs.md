# ยกเลิกเอกสารซื้อ มัดจำ และทะยอยรับ

**ใช้เมื่อ:** เอกสารซื้อบันทึกไปแล้ว แต่ต้องการยกเลิกทั้งใบ หรือยกเลิกบางรายการของใบเสนอซื้อ/ใบสั่งซื้อ โดยยังเก็บร่องรอยไว้
**เมนู:** ซื้อ › ยกเลิกเอกสารซื้อ มัดจำ และทะยอยรับ › เลือกเมนูยกเลิกตามชนิดเอกสาร
**ต้องมีก่อน:** เอกสารที่จะยกเลิกยังไม่ถูกเอกสารอื่นนำไปใช้

## เมนูยกเลิกที่มี
ยกเลิกใบเสนอซื้อสินค้า, ยกเลิกใบสั่งซื้อสินค้า, ยกเลิกจ่ายเงินล่วงหน้า, ยกเลิกรับคืนจ่ายเงินล่วงหน้า, ยกเลิกจ่ายเงินมัดจำ, ยกเลิกรับคืนจ่ายเงินมัดจำ, ยกเลิกซื้อสินค้า/ตั้งหนี้ซื้อ, ยกเลิกส่งคืนสินค้า/ลดหนี้ซื้อ, ยกเลิกเพิ่มหนี้ซื้อ/ราคาผิด, ยกเลิกรับสินค้าตามใบสั่งซื้อ, ยกเลิกส่งคืนสินค้าจากการรับ, ยกเลิกตั้งหนี้จากการรับสินค้า, ยกเลิกเพิ่มหนี้จากใบตั้งหนี้, ยกเลิกลดหนี้จากใบตั้งหนี้

## ขั้นตอน
1. เปิดเมนูยกเลิกของเอกสารชนิดนั้น
2. กดปุ่มค้นหาข้างช่องเลขที่อ้างอิง เลือกเอกสารที่จะยกเลิก
3. ตรวจรายละเอียดเอกสาร ใส่ "หมายเหตุ" เหตุผลการยกเลิก
4. เฉพาะใบเสนอซื้อและใบสั่งซื้อ เลือก "ประเภทการยกเลิก" ได้
   - "ยกเลิกทั้งหมด" ยกเลิกทั้งใบ
   - "ยกเลิกรายสินค้า" กด "ดึงรายการ" แล้วใส่ "จำนวนยกเลิก" เฉพาะบรรทัดที่ต้องการ
5. กด "บันทึกยกเลิก" ระบบออกเลขที่ใบยกเลิกให้อัตโนมัติ

## บันทึกแล้วระบบทำอะไรให้
- สถานะเอกสารเดิมเปลี่ยนเป็น "ยกเลิกแล้ว" ดึงไปใช้ต่อไม่ได้
- ระบบทำใบยกเลิกแยกไว้ ลงบัญชีกลับรายการ (สลับเดบิต/เครดิต) ตามวันที่ของใบยกเลิก
- สต๊อกและยอดเจ้าหนี้ของเอกสารเดิมไม่นับอีก
- ยกเลิกรายสินค้าของใบสั่งซื้อ จะลดยอดค้างรับเฉพาะบรรทัดนั้น ส่วนที่เหลือยังรับต่อได้

## เปลี่ยนใจ (คืนสถานะ)
- เปิดเมนูเดิม เลือกเอกสารที่ยกเลิกไว้ กด "คืนสถานะเอกสารปกติ"
- ระบบลบใบยกเลิกและรายการบัญชีกลับรายการออก เอกสารเดิมกลับเป็น "ปกติ"

## เงื่อนไขที่ระบบตรวจ
- วันที่ของเอกสารเดิมและวันที่ใบยกเลิก ต้องอยู่ในงวดที่ยังไม่ปิด ([[ts-common-period-closed]])
- เอกสารที่ถูกนำไปใช้ต่อแล้ว (เช่น ใบซื้อที่มีใบลดหนี้หรือจ่ายชำระแล้ว) ยกเลิกไม่ได้ ต้องยกเลิกเอกสารปลายทางก่อน
- ใบสั่งซื้อที่รับของไปบางส่วน ยังยกเลิกส่วนที่เหลือได้ แต่ถ้ารับครบแล้วยกเลิกไม่ได้
- เอกสารยกมา (จ่ายเงินล่วงหน้ายกมา, จ่ายเงินมัดจำยกมา) ไม่มีเมนูยกเลิก ให้แก้ไขหรือลบที่หน้าจอเอกสารนั้นแทน

## ปัญหาที่พบบ่อย
- "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้" → [[ts-buy-cancel-refused]]
- "เอกสาร ... ปิดรายการไปแล้ว (ถูกนำไปใช้ครบ) ไม่สามารถนำมายกเลิกได้" → [[ts-buy-cancel-refused]]
- "เอกสาร ... ถูกยกเลิกแล้ว" → ยกเลิกไปแล้ว ไม่ต้องทำซ้ำ
- "ยังไม่มีรายการยกเลิก: กด ดึงรายการ แล้วใส่จำนวนยกเลิก" → เลือกยกเลิกรายสินค้าแล้วแต่ยังไม่ใส่จำนวน
- "ใบนี้ไม่มีรายการคงเหลือให้ยกเลิก" → ทุกบรรทัดถูกใช้หรือยกเลิกครบแล้ว
