# ดูงบทดลอง กระดาษทำการ และงบดุล บนหน้าจอ

**ใช้เมื่อ:** อยากดูภาพรวมยอดทุกบัญชี ตรวจว่าเดบิตรวมเท่ากับเครดิตรวม หรือดูกำไรขาดทุน/ฐานะการเงินคร่าวๆ บนจอ (งบทดลอง = ตารางยอดทุกบัญชีในช่วงเวลา)
**เมนู:** บัญชี › สอบถามบัญชีแยกประเภทและงบการเงิน (บนหน้าจอ) › แสดงงบทดลอง / แสดงงบทดลอง (มิติ) / แสดงกระดาษทำการ / แสดงรายการงบดุล
**ต้องมีก่อน:** ผังบัญชีที่กำหนดประเภทบัญชีถูกต้อง ([[howto-gl-chart-of-accounts]])

## ขั้นตอน
1. เปิดเมนูที่ต้องการ ใส่ ตั้งแต่วันที่ / ถึงวันที่ (และ จากรหัส / ถึงรหัส ถ้าต้องการดูบางบัญชี)
2. เลือกตัวเลือก: แสดงงบทดลอง มี "ต้องการแสดงยอดสุทธิ" (ไม่ติ๊กไว้ก่อน) "ต้องการแสดงยอดปรับปรุง" "รวมรายการปิดบัญชี" "รวมรายการยกไป" (สามช่องหลังติ๊กไว้ก่อน) ส่วน แสดงงบทดลอง (มิติ) มีแค่ "ต้องการแสดงยอดสุทธิ"
3. กด ค้นหา

## ช่องสำคัญที่ต้องกรอก
| หน้าจอ | แสดงอะไร |
|---|---|
| แสดงงบทดลอง | ต่อบัญชี: ยอดยกมา เดบิต/เครดิต, ยอดประจำงวด เดบิต/เครดิต, ยอดยกไป เดบิต/เครดิต และบรรทัดท้าย กำไร (ขาดทุน) |
| แสดงงบทดลอง (มิติ) | งบทดลองแบบเดียวกัน รวมทุกรายการ (ไม่มีช่องติ๊กปรับปรุง/ปิดบัญชี/ยกไป มีแค่ ต้องการแสดงยอดสุทธิ) ยังไม่ได้แยกยอดตามมิติ ถ้าต้องการดูตามมิติใช้ ข้อมูลรายวันเชิงวิเคราะห์ ([[howto-gl-dimensions]]) |
| แสดงกระดาษทำการ | ยอดสะสมทุกรายการจนถึง ถึงวันที่ แยกเป็นคอลัมน์ งบทดลอง งบกำไรขาดทุน และ งบดุล (เดบิต/เครดิต) พร้อมบรรทัด กำไร (ขาดทุน) สุทธิ และ Balance |
| แสดงรายการงบดุล | ยอดคงเหลือ ณ ถึงวันที่ (คอลัมน์เดียว) ของสินทรัพย์ หนี้สิน ส่วนของผู้ถือหุ้น พร้อมบรรทัด กำไร (ขาดทุน) สะสม รวมสินทรัพย์ และ รวมหนี้สินและส่วนของผู้ถือหุ้น ถ้าต้องการเทียบ ยอดต้นงวด กับ ยอดปลายงวด ใช้ รายงานงบดุล ในกลุ่มรายงาน |

## บันทึกแล้วระบบทำอะไรให้
- หน้าจอนี้ดูอย่างเดียว
- ยอดยกมาคำนวณจากทุกรายการก่อนวันเริ่ม ไม่ต้องยกยอดเอง ([[faq-gl-carry-forward]])
- รวมใบสำคัญทั้งที่ผ่านรายการและยังไม่ผ่าน
- เอาติ๊ก "รวมรายการปิดบัญชี" ออก ถ้าไม่ต้องการให้ใบปิดงวด/ปิดปีที่ลงวันสุดท้ายของช่วง มารวมในยอดประจำงวด
- ติ๊ก "ต้องการแสดงยอดสุทธิ" = ช่อง ยอดประจำงวด แสดงยอดสุทธิฝั่งเดียวต่อบัญชี แทนแสดงทั้งเดบิตและเครดิต (ยอดยกมาและยอดยกไปแสดงฝั่งเดียวอยู่แล้ว)
- บรรทัด กำไร (ขาดทุน) ท้ายงบทดลอง: ถ้ากำไร ตัวเลขอยู่ฝั่งเดบิต ถ้าขาดทุน อยู่ฝั่งเครดิต (เพื่อให้รวมแล้วดุล)

## แก้ไข ยกเลิก พิมพ์
- งบการเงินแบบพิมพ์ และงบทดลองแบบรายงาน อยู่ในกลุ่มรายงาน ([[rpt-overview]])

## ปัญหาที่พบบ่อย
- งบทดลองเดบิตรวมไม่เท่าเครดิตรวม → มีใบสำคัญไม่ดุล ใช้ ตรวจสอบความถูกต้อง ([[ts-gl-debit-credit-not-equal]])
- บัญชีไปอยู่ผิดฝั่งงบ (กำไรขาดทุน/งบดุล) → ตรวจ ประเภทบัญชี ในผังบัญชี
- ทำปิดงวดแล้วรายได้ค่าใช้จ่ายในงบทดลองเป็นศูนย์ → เอาติ๊ก รวมรายการปิดบัญชี ออก (ได้เฉพาะใบปิดที่ลงวันเดียวกับ ถึงวันที่ ของงบทดลอง ใบปิดของงวดก่อนหน้าจะรวมอยู่ในยอดยกมาเสมอ)
