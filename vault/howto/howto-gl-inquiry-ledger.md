# ดูบัญชีแยกประเภทบนหน้าจอ (รายตัว และแบบสรุป)

**ใช้เมื่อ:** อยากดูว่าบัญชีหนึ่ง (เช่น เงินสด ลูกหนี้ ค่าใช้จ่าย) มีรายการอะไรเข้าออกบ้าง และยอดคงเหลือเท่าไร (บัญชีแยกประเภท = สมุดที่รวมรายการของแต่ละบัญชี)
**เมนู:** บัญชี › สอบถามบัญชีแยกประเภทและงบการเงิน (บนหน้าจอ) › แสดงบัญชีแยกประเภท / แสดงบัญชีแยกประเภท (แบบสรุป)
**ต้องมีก่อน:** มีรายการบัญชีแล้ว

## ขั้นตอน
1. เปิดเมนู แสดงบัญชีแยกประเภท
2. ใส่ ตั้งแต่วันที่ / ถึงวันที่ และ จากรหัส / ถึงรหัส (รหัสบัญชี) ที่ต้องการดู
3. กด ค้นหา ระบบแสดงทีละบัญชี: ชื่อบัญชี ยอดยกมา แล้วตามด้วยรายการ วันที่ เอกสาร รายละเอียด สมุดรายวัน เดบิต เครดิต ยอดคงเหลือ มีบรรทัดรวมท้ายแต่ละวัน และบรรทัดรวมท้ายบัญชี
4. ถ้าต้องการดูแค่ยอดเดบิต/เครดิตรวมของแต่ละบัญชี ใช้ แสดงบัญชีแยกประเภท (แบบสรุป) ซึ่งรวมยอดสะสมทุกรายการจนถึง ถึงวันที่ (ณ วันที่) ไม่ได้ตัดตามวันเริ่มต้น ช่อง "ต้องการแสดงยอดสุทธิ" ติ๊กไว้ให้แล้ว จะแสดงยอดสุทธิฝั่งเดียว ถ้าเอาติ๊กออกจะแสดงทั้งเดบิตและเครดิต

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ตั้งแต่วันที่ / ถึงวันที่ | วันที่ของรายการที่จะดู | ยอดยกมา = ทุกรายการก่อนวันเริ่ม |
| จากรหัส / ถึงรหัส | รหัสบัญชีแรกและสุดท้าย | ว่าง = ทุกบัญชี |

## บันทึกแล้วระบบทำอะไรให้
- หน้าจอนี้ดูอย่างเดียว ไม่บันทึกอะไร
- รวมใบสำคัญทุกใบ ทั้งที่ผ่านรายการแล้วและยังไม่ผ่าน ([[faq-gl-pass-journal-needed]])
- ยอดคงเหลือคิดเป็น เดบิต ลบ เครดิต ทุกบัญชี บัญชีที่ยอดอยู่ด้านเครดิต (เช่น เจ้าหนี้ รายได้) จึงเห็นเป็นตัวเลขติดลบ
- บัญชีที่ไม่มีรายการในช่วงและยอดยกมาเป็นศูนย์ จะไม่แสดง
- ยอดยกมาคำนวณจากรายการก่อนวันเริ่มต้นเสมอ ไม่ต้องทำยกยอดเอง ([[faq-gl-carry-forward]])

## แก้ไข ยกเลิก พิมพ์
- อยากแก้รายการที่เห็น ให้แก้ที่เอกสารต้นทาง (ตามเลขที่เอกสาร) หรือใบสำคัญใน ข้อมูลรายวัน
- พิมพ์/ส่งออก ดู [[rpt-print-export]] ส่วนรายงานบัญชีแบบพิมพ์ ดู [[rpt-overview]]

- ไม่เห็นรายการของเอกสารขาย/ซื้อ → [[ts-gl-document-no-journal]]
