# ระบบอนุมัติเอกสาร ปรับจำนวนอนุมัติ และยกเลิกการอนุมัติ

สำหรับกิจการที่ต้องการให้หัวหน้างานหรือผู้จัดการตรวจสอบก่อนสั่งซื้อหรือปล่อยสินค้าออกจากคลัง สามารถเปิดใช้งานระบบอนุมัติเอกสารแยกตามขั้นตอนได้

---

## 1. เอกสารที่มีหน้าจออนุมัติโดยเฉพาะ

- **ระบบซื้อ**:
  - "ซื้อ > อนุมัติใบเสนอซื้อสินค้า" (PR)
  - "ซื้อ > อนุมัติใบสั่งซื้อสินค้า" (PO)
- **ระบบขาย**:
  - "ขาย > อนุมัติใบเสนอราคาขาย"
  - "ขาย > อนุมัติใบสั่งจองสินค้า"
  - "ขาย > อนุมัติใบสั่งขายสินค้า" (SO)

---

## 2. ขั้นตอนการอนุมัติและไม่อนุมัติ

1. เปิดหน้าจออนุมัติเอกสารที่ต้องการ แล้วกด **เลือกเอกสาร** (หรือคลิกจากรายการฝั่งซ้าย)
2. ตรวจสอบรายการสินค้า ราคา และยอดรวมสุทธิ
   - **พิเศษสำหรับใบเสนอซื้อ (PR)**: ผู้อนุมัติสามารถแก้ **จำนวนอนุมัติ**, **ราคาอนุมัติ** และ **ส่วนลด** รายบรรทัดได้ก่อนบันทึก ระบบจะเก็บค่าที่ขอเดิมไว้เปรียบเทียบและคำนวณยอดที่อนุมัติจริงให้ใหม่
3. กรอก **หมายเหตุ** หากต้องการบันทึกคำชี้แจง
4. เลือกบันทึกผล:
   - หากผ่าน: กดปุ่ม **บันทึกอนุมัติ**
   - หากไม่ผ่าน: ติ๊กช่อง **ไม่อนุมัติ** แล้วปุ่มจะเปลี่ยนเป็น **บันทึกไม่อนุมัติ** กดเพื่อยืนยัน
   - ระบบจะแจ้งผล เช่น "อนุมัติเอกสาร ... เรียบร้อยแล้ว" หรือ "บันทึกไม่อนุมัติเอกสาร ... เรียบร้อยแล้ว"

---

## 3. การยกเลิกการอนุมัติ

- หากอนุมัติผิดใบและเอกสารนั้นยัง **ไม่ถูกนำไปออกบิลต่อ** ให้เปิดหน้ารายการในหน้าจออนุมัติเดิม แล้วกดปุ่ม **ยกเลิกการอนุมัติ** (หรือปุ่ม **คืนสถานะ** ในรายการ)
- **ข้อห้าม**: หากใบที่อนุมัติถูกดึงไปสร้างใบสั่งซื้อ ใบรับของ หรือใบขายแล้ว ระบบจะไม่อนุญาตให้ยกเลิกการอนุมัติ จนกว่าจะจัดการเอกสารปลายทางก่อน

---

## 4. การตั้งค่าบังคับให้อนุมัติก่อนใช้งานต่อ

ผู้ดูแลระบบสามารถตั้งค่าการบังคับใน "เริ่มต้น > ตั้งค่าองค์กร พนักงาน และเอกสาร > กำหนดข้อเลือกพิเศษต่างๆ":
- **ฝั่งซื้อ (แท็บ 3. สินค้าคงคลัง / แท็บ 1. ตั้งค่าระบบ)**:
  - **อ้างอิงเอกสารเสนอซื้อที่อนุมัติแล้วเท่านั้น** (บังคับอนุมัติ PR ก่อนดึงไปเปิด PO)
  - **อ้างอิงเอกสารสั่งซื้อที่อนุมัติแล้วเท่านั้น** (บังคับอนุมัติ PO ก่อนดึงไปรับสินค้า/ซื้อ)
  - **อนุมัติใบสั่งซื้อก่อนพิมพ์** และ **ใบอนุมัติซื้ออ้างอิงได้ครั้งเดียว**
  - **อนุมัติรายการเสนอซื้อได้มากกว่า 1 ครั้ง**
- **ฝั่งขาย (แท็บ 4. ระบบขาย)**:
  - **เปิดใช้ระบบอ้างอิงใบสั่งจองที่อนุมัติแล้วเท่านั้น**
  - **เปิดใช้ระบบอ้างอิงใบสั่งขายที่อนุมัติแล้วเท่านั้น**

> [!NOTE]
> หากกำหนดสิทธิ์กลุ่มพนักงานไว้ใน [[howto-setup-permissions-advanced]] จะต้องตั้งค่ากลุ่มผู้อนุมัติ PO / SO / เสนอซื้อ ให้ตรงกับพนักงานผู้อนุมัติด้วย
