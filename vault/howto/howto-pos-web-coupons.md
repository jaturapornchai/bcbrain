# สร้างและจัดการคูปองส่วนลดสำหรับ POS

**ใช้เมื่อ:** แจกคูปองส่วนลดให้ลูกค้านำมาใช้ที่แคชเชียร์
**เมนู:** เริ่มต้น › ตั้งค่าระบบการเงินและธนาคาร › รายละเอียดคูปอง (ดู/แก้รายใบ) · ขาย › ระบบขายหน้าร้าน POS › สร้างคูปองแบบเร็ว (สร้างเป็นชุด)
**ต้องมีก่อน:** สิทธิ์แก้ไขหน้าจอ POS

## สร้างรายใบ
1. เปิด "รายละเอียดคูปอง" กด **แก้ไข** หรือ **เพิ่มใหม่** (ปุ่ม เพิ่มใหม่ ของหน้านี้ไม่ล้างฟอร์ม ถ้าฟอร์มยังเป็นคูปองใบเดิมอยู่ ต้องลบ "หมายเลขคูปอง" ออกเองก่อน ไม่งั้นการบันทึกจะทับคูปองใบเดิม) หรือคลิกแถวในตาราง "รายการคูปองส่วนลดทั้งหมดในระบบ" เพื่อดึงมาแก้
2. กรอกฟอร์ม "เพิ่ม/แก้ไขรายละเอียดคูปองส่วนลด" แล้วกด **บันทึก** (ที่ด้านบน)

| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| กลุ่มคูปอง | ชื่อกลุ่มแคมเปญ | ถ้าว่างระบบใช้ชื่อกลุ่มตัวอย่าง |
| หมายเลขคูปอง | เลขหรือบาร์โค้ดของคูปอง | ระบบแปลงเป็นตัวพิมพ์ใหญ่ ถ้าว่างระบบสร้างเลขให้ ใช้เลขเดิมซ้ำ = แก้คูปองเดิม |
| มูลค่า | ส่วนลดเป็นบาท | |
| มูลค่าคงเหลือ | ส่วนลดที่ยังเหลือ | แก้เองไม่ได้ (ช่องถูกปิดไว้) จะเท่ากับมูลค่าที่กรอกโดยอัตโนมัติ |
| วันที่ออกคูปอง / วันที่หมดอายุ | วันที่ | ฟอร์มจะใส่วันนี้ให้ทั้งสองช่องก่อน คูปองจะหมดอายุวันนี้ถ้าไม่แก้ ควรกรอกวันหมดอายุเอง |
| ประเภทคูปอง | "0 — ลดตามมูลค่า" / "1 — ลดตามเปอร์เซ็นต์" | แอปแคชเชียร์ใช้ตัวเลขมูลค่าเป็นบาทเสมอ ไม่คิดเป็นเปอร์เซ็นต์ จึงควรใช้แบบลดตามมูลค่า |
| รหัสลูกค้า | ผูกคูปองกับลูกค้า (ถ้าต้องการ) | แอปแคชเชียร์ยังไม่ตรวจว่าผู้ใช้คูปองเป็นลูกค้าคนนี้ |
| ใช้งานเพียงครั้งเดียว | ใช้ได้ครั้งเดียวแล้วหมดสถานะ | |
| ยกเลิก / ใช้แล้ว | สถานะคูปอง | |
| หมายเหตุ | รายละเอียดแคมเปญ | |

## สร้างเป็นชุด (สร้างคูปองแบบเร็ว)
1. เปิด "สร้างคูปองแบบเร็ว" ในส่วน "สร้างคูปองแบบเร็วเป็นชุด"
2. ใส่ "คำนำหน้า (Prefix)" (ค่าตั้งต้น VIP), "จำนวนใบที่สร้าง" (ค่าตั้งต้น 5), "มูลค่าต่อใบ (บาท)" (ค่าตั้งต้น 50) หน้าจอนี้มี 3 ช่องเท่านั้น ไม่มีช่องวันหมดอายุหรือหมายเหตุ
3. กด **สร้างชุดคูปองทันที** ขึ้น "สร้างชุดคูปอง ... จำนวน ... ใบ เรียบร้อยแล้ว"
- สร้างได้ครั้งละไม่เกิน **50 ใบ** ถ้าใส่เกิน ระบบสร้าง 50 ใบ
- เลขคูปองเป็นคำนำหน้าตามด้วยเลขรัน ทุกใบเป็นแบบใช้ครั้งเดียว ลดตามมูลค่า มูลค่าตามที่ใส่
- **วันหมดอายุของคูปองชุดจะเป็นวันที่สร้างเสมอ** เพราะหน้าจอไม่มีช่องให้เลือก (ใช้ได้ถึงสิ้นวันนั้น) ถ้าต้องการอายุนานกว่านั้น ให้เปิด "รายละเอียดคูปอง" แล้วแก้วันหมดอายุทีละใบ
- ถ้าสร้างไม่สำเร็จ หน้าจอไม่แสดงข้อความผิดพลาด ให้ดูในตารางรายการว่ามีคูปองขึ้นมาหรือไม่
- หากกดสร้างซ้ำในเวลาใกล้เคียงกัน เลขที่ซ้ำจะถูกข้าม ไม่เกิดคูปองซ้ำ

## ใช้คูปองแล้วระบบทำอะไร
เมื่อแคชเชียร์ใช้คูปองในบิลและบิลเข้าระบบ ยอดคงเหลือของคูปองถูกคำนวณใหม่จากบิลทั้งหมดที่ใช้คูปองนั้น (ไม่ใช่หักทีละครั้ง) ถ้าเป็นคูปองใช้ครั้งเดียวและมีการใช้แล้ว สถานะเปลี่ยนเป็นใช้แล้ว ตารางรายการแสดง 100 ใบล่าสุด คูปองส่งลงเครื่อง POS ตอนซิงก์ ([[howto-pos-web-monitor-sync]])

## ปัญหาที่พบบ่อย
- ลูกค้าถือคูปองที่เพิ่งสร้างแต่เครื่อง POS ไม่รู้จัก → เครื่องยังไม่ซิงก์ ดูสถานะที่ [[howto-pos-web-monitor-sync]]
- "มีข้อมูลที่ต้องลบจำนวน: 1 รายการ ต้องการลบ ... จริงหรือไม่" → ยืนยันก่อนลบคูปอง
