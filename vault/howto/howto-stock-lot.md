# ใช้สินค้าแบบ LOT และค้นหา LOT อัตโนมัติ

**ใช้เมื่อ:** ต้องแยกสต็อกตามล็อตการผลิตหรือล็อตที่รับเข้า เช่น ยา อาหาร เคมีภัณฑ์
**เมนู:** สินค้า › ทะเบียนข้อมูลสินค้าและคลังที่เก็บ › ข้อมูลสินค้า (ช่อง ประเภทต้นทุน)
**ต้องมีก่อน:** สินค้ายังไม่มีความเคลื่อนไหว เพราะเปลี่ยนประเภทต้นทุนหลังใช้งานไม่ได้

## ขั้นตอน
1. ในข้อมูลสินค้า เลือก ประเภทต้นทุน = 3.ต้นทุน LOT กำหนดเอง แล้วบันทึก
2. ทุกเอกสารรับ-จ่ายสินค้าตัวนี้ (ซื้อ ขาย ใบสั่งขาย รับคืน ส่งคืน เบิก รับคืนจากการเบิก โอน ปรับปรุง รับสำเร็จรูป) ต้องกรอกเลข LOT ในแถว ส่วนยอดยกมาระบบไม่บังคับ แต่กรอกเลข LOT ได้
3. ถ้าอยากให้ระบบเลือก LOT ให้ตอนขาย เปิดตัวเลือก "ใช้ระบบค้นหา LOT อัตโนมัติ" ([[howto-stock-options]])

## LOT อัตโนมัติทำงานอย่างไร
- ใช้กับบิลขายใหม่เท่านั้น แถวที่ยังไม่กรอก LOT
- ระบบหา LOT แรก (เรียงตามเลข LOT) ที่คลังและที่เก็บเดียวกันมียอดพอ แล้วใส่ให้
- ถ้าไม่มี LOT ไหนพอ ระบบใช้ LOT แรกจนหมด แล้วแตกแถวใหม่สำหรับจำนวนที่เหลือ
- ถ้าหาไม่เจอเลย ช่อง LOT จะว่าง และบันทึกไม่ผ่าน
- รุ่นปัจจุบันการค้นหา LOT อัตโนมัติมองเห็นเฉพาะ LOT ที่มาจากเอกสารซื้อ ขาย เบิก โอน ปรับปรุง ยังมองไม่เห็น LOT ที่บันทึกในยอดยกมา ถ้าของมาจากยอดยกมา ต้องกรอกเลข LOT เอง ถ้าลูกค้าพบปัญหา ให้ส่งต่อเจ้าหน้าที่

## บันทึกแล้วระบบทำอะไรให้
- ยอดคงเหลือแยกตาม LOT ดูได้ที่ ยอดคงเหลือสินค้าตาม LOT ([[howto-stock-inquiry-balance]]) แต่รุ่นปัจจุบันหน้าจอนี้นับเฉพาะ LOT จากยอดยกมาและเอกสารที่หน้าจอปรับปรุงตาม LOT สร้าง ยังไม่รวม LOT จากบิลซื้อ บิลขาย หรือใบเบิก ยอดจึงอาจไม่ตรง ถ้าลูกค้าพบ ให้ส่งต่อเจ้าหน้าที่
- ต้นทุนยังคิดแบบเฉลี่ยของสินค้า ([[faq-stock-cost-method]])

## แก้ไข ยกเลิก พิมพ์
- ตรวจนับและปรับปรุงตาม LOT ดู [[howto-stock-count-auto-adjust]]
- LOT ที่จำนวนเป็น 0 แต่ยังมีมูลค่าค้าง ใช้เมนู ปรับปรุงมูลค่าสินค้า Lot คงค้าง ([[howto-stock-count-auto-adjust]])
