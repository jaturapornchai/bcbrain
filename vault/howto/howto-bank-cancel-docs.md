# ยกเลิกเอกสารธนาคาร เช็ครับ เช็คจ่าย และบัตรเครดิต

**ใช้เมื่อ:** บันทึกเอกสารฝาก ถอน โอน หรือเอกสารจัดการเช็คผิด และต้องการยกเลิกโดยเก็บประวัติ
**เมนู:** เงินสด/ธนาคาร › ยกเลิกเอกสารธนาคาร เช็ครับ เช็คจ่าย และบัตรเครดิต
- ธนาคาร: บันทึกยกเลิกฝากเงิน / บันทึกยกเลิกถอนเงิน / บันทึกยกเลิกโอนเงินระหว่างธนาคาร
- เช็ครับ: บันทึกยกเลิกนำฝากเช็ค / บันทึกยกเลิกเช็คผ่าน / บันทึกยกเลิกเช็ครับคืน / บันทึกยกเลิกเช็คขาดสิทธิ์ / บันทึกยกเลิกเปลี่ยนเช็ค
- เช็คจ่าย: บันทึกยกเลิกเช็คจ่ายผ่าน / บันทึกยกเลิกเช็คขาดสิทธิ์ / บันทึกยกเลิกเช็คคืน / บันทึกยกเลิกเปลี่ยนเช็คจ่าย
- บัตรเครดิต: บันทึกยกเลิกบัตรเครดิต (เมนูนี้ไม่ใช่การยกเลิกเอกสาร แต่เป็นการบันทึกว่ารายการบัตรถูกยกเลิก ดู [[howto-bank-credit-card]])
**ต้องมีก่อน:** เลขที่เอกสารเดิม

## ขั้นตอน
1. เปิดเมนูยกเลิกที่ตรงกับเอกสารเดิม จอแสดง "โหมดยกเลิกเอกสาร"
2. กด "เลือกเอกสาร" เลือกเอกสารเดิม
3. ใส่ "วันที่" ยกเลิก และ "หมายเหตุ" (ระบุเหตุผลการยกเลิก)
4. กด "บันทึกยกเลิก" ระบบแจ้ง "ยกเลิกเอกสาร ... เรียบร้อยแล้ว (เลขที่ยกเลิก ...)"

## ลำดับการยกเลิกเช็ค
- ยกเลิกย้อนจากขั้นล่าสุดก่อนเสมอ เช่น เช็ครับที่ นำฝาก แล้ว ผ่าน ต้องยกเลิกเช็คผ่านก่อน แล้วจึงยกเลิกนำฝากเช็ค
- ถ้ายกเลิกข้ามขั้น ระบบแจ้ง "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้"

## บันทึกแล้วระบบทำอะไรให้
- เอกสารเดิมถูกทำเครื่องหมายยกเลิก รายการบัญชีเดิมยังอยู่ และเอกสารยกเลิกลงบัญชีกลับด้านด้วยวันที่ยกเลิก
- สถานะเช็คหรือบัตรในทะเบียนคำนวณใหม่ตามรายการล่าสุดที่ยังไม่ถูกยกเลิก เช่น ยกเลิกนำฝากแล้ว เช็คกลับเป็น "เช็คในมือ"

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกผิด เปิดเอกสารยกเลิกแล้วกด "คืนสถานะเอกสารปกติ"
- ยังไม่มีเอกสารอื่นอ้างถึง ใช้การลบเอกสารเดิมแทนได้ ([[howto-doc-edit-cancel-delete]])
