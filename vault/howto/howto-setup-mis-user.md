# กำหนดผู้ใช้ระบบ MIS

**ใช้เมื่อ:** ต้องสร้างบัญชีผู้ใช้สำหรับระบบ MIS (ระบบรายงานผู้บริหาร/คู่ค้า) โดยผูกกับเจ้าหนี้หรือคู่ค้า
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดผู้ใช้ระบบ MIS (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin · รุ่นที่ใช้ต้องมีระบบ MIS (หมวด MIS ในข้อเลือกพิเศษจะถูกซ่อนถ้าไม่มี สอบถามฝ่ายขาย) · ถ้าผูกกับเจ้าหนี้ ต้องมีรหัสเจ้าหนี้ก่อน · เริ่มต้นดู [[start-first-day]]

## ขั้นตอน
1. เปิดเมนู "กำหนดผู้ใช้ระบบ MIS" กด "เพิ่มใหม่"
2. กรอก "รหัสผู้ใช้ MIS" และ "ชื่อผู้ใช้ MIS"
3. ตั้ง "รหัสผ่าน MIS"
4. เลือก "ประเภทผู้ใช้" (คู่ค้า/เจ้าหนี้ Vendor) แล้วเลือก "รหัสเจ้าหนี้ (Vendor)" ที่ต้องการผูก
5. กดบันทึก (F12 หรือ Ctrl+S)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสผู้ใช้ MIS | รหัสประจำตัวผู้ใช้ MIS | ห้ามซ้ำ ถ้าว่างขึ้น "กรุณาระบุรหัส" |
| ชื่อผู้ใช้ MIS | ชื่อแสดง | ถ้าว่างขึ้น "กรุณาระบุชื่อ" |
| รหัสผ่าน MIS | รหัสผ่านที่ตั้งให้ผู้ใช้ | แจ้งผู้ใช้ผ่านช่องทางส่วนตัว อย่าส่งในที่สาธารณะ |
| ประเภทผู้ใช้ | คู่ค้า/เจ้าหนี้ (Vendor) | |
| รหัสเจ้าหนี้ (Vendor) | เจ้าหนี้ที่ผู้ใช้นี้เป็นตัวแทน | เลือกจากรายการ |
| ยกเลิกการใช้งาน | ติ๊กเมื่อปิดสิทธิ์ผู้ใช้ | ใช้แทนการลบ |

## บันทึกแล้วระบบทำอะไรให้
ระบบเก็บรหัสผู้ใช้ รหัสผ่าน และเจ้าหนี้ที่ผูกไว้เป็นทะเบียน ในรุ่นปัจจุบันยังไม่มีหน้าจอในโปรแกรมนี้ที่นำรหัสเหล่านี้ไปใช้เข้าระบบ MIS ถ้าลูกค้าถามวิธีเข้าใช้ MIS ให้ส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- แก้ไข/เปลี่ยนรหัสผ่าน: เลือกรายการ กด "แก้ไข" แก้แล้วบันทึก
- ลบ: ยืนยัน "ต้องการลบรายการ ... หรือไม่?" ถ้าลบไม่ได้ให้ติ๊ก "ยกเลิกการใช้งาน"
- คนที่เข้าโปรแกรมบัญชีไม่ได้ตั้งที่เมนูนี้ ให้เชิญด้วยบัญชี Google ดู [[howto-user-invite-member]] ส่วน [[howto-setup-staff]] เป็นข้อมูลพนักงานในบริษัท

## ปัญหาที่พบบ่อย
- รหัสซ้ำ: ใช้รหัสอื่น
- เลือกรหัสเจ้าหนี้ไม่เจอ: ยังไม่ได้สร้างเจ้าหนี้ ดู [[howto-ap-overview]]
- ไม่มีสิทธิ์: ดู [[ts-common-no-permission]]
