# ยกเลิกเอกสารลูกหนี้ (ตั้งหนี้อื่น วางบิล รับชำระ)

**ใช้เมื่อ:** ออกใบเสร็จรับเงิน ใบวางบิล หรือตั้งหนี้อื่นๆ ผิด หรือลูกค้าขอยกเลิก ต้องการยกเลิกโดยเก็บประวัติเอกสารเดิมไว้
**เมนู:** ลูกหนี้ › ยกเลิกเอกสารลูกหนี้ (ตั้งหนี้อื่น/วางบิล/รับชำระ) › เลือก
- ยกเลิกตั้งหนี้อื่นๆ (ลูกหนี้)
- ยกเลิกเพิ่มหนี้อื่นๆ (ลูกหนี้)
- ยกเลิกลดหนี้อื่นๆ (ลูกหนี้)
- ยกเลิกใบวางบิล (ลูกหนี้)
- ยกเลิกชำระหนี้/ยกเลิกใบเสร็จรับเงิน
**ต้องมีก่อน:** สิทธิ์ใช้เมนูยกเลิก ([[ts-common-no-permission]])

## ขั้นตอน
1. เปิดเมนูยกเลิกของเอกสารนั้น (จอขึ้นว่า "โหมดยกเลิกเอกสาร")
2. กด "เลือกเอกสาร" เลือกใบที่จะยกเลิก (หรือคลิกจากรายการด้านซ้าย) ระบบแสดงรายละเอียดเดิมแบบอ่านอย่างเดียว
3. ใส่ "วันที่" ของใบยกเลิก และ "หมายเหตุ" เหตุผลการยกเลิก
4. กด "บันทึกยกเลิก" ระบบขึ้น "ยกเลิกเอกสาร ... เรียบร้อยแล้ว (เลขที่ยกเลิก ...)"
- จอยกเลิกใบวางบิลแสดงชื่อช่องว่า "ใบรับวางบิล" เป็นชื่อบนจอ ไม่ใช่เลือกผิดเมนู

## ลำดับการยกเลิก (ต้องยกเลิกใบปลายทางก่อน)
- ใบเสร็จรับเงินใช้ใบวางบิล และใช้บิลหนี้ → ยกเลิก **ใบเสร็จ** ก่อน แล้วค่อยยกเลิกใบวางบิล หรือตั้งหนี้อื่นๆ
- ใบวางบิลใช้บิลหนี้ → ยกเลิก **ใบวางบิล** ก่อน แล้วค่อยยกเลิกตั้งหนี้อื่นๆ
- ถ้ายกเลิกผิดลำดับ ระบบขึ้น "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถนำมายกเลิกได้" ข้อความบอกเลขที่ใบที่ต้องยกเลิกก่อน
- ถ้าบิลเดียวกันถูกวางบิลไว้ในใบวางบิลใหม่แล้ว ใบวางบิลใบเก่าจะยกเลิกไม่ได้ ขึ้นข้อความเดียวกันโดยบอกเลขที่ใบวางบิลใหม่ (ต้องยกเลิกใบใหม่ก่อน) ถ้าต้องการเก็บใบใหม่ไว้ ส่งต่อเจ้าหน้าที่

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| เลือกเอกสาร | ใบที่จะยกเลิก | เลือกได้เฉพาะใบที่ยังไม่ถูกยกเลิก |
| หมายเหตุ | เหตุผลการยกเลิก | เก็บไว้ดูย้อนหลัง |

## บันทึกแล้วระบบทำอะไรให้
- เอกสารเดิมยังอยู่ สถานะเป็น "ยกเลิกแล้ว" และใบยกเลิกถูกบันทึกเป็นเอกสารใหม่
- ใบที่ลงบัญชีไว้ (ตั้งหนี้ เพิ่มหนี้ ลดหนี้อื่นๆ และใบเสร็จ) ระบบกลับรายการบัญชีให้ ลงวันที่ของใบยกเลิก
- ยกเลิกใบเสร็จ: บิลที่รับชำระในใบนั้นกลับมาค้างชำระ ดึงไปรับชำระใหม่ได้
- ยกเลิกตั้งหนี้อื่นๆ: หนี้นั้นไม่ขึ้นใน "ดึงเอกสารค้างชำระ" อีก
- ใบวางบิลไม่ได้ลงบัญชี ยกเลิกแล้วบิลในใบนั้นวางบิลใหม่ได้

## ยกเลิกผิด ต้องการคืน
- คลิกเอกสารที่สถานะ "ยกเลิกแล้ว" จากรายการด้านซ้าย แล้วกด "คืนสถานะเอกสารปกติ" ([[howto-sale-cancel-docs]] มีรายละเอียดเดียวกัน)
- **ข้อควรระวัง:** ตอนคืนสถานะใบเสร็จ ระบบรุ่นปัจจุบันไม่ตรวจว่าบิลในใบนั้นถูกรับชำระด้วยใบเสร็จใหม่ไปแล้วหรือยัง ถ้าออกใบเสร็จใหม่แทนไปแล้ว อย่าคืนสถานะใบเดิม เพราะบิลจะถูกนับว่ารับเงินซ้ำ ถ้าเผลอทำไปแล้วส่งต่อเจ้าหน้าที่

## ปัญหาที่พบบ่อย
- "เอกสาร ... ถูกยกเลิกแล้ว" → ใบนี้ยกเลิกไปแล้ว
- ยกเลิกในงวดที่ปิดแล้ว ระบบตรวจทั้งวันที่ของใบเดิมและวันที่ของใบยกเลิก → [[ts-common-period-closed]]
- ยกเลิกไม่ได้กรณีอื่น → [[ts-sale-cannot-cancel]]
- ตั้งหนี้ยกมา เพิ่มหนี้ยกมา ลดหนี้ยกมา ไม่มีเมนูยกเลิก ให้แก้หรือลบแทน ([[howto-ar-opening-balance]])
