# ดูกำไรขั้นต้น ตามสินค้า ตามเอกสารขาย ตามลูกค้า

**ใช้เมื่อ:** อยากรู้ว่าขายแล้วได้กำไรขั้นต้น (ยอดขายหักต้นทุนสินค้า ยังไม่หักค่าใช้จ่ายอื่น) เท่าไร ต่อสินค้า ต่อบิล หรือต่อลูกค้า
**เมนู:** สินค้า › สอบถามและวิเคราะห์ข้อมูลสินค้า (บนหน้าจอ) › กำไรขั้นต้นตามสินค้า / กำไรขั้นต้นตามเอกสารขาย / กำไรขั้นต้นตามลูกค้า
**ต้องมีก่อน:** มีบิลขายในช่วงวันที่ ([[howto-sale-overview]])

## ขั้นตอน
1. เปิดหัวข้อที่ต้องการ
2. ใส่ ตั้งแต่วันที่ ถึงวันที่ และช่วงรหัส
3. กด ประมวลผลรายงาน
4. พิมพ์หรือส่งออกด้วยปุ่ม พิมพ์รายงาน / ส่งออก CSV ([[rpt-print-export]])

## ช่องที่แสดง
| ช่อง | ความหมาย |
|---|---|
| มูลค่าสุทธิ | ยอดขายไม่รวมภาษีมูลค่าเพิ่ม (VAT) |
| ต้นทุนสุทธิ | ต้นทุนสินค้าที่ระบบคิดไว้ในบิลขาย ([[faq-stock-cost-method]]) |
| กำไร(ขาดทุน) | มูลค่าสุทธิ ลบ ต้นทุนสุทธิ |
| % กำไรขั้นต้น | กำไรเทียบกับยอดขาย |

## ระบบคิดอย่างไร
- นับบิลขายและเพิ่มหนี้ หักด้วยรับคืนหรือลดหนี้ ในช่วงวันที่ เอกสารที่ยกเลิกแล้วไม่นับ
- ต้นทุนใช้ค่าที่บันทึกในเอกสารขาย ถ้าต้นทุนเฉลี่ยเพิ่งเปลี่ยน เช่น เพิ่งบันทึกบิลซื้อย้อนหลัง ให้คำนวณยอดสต๊อกใหม่ก่อนดู ([[howto-stock-recalc]])
- ถ้าผู้ใช้ไม่มีสิทธิ์ดูต้นทุน จะไม่เห็นช่องต้นทุนและกำไร ([[howto-stock-inquiry-movement]])

## เรื่องหัวข้อ (รวมต้นทุนแฝง)
- มีหัวข้อ กำไรขั้นต้นตามสินค้า (รวมต้นทุนแฝง) ด้วย แต่ตอนนี้ต้นทุนแฝงที่ประมวลผลถูกรวมในต้นทุนเฉลี่ยปกติอยู่แล้ว
- รุ่นปัจจุบันหัวข้อรวมต้นทุนแฝงแสดงต้นทุนเป็นศูนย์ เพราะระบบยังไม่ได้คำนวณต้นทุนส่วนนี้ ให้ใช้หัวข้อปกติเป็นหลัก ถ้าลูกค้าต้องใช้ ให้ส่งต่อเจ้าหน้าที่ ([[faq-stock-hidden-cost-effect]])

## แก้ไข ยกเลิก พิมพ์
- หน้าจอสอบถามอ่านอย่างเดียว กำไรผิดเพราะราคาขายให้แก้บิลขาย กำไรผิดเพราะต้นทุนดู [[ts-stock-cost-wrong]]

## ปัญหาที่พบบ่อย
