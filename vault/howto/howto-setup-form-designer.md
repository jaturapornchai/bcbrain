# สร้าง/แก้ไขแบบฟอร์ม

**ใช้เมื่อ:** ต้องการออกแบบหรือปรับแบบฟอร์มเอกสารที่พิมพ์ เช่น ใบกำกับภาษี ใบเสร็จ ให้ตรงกับกระดาษที่ใช้จริงหรือแบบที่กิจการต้องการ
**เมนู:** เริ่มต้น › สร้าง/แก้ไขแบบฟอร์ม (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin · ถ้าจะทาบกับกระดาษเดิม ให้มีรูปสแกนของฟอร์ม (ไฟล์ PNG, JPG หรือ WebP) · เป็นงานปรับแต่งขั้นสูง แนะนำผู้ที่คุ้นกับการจัดหน้า · เริ่มต้นดู [[start-first-day]]

หน้านี้เป็นกระดาษเปล่าให้วางช่องข้อมูลเอง ตอนนี้เอกสารนี้อธิบายการใช้งานหลัก ปุ่มเชิงลึกบางส่วนไม่ได้ลงรายละเอียด

## ขั้นตอน
1. เปิดเมนู "สร้าง/แก้ไขแบบฟอร์ม"
2. เริ่มจากเปิดแบบที่มีอยู่ (ปุ่มเปิดแบบฟอร์มที่บันทึกไว้) หรือกด "สร้างใหม่ (New Form)" เพื่อเริ่มจากกระดาษเปล่า
3. กดปุ่ม "แก้ไข" ก่อนวางหรือย้ายอะไร ถ้ายังไม่กดจะขึ้น "กรุณากดปุ่ม [แก้ไข] ก่อนวางวัตถุใหม่บนแบบฟอร์ม"
4. ถ้ามีกระดาษเดิม กด "ตั้งค่ารูปพื้นหลังแบบฟอร์ม (Background Form)" หรือ "อัปโหลดรูปฟอร์มมาทาบ" เลือกรูปสแกน แล้วจัดช่องข้อมูลให้ตรงกับรูป
5. ฝั่งซ้ายเป็นคลังฟิลด์ข้อมูล (ชื่อบริษัท หัวเอกสาร รายการสินค้า ฯลฯ) กดเพิ่มลงบนกระดาษ แล้วลากไปวางตามตำแหน่ง ปรับตัวหนา เอียง ขีดเส้นใต้ จัดซ้าย กลาง ขวา และลำดับชั้นหน้า-หลังได้จากแถบเครื่องมือ
6. ทดสอบด้วย "ทดสอบพิมพ์ฟอร์ม / ดูตัวอย่างจริง (Print Preview)" เพื่อดูข้อมูลจริงบนกระดาษ
7. กดบันทึก (ถ้าต้องการเก็บเป็นฟอร์มใหม่อีกชุด ใช้ "บันทึกเป็นรหัสใหม่ (Save As)")

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสแบบฟอร์ม (Form Code) | รหัสของฟอร์มนี้ | ต้องกรอก ระบบเสนอรหัสให้ตอนสร้างใหม่ |
| ภาษาฟอร์ม | ไทย หรือ English | สลับภาษาที่แสดงบนฟอร์ม |
| ขนาดกระดาษ และมุมมอง | เลือกขนาดและแนวกระดาษ | |
| แสดง/ซ่อนรูปพื้นหลังแบบฟอร์ม | เปิดดูรูปทาบตอนจัดตำแหน่ง ปิดตอนพิมพ์จริงบนกระดาษที่มีตัวฟอร์มพิมพ์ไว้แล้ว | |
| ไฮไลต์สีช่องข้อมูล, แสดง/ซ่อนจุดตาราง, แสดง/ซ่อนไม้บรรทัด | ตัวช่วยจัดวาง | ไม่มีผลต่อกระดาษที่พิมพ์ |

## บันทึกแล้วระบบทำอะไรให้
- เก็บแบบฟอร์มไว้ในฐานข้อมูลของกิจการ ใช้เป็นแบบพิมพ์ของเอกสารชนิดนั้นได้ (ไปผูกที่ช่องรหัสแบบพิมพ์ในหน้า [[howto-setup-doc-format]])
- "ส่งออกไฟล์แบบฟอร์ม" เก็บสำรองเป็นไฟล์ในเครื่อง และ "นำเข้าไฟล์แบบฟอร์ม" โหลดกลับมาแก้ต่อ

## แก้ไข ยกเลิก พิมพ์
- ย้อนกลับ (Undo) ได้สูงสุด 25 ขั้น ทำซ้ำ (Redo) ได้
- ลบวัตถุที่เลือกด้วยปุ่มลบ ถ้าวัตถุถูกล็อกตำแหน่งขึ้น "วัตถุนี้ถูกล็อกตำแหน่งอยู่ กรุณาปลดล็อกก่อน"
- "ปิดหน้าจอ" ออกจากโหมดแก้ไข
- การสั่งพิมพ์เอกสารจริงดู [[howto-common-print-document]]
- ปุ่ม AI "อ่านฟอร์มวางตำแหน่งอัตโนมัติ (Clean & Rebuild)" จะล้างวัตถุเดิมบนกระดาษก่อนวางใหม่ ใช้ด้วยความระวังและเก็บสำรองไฟล์ก่อน

## ปัญหาที่พบบ่อย
- พิมพ์แล้วตัวหนังสือเยื้องจากช่อง: เปิดรูปพื้นหลังทาบ แล้วขยับฟิลด์ให้ตรง ทดสอบพิมพ์จริงบนกระดาษเปล่าเทียบกับกระดาษจริง
- วางฟิลด์ไม่ได้: ยังไม่ได้กด "แก้ไข" หรือวัตถุถูกล็อก
- ไม่มีสิทธิ์เปิดหน้านี้: ดู [[ts-common-no-permission]]
- งานออกแบบใหม่ทั้งชุด สอบถามฝ่ายขายหรือผู้ดูแลระบบ
