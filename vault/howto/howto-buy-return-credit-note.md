# ส่งคืนสินค้าให้ผู้ขาย และบันทึกลดหนี้ซื้อ

**ใช้เมื่อ:** คืนสินค้าที่ซื้อมา หรือผู้ขายออกใบลดหนี้ให้เพราะคิดราคาเกิน
**เมนู:** ซื้อ › รับสินค้า ซื้อ/ตั้งหนี้ และเพิ่ม/ลดหนี้ › ส่งคืนสินค้า/ลดหนี้ซื้อ
**ต้องมีก่อน:** ใบซื้อสินค้า/ตั้งหนี้ซื้อ ของผู้ขายรายนั้น ([[howto-buy-purchase-invoice]])

## ขั้นตอน
1. เปิดเมนู กด "เพิ่มใหม่" เลือกรหัสเจ้าหนี้และประเภทภาษีให้ตรงกับใบซื้อเดิม
2. เลือก "ประเภทการส่งคืน" (ดูตาราง)
3. กด "ดึงเอกสาร" เลือกใบซื้อเดิม ระบบดึงรายการมาให้
4. แก้จำนวนให้เหลือเท่าที่คืนจริง หรือแก้ยอดเงินที่ลดหนี้
5. ใส่ "สาเหตุ:" และเลขที่ใบลดหนี้ของผู้ขายในช่องเลขที่ใบกำกับภาษี
6. ถ้าเลือกแบบเงินสด ใส่ช่องทางรับเงินคืนที่แท็บ "การรับ/จ่ายชำระเงิน"
7. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ประเภทการส่งคืน | ใช้เมื่อ | ผลกับสต๊อก |
|---|---|---|
| ลดหนี้เจ้าหนี้, ลดสินค้า | คืนของ และหักจากหนี้ที่ค้างจ่าย | ตัดสินค้าออกจากคลัง |
| ลดหนี้เจ้าหนี้, ราคาผิด (ไม่มีผลกับสต๊อกสินค้า) | ผู้ขายลดราคา ของไม่ได้คืน | จำนวนสินค้าไม่เปลี่ยน |
| ส่งคืนเงินสด | คืนของ และผู้ขายคืนเป็นเงิน | ตัดสินค้าออกจากคลัง |
| ราคาผิดเงินสด (ไม่มีผลกับสต๊อกสินค้า) | ผู้ขายลดราคาและคืนเป็นเงิน | จำนวนสินค้าไม่เปลี่ยน |

## บันทึกแล้วระบบทำอะไรให้
- แบบลดหนี้เจ้าหนี้: ลดยอดหนี้ค้างจ่ายของผู้ขาย ตอนจ่ายชำระหนี้ใบนี้จะขึ้นเป็นยอดติดลบให้หักกับหนี้ใบอื่น ([[howto-ap-payment]])
- แบบเงินสด: ไม่ลดหนี้ค้างจ่าย แต่บันทึกเงินที่ได้รับคืน
- ลงบัญชี: เจ้าหนี้การค้า (หรือเงินที่รับคืน) คู่กับ ซื้อสินค้า และ ภาษีซื้อ ฝั่งลดลง ([[howto-buy-gl-posting]])
- ลดภาษีซื้อในทะเบียนภาษีซื้อ

## แก้ไข ยกเลิก พิมพ์
- ยกเลิกด้วยเมนู ยกเลิกส่งคืนสินค้า/ลดหนี้ซื้อ ([[howto-buy-cancel-docs]])
- ใบที่ถูกนำไปวางบิลหรือจ่ายชำระหนี้แล้ว ลบไม่ได้ ระบบตอบ "เอกสาร ... มีการอ้างอิงไปแล้วโดยเอกสาร ... ไม่สามารถลบได้" ([[ts-buy-cannot-edit]])
- ข้อควรรู้: รุ่นปัจจุบันยังไม่กันการแก้ไขใบลดหนี้ที่จ่ายชำระไปแล้ว ถ้าลูกค้าต้องแก้ใบที่จ่ายแล้ว อย่าแก้เอง ให้ส่งต่อเจ้าหน้าที่

## ปัญหาที่พบบ่อย
- "ส่งคืนเกินจำนวน" หรือ "ส่งคืนเกินมูลค่า : ..." → คืนเกินกว่าที่ซื้อมา ([[ts-buy-return-over]])
- ไม่พบใบซื้อให้ดึง → รหัสเจ้าหนี้หรือประเภทภาษีไม่ตรงกับใบซื้อ ([[ts-buy-ref-doc-not-listed]])
- "ไม่พบรายการอ้างอิง : ... ..." → บรรทัดที่อ้างถึงไม่มีในใบซื้อเดิม ให้ดึงเอกสารใหม่
