# กำหนดกลุ่มพนักงาน

**ใช้เมื่อ:** ต้องการจัดพนักงานเป็นกลุ่มตามหน้าที่ (จัดซื้อ ขาย คลัง) และกำหนดว่าใครอนุมัติเอกสารได้
**เมนู:** เริ่มต้น › ตั้งค่าองค์กร พนักงาน และเอกสาร › กำหนดกลุ่มพนักงาน (มีป้าย Admin)
**ต้องมีก่อน:** ล็อกอินเป็นผู้ใช้ Admin · มีพนักงานในระบบแล้ว ([[howto-setup-staff]]) · เริ่มต้นดู [[start-first-day]]

## ขั้นตอน
1. เปิดเมนู "กำหนดกลุ่มพนักงาน" กด "เพิ่มใหม่"
2. กรอก "รหัสกลุ่มพนักงาน" และ "ชื่อกลุ่มพนักงาน 1" (ชื่อ 2 เป็นภาษาอังกฤษ)
3. ติ๊กชนิดของกลุ่มและสิทธิ์อนุมัติที่กลุ่มนี้มี
4. ไปแท็บ "รายชื่อพนักงานในกลุ่ม" ใส่รหัสพนักงานทีละแถว หรือกดปุ่ม "เลือกทั้งหมด" เพื่อใส่ทุกคน
5. ถ้าต้องการกำหนดผู้อนุมัติ ไปแท็บ "ผู้อนุมัติใบสั่งซื้อ (PO)", "ผู้อนุมัติใบสั่งขาย (SS)" หรือ "ผู้อนุมัติใบขอซื้อ (SR/PR)" แล้วใส่รหัสพนักงานผู้อนุมัติ
6. กดบันทึก

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| รหัสกลุ่มพนักงาน | รหัสสั้นของกลุ่ม | ห้ามซ้ำ ถ้าซ้ำขึ้น "รหัส ... มีอยู่แล้ว" |
| ชื่อกลุ่มพนักงาน 1 / 2 | ชื่อไทย / อังกฤษ | ต้องกรอกชื่อ ไม่งั้นขึ้น "กรุณาระบุชื่อกลุ่มพนักงาน" |
| กลุ่มจัดซื้อ (PO), กลุ่มขาย (SO), กลุ่มคลังสินค้า (WH), กลุ่มพนักงานขาย (Sale Group) | ติ๊กชนิดกลุ่ม | ใช้จัดหมวดหมู่ รุ่นปัจจุบันยังไม่มีผลต่อการทำงานของเอกสาร |
| อนุมัติใบขอซื้อ (PR Approve), อนุมัติใบสั่งซื้อ (PO Approve), อนุมัติใบเสนอราคา/ราคาขาย, อนุมัติใบสั่งขาย (SO Approve) | ติ๊กสิทธิ์อนุมัติ | ก่อนใช้คุมสิทธิ์จริง ส่งต่อเจ้าหน้าที่ช่วยตรวจตั้งค่า |
| แก้ไขข้อมูลหลัก (Master Data) | ติ๊กถ้ากลุ่มนี้แก้ข้อมูลหลักได้ | ระบบตรวจจริงเฉพาะตอนบันทึกข้อมูลสินค้า ถ้าผู้ใช้อยู่ในกลุ่มที่ไม่ติ๊กข้อนี้ จะขึ้น "ไม่อนุญาตให้แก้ไขข้อมูลหลัก (กลุ่มผู้ใช้ปิดสิทธิ์แก้ไขข้อมูลหลัก) กรุณาติดต่อผู้ดูแลระบบ" (ผู้ใช้ที่ไม่อยู่ในกลุ่มใดแก้ได้) ข้อมูลหลักอื่นไม่ถูกตรวจ |
| รหัสพนักงาน (ในตารางของแต่ละแท็บ) | รหัสพนักงานที่มีอยู่แล้ว | ถ้าไม่มีรหัสนี้ขึ้น "ไม่พบรหัสพนักงาน" |

## บันทึกแล้วระบบทำอะไรให้
เก็บกลุ่ม รายชื่อสมาชิก และรายชื่อผู้อนุมัติของแต่ละชนิดเอกสาร ระบบตรวจว่ารหัสพนักงานทุกแถวมีอยู่จริง รายชื่อผู้อนุมัติในแท็บ 2 ถึง 4 เป็นการเก็บรายชื่อ รุ่นปัจจุบันยังไม่พบว่าระบบนำไปบังคับให้ต้องอนุมัติเอกสาร ถ้าลูกค้าต้องการระบบอนุมัติเอกสาร ให้ส่งต่อเจ้าหน้าที่

## แก้ไข ยกเลิก พิมพ์
- แก้ไข: เลือกกลุ่ม กด "แก้ไข" เพิ่มหรือลบแถวพนักงาน แล้วบันทึก
- ลบกลุ่ม: กด "ลบ" แล้วยืนยัน ถ้ากลุ่มถูกใช้อยู่ระบบขึ้น "ไม่อนุญาตให้ลบ ...:" พร้อมเหตุผล

## ปัญหาที่พบบ่อย
- "ไม่พบรหัสพนักงาน": พนักงานคนนั้นยังไม่ถูกสร้าง สร้างที่ [[howto-setup-staff]] ก่อน
- เรื่องจำกัดคลังตามกลุ่ม ดู [[howto-setup-warehouse-rights]]
