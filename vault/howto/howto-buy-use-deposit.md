# หักเงินมัดจำที่จ่ายไว้ ออกจากใบซื้อ (แท็บใช้เงินมัดจำ)

**ใช้เมื่อ:** เคยจ่ายเงินมัดจำให้ผู้ขายไว้ และตอนนี้ได้รับสินค้าหรือบิลแล้ว ต้องการหักมัดจำออกจากยอดที่ต้องจ่าย
**เมนู:** ซื้อ › ซื้อสินค้า/ตั้งหนี้ซื้อ หรือ ซื้อ › ซื้อสินค้าแบบทะยอยรับ (รับของก่อนตั้งหนี้) › ตั้งหนี้ซื้อจากการรับสินค้า หรือ เจ้าหนี้ › ตั้งหนี้อื่นๆ (เจ้าหนี้) › แท็บ "ใช้เงินมัดจำ"
**ต้องมีก่อน:** ใบจ่ายเงินมัดจำ หรือ จ่ายเงินมัดจำยกมา ของผู้ขายรายเดียวกันที่ยังมียอดคงเหลือ ([[howto-buy-advance-deposit]])

## ขั้นตอน
1. ในใบซื้อ เลือกรหัสเจ้าหนี้ก่อน
2. ไปแท็บ "ใช้เงินมัดจำ" กด "ดึงเอกสารมัดจำ"
3. ระบบแสดงใบมัดจำของเจ้าหนี้รายนี้ที่ยังมียอดคงเหลือ พร้อมช่อง เลขที่เอกสาร วันที่ ยอดเงิน คงเหลือ
4. ใส่ "ยอดตัด" ในใบที่ต้องการหัก ลบแถวที่ไม่ใช้ออก
5. ดู "รวมยอดตัดเงินมัดจำ:" แล้วกลับไปตรวจยอดสุทธิของใบซื้อ
6. กด "บันทึก"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ยอดตัด | ยอดมัดจำที่จะหักในใบนี้ | ต้องมากกว่า 0 และไม่เกินคงเหลือ |
| หมายเหตุ | ข้อความประกอบ | ไม่บังคับ |

## บันทึกแล้วระบบทำอะไรให้
- ยอดหักมัดจำท้ายบิลคิดจากแท็บนี้ ยอดตัดที่กรอกเป็นยอดรวมภาษี ถ้าใบซื้อเป็นภาษีแยกนอก ระบบถอดภาษีออกก่อนนำไปหัก
- ลงบัญชี: ลดยอด เงินมัดจำจ่าย ตามยอดที่ตัด และบันทึกค่าสินค้าเต็มจำนวนในบัญชีซื้อสินค้า
- ยอดคงเหลือของใบมัดจำลดลง ใบที่ถูกตัดแล้วจะลบไม่ได้ ([[ts-buy-deposit-cannot-delete]])
- แท็บนี้ใช้ได้กับใบจ่ายเงินมัดจำเท่านั้น ใบจ่ายเงินล่วงหน้าไม่ขึ้นในรายการ ([[faq-buy-advance-vs-deposit]])

## แก้ไข ยกเลิก พิมพ์
- แก้ยอดตัดได้ด้วยการแก้ไขใบซื้อ ถ้าใบซื้อยังแก้ได้
- ยกเลิกใบซื้อ ยอดมัดจำที่ตัดไปจะกลับมาเป็นคงเหลือ ([[howto-buy-cancel-docs]])

## ปัญหาที่พบบ่อย
- "กรุณาระบุรหัสเจ้าหนี้ก่อนดึงเอกสารมัดจำ" → เลือกรหัสเจ้าหนี้ที่หัวเอกสารก่อน
- "ยอดตัดจ่ายมากกว่ายอดคงเหลือ: เอกสาร ... เกินอยู่ ..." → ลดยอดตัด ([[ts-buy-deposit-errors]])
- "ยอดมัดจำมากกว่ามูลค่าสุทธิ" → ยอดหักมัดจำเกินยอดใบซื้อ ([[ts-buy-deposit-errors]])
- "เลือกเอกสารเงินมัดจำ ... ซ้ำ" → มีใบมัดจำเดียวกันสองแถว ลบออกหนึ่งแถว
