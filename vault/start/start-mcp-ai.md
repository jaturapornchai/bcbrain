# เชื่อมต่อผู้ช่วย AI ภายนอกแบบอ่านอย่างเดียว (MCP Token)

ระบบมีหน้าจอสำหรับสร้างรหัสเชื่อมต่อให้ผู้ช่วย AI ภายนอกเข้ามาช่วยสอบถามและวิเคราะห์ข้อมูลกิจการได้อย่างปลอดภัย โดยจำกัดสิทธิ์เป็น **อ่านอย่างเดียว (Read-Only) เท่านั้น** ไม่สามารถแก้ไขหรือลบเอกสารบัญชีได้

---

## 1. สิทธิ์และความปลอดภัย

- **Admin เท่านั้น**: เมนูนี้สงวนสิทธิ์เฉพาะผู้ดูแลระบบ เข้าได้ที่ "เริ่มต้น > ตั้งค่าองค์กร พนักงาน และเอกสาร > จัดการ MCP Token เชื่อมต่อ AI (Read-Only)" (รหัสเมนู **1026**)
- **อ่านข้อมูลได้อย่างเดียว**: ผู้ช่วย AI ที่เชื่อมต่อด้วย Token จะเรียกดูข้อมูลได้เฉพาะฐานข้อมูลที่คุณเลือกอนุญาต และไม่สามารถสั่งแก้ไข ยกเลิก หรือบันทึกเอกสารบัญชีได้
- **กำหนดวันหมดอายุได้**: เลือกอายุการใช้งานของ Token ได้ตั้งแต่ **1 ถึง 365 วัน**

---

## 2. ขั้นตอนสร้าง Token ใหม่

1. เปิดเมนู **จัดการ MCP Token เชื่อมต่อ AI (Read-Only)**
2. กรอก **ชื่อเรียก Token** เพื่อระบุว่านำไปใช้กับเครื่องหรือผู้ช่วย AI ตัวใด
3. ระบุ **จำนวนวันหมดอายุ** (1–365 วัน)
4. ติ๊กเลือก **ฐานข้อมูลกิจการที่อนุญาต** อย่างน้อย 1 ฐานข้อมูล
5. กดสร้าง Token — หน้าจอจะแสดงข้อความ **"กรุณาคัดลอก Token ด้านล่างเก็บไว้ทันที (แสดงเพียงครั้งเดียว)"**
   - คัดลอกเก็บไว้ในที่ปลอดภัยทันที เพราะเมื่อปิดหน้าต่างแล้วระบบจะไม่แสดงรหัสเต็มซ้ำอีกเพื่อความปลอดภัย
6. บนหน้าจอเดียวกันยังมีเครื่องมือทดสอบการเชื่อมต่อให้ลองเรียกดูข้อมูลจริงได้ทันที

---

## 3. การเพิกถอน Token เมื่อเลิกใช้งาน

- หากพบว่ามีการทำ Token หาย เปลี่ยนเครื่อง หรือไม่ต้องการให้เชื่อมต่ออีกต่อไป ให้เข้าหน้าเดิมแล้วกดปุ่ม **เพิกถอน (Revoke)** ที่รายการ Token นั้น ระบบจะตัดการเชื่อมต่อทันที

---

## คำถามที่ลูกค้ามักถาม

- **ถ้าเชื่อมต่อผู้ช่วย AI ภายนอกด้วย MCP Token แล้ว AI จะเผลอแก้ไข ยกเลิก หรือลบบิลบัญชีของเราได้ไหม?**
  ไม่ได้เด็ดขาดครับ ระบบจำกัดสิทธิ์ MCP Token เป็น **อ่านอย่างเดียว (Read-Only) 100%** และเข้าดูได้เฉพาะฐานข้อมูลบริษัทที่คุณติ๊กอนุญาตเท่านั้น ไม่สามารถแก้ไขหรือลบเอกสารใดๆ ได้
- **ใครสามารถสร้างหรือยกเลิก MCP Token ในระบบได้บ้าง?**
  สงวนสิทธิ์เฉพาะ **ผู้ดูแลระบบ (Admin) เท่านั้น** ที่รหัสเมนู **1026** (จัดการ MCP Token เชื่อมต่อ AI) โดยกำหนดวันหมดอายุได้ตั้งแต่ **1 ถึง 365 วัน**
- **ลืมคัดลอกรหัส Token ตอนสร้างเสร็จ ปิดหน้าต่างไปแล้วกลับมาดูรหัสเดิมได้ไหม?**
  ไม่ได้ครับ เพื่อความปลอดภัยระบบจะแสดงรหัสเต็มเพียงครั้งเดียวตอนสร้าง (พร้อมข้อความแจ้งเตือนให้คัดลอกเก็บไว้ทันที) หากลืมคัดลอกให้สร้าง Token ใหม่และกดเพิกถอนตัวเดิมครับ
- **ถ้าเปลี่ยนเครื่องใช้งานหรือสงสัยว่า Token หลุด ต้องรีบทำยังไง?**
  เข้าหน้าจอ **จัดการ MCP Token เชื่อมต่อ AI (Read-Only)** (รหัสเมนู **1026**) แล้วกดปุ่ม **เพิกถอน (Revoke)** ที่รายการนั้น ระบบจะตัดสิทธิ์การเชื่อมต่อทันทีครับ
