# ปุ่มลัดคีย์บอร์ด

**ใช้เมื่อ:** อยากทำงานเร็วขึ้นด้วยคีย์บอร์ด ไม่ต้องคลิกเมาส์ทุกครั้ง
**เมนู:** ปุ่มลัดส่วนใหญ่ใช้ได้ในหน้าจอรายการข้อมูลหลัก (เช่น รายการสินค้า) ส่วนหน้าจอเอกสารใช้ได้เฉพาะ Ctrl + S ดูรายการปุ่มลัดได้ที่ปุ่ม "คำแนะนำการใช้งาน (Help)" ซึ่งมีบนหน้าจอรายการ (เปิด "คู่มือคีย์ลัด BC Account (Keyboard Shortcuts)")
**ต้องมีก่อน:** เปิดหน้าจอที่ต้องการแล้ว

## ขั้นตอน
1. เปิดหน้าจอข้อมูล เช่น รายการสินค้า หรือหน้าจอเอกสาร
2. กดปุ่มลัดตามตารางด้านล่าง
3. ถ้าจำไม่ได้ กดปุ่ม "คำแนะนำการใช้งาน (Help)" เพื่อดูคู่มือคีย์ลัด

## ช่องสำคัญที่ต้องกรอก
| ปุ่ม | ทำอะไร | หมายเหตุ |
|---|---|---|
| Ctrl + S | บันทึกข้อมูลในหน้าจอแก้ไขหรือเพิ่มใหม่ | ใช้ได้ทั้งหน้าจอข้อมูลหลักและเอกสาร เฉพาะตอนที่อยู่ในโหมดแก้ไขหรือเพิ่มใหม่ |
| Escape | ยกเลิกโหมดแก้ไข ปิดหน้าต่างตัวกรอง หรือล้างค่า | ในหน้าต่างค้นหาใช้ปิดหน้าต่าง |
| Insert หรือ Alt + N | สร้างรายการใหม่ | เฉพาะหน้าจอรายการข้อมูลหลัก |
| Ctrl + F | ไปที่ช่องค้นหาทันที | เฉพาะหน้าจอรายการข้อมูลหลัก |
| ลูกศรขึ้น ลง | เลื่อนเลือกรายการก่อนหน้าหรือถัดไปในตาราง | |
| Home / End | ไปแถวแรกสุด หรือแถวสุดท้าย | |
| PageUp / PageDown | ข้ามทีละ 10 แถว | ในหน้าต่างค้นหาใช้เปลี่ยนหน้า |
| Enter | เลือกรายการ หรือไปช่องถัดไป | ในหน้าต่างค้นหาและตารางรายการสินค้า |
| Ctrl + B | ค้นด้วยบาร์โค้ด | ในหน้าต่างค้นหาสินค้า (ได้รหัสสินค้าจากบาร์โค้ดแล้วใส่ช่องค้นหา ถ้าไม่เจอรายการจะไม่เปลี่ยน) |
| คลิกหัวคอลัมน์ | เรียงข้อมูลตามคอลัมน์นั้น | |

## บันทึกแล้วระบบทำอะไรให้
- Ctrl + S ทำงานเหมือนกดปุ่ม "บันทึก" ทุกประการ รวมถึงการตรวจสิทธิ์และงวดบัญชี

## แก้ไข ยกเลิก พิมพ์
- ถ้ากด Ctrl + P ของเบราว์เซอร์ขณะเปิดหน้าต่างตัวอย่างก่อนพิมพ์ตอนเอกสารยังไม่ได้บันทึก ระบบจดไว้ว่ามีการพยายามพิมพ์ก่อนบันทึก ควรบันทึกก่อนแล้วพิมพ์จากปุ่มในหน้าต่างพิมพ์ ดู [[howto-common-print-document]]

## ปัญหาที่พบบ่อย
- ผู้ที่เคยใช้โปรแกรมรุ่นติดตั้งในเครื่องอาจคุ้นกับปุ่ม F3 F4 F8 ในหน้าต่างค้นหาสินค้า บนเว็บนี้กดปุ่มเหล่านี้บนคีย์บอร์ดแล้วยังไม่ทำงาน ให้คลิกปุ่มบนจอแทน คือ "เลือกตามคลัง/ที่เก็บ", "เลือกตามคลัง/ที่เก็บ/หน่วยนับ" และ "ยอดคงเหลือตามคลัง"
- ตารางรายการสินค้าในเอกสารใช้สูตรคำนวณแทนคีย์ลัด ดู [[howto-common-grid-editing]]
