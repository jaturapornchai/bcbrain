# เลือกฐานข้อมูล และสลับฐานข้อมูล

**ใช้เมื่อ:** เข้าสู่ระบบแล้ว ต้องการเลือกว่าจะทำงานกับกิจการไหน หรือมีหลายบริษัทแล้วต้องการสลับไปมา
**เมนู:** หน้าเลือกฐานข้อมูล (ขึ้นอัตโนมัติหลังเข้าสู่ระบบ)
**ต้องมีก่อน:** เข้าสู่ระบบด้วย Google แล้ว ดู [[start-login-logout]]

1 ฐานข้อมูล = ข้อมูลของ 1 กิจการ แยกจากกันเด็ดขาด เอกสาร สต็อก และบัญชีไม่ปนกัน

## ขั้นตอน
1. หน้าเลือกฐานข้อมูลแสดงหัวข้อ "ฐานข้อมูลที่คุณมีสิทธิ์เข้าใช้งาน (...)" พร้อมจำนวน Admin และ Member
2. แต่ละการ์ดบอกชื่อกิจการ รหัสฐานข้อมูล รหัสผู้ใช้ที่ผูกไว้ และป้ายสิทธิ์
   - **Admin** "ทำได้ทุกอย่าง + จัดการสมาชิก/สิทธิ์จอ"
   - **Member** "ใช้หน้าจอตามสิทธิ์ที่ได้รับ"
3. กด "เข้าใช้งานฐานข้อมูล" ที่การ์ดที่ต้องการ
4. ระบบเปิดหน้า "เมนูรวมทุกระบบ" ให้เลือกระบบงาน กด "เข้าใช้งานระบบนี้" ที่การ์ด BC Account เพื่อเข้าระบบบัญชี ดู [[start-main-menu]]

**สลับฐานข้อมูลระหว่างทำงาน**
1. คลิกชื่อฐานข้อมูลที่แถบด้านบน ("คลิกเพื่อสลับฐานข้อมูล / สร้างฐานข้อมูลใหม่ / จัดการสมาชิกและสิทธิ์จอ") ข้างชื่อมีป้าย Admin, Member หรือ Demo บอกสิทธิ์ของคุณ
2. ระบบกลับไปหน้าเลือกฐานข้อมูล ไม่ต้องเข้าสู่ระบบใหม่ (ไอคอนออกด้านขวาบนในระบบงานจะพากลับหน้า "เมนูรวมทุกระบบ" ก่อน ต้องกดซ้ำอีกครั้งที่หน้านั้นจึงจะถึงหน้าเลือกฐานข้อมูล)
3. เลือกฐานข้อมูลอื่นแล้วกด "เข้าใช้งานฐานข้อมูล"

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| (ไม่มีช่องกรอก) | เลือกการ์ดฐานข้อมูล | ปุ่ม "สมาชิก & สิทธิ์จอ" มีเฉพาะผู้ที่เป็น Admin |
| อีเมลผู้ใช้งาน (Google / Gmail) | อีเมลสมาชิกที่จะเพิ่ม (Admin เท่านั้น) | กดปุ่ม "เพิ่ม/บันทึก" เพื่อเพิ่มหรือแก้สมาชิก |

## บันทึกแล้วระบบทำอะไรให้
- จำว่าเลือกฐานข้อมูลไหนไว้ ระหว่างใช้งานทุกหน้าจอจะทำงานกับฐานข้อมูลนั้น
- ถ้าเข้ามาจากลิงก์ของหน้าจอเดิม (เช่น หลังหมดเวลาใช้งาน) ระบบพากลับไปหน้าจอนั้นให้

## แก้ไข ยกเลิก พิมพ์
- ไอคอนถังขยะลบสมาชิกในหน้าจัดการสมาชิก ลบทันทีโดยไม่ถามยืนยันอีกครั้ง ต้องกดให้แน่ใจก่อน
- เพิ่มสมาชิกหรือกำหนดสิทธิ์ ดู [[howto-user-invite-member]] [[howto-user-screen-permission]]
- สร้างฐานข้อมูลใหม่ ดู [[start-create-database]]

## ปัญหาที่พบบ่อย
- ขึ้น "ยังไม่มีฐานข้อมูลที่ผูกกับบัญชีนี้" → อีเมลนี้ยังไม่ได้สร้างหรือยังไม่ถูกเพิ่มเป็นสมาชิก ให้ Admin ของกิจการเพิ่มอีเมลให้ หรือสร้างฐานข้อมูลใหม่เอง
- ขึ้น "คุณไม่มีสิทธิ์เข้าใช้งานฐานข้อมูลนี้ (PDPA Access Denied)" → ดู [[ts-common-no-permission]]
- เข้าผิดบัญชี Google → ออกจากระบบแล้วเข้าใหม่ด้วยบัญชีที่ถูก ดู [[start-login-logout]]
