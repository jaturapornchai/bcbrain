# คำอธิบายบอลลูน

**ใช้เมื่อ:** ไม่แน่ใจว่าปุ่มหรือช่องบนหน้าจอใช้ทำอะไร อยากได้คำอธิบายภาษาไทยทันทีบนจอ
**เมนู:** ปุ่ม "คำอธิบาย" ที่แถบด้านบน (มีที่หน้าเข้าสู่ระบบด้วย) ข้างปุ่มมีป้าย ON หรือ OFF บอกสถานะ
**ต้องมีก่อน:** ไม่มี

## ขั้นตอน
1. กดปุ่ม "คำอธิบาย" ที่แถบด้านบน ชี้เมาส์ที่ปุ่มจะเห็นข้อความทำนอง "คลิกเพื่อเปิดระบบคำอธิบายบอลลูนเมื่อวางเมาส์ค้าง 2 วินาที (Balloon Help: OFF)"
2. วางเมาส์ค้างบนปุ่มหรือช่องที่สงสัยประมาณ 2 วินาที
3. กล่องคำอธิบายจะขึ้น แบ่งเป็นหัวข้อ จุดประสงค์, วิธีใช้, ตัวอย่าง, คำเตือน, หมายเหตุ (บางช่องมีไม่ครบทุกหัวข้อ)
4. ปิดกล่องได้โดยกดไอคอนกากบาท (X) ที่กล่อง หรือคลิกที่อื่น กดแป้นใดก็ได้ เลื่อนหน้าจอ หรือเลื่อนเมาส์ออก
5. กล่องจะขึ้นเฉพาะปุ่มหรือช่องที่ระบบมีคำอธิบายเตรียมไว้ ช่องที่ไม่มีคำอธิบายจะไม่ขึ้นอะไร
6. ถ้าไม่อยากให้ขึ้นอีก กดปุ่มเดิมเพื่อปิดระบบ (ป้ายเปลี่ยนเป็น OFF ชี้เมาส์จะเห็นข้อความ "คลิกเพื่อปิดระบบคำอธิบายบอลลูน" ตอนกำลังเปิดอยู่)

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| (ไม่มี) | กดปุ่มเปิดหรือปิดอย่างเดียว | ค่าเริ่มต้นคือปิด |

## บันทึกแล้วระบบทำอะไรให้
- จำการตั้งค่าเปิดหรือปิดไว้ในเบราว์เซอร์เครื่องนั้น ครั้งหน้าไม่ต้องตั้งใหม่ (ใช้เครื่องอื่นต้องตั้งอีกครั้ง)
- ถ้าเลือกภาษาอังกฤษไว้ คำอธิบายจะแสดงเป็นภาษาอังกฤษ ดู [[faq-general-language-english]]

## แก้ไข ยกเลิก พิมพ์
- ไม่มี

## ปัญหาที่พบบ่อย
- กล่องคำอธิบายเด้งบ่อยจนรำคาญ → ปิดระบบคำอธิบายบอลลูนที่ปุ่มบนแถบด้านบน
- วางเมาส์แล้วไม่ขึ้น → ตรวจว่าเปิดระบบไว้แล้ว และวางเมาส์นิ่งให้ครบ 2 วินาที
