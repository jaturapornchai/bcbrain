# สร้างฐานข้อมูลใหม่

**ใช้เมื่อ:** เริ่มใช้งานกับกิจการของตัวเอง เพิ่มบริษัทใหม่ หรืออยากได้ฐานข้อมูลไว้ทดลองแยกจากของจริง
**เมนู:** หน้าเลือกฐานข้อมูล › ปุ่ม "สร้างข้อมูลใหม่ (สร้างฐานข้อมูลใหม่)"
**ต้องมีก่อน:** เข้าสู่ระบบด้วย Google แล้ว ดู [[start-login-logout]]

## ขั้นตอน
1. ที่หน้าเลือกฐานข้อมูล กด "สร้างข้อมูลใหม่ (สร้างฐานข้อมูลใหม่)"
2. กรอก "ตั้งชื่อฐานข้อมูล (Database Name)" ระหว่างพิมพ์ระบบจะตรวจชื่อซ้ำให้ ("กำลังตรวจสอบชื่อฐานข้อมูลซ้ำ...") ถ้าใช้ได้จะขึ้น "สามารถใช้ชื่อฐานข้อมูลนี้ได้"
3. กรอก "ชื่อบริษัท / ชื่อกิจการ"
4. กด "ยืนยันสร้างฐานข้อมูลใหม่" รอสักครู่ ("กำลังสร้างฐานข้อมูลใหม่...")
5. สำเร็จจะขึ้น "สร้างฐานข้อมูลใหม่ "..." (...) สำเร็จแล้ว! บัญชีของคุณเป็น Admin..." และฐานข้อมูลใหม่จะอยู่ในรายการ
6. กด "เข้าใช้งานฐานข้อมูล" แล้วตั้งค่าเริ่มต้นตาม [[start-first-day]]

## ช่องสำคัญที่ต้องกรอก
| ช่อง | กรอกอะไร | หมายเหตุ |
|---|---|---|
| ตั้งชื่อฐานข้อมูล (Database Name) | ภาษาอังกฤษพิมพ์เล็ก ตัวเลข หรือขีดล่าง ยาว 3-40 ตัว | ต้องขึ้นต้นด้วยตัวอักษร a-z ห้ามซ้ำกับผู้อื่น ตั้งแล้วเปลี่ยนไม่ได้ |
| ชื่อบริษัท / ชื่อกิจการ | ชื่อที่จะแสดงบนการ์ดและในข้อมูลบริษัท | แก้ภายหลังได้ที่ [[howto-setup-company-profile]] |

## บันทึกแล้วระบบทำอะไรให้
- สร้างฐานข้อมูลเปล่า ไม่มีข้อมูลตัวอย่าง
- ใส่ค่าเริ่มต้นให้: ประเภทปีเป็นพุทธศักราช ทศนิยม 2 ตำแหน่ง ชื่อกิจการ และสาขาสำนักงานใหญ่
- ผู้สร้างเป็น Admin ของฐานข้อมูลนั้นทันที เพิ่มคนอื่นเข้ามาได้ภายหลัง ดู [[howto-user-invite-member]]
- 1 บัญชี Google สร้างฐานข้อมูลได้ไม่จำกัดจำนวน (เรื่องแพ็กเกจและค่าบริการ สอบถามฝ่ายขาย)

## แก้ไข ยกเลิก พิมพ์
- ชื่อฐานข้อมูลเปลี่ยนไม่ได้หลังสร้าง ชื่อกิจการแก้ได้ที่ข้อมูลบริษัท
- หน้าจอนี้ไม่มีปุ่มลบฐานข้อมูล ถ้าต้องการลบ ส่งต่อทีมงาน

## ปัญหาที่พบบ่อย
